## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем. Побудована як кумулятивна ієрархія рівнів:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-CAT  ⊂  SUBIT_∞
```

**Ключова архітектурна зміна v6.3.** Усі попередні версії намагалися класифікувати множину P одним із чотирьох-п'яти значень. Це принципово неможливо: тип орбіти (як P еволюціонує) і відношення включення (як образ F(P) співвідноситься з P) — **дві незалежні властивості**. v6.3 розділяє їх і будує класифікацію як пару:

```
Classify(P) := ( OrbitType(P), InclusionType(P) )
```

Це виправляє помилку P0-1 аудиту v6.2: скінченна множина може мати тип EVENTUALLY_PERIODIC і одночасно DISJOINT_IMAGE, і це не робить її хаотичною.

**CHAOTIC** залишається лише для APERIODIC-множин із додатною топологічною ентропією. На скінченному рівні CHAOTIC недосяжний — але тепер це випливає з коректного означення, а не з хибного аргументу.

**Система статусів** — вектор із семи незалежних прапорців: DEFINED / PROVED ON PAPER / FORMALLY VERIFIED / IMPLEMENTED / TESTED / EMPIRICALLY SUPPORTED / OPEN-WITHDRAWN. На момент v6.3-draft **усі FORMALLY VERIFIED = НІ** (Lean-пакет не опубліковано).

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

**DEFINED.** Один скінченний алфавіт A потужності 4.

**Семантична реалізація:**

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація (білаттис Белнапа):**

```
𝔸 = { T, F, B, N }
```

**Кодування:**

| Bigram | Логічна | Семантична (WHO / WHERE / WHEN) |
|---|---|---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Розмежування (виправлення P1-1 v6.2).** Семантична й логічна реалізації — це **три окремі бієкції** на один і той самий абстрактний алфавіт A = {00, 01, 10, 11}:

```
β_WHO   : A_WHO   → 𝔸
β_WHERE : A_WHERE → 𝔸
β_WHEN  : A_WHEN  → 𝔸
```

Явно: β_WHO(ME) = T, β_WHO(WE) = B, β_WHO(YOU) = F, β_WHO(THEY) = N; аналогічно для WHERE і WHEN.

Білаттисна структура на 𝔸 **не переноситься автоматично** на ґратку Ω у §7. Ω — самостійна алгебра (див. §7.3).

**Білаттисна структура** на 𝔸:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

## 2. Простір станів S₀

**DEFINED.** S₀ = A³, |S₀| = 4³ = 64. Кожен стан s = (α, β, γ) кодується 6 бітами: b₁b₂ = WHO, b₃b₄ = WHERE, b₅b₆ = WHEN.

**Гексаграмна нотація** (Додаток A) — компактний запис 6-бітного слова.

# ЧАСТИНА II. SUBIT⁺ — скінченна динаміка

## 3. Простір правил і розширений стан

**DEFINED.** ℛ = {ρ₁, …, ρₙ}, ρᵢ : S₀ → S₀ — скінченна множина.

**DEFINED.** Розширений стан: ŝ = (s, ρ) ∈ S₀ × ℛ.

**Застереження 3.1.** SUBIT⁺ еквівалентний автономному детермінованому скінченному автомату з |Q| = |S₀ × ℛ|.

## 4. Оператор еволюції

**DEFINED.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

**Аксіома 4.1.** F — тотальна.

## 5. Траєкторії та класифікація точок (переписано в v6.3)

**Переписано з нуля.** У v6.2 означення FIXED/PERIODIC/NONRETURNING перетиналися, а алгоритм класифікації повертав не початкову категорію точки (P0-4).

### 5.1. Траєкторія

**DEFINED.** τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …), ŝₙ₊₁ = F(ŝₙ).

### 5.2. Точкова категорія

**Означення 5.2.1.**

```
Ω_point(ŝ) :=
   FIXED           якщо F(ŝ) = ŝ
   PERIODIC(p)     якщо p := min{ k > 1 : Fᵏ(ŝ) = ŝ } існує
   NONRETURNING    інакше
```

**Зауваження 5.2.2.** FIXED і PERIODIC(p) **не перетинаються**: p визначається як мінімальне k > 1, тому p = 1 виключено.

### 5.3. Скінченна періодичність

**Твердження 5.3.1.** Для будь-якого ŝ₀ існують m ≥ 0 і p ≥ 1 такі, що ŝ_{m+p} = ŝ_m.

**PROVED ON PAPER:** принцип Діріхле.
**IMPLEMENTED, TESTED:** Rust `subit-core::trajectory` (незалежна перевірка не проводилася).

### 5.4. Алгоритм класифікації (переписано, виправлення P0-4)

**Алгоритм 5.4.1.**

```
Вхід: ŝ₀, горизонт N_max (вимагається N_max ≥ |S₀ × ℛ|)
Вихід: PointClass(ŝ₀) := (category, m, p, cycle, certificate)

visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← позначку входження ŝₙ у visited
        p ← n − m
        cycle ← [ŝ_m, ŝ_{m+1}, …, ŝ_{n-1}]
        category ←
            FIXED           якщо m = 0 і p = 1
            PERIODIC(p)     якщо m = 0 і p > 1
            NONRETURNING    якщо m > 0
        certificate ← {m, p, cycle}
        повернути (category, m, p, cycle, certificate)
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
повернути (RESOURCE_EXCEEDED, ⊥, ⊥, ⊥, ⊥)
```

**Зауваження 5.4.2.** Категорія стосується **початкової точки** ŝ₀, не точки циклу.

**Приклад 5.4.3.** F(a) = b, F(b) = b.
- ŝ₀ = a. visited = {a}. ŝ₁ = b. visited = {a, b}. ŝ₂ = b ∈ visited, m = 1, p = 1, cycle = [b]. category = NONRETURNING (бо m > 0).
- ŝ₀ = b. visited = {b}. ŝ₁ = b ∈ visited, m = 0, p = 1, cycle = [b]. category = FIXED.

**PROVED ON PAPER.** Коректність: алгоритм коректно розрізняє початкову категорію за m.

### 5.5. Граничне застереження

**Застереження 5.5.1.** Для скінченного S₀ × ℛ: N_max ≥ |S₀ × ℛ| гарантує знаходження повтору.

**Застереження 5.5.2.** Для S_∞ алгоритм 5.4.1 може не завершитися; гілка RESOURCE_EXCEEDED стає змістовною.

# ЧАСТИНА III. SUBIT-CAT — категорія і класифікація

## 6. Класифікація множин (переписано з нуля в v6.3)

**Переписано з нуля.** У v6.2 класифікація множин мала три несумісні означення TRANSIENT і принципово не могла розрізняти тип орбіти й відношення включення (P0-1, P0-2).

### 6.1. Розділення на дві складові

**Ключове архітектурне рішення.** Класифікація множини P ⊆ S_∞ × ℛ — це **пара**:

```
Classify(P) := ( OrbitType(P), InclusionType(P) )
```

де OrbitType описує, **як P еволюціонує**, а InclusionType — **як F(P) співвідноситься з P**. Ці дві властивості незалежні.

### 6.2. OrbitType — тип орбіти

**Означення 6.2.1.**

```
OrbitType(P) :=
   FIXED_SET                якщо F(P) = P і всі точки P F-нерухомі
   PERIODIC_SET(p)          якщо p := min{ k ≥ 1 : Fᵏ(P) = P } існує, і p > 1,
                              і не FIXED_SET
   EVENTUALLY_FIXED(m)      якщо ∃m ≥ 1: F^m(P) = F^{m+1}(P), F^m(P) ≠ P,
                              і m мінімальне
   EVENTUALLY_PERIODIC(m,p) якщо ∃m ≥ 0, p > 1: F^{m+p}(P) = F^m(P),
                              F^m(P) ≠ P, і (m, p) мінімальні лексикографічно
   APERIODIC                якщо не існує жодного (m, p) з F^{m+p}(P) = F^m(P)
```

**Зауваження 6.2.2.** FIXED_SET і PERIODIC_SET(p) розрізняються умовою «всі точки F-нерухомі». Наприклад, P = {a, b}, F(a) = b, F(b) = a: F(P) = P, p = 2, але точки не нерухомі — PERIODIC_SET(2).

**Зауваження 6.2.3.** EVENTUALLY_PERIODIC(m, p) — це узагальнення, що покриває EVENTUALLY_FIXED (при p = 1). Окремий клас EVENTUALLY_FIXED збережено для зручності.

**Приклад 6.2.4 (P0-1 з аудиту v6.2).** X = {a, b, c}, F(a) = b, F(b) = c, F(c) = b, P = {a}.

- F(P) = {b}, F²(P) = {c}, F³(P) = {b}, F⁴(P) = {c}, …
- Існує m = 1, p = 2: F³(P) = F¹(P) = {b}. Мінімальне лексикографічно (m=1, p=2).
- OrbitType(P) = EVENTUALLY_PERIODIC(1, 2).

**Це коректно.** Множина P входить у двоцикл після одного кроку. Це не хаос.

### 6.3. InclusionType — відношення включення

**Означення 6.3.1.**

```
InclusionType(P) :=
   CONTAINED         якщо F(P) ⊆ P
   STRICTLY_SMALLER  якщо F(P) ⊊ P
   DISJOINT_IMAGE    якщо F(P) ∩ P = ∅
   MIXED             інакше (F(P) частково перетинається з P, але не ⊆)
```

**Приклад 6.3.2.** P = {a} з прикладу 6.2.4: F(P) = {b}, P ∩ F(P) = ∅. InclusionType = DISJOINT_IMAGE.

**Зауваження 6.3.3.** CONTAINED і STRICTLY_SMALLER — не те саме. Перше допускає рівність, друге — ні.

### 6.4. CHAOTIC — окремий предикат

**CHAOTIC не є частиною OrbitType чи InclusionType.** Це окремий предикат для нескінченних множин:

**Означення 6.4.1.** P ⊆ S_∞ × ℛ **хаотична**, якщо:
1. OrbitType(P) = APERIODIC;
2. P компактна й мінімальна (не містить власної непорожньої замкненої F-інваріантної підмножини);
3. h_top(P, F|_P) > 0.

**Твердження 6.4.2.** На скінченному рівні SUBIT⁺ хаотичних множин **не існує**.

*Доведення.* Кожна P ⊆ S₀ × ℛ скінченна, тому її орбіта P, F(P), F²(P), … має повторення (принцип Діріхле). Отже, OrbitType(P) ≠ APERIODIC. ∎

**PROVED ON PAPER.** Це виправляє P0-1: CHAOTIC недосяжний на скінченному рівні, але тепер це випливає з коректного означення, а не з хибного міркування.

### 6.5. Точковий класифікатор Ω_point і його зв'язок із Classify

**Твердження 6.5.1 (скінченний рівень).** Для скінченної P:

```
OrbitType(P) = FIXED_SET ⟹ ∀ŝ ∈ P: Ω_point(ŝ) = FIXED
OrbitType(P) = PERIODIC_SET(p) ⟹ ∀ŝ ∈ P: Ω_point(ŝ) = PERIODIC(q) для деякого q | p
```

**PROVED ON PAPER.**

**Твердження 6.5.2 (нескінченний рівень, виправлення P0-3).** На S_∞ твердження 6.5.1 **хибне**.

*Контрприклад.* X = ℤ, F(n) = n+1, P = ℤ. F(P) = P (FIXED_SET? Ні, бо точки не нерухомі; P — PERIODIC_SET(1)). Але жодна точка не повертається: Ω_point(n) = NONRETURNING для всіх n.

**PROVED ON PAPER.** Це виправляє P0-3: потрібна умова скінченності.

**Твердження 6.5.3 (правильне формулювання).** Для **скінченної** P:

```
F(P) = P ⟹ ∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}
```

Для нескінченної P потрібне додаткове припущення (наприклад, F ін'єктивне на P і P компактна).

### 6.6. Ω_set як пара (переформульовано)

**Означення 6.6.1.** Ω_set := OrbitType × InclusionType.

**Зауваження 6.6.2.** Множина Ω_set **не є лінійно впорядкованою** за побудовою. Порядок, який використовується в §7, — це окрема конвенція для ґратки.

**Означення 6.6.3 (порядок на Ω_set, конвенція).** Для ґраткової структури в §7 вводимо лінійний порядок:

```
CHAOTIC < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC < PERIODIC_SET < FIXED_SET
```

**Застереження 6.6.4.** Це **дизайнерське рішення**, а не семантичний висновок. Воно не стверджує, що FIXED_SET «стабільніший» за PERIODIC_SET у якомусь абсолютному сенсі; це лише порядок для ґраткової алгебри.

## 7. Алгебра Ω

**DEFINED.** Ω := {CHAOTIC, APERIODIC_NON_CHAOTIC, EVENTUALLY_PERIODIC, PERIODIC_SET, FIXED_SET} з лінійним порядком §6.6.3.

**Твердження 7.1.** Ω із ∧ = min, ∨ = max, → (релятивне псевдодоповнення), ¬a := a → ⊥ утворює **алгебру Гейтінга** (логіку Геделя–Даммета).

**PROVED ON PAPER.** (Механічна перевірка таблиць для п'ятиелементного ланцюга.)

**Твердження 7.2 (недосяжність виключеного третього).** EVENTUALLY_PERIODIC ∨ ¬EVENTUALLY_PERIODIC = EVENTUALLY_PERIODIC ≠ FIXED_SET = ⊤.

**PROVED ON PAPER.**

**Застереження 7.3.** Ω — самостійна алгебра. Вона **не** пов'язана формально з білаттисом Белнапа на 𝔸.

## 8. Категорія SUBIT

**DEFINED.** Об'єкт X = (S_X, ℛ_X, F_X, g_X).

**DEFINED.** Морфізм φ = (φ_S, φ_ℛ), що задовольняє умову динамічної сумісності §8.2.

**DEFINED (аксіоми).** Тотожний морфізм id_X := (id_{S_X}, id_{ℛ_X}). Композиція покомпонентна.

**Твердження 8.1.** SUBIT — категорія.

**PROVED ON PAPER.** Асоціативність і нейтральність id спадкуються від функцій.

**DEFINED.** 1 = ({∗}, {id}). X × Y = (S_X × S_Y, ℛ_X × ℛ_Y, F_X × F_Y).

**Твердження 8.2.** 1 — термінальний; X × Y — добуток.

**PROVED ON PAPER.**

**Застереження 8.3.** Експоненціал Yˣ визначений лише для об'єктів із оборотним F_X. Загальний випадок — Q1.

**Застереження 8.4.** Морфізми **не** зберігають метаеволюцію g. CCC — умовний.

## 9. Dyn як топос

**DEFINED.** Категорія Dyn: об'єкти (S, f), f : S → S; морфізми φ ∘ f = g ∘ φ.

**Твердження 9.1.** Dyn ≅ `Set^ℕ`.

**PROVED ON PAPER.** (Lawvere, 1964.)

**Твердження 9.2 (класифікатор).** Ω_Dyn = ℕ ∪ {∞}, дія n · k := max(n − k, 0), ∞ · k := ∞. χ_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U}.

**Твердження 9.3.** χ_U — морфізм Dyn: χ_U(f(x)) = max(χ_U(x) − 1, 0).

**PROVED ON PAPER.**

**Твердження 9.4 (повнота, виправлення P1 v6.2).** Sub_Dyn(X) → Hom_Dyn(X, Ω_Dyn), U ↦ χ_U — бієкція.

**PROVED ON PAPER.** (Стандартний результат для топосу прешейвів.)

**Твердження 9.5.** Dyn — топос.

### 9.6. Конкретний контрприклад до χ_U для SUBIT (виправлення P1-3.6 v6.2)

**Твердження 9.6.1.** Поточний кандидат Ω_SUBIT = Ω (Ґратка §7 із тотожною динамікою) **не є** субоб'єктним класифікатором SUBIT.

*Доведення (конкретний контрприклад).* Нехай X = ({a, b}, {id}, F_X, g ≡ id), F_X(a) = a, F_X(b) = a. Розглянемо два субоб'єкти:
- U₁ = {a} ↪ X.
- U₂ = {a, b} ↪ X.

Обидва замкнені під F_X (F_X(U₁) = {a} ⊆ U₁; F_X(U₂) = {a} ⊆ U₂). Гіпотетичне χ_U₁ і χ_U₂ визначаються як у §9 v6.2 через умови STABLE/METASTABLE/CYCLIC/CHAOTIC. Але через замкненість гілки METASTABLE, CYCLIC, CHAOTIC для субоб'єктів недосяжні, тому χ_U₁(x) ∈ {STABLE, CHAOTIC} для всіх x, і аналогічно χ_U₂. Прямий розрахунок: χ_U₁(a) = STABLE, χ_U₁(b) = CHAOTIC (бо b ∉ U₁); χ_U₂(a) = STABLE, χ_U₂(b) = STABLE (бо b ∈ U₂ і F_X(b) = a ∈ U₂). Отже, χ_U₁ ≠ χ_U₂ — бієкція не потрібна, але й не доведена.

**Цей контрприклад не доводить, що Ω_SUBIT не працює.** Він лише показує, що розрахунок χ_U нетривіальний. Повне негативне твердження залишається Q2''.

**Застереження 9.6.2.** «SUBIT не є топосом» — у v6.3 **не стверджується**. Питання Q2'' (❓): чи має SUBIT будь-який субоб'єктний класифікатор?

## 10. Динамічна теорія типів

**DEFINED.** Судження Γ ⊢ t : A @ τ.

**Правила:**

```
Рефлексивність:    Γ, x:A@τ ⊢ x : A@τ
Еволюція:          Γ ⊢ t:A@τ     F(A) ⊆ B
                   Γ ⊢ F(t) : B @ (τ+1)
Стабільний:        Γ ⊢ t:A@τ     F(A) = A
                   Γ ⊢ t : □A @ τ
Потенційний:       Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   Γ ⊢ t : ◇B @ τ
```

## 11. Модальна логіка

### 11.A. LTL-семантика

**DEFINED.** Для ŝ ∈ S_∞ × ℛ і A ⊆ S_∞ × ℛ:

```
ŝ ⊨ X A       ⟺   F(ŝ) ∈ A
ŝ ⊨ ◇ A       ⟺   ∃n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◇⁺ A      ⟺   ∃n ≥ 1: Fⁿ(ŝ) ∈ A
ŝ ⊨ □ A       ⟺   ∀n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ↺ A       ⟺   ∃k > 1: Fᵏ(ŝ) ∈ A
```

**Твердження 11.A.1 (аксіоми).**

```
(X1)   X A → ◇⁺A
(X2)   X A ∧ X B ↔ X (A ∧ B)
(X3)   X A ∨ X B ↔ X (A ∨ B)
(D1)   ◇A ↔ A ∨ X ◇A
(D2)   ◇⁺A ↔ X ◇A
(D3)   ◇A ↔ A ∨ ◇⁺A
(B1)   □A ↔ A ∧ X □A
(B2)   □A → A
(B3)   □A → X □A
(B4)   □A → ◇A
(B5)   □(A → B) → (□A → □B)
(R1)   ↺A ↔ ◇⁺(X A)
(R2)   ↺A → ◇⁺A
(M4)   ◇A ↔ ¬□¬A
```

**Твердження 11.A.2 (M6, виправлення P0-6).** Формула

```
(M6)   □A → ↺A
```

виконується для будь-якого A і будь-якого тотального F **без додаткових умов**.

*Доведення.* Якщо □A істинне в ŝ, то F²(ŝ) ∈ A, отже ∃k = 2 > 1: F^k(ŝ) ∈ A, що є означенням ↺A. ∎

**PROVED ON PAPER.**

**Твердження 11.A.3 (окрема властивість повернення).** Властивість «кожна точка A повертається в A» формулюється окремо:

```
(Return)   A ⊆ ◇⁺(X A)
```

Вона **не** ототожнюється з □A → ↺A.

### 11.B. Гейтінгова семантика

**DEFINED.** Ω = п'ятиланцюгова Ґратка §7.

**Означення 11.B.1.**

```
(□_H A)(ŝ) := ⋀_{n ≥ 0} A(Fⁿŝ)
(◇_H A)(ŝ) := ⋁_{n ≥ 0} A(Fⁿŝ)
```

**Твердження 11.B.2 (M4_H).** ◇_H A ↔ ¬_H □_H ¬_H A **не виконується**.

*Контрмодель.* X = {a, b}, F(a) = b, F(b) = b, A(a) = EVENTUALLY_PERIODIC, A(b) = CHAOTIC.

- □_H ¬_H A(a) = ¬_H A(a) ∧ ¬_H A(F(a)) = ¬_H EVENTUALLY_PERIODIC ∧ ¬_H CHAOTIC = CHAOTIC ∧ FIXED_SET = CHAOTIC.
- ¬_H □_H ¬_H A(a) = ¬_H CHAOTIC = FIXED_SET.
- ◇_H A(a) = A(a) ∨ A(F(a)) = EVENTUALLY_PERIODIC ∨ CHAOTIC = EVENTUALLY_PERIODIC.
- FIXED_SET ≠ EVENTUALLY_PERIODIC. ∎

**PROVED ON PAPER.**

### 11.C. Співвідношення семантик

§11.A і §11.B — різні модальні системи. У §11.A □ і ◇ дуальні (M4 виконується). У §11.B — ні.

## 13. Простір станів S_∞

**DEFINED.** S_∞ := νX.(A ⊔ X³).

### 13.1. Усічення π_n (виправлення P0-5)

**DEFINED.** T_n — множина дерев глибини ≤ n над A ∪ {⊥}, де ⊥ ∉ A — маркер усічення.

**DEFINED.** π_n : S_∞ → T_n — усічення: замінює всі вузли глибини n на ⊥.

**DEFINED.** Класи еквівалентності: s ~_n t ⟺ π_n(s) = π_n(t).

**Застереження 13.1.1.** Канонічного вкладення T_n → S_∞ **не існує** (⊥ ∉ A). Це виправляє P0-5 v6.2.

### 13.2. Вкладення S₀ ⊂ S_∞

S₀ = {(a, b, c) ∈ S_∞ : a, b, c ∈ A}. Це вкладення, а не апроксимація.

### 13.3. Простір правил ℛ (виправлення P1-3.3)

**DEFINED.** ℛ := ℛ₀ ∪ ℛ₁ (об'єднання, не ⊎ — бо перетин непорожній).

**DEFINED.** ℛ₀ := { f : S_∞ → S_∞ : f причинна }.
**DEFINED.** ℛ₁ := { f : S_∞ → S_∞ : f задається скінченним описом }.

### 13.4. Функтори вкладення (виправлення P1-3.5)

**DEFINED.**

**ι_64→+ : SUBIT-64 → SUBIT⁺.** Об'єкти: S₀ ↦ (S₀, {id}, F_triv, id), де F_triv(s, id) := (s, id). Морфізми: функції S₀ → S₀ ↦ відповідні морфізми з ℛ = {id}.

**ι_+→CAT : SUBIT⁺ → SUBIT-CAT.** Об'єкти: X ↦ X як об'єкт SUBIT-CAT з g ≡ id. Морфізми: зберігаються.

**ι_CAT→∞ : SUBIT-CAT → SUBIT_∞.** Об'єкти: S_X ↦ S_X ⊂ S_∞ (якщо S_X ⊆ S₀); морфізми: зберігаються.

**Твердження 13.4.1.** Кожне ι — функтор (зберігає id і композицію).

**PROVED ON PAPER.**

## 15. Метрики (переписано в v6.3)

**Переписано з нуля.** У v6.2 d_traj була тривіальною (P1-3.1), d_S змішувала повні та усічені дерева (P1-3.2).

### 15.1. Метрика d_S на S_∞

**Означення 15.1.1 (глибина розходження).**

```
δ(s, t) := ∞,  якщо s = t
δ(s, t) := 0,  якщо s, t — листки з різними мітками,
             або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),
             якщо s = (w,x,y), t = (w',x',y')
```

**Застереження 15.1.2 (виправлення P1-3.2).** Умова «один із них містить ⊥» **прибрана**: d_S визначена на S_∞, де ⊥ ∉ A.

**Означення 15.1.3.**

```
d_S(s, t) := 2^(−δ(s,t))   якщо δ(s,t) < ∞
d_S(s, t) := 0              якщо s = t
```

**Твердження 15.1.4.** d_S — ультраметрика.

**PROVED ON PAPER.** Симетрія, рефлексивність, сильна нерівність трикутника — індукція по глибині.

### 15.2. Метрика d_ℛ на ℛ₀ (виправлення P0-5)

**Означення 15.2.1 (усічені правила).** Для f ∈ ℛ₀ означимо f_n : T_n → T_n:

```
f_n(π_n(s)) := π_n(f(s))   для будь-якого s ∈ S_∞
```

**Твердження 15.2.2 (коректність визначення).** f_n не залежить від вибору s ∈ π_n⁻¹(t).

*Доведення.* Причинність f: якщо δ(s, s') ≥ n, то δ(f(s), f(s')) ≥ n. ∎

**PROVED ON PAPER.**

**Означення 15.2.3.**

```
d_ℛ(f, g) := 2^(−n₀(f, g)),   n₀(f, g) := min{ n : f_n ≠ g_n }
d_ℛ(f, g) := 0,                якщо f_n = g_n для всіх n
```

**Твердження 15.2.4.** d_ℛ(f, g) = 0 ⟺ f = g.

**PROVED ON PAPER.**

### 15.3. Метрика d̂ на S_∞ × ℛ₀

d̂((s, ρ), (t, σ)) := max( d_S(s, t), d_ℛ(ρ, σ) )

**PROVED ON PAPER.**

**Твердження 15.3.3.** (S_∞ × ℛ₀, d̂) компактний гаусдорфовий.

**PROVED ON PAPER.**

### 15.4. Метрика Хаусдорфа d_H

d_H(K₁, K₂) := max( sup_{x ∈ K₁} inf_{y ∈ K₂} d̂(x, y),

**Твердження 15.4.2.** d_H — метрика на K(S_∞ × ℛ₀).

τ(ŝ) : ℕ → S_∞ × ℛ₀,   τ(ŝ)_n := Fⁿ(ŝ)

### 21.1. ℛ₀ і ℛ₁

### 21.2. Компактність ℛ₀ (чотири кроки, виправлення P0-5)

**Теорема 21.2.1.** (ℛ₀, d_ℛ) — компактний гаусдорфовий.

*Доведення.*

**Крок 1.** Для f ∈ ℛ₀ означимо f_n(π_n(s)) := π_n(f(s)). Коректність — Твердження 15.2.2.

**Крок 2.** Для кожної сумісної системи (f_n) означимо f(s) := lim_n f_n(π_n(s)) у d_S. Причинність f випливає з причинності кожного f_n (рівномірно).

**Крок 3.** Умова сумісності π_n ∘ f_{n+1} = f_n ∘ π_n замкнена в ∏_n (T_n)^{T_n}.

**Крок 4.** d_ℛ(f, g) = 0 ⟺ f = g — Твердження 15.2.4. ∎

**PROVED ON PAPER.**

## Додаток D. pilot-01 (виправлений)

**Система.** Hudson Bay lynx (Elton & Nicholson, 1942).

**Джерело даних.** `statsmodels.datasets.get_rdataset("lynx")`, версія зафіксована. Логарифмування log(x + 1).

**Крок 0.** Три координати: WHO = квантиль log(x_t), WHERE = квантиль Δlog(x_t), WHEN = квантиль Δ²log(x_t). 4 біни.

**Квантильні межі** обчислюються **лише** на навчальній частині (перші 80 трійок), застосовуються до тестової без змін. **(Виправлення витоку тестової інформації.)**

**Кількість трійок.** Після обчислення першої та другої різниць: T − 2 = 112 трійок. Поділ 80/32.

**Гіпотези.**

- **H₁**: ρ₁ = identity.
- **H₂**: ρ₂ = циклічний зсув на 1 у кожній координаті (mod 4).
- **H₃**: ρ₃(s) := argmax_t count(s → t) у навчальній вибірці. **Fallback** для неспостережених станів: identity (ρ₃(s) = s). **(Виправлення H₃ для неспостережених станів.)**

**Метрика.** Масштабована частка помилкових прогнозів: для кожної тестової трійки ŝ_t обчислюємо ŝ̂_{t+1} := ρᵢ(ŝ_t), порівнюємо з істинним ŝ_{t+1} у d_S (S₀ — дискретна). Частка помилок = кількість помилок / кількість тестових точок. **(Явна формула метрики.)**

**5-кроковий прогноз.** Рекурсія: ŝ̂_{t+5} := ρᵢ⁵(ŝ_t). Аналогічна метрика.

**Перестановка квантилів.** 10 випадкових перестановок міток бінів. Медіана й квартилі.

**Критерій спростування.** Пілот **провалюється**, якщо частка помилок H₃ ≥ min(H₁, H₂) на тестовій вибірці. **Успіх**: частка помилок H₃ < min(H₁, H₂) на ≥ 10%.

**Артефакти.** Репозиторій із commit hash; requirements.txt із точними версіями; Makefile для відтворення. **(Виправлення артефактів.)**
