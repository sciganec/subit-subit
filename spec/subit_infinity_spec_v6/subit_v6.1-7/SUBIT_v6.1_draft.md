# SUBIT-∞

## Формальна специфікація ієрархії SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-CAT ⊂ SUBIT_∞

**Версія 6.1 (draft)**

**Статус:** DRAFT — не для використання як стабільна специфікація. Усі твердження мають явний статус згідно з §20.

**Попередня версія:** v6.0 (WITHDRAWN — див. AUDIT-v6.0.md і PATCH-v6.1.md).

---

## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем: систем, у яких правило еволюції є частиною самого стану, а не зовнішнім параметром. Специфікація побудована як кумулятивна ієрархія з чотирьох рівнів:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-CAT  ⊂  SUBIT_∞
```

**SUBIT-64** — статичний алфавіт із 64 станів. **SUBIT⁺** — скінченна самореферентна динаміка (правило як частина стану). **SUBIT-CAT** — категоріальний рівень; з'ясовано, що SUBIT у повному вигляді **не є топосом**, але його дискретна підкатегорія `Dyn` із класифікатором Ω_Dyn = ℕ ∪ {∞} є топосом `Set^ℕ`. **SUBIT_∞** — рекурсивний нескінченний простір дерев із мітками.

Версія 6.1 є відповіддю на незалежний аудит v6.0 (AUDIT-v6.0.md). Ключові виправлення:

- **Термінологія CHAOTIC** розділена: точкова класифікація Ω_point = {FIXED, PERIODIC, TRANSIENT}; множинна Ω_set; динамічна S(τ) із п'яти класів ω-границь. Слово CHAOTIC вживається **лише** для ω-границь із додатною топологічною ентропією.
- **Метрика** d_ω замінена на d_traj (перша розбіжність траєкторій) і d_H (метрика Хаусдорфа на ω-границях).
- **Характеристичне відображення χ_U** визначене через час входу в U; SUBIT визнано нетопосом; підкатегорія `Dyn` визнана топосом `Set^ℕ`.
- **Модальна логіка** розділена на дві семантики: LTL-подібну (§11.A, M4 виконується) і Гейтінгову (§11.B, M4 не виконується).
- **Двоосьова класифікація** Ω_traj = (S, Att) із вичерпною S-компонентою (5 класів) і математичним Att (без ресурсної клаузули).
- **ℛ₀** — причинні функції; **ℛ₁** — обчислювані; уточнено співвідношення (не вкладено одне в одне).
- **Принцип симуляції** послаблено: вкладається один фіксований вхід, |Q| ≤ 64.
- **STATUS.md** приведено у відповідність; відкликано 7 тверджень; переоцінено статуси.

**Поточний стан доказовості:** частка ✅ значно нижча, ніж у v6.0; мета v6.1 — не максимізувати ✅, а зробити статуси відповідними фактичному рівню.

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

В основі системи лежить **один** скінченний алфавіт A потужності 4. Існує дві рівноправні *реалізації* цього алфавіту — способи називати його елементи.

**Семантична реалізація** — для прикладного моделювання:

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація** — білаттис Белнапа:

```
𝔸 = { T, F, B, N }
```

Кожне значення обох реалізацій кодується двома бітами (bigram = b₁b₂):

| Bigram | Логічна | Семантична (WHO / WHERE / WHEN) |
|---|---|---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Важливе уточнення.** Семантична реалізація використовує **той самий** алфавіт A = {00, 01, 10, 11} на всіх трьох осях. Це не три різні множини A_WHO, A_WHERE, A_WHEN; це одне A з різними мітками на кожній осі. Ізоморфізм між реалізаціями — це перейменування, а не ототожнення різних множин.

Білаттисна структура (два часткові порядки) на A:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

Ця структура використовується в §7 для побудови ґратки Ω, але не переноситься автоматично на динаміку S_∞.

## 2. Простір станів S₀

**Означення 2.1.** Простір станів SUBIT-64:

```
S₀ = A × A × A
|S₀| = 4³ = 64
```

Кожен стан — трійка s = (α, β, γ). Кодується 6-бітним словом b₁b₂b₃b₄b₅b₆, де b₁b₂ = WHO, b₃b₄ = WHERE, b₅b₆ = WHEN.

**Гексаграмна нотація.** Розбивши код на дві тригами — Lower Trigram (b₁b₂b₃) і Upper Trigram (b₄b₅b₆) — кожному стану зіставляється унікальна гексаграма І-Цзін (Додаток A). Це **виключно** компактний комбінаторний запис 6-бітного слова; жодне тлумачення традиційної символіки не є частиною специфікації. *(Перевірено аудитом v6.0: усі 64 коди узгоджуються зі стандартною побудовою гексаграм.)*

**Властивості рівня.** S₀ — статичний простір: відсутній оператор переходу.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.** Простір правил:

```
ℛ = { ρ₁, …, ρₙ },   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширений стан:

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

**Застереження 3.3.** «Правило належить стану» — це **зміна кодування**, а не збільшення виразності. Формально SUBIT⁺ еквівалентний автономному детермінованому скінченному автомату з |Q| = |S₀ × ℛ|. Справжня самореференція потребує зовнішнього входу або кодування (§12); у v6.1 вона **не** формалізована.

## 4. Оператор еволюції

**Означення 4.1.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

**Аксіома 4.2 (детермінованість).** F — тотальна.

**Рівні самореференції** (як спосіб опису, не як збільшення виразності):

```
Рівень 0:   s = (α, β, γ)      базовий стан
Рівень 1:   ŝ = (s, ρ)         стан із внутрішнім правилом
Рівень 2:   F(ŝ) = (s′, ρ′)    еволюція за крок
Рівень 3:   g(ρ, s) → ρ′       метаеволюція
```

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** Траєкторія:

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),   ŝₙ₊₁ = F(ŝₙ)
```

**Твердження 5.1 (скінченна періодичність).** Для будь-якого ŝ₀ існують m ≥ 0 і k ≥ 1 такі, що ŝ_{m+k} = ŝ_m. *(Lean T3.)*

**Таблиця типів одноточкових траєкторій:**

| Тип | Умова |
|---|---|
| FIXED (нерухома точка) | F(ŝ) = ŝ |
| PERIODIC (цикл довжини k > 1) | Fᵏ(ŝ) = ŝ і ∀i з 0 < i < k: Fⁱ(ŝ) ≠ ŝ |
| TRANSIENT (передперіодична) | ∃m > 0, k ≥ 1: ŝ_{m+k} = ŝ_m, і ŝ₀, …, ŝ_{m−1} — без повторів, і F(ŝ₀) ≠ ŝ₀ |

**Зауваження 5.2.** TRANSIENT **реалізується** на скінченному рівні. Попередня версія v6.0 помилково ототожнювала TRANSIENT із CHAOTIC і робила висновок, що «CHAOTIC не реалізується». Правильне формулювання: TRANSIENT реалізується; CHAOTIC (у сенсі §18.5) — не реалізується, бо визначене тільки для ω-границь.

**Алгоритм 5.3 (класифікація траєкторії).**

```
Вхід: ŝ₀, горизонт N_max
Вимагається: N_max ≥ |S₀ × ℛ| для гарантії знаходження циклу
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← позначку входження ŝₙ у visited
        L ← n − m
        якщо L = 1: повернути (FIXED, m=m)
        інакше:      повернути (PERIODIC, m=m, k=L)
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
повернути (RESOURCE_EXCEEDED)
```

Гілка RESOURCE_EXCEEDED виникає лише при N_max < |S₀ × ℛ| — або при користувацькому обмеженні горизонту.

# ЧАСТИНА III. SUBIT-CAT — категорія і класифікатор

## 6. Класифікатори Ω_set, Ω_point, S

Розділ **переписано** у v6.1: три різні класифікатори з різними областями визначення.

### 6.1. Класифікатор множин Ω_set

**Означення 6.1.1.** Клас стабільності множини P ⊆ S_∞ × ℛ:

```
STABLE       ⟺  F(P) = P
METASTABLE   ⟺  F(P) ⊊ P
CYCLIC       ⟺  ∃ мінімальне k > 1: Fᵏ(P) = P, і F(P) ≠ P
CHAOTIC      ⟺  F(P) ⊄ P і ∀k > 1: Fᵏ(P) ≠ P
```

**Твердження 6.1.2.** Ці чотири умови взаємовиключні й вичерпні.

*Доведення.* Якщо F(P) ⊊ P, то індукцією Fᵏ(P) ⊊ P для всіх k ≥ 1, тому CYCLIC неможливе. Якщо ∃k > 1: Fᵏ(P) = P і F(P) ≠ P, то F(P) не може бути власною підмножиною P (інакше Fᵏ(P) ⊊ P). Отже, при F(P) ≠ P рівно одна з трьох умов: METASTABLE, CYCLIC, CHAOTIC. ∎

**Означення 6.1.3 (семантична істина).** P істинне ⟺ F(P) = P.

### 6.2. Точковий класифікатор Ω_point

**Означення 6.2.1.**

```
Ω_point(ŝ) :=
   FIXED      якщо F(ŝ) = ŝ
   PERIODIC   якщо ∃k > 1: Fᵏ(ŝ) = ŝ
   TRANSIENT  інакше
```

**Зауваження 6.2.2.** Слово CHAOTIC **не вживається** для точок. У попередній версії v6.0 точковий клас CHAOTIC означав «не повертається», що суперечило множинному класу CHAOTIC («мінімальна ω з додатною ентропією»). Це джерело помилки К1 аудиту.

### 6.3. Зв'язок Ω_set і Ω_point

**Твердження 6.3.1 (однобічний зв'язок).** Для скінченної P:

```
Ω_set(P) = STABLE ⟹ ∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}
```

*Доведення.* Якщо F(P) = P і P скінченна, то F|_P — бієкція, отже кожна точка P періодична. ∎

**Зауваження 6.3.2.** Зворотне не виконується. Контрприклад: P = {a, b}, F(a) = b, F(b) = a. Тоді Ω_point(a) = Ω_point(b) = PERIODIC, але F(P) = P (STABLE як множина). Тут Ω_set(P) = STABLE, що не суперечить, але показує, що Ω_point не відрізняє FIXED від PERIODIC всередині STABLE-множин.

**Відкликано:** Твердження 6.3 v6.0 («Ω_set(P) = STABLE ⟺ ∀i: Ω_state(ŝᵢ) = STABLE і F(P) = P»).

**Зауваження про межу скінченного рівня (переформульоване).**

**Твердження 6.3.3.** На скінченному рівні SUBIT⁺ клас CHAOTIC (у сенсі §6.1.1) для одноточкових траєкторій **не реалізується**, але клас TRANSIENT реалізується.

*Доведення.* Кожна одноточкова траєкторія зрештою періодична (Твердження 5.1). Отже, для кожного ŝ існує k ≥ 1 із Fᵏ(ŝ) = ŝ. Якщо k = 1 — FIXED; якщо k > 1 — PERIODIC; якщо ŝ у передперіодичному хвості — TRANSIENT. ∎

## 7. Алгебра Ω

На множині Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC} визначено лінійний порядок:

```
CHAOTIC < CYCLIC < METASTABLE < STABLE
```

**Твердження 7.1.** Ω із ∧ = min, ∨ = max, → (релятивне псевдодоповнення), ¬a := a → ⊥ утворює **алгебру Гейтінга** (лінійну модель інтуїціоністської логіки, відому як логіка Геделя–Даммета).

**Таблиці.** *(Усі перевірені аудитом v6.0.)*

**∧ (min):**

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

**∨ (max):**

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**¬:**

| a | ¬a |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

**Твердження 7.2 (недосяжність виключеного третього).**

```
METASTABLE ∨ ¬METASTABLE = METASTABLE ≠ STABLE
```

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).** X = (S_X, ℛ_X, F_X, g_X), де S_X — довільна множина, ℛ_X ⊆ {f : S_X → S_X}, F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

**Означення 8.2 (морфізми).** φ = (φ_S, φ_ℛ), що задовольняє динамічну сумісність на S-проєкції:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

**Зауваження 8.3.** Морфізми **не** зберігають метаеволюцію g. Це означає, що SUBIT у повному вигляді (з нетривіальною g) не має природних експоненціалів. Статус CCC — умовний (для об'єктів із g ≡ id).

**Твердження 8.4.** SUBIT — категорія.

**Термінальний об'єкт, добуток:** стандартні.

**Експоненціал Yˣ:** визначений лише для об'єктів із оборотним F_X.

## 9. Категоріальна структура: Dyn як топос

### 9.1. SUBIT не є топосом

**Твердження 9.1.1.** SUBIT (у повному вигляді з g ≠ id) **не має** субоб'єктного класифікатора.

*Доведення (ескіз).* Спроба через Ω_SUBIT (4 значення, тотожна динаміка) не працює:

1. Гілки χ_U перекриваються.
2. χ_U не є морфізмом (для x ∉ U, F(x) ∈ U маємо χ(x) = CHAOTIC ≠ STABLE = χ(F x)).
3. Субоб'єкт U ↪ X у SUBIT замкнений (F_X(U) ⊆ U), тому гілки CYCLIC і «F(U) ⊄ U» недосяжні. ∎

**Відкликано:** Твердження 9.3, 9.4, 9.5 v6.0 (природність χ, Sub → Hom не бієкція, χ_U існує).

### 9.2. Позитивний результат: підкатегорія Dyn

**Означення 9.2.1.** Категорія **Dyn**:

- Об'єкти: пари (S, f), де S — множина, f : S → S.
- Морфізми: φ : (S, f) → (T, g) — функція φ : S → T із φ ∘ f = g ∘ φ.

**Твердження 9.2.2.** Dyn ≅ `Set^ℕ` (топос прешейвів на моноїді ℕ).

**Твердження 9.2.3 (субоб'єктний класифікатор).**

```
Ω_Dyn := ℕ ∪ {∞}
```

Дія моноїда: `n · k := max(n − k, 0)`, `∞ · k := ∞`. Характеристичне відображення:

```
χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U }   (∞ якщо ніколи)
```

**Твердження 9.2.4.** χ_U — морфізм у Dyn: χ_U(f(x)) = max(χ_U(x) − 1, 0).

*Доведення.* Якщо χ_U(x) = n, то fⁿ(x) ∈ U, тому f^{n−1}(f(x)) ∈ U, отже χ_U(f(x)) ≤ n − 1. І навпаки, якщо f^m(f(x)) ∈ U, то f^{m+1}(x) ∈ U, отже χ_U(x) ≤ m + 1. Разом χ_U(f(x)) = max(χ_U(x) − 1, 0). ∎

**Твердження 9.2.5.** Dyn — топос із класифікатором Ω_Dyn. *(Lawvere, 1964; Mac Lane & Moerdijk, 1992.)*

### 9.3. Співвідношення SUBIT і Dyn

**Твердження 9.3.1.** Dyn — повна підкатегорія SUBIT.

*Доведення.* Кожен об'єкт (S, f) ∈ Dyn є об'єктом SUBIT із ℛ = {f}, g(ρ, s) = ρ. Морфізми Dyn — це морфізми SUBIT, що комутують із F. ∎

**Відкрите питання Q2'.** Чи існує розширення Dyn ⊆ C ⊆ SUBIT, яке є топосом і класифікатор якого враховує метаеволюцію g? (❓)

## 10. Динамічна теорія типів

**Судження.** Γ ⊢ t : A @ τ.

**Правила виведення** (без змін щодо v6.0, але з уточненням узгодженості з §11.A):

```
Рефлексивність:    Γ, x:A@τ ⊢ x : A@τ

Еволюція:          Γ ⊢ t:A@τ     F(A) ⊆ B
                   Γ ⊢ F(t) : B @ (τ+1)

Стабільний:        Γ ⊢ t:A@τ     F(A) = A
                   Γ ⊢ t : □A @ τ

Потенційний:       Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   Γ ⊢ t : ◇B @ τ
```

Модальності тут — у семантиці §11.A (LTL-подібна).

## 11. Модальна логіка (дві семантики)

### 11.A. LTL-подібна семантика (траєкторії)

**Означення 11.A.1.** Для ŝ ∈ S_∞ × ℛ і A ⊆ S_∞ × ℛ:

```
ŝ ⊨ □A  ⟺  ∀n ≥ 0: Fⁿŝ ∈ A
ŝ ⊨ ◇A  ⟺  ∃n ≥ 0: Fⁿŝ ∈ A
ŝ ⊨ ◯A  ⟺  ∃k > 1: Fᵏŝ ∈ A
```

**¬** — класичне заперечення множин.

**Твердження 11.A.2 (аксіоми):**

| Аксіома | Формулювання | Статус |
|---|---|---|
| M1 | □A → A | ✅ |
| M2 | □A → □□A | ✅ |
| M3 | □(A → B) → (□A → □B) | ✅ |
| **M4** | **◇A ↔ ¬□¬A** | **✅ (теорема LTL)** |
| M5 | ◯A → ◇A | ✅ |
| M6 | □A → ◯A | ⚠️ умовно: лише якщо F сюр'єктивна на A |
| M7 | ◯◯A ↔ ◯A | ✅ |
| M8 | □A ∧ □B → □(A ∧ B) | ✅ |
| M9 | ¬¬□A → □A | ✅ (класичне подвійне заперечення) |

**Відкликано:** Твердження 11.2 v6.0 («M4 не виконується»), 11.3 v6.0 («M6 виконується»), 11.6 v6.0 («M9»).

### 11.B. Гейтінгова семантика (Ω-значення)

**Твердження 11.C.1.** §11.A і §11.B — різні модальні системи. У §11.A □ і ◇ дуальні (M4 виконується). У §11.B — ні. Це не суперечність: §11.A про траєкторії, §11.B про алгебру значень.

# ЧАСТИНА IV. SUBIT_∞ — рекурсивний нескінченний простір

## 13. Простір станів S_∞ як дерева з мітками

**Означення 13.1.** S_∞ := νX.(A ⊔ X³) — кінцева коалгебра функтора Φ(X) = A ⊔ X³.

**Явно:** S_∞ — множина дерев (скінченних і нескінченних) із мітками з A в листках, кожен внутрішній вузол має рівно три піддерева. Ототожнення за бісимуляцією.

**Чому потрібен доданок A.** Функтор Φ'(X) = X³ без базового конструктора має тривіальну кінцеву коалгебру νX.X³ ≅ 1 (Додаток B, Лема B.1). Додавання A вносить розрізняльність.

**Вкладення S₀ ⊂ S_∞ — вкладення, не апроксимація.**

**Означення 13.2.** S₀ := { (a, b, c) ∈ S_∞ : a, b, c ∈ A }.

Це дерева глибини рівно 1 з мітками лише в листках. |S₀| = 64. **S₀ ⊂ S_∞ — вкладення, а не апроксимація.** Усі 64 точки S₀ ізольовані в d_S (відстань ≥ 1/2).

**Справжні апроксимації — усічення π_n.**

**Означення 13.3.** T_n — скінченна множина дерев глибини ≤ n. π_n : S_∞ → T_n — усічення (замінює вузли глибини n на лист із фіксованою міткою).

**Простір правил.** ℛ — обчислювані функції S_∞ → S_∞. Може бути нескінченним.

## 14. Динаміка й категорія на рівні S_∞

F : S_∞ × ℛ → S_∞ × ℛ, F(s, ρ) = (f_ρ(s), g(ρ, s)).

**Множина нерухомих точок.** Fix(F) = {ŝ : F(ŝ) = ŝ} — **найбільша** множина нерухомих точок. Найменша STABLE-множина — ∅. *(Виправлено в v6.1.)*

**Категорія.** Перенесення §8 на S_∞ дослівно.

## 15. Семантичні ультраметрики

**Розділ переписано у v6.1.** Попередня d_ω була виродженою (ω(Fⁿŝ) = ω(ŝ)).

### 15.1. Структурна ультраметрика d_S

**Означення 15.1.1 (глибина розходження).**

```
δ(s, t) := ∞,  якщо s = t
δ(s, t) := 0,  якщо s, t — листки з різними мітками, або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),  якщо s = (w,x,y), t = (w',x',y')
```

**Означення 15.1.2 (d_S).**

```
d_S(s, t) := 2^(−δ(s,t))
```

**Твердження 15.1.3.** d_S — ультраметрика.

**Зауваження 15.1.4.** (S_∞, d_S) — **профінітний метризований простір** (гра­ниця скінченних T_n), а не зліченний добуток скінченних просторів. Листки ізольовані. Компактність все ще виконується.

### 15.2. Метрика d_traj

**Означення 15.2.1.** Для ŝ, t̂:

```
n₀(ŝ, t̂) := min{ n ≥ 0 : Fⁿŝ ≠ Fⁿt̂ }
d_traj(ŝ, t̂) := 2^(−n₀)   (якщо n₀ < ∞)
d_traj(ŝ, t̂) := 0         (якщо Fⁿŝ = Fⁿt̂ для всіх n)
```

**Теорема 15.2.2.** d_traj — ультраметрика на (S_∞ × ℛ)/~_traj.

**Твердження 15.2.3 (невиродженість).** `grow_chain` і `shift_spine` розходяться на кроці 1, отже d_traj = 1/2.

### 15.3. Метрика Хаусдорфа d_H на ω-границях

**Означення 15.3.1.**

```
d_H(ŝ, t̂) := d_Hausdorff( ω(ŝ), ω(t̂) )
```

де d_Hausdorff індукована d_S на підмножинах S_∞.

**Твердження 15.3.2 (невиродженість).** `identity` (ω = {s₀}) і `grow_chain` (ω = {нерухома точка на нескінченному дереві}) мають d_H > 0.

**Відкликано:** §15.2, §15.3, §15.4 v6.0 (d_ω вироджена, Твердження 15.3 хибне, нульвимірність необґрунтована).

## 16. Метатеоретичні властивості

**Несуперечність.** Несуперечність S_∞ спадкує від побудови як профінітна границя скінченних T_n. Несуперечність Ω_SUBIT із аксіомами §11.A **не випливає** з цього і потребує окремої перевірки (Q9 ❓).

**Аналогія з неповнотою.** ❓ Гіпотеза; статус збережено.

**Ієрархія виразності:**

| Рівень | Додає | Головне обмеження |
|---|---|---|
| SUBIT-64 | алфавіт 64 станів | відсутня динаміка |
| SUBIT⁺ | правило ρ як частина стану | еквівалентний автономному автомату |
| SUBIT-CAT | категорія; топос Dyn ⊂ SUBIT | SUBIT не топос |
| SUBIT_∞ | нескінченний S_∞; CHAOTIC (умовно) | CHAOTIC недосяжний у ℛ₀ |

**Відношення до відомих систем:**

| Система | Відношення до SUBIT_∞ |
|---|---|
| Автономні скінченні автомати | Вкладаються як один вхід (Твердження 12.1) |
| Класична логіка | Випадок виродження Ω до {⊤, ⊥} |
| Логіка Геделя–Даммета | Реалізується через Ω-алгебру Гейтінга |
| Топоси | SUBIT ⊃ Dyn ≅ Set^ℕ |
| Білаттис Белнапа | Реалізація A |
| Коіндукція / регулярні дерева | S_∞ = νX.(A ⊔ X³) |

**Примітка.** Рядки «U — λ-інтерпретатор, F ↔ β-редукція» і «DFA вкладаються» **прибрані** (не мали доведення і були хибні).

## 18. Канонічна побудова P(τ)

### 18.1. Постановка задачі

**Потрібна функція P**, що зіставляє траєкторії класифікований об'єкт. Чотири вимоги:

- **У0 (неколапс)** — P(τ) не повинна апріорно визначати S(τ) чи Att.
- **У1 (узгодженість)** — на скінченному рівні відтворює типологію Твердження 5.1.
- **У2 (інваріантність)** — не залежить від параметрів спостереження.
- **У3 (явність межі знання)** — окремо від математичної класифікації фіксується обчислювальний статус.

### 18.2. ω-границя для ℛ₀

**Означення 18.2.1.** ω(ŝ₀) := {ŝ ∈ S_∞ × ℛ₀ : ∃ підпослідовність ŝ_{nₖ} → ŝ}.

**Твердження 18.2.2.** Для ℛ₀: ω(ŝ₀) ≠ ∅ для всіх ŝ₀. *(Lean T7 ⚠️.)*

**Застереження.** Для ℛ₁ твердження умовне.

### 18.3. Чому P(τ) := ω(ŝ₀) — неправильно

**Твердження 18.3.1 (колапс).** Якщо P(τ) := ω(ŝ₀), то Ω_set(P(τ)) = STABLE завжди.

*Доведення.* F(ω(ŝ₀)) = ω(ŝ₀) за неперервності F. ∎

### 18.4. Математичні типи досягнення

**Означення 18.4.1 (Att).** Математичне поняття:

```
ATTAINED      якщо ∃n: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC    якщо ∀n: ŝₙ ∉ ω(ŝ₀) і dist(ŝₙ, ω(ŝ₀)) → 0
```

Гілка INDETERMINATE **прибрана** з математичного Att. *(Виправлено в v6.1 — раніше ресурсна клаузула суперечила У2.)*

**Означення 18.4.2 (обчислювальний статус).** Окреме поле сертифіката:

```
COMPUTED           класифікація завершена
RESOURCE_EXCEEDED  горизонт вичерпано
```

### 18.5. S-компонента (5 класів)

**Означення 18.5.1.**

```
S(τ) :=
   FIXED_POINT     якщо ω(ŝ₀) = {p}, F(p) = p
   PERIODIC        якщо ω(ŝ₀) скінченна, |ω(ŝ₀)| > 1
   MINIMAL_CANTOR  якщо ω(ŝ₀) нескінченна, мінімальна, h_top = 0
   CHAOTIC         якщо ω(ŝ₀) нескінченна, мінімальна, h_top > 0
   NON_MINIMAL     якщо ω(ŝ₀) нескінченна й не мінімальна
```

**Твердження 18.5.2 (вичерпність).** П'ять класів вичерпні й взаємовиключні.

### 18.6. CHAOTIC у ℛ₀ недосяжний

**Твердження 18.6.1.** Якщо f ∈ ℛ₀ (причинна), то h_top(ω(ŝ₀)) = 0.

*Доведення (ескіз).* Причинна f — 1-ліпшицева в d_S. За теоремою Боуена для нерозтягуючих відображень на компактному метричному просторі h_top = 0. ∎

**Наслідок 18.6.2.** Клас CHAOTIC **не реалізується** для траєкторій під правилами з ℛ₀.

**Наслідок 18.6.3.** Хаотична динаміка вимагає **не-причинних** правил (ρ ∈ ℛ₁) із додатковими припущеннями (неперервність у слабшій топології, ніж d_ℛ).

**Зауваження 18.6.4.** Демонстрація `shift_spine` лежить у ℛ₁. Клас CHAOTIC у S(τ) досяжний лише **умовно** (⚠️).

### 18.7. Підсумкова функція P(τ)

**Означення 18.7.1.**

```
P(τ) := ( A(τ), Ω_traj(τ), certificate )
```

де:

- **A(τ)** := ω(ŝ₀) — завжди атракторна множина, не «точка входу». *(Виправлено в v6.1.)*
- **Ω_traj(τ)** := (S(τ), Att(τ)).
- **certificate** — сертифікат класифікації.

### 18.8. Сертифікати

**Три типи:**

**Сертифікат ATTAINED** (поліноміально перевірюваний): містить `m`, `omega_set` (скінченна), `s_component`, `att_type = ATTAINED`.

**Сертифікат ASYMPTOTIC** (покроково перевірюваний): містить послідовність усічень π_n(ω(ŝ₀)) і збіжність dist(ŝₙ, ω(ŝ₀)) → 0. **Не** перевіряється за поліноміальний час.

**Сертифікат CHAOTIC** — лише для ℛ₁; свідок h_top > 0 (експоненційне зростання кількості (n, ε)-розділених орбіт). Не має скінченного свідка.

*(Виправлено в v6.1 — раніше v6.0 вимагала поліноміальної перевірюваності від усіх.)*

## 21. Топологія простору правил ℛ

**Розділ переписано у v6.1.**

### 21.1. ℛ₀: причинні функції

**Означення 21.1.1 (причинність).** f : S_∞ → S_∞ причинна, якщо:

```
∀s,t: δ(s, t) ≥ n ⟹ δ(f(s), f(t)) ≥ n
```

**Означення 21.1.2.** ℛ₀ := { f : S_∞ → S_∞ : f причинна }.

### 21.2. Топологія на ℛ₀ (переписано через усічення)

**Означення 21.2.1 (усічення).** T_n — множина дерев глибини ≤ n. π_n : S_∞ → T_n — канонічне усічення.

**Означення 21.2.2.** Для f ∈ ℛ₀: f_n := π_n ∘ f ∘ ι_n, де ι_n : T_n → S_∞.

**Твердження 21.2.3.** f ∈ ℛ₀ однозначно визначається (f_n)_{n ∈ ℕ}, узгодженими: π_n ∘ f_{n+1} = f_n ∘ π_n.

**Означення 21.2.4 (d_ℛ).**

```
d_ℛ(f, g) := 2^(−n₀(f, g)),   n₀(f, g) := min{ n : f_n ≠ g_n }
```

**Теорема 21.2.5 (компактність ℛ₀).** (ℛ₀, d_ℛ) — компактний гаусдорфовий простір.

*Доведення.* Кожне T_n скінченне, тому (T_n)^{T_n} скінченне. ℛ₀ ≅ lim←_n (T_n)^{T_n}. За Тихоновим для зліченного добутку скінченних дискретних просторів — компактний. Гаусдорфовість спадкується. ∎ *(Lean T6 ✅; доведення переписано через усічення.)*

**Наслідок 21.2.6.** S_∞ × ℛ₀ компактний.

**Наслідок 21.2.7.** Для будь-якого неперервного F : S_∞ × ℛ₀ → S_∞ × ℛ₀: ω(ŝ₀) ≠ ∅.

### 21.3. Неперервність F на ℛ₀

**Твердження 21.3.1.** Для f ∈ ℛ₀ відображення F_f : S_∞ → S_∞, F_f(s) := f(s), неперервне в d_S.

### 21.4. ℛ₁: виправлення

**Означення 21.4.1.** ℛ₁ := { f : S_∞ → S_∞ : f задається скінченним описом у фіксованій моделі обчислень }.

**Твердження 21.4.2.** ℛ₀ ⊄ ℛ₁ і ℛ₁ ⊄ ℛ₀.

*Приклади:*
- `shift_spine` ∈ ℛ₁, але ∉ ℛ₀.
- Більшість причинних f ∉ ℛ₁.

**Твердження 21.4.3.** |ℛ₀| = 2^ℵ₀; |ℛ₁| = ℵ₀.

**Застереження 21.4.4.** «Розривна обчислювана F» — поняття, яке вимагає уточнення. У ТТЕ обчислювані функції на нескінченних об'єктах зазвичай неперервні. У v6.1 розглядаються лише неперервні F ∈ ℛ₁ ∩ C(S_∞).

**Відкликано:** Контрприклад 21.1 v6.0 (хибний).

## Додаток B. Коректність конструкції S_∞

**Лема B.1.** νX.X³ ≅ 1.

*Доведення.* Термінальна послідовність 1 ← 1 ← … стабілізується. ∎

*Доведення.* Термінальна послідовність X₀ = 1, X₁ = A ⊔ 1, X₂ = A ⊔ (A ⊔ 1)³, … зберігає копію A на кожному кроці. Границя містить принаймні |A| різних точок. ∎ *(Lean T10 ✅.)*

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω_set, Ω_point, S, Att, Ω_traj,
            d_S, d_traj, d_H, ℛ₀, ℛ₁, Dyn, Ω_Dyn, P, ℒ )
```

де:

- S_∞ = νX.(A ⊔ X³) — простір дерев;
- ℛ = ℛ₀ ⊎ ℛ₁ — простір правил;
- F — оператор динаміки;
- g — метаеволюція;
- Ω_set = {STABLE, METASTABLE, CYCLIC, CHAOTIC} — класифікатор множин;
- Ω_point = {FIXED, PERIODIC, TRANSIENT} — точковий;
- S(τ) ∈ {FIXED_POINT, PERIODIC, MINIMAL_CANTOR, CHAOTIC, NON_MINIMAL};
- Att(τ) ∈ {ATTAINED, ASYMPTOTIC};
- Ω_traj = (S, Att);
- d_S — структурна ультраметрика;
- d_traj — метрика першої розбіжності;
- d_H — метрика Хаусдорфа на ω-границях;
- Dyn — підкатегорія Dyn ≅ Set^ℕ;
- Ω_Dyn = ℕ ∪ {∞} — субоб'єктний класифікатор Dyn;
- P — канонічна класифікація траєкторій;
- ℒ — внутрішня мова.

**Центральна теза v6.1.** SUBIT — формальна нотаційна система. Вона **не** є топосом у повному вигляді, але містить підкатегорію `Dyn`, яка є топосом `Set^ℕ`. Хаотична динаміка (h_top > 0) **недосяжна** для причинних правил ℛ₀ і вимагає не-причинних ℛ₁. Класифікатор Ω має **три шари** (точки, множини, ω-границі), які не можна ототожнювати. Правило належить стану — це зміна кодування, а не збільшення виразності; SUBIT⁺ еквівалентний автономному автомату.

**Методологічна теза v6.1.** Специфікація, яка претендує на перевірюваність, зобов'язана мати **зовнішній аудит** перед присвоєнням статусу STABLE. v6.0 не пройшла цей аудит. v6.1 враховує аудит і знижує власні претензії до фактичного рівня.
