## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем. Кумулятивна ієрархія рівнів:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-CAT  ⊂  SUBIT_∞
```

**Стан v6.7.** Після шести аудитів специфікація досягла внутрішньої несуперечливості за такими архітектурними стовпами:

1. **Classify(P) = (OrbitType, InclusionType)** — точна класифікація множин (v6.3).
2. **Ω — 6-ланцюг** — синтаксичний інструмент для Ґратінгової алгебри, **не** класифікація; проєкція π_Ω : Classify → Ω **втратна** (v6.4, розширено до 6 елементів у v6.6).
3. **d_finite (локальна чутливість) і d_ω (асимптотична)** — дві різні метрики для двох різних цілей (v6.4).
4. **Вектор статусів** — сім незалежних прапорців (v6.3).

**Ключове виправлення v6.7.** Клас `INVARIANT_PERIODIC` (v6.6) вимагав скінченного періоду для кожної точки множини. Це виключало з класифікації хаотичні інваріантні атрактори (наприклад, зсув Бернуллі на {0,1}^ℕ, де F(P) = P, але жодна точка не періодична). Клас перейменовано в **INVARIANT_DYNAMIC**; умову про скінченний період точок прибрано. Внутрішня структура точок (періодичність чи хаос) вимірюється окремо предикатом CHAOTIC і топологічною ентропією h_top.

**Поточний стан доказовості.** v6.7 **не претендує** на STABLE до публікації Lean-пакета. Усі FORMALLY VERIFIED = НІ.

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

**DEFINED.** Один скінченний алфавіт A потужності 4.

**Семантична реалізація:**

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація (білаттис Белнапа):**

```
𝔸 = { T, F, B, N }
```

**Кодування:**

| Bigram | Логічна | Семантична (WHO / WHERE / WHEN) |
|---|---|---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Розмежування.** Семантична й логічна реалізації — це **три окремі бієкції** на один абстрактний алфавіт A = {00, 01, 10, 11}:

```
β_WHO   : A_WHO   → 𝔸
β_WHERE : A_WHERE → 𝔸
β_WHEN  : A_WHEN  → 𝔸
```

Явно: β_WHO(ME) = T, β_WHO(WE) = B, β_WHO(YOU) = F, β_WHO(THEY) = N; аналогічно для WHERE і WHEN.

Білаттисна структура на 𝔸 **не переноситься автоматично** на ґратку Ω у §7. Ω — самостійна алгебра.

**Білаттисна структура** на 𝔸:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

## 2. Простір станів S₀

**DEFINED.** S₀ = A³, |S₀| = 4³ = 64. Кожен стан s = (α, β, γ) кодується 6 бітами: b₁b₂ = WHO, b₃b₄ = WHERE, b₅b₆ = WHEN.

**Гексаграмна нотація** (Додаток A) — компактний запис 6-бітного слова. Жодної семантики І-Цзін не вноситься.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**DEFINED.** ℛ = {ρ₁, …, ρₙ}, ρᵢ : S₀ → S₀ — скінченна множина.

**DEFINED.** Розширений стан: ŝ = (s, ρ) ∈ S₀ × ℛ.

**Застереження 3.1.** SUBIT⁺ еквівалентний автономному детермінованому скінченному автомату з |Q| = |S₀ × ℛ|. «Правило належить стану» — це зміна кодування, а не збільшення виразності.

## 4. Оператор еволюції

**DEFINED.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

**Аксіома 4.1.** F — тотальна.

## 5. Траєкторії та класифікація точок

### 5.1. Траєкторія

**DEFINED.** τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …), ŝₙ₊₁ = F(ŝₙ).

### 5.2. Точкова категорія

**Означення 5.2.1.**

```
Ω_point(ŝ) :=
   FIXED           якщо F(ŝ) = ŝ
   PERIODIC(p)     якщо p := min{ k > 1 : Fᵏ(ŝ) = ŝ } існує
   NONRETURNING    інакше
```

FIXED і PERIODIC(p) не перетинаються (p = 1 виключено).

### 5.3. Скінченна періодичність

**Твердження 5.3.1.** Існують m ≥ 0, p ≥ 1 такі, що ŝ_{m+p} = ŝ_m. **PROVED ON PAPER** (Діріхле).

### 5.4. Алгоритм класифікації

**Алгоритм 5.4.1.**

```
Вхід: ŝ₀, N_max ≥ |S₀ × ℛ|
Вихід: PointClass(ŝ₀) := (category, m, p, attractor_cycle, certificate)

visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← позначку входження ŝₙ у visited
        p ← n − m
        attractor_cycle ← [ŝ_m, ŝ_{m+1}, …, ŝ_{n-1}]
        category ←
            FIXED           якщо m = 0 і p = 1
            PERIODIC(p)     якщо m = 0 і p > 1
            NONRETURNING    якщо m > 0
        certificate ← {m, p, attractor_cycle}
        повернути (category, m, p, attractor_cycle, certificate)
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
повернути (RESOURCE_EXCEEDED, ⊥, ⊥, ⊥, ⊥)
```

**Зауваження 5.4.2.** Поле `attractor_cycle` (не `cycle`) — бо для NONRETURNING воно містить нерухому точку, у яку потрапляє хвіст, а не «цикл» у сенсі PERIODIC(p > 1).

**Приклад 5.4.3.** Три типи:

| ŝ₀ | категорія | m | p | attractor_cycle |
|---|---|---|---|---|
| a → a | FIXED | 0 | 1 | [a] |
| a → b → a | PERIODIC(2) | 0 | 2 | [a, b] |
| a → b → b | NONRETURNING | 1 | 1 | [b] |

### 5.5. Граничне застереження

Для S_∞ алгоритм 5.4.1 може не завершитися; гілка RESOURCE_EXCEEDED змістовна.

# ЧАСТИНА III. SUBIT-CAT — категорія і класифікація

## 6. Класифікація множин

### 6.1. Точна класифікація

**DEFINED.** `Classify(P) := ( OrbitType(P), InclusionType(P) )`.

### 6.2. OrbitType

**Означення 6.2.1.**

```
OrbitType(P) :=
   INVARIANT_FIXED          якщо F(P) = P і всі точки P F-нерухомі
   INVARIANT_DYNAMIC        якщо F(P) = P і не всі точки P F-нерухомі
   PERIODIC_SET(p)          якщо p := min{ k > 1 : Fᵏ(P) = P } існує,
                              F(P) ≠ P, і p мінімальне
   EVENTUALLY_FIXED(m)      якщо ∃m ≥ 1: F^m(P) = F^{m+1}(P) ≠ P,
                              і m мінімальне
   EVENTUALLY_PERIODIC(m,p) якщо ∃m ≥ 0, p > 1: F^{m+p}(P) = F^m(P),
                              F^m(P) ≠ P, і (m, p) мінімальні
                              лексикографічно
   APERIODIC                якщо не існує (m, p) з F^{m+p}(P) = F^m(P)
```

**Застереження 6.2.2.** Клас `INVARIANT_DYNAMIC` (перейменовано з `INVARIANT_PERIODIC` у v6.7) описує інваріантні множини з будь-якою внутрішньою динамікою рухомих точок — скінченні цикли, нескінченні орбіти, хаос. Умова про скінченний період точок **не входить** до OrbitType; вона вимірюється окремо (предикат CHAOTIC §6.4, топологічна ентропія h_top).

**Твердження 6.2.3 (вичерпність, взаємовиключність).** Шість класів вичерпні:

- F(P) = P і всі точки нерухомі → INVARIANT_FIXED.
- F(P) = P і не всі точки нерухомі → INVARIANT_DYNAMIC.
- F(P) ≠ P і ∃p > 1: F^p(P) = P → PERIODIC_SET(p).
- F(P) ≠ P і ∃m ≥ 1: F^m(P) = F^{m+1}(P) → EVENTUALLY_FIXED(m).
- F(P) ≠ P і ∃m ≥ 0, p > 1: F^{m+p}(P) = F^m(P) → EVENTUALLY_PERIODIC(m, p).
- Інакше → APERIODIC.

**PROVED ON PAPER.**

**Приклад 6.2.4 (інваріантний цикл).**

```
X = {a, b}, F(a) = b, F(b) = a, P = {a, b}
F(P) = P; точки не нерухомі → INVARIANT_DYNAMIC
```

**Приклад 6.2.5 (P0-1 v6.2, контрольний).**

```
X = {a, b, c}, F(a) = b, F(b) = c, F(c) = b, P = {a}
F(P) = {b}, F²(P) = {c}, F³(P) = {b} = F(P)
F(P) ≠ P; ∃m = 1, p = 2: F³(P) = F¹(P)
→ EVENTUALLY_PERIODIC(1, 2)
```

**Приклад 6.2.6 (множина як об'єкт у циклі).**

```
X = {a, b, c}, F(a) = b, F(b) = a, F(c) = c, P = {a, c}
F(P) = {b, c}; F²(P) = {a, c} = P; F(P) ≠ P
→ PERIODIC_SET(2)
```

**Застереження 6.2.7.** P містить нерухому точку c і нетривіальний цикл {a, b}. Наявність нерухомої точки всередині P **не робить** множину INVARIANT_FIXED: INVARIANT_FIXED вимагає, щоб **усі** точки були нерухомими. Тут множина P як об'єкт циклується, тому OrbitType(P) = PERIODIC_SET(2).

**Приклад 6.2.8 (INVARIANT_FIXED).**

```
X = {a, b}, F(a) = a, F(b) = b, P = {a, b}
F(P) = P; обидві точки нерухомі → INVARIANT_FIXED
```

**Приклад 6.2.9 (EVENTUALLY_FIXED).**

```
X = {a, b}, F(a) = a, F(b) = a, P = {a, b}
F(P) = {a}, F²(P) = {a}; F¹(P) ≠ P
→ EVENTUALLY_FIXED(1)
```

**Приклад 6.2.10 (хаотичний інваріантний атрактор — контрольний).**

```
X = {0, 1}^ℕ (зсув Бернуллі σ), P = X
F(P) = P; не всі точки нерухомі → INVARIANT_DYNAMIC
Додатково: h_top(P, F|_P) = log 2 > 0, P мінімальна → предикат CHAOTIC = true
```

**Застереження 6.2.11.** Це той випадок, який у v6.6 випадав із класифікації (умова скінченного періоду точок). У v6.7 він коректно класифікується як (INVARIANT_DYNAMIC, CONTAINED) із предикатом CHAOTIC = true.

### 6.3. InclusionType

**Означення 6.3.1.**

```
InclusionType(P) :=
   CONTAINED         якщо F(P) ⊆ P
   STRICTLY_SMALLER  якщо F(P) ⊊ P
   DISJOINT_IMAGE    якщо F(P) ∩ P = ∅
   MIXED             інакше
```

**Зауваження 6.3.2.** CONTAINED і STRICTLY_SMALLER — різні: перше допускає рівність, друге — ні.

**Приклад 6.3.3.** P = {a, b}, F(a) = a, F(b) = a. F(P) = {a}. F(P) ⊄ P (бо b ∉ F(P)); F(P) ∩ P = {a} ≠ ∅. InclusionType = MIXED.

### 6.4. CHAOTIC — окремий предикат

**Означення 6.4.1.** P **хаотична**, якщо:
1. OrbitType(P) = APERIODIC;
2. P компактна й мінімальна (не містить власної непорожньої замкненої F-інваріантної підмножини);
3. h_top(P, F|_P) > 0.

**Твердження 6.4.2.** На скінченному рівні SUBIT⁺ хаотичних множин немає.

*Доведення.* Будь-яка орбіта скінченної P під F має повторення (Діріхле). Отже, OrbitType(P) ≠ APERIODIC. ∎

**PROVED ON PAPER.**

### 6.5. Зв'язок точкової та множинної класифікації

**Твердження 6.5.1 (скінченна P).** F(P) = P ⟹ ∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}. **PROVED ON PAPER.**

**Твердження 6.5.2 (нескінченна P).** На S_∞ твердження 6.5.1 **хибне**. Контрприклад: X = ℤ, F(n) = n+1, P = ℤ (F(P) = P, але жодна точка не повертається). **PROVED ON PAPER.**

### 6.6. Classify vs Ω — розділення понять

**Означення 6.6.1.** Ω — **6-ланцюг**:

```
CHAOTIC
  < APERIODIC_NON_CHAOTIC
  < EVENTUALLY_PERIODIC
  < PERIODIC_SET
  < INVARIANT_DYNAMIC
  < INVARIANT_FIXED
```

**Означення 6.6.2 (проєкція π_Ω).**

```
π_Ω : Classify(P) → Ω
π_Ω((O, I)) :=
   CHAOTIC                  якщо O = APERIODIC і P хаотична
   APERIODIC_NON_CHAOTIC    якщо O = APERIODIC і P не хаотична
   EVENTUALLY_PERIODIC      якщо O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
   PERIODIC_SET             якщо O = PERIODIC_SET(p)
   INVARIANT_DYNAMIC        якщо O = INVARIANT_DYNAMIC
   INVARIANT_FIXED          якщо O = INVARIANT_FIXED
```

**Застереження 6.6.3 (втратність).** π_Ω втратна:

- π_Ω((EVENTUALLY_FIXED(1), STRICTLY_SMALLER)) = π_Ω((EVENTUALLY_PERIODIC(1, 2), DISJOINT_IMAGE)) = EVENTUALLY_PERIODIC;
- π_Ω((PERIODIC_SET(2), MIXED)) = π_Ω((PERIODIC_SET(3), DISJOINT_IMAGE)) = PERIODIC_SET;
- π_Ω((INVARIANT_DYNAMIC, CONTAINED)) = π_Ω((INVARIANT_DYNAMIC, MIXED)) = INVARIANT_DYNAMIC;
- π_Ω((INVARIANT_DYNAMIC, CONTAINED)) для інваріантного циклу = π_Ω((INVARIANT_DYNAMIC, CONTAINED)) для хаотичного атрактора = INVARIANT_DYNAMIC (незважаючи на різницю в h_top);
- параметри m, p, InclusionType і h_top не зберігаються.

**Застереження 6.6.4 (PERIODIC_SET і CONTAINED несумісні).** PERIODIC_SET(p) вимагає F(P) ≠ P; CONTAINED вимагає F(P) ⊆ P; разом дають F(P) ⊊ P, що разом із F^p(P) = P дає суперечність (F^p(P) ⊊ P для всіх p ≥ 1). Отже, для PERIODIC_SET(p) InclusionType ∈ {MIXED, DISJOINT_IMAGE}.

**PROVED ON PAPER.**

**Застереження 6.6.5 (кон'юнкція класів ≠ клас перетину).** Через втратність π_Ω:

```
π_Ω(Classify(A ∩ B))  ≠  π_Ω(Classify(A)) ∧ π_Ω(Classify(B))
```

у загальному випадку.

**Порівняння з топосами.** У стандартних топосах (Set) характеристична функція перетину **є** кон'юнкцією характеристичних функцій: χ_{A∩B} = χ_A ∧ χ_B. У SUBIT це не так, бо π_Ω — лише груба оцінка, не характеристична функція.

## 7. Алгебра Ω

**DEFINED.** Ω — 6-елементний ланцюг §6.6.1:

```
CHAOTIC < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
  < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Твердження 7.1.** Ω із ∧ = min, ∨ = max, → (релятивне псевдодоповнення), ¬a := a → ⊥ утворює **алгебру Гейтінга** (логіку Геделя–Даммета). **PROVED ON PAPER.** (Будь-який скінченний ланцюг є алгеброю Гейтінга.)

**Твердження 7.2 (недосяжність виключеного третього).**

```
EVENTUALLY_PERIODIC ∨ ¬EVENTUALLY_PERIODIC
  = EVENTUALLY_PERIODIC ≠ INVARIANT_FIXED
```

**PROVED ON PAPER.**

**Застереження 7.3.** Ω — самостійна алгебра. Не пов'язана формально з білаттисом Белнапа. Зв'язок із Classify — лише втратна проєкція π_Ω.

## 8. Категорія SUBIT

**DEFINED.** Об'єкт X = (S_X, ℛ_X, F_X, g_X), де S_X — множина, ℛ_X ⊆ {f : S_X → S_X}, F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

**DEFINED (морфізм).** φ = (φ_S, φ_ℛ), що задовольняє:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

**DEFINED (аксіоми).** Тотожний морфізм id_X := (id_{S_X}, id_{ℛ_X}). Композиція покомпонентна.

**Твердження 8.1.** SUBIT — категорія. **PROVED ON PAPER.**

**DEFINED.** 1 = ({∗}, {id}). X × Y = (S_X × S_Y, ℛ_X × ℛ_Y, F_X × F_Y).

**Твердження 8.2.** 1 — термінальний; X × Y — добуток. **PROVED ON PAPER.**

**Застереження 8.3.** Експоненціал Yˣ визначений лише для об'єктів із оборотним F_X. Загальний випадок — Q1.

**Застереження 8.4.** Морфізми **не** зберігають метаеволюцію g. CCC — умовний.

## 9. Dyn як топос

**DEFINED.** Категорія Dyn: об'єкти (S, f), f : S → S; морфізми φ ∘ f = g ∘ φ.

**Твердження 9.1.** Dyn ≅ `Set^ℕ`. **PROVED ON PAPER** (Lawvere).

**Твердження 9.2 (класифікатор).** Ω_Dyn = ℕ ∪ {∞}, дія n · k := max(n − k, 0), ∞ · k := ∞. χ_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U}. **PROVED ON PAPER.**

**Твердження 9.3.** χ_U — морфізм Dyn: χ_U(f(x)) = max(χ_U(x) − 1, 0). **PROVED ON PAPER.**

**Твердження 9.4 (повнота).** Sub_Dyn(X) → Hom_Dyn(X, Ω_Dyn), U ↦ χ_U — бієкція. **PROVED ON PAPER** (стандартний результат для топосу прешейвів).

**Твердження 9.5.** Dyn — топос.

### 9.6. χ_U-механізм v6.2 не працює як класифікатор SUBIT

**Твердження 9.6.1 (переформульовано).** Механізм χ_U з v6.2 (через 4-елементну Ґратку STABLE/METASTABLE/CYCLIC/CHAOTIC для субоб'єктів SUBIT) **не працює** як субоб'єктний класифікатор.

**Застереження 9.6.2.** Твердження «SUBIT не має субоб'єктного класифікатора» — **не доведено**. Питання Q2'' (❓).

**Застереження 9.6.3.** Для доведення неіснування треба:
1. Знайти U₁ ≠ U₂ з χ_{U₁} = χ_{U₂} (порушення ін'єктивності), **або**
2. Знайти φ : X → Ω без U з χ_U = φ (порушення сюр'єктивності).

Жоден із цих випадків не пред'явлено.

## 10. Динамічна теорія типів

**DEFINED.** Судження Γ ⊢ t : A @ τ.

**Правила:**

```
Рефлекс.:    Γ, x:A@τ ⊢ x : A@τ
Еволюція:    Γ ⊢ t:A@τ     F(A) ⊆ B
             Γ ⊢ F(t) : B @ (τ+1)
Стабільний:  Γ ⊢ t:A@τ     F(A) = A
             Γ ⊢ t : □A @ τ
Потенційний: Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
             Γ ⊢ t : ◇B @ τ
```

## 11. Модальна логіка

### 11.A. LTL-семантика

**DEFINED.**

```
ŝ ⊨ X A       ⟺   F(ŝ) ∈ A
ŝ ⊨ ◇ A       ⟺   ∃n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◇⁺ A      ⟺   ∃n ≥ 1: Fⁿ(ŝ) ∈ A
ŝ ⊨ □ A       ⟺   ∀n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ↺ A       ⟺   ∃k > 1: Fᵏ(ŝ) ∈ A
```

**Твердження 11.A.1 (аксіоми).**

```
(X1)   X A → ◇⁺A
(X2)   X A ∧ X B ↔ X (A ∧ B)
(X3)   X A ∨ X B ↔ X (A ∨ B)
(D1)   ◇A ↔ A ∨ X ◇A
(D2)   ◇⁺A ↔ X ◇A
(D3)   ◇A ↔ A ∨ ◇⁺A
(B1)   □A ↔ A ∧ X □A
(B2)   □A → A
(B3)   □A → X □A
(B4)   □A → ◇A
(B5)   □(A → B) → (□A → □B)
(R1)   ↺A ↔ ◇⁺(X A)
(R2)   ↺A → ◇⁺A
(M4)   ◇A ↔ ¬□¬A
```

**Твердження 11.A.2 (M6).** □A → ↺A виконується для будь-якого A і тотального F без умов.

*Доведення.* □A в ŝ тягне F²(ŝ) ∈ A, отже ∃k = 2 > 1: F^k(ŝ) ∈ A. ∎

**PROVED ON PAPER.**

**Твердження 11.A.3 (Return).** A ⊆ ◇⁺(X A) — окрема властивість, не ототожнюється з □A → ↺A.

### 11.B. Гейтінгова семантика

**DEFINED.** Ω — 6-ланцюг §7.

```
(□_H A)(ŝ) := ⋀_{n ≥ 0} A(Fⁿŝ)
(◇_H A)(ŝ) := ⋁_{n ≥ 0} A(Fⁿŝ)
```

**Твердження 11.B.1 (M4_H не виконується).** ◇_H A ↔ ¬_H □_H ¬_H A — хибне.

*Контрмодель.* X = {a, b}, F(a) = b, F(b) = b, A(a) := EVENTUALLY_PERIODIC, A(b) := CHAOTIC.

- □_H ¬_H A(a) = ¬_H EVENTUALLY_PERIODIC ∧ ¬_H CHAOTIC = CHAOTIC ∧ INVARIANT_FIXED = CHAOTIC.
- ¬_H □_H ¬_H A(a) = ¬_H CHAOTIC = INVARIANT_FIXED.
- ◇_H A(a) = EVENTUALLY_PERIODIC.
- INVARIANT_FIXED ≠ EVENTUALLY_PERIODIC. ∎

**PROVED ON PAPER.**

### 11.C. Співвідношення

§11.A — про траєкторії; §11.B — про значення в Ω. Різні системи.

# ЧАСТИНА IV. SUBIT_∞

## 13. Простір станів S_∞

**DEFINED.** S_∞ := νX.(A ⊔ X³).

**Лема 13.1.** νX.X³ ≅ 1. **PROVED ON PAPER.**
**Лема 13.2.** νX.(A ⊔ X³) ≠ 1 при |A| > 1. **PROVED ON PAPER.**

### 13.1. Усічення π_n

**DEFINED.** T_n — дерева глибини ≤ n над A ∪ {⊥}, ⊥ ∉ A — маркер усічення.

**DEFINED.** π_n : S_∞ → T_n — усічення (замінює вузли глибини n на ⊥).

**Застереження 13.1.1.** Канонічного вкладення T_n → S_∞ **не існує** (⊥ ∉ A).

### 13.2. Вкладення S₀ ⊂ S_∞

S₀ = {(a, b, c) ∈ S_∞ : a, b, c ∈ A}. Вкладення, не апроксимація.

### 13.3. Простір правил ℛ

**DEFINED.** ℛ := ℛ₀ ∪ ℛ₁ (об'єднання, не ⊎).

**DEFINED.** ℛ₀ := {f : S_∞ → S_∞ : f причинна}.
**DEFINED.** ℛ₁ := {f : S_∞ → S_∞ : f задається скінченним описом}.

### 13.4. Функтори вкладення

**DEFINED.**

- **ι_64→+ : SUBIT-64 → SUBIT⁺_id.** S₀ ↦ (S₀, {id}, F_triv, id), F_triv(s, id) := (s, id).
- **SUBIT⁺_id ⊂ SUBIT⁺** — повна підкатегорія об'єктів, для яких id ∈ ℛ_X.
- **ι_+→CAT : SUBIT⁺_id → SUBIT-CAT.** X ↦ X із g ≡ id.
- **ι_CAT→∞ : SUBIT-CAT → SUBIT_∞.**

**Твердження 13.4.1.** Кожне ι — функтор. **PROVED ON PAPER.**

**Застереження 13.4.2.** Композиція ι_CAT→∞ ∘ ι_+→CAT ∘ ι_64→+ визначена **лише** на підкатегорії SUBIT⁺_id. Для довільного SUBIT⁺-об'єкта з ℛ = {f}, f ≠ id, вкладення в SUBIT-CAT не визначене в цій конструкції. Розширення — Q12 (❓).

## 14. Динаміка й категорія на S_∞

F : S_∞ × ℛ → S_∞ × ℛ, F(s, ρ) = (f_ρ(s), g(ρ, s)).

**Fix(F)** := {ŝ : F(ŝ) = ŝ} — найбільша множина нерухомих точок.

## 15. Семантичні метрики

### 15.1. Структурні метрики

**Означення 15.1.1 (δ, d_S).**

```
δ(s, t) := ∞,  якщо s = t
δ(s, t) := 0,  якщо s, t — листки з різними мітками,
             або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),
             якщо s = (w,x,y), t = (w',x',y')
d_S(s, t) := 2^(−δ(s,t))   якщо δ < ∞
d_S(s, t) := 0              якщо s = t
```

**Застереження 15.1.2.** d_S ∈ [0, 1]; максимум = 1 (два різних листки, або лист і вузол).

**Твердження 15.1.3.** d_S — ультраметрика. **PROVED ON PAPER.**

**Означення 15.1.4 (d_ℛ).** Для f ∈ ℛ₀ означимо f_n(π_n(s)) := π_n(f(s)) (коректність — з причинності f).

```
d_ℛ(f, g) := 2^(−n₀(f, g)),   n₀(f, g) := min{ n : f_n ≠ g_n }
d_ℛ(f, g) := 0,                якщо f_n = g_n для всіх n
```

**Твердження 15.1.5.** d_ℛ(f, g) = 0 ⟺ f = g. **PROVED ON PAPER.**

**Означення 15.1.6 (d̂).** d̂((s, ρ), (t, σ)) := max(d_S(s, t), d_ℛ(ρ, σ)).

**Твердження 15.1.7.** (S_∞ × ℛ₀, d̂) компактний гаусдорфовий. **PROVED ON PAPER.**

### 15.2. Локальна метрика чутливості d_finite

**Означення 15.2.1.**

```
d_finite(ŝ, t̂) := sup_{n ≥ 0} 2^{-n} · d̂(Fⁿ(ŝ), Fⁿ(t̂))
```

**Твердження 15.2.2.** d_finite — метрика на S_∞ × ℛ₀. **PROVED ON PAPER.**

**Застереження 15.2.3.** d_finite вимірює локальну чутливість до початкових умов. Не узгоджена з асимптотикою. Не ультраметрика.

### 15.3. Асимптотична метрика d_ω

**Означення 15.3.1.** Для ŝ, t̂ ∈ S_∞ × ℛ₀ з непорожніми компактними (отже, замкненими) ω-границями:

```
d_ω(ŝ, t̂) := d_Hausdorff( ω(ŝ), ω(t̂) )
```

**Застереження 15.3.2.** Компактність ω(ŝ) гарантована, якщо F задовольняє NF1–NF4 (§18.2).

**Твердження 15.3.3.** d_ω — псевдометрика на S_∞ × ℛ₀; стає метрикою на факторі (S_∞ × ℛ₀) / ~_ω, де ŝ ~_ω t̂ ⟺ ω(ŝ) = ω(t̂). **PROVED ON PAPER.**

**Застереження 15.3.4.** Узгодженість d_finite і d_ω **залежить від F**:

- Якщо F структурно стійка — d_finite → 0 тягне d_ω → 0.
- Якщо F структурно нестійка (з межами басейнів) — можлива неузгодженість.

**Приклад 15.3.5 (x² на [0, 1]).**

**Система.** X = [0, 1], F(x) := x². Атрактори: 0 (стійкий), 1 (нестійкий). B(0) = [0, 1), B(1) = {1}.

**Ілюстрація.**

- ŝ₁ = 0.5, t̂₁ = 0.5 + ε: ω = {0} для обох, d_ω = 0; d_finite = ε² (мала).
- ŝ₂ = 1, t̂₂ = 1 − ε: ω(ŝ₂) = {1}, ω(t̂₂) = {0}, d_ω = 1; d_S(ŝ₂, t̂₂) = ε (мала).

**Ремарка.** X = [0, 1] — ізоморфний компакт, не підмножина S_∞. Структура басейнів притягання на [0, 1] ізоморфна відповідній структурі на підмножині S_∞ × ℛ₀.

**Зауваження 15.3.6.** Питання Q13: для яких F метрики узгоджені?

d_Ω_traj((S₁, Att₁), (S₂, Att₂)) := max( d_H(S₁, S₂), 1[Att₁ ≠ Att₂] )

## 18. Функція P(τ)

### 18.1. Постановка

Чотири вимоги: У0 (неколапс), У1 (узгодженість), У2 (інваріантність), У3 (явність межі знання).

### 18.2. ω-границя і неперервність F

**Означення 18.2.1.** ω(ŝ₀) := множина точок накопичення τ(ŝ₀) у d̂.

**Твердження 18.2.2 (умови неперервності повного F).** F : S_∞ × ℛ₀ → S_∞ × ℛ₀ неперервний, якщо:

- **(NF1)** f_ρ причинна для всіх ρ ∈ ℛ₀;
- **(NF2)** g : ℛ₀ × S_∞ → ℛ₀ неперервна в d_ℛ × d_S;
- **(NF3)** g(ρ, s) ∈ ℛ₀ для всіх ρ, s;
- **(NF4)** ρ ↦ f_ρ : ℛ₀ → ℛ₀ неперервна в d_ℛ.

**PROVED ON PAPER.**

**Застереження 18.2.3.** NF1–NF4 — сильні обмеження. Для багатьох «цікавих» метаеволюцій F розривний у d̂.

**Приклад 18.2.4 (неперервна g, тривіальна).** g(ρ, s) := ρ.

**Приклад 18.2.5 (неперервна, нетривіальна).** g(ρ, s) := ρ′ де f_{ρ′} := f_ρ ∘ λ_s, λ_s — причинне, неперервно залежить від s.

**Приклад 18.2.6 (розривна g).** g(ρ, s) := «додати вузол до ρ-дерева». d_ℛ стрибкоподібна. NF2, NF4 не виконуються.

### 18.3. Коллапс

**Твердження 18.3.1.** P(τ) := ω(ŝ₀) колапсує: Ω_set(ω(ŝ₀)) = INVARIANT_FIXED завжди. **PROVED ON PAPER.**

### 18.4. Att

**Означення 18.4.1.**

```
ATTAINED      якщо ∃n: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC    якщо ∀n: ŝₙ ∉ ω(ŝ₀) і dist(ŝₙ, ω(ŝ₀)) → 0
```

**Означення 18.4.2.** COMPUTED / RESOURCE_EXCEEDED — окреме поле сертифіката.

**Застереження 18.5.2.** Для скінченної ω-границі S ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. Для нескінченної — EVENTUALLY_* неможливе (ω-границя мінімальна), тому S ∈ {INVARIANT_DYNAMIC, APERIODIC}.

### 18.7. Сертифікати

**Сертифікат FINITE_CYCLE_ATTAINED.** Скінченна ω-границя, досягнута. Містить m, p, attractor_cycle. Поліноміально перевірюваний.

**Сертифікат CHAOTIC.** Зовнішній; скінченного свідка не існує.

## Додаток D. Емпіричний протокол pilot-01

**Система.** Hudson Bay lynx (Elton & Nicholson, 1942).

**Джерело даних.** `statsmodels.datasets.get_rdataset("lynx")`; логарифмування log(x + 1).

**Кількість трійок.** T − 2 = 112. Поділ 80/32.

**Гіпотези.**

- **H₁**: ρ₁ = identity.
- **H₂**: ρ₂ = циклічний зсув на 1 у кожній координаті (mod 4).

**Fallback H₃.** Для неспостережених станів:

- **Метод A (рекомендований).** Такі стани виключаються з тестового розрахунку. Тестова вибірка звужується.

**s_prev fallback не використовується** (порушує аксіому 4.1).

**Метрика.** Масштабована частка помилкових прогнозів. 1-крокова і 5-крокова (рекурсивна).

**Перестановка квантилів.** 10 випадкових перестановок. Медіана й квартилі.

**Критерій спростування.** H₃ провалюється, якщо частка помилок ≥ min(H₁, H₂). Успіх: < min(H₁, H₂) на ≥ 10%.

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g,
            Classify = (OrbitType, InclusionType),
            Ω (6-ланцюг), π_Ω : Classify → Ω,
            Ω_point, Ω_ω, Ω_traj,
            d_S, d_ℛ, d̂ (структурні),
            d_finite (локальна), d_ω (асимптотична, псевдометрика),
            ℛ₀, ℛ₁, Dyn, Ω_Dyn,
            P, ℒ )
```

**Центральна теза v6.7.** OrbitType описує **долю множини як об'єкта** під дією F (інваріантна, циклічна, евентуально періодична, аперіодична). Внутрішня структура точок (періодичність, хаотичність) — **окремий предикат** CHAOTIC, не частина OrbitType. Це розділення усуває останню логічну прогалину: хаотичний інваріантний атрактор коректно класифікується як (INVARIANT_DYNAMIC, CONTAINED) із предикатом CHAOTIC = true.

**Методологічна теза v6.7.** Якщо клас описує **долю об'єкта**, він не повинен містити умов на **внутрішню структуру**. Інваріантність множини і періодичність точок — різні рівні аналізу. Змішування їх — джерело помилок.

**Прогноз.** Сьомий аудит має перевірити:
- чи справді INVARIANT_DYNAMIC вичерпний для всіх інваріантних множин;
- чи зберігається взаємовиключність 6 класів при довільних скінченних P;
- чи узгоджена перейменована Ω з модальною логікою §11.B і сертифікатами §18.7.

**Якщо сьомий аудит не знайде P0/P1** — v6.7 може бути переведена в DRAFT-STABLE (з явним застереженням: без Lean-пакета FORMALLY VERIFIED = НІ).
