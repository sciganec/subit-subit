## Швидкий перегляд

Lean:

```bash
tar xzf subit-lean-mathlib-v6.13.37.tar.gz
cd pm
lake build Subit
```

Очікуваний результат: 2472 задачі, 0 попереджень (lean-toolchain: `leanprover/lean4:v4.32.0`).

Аксіоми W7:

```bash
lake env lean checks/w7_release_axioms_v6.13.37.lean
```

Очікуваний результат — лише `propext`, `Classical.choice`, `Quot.sound` (див. `checks/` у архіві або `w7_release_axioms_v6.13.37.log`).

Rust:

```bash
tar xzf subit-rust-v6.13.31.tar.gz
cd subit
cargo test          # 57 тестів
cargo clippy --all-targets
cargo run --release --bin pilot01
```

Перевірка цілісності файлів:

```bash
sha256sum -c SHA256SUMS
```
