## Ключові результати v6.14.3

### ALT-10: гібридна логіка на $\mathbb{F}$

| Атоми мови | Класів бісимуляції | Визначних множин |
| :-- | --: | --: |
| немає ($S5^3$) | 1 | 2 |
| $\{w{=}0\}$ | 2 | 4 |
| $\{w{=}0,e{=}0,n{=}0\}$ | 8 | 256 |
| усі 12 координатних атомів | 64 | $2^{64}$ |

Один номінал + $S5^3$: $R$-замикання $\{p\}$ = 8 множин (розміри $\{1{:}1,4{:}3,16{:}3,64{:}1\}$), булева алгебра = $2^8 = 256$ множин. Отже номінали й $\mathrm{@}$ **не дають більше**, ніж координатні атоми ($\mathrm{@}$ додає лише $\varnothing,\mathbb{S}$).

### ALT-11: комутація $M_k^b$ з $\mathrm{@}$

| Оператор | Область комутації | Розмір |
| :-- | :-- | --: |
| $M_k^b$ | $\{c_k{=}b\}\times\mathbb{S}$ (точно) | $1024 / 4096$ |
| $M_k^b$ глобально | — | жоден |
| $\tilde M_k^b$ (діагональ) | усе $\mathbb{S}\times\mathbb{S}$ | $4096 / 4096$ |

Свідок $\varphi = o_k{=}b$ розділяє 3072 пари поза гіперплощиною; $\mathrm{@}$ ідемпотентний.
