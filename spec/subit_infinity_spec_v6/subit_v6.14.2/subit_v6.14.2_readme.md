## Ключові результати v6.14.2

### ALT-8: структура $GL_3(\mathbb{Z}_4)$

| Величина | Значення |
| :-- | --: |
| $\lvert GL_3(\mathbb{Z}_4)\rvert$ | $86016 = 2^{12}\cdot 3\cdot 7$ |
| Ядро $K$ | $512 = 2^9 = (\mathbb{Z}/2)^9$ |
| Циклових типів | **17** |
| Класів спряженості | **60** |
| $\lvert H\rvert$ (індекс 28) | 3072 |

$$GL_3(\mathbb{Z}_4) \cong (\mathbb{Z}/2)^9 \rtimes GL_3(\mathbb{F}_2), \qquad H \cong (\mathbb{Z}/2)^9 \rtimes S_3.$$

Повна таблиця 17 циклових типів — у §17.6 специфікації.

### ALT-9: бісимуляція $S5+N$

| Величина | Значення |
| :-- | --: |
| Класів бісимуляції $S5+N+\text{атоми}$ | **36** |
| Структура | добуткове розбиття $P$ |
| Розподіл розмірів | $\{1{:}16, 2{:}16, 4{:}4\}$ |
| Класів $N+\text{атоми}$ (без $S5$) | 21 |
| Класів $S5+\text{атоми}$ (без $N$) | 8 |
| $\lvert\mathrm{Aut}\rvert$ структури | 1 (тривіальна) |

Блоки $P$: $w \in \{\{0\},\{1,2\},\{3\}\}$, $e$ — усі 4, $n \in \{\{0\},\{1\},\{2,3\}\}$; $3\cdot 4\cdot 3 = 36$.
