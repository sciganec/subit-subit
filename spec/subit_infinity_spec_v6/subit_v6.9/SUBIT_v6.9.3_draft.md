## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** ℛ\_fin — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан ŝ = (s, ρ) ∈ S₀ × ℛ\_fin. Метаеволюція g₀ : ℛ\_fin × S₀ → ℛ\_fin.

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ — тотальна. Часткові оператори, помилки, ресурсні переривання — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × ℛ\_fin, D₀) — автономний детермінований скінченний автомат з 64·|ℛ\_fin| станами. DP-f. Сильніша теза про самореферентну перевагу — ВІДКРИТО.

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ) з |Q| ≤ 64, тотальною δ : Q → Q і **без вхідного алфавіту** вкладається в SUBIT⁺.

**Доведення (повне).**

1. Оскільки |Q| ≤ |S₀| = 64, обираємо ін'єкцію ι : Q → S₀. Образ ι(Q) має |Q| елементів; поза ним зафіксуємо довільне значення s₀ ∈ S₀.
2. Визначимо ρ : S₀ → S₀:
   - ρ(ι(q)) := ι(δ(q)) для всіх q ∈ Q;
   - ρ(s) := s₀ для всіх s ∈ S₀ ∖ ι(Q).
3. ρ — тотальна функція S₀ → S₀ за побудовою.
4. Нехай ℛ\_fin = {ρ}. Визначимо g₀(ρ, s) := ρ для всіх s ∈ S₀. Тоді D₀(s, ρ) = (ρ(s), ρ).
5. Індукцією за n: якщо ŝ₀ = (ι(q₀), ρ), то ŝₙ = (ι(δⁿ(q₀)), ρ). База — n = 0; крок: ρ(ι(δⁿ(q₀))) = ι(δ(δⁿ(q₀))) = ι(δⁿ⁺¹(q₀)) за означенням ρ на образі ι(Q).

Отже, образ ι(Q) інваріантний під ρ, і траєкторія ŝₙ точно кодує δ-орбіту q₀. ∎ **DP-f.**

**Область.** Твердження стосується автономних систем з одним тотальним переходом. Воно **не** стверджує:

- універсальної симуляції довільного DFA з вхідним алфавітом;
- симуляції автоматів з |Q| > 64;
- універсальності SUBIT⁺ як λ-інтерпретатора.

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7, Q22 (|Q| > 64).

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень — Ω_point^fin

**Означення 3.1.1.** Область `Ω_point^fin` — Q₀ := S₀ × ℛ\_fin. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }   (скінченне)
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | 1 ≤ m < ∞ |

**Твердження 3.1.2 (P1).** У Q₀ для кожного ŝ: m(ŝ) < ∞. DP-f (Діріхле).

**Твердження 3.1.3 (P2).** Три класи попорожно не перетинаються й вичерпують Q₀. DP-f.

**Твердження 3.1.4 (P3, точний режим).**

```text
Вхід: ŝ₀
visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, |Q₀|:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m
        category ← FIXED / PERIODIC(p) / PREPERIODIC(m, p)
        повернути COMPUTED(category, m, p, attractor_cycle)
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
```

Оскільки |Q₀| скінченне й D₀ тотальне, повторення гарантоване на кроці n ≤ |Q₀|. Гілка `RESOURCE_EXCEEDED` **недосяжна**. **DP-f.**

**Твердження 3.1.5 (P3′, бюджетований режим).**

```text
Вхід: ŝ₀, N_max
... той самий цикл до N_max ...
    якщо повторення не знайдено за N_max кроків:
        повернути RESOURCE_EXCEEDED
```

Якщо N\_max < |Q₀|, гілка `RESOURCE_EXCEEDED` досяжна; результат **не є класифікацією**. Використовується для тестування обмежених обчислень. **DP-f.**

### 3.2. Нескінченний рівень — Ω_point^∞

**Означення 3.2.1 (повне).** Область — S\_∞ × R за припущення (H). Для ŝ ∈ S\_∞ × R:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }
        (∞, якщо множина індексів порожня)

Якщо m(ŝ) < ∞:
    p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }
Інакше:
    p(ŝ) := ∞
```

| Клас | Нормативна умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY\_PERIODIC(m, p) | 1 ≤ m < ∞, 1 ≤ p < ∞ |
| APERIODIC | m = ∞, p = ∞ |

**Твердження 3.2.2.** Чотири класи попарно не перетинаються й вичерпують S\_∞ × R. DP-f.

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀ (CE-11-R2.3).

## 4. Класифікація множин Classify⁺

У §4–§5 X — S₀ × ℛ\_fin або S\_∞ × R; P ⊆ X — **непорожня**; D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

**Означення 4.1.1.**

```text
μ(P)    := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }        (∞ якщо немає)
π(P)    := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }  (тільки при μ < ∞)
           ∞                                             (якщо μ = ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                     (∞ якщо немає)
```

| Клас OrbitType | Нормативна умова |
| :-- | :-- |
| INVARIANT\_FIXED | D[P] = P ∧ ∀x ∈ P: D(x) = x |
| INVARIANT\_DYNAMIC | D[P] = P ∧ ∃x ∈ P: D(x) ≠ x |
| PERIODIC\_SET | D[P] ≠ P ∧ μ(P) = 0 ∧ 2 ≤ p\_set(P) < ∞ |
| EVENTUALLY\_FIXED | 1 ≤ μ(P) < ∞ ∧ π(P) = 1 |
| EVENTUALLY\_PERIODIC | 1 ≤ μ(P) < ∞ ∧ 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.2 (C1, розбиття).** Шість класів попарно не перетинаються й вичерпують усі непорожні P. **DP-f** за тотальності D.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  інакше
```

**Твердження 4.2.1 (C2).** П'ять класів попарно не перетинаються; усі непорожні P розбиті. DP-f.

### 4.3. ChaosStatus — тризначний статус

**Означення 4.3.1.** Для непорожньої P ⊆ X:

```text
ChaosStatus_D(P) ∈ { NOT_APPLICABLE, NON_CHAOTIC, CHAOTIC }

NOT_APPLICABLE — топологічні передумови не виконані
CHAOTIC        — передумови виконані ∧ P мінімальна ∧ h_top(D|_P) > 0
NON_CHAOTIC    — передумови виконані, але CHAOTIC не виконується
```

**Застереження 4.3.2.** `NOT_APPLICABLE ≠ NON_CHAOTIC`. Перше означає, що критерій не застосовується; друге — що критерій застосовано і не справджено.

### 4.4. Три CHAOTIC

**Означення 4.4.1.** `CHAOTIC_set(P)` (у Ω-ланцюгу §5.1), `CHAOTIC_ω(τ)` (у S(τ), §11.1), `ChaosStatus_D(P) = CHAOTIC` — три різні об'єкти з однаковою інтуїтивною назвою. Жодної імплікації між ними без окремого доказу.

### 4.5. Classify⁺_D

**Означення 4.5.1.** Для фіксованої системи (K, D):

```text
Classify⁺_D(P) := (OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P))
```

Уніфікована назва — `Classify⁺_D`. У §5 вживається та сама назва.

**Твердження 4.5.2 (C3).** Складові не незалежні:

- (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC};
- (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT\_DYNAMIC.

DP-f.

**Твердження 4.5.3 (C7).** У скінченному X хаотичних множин немає. DP-f.

**Твердження 4.5.4 (C4, розділене).**

- **(C4a).** Якщо P скінченна й D[P] = P, то D|\_P — бієкція, і кожна точка P має скінченний період. **DP-f.**
- **(C4b).** Для нескінченної P бієкція D|\_P **не** тягне скінченної періодичності всіх точок. Контрприклад: одометр (§11.6). **DP-f.**
- **(C4c).** Для нескінченної P навіть сюр'єктивність D|\_P не тягне ін'єктивності. Контрприклад: однобічний зсув σ на {0, 1}^ℕ (σ(x)ₙ = xₙ₊₁): сюр'єктивний, не ін'єктивний. **DP-f.**

Раніше одометр подавався як спростування всього C4; це було неточно. Одометр спростовує лише періодичність усіх точок, а не бієктивність.

```text
π_Ω(O, I, C) :=
   CHAOTIC_set             якщо C = CHAOTIC
   APERIODIC_NON_CHAOTIC   якщо O = APERIODIC і C ≠ CHAOTIC
```

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

**Означення 6.1.1.** Для довільної динамічної системи (X, D), x ∈ X, U ⊆ X. Тут `¬U := X ∖ U` — **класичне** доповнення множини; воно не тотожне `¬_H` з §6.2.

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`D` замінює динамічний `F`. `F_tree` — виключно функтор `X ↦ A ⊔ X³`.

**Твердження 6.1.2 (M1).** Аксіоми X1–X3, D1–D3, B1–B5, R1–R2, M4 валідні. DP-f.

**Твердження 6.1.3 (M2, M6).** □U → ↺U. DP-f.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** (□\_H U)(x) := ⋀ₙ≥₀ U(Dⁿx), (◇\_H U)(x) := ⋁ₙ≥₀ U(Dⁿx) у решітці Ω. `¬_H a := a →_H ⊥` — псевдодоповнення в Ω (не класичне).

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g), S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ.

```text
D_X(s, ρ) := (ρ(s), g(ρ, s))
```

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ) з умовою:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))
```

**Застереження 7.3.** Умова стосується S-компоненти D.

**Означення 7.4 (SUBIT\_full).** Морфізми додатково:

```text
φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s))
```

**Твердження 7.5 (K1).** SUBIT і SUBIT\_full — категорії. DP-f.

**Твердження 7.6 (K2).** 1 = ({∗}, {id}, g\_triv) — термінальний об'єкт. DP-f.

**Твердження 7.7 (K3, добуток).** Для X, Y з непорожніми S\_X, S\_Y:

```text
ρ ⊠ σ : S_X × S_Y → S_X × S_Y,   (ρ ⊠ σ)(x, y) := (ρ(x), σ(y))
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
D_{X×Y}((x, y), ρ ⊠ σ) := ((ρ(x), σ(y)), g_X(ρ, x) ⊠ g_Y(σ, y))
```

DP-f.

**Застереження 7.8.** Якщо категорія має допускати порожні S, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X`.

**Відкрито.** Q1 (декартова замкненість), Q19 (ізоморфізм SUBIT\_full з різними g).

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — φ∘f = h∘φ.

**Означення 8.2 (Dyn₊).** Повна підкатегорія Dyn з непорожніми S.

**Твердження 8.3 (K4, топос).** Dyn ≅ Fun(Bℕ, Set), де Bℕ — категорія з одним об'єктом і моноїдом ендоморфізмів (ℕ, +, 0). Тут Bℕ — **не** категорія-порядок ℕ; це однооб'єктна категорія моноїда ℕ. Fun(Bℕ, Set) описує множини з однією ендодією, тобто (S, f). Класифікатор підоб'єктів: Ω\_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞, «істина» 0.

**Означення 8.4 (час входу, тільки для інваріантних U).** Нехай U ⊆ S — підоб'єкт, тобто f[U] ⊆ U. Час входу:

```text
χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U }   (∞, якщо ніколи)
```

**Твердження 8.5 (χ\_U — морфізм).** Для підоб'єкта U: χ\_U(f(x)) = max(χ\_U(x) − 1, 0), отже χ\_U : (S, f) → (Ω\_Dyn, ·) — морфізм Dyn. DP-f.

**Застереження 8.6.** Для довільної U ⊆ S (не інваріантної) формула χ\_U загалом **не** еквіваріантна і не є морфізмом. χ\_U визначено лише для підоб'єктів.

**Твердження 8.7.** Sub\_Dyn(X) ≅ Hom\_Dyn(X, Ω\_Dyn). DP-s.

**Твердження 8.8 (K5, вкладення).** Існує повне й вірне вкладення:

```text
Dyn₊ ↪ SUBIT,   (S, f) ↦ (S, {f}, g_f),   g_f(f, s) := f
```

Таке саме вкладення в SUBIT\_full. DP-f.

**Застереження 8.9.** Вкладення всієї Dyn неможливе без перегляду типу правил (S = ∅).

**Застереження 8.10.** Топосна структура Dyn не переноситься на SUBIT автоматично.

**Q2′ (ВІДКРИТО).** Чи існує категорія C, що містить образ Dyn₊ у SUBIT і має топосну структуру, яка зберігає нетривіальну метаеволюцію?

## 9. Простір S\_∞ = Tree\_∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, Λ := {None, node} ∪ {leaf(a) : a ∈ A} (|Λ| = 6). Tree\_∞ — множина f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None.

S\_∞ := Tree\_∞.

**Означення 9.2 (піддерево).** Для f з f(ε) = node: f\_i(σ) := f(i·σ). Для f з f(ε) = leaf(a) піддерево **не визначене**.

**Твердження 9.3 (T1, фінальна коалгебра).** Tree\_∞ з out(f) := inl(a), якщо f(ε) = leaf(a), і out(f) := inr(f₁, f₂, f₃), якщо f(ε) = node, — фінальна коалгебра `F_tree(X) = A ⊔ X³`. DP-s.

**Твердження 9.4 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S\_∞. DP-f.

### 9.2. Оператор Ψ і L_prod

**Означення 9.2.1 (T_n, q_n).**

```text
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) : a ∈ A } ∪ { Bottom_{n+1} }
         ∪ { Node_n(t₁, t₂, t₃) : t₁, t₂, t₃ ∈ T_n }

q_0 : T_1 → T_0
q_0(Leaf_1 a)          := Leaf_0 a
q_0(Bottom_1)          := Bottom_0
q_0(Node_0(t₁, t₂, t₃)) := Bottom_0

q_{n+1} : T_{n+2} → T_{n+1}
q_{n+1}(Leaf_{n+2} a)          := Leaf_{n+1} a
q_{n+1}(Bottom_{n+2})          := Bottom_{n+1}
q_{n+1}(Node_{n+1}(t₁,t₂,t₃))  := Node_n(q_n t₁, q_n t₂, q_n t₃)
```

**Означення 9.2.2 (U\_c).**

```text
U_c := { (t_n) ∈ ∏_n T_n : ∀n, q_n(t_{n+1}) = t_n }
```

**Означення 9.2.3 (LeafSeqs, NodeSeqs, Ψ).**

```text
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }
NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0
                ∧ ∃ u₁, u₂, u₃ ∈ X
                ∧ ∀n ≥ 0: t_{n+1} = Node_n(u_{1,n}, u_{2,n}, u_{3,n}) }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.2.4.** L\_prod = Ψ(L\_prod). DP-f.

**Твердження 9.2.5 (коалгебраїчний ізоморфізм).** p : Tree\_∞ → L\_prod, p(f) := (d\_n(f))\_n — бієкція з оберненим lim\_tree. DP-s.

**Застереження 9.2.6.** Ψ використовується виключно для оператора продуктивності. Глобальний предикат траєкторії — `GP_φ(τ)` (§6.4).

**Застереження 9.2.7.** Пряме означення `d_S` і доказ компактності `Tree_∞` через замкненість у `Λ^Pos` не залежать від `L_prod`. Відповідність `Tree_∞ ≅ L_prod` — окремий результат реконструкції.

### 9.3. Глибинні апроксимації d_n, метрика d_S

**Означення 9.3.1 (d_n).**

```text
d_0(f)     := Leaf_0(a)   якщо f(ε) = leaf(a)
d_0(f)     := Bottom_0    якщо f(ε) = node

d_{n+1}(f) := Leaf_{n+1}(a)   якщо f(ε) = leaf(a)
d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))   якщо f(ε) = node
```

**Твердження 9.3.2.** d\_n(f) ∈ T\_n; q\_n(d\_{n+1}(f)) = d\_n(f). DP-f.

**Означення 9.3.3 (d\_S).**

```text
r_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) }   (∞, якщо f = g)
d_S(f, g) := 2^{−r_addr(f, g)}   (0, якщо f = g)
```

**Лема 9.3.4 (R3.9.1).** Для f ≠ g: r\_addr(f, g) = min{ n ≥ 0 : d\_n(f) ≠ d\_n(g) }. DP-f (індукція за глибиною першої розбіжності).

**Твердження 9.3.5 (T3).** d\_S — ультраметрика. DP-f.

**Твердження 9.3.6 (T4).** **Нехай f(ε) = g(ε) = node.** Тоді для кожного i ∈ {1, 2, 3}:

```text
d_S(f_i, g_i) ≤ 2 · d_S(f, g)
```

DP-f. (Раніше умова була неявною; тепер вона явна.)

**Твердження 9.3.7 (T5).** (Tree\_∞, d\_S) компактний, повний, цілком обмежений. DP-s.

**Твердження 9.3.8 (R2.6.1, адресний доступ).** Нехай f ∈ Tree\_∞, σ ∈ Pos, n > |σ|. Тоді:

- f(σ) = leaf(a) ⇒ at\_n(d\_n(f), σ) = Some((n−|σ|, Leaf\_{n−|σ|}(a)));
- f(σ) = node ⇒ at\_n(d\_n(f), σ) має кореневий конструктор Node\_{n−|σ|−1};
- f(σ) = None ⇒ at\_n(d\_n(f), σ) = None.

DP-f.

**Твердження 9.3.9 (перша тотожність).** lim\_tree(p(f)) = f. Доведення — за довільною адресою через 9.3.8. DP-f. Не використовує другої тотожності.

**Твердження 9.3.10 (друга тотожність).** p(lim\_tree(t)) = t для t ∈ L\_prod. DP-f.

### 9.4. Кодування «хребта» і простір Y

**Означення 9.4.1.** Фіксуємо **три різні** літери α, β, η ∈ A, **α ≠ β**. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ:

```text
t(a)(1ᵏ)    := node
t(a)(1ᵏ·2)  := leaf(a_k)
t(a)(1ᵏ·3)  := leaf(η)
```

Інші позиції — за (T2)–(T4).

**Твердження 9.4.2.** Відображення t : {α, β}^ℕ → S\_∞ неперервне й ін'єктивне (оскільки α ≠ β). Образ Y := t({α, β}^ℕ) ≅ {α, β}^ℕ — канторів простір. Зсув σ на {α, β}^ℕ спряжений до T := t ∘ σ ∘ t⁻¹ на Y. DP-f.

**Зауваження 9.4.3.** S\_∞ — нульвимірний компакт. Скінченні дерева — ізольовані точки. Множина нескінченних дерев утворює перфектну замкнену частину S\_∞. **Y — перфектна підмножина S\_∞, гомеоморфна канторовому простору, але не вся перфектна частина S\_∞.**

## 10. Правила ℛ₀, ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні правила

**Означення 10.1.** ℛ\_caus := { f : S\_∞ → S\_∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) }. Історичне позначення: **ℛ₀ := ℛ\_caus**. Метрика:

```text
d_ℛ(ρ, σ) := sup_{s ∈ S_∞} d_S(ρ(s), σ(s))
```

**Означення 10.2 (ℛ₁, ℛ\_comp).** ℛ\_comp — множина функцій S\_∞ → S\_∞, що мають скінченний обчислювальний опис у фіксованій моделі обчислень, де дерево подано оракулом (адреса → мітка). Історичне позначення: **ℛ₁ := ℛ\_comp**.

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ n-префікс виходу залежить лише від n-префіксу входу. DP-f.

**Твердження 10.4 (T6).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. DP-s (Арцела–Асколі).

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀. |ℛ₁| = ℵ₀ за припущення про модель. DP-s.

### 10.2. Розширений простір і передумови

**Припущення (H).** R ⊆ ℛ₀ — непорожня замкнена (компактна) множина правил; g∞ : R × S\_∞ → R — неперервна (тотальна на всій області). Розширений простір X := S\_∞ × R. Метрика:

```text
d̂((s, ρ), (t, σ)) := max(d_S(s, t), d_ℛ(ρ, σ))
```

Для R × R: **d\_R := d\_ℛ|\_{R × R}**. Динаміка:

```text
D∞(s, ρ) := (ρ(s), g∞(ρ, s))
```

**Припущення (H₀).** Для скінченної моделі SUBIT⁺: S₀ скінченне з дискретною топологією, D₀ тотальне, g₀ тотальне. (H₀) не є екземпляром (H): простори станів і правил мають інші типи.

**Означення 10.6 (π\_R).** π\_R : R × S\_∞ → R, π\_R(ρ, s) := ρ.

**Застереження 10.7.** Запис `g∞ ≡ id` типізовано некоректний: id на R × S\_∞ має кодомен R × S\_∞, а не R. Правильна умова тотожної метаеволюції: **`g∞ = π_R`**, тобто ∀ρ ∈ R, ∀s ∈ S\_∞: g∞(ρ, s) = ρ. Надалі в D4 вживається `g∞ = π_R`, а в D5 — `g∞ ≠ π_R`.

**Твердження 10.8 (T7).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)). Отже при (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. DP-f.

### 10.3. Метрики на X

**Твердження 10.9 (T8, d\_finite).**

```text
d_finite(x, y) := sup_{n ≥ 0} 2^{−n} · d̂(D∞ⁿ(x), D∞ⁿ(y))
```

DP-f (аргумент: псевдоультраметрики, масштабування, супремум, член n = 0, компактність X, неперервність D∞ⁿ).

**Означення 10.10 (d\_H на S\_∞).** Для непорожніх компактних P, Q ⊆ S\_∞:

```text
d_H(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d_S(p, q),
                  sup_{q∈Q} inf_{p∈P} d_S(p, q) }
```

**Означення 10.11 (d\_H^X на X).** Для непорожніх компактних P, Q ⊆ X:

```text
d_H^X(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d̂(p, q),
                    sup_{q∈Q} inf_{p∈P} d̂(p, q) }
```

**Означення 10.12 (d\_ω, типізована).** Для ŝ, t̂ ∈ X з непорожніми компактними ω-границями:

```text
d_ω(ŝ, t̂) := d_H^X(ω(ŝ), ω(t̂))
```

Псевдометрика на X; метрика — на факторі `X / ~`, де ŝ ~ t̂ ⟺ ω(ŝ) = ω(t̂). **DP-f** за компактності X.

**Застереження 10.13.** d\_H (на S\_∞) і d\_H^X (на X) — різні функції.

**Застереження 10.14.** Правила з ℛ₁, які не неперервні, у (H) не потрапляють.

## 11. Класифікація траєкторій P(τ)

Всюди припускається (H). Без (H) твердження D1–D6 — УМОВНО.

### 11.1. ω-границя і класи S(τ)

**Означення 11.1.1 (мінімальність).** Непорожня компактна D∞-інваріантна M ⊆ X — **мінімальна**, якщо не містить власної непорожньої замкненої D∞-інваріантної підмножини.

**Означення 11.1.2 (класи S(τ)).** Для траєкторії τ з ω = ω(τ):

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω = {p}, D∞(p) = p |
| PERIODIC | ω скінченна, \|ω\| > 1 |
| MINIMAL\_ZERO\_ENTROPY | ω нескінченна, мінімальна, h\_top(D∞\|ω) = 0 |
| CHAOTIC\_ω | ω нескінченна, мінімальна, h\_top(D∞\|ω) > 0 |
| NON\_MINIMAL | ω нескінченна, не мінімальна |

`QUASI_PERIODIC_MINIMAL` — **підклас** `MINIMAL_ZERO_ENTROPY`.

**Твердження 11.1.3 (D1).** За (H) ω(τ) непорожня, компактна, D∞[ω(τ)] = ω(τ). DP-f.

**Означення 11.1.4 (Att).** ATTAINED ⇔ ∃n: x\_n ∈ ω(τ). **NONATTAINED := ¬ATTAINED.** Історична назва `ASYMPTOTIC` збережена як **синонім** для SUBIT-специфічного терміну «не досягнуто точно»; вона **не** означає стандартну асимптотичну збіжність відстані (яка в компактній системі виконується для будь-якої орбіти). У формальному тексті вживається `NONATTAINED`.

**Твердження 11.1.5 (D6).** За (H) п'ять класів попарно не перетинаються й вичерпують усі траєкторії. DP-f.

**Доведення.** За D1, ω = ω(τ) непорожня, компактна, D∞-інваріантна.

1. ω скінченна. Тоді D∞|ω — перестановка скінченної множини. ω — об'єднання циклів. Якщо |ω| = 1, FIXED. Якщо |ω| > 1, PERIODIC.
2. ω нескінченна. Тоді ω або мінімальна, або не мінімальна — це бінарна властивість.
   - ω не мінімальна → NON\_MINIMAL.
   - ω мінімальна. Тоді h\_top(D∞|ω) або 0, або > 0. Це дає MINIMAL\_ZERO\_ENTROPY або CHAOTIC\_ω.

Лема Цорна **не потрібна** для вичерпності: після D1 ω вже компактна й інваріантна, і питання мінімальності розв'язується бінарно. (Лема Цорна доречна лише для існування мінімальної підмножини, якщо така потрібна для інших цілей.) ∎

### 11.2. Ентропія

`CHAOTIC_ω` означає h\_top(D∞|\_ω) > 0 і ніяк інакше.

- **D3.** Нерозтягувальне D∞ на ω ⇒ h\_top = 0. DP-s.
- **D4.** `g∞ = π_R` ⇒ D∞(s, ρ) = (ρ(s), ρ) нерозтягувальне ⇒ h\_top = 0 і CHAOTIC\_ω неможливий. DP-f.
- **D3′.** Для ρ ∈ ℛ₀ і K\_ρ := S\_∞ × {ρ}, якщо g∞(ρ, s) = ρ, то D∞|\_{K\_ρ} ізоморфне ρ, і h\_top = 0. DP-f.

### 11.3. Метрика d\_Ω\_traj

Довжина найкоротшого шляху в графі «відмова від сертифікату». Діагностична роль; в Ω-логіці не використовується.

### 11.4. Явна реалізація CHAOTIC\_ω × ATTAINED (D5)

**Конструкція (CE-11-R4.D5).**

1. Нехай Z ⊆ {α, β}^ℕ (α ≠ β) — непорожній замкнений **мінімальний** підзсув з h\_top(σ|\_Z) > 0 (існує за відомою теоремою).
2. Нехай t : {α, β}^ℕ → S\_∞ — кодування §9.4. Позначимо Y := t[Z], T := t ∘ σ ∘ t⁻¹ : Y → Y — спряжений зсув.
3. Для кожного c ∈ Y визначимо константне правило κ\_c : S\_∞ → S\_∞, κ\_c(s) := c. Нехай R\_Y := {κ\_c : c ∈ Y}.
4. R\_Y ⊆ ℛ₀: d\_S(κ\_c(s), κ\_c(t)) = 0 ≤ d\_S(s, t). Відображення c ↦ κ\_c — ізометричне вкладення (Y, d\_S) → (ℛ₀, d\_ℛ). Отже, R\_Y компактна, значить замкнена.
5. Визначимо g∞ **на всій області** R\_Y × S\_∞:

```text
g∞(κ_c, s) := κ_{T(c)}
```

Неперервність: T неперервне на Y; κ\_c ↦ κ\_{T(c)} — композиція неперервних відображень; g∞ не залежить від s.
6. Розглянемо **граф**:

```text
G := { (c, κ_{T(c)}) : c ∈ Y } ⊆ S_∞ × R_Y
```

7. Обчислимо D∞ на G:

```text
D∞(c, κ_{T(c)}) = (κ_{T(c)}(c), g∞(κ_{T(c)}, c))
                = (T(c), κ_{T(T(c))})
                = (T(c), κ_{T²(c)}).
```

Отже, D∞[G] = G (бо T — бієкція Y → Y).
8. G компактна (неперервний образ компакту Y), D∞-інваріантна, і D∞|\_G спряжене до T|\_Y, яке мінімальне з h\_top > 0.
9. Якщо x₀ ∈ G, то ω(x₀) = G і x₀ ∈ ω(x₀). Отже, ATTAINED.
10. g∞ ≠ π\_R (бо g∞(κ\_c, s) = κ\_{T(c)} ≠ κ\_c для c з T(c) ≠ c, а такі c існують, бо T|\_Y мінімальне й нескінченне).

**Твердження (D5).** Пара CHAOTIC\_ω × ATTAINED реалізується в системі (X\_Y := S\_∞ × R\_Y, D∞), яка задовольняє (H). **DP-f.**
