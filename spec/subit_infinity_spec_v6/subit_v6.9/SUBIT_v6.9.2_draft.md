## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** ℛ\_fin — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан ŝ = (s, ρ) ∈ S₀ × ℛ\_fin. Метаеволюція g₀ : ℛ\_fin × S₀ → ℛ\_fin.

D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )

**Аксіома 2.2 (тотальність).** У базовій детермінованій моделі D₀ — тотальна. Часткові оператори, помилки, ресурсні переривання — окремий шар (§11.7).

**Твердження 2.4 (A4).** Кожний автономний скінченний автомат (Q, δ), |Q| ≤ 64, вкладається в SUBIT⁺. DP. ВІДКЛИКАНО: універсальний принцип симуляції DFA, універсальний об'єкт.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень — Ω_point^fin

**Означення 3.1.1.** Область `Ω_point^fin` — `Q₀ := S₀ × ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | 1 ≤ m < ∞ |

**Твердження 3.1.2 (P1).** У Q₀ для кожного ŝ виконується m(ŝ) < ∞. DP (Діріхле).

**Твердження 3.1.3 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP.

**Твердження 3.1.4 (P3).** Алгоритм:

```text
Вхід: ŝ₀, N_max ≥ |Q₀|
visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m
        category ← FIXED / PERIODIC(p) / PREPERIODIC(m, p)
        повернути
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
повернути RESOURCE_EXCEEDED
```

### 3.2. Нескінченний рівень — Ω_point^∞

**Означення 3.2.1.** Область — `S_∞ × R` за припущення (H). m(ŝ), p(ŝ) визначені з D∞, дозволяючи ∞.

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞ |
| APERIODIC | m = ∞ |

**Твердження 3.2.2.** Чотири класи попарно не перетинаються й вичерпують S\_∞ × R. DP.

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀ (CE-11-R2.3).

## 4. Класифікація множин Classify⁺

У §4–§5 X — S₀ × ℛ\_fin або S\_∞ × R; P ⊆ X — **непорожня**; D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

**Означення 4.1.1.**

```text
μ(P)    := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }        (∞ якщо немає)
π(P)    := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }  (тільки при μ < ∞)
           ∞                                             (якщо μ = ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                     (∞ якщо немає)
```

| Клас OrbitType | Нормативна умова |
| :-- | :-- |
| INVARIANT\_FIXED | D[P] = P ∧ ∀x ∈ P: D(x) = x |
| INVARIANT\_DYNAMIC | D[P] = P ∧ ∃x ∈ P: D(x) ≠ x |
| PERIODIC\_SET | D[P] ≠ P ∧ μ(P) = 0 ∧ 2 ≤ p\_set(P) < ∞ |
| EVENTUALLY\_FIXED | 1 ≤ μ(P) < ∞ ∧ π(P) = 1 |
| EVENTUALLY\_PERIODIC | 1 ≤ μ(P) < ∞ ∧ 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.2 (C1, розбиття).** Шість класів попарно не перетинаються й вичерпують усі непорожні P. DP за тотальності D.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  інакше
```

**Твердження 4.2.1 (C2).** П'ять класів попарно не перетинаються; усі непорожні P розбиті. DP.

### 4.3. ChaosStatus — тризначний статус

**Означення 4.3.1.** Для непорожньої P ⊆ X:

```text
ChaosStatus_D(P) ∈ { NOT_APPLICABLE, NON_CHAOTIC, CHAOTIC }

NOT_APPLICABLE — топологічні передумови не виконані
                 (P не компактна, або D[P] ≠ P, або D|_P не неперервне)

CHAOTIC        — передумови виконані ∧ P мінімальна ∧ h_top(D|_P) > 0

NON_CHAOTIC    — передумови виконані, але CHAOTIC не виконується
```

**Застереження 4.3.2.** `NOT_APPLICABLE` **не еквівалентне** `NON_CHAOTIC`. Перше означає, що топологічний критерій хаотичності не має застосування до цієї множини за поточними передумовами. Друге означає, що передумови виконані, але критерій не справджується. Різниця є нормативною.

**Твердження 4.3.3.** `Classify⁺` тотальний на непорожніх підмножинах для фіксованої динаміки D. DP (означення).

### 4.4. Розмежування трьох CHAOTIC

**Означення 4.4.1.** Назва `CHAOTIC` у трьох контекстах означає різні об'єкти:

- `CHAOTIC_set(P)` — нижній елемент Ω-ланцюга (§5.1);
- `CHAOTIC_ω(τ)` — клас траєкторії (§11.1);
- `ChaosStatus_D(P) = CHAOTIC` — предикат хаотичності компактної інваріантної множини (§4.3).

Наявність однакової назви не створює імплікації.

### 4.5. Classify⁺

```text
Classify⁺(P) := (OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P))
```

**Твердження 4.5.1 (C3).** Складові не незалежні:

- (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC};
- (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT\_DYNAMIC.

DP.

**Твердження 4.5.2 (C7).** У скінченному X хаотичних множин немає. DP.

**Твердження 4.5.3 (C4).** (а) Якщо P скінченна й D[P] = P, то D|\_P — бієкція; кожна точка P — FIXED або PERIODIC. (б) Для нескінченної P це хибне — див. одометр §11.6.

## 5. Алгебра Ω і проєкція π\_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D\_class, глобальна область).**

```text
D_class := { Classify_D⁺(P) : (K,D) — допустима система, ∅ ≠ P ⊆ K }
```

Усі координати кортежу обчислюються для тієї самої системи `(K,D)`.

**Означення 5.3 (π\_Ω).**

```text
π_Ω(O, I, C) :=
   CHAOTIC_set             якщо C = CHAOTIC
   APERIODIC_NON_CHAOTIC   якщо O = APERIODIC і C ≠ CHAOTIC
   EVENTUALLY_PERIODIC     якщо O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC} і C ≠ CHAOTIC
   PERIODIC_SET            якщо O = PERIODIC_SET і C ≠ CHAOTIC
   INVARIANT_DYNAMIC       якщо O = INVARIANT_DYNAMIC і C ≠ CHAOTIC
   INVARIANT_FIXED         якщо O = INVARIANT_FIXED і C ≠ CHAOTIC
```

**Твердження 5.4 (C5a, тотальність).** π\_Ω тотальна на D\_class. DP: кожен кортеж має визначені OrbitType, InclusionType і ChaosStatus.

**Твердження 5.5 (C5b, сюр'єктивність).** Образ π\_Ω є підмножиною Ω. Сюр'єктивність на всі шість класів заявляється лише для глобальної області, у якій наведені свідчення реалізовності кожного класу.

**Застереження 5.6.** Для фіксованої скінченної системи образ π\_Ω не може містити `CHAOTIC_set`, оскільки скінченні системи не мають додатної топологічної ентропії. Безумовне формулювання сюр'єктивності для довільної динаміки ВІДКЛИКАНО. Статус: тотальність — DP; глобальна сюр'єктивність — УМОВНО.

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b, ¬a := a → ⊥ (⊥ = CHAOTIC\_set, ⊤ = INVARIANT\_FIXED).

**Твердження 5.8 (C6).** Це алгебра Гейтінга; виключене третє не виконується. DP.

**Застереження 5.9.** π\_Ω втратна. Ω — синтаксичний інструмент, не пов'язана формально з білаттисом Белнапа.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

**Означення 6.1.1.** Для довільної динамічної системи (X, D), x ∈ X, U ⊆ X:

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`D` замінює динамічний `F` з v6.9.1. `F_tree` резервується виключно для функтора `X ↦ A ⊔ X³`.

**Твердження 6.1.2 (M1, аксіоми).**

```text
(X1) X U → ◇⁺ U                 (X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)      (D1) ◇U ↔ U ∨ X ◇U
(D2) ◇⁺ U ↔ X ◇U                 (D3) ◇U ↔ U ∨ ◇⁺ U
(B1) □U ↔ U ∧ X □U               (B2) □U → U
(B3) □U → X □U                  (B4) □U → ◇U
(B5) □(U → V) → (□U → □V)       (R1) ↺U ↔ ◇⁺(X U)
(R2) ↺U → ◇⁺ U                  (M4) ◇U ↔ ¬□¬U
```

DP.

**Твердження 6.1.3 (M2, M6).** □U → ↺U. DP.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** (□\_H U)(x) := ⋀ₙ≥₀ U(Dⁿx), (◇\_H U)(x) := ⋁ₙ≥₀ U(Dⁿx) у решітці Ω.

**Твердження 6.2.2 (M3).** Рівність ◇\_H U = ¬\_H □\_H ¬\_H U хибна. Контрмодель: X = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY\_PERIODIC, U(b) = CHAOTIC\_set. DP.

Q6, Q9 — ВІДКРИТО.

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : U @ τ. Правила:

```text
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ
Еволюція:        Γ ⊢ t:U@τ    D[U] ⊆ V   ⇒   Γ ⊢ D(t) : V@(τ+1)
Стабільність:     Γ ⊢ t:U@τ    D[U] = U     ⇒   Γ ⊢ t : □U@τ
Потенційність:    Γ ⊢ t:U@τ    ∃k: Dᵏ[U] ⊆ V   ⇒   Γ ⊢ t : ◇V@τ
```

ВИЗНАЧЕНО; метатеорія збереження й повноти — НЕ ПІДТВЕРДЖЕНО.

### 6.4. Предикати префікса

```text
PH_φ(N) := ∀k ≤ N: φ(k, τ)        (Prefix-Hereditary)
EP_φ(N) := ∃k ≤ N: φ(k, τ)        (Extension-Preserving)
PP_φ(k) := φ(k, τ)                 (Pointwise)
GP_φ(τ)                            (Global — властивість усієї траєкторії)
```

**Правила:** `PH_φ(N+1) ⟹ PH_φ(N)`; `EP_φ(N) ⟹ EP_φ(N+1)`; `PH_φ(N) ⟹ EP_φ(N)` для `N ≥ 0`. Жодних автоматичних імплікацій між PP і GP. Символ `Ψ` зарезервовано для оператора продуктивності (§9.2).

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g), де S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ.

```text
D_X(s, ρ) := (ρ(s), g(ρ, s))
```

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ) з умовою динамічної сумісності:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))
```

**Застереження 7.3.** Це умова на S-компоненту D; компонента g не входить.

**Означення 7.4 (SUBIT\_full).** Широка підкатегорія; морфізми додатково:

```text
φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s))
```

**Твердження 7.5 (K1).** SUBIT і SUBIT\_full — категорії. DP.

**Твердження 7.6 (K2).** 1 = ({∗}, {id}, g\_triv) — термінальний об'єкт. DP.

**Твердження 7.7 (K3, добуток).** Для X, Y з непорожніми S\_X, S\_Y:

```text
ρ ⊠ σ : S_X × S_Y → S_X × S_Y,   (ρ ⊠ σ)(x, y) := (ρ(x), σ(y))
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
D_{X×Y}((x, y), ρ ⊠ σ) := ((ρ(x), σ(y)), g_X(ρ, x) ⊠ g_Y(σ, y))
```

DP.

**Застереження 7.8.** Якщо категорія має допускати порожні простори станів, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X`.

**Відкрито.** Декартова замкненість — Q1. Ізоморфізм об'єктів SUBIT\_full з різними g — Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — φ∘f = h∘φ.

**Означення 8.2 (Dyn₊).** Повна підкатегорія Dyn з непорожніми просторами станів.

**Твердження 8.3 (K4).** Dyn ≅ Fun(ℕ, Set) — топос. Класифікатор Ω\_Dyn = ℕ ∪ {∞}, дія n·k := max(n − k, 0), ∞·k := ∞, «істина» 0. Час входу χ\_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U} (∞, якщо ніколи). DP.

**Твердження 8.4 (K5, вкладення).** Існує повне й вірне вкладення:

```text
Dyn₊ ↪ SUBIT,   (S, f) ↦ (S, {f}, g_f),   g_f(f, s) := f
```

Таке саме вкладення існує в SUBIT\_full. DP.

**Застереження 8.5.** Вкладення всієї `Dyn` не визначене в SUBIT, оскільки SUBIT забороняє S = ∅. Якщо потрібне вкладення всієї Dyn, SUBIT потребує перегляду типу правил (ідентифікатори замість `ℛ ⊆ S^S`).

**Застереження 8.6.** Топосна структура Dyn не переноситься на SUBIT автоматично.

**Q2′ (ВІДКРИТО, переформульовано).** Чи існує категорія C, що містить образ Dyn₊ у SUBIT і має топосну структуру, яка зберігає нетривіальну метаеволюцію?

## 9. Простір S\_∞ = Tree\_∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, Λ := {None, node} ∪ {leaf(a) : a ∈ A} (|Λ| = 6). Tree\_∞ — множина f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None.

S\_∞ := Tree\_∞.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree\_∞ з out(f) := inl(a), якщо f(ε) = leaf(a), і out(f) := inr(f₁, f₂, f₃), якщо f(ε) = node, — фінальна коалгебра `F_tree(X) = A ⊔ X³`. DP (схема).

**Твердження 9.3 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S\_∞. DP.

**Означення 9.4 (кодування «хребта»).** Фіксуємо α, β, η ∈ A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ дерево t(a): t(a)(1ᵏ) = node, t(a)(1ᵏ·2) = leaf(aₖ), t(a)(1ᵏ·3) = leaf(η). Тоді t(a)₁ = t(σa), де σ — зсув, і Y := {t(a)} ≅ {α, β}^ℕ неперервно вкладене.

### 9.2. Оператор Ψ

**Означення 9.2.1.** На 𝒫(U\_c):

```text
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.2.2.** L\_prod = Ψ(L\_prod). DP.

**Твердження 9.2.3 (коалгебраїчний ізоморфізм).** p : Tree\_∞ → L\_prod, p(f) := (d\_n(f))\_n — бієкція з оберненим lim\_tree. DP.

**Застереження 9.2.4.** Ψ використовується виключно для оператора продуктивності. Глобальний предикат траєкторії — `GP_φ(τ)` (§6.4).

**Застереження 9.2.5 (залежність).** Пряме означення `d_S` і доказ компактності `Tree_∞` через замкненість у `Λ^Pos` не залежать від `L_prod` або оберненої границі. Відповідність `Tree_∞ ≅ L_prod` зберігається як окремий результат реконструкції.

### 9.3. Метрика d\_S

**Означення 9.3.1.** r\_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) } (∞, якщо f = g). d\_S(f, g) := 2^{−r\_addr(f, g)} (0, якщо f = g).

**Лема 9.3.2 (R3.9.1, узгодження з апроксимаціями).** Для f, g ∈ Tree\_∞, f ≠ g, визначимо

```text
r_app(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }
```

Тоді `r_addr(f, g) = r_app(f, g)`. DP: апроксимація d\_n розрізняє мітки на глибині до n включно; перша адресна розбіжність на глибині k видима саме в d\_k.

**Твердження 9.3.3 (T3).** d\_S — ультраметрика. DP.

**Твердження 9.3.4 (T4).** d\_S(f\_i, g\_i) ≤ 2·d\_S(f, g). DP.

**Твердження 9.3.5 (T5).** (Tree\_∞, d\_S) компактний, повний, цілком обмежений. DP.

**Твердження 9.3.6 (R2.6.1, адресний доступ).** Нехай f ∈ Tree\_∞, σ ∈ Pos, n > |σ|. Тоді:

- f(σ) = leaf(a) ⇒ at\_n(d\_n(f), σ) = Some((n−|σ|, Leaf\_{n−|σ|}(a)));
- f(σ) = node ⇒ at\_n(d\_n(f), σ) має кореневий конструктор `Node_{n−|σ|−1}`;
- f(σ) = None ⇒ at\_n(d\_n(f), σ) = None.

DP.

**Твердження 9.3.7 (перша тотожність).** lim\_tree(p(f)) = f. Доведення — за довільною адресою через 9.3.6. DP. Не використовує другої тотожності.

**Твердження 9.3.8 (друга тотожність).** p(lim\_tree(t)) = t для t ∈ L\_prod. DP.

**Зауваження 9.3.9.** Ізольовані точки Tree\_∞ — рівно скінченні дерева. S\_∞ — нульвимірний компакт з перфектною частиною (Y) і деякими ізольованими точками; не канторівський простір.

## 10. Правила ℛ₀, припущення (H) і (H₀), метрики

### 10.1. Причинні правила

**Означення 10.1.** ℛ₀ := { f : S\_∞ → S\_∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) }. Метрика d\_ℛ(ρ, σ) := sup\_s d\_S(ρ(s), σ(s)).

**Твердження 10.2 (T5′).** f ∈ ℛ₀ ⇔ n-префікс виходу залежить лише від n-префіксу входу. DP.

**Твердження 10.3 (T6).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. DP (Арцела–Асколі).

**Твердження 10.4 (T9).** |ℛ₀| = 2^ℵ₀; |ℛ₁| = ℵ₀ (за припущення про модель обчислень). DP.

### 10.2. Розширений простір і передумови

**Припущення (H).** R ⊆ ℛ₀ — непорожня замкнена (компактна) множина правил; g∞ : R × S\_∞ → R неперервна. Розширений простір X := S\_∞ × R з d̂((s, ρ), (t, σ)) := max(d\_S(s, t), d\_ℛ(ρ, σ)).

```text
D∞(s, ρ) := (ρ(s), g∞(ρ, s))
```

**Припущення (H₀).** Для скінченної моделі SUBIT⁺: простір станів скінченний із дискретною топологією, D₀ тотальна, g₀ тотальна. Будь-яке відображення між дискретними скінченними просторами неперервне. **(H₀) не є екземпляром (H)**, оскільки простори станів і правил мають інші типи.

**Твердження 10.5 (T7).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)). Отже при (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. DP.

### 10.3. Метрики на розширеному просторі

**Твердження 10.6 (T8, d\_finite).**

```text
d_finite(x, y) := sup_{n ≥ 0} 2^{−n} · d̂(D∞ⁿ(x), D∞ⁿ(y))
```

DP. Аргумент:

1. `(x, y) ↦ d̂(D∞ⁿ(x), D∞ⁿ(y))` — псевдоультраметрика.
2. Масштабування додатним `2^{−n}` зберігає псевдоультраметрику.
3. Супремум сімейства псевдоультраметрик задовольняє ультраметричну нерівність.
4. Член n = 0 дорівнює d̂, тому d\_finite(x, y) = 0 ⇒ x = y. Метрика.
5. X компактний ⇒ d̂ обмежена. Для великих n хвіст рівномірно малий.
6. Кожне D∞ⁿ неперервне; контроль перших скінченних членів + рівномірно малий хвіст дають ту саму топологію.

**Означення 10.7 (d\_H на S\_∞).** Для непорожніх компактних P, Q ⊆ S\_∞:

```text
d_H(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d_S(p, q),
                  sup_{q∈Q} inf_{p∈P} d_S(p, q) }
```

**Означення 10.8 (d\_H^X, метрика Хаусдорфа на X).** Для непорожніх компактних P, Q ⊆ X (X = S\_∞ × R):

```text
d_H^X(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d̂(p, q),
                    sup_{q∈Q} inf_{p∈P} d̂(p, q) }
```

**Означення 10.9 (d\_ω, типізована).** Для ŝ, t̂ ∈ X з непорожніми компактними ω-границями:

```text
d_ω(ŝ, t̂) := d_H^X(ω(ŝ), ω(t̂))
```

Псевдометрика на X; метрика — на факторі `X / ~`, де ŝ ~ t̂ ⟺ ω(ŝ) = ω(t̂). **DP** за компактності X.

**Застереження 10.10.** d\_H (для S\_∞) і d\_H^X (для X) — різні функції; d\_H не замінює d\_H^X.

**Застереження 10.11.** Правила з ℛ₁, які не неперервні, у рамки (H) не потрапляють: ω-границі й класифікація §11 для них не визначені.

## 11. Класифікація траєкторій P(τ)

Всюди припускається (H). Без (H) твердження D1–D6 — УМОВНО.

### 11.1. ω-границя і класи S(τ)

**Означення 11.1.1 (мінімальність).** Непорожня компактна D∞-інваріантна M ⊆ X називається **мінімальною**, якщо не містить власної непорожньої замкненої D∞-інваріантної підмножини.

**Означення 11.1.2 (класи S(τ)).** Для траєкторії τ з ω = ω(τ):

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω = {p}, D∞(p) = p |
| PERIODIC | ω скінченна, \|ω\| > 1 |
| MINIMAL\_ZERO\_ENTROPY | ω нескінченна, мінімальна, h\_top(D∞\|ω) = 0 |
| CHAOTIC\_ω | ω нескінченна, мінімальна, h\_top(D∞\|ω) > 0 |
| NON\_MINIMAL | ω нескінченна, не мінімальна |

`QUASI_PERIODIC_MINIMAL` — **підклас** `MINIMAL_ZERO_ENTROPY`.

**Твердження 11.1.3 (D1).** За (H) ω(τ) непорожня, компактна, D∞[ω(τ)] = ω(τ). DP.

**Означення 11.1.4 (Att).** ATTAINED ⇔ ∃n: x\_n ∈ ω(τ). ASYMPTOTIC := ¬ATTAINED. **D2:** дві взаємовиключні позначки.

**Твердження 11.1.5 (D6).** За (H) п'ять класів попарно не перетинаються й вичерпують усі траєкторії. DP (лема Цорна для нескінченної ω).

### 11.2. Ентропія

`CHAOTIC_ω` означає h\_top(D∞|\_ω) > 0 і ніяк інакше.

- **D3.** Нерозтягувальне D∞ на ω ⇒ h\_top = 0. DP.
- **D4.** g∞ ≡ id ⇒ D∞ нерозтягувальне ⇒ h\_top = 0 і CHAOTIC\_ω неможливий. DP. Застереження: «NON\_MINIMAL порожній при g∞ ≡ id» — ВІДКРИТО.
- **D3′.** Для ρ ∈ ℛ\_caus і K\_ρ := S\_∞ × {ρ}, якщо g∞(ρ, s) = ρ, то D∞|\_{K\_ρ} ізоморфне ρ, і h\_top = 0. DP.

### 11.3. Метрика d\_Ω\_traj

На Ω\_traj — довжина найкоротшого шляху в графі «відмова від сертифікату». Діагностична роль; в Ω-логіці не використовується.

### 11.4. Вироджена реалізація CHAOTIC\_ω × ATTAINED (D5)

Нехай g∞ ≠ id. Мінімальний підзсув Y додатної ентропії; правила-константи ρ\_c; метаеволюція g∞(ρ\_c, c) := ρ\_{σ(c)}. D∞ має ω(τ) ≅ (Y, σ), тому h\_top > 0, старт у Y ⇒ ATTAINED. **D5**: пара CHAOTIC\_ω × ATTAINED реалізується вироджено. УМОВНО.

### 11.5. Таблиця реалізовності

| S(τ) | ATTAINED | ASYMPTOTIC |
| :-- | :-- | :-- |
| FIXED | так | так |
| PERIODIC | так | так |
| MINIMAL\_ZERO\_ENTROPY | так (одометр) | так |
| CHAOTIC\_ω | лише вироджено (D5) | так (ВІДКРИТО щодо невироджених) |
| NON\_MINIMAL | потрібен явний приклад | потрібен явний приклад |

**Застереження 11.5.1.** Ω\_traj має десять **номінальних** пар значень. **Реалізовність усіх десяти комбінацій траєкторій не доведена.**

### 11.6. Одометр: контрприклад і приклад

- **Контрприклад до скінченної періодичності в S\_∞ × ℛ₀.** Одометр (ℤ₂, +1) вкладається у S\_∞ × ℛ₀. Твердження «кожна ω-границя скінченно-періодична» хибне. DP.
- **Приклад MINIMAL\_ZERO\_ENTROPY.** Той самий одометр. DP.

### 11.7. Рівні сертифікації

COMPUTED (повний результат з рівнем сертифікату) або RESOURCE\_EXCEEDED.

1. **L0.** Скінченна орбіта в S₀, обхід.
2. **L1.** Періодичність у розширеному стані.
3. **L2.** Верхня оцінка ентропії за нерозтягувальністю (D3/D4).
4. **L3.** Лише емпірична оцінка за горизонтом (без сертифікату).

## 13. Pilot-01 (smoke-test)

**Мета.** Pilot-01 визначається як **smoke-test реалізації**, а не експериментальна перевірка теореми D4.

**Перевірки:**

1. Усі орбіти у скінченній моделі повторюються в межах |Q₀|+1 відвідувань станів.
2. Класифікатор правильно визначає m, p і періодичний цикл.
3. У скінченній моделі класифікатор не видає `CHAOTIC_ω`.
4. `RESOURCE_EXCEEDED` не подається як доведена класифікація.

**Критерій провалу:** порушення хоча б однієї властивості.

**Застереження 13.1 (неможливість фальсифікації).** Для тотальної динаміки на скінченному просторі кожна орбіта зрештою періодична, ω-границя скінченна, h\_top = 0 незалежно від гіпотези про g∞ у нескінченній моделі. Тому скінченний прогін **не може фальсифікувати** D4; для перевірки D4 потрібен незалежний математичний доказ або формальна перевірка.
