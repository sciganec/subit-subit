## 1. Алфавіт і простір станів S₀

### 1.1. Алфавіт

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, |A| = 4. Дві рівноправні інтерпретації одного й того ж чотириелементного коду (це не твердження про фізичну тотожність різних понять):

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. N і B непорівнянні за істинністю, F і T — за інформацією. Властивості білаттису не переносяться на динаміку S\_∞ без окремого означення. Статус: ВИЗНАЧЕНО.

### 1.2. Простір S₀

**Означення 1.2 (A2).** S₀ = A × A × A, |S₀| = 64. Стан s = (α, β, γ); 6-бітний код b₁b₂b₃b₄b₅b₆, де b₁b₂ — WHO, b₃b₄ — WHERE, b₅b₆ — WHEN:

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3).** code6 — бієкція S₀ → {0, …, 63}. DP: це двійковий запис числа з шести бітів.

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = WE/SOUTH/SUMMER = 63; 010001 = YOU/NORTH/AUTUMN = 17. Гексаграмний запис (Додаток А) — лише індексація; традиційне тлумачення гексаграм не є аксіомою SUBIT. SUBIT-64 не містить оператора переходу і не визначає траєкторій.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** ℛ_fin — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан ŝ = (s, ρ) ∈ S₀ × ℛ_fin. Метаеволюція g₀ : ℛ_fin × S₀ → ℛ_fin. Оператор еволюції:

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** У базовій детермінованій моделі D₀ — тотальна функція. Якщо реалізація допускає невизначені переходи, помилки чи переривання за ресурсом, їх подають у окремому шарі обчислювального статусу (§11.7), а не мовчки трактують як тотальну.

Рівні опису: 0 — стан s; 1 — розширений стан ŝ; 2 — крок D₀(ŝ); 3 — метаеволюція g₀(ρ, s).

**Твердження 2.3 (E1, еквівалентність автомату).** (S₀ × ℛ_fin, D₀) — автономний детермінований скінченний автомат з 64·|ℛ_fin| станами без входу. Теза «правило належить стану» — зміна представлення, а не сильніша виразність. DP (означення). Сильніша теза про самореферентну перевагу — ВІДКРИТО: потрібен додатковий механізм (необмежена пам'ять, зовнішній вхід).

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ), |Q| ≤ 64, вкладається в SUBIT⁺. DP: оберіть ін'єкцію ι : Q → S₀; нехай ℛ_fin = {ρ}, де ρ(ι(q)) := ι(δ(q)) на образі ι і ρ(s) := s поза ним; g₀(ρ, s) := ρ. Індукцією за n: ι⁻¹(ρⁿ(ι(q₀))) = δⁿ(q₀). ВІДКЛИКАНО: універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT із λ-інтерпретатором. Відкриті: Q7, Q22 (|Q| > 64).

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень — Ω_point^fin

**Означення 3.1.1.** τ(ŝ₀) = (ŝ₀, ŝ₁, …), ŝₙ₊₁ = D₀(ŝₙ). Область `Ω_point^fin` — `Q₀ := S₀ × ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

**Означення 3.1.2 (Ω_point^fin).**

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | 1 ≤ m < ∞ (уключно з p = 1: «зрештою нерухома») |

Назви PREPERIODIC і EVENTUALLY_PERIODIC означають один клас; в формальному тексті вживається PREPERIODIC. TRANSIENT — лише неформальний синонім.

**Твердження 3.1.3 (P1, скінченна періодичність).** У Q₀ для кожного ŝ виконується m(ŝ) < ∞. DP: принцип Діріхле.

**Твердження 3.1.4 (P2, розбиття).** Три класи попарно не перетинаються й вичерпують Q₀. DP.

**Твердження 3.1.5 (P3, алгоритм).** Нехай N\_max ≥ |Q₀|. Алгоритм нижче завжди зупиняється на першому повторенні й повертає саме m(ŝ), p(ŝ).

```text
Вхід: ŝ₀, N_max          Вихід: (category, m, p, attractor_cycle) або RESOURCE_EXCEEDED
visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m;  attractor_cycle ← [ŝ_m, …, ŝ_{n−1}]
        category ← FIXED               якщо m = 0 і p = 1
                    PERIODIC(p)         якщо m = 0 і p ≥ 2
                    PREPERIODIC(m, p)   якщо m ≥ 1
        повернути
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
повернути RESOURCE_EXCEEDED
```

Приклад: D₀(a) = b, D₀(b) = b. Для ŝ₀ = a: m = 1, p = 1, PREPERIODIC(1, 1), attractor = [b]. Для ŝ₀ = b: FIXED.

### 3.2. Нескінченний рівень — Ω_point^∞

**Означення 3.2.1.** Область `Ω_point^∞` — `S_∞ × R` за припущення (H) (§10). Для ŝ ∈ S_∞ × R: m(ŝ), p(ŝ) визначені так само, як у §3.1, з D∞ замість D₀ (дозволяючи m = ∞, p = ∞).

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞ |
| APERIODIC | m = ∞ |

**Твердження 3.2.2.** Чотири класи попарно не перетинаються й вичерпують S_∞ × R. DP.

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза `Q₀` — CE-11-R2.3.

## 4. Класифікація множин Classify⁺

У §4–§5 X — S₀ × ℛ_fin або S_∞ × R (§10); P ⊆ X — **непорожня** множина; D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

**Означення 4.1.1.**

```text
μ(P)    := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }           (∞ якщо немає)
π(P)    := min{ n − μ(P) : n > μ(P), Dⁿ[P] = D^{μ(P)}[P] }  (для μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                         (∞ якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT\_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT\_DYNAMIC | D[P] = P і є x ∈ P: D(x) ≠ x |
| PERIODIC\_SET(p) | D[P] ≠ P, μ(P) = 0, p = p\_set(P) ≥ 2 |
| EVENTUALLY\_FIXED(μ) | μ(P) ≥ 1, π(P) = 1 |
| EVENTUALLY\_PERIODIC(μ, π) | μ(P) ≥ 1, π(P) ≥ 2 |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.2 (C1, розбиття).** Шість класів попарно не перетинаються й вичерпують усі непорожні P. DP.

Увага: скінченна P у нескінченному X може бути APERIODIC (D(n) = n + 1, P = {0}).

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  інакше
```

**Твердження 4.2.1 (C2).** П'ять класів попарно не перетинаються; усі непорожні P розбиті. DP.

### 4.3. ChaosStatus — тризначний статус

**Означення 4.3.1.** Для непорожньої P ⊆ X:

```text
ChaosStatus_D(P) ∈ { NOT_APPLICABLE, NON_CHAOTIC, CHAOTIC }

NOT_APPLICABLE — якщо не виконано топологічних передумов:
                 P компактна ∧ D[P] = P ∧ D|_P неперервне

CHAOTIC        — якщо передумови виконані ∧ P мінімальна ∧ h_top(D|_P) > 0

NON_CHAOTIC    — якщо передумови виконані, але CHAOTIC не виконується
```

Тут **мінімальність** означає відсутність власної непорожньої замкненої D-інваріантної підмножини. Це означення не застосовується до множин, для яких топологічна структура або неперервність динаміки не задані.

**Твердження 4.3.2.** `Classify⁺` є тотальним на непорожніх підмножинах для фіксованої динаміки D. Для порожньої множини класифікатор не застосовується.

### 4.4. Розмежування трьох CHAOTIC

**Означення 4.4.1.** Назва `CHAOTIC` у трьох різних контекстах означає різні об'єкти:

- `CHAOTIC_set(P)` — нижній елемент Ω-ланцюга (§5.1), структурний клас множин;
- `CHAOTIC_ω(τ)` — клас траєкторії (§11.1) з ω нескінченною мінімальною і h_top > 0;
- `Chaos_D(P)` — предикат хаотичності компактної інваріантної множини (§4.3).

Наявність однакової інтуїтивної назви не створює імплікації між цими трьома поняттями.

### 4.5. Classify⁺

**Означення 4.5.1.**

```text
Classify⁺(P) := (OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P))
```

Усі три компоненти відносні до однієї динаміки D.

**Твердження 4.5.2 (C3, незалежність складових).** Складові Classify⁺(P) **не незалежні**:

- (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC};
- (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT\_DYNAMIC.

DP: (a) — з означень. (b): CHAOTIC дає D[P] = P, тобто клас ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. Якби було INVARIANT\_FIXED, кожен синглетон — замкнена інваріантна підмножина; мінімальність дає |P| = 1 і h_top = 0, суперечність.

**Твердження 4.5.3 (C7).** У скінченному X хаотичних множин немає. DP.

**Твердження 4.5.4 (C4).** (а) Якщо P скінченна й D[P] = P, то D|\_P — бієкція, і кожна точка P — FIXED або PERIODIC. (б) Для нескінченної P це хибне: контрприклад у `S_∞ × R` — одометр (§11.6).

## 5. Алгебра Ω і проєкція π\_Ω

**Означення 5.1 (6-ланцюг).** Ω з порядком від найменшого до найбільшого:

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (π\_Ω).** π\_Ω : D\_class → Ω, D\_class := {Classify⁺(P)}:

```text
π_Ω(O, I, C) :=
   CHAOTIC_set             якщо C = CHAOTIC
   APERIODIC_NON_CHAOTIC   якщо O = APERIODIC і C ≠ CHAOTIC
   EVENTUALLY_PERIODIC     якщо O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC} і C ≠ CHAOTIC
   PERIODIC_SET            якщо O = PERIODIC_SET і C ≠ CHAOTIC
   INVARIANT_DYNAMIC       якщо O = INVARIANT_DYNAMIC і C ≠ CHAOTIC
   INVARIANT_FIXED         якщо O = INVARIANT_FIXED і C ≠ CHAOTIC
```

Клас Ω\_set вважається **образом** π\_Ω — тобто Ω\_set = π\_Ω ∘ Classify⁺.

**Твердження 5.3 (C5).** π\_Ω тотальна на D\_class, втратна і має образом увесь Ω. DP.

**Означення 5.4 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b, ¬a := a → ⊥ (⊥ = CHAOTIC\_set, ⊤ = INVARIANT\_FIXED).

**Твердження 5.5 (C6).** Це алгебра Гейтінга; виключене третє не виконується. DP.

**Застереження 5.6.** Ω — синтаксичний інструмент; вона не класифікує об'єкти SUBIT і не пов'язана формально з білаттисом Белнапа. Знак ¬ тут лише алгебраїчний: ¬x = CHAOTIC\_set для будь-якого x ≠ CHAOTIC\_set.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

**Означення 6.1.1.** Для ŝ ∈ X, A ⊆ X:

```text
ŝ ⊨ X A    ⇔  F(ŝ) ∈ A                 (наступний крок)
ŝ ⊨ ◇ A    ⇔  ∃n ≥ 0: Fⁿ(ŝ) ∈ A       (колись)
ŝ ⊨ ◇⁺ A   ⇔  ∃n ≥ 1: Fⁿ(ŝ) ∈ A       (колись у майбутньому)
ŝ ⊨ □ A    ⇔  ∀n ≥ 0: Fⁿ(ŝ) ∈ A       (завжди)
ŝ ⊨ ↺ A    ⇔  ∃k > 1: Fᵏ(ŝ) ∈ A       (на кроці k > 1)
```

**Увага.** ↺ A означає лише «на деякому кроці k > 1 стан у A». Це не «повернення в той самий стан». Оператор X — примітивний і не ототожнюється з ↺. Відкликаний оператор ◯ в цій редакції не вживається.

**Твердження 6.1.2 (M1, аксіоми).**

```text
(X1) X A → ◇⁺ A                 (X2) X A ∧ X B ↔ X(A ∧ B)
(X3) X A ∨ X B ↔ X(A ∨ B)      (D1) ◇A ↔ A ∨ X ◇A
(D2) ◇⁺ A ↔ X ◇A                 (D3) ◇A ↔ A ∨ ◇⁺ A
(B1) □A ↔ A ∧ X □A               (B2) □A → A
(B3) □A → X □A                  (B4) □A → ◇A
(B5) □(A → B) → (□A → □B)       (R1) ↺A ↔ ◇⁺(X A)
(R2) ↺A → ◇⁺ A                  (M4) ◇A ↔ ¬□¬A
```

DP: кожна — пряма перевірка за означенням 6.1.1.

**Твердження 6.1.3 (M2, M6).** □A → ↺A без додаткових умов. DP: □A дає F²(ŝ) ∈ A, тобто k = 2 > 1.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** Для A : X → Ω: (□\_H A)(ŝ) := ⋀ₙ≥₀ A(Fⁿŝ), (◇\_H A)(ŝ) := ⋁ₙ≥₀ A(Fⁿŝ) у решітці Ω (§5).

**Твердження 6.2.2 (M3, M4 у гейтінговій семантиці не виконується).** Рівність ◇\_H A = ¬\_H □\_H ¬\_H A хибна. Контрмодель: X = {a, b}, F(a) = b, F(b) = b, A(a) = EVENTUALLY\_PERIODIC, A(b) = CHAOTIC\_set. Тоді ¬\_H A(a) = CHAOTIC\_set, ¬\_H A(b) = INVARIANT\_FIXED; □\_H ¬\_H A(a) = CHAOTIC\_set; ¬\_H □\_H ¬\_H A(a) = INVARIANT\_FIXED; але ◇\_H A(a) = EVENTUALLY\_PERIODIC. DP.

§6.1 описує траєкторії, §6.2 — алгебраїчні значення. Питання про M4 як про властивість самого SUBIT — Q6, відкрите. Несуперечність усієї модальної системи разом із Ω — Q9, відкрите.

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : A @ τ. Правила:

```text
Рефлексивність:  Γ, x:A@τ ⊢ x : A@τ
Еволюція:        Γ ⊢ t:A@τ    D[A] ⊆ B   ⇒   Γ ⊢ D(t) : B@(τ+1)
Стабільність:     Γ ⊢ t:A@τ    D[A] = A     ⇒   Γ ⊢ t : □A@τ
Потенційність:    Γ ⊢ t:A@τ    ∃k: Dᵏ[A] ⊆ B   ⇒   Γ ⊢ t : ◇B@τ
```

Статус: схема ВИЗНАЧЕНА; метатеорія збереження й повноти — НЕ ПІДТВЕРДЖЕНО.

### 6.4. Предикати префікса

Для предиката φ(k, τ):

```text
PH_φ(N) := ∀k ≤ N: φ(k, τ)        (Prefix-Hereditary)
EP_φ(N) := ∃k ≤ N: φ(k, τ)        (Extension-Preserving)
PP_φ(k) := φ(k, τ)                 (Pointwise)
GP_φ(τ)                            (Global — властивість усієї траєкторії)
```

**Правила перенесення:**
`PH_φ(N+1) ⟹ PH_φ(N)`;
`EP_φ(N) ⟹ EP_φ(N+1)`;
`PH_φ(N) ⟹ EP_φ(N)` для `N ≥ 0`.

Жодних автоматичних імплікацій між PP і GP не встановлюється. Символ `Ψ` зарезервовано виключно для оператора продуктивності (§9.2).

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g), де S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. Оператор визначено за об'єктом: D\_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ), φ\_S : S\_X → S\_Y, φ\_ℛ : ℛ\_X → ℛ\_Y, з умовою динамічної сумісності:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))     для всіх ρ ∈ ℛ_X, s ∈ S_X
```

**Застереження 7.3.** Це рівно умова на S-компоненту D; компонента g до умови не входить. Наслідок: два об'єкти з однаковими (S, ℛ) і різними g ізоморфні в SUBIT (тотожний морфізм).

**Означення 7.4 (SUBIT\_full).** Широка підкатегорія; морфізми додатково задовольняють

```text
φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s))
```

**Твердження 7.5 (K1).** SUBIT і SUBIT\_full — категорії. DP.

**Твердження 7.6 (K2, термінальний об'єкт).** 1 = ({∗}, {id}, g\_triv), g\_triv(id, ∗) = id — термінальний в обох. DP.

**Твердження 7.7 (K3, добуток — типізований).** Для об'єктів X, Y з непорожніми S\_X, S\_Y визначимо:

```text
ρ ⊠ σ : S_X × S_Y → S_X × S_Y
(ρ ⊠ σ)(x, y) := (ρ(x), σ(y))

ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
D_{X×Y}((x, y), ρ ⊠ σ) := ((ρ(x), σ(y)), g_X(ρ, x) ⊠ g_Y(σ, y))
```

X × Y := (S\_X × S\_Y, ℛ\_{X×Y}, g\_{X×Y}). DP: S\_X, S\_Y непорожні, тому ρ ⊠ σ однозначно відновлює ρ і σ; проєкції — морфізми; пара ⟨φ, ψ⟩ — морфізм і єдина з потрібними проєкціями.

**Застереження 7.8.** Якщо категорія має допускати порожні простори станів, не можна покладатися на однозначне відновлення ρ і σ з функції ρ ⊠ σ. Тоді слід перейти до окремого типу кодів правил із функцією обчислення `eval_X : ℛ_X × S_X → S_X`.

**Відкрито.** Декартова замкненість SUBIT і SUBIT\_full — Q1. Ізоморфізм об'єктів SUBIT\_full з різними g — Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — функція з φ∘f = h∘φ.

**Твердження 8.2 (K4, Dyn — топос).** Dyn ≅ Fun(ℕ, Set) — прешейфи на моноїді ℕ; тому це топос. Класифікатор підоб'єктів: Ω\_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞ і «істиною» 0. Підоб'єкт — U ⊆ S з f(U) ⊆ U; час входу χ\_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U} (∞, якщо ніколи). DP.

**Твердження 8.3 (K5, вкладення).** (S, f) ↦ (S, {f}, g) з g(f, s) := f — повне і вірне вкладення Dyn у SUBIT і SUBIT\_full. DP.

**Застереження 8.4.** Топосна структура Dyn не переноситься на SUBIT автоматично. Q2′ (ВІДКРИТО).

## 9. Простір S\_∞ = Tree\_∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, Λ := {None, node} ∪ {leaf(a) : a ∈ A} (|Λ| = 6). Tree\_∞ — множина функцій f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None для i = 1, 2, 3;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None для i = 1, 2, 3;
- (T4) f(σ) = None ⇒ f(σ·τ) = None для всіх τ ∈ Pos.

S\_∞ := Tree\_∞.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree\_∞ з out(f) := inl(a), якщо f(ε) = leaf(a), і out(f) := inr(f₁, f₂, f₃), якщо f(ε) = node, — фінальна коалгебра функтора F\_tree(X) = A ⊔ X³. DP (схема).

**Твердження 9.3 (T2, вкладення S₀).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S\_∞, образ — дерева глибини 1. DP.

**Означення 9.4 (кодування «хребта»).** Фіксуємо три різні літери α, β, η ∈ A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ дерево t(a): t(a)(1ᵏ) = node, t(a)(1ᵏ·2) = leaf(aₖ), t(a)(1ᵏ·3) = leaf(η) для всіх k ≥ 0; інші позиції — за (T2)–(T4). Тоді t(a)₁ = t(σa), де σ — зсув послідовності, і маємо неперервне вкладення Y := {t(a)} ≅ {α, β}^ℕ.

### 9.2. Оператор Ψ

**Означення 9.2.1.** На 𝒫(U\_c), де U\_c — сумісні послідовності скінченних апроксимацій T\_n (див. CE-10i/10j-R1):

```text
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.2.2.** L\_prod = Ψ(L\_prod). DP.

**Твердження 9.2.3 (коалгебраїчний ізоморфізм).** p : Tree\_∞ → L\_prod, p(f) := (d\_n(f))\_n — бієкція з оберненим lim\_tree. DP.

**Застереження 9.2.4.** Символ Ψ використовується **виключно** для оператора продуктивності на 𝒫(U\_c). Для глобального предиката траєкторії вживається `GP_φ(τ)` (§6.4).

### 9.3. Метрика d\_S

**Означення 9.3.1.** r(f, g) := min{ |σ| : f(σ) ≠ g(σ) } (∞, якщо f = g); d\_S(f, g) := 2^{−r(f, g)} (і 0, якщо f = g).

**Твердження 9.3.2 (T3, ультраметрика).** d\_S — ультраметрика на Tree\_∞. DP.

**Твердження 9.3.3 (T4, оцінка піддерев).** d\_S(f\_i, g\_i) ≤ 2·d\_S(f, g) для всіх f, g з вузловими коренями. DP.

**Твердження 9.3.4 (T5, повнота й компактність).** (Tree\_∞, d\_S) компактний, а значить повний і цілком обмежений. DP (прямий довід, без оберненої границі; метрика d\_S — стандартна метрика добутку топології на Λ^Pos; T1–T4 задають замкнену підмножину).

**Твердження 9.3.5 (лема адресного доступу — R2.6.1).** Нехай f ∈ Tree\_∞, σ ∈ Pos, n > |σ|. Тоді виконується рівно один із випадків:

- якщо f(σ) = leaf(a), то `at_n(d_n(f), σ) = Some((n−|σ|, Leaf_{n−|σ|}(a)))`;
- якщо f(σ) = node, то `at_n(d_n(f), σ)` має кореневий конструктор `Node_{n−|σ|−1}(v₁, v₂, v₃)`;
- якщо f(σ) = None, то `at_n(d_n(f), σ) = None`.

DP: індукція за |σ| з використанням комутації d\_n з безпосереднім піддеревом; для випадку `None` — за найкоротшим префіксом, на якому шлях недосяжний.

**Твердження 9.3.6 (перша тотожність реконструкції — поправлено).** `lim_tree(p(f)) = f` для всіх f ∈ Tree\_∞. Доведення — за довільною адресою σ через лему 9.3.5. Не використовує другої тотожності.

**Твердження 9.3.7 (друга тотожність).** `p(lim_tree(t)) = t` для всіх t ∈ L\_prod. DP: індукція за n з універсальною гіпотезою; у вузловому випадку — через комутацію `lim_tree` з піддеревами.

**Зауваження 9.3.8.** Ізольовані точки Tree\_∞ — рівно скінченні дерева. S\_∞ не є канторівським простором: він нульвимірний компакт з перфектною частиною (нескінченні дерева, див. Y) і деякими ізольованими точками. Застаріла «обернена границя T\_n» не використовується.

## 10. Правила ℛ₀, припущення (H) і метрики

### 10.1. Причинні правила

**Означення 10.1.** ℛ₀ := { f : S\_∞ → S\_∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) для всіх s, t } — 1-ліпшицеві (причинні) функції. Метрика: d\_ℛ(ρ, σ) := sup\_s d\_S(ρ(s), σ(s)).

**Твердження 10.2 (T5′, причинність як незалежність від майбутнього).** f ∈ ℛ₀ ⇔ для всіх n: якщо s і t збігаються на глибині < n, то f(s) і f(t) збігаються на глибині < n. DP.

**Твердження 10.3 (T6, компактність ℛ₀).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. DP: за Арцела–Асколі, всі функції з ℛ₀ однаково 1-ліпшицеві.

**Твердження 10.4 (T9, потужності).** |ℛ₀| = 2^ℵ₀. DP: константи дають ≥; неперервні функції на сепарабельному просторі визначаються зліченною щільною множиною. |ℛ₁| = ℵ₀ за припущення (модель обчислень — частина означення).

### 10.2. Розширений простір і припущення (H)

**Припущення (H).** R ⊆ ℛ₀ — непорожна замкнена (а значить компактна) множина правил, і g∞ : R × S\_∞ → R неперервна. Розширений простір X := S\_∞ × R з d̂((s, ρ), (t, σ)) := max(d\_S(s, t), d\_ℛ(ρ, σ)); D∞(s, ρ) := (ρ(s), g∞(ρ, s)). Умова g∞(ρ, s) ∈ R вбудована в (H). У скінченному SUBIT⁺ (H) тривіальне.

**Твердження 10.5 (T7, неперервність D∞).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)). Отже при (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. DP.

### 10.3. Метрики на розширеному просторі

**Твердження 10.6 (T8, d\_finite).** При (H) визначено d\_finite(x, y) := sup\_{n ≥ 0} 2^{−n}·d̂(D∞ⁿ(x), D∞ⁿ(y)). Вона — ультраметрика на X, що задає ту саму топологію, що й d̂. DP.

**Означення 10.7 (метрика Хаусдорфа).** Для непорожніх компактних P, Q ⊆ S\_∞:

```text
d_H(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d_S(p, q),
                  sup_{q∈Q} inf_{p∈P} d_S(p, q) }
```

**Означення 10.8 (асимптотична метрика).** Для ŝ, t̂ ∈ S\_∞ × R з непорожніми компактними ω-границями: d\_ω(ŝ, t̂) := d\_H(ω(ŝ), ω(t̂)). Це псевдометрика; метрика — на факторі за ω(ŝ) = ω(t̂).

**Застереження 10.9.** Правила з ℛ₁, які не неперервні (і не входять у ℛ₀), у рамки (H) не потрапляють: для них ω-границі й класифікація §11 не визначені.

## 11. Класифікація траєкторій P(τ)

У цьому розділі всюди припускається гіпотеза (H): R ⊆ ℛ₀ замкнена, g∞ неперервна, тож D∞ неперервне на компактному ультраметричному просторі X = S\_∞ × R. Без (H) твердження D1–D6 мають статус УМОВНО.

### 11.1. ω-границя і класи S(τ)

**Означення 11.1.1 (мінімальність).** Непорожня компактна F-інваріантна множина M ⊆ X називається **мінімальною**, якщо вона не містить власної непорожньої замкненої F-інваріантної підмножини.

**Означення 11.1.2 (класи S(τ)).** Для траєкторії τ з ω = ω(τ):

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω = {p}, F(p) = p |
| PERIODIC | ω скінченна, \|ω\| > 1 |
| MINIMAL\_ZERO\_ENTROPY | ω нескінченна, мінімальна, h\_top(F\|ω) = 0 |
| CHAOTIC\_ω | ω нескінченна, мінімальна, h\_top(F\|ω) > 0 |
| NON\_MINIMAL | ω нескінченна, не мінімальна |

`QUASI_PERIODIC_MINIMAL` — не окремий клас, а **підклас** `MINIMAL_ZERO_ENTROPY`: ω мінімальна, h\_top(F\|ω) = 0, і F\|ω є мінімальною еквінеперервною динамікою.

**Твердження 11.1.3 (D1).** За (H) ω(τ) непорожня, компактна і F(ω(τ)) = ω(τ). DP.

**Означення 11.1.4 (Att).** ATTAINED, якщо τ потрапляє в ω(τ) за скінченний час (∃n: x\_n ∈ ω(τ)). ASYMPTOTIC := ¬ATTAINED. Це **D2**: дві взаємовиключні позначки, без третього значення.

**Твердження 11.1.5 (D6, вичерпність S(τ)).** За (H) п'ять класів `FIXED`, `PERIODIC`, `MINIMAL_ZERO_ENTROPY`, `CHAOTIC_ω`, `NON_MINIMAL` попарно не перетинаються й вичерпують усі траєкторії.

**Доведення.** За D1 ω непорожня, компактна і F(ω) = ω.

1. Якщо ω скінченна, то F|ω — перестановка скінченної множини, отже ω є об'єднанням циклів. Тому або ω = {p} з F(p) = p — `FIXED`, або |ω| > 1 — `PERIODIC`.

2. Якщо ω нескінченна, за лемою Цорна існує непорожня мінімальна компактна F-інваріантна M ⊆ ω.

   - Якщо M = ω, то ω мінімальна. Тоді h\_top(F|ω) або 0, або > 0. Це дає `MINIMAL_ZERO_ENTROPY` або `CHAOTIC_ω`.
   - Якщо M ⊊ ω, то ω не мінімальна, тобто `NON_MINIMAL`.

Взаємовиключність випливає з умов на ω та h\_top. ∎ **DP** за (H) і лемою Цорна.

### 11.2. Ентропія

`CHAOTIC_ω` означає h\_top(F|\_ω) > 0 і ніяк інакше.

- **D3.** Якщо F на ω(τ) нерозтягувальне (d(Fx, Fy) ≤ d(x, y)), то h\_top(F|\_ω) = 0. DP.
- **D4 (мій результат).** Якщо g∞ ≡ id, то D∞(s, ρ) = (ρ(s), ρ) нерозтягувальне, отже h\_top = 0 і CHAOTIC\_ω неможливий. DP. Застереження: твердження «за g∞ ≡ id клас NON\_MINIMAL порожній» спирається на теорему типу Едельштейна; без явної перевірки умов вона подається як ВІДКРИТО.
- **D3′ (R2.7.1).** Для ρ ∈ ℛ\_caus і підпростору K\_ρ := S\_∞ × {ρ}, якщо g∞(ρ, s) = ρ, то D∞|\_{K\_ρ} ізоморфне ρ, і h\_top(D∞|\_{ω\_{D∞}(s,ρ)}) = 0.

### 11.3. Метрика d\_Ω\_traj

Ω\_traj складається з 10 допустимих пар (S, Att). На Ω\_traj задається d\_Ω\_traj як довжина найкоротшого шляху в графі переходів «відмова від сертифікату»: сусідні пари відрізняються однією ознакою (клас S або Att). Це метрика на скінченній множині; її роль суто діагностична, в Ω-логіці не використовується.

### 11.4. Вироджена реалізація CHAOTIC\_ω × ATTAINED (D5)

Нехай g∞ ≠ id. Візьмемо мінімальний підзсув Y додатної ентропії (існує за відомою теоремою) і правила-константи ρ\_c, які на кожному кроці ігнорують s і повертають c. Метаеволюція g∞(ρ\_c, c) := ρ\_{σ(c)}. Побудований за ними D∞ має ω(τ), ізоморфну (Y, σ), тому h\_top > 0, а траєкторія стартує у Y, тобто ATTAINED. Це **D5**: пара CHAOTIC\_ω × ATTAINED реалізується, але вироджено. Статус: УМОВНО.

### 11.5. Таблиця реалізовності

| S(τ) | ATTAINED | ASYMPTOTIC |
| :-- | :-- | :-- |
| FIXED | так | так |
| PERIODIC | так | так |
| MINIMAL\_ZERO\_ENTROPY | так (одометр; QUASI\_PERIODIC\_MINIMAL — підклас) | так |
| CHAOTIC\_ω | лише вироджено (D5) | так (ВІДКРИТО щодо невироджених) |

**Застереження 11.5.1.** Ω\_traj має десять номінальних пар значень, оскільки |S| = 5 і |Att| = 2. **Реалізовність усіх десяти комбінацій траєкторій не доведена.** Усі твердження про фактичну реалізацію конкретної пари потребують прикладу або окремого доказу.

### 11.6. Одометр: контрприклад і приклад

- **Контрприклад до твердження про скінченну періодичність у S\_∞ × ℛ₀.** Одометр (ℤ₂, +1) вкладається у S\_∞ × ℛ₀ як мінімальна підсистема без періодичних точок. Отже, твердження «кожна ω-границя скінченно-періодична» хибне. Закрито питання Q23 і Q28 частково.
- **Приклад MINIMAL\_ZERO\_ENTROPY.** Той самий одометр дає клас MINIMAL\_ZERO\_ENTROPY: мінімальний, нескінченний, h\_top = 0.

Статус обох результатів: DP.

### 11.7. Рівні сертифікації

Кожне виконання класифікації повертає одне з двох значень: COMPUTED (повний результат з указаним рівнем сертифікату) або RESOURCE\_EXCEEDED (обчислення перервано за бюджетом, результат не є класифікацією). Рівні сертифікату:

1. **L0.** Скінченна орбіта в S₀, перевірена обходом (повний доказ).
2. **L1.** Періодичність у розширеному стані (s, ρ), перевірена за скінченну кількість кроків.
3. **L2.** Верхня оцінка ентропії за нерозтягувальністю (D3/D4).
4. **L3.** Лише емпірична оцінка за обмеженим горизонтом (не доказ; позначається РЕЗУЛЬТАТ БЕЗ СЕРТИФІКАТУ).
