## Ключові результати v6.14.4

### ALT-12: епістемічна версія рамки $\mathbb{F}$

8 відношень видимості осей $R_S$ ($S \subseteq \{w,e,n\}$); $R_S\cap R_T = R_{S\cap T}$, $R_S\circ R_T = R_{S\cup T}$.

| Що | Формула / значення |
| :-- | :-- |
| Розподілене знання | $D = R_{\bigcap_a S_a}$ |
| Загальне знання | $C = R_{\bigcup_a S_a}$ |
| Ієрархія | $\Box^D\varphi \to \Box_a\varphi \to \Box^C\varphi$ валідне |
| Рівність $D=C$ | Рівно при збігу всіх $S_a$ (8 із 4096 призначень) |
| Розподіл $|D|$ | $\{1{:}1,\ 4{:}45,\ 16{:}675,\ 64{:}3375\}$ (для $C$ — дзеркально) |

Канонічна модельна пропозиція:

| Агент | Невидима вісь | $R_a$ | Класів |
| :-- | :-- | :-- | --: |
| ME | — | identity | 64 |
| WE | w | $R_{\{w\}}$ | 16 |
| YOU | e | $R_{\{e\}}$ | 16 |
| THEY | n | $R_{\{n\}}$ | 16 |

$D = $ identity; $C = $ universal; $\{\mathrm{WE},\mathrm{YOU},\mathrm{THEY}\}$ самі дають $D =$ identity.

Бісимуляційні класи 4-агентної рамки: $1 \to 2 \to 8 \to 64$ (без атомів, $+\{w{=}0\}$, $+3$ атоми, $+12$ атомів), тобто $2, 4, 256, 2^{64}$ визначних множин.
