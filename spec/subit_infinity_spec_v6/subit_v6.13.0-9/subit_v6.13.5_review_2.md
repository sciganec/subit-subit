## Lean-формалізація

Усі файли без `sorry`. Аксіоми позначено за `#print axioms`.

- `Subit/IsoFull.lean` (standalone, лише ядро Lean): `mor_conj`, `iso_conj`, `isoXY`, `g_differ`. Аксіоми не залежать.
- `Subit/DensityComp.lean` (standalone, довільні Nat → Bool, префіксна причинність): `approx_causal`, `approx_finDep`, `density`. Аксіоми: propext, Quot.sound.
- `Subit/DensityTree.lean` (поверх `Subit.DSExact`): `tr_isTree` (обрізання зберігає T1–T4), `Gap_nonexp`, `Gap_finDep`, `Gap_close`, `density_tree`. Аксіоми: propext, Classical.choice, Quot.sound. Потрібне A ≠ ∅ (елемент a₀).
- `Subit/A4.lean`: `A4_general` (теги в базі 64, відрізняються функції).

**Не формалізовано:** лема 11.9 (продовження в ультраметриці); T6; опис ℛ\_comp як скінчної таблиці (у Lean лише скінчна залежність); символ `ℕ` у standalone-файлах замінено на `Nat`, бо Mathlib тут не потрібен.

## Rust-перевірки

Крейт `subit`, 57 тестів, `cargo clippy --all-targets` без попереджень. Ці тести написані тим самим автором, тому вони не є незалежним доведенням.

- `conj.rs`: спряження для 7.8 (вичерпно для |S|, |ℛ| ≤ 2); приклад Q19; скінченний аналог Q28b для перестановок n ≤ 4.
- `w8.rs`: перевірка оцінки p\_d(N) ≤ 2(2N+1)(N+2)(N+3) на префіксі довжини 2¹⁵, N ≤ 100. Це не доведення.
- Залишені модулі (`finite`, `orbit`, `minimal`, `subobj`, `plus`, `inf::*`) перевіряють скінчний рівень і точні об'єкти нескінчного рівня, без загального випадку (див. README крейту).

## Передумови й залежності

- **H1:** (S∞, d\_S) — компактний ультраметричний простір (T3, T5). Виключено в Lean.
- **H2:** R ⊆ ℛ₀ непорожній компактний. Для R = ℛ₀ виводиться з T6 (v6.13.2, DP-f, відведення із замкненістю та діагональним вибором). Для інших R компактність залишається передумовою.
- **H3:** g∞ неперервна і тотальна. В Lean перевіряється для конкретних побудов (Gap, константні правила у Q28b).
- **Виведення:** Q28b (11.11) без передумови H2 для повного ℛ₀ — за T6 і лемою 11.9. Сама лема 11.9 доведена лише ескізом на папері — це найбільш ризикований пункт для рецензії.

## Рішення для рецензента

1. **W8 (Q10″):** чи є підрахунок p\_d(N) = O(N³) повним і чи статус DP-f на папері виправданий. Умова: n\_k строго зростають.
2. **Q28b (11.11):** чи коректна конструкція g∞(ρ, s) = κ\_{T′(p(ρ))} і чи припустиме це лема 11.9 на відкритій або замкненій з аргументами.
3. **Лема 11.9:** чи довіднізація в Lean потрібна до захисту до випуску (зараз статус DP-f, ескіз).
4. **Відкриті пункти етапу 4:** CHAOTIC ⇔ h\_top > 0 для нескінченних систем; D4 при g∞ = π\_R; Ω\_point поза Q₀. Тепер відкриті не закриті і потребують моделі нескінчного рівня.
5. **Статус специфікації:** підтвердити LEAN-CHECKED для 7.8 і 10.10 (тільки формальна частина) або залишити частковою.
