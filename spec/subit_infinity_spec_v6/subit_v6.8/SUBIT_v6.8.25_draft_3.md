# Частина I. SUBIT-64 — скінченний алфавіт станів

## 1. Алфавіт примітивів

**Означення 1.1.** Базовий алфавіт:

```
A = {00, 01, 10, 11},   |A| = 4
```

Дві рівноправні інтерпретації:

**Семантична:** WHO = {ME, WE, YOU, THEY}, WHERE = {EAST, SOUTH, WEST, NORTH}, WHEN = {SPRING, SUMMER, AUTUMN, WINTER}.

**Логічна (чотиризначний алфавіт Белнапа):** `𝔸 = {T, F, B, N}`.

**Відповідність кодів:**

| Код | Логічна | Семантична мітка |
|:---|:---|:---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Означення 1.2 (білаттисна структура).** Порядок істинності: F ≤ₜ N ≤ₜ T; F ≤ₜ B ≤ₜ T. Порядок інформації: N ≤ᵢ F ≤ᵢ B; N ≤ᵢ T ≤ᵢ B.

Властивості білаттиса **не переносяться автоматично** на динаміку `S_∞`.

## 2. Простір станів S₀

**Означення 2.1.**

```
S₀ = A × A × A,   |S₀| = 4³ = 64
```

Кожен стан `s = (α, β, γ)` кодується 6 бітами: `b₁b₂` = WHO, `b₃b₄` = WHERE, `b₅b₆` = WHEN.

**Статус:** 64 стани визначені. SUBIT-64 не містить оператора переходу, не визначає траєкторій.

**Гексаграмна нотація** (Додаток A) — додаткова система індексації; традиційна символіка І-Цзін не є аксіомою SUBIT.

# Частина II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.**

```
ℛ = {ρ₁, …, ρₙ},   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширений стан: `ŝ = (s, ρ) ∈ S₀ × ℛ`.

**Застереження 3.3.** SUBIT⁺ із фіксованим скінченним простором еквівалентний автономному детермінованому скінченному автомату з `|Q| = |S₀ × ℛ|`. «Правило належить стану» — структурна зміна представлення, а не доказ сильнішої виразності.

## 4. Оператор еволюції та метаеволюція

**Означення 4.1.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = (f_ρ(s), g(ρ, s))
```

**Аксіома 4.2 (тотальність).** У базовій детермінованій моделі `F` — тотальна.

Часткові оператори, помилки виконання, ресурсне переривання — окремий шар обчислювального статусу, не змішується з `F`.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** `τ(ŝ₀) = (ŝ₀, ŝ₁, …)`, `ŝₙ₊₁ = F(ŝₙ)`.

### 5.1. Скінченна періодичність

**Твердження 5.1.1.** Для кожного `ŝ₀` існують `m ≥ 0, k ≥ 1`: `ŝ_{m+k} = ŝ_m`.

**PROVED ON PAPER** (принцип Діріхле).

### 5.2. Точкова категорія

**Означення 5.2.1.**

```
Ω_point(ŝ) :=
   FIXED          якщо F(ŝ) = ŝ
   PERIODIC(p)    якщо p := min{ k > 1 : Fᵏ(ŝ) = ŝ } існує
   PREPERIODIC    інакше
```

**Застереження 5.2.2 (CE-1).** Клас `PREPERIODIC` (замість `TRANSIENT` у v6.8.24). `TRANSIENT` — неформальний синонім; у формальному означенні не використовується.

**FIXED** і **PERIODIC(p)** взаємовиключні (`p = 1` виключено).

### 5.3. Відкликане ототожнення

**ВІДКЛИКАНО:** ототожнення `PREPERIODIC` із `CHAOTIC`. Передперіодичність — звичайна поведінка скінченного автомата. «Хаотичність» у SUBIT-∞ має окреме визначення через ω-граничну динаміку.

# Частина III. SUBIT-CAT — категорія, класифікатори та логіка

## 6. Три класифікатори

Класифікатори визначені на різних об'єктах. Їх не можна використовувати взаємозамінно.

### 6.1. Класифікатор множин `Ω_set`

**Означення 6.1.1.** Для `P ⊆ S_∞ × ℛ`, `F(P) = {F(x) : x ∈ P}`:

```
STABLE       ⟺ F(P) = P
METASTABLE   ⟺ F(P) ⊊ P
CYCLIC       ⟺ ∃ мінімальне k > 1: Fᵏ(P) = P, і F(P) ≠ P
CHAOTIC      ⟺ F(P) ⊄ P і ∀k > 1: Fᵏ(P) ≠ P
```

**Застереження 6.1.2.** Формула `CHAOTIC` не охоплює випадок `F(P) ⊊ P`, який уже належить `METASTABLE`. Для взаємовиключності визначення застосовуються як **пріоритетний розподіл** (STABLE → METASTABLE → CYCLIC → CHAOTIC).

### 6.2. Точковий класифікатор `Ω_point`

**Означення 6.2.1.** `Ω_point(ŝ) ∈ {FIXED, PERIODIC, PREPERIODIC}`.

`CHAOTIC` **не є** точковим класом.

### 6.3. Зв'язок `Ω_set` і `Ω_point`

**Твердження 6.3.1 (скінченна P).** Якщо `P` скінченна і `F(P) = P`, то `F|_P` — бієкція, отже `∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}`.

**PROVED ON PAPER.**

**Твердження 6.3.2 (нескінченна P).** Для нескінченної `P` на `S_∞` твердження 6.3.1 хибне. Контрприклад: `X = ℤ`, `F(n) = n+1`, `P = ℤ` (не в `S_∞ × ℛ`; для `S_∞ × ℛ` — Q28 ❓).

### 6.4. Класифікатор ω-границь `S(τ)`

**Означення 6.4.1.** П'ять класів (див. §18.6, Частина IV). Класифікація **ω-границь окремих траєкторій**, не довільних інваріантних множин.

## 7. Алгебра Ω

**Означення 7.1 (6-ланцюг, CE-1).**

```
CHAOTIC
  < APERIODIC_NON_CHAOTIC
  < EVENTUALLY_PERIODIC
  < PERIODIC_SET
  < INVARIANT_DYNAMIC
  < INVARIANT_FIXED
```

**Застереження 7.2.** Ω — **синтаксичний** інструмент Ґратінгової алгебри. Не є класифікацією об'єктів SUBIT.

**Твердження 7.3.** Ω із `∧ = min`, `∨ = max`, `→` (релятивне псевдодоповнення), `¬a := a → ⊥` — **алгебра Гейтінга** (логіка Геделя–Даммета).

**PROVED ON PAPER** (будь-який скінченний ланцюг є алгеброю Гейтінга).

**Твердження 7.4.** Виключене третє не виконується:

```
EVENTUALLY_PERIODIC ∨ ¬EVENTUALLY_PERIODIC = EVENTUALLY_PERIODIC ≠ INVARIANT_FIXED
```

**Застереження 7.5.** Ω — самостійна алгебра; не пов'язана формально з білаттисом Белнапа.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).** `X = (S_X, ℛ_X, F_X, g_X)`, де `S_X` — множина, `ℛ_X ⊆ {f : S_X → S_X}`, `F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X`.

**Означення 8.2 (морфізми).** Пара `φ = (φ_S, φ_ℛ)` з умовою динамічної сумісності:

```
φ_S(π_S(F_X(s, ρ))) = π_S(F_Y(φ_S(s), φ_ℛ(ρ)))
```

**Застереження 8.3.** Умова стосується **лише S-компоненти** `F`. Компонента `g_X` не входить до умови.

**Означення 8.4 (SUBIT_full).** Широка підкатегорія SUBIT: ті самі об'єкти; морфізми додатково задовольняють:

```
φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s))
```

**Твердження 8.5.** SUBIT — категорія.

**PROVED ON PAPER.**

**Застереження 8.6.** Експоненціал `Yˣ` визначений лише для об'єктів із оборотним `F_X`. Загальна декартова замкненість — **Q1** (❓).

## 9. Dyn як категорія динамічних систем

**Означення 9.1.** `(S, f)`, `f : S → S`; морфізми: `φ ∘ f = g ∘ φ`.

**Твердження 9.2.** `Dyn ≅ Fun(ℕ, Set)` (категорія множин із дією моноїда ℕ).

**PROVED ON PAPER** (Lawvere 1964).

**Означення 9.3.** `Ω_Dyn = ℕ ∪ {∞}`; дія `n · k := max(n − k, 0)`, `∞ · k := ∞`. `χ_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U}` (∞ якщо ніколи).

**Твердження 9.4.** `χ_U` — морфізм Dyn: `χ_U(f(x)) = max(χ_U(x) − 1, 0)`.

**Твердження 9.5.** `Sub_Dyn(X) ≅ Hom_Dyn(X, Ω_Dyn)` — бієкція.

**PROVED ON PAPER.**

**Твердження 9.6.** Dyn — топос.

**Застереження 9.7.** Топосна структура **Dyn** не переноситься автоматично на повну категорію SUBIT. **Q2'** (❓).

## 10. Динамічна теорія типів

**Судження:** `Γ ⊢ t : A @ τ`.

**Правила:** рефлексивність, еволюція (`F(A) ⊆ B → F(t) : B @ (τ+1)`), стабільність (`F(A) = A → t : □A @ τ`), потенційність (`∃k: Fᵏ(A) ⊆ B → t : ◇B @ τ`).

**Статус:** схема визначена; повна метатеорія збереження та повноти не підтверджена.

## 11. Модальна логіка

### 11.A. LTL-подібна семантика

**Означення 11.A.1.**

```
ŝ ⊨ X A   ⟺  F(ŝ) ∈ A
ŝ ⊨ ◇ A   ⟺  ∃n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◇⁺ A  ⟺  ∃n ≥ 1: Fⁿ(ŝ) ∈ A
ŝ ⊨ □ A   ⟺  ∀n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ↺ A   ⟺  ∃k > 1: Fᵏ(ŝ) ∈ A
```

**Застереження 11.A.2.** `X` — примітивний оператор «наступний крок», не ототожнюється з `↺`.

**Твердження 11.A.3 (аксіоми).** `X1–X3, D1–D3, B1–B5, R1–R2, M4` — стандартна LTL.

**Твердження 11.A.4 (M6).** `□A → ↺A` — без додаткових умов.

**PROVED ON PAPER.**

### 11.B. Гейтінгова семантика

**Означення 11.B.1.** `(□_H A)(ŝ) := ⋀_{n ≥ 0} A(Fⁿŝ)`, `(◇_H A)(ŝ) := ⋁_{n ≥ 0} A(Fⁿŝ)`.

**Твердження 11.B.2.** M4_H не виконується (`◇_H A ↔ ¬_H □_H ¬_H A` — хибне).

**PROVED ON PAPER** (загальне порушення класичної дуальності в логіці Геделя–Даммета).

### 11.C. Узгодження

LTL описує траєкторії; Гейтінг — алгебраїчні значення. Не змішуються.

## 12. Межі симуляції

**Твердження 12.1.** Автономний скінченний автомат `(Q, δ)` з `|Q| ≤ 64` вкладається в SUBIT⁺ як одна траєкторія (ін'єкція `ι : Q → S₀`, правило `ρ : S₀ → S₀`, метаеволюція `g ≡ id`).

**PROVED ON PAPER.**

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT із λ-інтерпретатором.

**Q7** (❓): універсальний об'єкт із доведеною властивістю.

# Частина IV. SUBIT-∞ — нескінченний простір рекурсивних дерев

**Примітка.** Ця частина **повністю переписана** в v6.8.25 на основі CE-10i–CE-10j-R4. Ключова зміна: бієкція `S_∞ ≅ L_prod` замість хибної `S_∞ ≅ lim←`.

## 13. Функтор і оператор

**Означення 13.1 (деревний функтор `F`).**

```
F(X) := A ⊔ X³
```

Функтор на категорії множин. `νF` — фінальна коалгебра.

**Означення 13.2 (оператор продуктивності `Ψ`).** На `𝒫(U_c)`:

```
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Застереження 13.3.** `F` і `Ψ` — різних типів. Позначення `Φ` з попередніх редакцій розділено.

## 14. Скінченні апроксимації

**Означення 14.1 (`T_n`).**

```
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) : a ∈ A }
         ∪ { Bottom_{n+1} }
         ∪ { Node_n(t₁, t₂, t₃) : t₁, t₂, t₃ ∈ T_n }
```

**Конвенція:** `Leaf_n`, `Bottom_n` — за рівнем; `Node_n : T_n³ → T_{n+1}` — за рівнем дітей.

**Означення 14.2 (`q_n`).**

```
q_0 : T_1 → T_0
q_0 (Leaf_1 a)          := Leaf_0 a
q_0 (Bottom_1)          := Bottom_0
q_0 (Node_0(t₁,t₂,t₃))  := Bottom_0

q_{n+1} : T_{n+2} → T_{n+1}
q_{n+1} (Leaf_{n+2} a)         := Leaf_{n+1} a
q_{n+1} (Bottom_{n+2})         := Bottom_{n+1}
q_{n+1} (Node_{n+1}(t₁,t₂,t₃)) := Node_n(q_n t₁, q_n t₂, q_n t₃)
```

**Лема 14.3.** `q_n(t) ∈ T_n`.

**PROVED ON PAPER.**

## 15. Сумісні та продуктивні послідовності

**Означення 15.1 (`U_c`).**

```
U_c := { (t_n) ∈ ∏_n T_n : ∀n, q_n(t_{n+1}) = t_n }
```

**Означення 15.2 (`LeafSeqs`, `NodeSeqs`, `Ψ`).**

```
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }

NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0
                ∧ ∃u₁,u₂,u₃ ∈ X
                ∧ ∀n ≥ 0: t_{n+1} = Node_n(u_{1,n}, u_{2,n}, u_{3,n}) }

Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Означення 15.3 (`L_prod`).**

```
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Лема 15.4.** `L_prod = Ψ(L_prod)`.

**PROVED ON PAPER** (CE-10j.0.2.1).

**Лема 15.5 (принцип коіндукції).** Якщо `X ⊆ U_c` і `X ⊆ Ψ(X)`, то `X ⊆ L_prod`.

**Контрприклад.** `L_prod ⊊ U_c`: `(Bottom_n)_n ∈ U_c \ L_prod`.

**Лема 15.6 (розклад).** Кожен `t ∈ L_prod` має або Leaf-, або Node-розклад.

## 16. Адресне кодування `Tree_∞`

**Означення 16.1.** `Pos := {1,2,3}^{<ω}`, `Label := A ⊔ {node}`.

**Означення 16.2 (`Tree_∞`).** Підтип `Pos → Option(Label)` з (T1)–(T4):

- (T1) `f(ε) ≠ None`;
- (T2) `f(σ) = Some(node)` ⟹ `f(σ·i) ≠ None`;
- (T3) `f(σ) = Some(leaf(a))` ⟹ `f(σ·i) = None`;
- (T4) `f(σ) = None` ⟹ `f(σ·τ) = None`.

**Означення 16.3 (`out_Tree`).**

```
out_Tree : Tree_∞ → A ⊔ Tree_∞³
out_Tree(f) := inl(a)            якщо f(ε) = Some(leaf(a))
out_Tree(f) := inr(f₁, f₂, f₃)   якщо f(ε) = Some(node)
```

де `f_i(σ) := f(i·σ)`.

**Лема 16.4 (фінальність).** `(Tree_∞, out_Tree)` — фінальна коалгебра `F`.

**PROVED ON PAPER** (CE-10j-R3 §R3.1).

**Означення 16.5.** `S_∞ := Tree_∞` — канонічний носій.

## 17. Глибинні апроксимації `d_n`

**Означення 17.1 (база).**

- `f(ε) = Some(leaf(a))` → `d_0(f) := Leaf_0(a)`;
- `f(ε) = Some(node)` → `d_0(f) := Bottom_0`.

**Означення 17.2 (крок).**

- `f(ε) = Some(leaf(a))` → `d_{n+1}(f) := Leaf_{n+1}(a)`;
- `f(ε) = Some(node)` → `d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))`.

**Лема 17.3 (типізація).** `d_n(f) ∈ T_n`.

**Лема 17.4 (сумісність).** `q_n(d_{n+1}(f)) = d_n(f)`.

**Лема 17.5 (комутація з піддеревом).** Якщо `f(ε) = Some(node)`, то `d_n(f_i) = (d_{n+1}(f))|_i`.

**PROVED ON PAPER.**

**Означення 17.6 (проєкції).** `p_n : Tree_∞ → T_n`, `p_n(f) := d_n(f)`.

## 18. Стабілізація та `lim_tree`

**Лема 18.1 (стабілізація міток).** Для `t ∈ L_prod` і позиції σ виконується рівно один із трьох випадків:

- **Z (недосяжна):** `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = None`;
- **L (стабільний листок):** `∃N, a: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Some(Leaf_{m-|σ|}(a))`;
- **N (стабільний вузол):** `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Node_{m-|σ|-1}(...)`.

**PROVED ON PAPER** (CE-10j.3.1–3.2).

**Означення 18.2 (`lim_tree`).**

```
lim_tree(t)(σ) := lim_label(t, σ)
```

де `lim_label(t, σ) ∈ {Some(leaf(a)), Some(node), None}` за випадком Z/L/N.

**Лема 18.3 (`Tree_∞`-умови).** `lim_tree(t)` задовольняє (T1)–(T4).

**PROVED ON PAPER** (CE-10j.3.4).

## 19. Метрика `d_S`

**Означення 19.1 (розділення).** `(∀n: d_n(f) = d_n(g)) → f = g`.

**PROVED ON PAPER** (CE-10j-R3 §R3.3).

**Означення 19.2.**

```
r(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }   якщо f ≠ g
d_S(f, g) := 0                                якщо f = g
d_S(f, g) := 2^{−r(f, g)}                     якщо f ≠ g
```

**Лема 19.3 (ультраметрика).** `d_S` — ультраметрика на `Tree_∞`.

**PROVED ON PAPER** (CE-10j-R3 §R3.4).

**Лема 19.4 (оцінка піддерев).** Для `f, g` з вузловими коренями: `d_S(f_i, g_i) ≤ 2 · d_S(f, g)`.

**PROVED ON PAPER** (CE-10j.7.1).

## 20. Бієкція `Tree_∞ ≅ L_prod`

**Означення 20.1.** `p : Tree_∞ → L_prod`, `p(f) := (d_n(f))_n`.

**Лема 20.2 (продуктивність).** `p(f) ∈ L_prod`.

**PROVED ON PAPER** (CE-10j.4.2).

**Означення 20.3 (`out_L`).**

```
out_L : L_prod → A ⊔ L_prod³
out_L(t) := inl(a)               якщо t_n = Leaf_n(a)
out_L(t) := inr(u₁, u₂, u₃)      якщо t_0 = Bottom_0 і t_{n+1} = Node_n(...)
```

**Теорема 20.4 (коалгебраїчний ізоморфізм).** `out_L ∘ p = F(p) ∘ out_Tree`.

**PROVED ON PAPER** (CE-10j-R2 §R2.4.1).

**Теорема 20.5 (перша тотожність).** `lim_tree(p(f)) = f`.

**Теорема 20.6 (друга тотожність).** `p(lim_tree(t)) = t`.

**Теорема 20.7 (бієкція).** `p : Tree_∞ → L_prod` — бієкція.

**PROVED ON PAPER** (CE-10j.6.1–6.3, незалежні доведення).

## 21. Повнота, цілком обмеженість, компактність

## 22. Динаміка та класифікація

**Означення 22.1.** `F : S_∞ × ℛ → S_∞ × ℛ`, `F(s, ρ) = (f_ρ(s), g(ρ, s))`.

**Означення 22.2 (`Fix(F)`).** `{ŝ : F(ŝ) = ŝ}` — **найбільша** множина нерухомих точок. Найменша STABLE-множина — ∅.

**Означення 22.3 (ω-границя).** `ω(ŝ₀) := {x : ∃nₖ → ∞, ŝ_{nₖ} → x}`.

**Означення 22.4 (Att).**

```
ATTAINED    ⟺ ∃n: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC  ⟺ ∀n: ŝₙ ∉ ω(ŝ₀), dist(ŝₙ, ω(ŝ₀)) → 0
```

**Означення 22.5 (S(τ), CE-1).** П'ять класів:

```
FIXED_POINT              ω = {p}, F(p) = p
PERIODIC                 ω скінченна, |ω| > 1
MINIMAL_ZERO_ENTROPY     ω нескінченна, мінімальна, h_top = 0
CHAOTIC                  ω нескінченна, мінімальна, h_top > 0
NON_MINIMAL              ω нескінченна, не мінімальна
```

**Застереження 22.6.** `MINIMAL_CANTOR` з v6.8.24 замінено на `MINIMAL_ZERO_ENTROPY` (CE-1): нескінченна мінімальна ω-границя з `h_top = 0` не обов'язково має топологію Кантора (ірраціональне обертання кола, одометр).

**Означення 22.7 (`Ω_traj`).** `Ω_traj := S(τ) × Att(τ)` — 10 пар.

**Означення 22.8 (Certification, три рівні, CE-8.5).**

```
PREFIX_CERTIFIED(N)          — префікс довжини N
GLOBAL_EXACT_CERTIFIED       — вся траєкторія
APPROXIMATION_CONVERGED(N)   — числовий критерій на горизонті N
```

**Означення 22.9 (COMPUTED / RESOURCE_EXCEEDED).** Окреме поле, не входить в `Ω_traj`.

**Означення 22.10 (CHAOTIC і ℛ₀).** Для `ρ ∈ ℛ₀` з `g ≡ id`: `h_top(ω(ŝ₀)) = 0` (Bowen 1971). Для `g ≠ id` — **Q10** (❓).

**Означення 22.11 (P(τ)).**

```
P(τ) := ( ω(ŝ₀), Ω_traj(τ), certificate )
```

**Означення 22.12 (типологія предикатів префікса, CE-10c.6).**

- **PH** (Prefix-Hereditary): `P(N+1) ⟹ P(N)`;
- **EP** (Extension-Preserving): `P(N) ⟹ P(N+1)`;
- **PP** (Pointwise): `P(k)` для фіксованого `k`;
- **GP** (Global): властивість всієї траєкторії.

Правила перенесення — CE-10c.6.1 (безумовне `PH(N) ⟹ EP(N)`).

## 23. Шість динамічних класів множин

**Означення 23.1 (μ, π, p_set).**

```
μ(P) := min{ m ≥ 0 : ∃n > m: F^m(P) = F^n(P) }    (∞ якщо немає)
π(P) := min{ n − μ(P) : n > μ(P), F^n(P) = F^{μ(P)}(P) }    (∞ якщо μ = ∞)
p_set(P) := min{ k ≥ 1 : F^k(P) = P }    (∞ якщо немає)
```

**Означення 23.2 (шість класів, CE-10e.3.2).**

```
INVARIANT_FIXED(P)        ⟺ F(P) = P ∧ ∀x ∈ P: f(x) = x
INVARIANT_DYNAMIC(P)      ⟺ F(P) = P ∧ ∃x ∈ P: f(x) ≠ x
PERIODIC_SET(P)           ⟺ p_set(P) = p ≥ 2
EVENTUALLY_FIXED(P)       ⟺ μ(P) ≥ 1 ∧ π(P) = 1
EVENTUALLY_PERIODIC(P)    ⟺ μ(P) ≥ 1 ∧ π(P) ≥ 2
APERIODIC(P)              ⟺ μ(P) = ∞
```

**Твердження 23.3.** Шість класів попарно не перетинаються і вичерпують `2^{S_∞ × ℛ} ∖ {∅}`.

**PROVED ON PAPER** (CE-10e.3.4).

## 24. Топологія простору правил `ℛ`

**Означення 24.1 (`ℛ₀`).** Причинні функції: `d_S(f(s), f(t)) ≤ d_S(s, t)`.

**Означення 24.2 (`ℛ₁`).** Функції зі скінченним обчислюваним описом у фіксованій моделі.

**Застереження 24.3.** `ℛ₀` і `ℛ₁` не тотожні. `|ℛ₀| = 2^{ℵ₀}`, `|ℛ₁| = ℵ₀` — **Q25** (❓).

**Твердження 24.4.** `(ℛ₀, d_ℛ)` — компактний гаусдорфовий.

**PROVED ON PAPER** (CE-6.4.6, уточнено CE-10j).

# Частина V. Застосування та методологія

## 25. Епістемологічний статус

**25.1.** Теореми SUBIT — твердження про формальну систему. Не доводять, що фізична, біологічна, соціальна чи психологічна система має ту саму структуру.

**25.2.** Призначення: класифікація станів, представлення переходів, формалізація гіпотез, порівняння правил, аналіз граничної поведінки, сертифікати, розділення невизначеності.

**25.3. Протокол застосування.**

- **Крок 0** — кодування (розбиття неперервних даних в A; аналіз чутливості);
- **Крок 0'** — клас правил (`ℛ₀`/`ℛ₁`; не плутати причинність і обчислюваність);
- **Крок 1** — простір станів;
- **Крок 2** — динаміка (`F`, `f_ρ`, `g` з точними типами);
- **Крок 3** — перевірка умов (тотальність, неперервність, причинність);
- **Крок 4** — обчислення траєкторії;
- **Крок 5** — класифікація (не змішувати `Ω_point`, `Ω_set`, `S`);
- **Крок 6** — валідація (чутливість до кодування).

## 26. Статуси доказовості

**26.1. Обов'язкові поля твердження:** ID, формулювання, область, припущення, статус, посилання на доказ, журнал змін.

**26.2.** Позначка ✅ **не є** математичним обґрунтуванням. «Доведено на папері», «доведено в Lean», «реалізовано», «протестовано» — окремі стани.
