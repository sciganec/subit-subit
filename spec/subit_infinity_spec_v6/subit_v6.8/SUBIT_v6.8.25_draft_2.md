## 1. Структурні означення

### 1.1. Функтор і оператор

**Означення 1.1.1 (деревний функтор `F`).**

```
F(X) := A ⊔ X³
```

Функтор на категорії множин. Позначення: `νF` — фінальна коалгебра `F`.

**Означення 1.1.2 (оператор продуктивності `Ψ`).** На множині підмножин `U_c`:

```
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Застереження 1.1.3.** `F` і `Ψ` — різних типів. `F` діє на множинах, `Ψ` — на підмножинах `U_c`. Їх не можна позначати одним символом.

### 1.2. Скінченні апроксимації `T_n`

**Означення 1.2.1.** Індексований тип:

```
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) : a ∈ A }
         ∪ { Bottom_{n+1} }
         ∪ { Node_n(t₁, t₂, t₃) : t₁, t₂, t₃ ∈ T_n }
```

**Конвенція.** `Leaf_n`, `Bottom_n` індексовані за рівнем; `Node_n : T_n³ → T_{n+1}` — за рівнем дітей.

### 1.3. Усічення `q_n`

**Означення 1.3.1.**

```
q_0 : T_1 → T_0
q_0 (Leaf_1 a)          := Leaf_0 a
q_0 (Bottom_1)          := Bottom_0
q_0 (Node_0(t₁,t₂,t₃))  := Bottom_0

q_{n+1} : T_{n+2} → T_{n+1}
q_{n+1} (Leaf_{n+2} a)         := Leaf_{n+1} a
q_{n+1} (Bottom_{n+2})         := Bottom_{n+1}
q_{n+1} (Node_{n+1}(t₁,t₂,t₃)) := Node_n(q_n t₁, q_n t₂, q_n t₃)
```

**Лема 1.3.2 (типізація).** `q_n(t) ∈ T_n` для всіх `t ∈ T_{n+1}`.

**PROVED ON PAPER.**

### 1.4. Проєкції `p_n`

**Означення 1.4.1.**

```
p_0 : S_∞ → T_0
p_0 (Leaf a)      := Leaf_0 a
p_0 (Node _ _ _)  := Bottom_0

p_{n+1} : S_∞ → T_{n+1}
p_{n+1} (Leaf a)         := Leaf_{n+1} a
p_{n+1} (Node t₁ t₂ t₃)  := Node_n(p_n t₁, p_n t₂, p_n t₃)
```

**Лема 1.4.2 (факторизація).** `q_n(p_{n+1}(s)) = p_n(s)`.

**PROVED ON PAPER** (CE-10j.1.3).

### 1.5. Сумісні послідовності `U_c`

**Означення 1.5.1.**

```
U_c := { (t_n) ∈ ∏_n T_n : ∀n ≥ 0, q_n(t_{n+1}) = t_n }
```

**Застереження 1.5.2.** `U_c ≠ ∏_n T_n`. Контрприклад: `w = (Leaf_0(a), Bottom_1, Bottom_2, …) ∈ ∏T_n`, але `q_0(w_1) = Bottom_0 ≠ Leaf_0(a) = w_0`, отже `w ∉ U_c`.

### 1.6. Продуктивні послідовності `L_prod`

**Означення 1.6.1 (`LeafSeqs`, `NodeSeqs`, `Ψ`).**

```
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }

NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0
                ∧ ∃u₁,u₂,u₃ ∈ X
                ∧ ∀n ≥ 0, t_{n+1} = Node_n(u_{1,n}, u_{2,n}, u_{3,n}) }

Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Означення 1.6.2 (`L_prod`).**

```
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Лема 1.6.3.** `L_prod = Ψ(L_prod)`.

**PROVED ON PAPER** (CE-10j.0.2.1).

**Лема 1.6.4 (принцип коіндукції).** Якщо `X ⊆ U_c` і `X ⊆ Ψ(X)`, то `X ⊆ L_prod`.

**PROVED ON PAPER.**

**Контрприклад.** `L_prod ⊊ U_c`: `b = (Bottom_n)_n ∈ U_c \ L_prod`.

**Лема 1.6.5 (розклад).** Кожен `t ∈ L_prod` має або Leaf-, або Node-розклад.

**PROVED ON PAPER.**

### 1.7. Адресне кодування `Tree_∞`

**Означення 1.7.1.** `Pos := {1,2,3}^{<ω}`, `Label := A ⊔ {node}`.

**Означення 1.7.2 (`Tree_∞`).** Підтип `Pos → Option(Label)` з умовами (T1)–(T4):

- (T1) `f(ε) ≠ None`;
- (T2) `f(σ) = Some(node)` ⟹ `f(σ·i) ≠ None` для `i ∈ {1,2,3}`;
- (T3) `f(σ) = Some(leaf(a))` ⟹ `f(σ·i) = None` для `i ∈ {1,2,3}`;
- (T4) `f(σ) = None` ⟹ `f(σ·τ) = None` для всіх `τ`.

**Означення 1.7.3 (`out_Tree`).**

```
out_Tree : Tree_∞ → A ⊔ Tree_∞³
out_Tree(f) := inl(a)            якщо f(ε) = Some(leaf(a))
out_Tree(f) := inr(f₁, f₂, f₃)   якщо f(ε) = Some(node)
```

де `f_i(σ) := f(i·σ)`.

**Лема 1.7.4 (фінальність).** `(Tree_∞, out_Tree)` — фінальна коалгебра `F`.

**PROVED ON PAPER** (CE-10j-R3 §R3.1).

### 1.8. `L_prod` як друга модель

**Означення 1.8.1 (`out_L`).** Для `t ∈ L_prod`:

```
out_L(t) := inl(a)                 якщо t_n = Leaf_n(a) для всіх n
out_L(t) := inr(u₁, u₂, u₃)        якщо t_0 = Bottom_0 і t_{n+1} = Node_n(...)
```

**Лема 1.8.2.** `(L_prod, out_L)` — коалгебра `F`.

**PROVED ON PAPER** (CE-10j-R2 §R2.4).

**Теорема 1.8.3 (коалгебраїчний ізоморфізм).** `p : Tree_∞ → L_prod` — коалгебраїчний ізоморфізм:

```
out_L ∘ p = F(p) ∘ out_Tree
```

**PROVED ON PAPER** (CE-10j-R2 §R2.4.1).

**Наслідок 1.8.4.** `Tree_∞` і `L_prod` — **ізоморфні моделі** фінальної коалгебри `F`.

**Означення 1.8.5.** `S_∞ := Tree_∞` — канонічний носій.

## 2. Глибинні апроксимації та метрика

### 2.1. Рекурсивне `d_n`

**Означення 2.1.1 (база).** Для `f ∈ Tree_∞`:

- `f(ε) = Some(leaf(a))` → `d_0(f) := Leaf_0(a)`;
- `f(ε) = Some(node)` → `d_0(f) := Bottom_0`.

**Означення 2.1.2 (крок).** Для `n ≥ 0`:

- `f(ε) = Some(leaf(a))` → `d_{n+1}(f) := Leaf_{n+1}(a)`;
- `f(ε) = Some(node)` → `d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))`.

**Лема 2.1.3 (типізація).** `d_n(f) ∈ T_n`.

**Лема 2.1.4 (сумісність).** `q_n(d_{n+1}(f)) = d_n(f)`.

**Лема 2.1.5 (комутація з піддеревом).** Якщо `f(ε) = Some(node)`, то `d_n(f_i) = (d_{n+1}(f))|_i`.

**PROVED ON PAPER** (CE-10j.1.1–1.4).

### 2.2. Проєкції

**Означення 2.2.1.** `p_n : Tree_∞ → T_n`, `p_n(f) := d_n(f)`.

### 2.3. Розділення дерев

**Лема 2.3.1.** Для `f, g ∈ Tree_∞`: `(∀n: d_n(f) = d_n(g)) → f = g`.

**PROVED ON PAPER** (CE-10j-R3 §R3.3).

### 2.4. Метрика `d_S`

**Означення 2.4.1.**

```
r(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }    якщо f ≠ g
d_S(f, g) := 0                                 якщо f = g
d_S(f, g) := 2^{−r(f, g)}                      якщо f ≠ g
```

**Лема 2.4.2 (ультраметрика).** `d_S` — ультраметрика на `Tree_∞`.

**PROVED ON PAPER** (CE-10j-R3 §R3.4).

**Лема 2.4.3 (оцінка піддерев).** Для `f, g` з вузловими коренями: `d_S(f_i, g_i) ≤ 2 · d_S(f, g)`.

**PROVED ON PAPER** (CE-10j.7.1).
