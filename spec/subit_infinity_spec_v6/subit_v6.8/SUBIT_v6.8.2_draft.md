# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

**DEFINED.** Один скінченний алфавіт A потужності 4.

**Семантична реалізація:**

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація (білаттис Белнапа):**

```
𝔸 = { T, F, B, N }
```

**Кодування:**

| Bigram | Логічна | Семантична (WHO / WHERE / WHEN) |
|---|---|---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Розмежування.** Семантична й логічна реалізації — це **три окремі бієкції** на один абстрактний алфавіт A = {00, 01, 10, 11}:

```
β_WHO   : A_WHO   → 𝔸
β_WHERE : A_WHERE → 𝔸
β_WHEN  : A_WHEN  → 𝔸
```

Явно: β_WHO(ME) = T, β_WHO(WE) = B, β_WHO(YOU) = F, β_WHO(THEY) = N; аналогічно для WHERE і WHEN.

Білаттисна структура на 𝔸 **не переноситься автоматично** на ґратку Ω у §7. Ω — самостійна алгебра.

**Білаттисна структура** на 𝔸:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

## 2. Простір станів S₀

**DEFINED.** S₀ = A³, |S₀| = 4³ = 64. Кожен стан s = (α, β, γ) кодується 6 бітами: b₁b₂ = WHO, b₃b₄ = WHERE, b₅b₆ = WHEN.

**Гексаграмна нотація** (Додаток A) — компактний запис 6-бітного слова. Жодної семантики І-Цзін не вноситься.

**PROVED ON PAPER:** |S₀| = 64.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**DEFINED.** ℛ = {ρ₁, …, ρₙ}, ρᵢ : S₀ → S₀ — скінченна множина.

**DEFINED.** Розширений стан: ŝ = (s, ρ) ∈ S₀ × ℛ.

**Застереження 3.1.** SUBIT⁺ еквівалентний автономному детермінованому скінченному автомату з |Q| = |S₀ × ℛ|. «Правило належить стану» — це зміна кодування, а не збільшення виразності.

## 4. Оператор еволюції

**DEFINED.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

**Аксіома 4.1.** F — тотальна.

## 5. Траєкторії та класифікація точок

### 5.1. Траєкторія

**DEFINED.** τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …), ŝₙ₊₁ = F(ŝₙ).

### 5.2. Точкова категорія

**Означення 5.2.1.**

```
Ω_point(ŝ) :=
   FIXED           якщо F(ŝ) = ŝ
   PERIODIC(p)     якщо p := min{ k > 1 : Fᵏ(ŝ) = ŝ } існує
   NONRETURNING    інакше
```

FIXED і PERIODIC(p) не перетинаються (p = 1 виключено).

### 5.3. Скінченна періодичність

**Твердження 5.3.1.** Існують m ≥ 0, p ≥ 1 такі, що ŝ_{m+p} = ŝ_m.

**PROVED ON PAPER** (Діріхле).

### 5.4. Алгоритм класифікації

**Алгоритм 5.4.1.**

```
Вхід: ŝ₀, N_max ≥ |S₀ × ℛ|
Вихід: PointClass(ŝ₀) := (category, m, p, attractor_cycle, certificate)

visited : Map<ExtendedState, ℕ> ← ∅      # мапа стан → індекс першого входження
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ]
        p ← n − m
        attractor_cycle ← [ŝ_m, ŝ_{m+1}, …, ŝ_{n-1}]
        category ←
            FIXED           якщо m = 0 і p = 1
            PERIODIC(p)     якщо m = 0 і p > 1
            NONRETURNING    якщо m > 0
        certificate ← {m, p, attractor_cycle}
        повернути (category, m, p, attractor_cycle, certificate)
    visited[ŝₙ] ← n
    ŝₙ₊₁ ← F(ŝₙ)
повернути (RESOURCE_EXCEEDED, ⊥, ⊥, ⊥, ⊥)
```

**Застереження 5.4.2.** `visited` — **мапа** (не множина): зберігає індекс першого входження. Без цього `m` не відновлюється.

**Застереження 5.4.3.** Поле `attractor_cycle` (не `cycle`) — для NONRETURNING воно містить нерухому точку, у яку потрапляє хвіст, а не «цикл» у сенсі PERIODIC(p > 1).

**Застереження 5.4.4.** N_max ≥ |S₀ × ℛ| гарантує знаходження повтору лише за умов: S₀ × ℛ скінченний, F тотальна, |ℛ| відомий.

**Приклад 5.4.5.**

| ŝ₀ | категорія | m | p | attractor_cycle |
|---|---|---|---|---|
| a → a | FIXED | 0 | 1 | [a] |
| a → b → a | PERIODIC(2) | 0 | 2 | [a, b] |
| a → b → b | NONRETURNING | 1 | 1 | [b] |

### 5.5. Граничне застереження

Для S_∞ алгоритм 5.4.1 може не завершитися; гілка RESOURCE_EXCEEDED змістовна.

# ЧАСТИНА III. SUBIT-CAT — категорія і класифікація

## 6. Класифікація множин

### 6.1. Точна класифікація

**DEFINED.** `Classify⁺(P) := ( OrbitType(P), InclusionType(P), Chaos(P) )`.

Три незалежні складові: тип орбіти множини, співвідношення образу з P, предикат внутрішньої хаотичності.

### 6.2. OrbitType

**Означення 6.2.1 (пріоритетний порядок).**

```
OrbitType(P) :=
   1. INVARIANT_FIXED
         якщо F(P) = P ∧ ∀x ∈ P: F(x) = x
   2. INVARIANT_DYNAMIC
         якщо F(P) = P ∧ ¬(∀x ∈ P: F(x) = x)
   3. PERIODIC_SET(p)
         якщо ∃p ≥ 2: F^p(P) = P ∧ F(P) ≠ P
            (p — найменший такий)
   4. EVENTUALLY_FIXED(m)
         якщо ∃m ≥ 1: F^{m+1}(P) = F^m(P) ∧ F^m(P) ≠ P
            ∧ ∀k ≥ 1: F^k(P) ≠ P
            (m — найменше таке)
   5. EVENTUALLY_PERIODIC(m, p)
         якщо ∃m ≥ 1, p ≥ 2: F^{m+p}(P) = F^m(P)
            ∧ F^{m+1}(P) ≠ F^m(P)
            ∧ ∀k ≥ 1: F^k(P) ≠ P
            ((m, p) — лексикографічно найменша така пара)
   6. APERIODIC
         якщо жодна з умов 1–5 не виконується
```

**Застереження 6.2.2.** Умова `∀k ≥ 1: F^k(P) ≠ P` у класах 4 і 5 виключає **початково періодичні** множини (P = F^k(P) для деякого k ≥ 1), але **не** виключає звичайних передперіодичних траєкторій, які зрештою потрапляють у цикл.

**Твердження 6.2.3 (вичерпність і взаємовиключність).** Шість класів вичерпні й взаємовиключні.

*Доведення.* Взаємовиключність:

- 1 vs 2: розділені умовою «всі точки нерухомі».
- 1, 2 vs 3–5: `F(P) = P` vs `F(P) ≠ P`.
- 3 vs 4, 5: клас 3 вимагає `∃p ≥ 2: F^p(P) = P`; класи 4, 5 — `∀k ≥ 1: F^k(P) ≠ P`. Суперечні.
- 4 vs 5: клас 4 вимагає `F^{m+1}(P) = F^m(P)`; клас 5 — `F^{m+1}(P) ≠ F^m(P)`.
- 6 — залишок.

Вичерпність: будь-яка P потрапляє рівно в один клас за побудовою. ∎

**PROVED ON PAPER.**

**Приклади.**

```
Приклад 6.2.4 (INVARIANT_DYNAMIC):
  X = {a, b}, F(a) = b, F(b) = a, P = {a, b}
  F(P) = P; точки не нерухомі → INVARIANT_DYNAMIC

Приклад 6.2.5 (EVENTUALLY_PERIODIC):
  X = {a, b, c}, F(a) = b, F(b) = c, F(c) = b, P = {a}
  F(P) = {b}, F²(P) = {c}, F³(P) = {b} = F(P)
  F(P) ≠ P; ∃m = 1, p = 2: F³(P) = F¹(P)
  ∀k ≥ 1: F^k(P) ≠ P
  → EVENTUALLY_PERIODIC(1, 2)

Приклад 6.2.6 (PERIODIC_SET):
  X = {a, b, c}, F(a) = b, F(b) = a, F(c) = c, P = {a, c}
  F(P) = {b, c}; F²(P) = {a, c} = P; F(P) ≠ P
  → PERIODIC_SET(2)

Приклад 6.2.7 (INVARIANT_FIXED):
  X = {a, b}, F(a) = a, F(b) = b, P = {a, b}
  F(P) = P; обидві точки нерухомі → INVARIANT_FIXED

Приклад 6.2.8 (EVENTUALLY_FIXED):
  X = {a, b}, F(a) = a, F(b) = a, P = {a, b}
  F(P) = {a}; F²(P) = {a} = F(P); F(P) ≠ P
  ∀k ≥ 1: F^k(P) ≠ P
  → EVENTUALLY_FIXED(1)
```

### 6.3. InclusionType

**Означення 6.3.1 (пріоритетний порядок).**

```
InclusionType(P) :=
   1. EQUAL_IMAGE
         якщо F(P) = P
   2. DISJOINT_IMAGE
         якщо F(P) ∩ P = ∅
   3. STRICT_SUBIMAGE
         якщо F(P) ⊊ P
   4. STRICT_SUPERIMAGE
         якщо P ⊊ F(P)
   5. OVERLAPPING_NONCOMPARABLE
         якщо F(P) ∩ P ≠ ∅, F(P) ⊄ P, P ⊄ F(P)
```

**Застереження 6.3.2.** Пріоритетний порядок гарантує, що кожне P потрапляє рівно в один клас:

- P = ∅: F(P) = ∅ = P → EQUAL_IMAGE.
- F(P) ∩ P = ∅: DISJOINT_IMAGE (раніше за STRICT_SUBIMAGE, якщо F(P) = ∅ ⊊ P).
- F(P) ⊊ P, перетин непорожній: STRICT_SUBIMAGE.
- P ⊊ F(P): STRICT_SUPERIMAGE.
- Інакше (перетин непорожній, жодне не містить інше): OVERLAPPING_NONCOMPARABLE.

**Твердження 6.3.3.** InclusionType утворює розбиття множини всіх P ⊆ S_∞ × ℛ₀.

**PROVED ON PAPER.**

**Приклад 6.3.4.**

```
P = {a, b}, F(a) = a, F(b) = a
F(P) = {a}
F(P) ∩ P = {a} ≠ ∅, F(P) = {a} ⊊ {a, b} = P
→ STRICT_SUBIMAGE
```

### 6.4. Chaos — окремий предикат

**Означення 6.4.1.** P **хаотична**, якщо:

1. `F(P) = P` (P інваріантна);
2. `F|_P : P → P` коректно визначене як динамічне відображення;
3. P компактна в топології d̂;
4. P мінімальна: не містить власної непорожньої замкненої F-інваріантної підмножини;
5. `h_top(P, F|_P) > 0`.

**Застереження 6.4.2.** CHAOTIC — **предикат** на множинах, не значення OrbitType і не клітинка Ω. Може співіснувати лише з OrbitType, для якого P інваріантна:

| OrbitType(P) | Chaos(P) можливий? |
|---|---|
| INVARIANT_FIXED | ⊥ (h_top = 0 обов'язково) |
| INVARIANT_DYNAMIC | ⊤ або ⊥ |
| PERIODIC_SET(p) | ⊥ (F(P) ≠ P, умова 1 не виконана) |
| EVENTUALLY_* | ⊥ (F(P) ≠ P) |
| APERIODIC | ⊥ (F(P) ≠ P) |

**Твердження 6.4.3.** На скінченному рівні SUBIT⁺ хаотичних множин немає.

*Доведення.* Будь-яка орбіта скінченної P під F має повторення (Діріхле). Отже, OrbitType(P) ≠ APERIODIC і одночасно F(P) ≠ P (інакше один із перших двох класів), але CHAOTIC вимагає F(P) = P. Суперечність. ∎

**PROVED ON PAPER.**

**Приклад 6.4.4 (Chaos(P) = ⊥).**

```
X = {0, 1}^ℕ, F = σ (зсув Бернуллі), P = X
F(P) = P → INVARIANT_DYNAMIC
P НЕ мінімальна (містить 0∞, 1∞) → Chaos(P) = ⊥
```

**Приклад 6.4.5 (Chaos(P) = ⊤ у символічній динаміці).**

У символічній динаміці існують мінімальні підсистеми повного зсуву з додатною топологічною ентропією. Для такої підсистеми P ⊆ {0,1}^ℕ виконуються всі п'ять умов означення 6.4.1, отже Chaos(P) = ⊤, і OrbitType(P) = INVARIANT_DYNAMIC.

**Застереження 6.4.6.** Приклад 6.4.5 підтверджує **несуперечність означення** у загальному контексті символічної динаміки. Він **не** доводить існування такої P у класі ℛ₀ (причинні функції). Питання явної реалізації CHAOTIC у ℛ₀ — Q14 (❓).

### 6.5. Зв'язок точкової та множинної класифікації

**Твердження 6.5.1 (скінченна P).** F(P) = P ⟹ ∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}.

*Доведення.* F|_P — сюр'єкція скінченної множини на себе, отже бієкція. Кожна точка P періодична. ∎

**PROVED ON PAPER.**

**Твердження 6.5.2 (нескінченна P).** На S_∞ твердження 6.5.1 **хибне**.

*Контрприклад.* X = ℤ, F(n) = n+1, P = ℤ. F(P) = P, але жодна точка не повертається: F^k(n) = n+k ≠ n для k ≥ 1. ∎

**PROVED ON PAPER.**

### 6.6. Classify⁺ vs Ω — розділення понять

**Означення 6.6.1.** Ω — **6-ланцюг**:

```
CHAOTIC
  < APERIODIC_NON_CHAOTIC
  < EVENTUALLY_PERIODIC
  < PERIODIC_SET
  < INVARIANT_DYNAMIC
  < INVARIANT_FIXED
```

**Означення 6.6.2 (домен проєкції).**

```
D_class := { Classify⁺(P) : P ⊆ S_∞ × ℛ₀ }
```

**Означення 6.6.3 (проєкція π_Ω).**

```
π_Ω : D_class → Ω
π_Ω((O, I, C)) :=
   CHAOTIC                  якщо C = ⊤
   APERIODIC_NON_CHAOTIC    якщо O = APERIODIC ∧ C = ⊥
   EVENTUALLY_PERIODIC      якщо O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
                               ∧ C = ⊥
   PERIODIC_SET             якщо O = PERIODIC_SET ∧ C = ⊥
   INVARIANT_DYNAMIC        якщо O = INVARIANT_DYNAMIC ∧ C = ⊥
   INVARIANT_FIXED          якщо O = INVARIANT_FIXED ∧ C = ⊥
```

**Твердження 6.6.4 (тотальність).** π_Ω визначена на всьому D_class.

*Доведення.* Кожен результат Classify⁺(P) має вигляд (O, I, C) з O ∈ {6 значень OrbitType} і C ∈ {⊤, ⊥}. Гілка π_Ω для кожного O і C покрита. ∎

**PROVED ON PAPER.**

## 8. Категорія SUBIT

**DEFINED.** Об'єкт X = (S_X, ℛ_X, F_X, g_X), де S_X — множина, ℛ_X ⊆ {f : S_X → S_X}, F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

**DEFINED (морфізм).** φ = (φ_S, φ_ℛ), що задовольняє:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

**DEFINED (аксіоми).** Тотожний морфізм id_X := (id_{S_X}, id_{ℛ_X}). Композиція покомпонентна.

**Твердження 8.1.** SUBIT — категорія.

**PROVED ON PAPER.** Асоціативність і нейтральність id спадкуються від функцій.

**DEFINED.** 1 = ({∗}, {id}). X × Y = (S_X × S_Y, ℛ_X × ℛ_Y, F_X × F_Y).

**Твердження 8.2.** 1 — термінальний; X × Y — добуток.

**PROVED ON PAPER.**

**Застереження 8.3.** Експоненціал Yˣ визначений лише для об'єктів із оборотним F_X. Загальний випадок — Q1.

## 9. Dyn як топос

**DEFINED.** Категорія Dyn: об'єкти (S, f), f : S → S; морфізми φ ∘ f = g ∘ φ.

**Твердження 9.1.** Dyn ≅ `Set^ℕ`.

**PROVED ON PAPER** (Lawvere, 1964).

**Твердження 9.2 (класифікатор).** Ω_Dyn = ℕ ∪ {∞}, дія n · k := max(n − k, 0), ∞ · k := ∞. χ_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U}.

**PROVED ON PAPER.**

**Твердження 9.3.** χ_U — морфізм Dyn: χ_U(f(x)) = max(χ_U(x) − 1, 0).

**PROVED ON PAPER.**

**Твердження 9.4 (повнота).** Sub_Dyn(X) → Hom_Dyn(X, Ω_Dyn), U ↦ χ_U — бієкція.

**PROVED ON PAPER** (стандартний результат для топосу прешейвів).

**Твердження 9.5.** Dyn — топос.

### 9.6. χ_U-механізм v6.2 не працює як класифікатор SUBIT

**Твердження 9.6.1.** Механізм χ_U з v6.2 (через 4-елементну Ґратку STABLE/METASTABLE/CYCLIC/CHAOTIC для субоб'єктів SUBIT) **не працює** як субоб'єктний класифікатор.

**Застереження 9.6.3.** Для доведення неіснування треба:

## 10. Динамічна теорія типів

**DEFINED.** Судження Γ ⊢ t : A @ τ.

**Правила:**

```
Рефлекс.:    Γ, x:A@τ ⊢ x : A@τ
Еволюція:    Γ ⊢ t:A@τ     F(A) ⊆ B
             Γ ⊢ F(t) : B @ (τ+1)
Стабільний:  Γ ⊢ t:A@τ     F(A) = A
             Γ ⊢ t : □A @ τ
Потенційний: Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
             Γ ⊢ t : ◇B @ τ
```

## 11. Модальна логіка

### 11.A. LTL-семантика

**DEFINED.**

```
ŝ ⊨ X A       ⟺   F(ŝ) ∈ A
ŝ ⊨ ◇ A       ⟺   ∃n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◇⁺ A      ⟺   ∃n ≥ 1: Fⁿ(ŝ) ∈ A
ŝ ⊨ □ A       ⟺   ∀n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ↺ A       ⟺   ∃k > 1: Fᵏ(ŝ) ∈ A
```

**Твердження 11.A.1 (аксіоми).**

```
(X1)   X A → ◇⁺A
(X2)   X A ∧ X B ↔ X (A ∧ B)
(X3)   X A ∨ X B ↔ X (A ∨ B)
(D1)   ◇A ↔ A ∨ X ◇A
(D2)   ◇⁺A ↔ X ◇A
(D3)   ◇A ↔ A ∨ ◇⁺A
(B1)   □A ↔ A ∧ X □A
(B2)   □A → A
(B3)   □A → X □A
(B4)   □A → ◇A
(B5)   □(A → B) → (□A → □B)
(R1)   ↺A ↔ ◇⁺(X A)
(R2)   ↺A → ◇⁺A
(M4)   ◇A ↔ ¬□¬A
```

**Твердження 11.A.2 (M6).** □A → ↺A виконується для будь-якого A і тотального F без умов.

*Доведення.* □A в ŝ тягне F²(ŝ) ∈ A, отже ∃k = 2 > 1: F^k(ŝ) ∈ A. ∎

**PROVED ON PAPER.**

**Твердження 11.A.3 (Return).** A ⊆ ◇⁺(X A) — окрема властивість, не ототожнюється з □A → ↺A.

### 11.B. Гейтінгова семантика

**DEFINED.** Ω — 6-ланцюг §7.

```
(□_H A)(ŝ) := ⋀_{n ≥ 0} A(Fⁿŝ)
(◇_H A)(ŝ) := ⋁_{n ≥ 0} A(Fⁿŝ)
```

**Твердження 11.B.1 (M4_H не виконується).** ◇_H A ↔ ¬_H □_H ¬_H A — хибне.

*Контрмодель.* X = {a, b}, F(a) = b, F(b) = b, A(a) := EVENTUALLY_PERIODIC, A(b) := CHAOTIC.

- □_H ¬_H A(a) = ¬_H EVENTUALLY_PERIODIC ∧ ¬_H CHAOTIC = CHAOTIC ∧ INVARIANT_FIXED = CHAOTIC.
- ¬_H □_H ¬_H A(a) = ¬_H CHAOTIC = INVARIANT_FIXED.
- ◇_H A(a) = EVENTUALLY_PERIODIC.
- INVARIANT_FIXED ≠ EVENTUALLY_PERIODIC. ∎

**PROVED ON PAPER.**

### 11.C. Співвідношення

§11.A — про траєкторії; §11.B — про значення в Ω. Різні системи. Не змішуються.

## 15. Семантичні метрики

### 15.1. Структурні метрики

**Означення 15.1.1 (δ, d_S).**

```
δ(s, t) := ∞,  якщо s = t
δ(s, t) := 0,  якщо s, t — листки з різними мітками,
             або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),
             якщо s = (w,x,y), t = (w',x',y')
d_S(s, t) := 2^(−δ(s,t))   якщо δ < ∞
d_S(s, t) := 0              якщо s = t
```

**Застереження 15.1.2.** d_S ∈ [0, 1]; максимум = 1 (два різних листки, або лист і вузол). Це не евклідова метрика.

**Твердження 15.1.3.** d_S — ультраметрика.

**PROVED ON PAPER.**

**Означення 15.1.4 (d_ℛ).** Для f ∈ ℛ₀ означимо f_n(π_n(s)) := π_n(f(s)) (коректність — з причинності f).

```
d_ℛ(f, g) := 2^(−n₀(f, g)),   n₀(f, g) := min{ n : f_n ≠ g_n }
d_ℛ(f, g) := 0,                якщо f_n = g_n для всіх n
```

**Твердження 15.1.5.** d_ℛ(f, g) = 0 ⟺ f = g.

**PROVED ON PAPER.**

**Означення 15.1.6 (d̂).** d̂((s, ρ), (t, σ)) := max(d_S(s, t), d_ℛ(ρ, σ)).

**Твердження 15.1.7.** d̂ — ультраметрика.

**PROVED ON PAPER.**

**Твердження 15.1.8.** (S_∞ × ℛ₀, d̂) компактний гаусдорфовий.

**PROVED ON PAPER.**

### 15.2. Локальна метрика чутливості d_finite

**Означення 15.2.1.**

```
d_finite(ŝ, t̂) := sup_{n ≥ 0} 2^{-n} · d̂(Fⁿ(ŝ), Fⁿ(t̂))
```

**Твердження 15.2.2.** Якщо d̂ — ультраметрика і sup скінченний, то d_finite — **ультраметрика** на S_∞ × ℛ₀.

*Доведення.*

1. Кожна d_n(ŝ, t̂) := 2^{-n} · d̂(Fⁿŝ, Fⁿt̂) — ультрапсевдометрика.
2. Sup сімейства ультрапсевдометрик — ультрапсевдометрика.
3. Член n = 0 дає d_finite(ŝ, t̂) ≥ d̂(ŝ, t̂).
4. Якщо d_finite(ŝ, t̂) = 0, то d̂(ŝ, t̂) = 0, отже ŝ = t̂.
5. Отже, d_finite — ультраметрика. ∎

**PROVED ON PAPER.**

**Застереження 15.2.3.** v6.8 помилково називав d_finite «псевдоультраметрикою». Насправді це **ультраметрика**. Факторизація за ~_traj (ототожнення станів з однаковою майбутньою траєкторією) — окрема конструкція, не потрібна для метричності.

**Застереження 15.2.4.** d_finite вимірює локальну чутливість до початкових умов; не узгоджена з асимптотикою в загальному випадку.

**Застереження 15.2.5.** Скінченність супрему автоматична, якщо d̂ обмежена (d̂ ∈ [0, 1]).

### 15.3. Асимптотична метрика d_ω

**Означення 15.3.1.** Для ŝ, t̂ ∈ S_∞ × ℛ₀ з непорожніми компактними (отже, замкненими) ω-границями:

```
d_ω(ŝ, t̂) := d_Hausdorff( ω(ŝ), ω(t̂) )
```

де d_Hausdorff визначена на компактних підмножинах S_∞ × ℛ₀.

**Застереження 15.3.2.** Компактність ω(ŝ) гарантована, якщо F задовольняє NF1–NF4 (§18.2).

**Твердження 15.3.3.** d_ω — псевдометрика на S_∞ × ℛ₀; стає метрикою на факторі (S_∞ × ℛ₀) / ~_ω, де ŝ ~_ω t̂ ⟺ ω(ŝ) = ω(t̂).

**PROVED ON PAPER.**

**Застереження 15.3.4.** Узгодженість d_finite і d_ω **залежить від F**:

- Якщо F структурно стійка — d_finite → 0 тягне d_ω → 0.
- Якщо F структурно нестійка (з межами басейнів) — можлива неузгодженість.

**Приклад 15.3.5 (x² на [0, 1], якісний).**

**Система.** X = [0, 1], F(x) := x². Атрактори: 0 (стійкий), 1 (нестійкий). B(0) = [0, 1), B(1) = {1}.

**Ремарка.** X = [0, 1] — ізоморфний компакт, не підмножина S_∞ × ℛ₀; використовується як наочна ілюстрація.

**Ілюстрація (якісна).**

- ŝ₁ = 0.5, t̂₁ = 0.5 + ε (обидва в B(0)): d_finite = O(ε); d_ω = 0.
- ŝ₂ = 1, t̂₂ = 1 − ε (різні басейни): d_finite = O(ε); d_ω = d̂(0, 1) > 0.

**Наслідок.** На межі басейнів d_ω стрибкоподібна, d_finite залишається малою. Приклад ілюструє, але не доводить неузгодженості метрик.

**Зауваження 15.3.6.** Питання Q12: для яких F метрики узгоджені?

### 18.2. ω-границя і неперервність F

**Означення 18.2.1.** ω(ŝ₀) := множина точок накопичення τ(ŝ₀) у d̂.

**Твердження 18.2.2 (умови неперервності повного F).** F : S_∞ × ℛ₀ → S_∞ × ℛ₀ неперервний, якщо:

- **(NF1)** f_ρ причинна для всіх ρ ∈ ℛ₀;
- **(NF2)** g : ℛ₀ × S_∞ → ℛ₀ неперервна в d_ℛ × d_S;
- **(NF3)** g(ρ, s) ∈ ℛ₀ для всіх ρ, s;
- **(NF4)** ρ ↦ f_ρ : ℛ₀ → ℛ₀ неперервна в d_ℛ.

**Статус:** **OPEN.** Повне доведення потребує сумісної неперервності (s, ρ) ↦ f_ρ(s) у d̂.

**Застереження 18.2.3.** NF1–NF4 — сильні обмеження. Для багатьох «цікавих» метаеволюцій F розривний у d̂.

**Приклад 18.2.4 (неперервна g, тривіальна).** g(ρ, s) := ρ.

**Приклад 18.2.5 (неперервна, нетривіальна).** g(ρ, s) := ρ′ де f_{ρ′} := f_ρ ∘ λ_s, λ_s — причинне, неперервно залежить від s.

**Приклад 18.2.6 (розривна g).** g(ρ, s) := «додати вузол до ρ-дерева». d_ℛ стрибкоподібна. NF2, NF4 не виконуються.

### 18.3. Коллапс

**Твердження 18.3.1.** За умов компактності X і неперервності F: ω(ŝ₀) — непорожня компактна F-інваріантна підмножина, `F(ω(ŝ₀)) = ω(ŝ₀)`.

**PROVED ON PAPER.**

**Твердження 18.3.2.** Тому OrbitType(ω(ŝ₀)) ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. **Не завжди** INVARIANT_FIXED (контрприклад: двоцикл). Класифікація Ω_set(ω(ŝ₀)) не розрізняє внутрішню динаміку ω-границі; тому для P(τ) використовується **окремий** класифікатор DynType (§18.5).

### 18.4. Att

**Означення 18.4.1.**

```
ATTAINED      якщо ∃n: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC    якщо ∀n: ŝₙ ∉ ω(ŝ₀) і dist(ŝₙ, ω(ŝ₀)) → 0
```

**Означення 18.4.2.** COMPUTED / RESOURCE_EXCEEDED — окреме поле сертифіката.

### 18.5. DynType — класифікатор внутрішньої динаміки ω-границі

**Означення 18.5.1 (передумови).** X — компактний метричний простір; F : X → X — неперервне; ω(ŝ₀) — ω-границя траєкторії.

**Означення 18.5.2 (класифікатор).**

```
DynType(ω, F|ω) :=
   FIXED_POINT                 якщо ω = {p}, F(p) = p
   PERIODIC_ORBIT              якщо ω скінченна, |ω| > 1
   MINIMAL_ZERO_ENTROPY        якщо ω нескінченна, мінімальна, h_top = 0
   MINIMAL_POSITIVE_ENTROPY    якщо ω нескінченна, мінімальна, h_top > 0
   NON_MINIMAL                 якщо ω нескінченна і не мінімальна
```

**Твердження 18.5.3' (вичерпність).** DynType вичерпний для всіх ω-границь у межах передумов.

*Доведення.* Неперервність F і компактність X дають інваріантність і непорожність ω (Bowen 1971).

**Внутрішня ланцюгова транзитивність.** Для будь-яких x, y ∈ ω та ε > 0 існує скінченний ε-ланцюг у ω, що веде від x до y. Це властивість ω-границі.

**Скінченна ω.** F|_ω — перестановка, отже ω розпадається на скінченну кількість неперетинних циклів.

**Один цикл.** Якщо циклів ≥ 2, мінімальна додатна відстань δ між ними. Для ε < δ/2 жоден ε-ланцюг не може перейти між циклами — суперечність із ланцюговою транзитивністю.

Отже, ω — один цикл (PERIODIC_ORBIT) або одна точка (FIXED_POINT).

**Нескінченна ω.** Розбивається на мінімальні й немінімальні. Мінімальні — на випадки h_top = 0 і h_top > 0. ∎

**PROVED ON PAPER.**

**Застереження 18.5.4.** Для некомпактних X або розривного F класифікація DynType **не застосовна**; у таких випадках S(τ) := ⊥.

**Означення 18.5.5.** `S(τ) := DynType(ω(ŝ₀), F|ω(ŝ₀))`.

**Означення 18.5.6 (Ω_ω).**

```
Ω_ω := { FIXED_POINT, PERIODIC_ORBIT, MINIMAL_ZERO_ENTROPY,
         MINIMAL_POSITIVE_ENTROPY, NON_MINIMAL }
```

5 класів.

### 18.6. CHAOTIC у ℛ₀

**Твердження 18.6.1.** Для ρ ∈ ℛ₀ з g ≡ id (фіксоване правило): h_top(ω(ŝ₀)) = 0.

**PROVED ON PAPER** (Bowen 1971).

**Застереження 18.6.2.** Для повної динаміки з нетривіальною g — Q10 (❓).

### 18.7. Сертифікати

**Сертифікат ATTAINED (розділений на три компоненти).**

- **ENTRY_WITNESS**: n ∈ ℕ таке, що ŝₙ ∈ C для кандидатної множини C.
- **INVARIANCE_WITNESS**: F(C) = C.
- **OMEGA_COMPLETENESS**: C = ω(ŝ₀). Доведення, що C — уся ω-границя, а не лише частина орбіти.

**Застереження 18.7.1.** Входження в ω не доводить C = ω(ŝ₀). Замкненість C не доводить C = ω(ŝ₀).

**Сертифікат ASYMPTOTIC.** Містить послідовність усічень π_n(ω) і модуль збіжності N(ε), якщо доступний.

**Сертифікат CHAOTIC.** Зовнішній; скінченного свідка не існує.
