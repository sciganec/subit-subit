## Анотація

SUBIT-∞ — формальна нотаційна система для опису станів, переходів, правил еволюції та метаеволюції динамічних систем. Архітектура кумулятивна:

```
SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-CAT ⊂ SUBIT-∞
```

**Ключові архітектурні рішення цієї редакції:**

1. **Деревний функтор** `F_tree(X) = A ⊔ X³` відділено від **динамічних операторів** `D₀` (на `S₀`) та `D∞` (на `S_∞`).
2. **Обернена границя** `U_c = lim←(T_n, q_n)` **строго більша** за фінальну коалгебру `S_∞`. Правильна бієкція — `Tree_∞ ≅ L_prod` для продуктивного підпростірства `L_prod ⊊ U_c`.
3. **Три класифікатори** розділені: `Ω_set` (множини), `Ω_point` (точки), `S(τ)` (ω-границі).
4. **Компактність `S_∞`** доведена **прямо** через повноту і цілковиту обмеженість (класи `C_u`), без хибної бієкції з `U_c`.

**Обмеження.** Наведені математичні означення не означають, що всі заявлені теореми формально доведені в Lean 4. Статус «доведено на папері» не еквівалентний машинно перевіреному доказу.

# Частина I. SUBIT-64 — скінченний алфавіт станів

## 1. Алфавіт примітивів

**Означення 1.1 (носій і кодування).**

```
A_Belnap := {T, F, B, N}
A_bit    := {00, 01, 10, 11}
enc₂ : A_Belnap → A_bit
enc₂(N) = 00,   enc₂(F) = 01,   enc₂(T) = 10,   enc₂(B) = 11
```

`A_Belnap` — канонічна множина міток для дерев; `A_bit` — 2-бітні коди для `SUBIT-64`.

**Семантичні інтерпретації** (мітки значень, а не додаткові елементи):

```
WHO   : ME, WE, YOU, THEY
WHERE : EAST, SOUTH, WEST, NORTH
WHEN  : SPRING, SUMMER, AUTUMN, WINTER
```

**Білаттисна структура.** Порядок істинності: `F <ₜ N <ₜ T`, `F <ₜ B <ₜ T`. Порядок інформації: `N <ᵢ F <ᵢ B`, `N <ᵢ T <ᵢ B`. Ця структура **не переноситься автоматично** на динаміку `S_∞`.

## 2. Простір станів S₀ і кодування

**Означення 2.1.**

```
S₀ := A_Belnap × A_Belnap × A_Belnap,   |S₀| = 4³ = 64
```

Стан `s = (α, β, γ)`. Нехай `enc₂(α) = w₁w₂`, `enc₂(β) = h₁h₂`, `enc₂(γ) = t₁t₂`.

**Означення 2.2 (канонічне числове кодування).**

```
code6(α, β, γ) := 32·w₁ + 16·w₂ + 8·h₁ + 4·h₂ + 2·t₁ + t₂
```

Це числове значення 6-бітного слова `w₁w₂h₁h₂t₁t₂`.

**Приклади:** `101010₂ = 42`, `111111₂ = 63`, `010001₂ = 17`.

**ВІДКЛИКАНО:** попереднє означення `32·w₂ + 16·w₁ + 8·h₂ + 4·h₁ + 2·t₂ + t₁`.

**Гексаграмна нотація** (Додаток A) — компактний запис; традиційна символіка І-Цзін не є аксіомою.

**Статус:** SUBIT-64 — статичний рівень без оператора переходу.

# Частина II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.** `ℛ_fin ⊆ (S₀ → S₀)` — скінченний набір правил.

**Означення 3.2.** Розширений стан: `ŝ = (s, ρ) ∈ S₀ × ℛ_fin`.

**Застереження 3.3.** SUBIT⁺ еквівалентний автономному детермінованому скінченному автомату з `|Q| = |S₀ × ℛ_fin|`. «Правило належить стану» — структурна зміна кодування, не доказ сильнішої виразності.

## 4. Оператор еволюції `D₀` та метаеволюція

**Означення 4.1 (динаміка скінченної моделі `D₀`).** Нехай `g₀ : ℛ_fin × S₀ → ℛ_fin`. Визначимо:

```
D₀ : S₀ × ℛ_fin → S₀ × ℛ_fin
D₀(s, ρ) := (ρ(s), g₀(ρ, s))
```

Якщо правила подано кодами, `ρ(s)` замінюється на явно визначену функцію `eval₀(ρ, s)`.

**Аксіома 4.2 (тотальність).** `D₀` — тотальна.

Часткові оператори, помилки, ресурсне переривання — окремий шар обчислювального статусу.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** `τ(ŝ₀) = (ŝ₀, ŝ₁, …)`, `ŝₙ₊₁ = D₀(ŝₙ)`.

### 5.1. Скінченна періодичність

**Твердження 5.1.1.** Для кожного `ŝ₀` існують `m ≥ 0, k ≥ 1`: `ŝ_{m+k} = ŝ_m`.

**Доведення.** Принцип Діріхле. ∎ **PROVED ON PAPER.**

### 5.2. Точкова класифікація `Ω_point` (виправлено)

**Означення 5.2.1 (область дії).** `Ω_point` визначається для `Q₀ := S₀ × ℛ_fin` з тотальним оператором `D₀`.

**Означення 5.2.2 (`m`, `p`).** Для `x ∈ Q₀`:

```
m(x) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(x) = D₀^m(x) }
p(x) := min{ p ≥ 1 : D₀^{m(x)+p}(x) = D₀^{m(x)}(x) }
```

**Означення 5.2.3 (три класи).**

```
FIXED          ⟺ m(x) = 0 ∧ p(x) = 1
PERIODIC(p)    ⟺ m(x) = 0 ∧ p(x) = p ≥ 2
PREPERIODIC    ⟺ m(x) ≥ 1
```

**Твердження 5.2.4.** Три класи попарно не перетинаються і вичерпують `Q₀`.

**PROVED ON PAPER.**

**ВІДКЛИКАНО:** попереднє означення через `min{k > 1 : D₀ᵏ(x) = x}`, яке для нерухомих точок давало `PERIODIC(2)`.

### 5.3. Алгоритм скінченної класифікації

```
Вхід: ŝ₀, горизонт N_max ≥ |Q₀|
visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ]
        p ← n − m
        attractor_cycle ← [ŝ_m, …, ŝ_{n-1}]
        category ←
            FIXED           якщо m = 0 і p = 1
            PERIODIC(p)     якщо m = 0 і p > 1
            PREPERIODIC     якщо m > 0
        повернути (category, m, p, attractor_cycle)
    visited[ŝₙ] ← n
    ŝₙ₊₁ ← D₀(ŝₙ)
повернути RESOURCE_EXCEEDED
```

### 5.4. Відкликане ототожнення

**ВІДКЛИКАНО:** ототожнення `PREPERIODIC` із `CHAOTIC`. Передперіодичність — звичайна поведінка скінченного автомата.

# Частина III. SUBIT-CAT — категорія, класифікатори та логіка

## 6. Три класифікатори

### 6.1. Класифікатор множин `Ω_set` (нормативно, через `D`)

**Означення 6.1.1 (образ множини).** Для динамічної системи `(K, D)` і `P ⊆ K`:

```
D[P] := { D(x) : x ∈ P }
Dⁿ[P] := { Dⁿ(x) : x ∈ P }
```

**Означення 6.1.2 (чотири класи).**

```
STABLE(P)     ⟺ D[P] = P
METASTABLE(P) ⟺ D[P] ⊊ P
CYCLIC(P)     ⟺ D[P] ≠ P ∧ ∃k ≥ 2: Dᵏ[P] = P
CHAOTIC(P)    ⟺ D[P] ⊄ P ∧ ∀k ≥ 2: Dᵏ[P] ≠ P
```

**Твердження 6.1.3 (взаємовиключність і вичерпність).** Чотири класи попарно не перетинаються і вичерпують усі підмножини `K`.

**Доведення.** Якщо `D[P] = P` — STABLE. Інакше, якщо `D[P] ⊊ P` — METASTABLE. Інакше `D[P] ⊄ P`: якщо є повернення — CYCLIC, якщо немає — CHAOTIC. ∎ **PROVED ON PAPER.**

### 6.2. Точковий класифікатор `Ω_point`

Три класи за §5.2, визначені для `Q₀ = S₀ × ℛ_fin`. `CHAOTIC` не є точковим класом.

### 6.3. Класифікатор ω-границь `S(τ)` — область застосування

**Передумова 6.3.1.** Класифікатор `S(τ)` застосовується до топологічної динамічної системи `(K, d_K, D)`, де `K` — компактний метричний простір, `D : K → K` — неперервне.

Деталі §22.

### 6.4. Точна класифікація `Classify⁺`

**Означення 6.4.1.**

```
Classify⁺(P) := (OrbitType_D(P), InclusionType_D(P), Chaos_D(P))
```

Три компоненти відносні до **однієї** динаміки `D`.

**OrbitType_D** — шість класів (§23).

**InclusionType_D:**

```
EQUAL_IMAGE(D)               D[P] = P
DISJOINT_IMAGE(D)            D[P] ∩ P = ∅
STRICT_SUBIMAGE(D)           D[P] ⊊ P
STRICT_SUPERIMAGE(D)         P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE(D) інакше
```

**Chaos_D(P)** (предикат): визначений лише для непорожніх компактних `P` з `D[P] = P` і неперервним `D|_P`:

```
Chaos_D(P) ⟺ P мінімальна ∧ h_top(D|_P) > 0
```

### 6.5. Зв'язок точкової та множинної класифікації

**Твердження 6.5.1 (скінченна P).** Якщо `P` скінченна і `D[P] = P`, то `D|_P` — бієкція, отже `∀x ∈ P: Ω_point(x) ∈ {FIXED, PERIODIC}`.

**PROVED ON PAPER.**

**Твердження 6.5.2 (нескінченна P).** Для нескінченної `P` на `S_∞` твердження 6.5.1 хибне.

**Контрприклад (абстрактний).** `X = ℤ`, `D(n) = n+1`, `P = ℤ`.

**Контрприклад у `S_∞ × ℛ_caus` — Q28 (❓).**

## 7. Алгебра Ω

**Означення 7.1 (6-ланцюг).**

```
CHAOTIC
  < APERIODIC_NON_CHAOTIC
  < EVENTUALLY_PERIODIC
  < PERIODIC_SET
  < INVARIANT_DYNAMIC
  < INVARIANT_FIXED
```

**Застереження 7.2.** Ω — **синтаксичний** інструмент Ґратінгової алгебри. Не є класифікацією об'єктів SUBIT.

**Твердження 7.3.** Ω із `∧ = min`, `∨ = max`, релятивним псевдодоповненням `→`, `¬a := a → ⊥` — алгебра Гейтінга.

**PROVED ON PAPER.**

**Твердження 7.4.** `EVENTUALLY_PERIODIC ∨ ¬EVENTUALLY_PERIODIC = EVENTUALLY_PERIODIC ≠ INVARIANT_FIXED`.

**Застереження 7.5.** Ω самостійна; не пов'язана формально з білаттисом Белнапа.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).**

```
X := (S_X, ℛ_X, D_X, g_X)
```

де `ℛ_X ⊆ (S_X → S_X)`, `g_X : ℛ_X × S_X → ℛ_X`, і

```
D_X(s, ρ) := (ρ(s), g_X(ρ, s))
```

Обов'язкова умова узгодженості:

```
π_S(D_X(s, ρ)) = ρ(s)
π_R(D_X(s, ρ)) = g_X(ρ, s)
```

**Означення 8.2 (морфізми).** Пара `φ = (φ_S, φ_R)` з умовою:

```
φ_S(ρ(s)) = φ_R(ρ)(φ_S(s))
```

**Застереження 8.3.** Умова стосується S-компоненти.

**Означення 8.4 (SUBIT_full).** Широка підкатегорія: морфізми додатково задовольняють

```
φ_R(g_X(ρ, s)) = g_Y(φ_R(ρ), φ_S(s))
```

**Твердження 8.5.** SUBIT і SUBIT_full — категорії.

**PROVED ON PAPER.**

**Означення 8.6 (термінальний об'єкт).** `1 = ({∗}, {id}, D_triv, g_triv)`.

**Означення 8.7 (добуток).** `X × Y = (S_X × S_Y, ℛ_X × ℛ_Y, D_X × D_Y, g_X × g_Y)`.

**Застереження 8.8.** Експоненціал `Yˣ` — лише для об'єктів з оборотним `D_X`. Загальна декартова замкненість — Q1 (❓).

## 9. Dyn як категорія динамічних систем

**Означення 9.1.** Об'єкт — пара `(S, f)`, `f : S → S`; морфізм `φ ∘ f = g ∘ φ`.

**Твердження 9.2.** `Dyn ≅ Fun(ℕ, Set)`.

**PROVED ON PAPER** (Lawvere, 1964).

**Означення 9.3.** `Ω_Dyn := ℕ ∪ {∞}`; дія `n·k := max(n−k, 0)`, `∞·k := ∞`. `χ_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U}`.

**Твердження 9.4.** `χ_U` — морфізм: `χ_U(f(x)) = max(χ_U(x) − 1, 0)`.

**Твердження 9.5.** `Sub_Dyn(X) ≅ Hom_Dyn(X, Ω_Dyn)`.

**Твердження 9.6.** Dyn — топос.

**Застереження 9.7.** Топосна структура Dyn не переноситься на повну SUBIT. Q2' (❓).

## 10. Динамічна теорія типів (узгоджено з `D`)

**Судження:** `Γ ⊢ t : U @ τ`. Тип `U ⊆ C` — клас станів у конфігураційному просторі `C` з тотальною динамікою `D`.

**Правила:**

```
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ

Еволюція:        Γ ⊢ t : U@τ     D[U] ⊆ V
                 ─────────────────────────────
                 Γ ⊢ D(t) : V @ (τ+1)

Стабільність:    Γ ⊢ t : U@τ     D[U] = U
                 ───────────────────────────
                 Γ ⊢ t : □U @ τ

Потенційність:   Γ ⊢ t : U@τ     ∃k≥0: Dᵏ[U] ⊆ V
                 ───────────────────────────────
                 Γ ⊢ t : ◇V @ τ
```

**Статус:** схема; повна метатеорія збереження та повноти не підтверджена.

## 11. Модальна логіка

### 11.A. LTL-семантика

**Означення 11.A.1.** Для `x ∈ K` і `U ⊆ K`:

```
x ⊨ X U       ⟺ D(x) ∈ U
x ⊨ ◇ U       ⟺ ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U      ⟺ ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U       ⟺ ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U       ⟺ x ∈ U ∧ ∃k ≥ 2: Dᵏ(x) ∈ U
```

**Застереження 11.A.2.** `X` — примітивний оператор наступного кроку.

**Твердження 11.A.3 (аксіоми).**

```
(X1) X U → ◇⁺U
(X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)
(D1) ◇U ↔ U ∨ X ◇U
(D2) ◇⁺U ↔ X ◇U
(D3) ◇U ↔ U ∨ ◇⁺U
(B1) □U ↔ U ∧ X □U
(B2) □U → U
(B3) □U → X □U
(B4) □U → ◇U
(B5) □(U → V) → (□U → □V)
(R1) ↺U ↔ U ∧ ◇⁺(X U)
(R2) ↺U → ◇⁺U
(M4) ◇U ↔ ¬□¬U
```

**Твердження 11.A.4 (M6).** `□U → ↺U`.

**Доведення.** `□U` тягне `x ∈ U` і `D²(x) ∈ U`. ∎ **PROVED ON PAPER.**

**Застереження 11.A.5.** Якщо потрібно означати лише досягнення `U` на кроці ≥ 2 без вимоги `x ∈ U`, для цього використовується окремий оператор `◇_{≥2}U`.

### 11.B. Гейтінгова семантика

**Означення 11.B.1.** `(□_H U)(x) := ⋀_{n ≥ 0} U(Dⁿx)`, `(◇_H U)(x) := ⋁_{n ≥ 0} U(Dⁿx)`.

**Твердження 11.B.2.** `◇_H U ↔ ¬_H □_H ¬_H U` — хибне.

**Контрмодель.** `K = {a, b}`, `D(a) = b`, `D(b) = b`, `U(a) := EVENTUALLY_PERIODIC`, `U(b) := CHAOTIC`. Далі обчислення дають `INVARIANT_FIXED ≠ EVENTUALLY_PERIODIC`. ∎ **PROVED ON PAPER.**

### 11.C. Узгодження

LTL описує траєкторії; Гейтінг — алгебраїчні значення. Не змішуються.

## 12. Межі симуляції

**Твердження 12.1.** Автономний скінченний автомат `(Q, δ)`, `|Q| ≤ 64`, вкладається в SUBIT⁺ як одна траєкторія.

F_tree : Set → Set

Ψ(X) := LeafSeqs ∪ NodeSeqs(X)

## 14. Скінченні апроксимації

**Означення 14.1 (`T_n`).**

```
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) : a ∈ A }
         ∪ { Bottom_{n+1} }
         ∪ { Node_n(t₁, t₂, t₃) : t₁, t₂, t₃ ∈ T_n }
```

**Означення 14.2 (усічення `q_n`).**

```
q_0 : T_1 → T_0
q_0 (Leaf_1 a)          := Leaf_0 a
q_0 (Bottom_1)          := Bottom_0
q_0 (Node_0(t₁,t₂,t₃))  := Bottom_0

q_{n+1} : T_{n+2} → T_{n+1}
q_{n+1} (Leaf_{n+2} a)         := Leaf_{n+1} a
q_{n+1} (Bottom_{n+2})         := Bottom_{n+1}
q_{n+1} (Node_{n+1}(t₁,t₂,t₃)) := Node_n(q_n t₁, q_n t₂, q_n t₃)
```

**Лема 14.3.** `q_n(t) ∈ T_n`. **PROVED ON PAPER.**

## 15. Сумісні та продуктивні послідовності

**Означення 15.1 (`U_c`).**

```
U_c := { (t_n) ∈ ∏_n T_n : ∀n, q_n(t_{n+1}) = t_n }
```

**Застереження 15.2.** `U_c ≠ ∏_n T_n` (контрприклад: `w = (Leaf_0(a), Bottom_1, Bottom_2, …)`).

**Означення 15.3 (`LeafSeqs`, `NodeSeqs`, `Ψ`).**

```
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }

NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0
                ∧ ∃u₁,u₂,u₃ ∈ X
                ∧ ∀n ≥ 0: t_{n+1} = Node_n(u_{1,n}, u_{2,n}, u_{3,n}) }

Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Означення 15.4 (`L_prod`).**

```
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Лема 15.5.** `L_prod = Ψ(L_prod)`. **PROVED ON PAPER.**

**Лема 15.6 (принцип коіндукції).** `X ⊆ U_c ∧ X ⊆ Ψ(X) ⟹ X ⊆ L_prod`.

**Контрприклад.** `L_prod ⊊ U_c`: `(Bottom_n)_n ∈ U_c \ L_prod`.

**Лема 15.7.** Кожен `t ∈ L_prod` має рівно один Leaf- або Node-розклад.

## 16. Адресне кодування `Tree_∞`

**Означення 16.1.** `Pos := {1,2,3}^{<ω}`, `Label := A ⊔ {node}`.

**Означення 16.2 (`Tree_∞`).** Підтип `Pos → Option(Label)` з (T1)–(T4):

- **(T1)** `f(ε) ≠ None`;
- **(T2)** `f(σ) = Some(node) ⟹ f(σ·i) ≠ None`;
- **(T3)** `f(σ) = Some(leaf(a)) ⟹ f(σ·i) = None`;
- **(T4)** `f(σ) = None ⟹ f(σ·τ) = None`.

**Означення 16.3 (`out_Tree`).**

```
out_Tree(f) := inl(a)            якщо f(ε) = Some(leaf(a))
out_Tree(f) := inr(f₁, f₂, f₃)   якщо f(ε) = Some(node)
```

де `f_i(σ) := f(i·σ)`.

**Лема 16.4 (фінальність).** `(Tree_∞, out_Tree)` — фінальна коалгебра `F_tree`.

**Доведення (схема).** Для коалгебри `c : X → A ⊔ X³`:

1. `state_x : Pos ⇀ X` — часткова функція: `state_x(ε) := x`; якщо `state_x(σ) = y` і `c(y) = inr(y₁,y₂,y₃)`, то `state_x(σ·i) := y_i`; якщо `c(y) = inl(a)`, то `state_x(σ·i)` не визначено.
2. `h(x)(σ) := None` якщо `state_x(σ)` не визначено; `Some(leaf(a))` якщо `c(state_x(σ)) = inl(a)`; `Some(node)` якщо `c(state_x(σ)) = inr(...)`.

Коректність (T1)–(T4) — з побудови; коалгебраїчна рівність і єдиність — індукцією за довжиною адреси. ∎ **PROVED ON PAPER.**

**Означення 16.5.** `S_∞ := Tree_∞` — канонічний носій.

## 17. Глибинні апроксимації `d_n`

**Означення 17.1 (база).**

- `f(ε) = Some(leaf(a))` → `d_0(f) := Leaf_0(a)`;
- `f(ε) = Some(node)` → `d_0(f) := Bottom_0`.

**Означення 17.2 (крок).**

- `f(ε) = Some(leaf(a))` → `d_{n+1}(f) := Leaf_{n+1}(a)`;
- `f(ε) = Some(node)` → `d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))`.

**Лема 17.3 (типізація).** `d_n(f) ∈ T_n`.

**Лема 17.4 (сумісність).** `q_n(d_{n+1}(f)) = d_n(f)`.

**Лема 17.5 (комутація з безпосереднім піддеревом).** Якщо `f(ε) = Some(node)`, то `d_n(f_i) = (d_{n+1}(f))|_i`.

**PROVED ON PAPER.**

**Означення 17.6 (проєкції).** `p_n : Tree_∞ → T_n`, `p_n(f) := d_n(f)`.

## 18. Типізований `at_n` і стабілізація Z/L/N

**Означення 18.1 (сума рівневих типів).**

```
TΣ := Σ_{k ∈ ℕ} T_k
```

Елемент `TΣ` — пара `(k, u)`, де `u ∈ T_k`.

**Означення 18.2 (`at_n`).**

```
at_n : T_n → Pos → Option(TΣ)

at_n(t, ε)                          := Some((n, t))
at_0(t, i·τ)                        := None
at_{n+1}(Leaf_{n+1}(a), i·τ)        := None
at_{n+1}(Bottom_{n+1}, i·τ)         := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ)     := at_n(u_i, τ)
```

**Лема 18.3 (типізація).** Якщо `at_n(t, σ) = Some((k, u))`, то `|σ| ≤ n`, `k = n − |σ|`, `u ∈ T_k`. Якщо `|σ| > n` — результат `None`.

**Доведення.** Індукція за `n` і `|σ|`. ∎ **PROVED ON PAPER.**

**Лема 18.4 (стабілізація міток Z/L/N).** Для `t ∈ L_prod` і позиції `σ` виконується рівно один із:

- **Z** — `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = None`;
- **L** — `∃N, a: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Some((m−|σ|, Leaf_{m−|σ|}(a)))`;
- **N** — `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Some((m−|σ|, Node_{m−|σ|−1}(...)))`.

**Доведення.** Індукція за довжиною `σ`. Для `σ = ε` — Leaf/Node-розклад `L_prod`. Для `σ = i·τ` — редукція до дочірньої послідовності (замкненість). Взаємовиключність — за конструкторами `Leaf`/`Node`/`None`. ∎ **PROVED ON PAPER.**

**Означення 18.5 (`lim_tree`).**

```
lim_tree(t)(σ) := lim_label(t, σ)
```

де `lim_label(t, σ) := Some(leaf(a))` у випадку L; `Some(node)` у випадку N; `None` у випадку Z.

**Лема 18.6.** `lim_tree(t)` задовольняє (T1)–(T4). **PROVED ON PAPER.**

## 19. Метрика `d_S`

**Лема 19.1 (розділення).** `(∀n: d_n(f) = d_n(g)) → f = g`.

**Доведення.** Припустимо `f ≠ g`. Найкоротша адреса `σ` з `f(σ) ≠ g(σ)`. Строгі префікси мають однакові мітки, не `None` (за T4), не листки (за T3) — отже, вузли. На `σ` — різні листки або листок/вузол. Для `n > |σ|`: `d_n(f) ≠ d_n(g)`. Суперечність. ∎ **PROVED ON PAPER.**

**Означення 19.2.**

```
r(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }   якщо f ≠ g
d_S(f, g) := 0                                якщо f = g
d_S(f, g) := 2^{−r(f, g)}                     якщо f ≠ g
```

**Лема 19.3 (ультраметрика).** `d_S` — ультраметрика.

**Доведення.** Випадки рівності — безпосередньо. Для попарно різних: `m := min(r(f,g), r(g,h))`. Для `n < m`: `d_n(f) = d_n(g) = d_n(h)`, отже `r(f,h) ≥ m`, звідки `d_S(f,h) ≤ 2^{-m} = max(d_S(f,g), d_S(g,h))`. ∎ **PROVED ON PAPER.**

**Лема 19.4 (оцінка піддерев).** Для `f, g` з вузловими коренями: `d_S(f_i, g_i) ≤ 2 · d_S(f, g)`. **PROVED ON PAPER.**

## 20. Бієкція `Tree_∞ ≅ L_prod`

**Означення 20.1.** `p : Tree_∞ → L_prod`, `p(f) := (d_n(f))_n`.

**Лема 20.2 (продуктивність).** `p(f) ∈ L_prod`. **PROVED ON PAPER.**

**Означення 20.3 (`out_L`).**

```
out_L(t) := inl(a)               якщо t_n = Leaf_n(a) для всіх n
out_L(t) := inr(u₁, u₂, u₃)      якщо t_0 = Bottom_0 і t_{n+1} = Node_n(...)
```

**Теорема 20.4 (коалгебраїчний ізоморфізм).** `out_L ∘ p = F_tree(p) ∘ out_Tree`.

**PROVED ON PAPER.**

**Лема 20.5 (комутація `lim_tree` з піддеревом).** Нехай `t ∈ L_prod` з Node-розкладом і дочірніми послідовностями `u₁, u₂, u₃ ∈ L_prod`. Тоді для кожного `i` і `σ`:

```
lim_tree(t)(i·σ) = lim_tree(u_i)(σ)
```

**Доведення.** Для достатньо великих `m`: `at_m(t_m, i·σ) = at_{m−1}(u_{i,m−1}, σ)`. За стабілізацією Z/L/N обидві частини зрештою в одному випадку. Мітки збігаються. ∎ **PROVED ON PAPER.**

**Теорема 20.6 (перша тотожність).** `lim_tree(p(f)) = f` для всіх `f ∈ Tree_∞`.

**Доведення.** Показати `lim_label(p(f), σ) = f(σ)` для всіх `σ` за лемою 17.5 і типізацією `at_n`. ∎ **PROVED ON PAPER.**

**Теорема 20.7 (друга тотожність).** `p(lim_tree(t)) = t` для всіх `t ∈ L_prod`.

**Доведення.** Індукція за `n` з універсальною гіпотезою. Leaf-випадок — тривіально. Node-випадок — за лемою 20.5 і IH для трьох `u_i`. ∎ **PROVED ON PAPER.**

**Теорема 20.8 (бієкція).** `p : Tree_∞ → L_prod` — бієкція з оберненим `lim_tree`.

**Доведення.** Ін'єктивність: `p(f) = p(g) ⟹ f = lim_tree(p(f)) = lim_tree(p(g)) = g`. Сюр'єктивність: `p(lim_tree(t)) = t`. ∎ **PROVED ON PAPER.**

## 21. Повнота, цілком обмеженість, компактність

**Передумова 21.1 (`Finite A`).** `A = {T, F, B, N}`, `|A| = 4`.

**Лема 21.2 (скінченність `T_n`).** `|T_0| = |A| + 1`, `|T_{n+1}| = |A| + 1 + |T_n|³`. **PROVED ON PAPER.**

**Теорема 21.3 (повнота).** `(Tree_∞, d_S)` повний.

**Доведення (схема).** Нехай `(s_k)` — Коші. Проєкції `d_n(s_k)` стабілізуються; стабілізоване `t* = (t_n*) ∈ U_c`. Визначимо `R_C` — множину всіх покоординатних границь послідовностей Коші в `Tree_∞`. Покажемо `R_C ⊆ Ψ(R_C)`:

- **Leaf:** `t*_0 = Leaf_0(a)` → `t*_n = Leaf_n(a)` → `t* ∈ LeafSeqs`.
- **Node:** `t*_0 = Bottom_0` → на пізньому хвості корені `s_k` — вузли; дочірні послідовності Коші за лемою 19.4; визначають `u_i* ∈ R_C`; `t*_{n+1} = Node_n(u_{1,n}*, u_{2,n}*, u_{3,n}*)` → `t* ∈ NodeSeqs(R_C)`.

За принципом коіндукції: `R_C ⊆ L_prod`. Покладемо `s* := lim_tree(t*)`. За теоремою 20.7 `d_n(s*) = t_n*`. Стабілізація → `s_k → s*`. ∎ **PROVED ON PAPER.**

**Теорема 21.4 (цілком обмеженість).** Класи `C_u := {f : d_n(f) = u}` для `u ∈ T_n` — скінченне сімейство. Вибір представника з кожного непорожнього класу дає скінченну ε-мережу. **PROVED ON PAPER.**

**Теорема 21.5 (компактність).** `(Tree_∞, d_S)` компактний (повний + цілком обмежений). **PROVED ON PAPER.**

## 22. Динаміка `D∞` та класифікація

**Означення 22.1 (динаміка нескінченної моделі).** Нехай `ℛ_all := (S_∞ → S_∞)`, `g∞ : ℛ_all × S_∞ → ℛ_all`. Визначимо:

```
D∞ : S_∞ × ℛ_all → S_∞ × ℛ_all
D∞(s, ρ) := (ρ(s), g∞(ρ, s))
```

**Означення 22.2 (`Fix(D∞)`).** `{ŝ : D∞(ŝ) = ŝ}` — найбільша множина нерухомих точок. Найменша STABLE-множина — ∅.

**Означення 22.3 (область топологічної класифікації).** Система `(K, d_K, D)`, де `K` — компактний метричний простір, `D : K → K` — неперервне.

Якщо `K ⊆ S_∞ × ℛ_all`, топологія та метрика задаються явно.

**Означення 22.4 (ω-границя).** `ω_D(x) := {y ∈ K : ∃nₖ → ∞, Dⁿᵏ(x) → y}`.

**Твердження 22.5.** За компактності `K` і неперервності `D`: `ω_D(x)` непорожня, компактна, інваріантна; `dist(Dⁿ(x), ω_D(x)) → 0`.

**PROVED ON PAPER.**

**Означення 22.6 (`Att`).**

```
ATTAINED    ⟺ ∃n: Dⁿ(x) ∈ ω_D(x)
ASYMPTOTIC  ⟺ ∀n: Dⁿ(x) ∉ ω_D(x) ∧ dist(Dⁿ(x), ω_D(x)) → 0
```

**Означення 22.7 (`S(τ)`).** П'ять класів:

```
FIXED_POINT              ω = {p}, D(p) = p
PERIODIC                 ω скінченна, |ω| > 1
MINIMAL_ZERO_ENTROPY     ω нескінченна, мінімальна, h_top = 0
CHAOTIC                  ω нескінченна, мінімальна, h_top > 0
NON_MINIMAL              ω нескінченна, не мінімальна
```

**Застереження 22.8.** `MINIMAL_CANTOR` (попередні редакції) замінено на `MINIMAL_ZERO_ENTROPY`.

**Означення 22.9 (`Ω_traj`).** `Ω_traj := S(τ) × Att(τ)`.

**Означення 22.10 (три рівні сертифікації).**

```
PREFIX_CERTIFIED(N)          — префікс довжини N
GLOBAL_EXACT_CERTIFIED       — вся траєкторія
APPROXIMATION_CONVERGED(N)   — числовий критерій на N
```

**Означення 22.11 (COMPUTED / RESOURCE_EXCEEDED).** Окреме поле.

**Означення 22.12 (CHAOTIC у ℛ_caus).** Для `ρ ∈ ℛ_caus` з `g ≡ id`: `h_top(ω_D(x)) = 0` (Bowen, 1971). Для `g ≠ id` — Q10 (❓).

**Означення 22.13 (`P(τ)`).**

```
P(τ) := ( ω_D(x), Ω_traj(τ), certificate )
```

**Означення 22.14 (типологія предикатів префікса).**

Для предиката `φ(k, τ)`:

- **PH**: `Φ_PH(N) := ∀k ≤ N: φ(k, τ)`; `Φ_PH(N+1) ⟹ Φ_PH(N)`.
- **EP**: `Φ_EP(N) := ∃k ≤ N: φ(k, τ)`; `Φ_EP(N) ⟹ Φ_EP(N+1)`.

- **GP**: `Ψ(τ)` — глобальна властивість.

## 23. Шість динамічних класів (виправлено)

**Означення 23.1 (`μ, π, p_set`).**

```
μ(P) := min{ m ≥ 0 : ∃n > m: Dᵐ[P] = Dⁿ[P] }       (∞ якщо немає)
π(P) := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }  (∞ якщо μ = ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                (∞ якщо немає)
```

**Означення 23.2 (шість класів).**

```
INVARIANT_FIXED(P)        ⟺ D[P] = P ∧ ∀x ∈ P: D(x) = x
INVARIANT_DYNAMIC(P)      ⟺ D[P] = P ∧ ∃x ∈ P: D(x) ≠ x
PERIODIC_SET(P)           ⟺ 2 ≤ p_set(P) < ∞
EVENTUALLY_FIXED(P)       ⟺ 1 ≤ μ(P) < ∞ ∧ π(P) = 1
EVENTUALLY_PERIODIC(P)    ⟺ 1 ≤ μ(P) < ∞ ∧ 2 ≤ π(P) < ∞
APERIODIC(P)              ⟺ μ(P) = ∞
```

**Твердження 23.3.** Шість класів попарно не перетинаються і вичерпують `2^K ∖ {∅}`.

**PROVED ON PAPER.**

**ВІДКЛИКАНО:** попереднє означення `EVENTUALLY_PERIODIC(P) ⟺ μ(P) ≥ 1 ∧ π(P) ≥ 2`, яке при `μ = ∞` могло перетинатися з `APERIODIC`.

## 24. Топологія простору правил

**Означення 24.1 (`ℛ_caus`).**

```
ℛ_caus := { ρ : S_∞ → S_∞ : ∀s,t, d_S(ρ(s), ρ(t)) ≤ d_S(s,t) }
```

**Означення 24.2 (`ℛ_comp`).** Функції зі скінченним обчислюваним описом у фіксованій моделі.

**Означення 24.3 (рівномірна метрика).**

```
d_R(ρ, σ) := sup_{s ∈ S_∞} d_S(ρ(s), σ(s))
```

Скінченна (бо `S_∞` компактний, `d_S` обмежена).

**Теорема 24.4.** `(ℛ_caus, d_R)` компактний.

**Доведення.** Усі `ρ ∈ ℛ_caus` 1-ліпшицеві, отже сімейство рівностепенево неперервне. За Арцела–Асколі — компактне замикання в рівномірній топології. Рівномірна границя 1-ліпшицевих — 1-ліпшицева, тому `ℛ_caus` замкнене. Отже компактний. Метричний — гаусдорфовий. ∎ **PROVED ON PAPER.**

**Застереження 24.5.** Попереднє подання `ℛ₀ ≅ lim←(T_n)^{T_n}` відкликано: `T_n` містить `Bottom_n`, які не в образі `d_n`; довільні функції не зобов'язані поважати `q_n`.

**Наслідок 24.6 (кардинальності).** `|S_∞| = 2^{ℵ₀}`; `|ℛ_caus| = 2^{ℵ₀}`; `|ℛ_comp| = ℵ₀`.

**Q25 (переформульовано).** Чи є `ℛ_comp ∩ ℛ_caus` щільною в `ℛ_caus` за `d_R`?
