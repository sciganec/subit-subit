## 1. Структурні означення

### 1.1. Базова множина і функтор

**Передумова 1.1.1 (скінченність `A`).** `A` — скінченна множина. У канонічній чотиризначній моделі Белнапа `A = {T, F, B, N}`, `|A| = 4`. Ця передумова використовується в доведеннях цілком обмеженості та компактності (§5).

**Означення 1.1.2 (деревний функтор `F`).**

```
F(X) := A ⊔ X³
```

Функтор на категорії множин. Його фінальну коалгебру позначатимемо `νF`.

**Означення 1.1.3 (оператор продуктивності `Ψ`).** На `𝒫(U_c)`:

```
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

де `U_c`, `LeafSeqs`, `NodeSeqs` — з CE-10j.0.1.

**Застереження 1.1.4.** `F` (функтор) і `Ψ` (оператор) — різних типів. `F` діє на множинах, `Ψ` — на підмножинах `U_c`. Їх не можна позначати одним символом. Попередній символ `Φ` розділено: `F` для функтора, `Ψ` для оператора.

### 1.2. Сумісні і продуктивні послідовності

**Означення 1.2.1 (`T_n`, `q_n`).** Як у v6.8.24 §13.3.2, §13.3.4, з виправленням `q_0(Bottom_1) = Bottom_0`.

**Означення 1.2.2 (`U_c`).**

```
U_c := { (t_n) ∈ ∏_n T_n : ∀n ≥ 0, q_n(t_{n+1}) = t_n }
```

**Застереження 1.2.3.** `U_c ≠ ∏_n T_n`. Контрприклад: `(Bottom_0, Bottom_1, …) ∈ U_c`, але він не належить жодному `L_prod` (див. §1.5).

**Означення 1.2.4 (`L_prod`).**

```
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Лема 1.2.5.** `L_prod = Ψ(L_prod)`.

**Доведення.** CE-10j.0.2.1. ∎

**PROVED ON PAPER.**

**Лема 1.2.6 (принцип коіндукції).** Якщо `X ⊆ U_c` і `X ⊆ Ψ(X)`, то `X ⊆ L_prod`.

**PROVED ON PAPER.**

**Контрприклад.** `L_prod ⊊ U_c`: послідовність `(Bottom_0, Bottom_1, …) ∈ U_c \ L_prod`.

### 1.3. Адресне кодування `Tree_∞`

**Означення 1.3.1.** `Pos := {1,2,3}^{<ω}`, `Label := A ⊔ {node}`.

**Означення 1.3.2 (`Tree_∞`).** Підтип `Pos → Option(Label)` з умовами (T1)–(T4) (CE-10i.1.3):

- (T1) `f(ε) ≠ None`;
- (T2) `f(σ) = Some(node)` ⟹ `f(σ·i) ≠ None` для `i ∈ {1,2,3}`;
- (T3) `f(σ) = Some(leaf(a))` ⟹ `f(σ·i) = None` для `i ∈ {1,2,3}`;
- (T4) `f(σ) = None` ⟹ `f(σ·τ) = None` для всіх `τ`.

**Означення 1.3.3 (`out_Tree`).**

```
out_Tree : Tree_∞ → A ⊔ Tree_∞³
out_Tree(f) := inl(a)                якщо f(ε) = Some(leaf(a))
out_Tree(f) := inr(f₁, f₂, f₃)       якщо f(ε) = Some(node)
```

де `f_i(σ) := f(i·σ)`.

### 1.4. Фінальність `Tree_∞` (CE-10j-R3 §R3.1)

**Означення 1.4.1 (стан за адресою).** Нехай `c : X → A ⊔ X³` — коалгебра `F`. Визначимо часткову функцію `state_x : Pos ⇀ X` рекурсивно:

- `state_x(ε) := x`;
- якщо `state_x(σ) = y` і `c(y) = inr(y₁,y₂,y₃)`, то `state_x(σ·i) := yᵢ` для `i ∈ {1,2,3}`;
- якщо `state_x(σ) = y` і `c(y) = inl(a)`, то `state_x(σ·i)` не визначено;
- якщо `state_x(σ)` не визначено, то `state_x(σ·i)` також не визначено.

**Означення 1.4.2 (фінальний морфізм `h`).**

```
h(x)(σ) := None                    якщо state_x(σ) не визначено
h(x)(σ) := Some(leaf(a))           якщо state_x(σ) = y, c(y) = inl(a)
h(x)(σ) := Some(node)              якщо state_x(σ) = y, c(y) = inr(...)
```

**Лема 1.4.3 (коректність адресного кодування).** `h(x) ∈ Tree_∞` для всіх `x ∈ X`.

**Доведення.** (T1) `state_x(ε) = x`. (T2) якщо `h(x)(σ) = Some(node)`, то `c(state_x(σ)) = inr(...)`, отже всі три дочірні стани визначені. (T3) якщо `h(x)(σ) = Some(leaf(a))`, то `c(state_x(σ)) = inl(a)`, отже нащадки не визначені. (T4) якщо `state_x(σ)` не визначено, то всі нащадки також. ∎

**PROVED ON PAPER.**

**Лема 1.4.4 (коалгебраїчна рівність).** `out_Tree(h(x)) = F(h)(c(x))` для всіх `x ∈ X`.

**Доведення.** Розбір `c(x) = inl(a)` і `c(x) = inr(x₁,x₂,x₃)`. ∎

**PROVED ON PAPER.**

**Лема 1.4.5 (єдиність).** Якщо `g : X → Tree_∞` задовольняє `out_Tree ∘ g = F(g) ∘ c`, то `g = h`.

**Доведення.** Індукція за довжиною адреси `σ`. База — коренева мітка визначається `c(x)`. Крок — мітка за адресою `i·σ` визначається значенням `xᵢ`. ∎

**PROVED ON PAPER.**

**Теорема 1.4.6 (фінальність).** `(Tree_∞, out_Tree)` — фінальна коалгебра `F`.

**PROVED ON PAPER.**

### 1.5. Друга модель `L_prod` (CE-10j-R2 §R2.4)

**Означення 1.5.1 (`out_L`).** Як у CE-10j-R2 §R2.4: `out_L : L_prod → A ⊔ L_prod³`.

**Лема 1.5.2.** `(L_prod, out_L)` — коалгебра `F`.

**PROVED ON PAPER.**

**Теорема 1.5.3 (коалгебраїчний ізоморфізм).** `p : Tree_∞ → L_prod` — коалгебраїчний ізоморфізм:

```
out_L ∘ p = F(p) ∘ out_Tree
```

**Доведення.** CE-10j.6.1–6.3 (бієкція) і CE-10j-R2 §R2.4.1 (збереження структури). ∎

**PROVED ON PAPER.**

**Наслідок 1.5.4.** `Tree_∞` і `L_prod` — **ізоморфні моделі** фінальної коалгебри `F`, а не «тотожні».

**Означення 1.5.5.** `S_∞ := Tree_∞` — конкретний носій.

## 2. Проєкції та глибинні апроксимації

### 2.1. Рекурсивне `d_n` (CE-10j.1.1)

**Означення 2.1.1 (база).** Для `f ∈ Tree_∞`:

- `f(ε) = Some(leaf(a))` → `d_0(f) := Leaf_0(a)`;
- `f(ε) = Some(node)` → `d_0(f) := Bottom_0`.

**Означення 2.1.2 (крок).** Для `n ≥ 0`:

- `f(ε) = Some(leaf(a))` → `d_{n+1}(f) := Leaf_{n+1}(a)`;
- `f(ε) = Some(node)` → `d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))`.

**Лема 2.1.3 (типізація).** `d_n(f) ∈ T_n`.

**Лема 2.1.4 (сумісність).** `q_n(d_{n+1}(f)) = d_n(f)`.

**PROVED ON PAPER** (CE-10j.1.2–1.3).

### 2.2. Проєкції

**Означення 2.2.1.** `p_n : Tree_∞ → T_n`, `p_n(f) := d_n(f)`.

**Застереження 2.2.2.** У v6.8.24 §13.3.6 `p_n` визначено рекурсивно для абстрактного `S_∞` з конструкторами. У цій редакції `p_n := d_n` для адресного кодування. Факторизація `q_n ∘ p_{n+1} = p_n` випливає з Леми 2.1.4.

## 3. Метрика `d_S`

### 3.1. Розділення дерев (CE-10j-R3 §R3.3)

**Лема 3.1.1 (відображення адрес у апроксимацію).** Для `f ∈ Tree_∞`, `σ ∈ Pos`, `n > |σ|`:

- `f(σ) = Some(leaf(a))` → `at_n(d_n(f), σ) = Some(Leaf_{n-|σ|}(a))`;
- `f(σ) = Some(node)` → `at_n(d_n(f), σ)` має кореневий конструктор `Node_{n-|σ|-1}`;
- `f(σ) = None` → `at_n(d_n(f), σ) = None`.

**Доведення.** Індукція за `|σ|`. База — рекурсивне `d_n`. Крок — для листка шлях недосяжний; для вузла — індукція за `f_i` і комутація. Випадок `None` — через найкоротший префікс, що є листком (за (T2)–(T4)). ∎

**PROVED ON PAPER.**

**Лема 3.1.2 (розділення).** Для `f, g ∈ Tree_∞`:

```
(∀n ≥ 0: d_n(f) = d_n(g)) → f = g
```

**Доведення.** Припустимо `f ≠ g`. Виберемо найкоротшу адресу `σ`, на якій `f(σ) ≠ g(σ)`. Усі строгі префікси `σ` мають однакові мітки. Вони не можуть бути `None` (за T4 обидва дерева були б невизначені при `σ`) або листками (за T3 нащадки були б невизначені). Отже, строгі префікси — вузли. На позиції `σ` розбіжність — або різні листки, або листок vs вузол. За Лемою 3.1.1 апроксимації `d_n` для `n > |σ|` зберігають цю розбіжність: `d_n(f) ≠ d_n(g)`. Суперечність. ∎

**PROVED ON PAPER.**

**Наслідок 3.1.3.** Для `f ≠ g` множина `{n : d_n(f) ≠ d_n(g)}` непорожня.

### 3.2. Визначення `d_S` і ультраметрика (CE-10j-R3 §R3.4)

**Означення 3.2.1.**

```
r(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }    якщо f ≠ g
d_S(f, g) := 0                                 якщо f = g
d_S(f, g) := 2^{−r(f, g)}                      якщо f ≠ g
```

**Лема 3.2.2 (ультраметрична нерівність).** Для всіх `f, g, h ∈ Tree_∞`:

```
d_S(f, h) ≤ max(d_S(f, g), d_S(g, h))
```

**Доведення.** Нехай `m := min(r(f, g), r(g, h))`. Для кожного `n < m`: `d_n(f) = d_n(g)` і `d_n(g) = d_n(h)`, отже `d_n(f) = d_n(h)`. Тому `r(f, h) ≥ m`. Отже, `d_S(f, h) ≤ 2^{−m} = max(d_S(f, g), d_S(g, h))`. Випадки `f = h`, `f = g`, `g = h` — безпосередньо. ∎

**PROVED ON PAPER.**

**Наслідок 3.2.3.** `d_S` — ультраметрика на `Tree_∞` (невід'ємність, симетрія, розділення, сильна нерівність трикутника).

**Лема 3.2.4 (оцінка піддерев).** Для `f, g` з вузловими коренями:

```
d_S(f_i, g_i) ≤ 2 · d_S(f, g)
```

**Доведення.** CE-10j.7.1. ∎

**PROVED ON PAPER.**

## 4. Бієкція `Tree_∞ ≅ L_prod`

**Означення 4.1.** `p : Tree_∞ → L_prod`, `p(f) := (d_n(f))_n`.

**Лема 4.2.** `p(f) ∈ L_prod`.

**Доведення.** CE-10j.4.2. ∎

**Означення 4.3.** `lim_tree : L_prod → Tree_∞` — через стабілізацію міток (CE-10j.3.3–3.4).

**Теорема 4.4 (перша тотожність).** `lim_tree(p(f)) = f`.

**Теорема 4.5 (друга тотожність).** `p(lim_tree(t)) = t`.

**Теорема 4.6 (бієкція).** `p : Tree_∞ → L_prod` — бієкція.

**Доведення.** CE-10j.6.1–6.3. ∎

**PROVED ON PAPER.**

## 5. Повнота, цілком обмеженість, компактність

### 5.1. Скінченність `T_n` (CE-10j-R3 §R3.2)

**Лема 5.1.1 (скінченність `T_0`).** `|T_0| = |A| + 1 < ∞` за передумовою 1.1.1.

**Лема 5.1.2 (індукція).** `|T_{n+1}| = |A| + 1 + |T_n|³`.

**Доведення.** За диз'юнктністю конструкторів `Leaf_{n+1}`, `Bottom_{n+1}`, `Node_n`. ∎

**PROVED ON PAPER.**

**Наслідок 5.1.3.** `Finite(T_n)` для всіх `n ≥ 0`.

### 5.2. Цілком обмеженість

**Теорема 5.2.1.** `(Tree_∞, d_S)` цілком обмежений.

**Доведення.** Класи `C_u := {f : d_n(f) = u}` для `u ∈ T_n` — скінченне сімейство (бо `T_n` скінченна). Виберемо по представнику з кожного непорожнього класу. Якщо `f, g ∈ C_u`, то `d_m(f) = d_m(g)` для всіх `m ≤ n` (за сумісністю), отже `d_S(f, g) ≤ 2^{−(n+1)}`. Для `ε > 0` вибираємо `n` з `2^{−(n+1)} < ε`. ∎

**PROVED ON PAPER** (за передумови `Finite A`).

### 5.3. Повнота

**Теорема 5.3.1.** `(Tree_∞, d_S)` повний.

**Доведення.** CE-10j.8.3 + CE-10j-R1 §R4 (множник 2 у Коші). ∎

**PROVED ON PAPER.**

### 5.4. Компактність

**Теорема 5.4.1.** `(Tree_∞, d_S)` компактний.

**Доведення.** Повний + цілком обмежений. ∎

**PROVED ON PAPER** (за передумови `Finite A`).
