## Анотація

SUBIT-∞ — формальна нотаційна система для опису станів, переходів, правил еволюції та метаеволюції динамічних систем. Архітектура кумулятивна:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-CAT  ⊂  SUBIT-∞
```

**SUBIT-64** — скінченний алфавіт із 64 станів. **SUBIT⁺** — правило еволюції як компонента стану разом з оператором метаеволюції. **SUBIT-CAT** — категоріальний рівень із трьома незалежними класифікаторами (`Ω_set`, `Ω_point`, `S(τ)`), динамічною теорією типів і модальною логікою. **SUBIT-∞** — нескінченний простір рекурсивних дерев із мітками, у якому хаотична динаміка вперше стає математично змістовною.

**Ключові архітектурні рішення.**

1. Три класифікатори розділені: поведінка множин, поведінка точок, ω-гранична поведінка траєкторій.
2. Функтор `F(X) = A ⊔ X³` і оператор продуктивності `Ψ` — різних типів і не ототожнюються.
3. Обернена границя `U_c = lim←(T_n, q_n)` **строго більша** за фінальну коалгебру `S_∞`. Правильна бієкція — `Tree_∞ ≅ L_prod` для продуктивного підпростірства `L_prod ⊊ U_c`.
4. Компактність `S_∞` доводиться **прямо** через повноту та цілковиту обмеженість (класи `C_u`), без використання хибної бієкції з `U_c`.

**Обмеження.** Наведені математичні означення не означають, що всі заявлені теореми формально доведені в Lean 4. Статус «доведено на папері» не еквівалентний машинно перевіреному доказу.

# Частина I. SUBIT-64 — скінченний алфавіт станів

## 1. Алфавіт примітивів

**Означення 1.1.** Базовий алфавіт:

```
A = {00, 01, 10, 11},   |A| = 4
```

**Семантична реалізація:**

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація — білаттис Белнапа:**

```
𝔸 = { T, F, B, N }
```

де `T` = True, `F` = False, `B` = Both, `N` = Neither.

**Відповідність кодів:**

| Bigram | Логічна | Семантична мітка |
|:---|:---|:---|
| 10 | T | ME / EAST / SPRING |
| 11 | B | WE / SOUTH / SUMMER |
| 01 | F | YOU / WEST / AUTUMN |
| 00 | N | THEY / NORTH / WINTER |

**Білаттисна структура.** Порядок істинності:

```
F <ₜ N <ₜ T
F <ₜ B <ₜ T
```

Порядок інформації:

```
N <ᵢ F <ᵢ B
N <ᵢ T <ᵢ B
```

Ця структура використовується для логічних операцій. Її властивості **не переносяться автоматично** на динаміку `S_∞`. Кожне перенесення потребує окремого означення.

**Статус:** базова алгебраїчна структура визначена; прикладні інтерпретації не є емпіричними фактами.

## 2. Простір станів S₀

**Означення 2.1.**

```
S₀ = A × A × A,   |S₀| = 4³ = 64
```

Кожен стан — трійка `s = (α, β, γ)`. 6-бітний код: `b₁b₂b₃b₄b₅b₆`, де `b₁b₂` = WHO, `b₃b₄` = WHERE, `b₅b₆` = WHEN.

**Числове кодування:**

```
code6(s) := 32·w₂ + 16·w₁ + 8·h₂ + 4·h₁ + 2·t₂ + t₁ ∈ [0, 63]
```

**Приклади:**

- `101010` = ME / EAST / SPRING = 42;
- `111111` = WE / SOUTH / SUMMER = 63;
- `010001` = YOU / NORTH / AUTUMN = 17.

**Гексаграмна нотація** (Додаток A) — компактний запис 6-бітного слова. Традиційне тлумачення гексаграм І-Цзін **не є** аксіомою SUBIT.

**Статус:** SUBIT-64 — статичний алфавіт. Він не містить оператора переходу, не визначає траєкторій, не гарантує динамічної поведінки.

# Частина II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.**

```
ℛ = { ρ₁, ρ₂, …, ρₙ },   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширений стан:

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

**Застереження 3.3.** SUBIT⁺ із фіксованим скінченним простором еквівалентний автономному детермінованому скінченному автомату з `|Q| = |S₀ × ℛ|`. Твердження «правило належить стану» — структурна зміна представлення, а не доведення сильнішої виразності. Для сильнішої тези потрібен додатковий механізм: необмежена пам'ять, зовнішній вхід, динамічне розширення простору станів.

## 4. Оператор еволюції та метаеволюція

**Означення 4.1.**

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

де:

- `f_ρ : S₀ → S₀` — застосування поточного правила до стану;
- `g : ℛ × S₀ → ℛ` — метаеволюція: як правило змінюється залежно від поточного правила й стану.

**Аксіома 4.2 (тотальність).** У базовій детермінованій моделі `F` — тотальна функція.

Якщо реалізація допускає невизначені переходи, помилки виконання чи ресурсне переривання — вони подаються **окремим шаром обчислювального статусу**. Не можна мовчки трактувати частковий оператор як тотальний.

**Рівні опису:**

```
Рівень 0:   s = (α, β, γ)      базовий стан
Рівень 1:   ŝ = (s, ρ)         стан із внутрішнім правилом
Рівень 2:   F(ŝ) = (s′, ρ′)    еволюція за крок
Рівень 3:   g(ρ, s) → ρ′       метаеволюція
```

Це різні способи опису однієї архітектури, не автоматична ієрархія обчислювальної потужності.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.**

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),   ŝₙ₊₁ = F(ŝₙ)
```

### 5.1. Скінченна періодичність

**Твердження 5.1.1.** Оскільки `S₀ × ℛ` скінченний, а `F` — детермінована тотальна функція, для будь-якого `ŝ₀` існують `m ≥ 0`, `k ≥ 1`: `ŝ_{m+k} = ŝ_m`.

**Доведення.** Принцип Діріхле: нескінченна послідовність у скінченній множині обов'язково повторює стан. ∎

**PROVED ON PAPER.**

### 5.2. Точкова категорія

**Означення 5.2.1.**

```
Ω_point(ŝ) :=
   FIXED           якщо F(ŝ) = ŝ
   PERIODIC(p)     якщо p := min{ k > 1 : Fᵏ(ŝ) = ŝ } існує
   PREPERIODIC     інакше
```

**Застереження 5.2.2.** Клас `PREPERIODIC` — формальна назва передперіодичної точки. Термін `TRANSIENT` **не використовується** у формальному означенні. Клас `CHAOTIC` **не є** точковим класом.

**FIXED** і **PERIODIC(p)** взаємовиключні (`p = 1` виключено з PERIODIC).

### 5.3. Алгоритм скінченної класифікації

```
Вхід: ŝ₀, горизонт N_max ≥ |S₀ × ℛ|
Вихід: (category, m, p, attractor_cycle)

visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ]
        p ← n − m
        attractor_cycle ← [ŝ_m, …, ŝ_{n-1}]
        category ←
            FIXED           якщо m = 0 і p = 1
            PERIODIC(p)     якщо m = 0 і p > 1
            PREPERIODIC     якщо m > 0
        повернути (category, m, p, attractor_cycle)
    visited[ŝₙ] ← n
    ŝₙ₊₁ ← F(ŝₙ)
повернути RESOURCE_EXCEEDED
```

**Приклад.** `F(a) = b, F(b) = b`:

- `ŝ₀ = a`: `m = 1, p = 1`, category = `PREPERIODIC`, attractor = `[b]`;
- `ŝ₀ = b`: `m = 0, p = 1`, category = `FIXED`.

### 5.4. Відкликане ототожнення

**ВІДКЛИКАНО:** ототожнення `PREPERIODIC` із `CHAOTIC`. Передперіодичність — звичайна поведінка скінченного автомата. «Хаотичність» у SUBIT-∞ має окреме визначення через ω-граничну динаміку (§22).

# Частина III. SUBIT-CAT — категорія, класифікатори та логіка

## 6. Три класифікатори

Класифікатори визначені на різних математичних об'єктах. Їх не можна використовувати взаємозамінно.

### 6.1. Класифікатор множин `Ω_set`

**Означення 6.1.1.** Нехай `P ⊆ S_∞ × ℛ`, `F(P) := {F(x) : x ∈ P}`. Клас стабільності `P`:

```
STABLE       ⟺ F(P) = P
METASTABLE   ⟺ F(P) ⊊ P                         (строга власна підмножина)
CYCLIC       ⟺ ∃ мінімальне k > 1: Fᵏ(P) = P, і F(P) ≠ P
CHAOTIC      ⟺ F(P) ⊄ P і ∀k > 1: Fᵏ(P) ≠ P
```

**Застереження 6.1.2 (пріоритетний розподіл).** Формула `CHAOTIC` не охоплює випадок `F(P) ⊊ P`, який уже належить `METASTABLE`. Для взаємовиключності визначення застосовуються як **пріоритетний розподіл**: STABLE → METASTABLE → CYCLIC → CHAOTIC.

**Означення 6.1.3 (семантична істина).** `P` істинне ⟺ `F(P) = P`. Це внутрішній критерій: не апелює до зовнішнього спостерігача.

### 6.2. Точковий класифікатор `Ω_point`

`Ω_point(ŝ) ∈ {FIXED, PERIODIC, PREPERIODIC}` (§5.2). `CHAOTIC` не є точковим класом.

### 6.3. Класифікатор ω-границь `S(τ)`

П'ять класів (§22.5): `FIXED_POINT`, `PERIODIC`, `MINIMAL_ZERO_ENTROPY`, `CHAOTIC`, `NON_MINIMAL`. Класифікація **ω-границь окремих траєкторій**, не довільних інваріантних множин.

### 6.4. Точна класифікація `Classify⁺`

**Означення 6.4.1.**

```
Classify⁺(P) := (OrbitType(P), InclusionType(P), Chaos(P))
```

Три незалежні складові.

**OrbitType** (§23) — шість класів: `INVARIANT_FIXED`, `INVARIANT_DYNAMIC`, `PERIODIC_SET(p)`, `EVENTUALLY_FIXED`, `EVENTUALLY_PERIODIC`, `APERIODIC`.

**InclusionType** — п'ять класів:

```
EQUAL_IMAGE                F(P) = P
DISJOINT_IMAGE             F(P) ∩ P = ∅
STRICT_SUBIMAGE            F(P) ⊊ P
STRICT_SUPERIMAGE          P ⊊ F(P)
OVERLAPPING_NONCOMPARABLE  інакше
```

**Chaos** — предикат:

```
Chaos(P) ⟺ F(P) = P
          ∧ P компактна
          ∧ P мінімальна (не містить власної непорожньої
                          замкненої F-інваріантної підмножини)
          ∧ h_top(P, F|_P) > 0
```

**Застереження 6.4.2.** `CHAOTIC` — предикат, не значення `OrbitType` і не клітинка `Ω`. Співіснує лише з `OrbitType`, для якого `P` інваріантна.

### 6.5. Зв'язок точкової та множинної класифікації

**Твердження 6.5.1 (скінченна P).** Якщо `P` скінченна і `F(P) = P`, то обмеження `F|_P` — сюр'єкція скінченної множини на себе, отже бієкція. Тому `∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}`.

**PROVED ON PAPER.**

**Твердження 6.5.2 (нескінченна P).** Для нескінченної `P` на `S_∞` твердження 6.5.1 хибне.

**Контрприклад (абстрактний).** `X = ℤ`, `F(n) = n+1`, `P = ℤ`. `F(P) = P`, але жодна точка не повертається: `Fᵏ(n) = n+k ≠ n` для `k ≥ 1`.

**Контрприклад у `S_∞ × ℛ₀` — Q28 (❓).**

## 7. Алгебра Ω

**Означення 7.1 (6-ланцюг).**

```
CHAOTIC
  < APERIODIC_NON_CHAOTIC
  < EVENTUALLY_PERIODIC
  < PERIODIC_SET
  < INVARIANT_DYNAMIC
  < INVARIANT_FIXED
```

**Застереження 7.2.** Ω — **синтаксичний** інструмент Ґратінгової алгебри. Не є класифікацією об'єктів SUBIT. Класифікація — `Classify⁺` (§6.4).

**Твердження 7.3.** Ω із операціями `∧ = min`, `∨ = max`, `→` (релятивне псевдодоповнення: `a → b := ⊤` якщо `a ≤ b`, інакше `b`), `¬a := a → ⊥` — **алгебра Гейтінга** (логіка Геделя–Даммета).

**PROVED ON PAPER.** Будь-який скінченний ланцюг є алгеброю Гейтінга.

**Твердження 7.4 (недосяжність виключеного третього).**

```
EVENTUALLY_PERIODIC ∨ ¬EVENTUALLY_PERIODIC = EVENTUALLY_PERIODIC ≠ INVARIANT_FIXED
```

**Застереження 7.5.** Ω — самостійна алгебра; не пов'язана формально з білаттисом Белнапа на `𝔸`.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).**

```
X = (S_X, ℛ_X, F_X, g_X)
```

де:

- `S_X` — простір станів;
- `ℛ_X ⊆ {f : S_X → S_X}` — допустимі правила;
- `F_X : S_X × ℛ_X → S_X × ℛ_X` — оператор переходу;
- `g_X : ℛ_X × S_X → ℛ_X` — метаеволюція.

**Означення 8.2 (морфізми).** Пара `φ = (φ_S, φ_ℛ)`, де `φ_S : S_X → S_Y`, `φ_ℛ : ℛ_X → ℛ_Y`, що задовольняє **умову динамічної сумісності**:

```
∀(s, ρ) ∈ S_X × ℛ_X:
   φ_S(π_S(F_X(s, ρ))) = π_S(F_Y(φ_S(s), φ_ℛ(ρ)))
```

де `π_S(s, ρ) := s`, `π_ℛ(s, ρ) := ρ`.

**Застереження 8.3.** Умова стосується **лише S-компоненти** `F`. Компонента `g_X` не входить до умови морфізму SUBIT.

**Означення 8.4 (SUBIT_full).** Широка підкатегорія SUBIT: ті самі об'єкти; морфізми додатково задовольняють:

```
∀(s, ρ) ∈ S_X × ℛ_X:
   φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s))
```

**Твердження 8.5.** SUBIT і SUBIT_full — категорії.

**Доведення.** Асоціативність композиції та нейтральність тотожного морфізму спадкуються від функцій покомпонентно. ∎

**PROVED ON PAPER.**

**Означення 8.6 (термінальний об'єкт).** `1 = ({∗}, {id}, F_triv, g_triv)`, де `F_triv(∗, id) := (∗, id)`, `g_triv(id, ∗) := id`.

**Твердження 8.7.** `1` — термінальний об'єкт.

**Означення 8.8 (добуток).** `X × Y = (S_X × S_Y, ℛ_X × ℛ_Y, F_X × F_Y, g_X × g_Y)`.

**Твердження 8.9.** `X × Y` — добуток.

**Застереження 8.10.** Експоненціал `Yˣ` визначений **лише для об'єктів з оборотним** `F_X`. Загальна декартова замкненість — **Q1** (❓).

## 9. Dyn як категорія динамічних систем

**Означення 9.1.** Об'єкт Dyn — пара `(S, f)`, `f : S → S`. Морфізм `φ : (S, f) → (T, g)` — функція `φ : S → T` з `φ ∘ f = g ∘ φ`.

**Твердження 9.2.** `Dyn ≅ Fun(ℕ, Set)` (категорія множин із дією моноїда `ℕ`; `n · s := fⁿ(s)`).

**PROVED ON PAPER** (Lawvere, 1964).

**Означення 9.3 (класифікатор).** `Ω_Dyn := ℕ ∪ {∞}`; дія моноїда: `n · k := max(n − k, 0)`, `∞ · k := ∞`. Час входу:

```
χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U }   (∞ якщо ніколи)
```

**Твердження 9.4.** `χ_U` — морфізм Dyn: `χ_U(f(x)) = max(χ_U(x) − 1, 0)`.

**Твердження 9.5 (повнота).** `Sub_Dyn(X) → Hom_Dyn(X, Ω_Dyn)`, `U ↦ χ_U` — бієкція.

**PROVED ON PAPER** (стандартний результат для топосу прешейвів).

**Твердження 9.6.** Dyn — топос.

**Застереження 9.7.** Топосна структура Dyn **не переноситься автоматично** на повну категорію SUBIT. **Q2'** (❓): чи існує категорія `C` з `Dyn ⊆ C ⊆ SUBIT`, яка є топосом і зберігає нетривіальну метаеволюцію?

## 10. Динамічна теорія типів

**Судження:** `Γ ⊢ t : A @ τ` — у контексті `Γ` терм `t` має тип `A` у часовому стані `τ`. Тип `A` — клас траєкторій зі спільним режимом стабільності.

**Правила виведення:**

```
Рефлексивність:    Γ, x:A@τ ⊢ x : A@τ

Еволюція:          Γ ⊢ t:A@τ     F(A) ⊆ B
                   ─────────────────────────
                   Γ ⊢ F(t) : B @ (τ+1)

Стабільність:      Γ ⊢ t:A@τ     F(A) = A
                   ─────────────────────────
                   Γ ⊢ t : □A @ τ

Потенційність:     Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   ────────────────────────────
                   Γ ⊢ t : ◇B @ τ
```

**Статус:** схема визначена; повна метатеорія збереження та повноти **не підтверджена**.

## 11. Модальна логіка

### 11.A. LTL-подібна семантика траєкторій

**Означення 11.A.1.** Для `ŝ ∈ S_∞ × ℛ` і `A ⊆ S_∞ × ℛ`:

```
ŝ ⊨ X A       ⟺   F(ŝ) ∈ A                    (наступний крок)
ŝ ⊨ ◇ A       ⟺   ∃n ≥ 0: Fⁿ(ŝ) ∈ A            (колись)
ŝ ⊨ ◇⁺ A      ⟺   ∃n ≥ 1: Fⁿ(ŝ) ∈ A            (колись у майбутньому)
ŝ ⊨ □ A       ⟺   ∀n ≥ 0: Fⁿ(ŝ) ∈ A            (завжди)
ŝ ⊨ ↺ A       ⟺   ∃k > 1: Fᵏ(ŝ) ∈ A            (повернення через k > 1)
```

**Застереження 11.A.2.** `X` — примітивний оператор «наступний крок», **не ототожнюється** з `↺`.

**Твердження 11.A.3 (аксіоми).**

```
(X1)   X A → ◇⁺A
(X2)   X A ∧ X B ↔ X(A ∧ B)
(X3)   X A ∨ X B ↔ X(A ∨ B)
(D1)   ◇A ↔ A ∨ X ◇A
(D2)   ◇⁺A ↔ X ◇A
(D3)   ◇A ↔ A ∨ ◇⁺A
(B1)   □A ↔ A ∧ X □A
(B2)   □A → A
(B3)   □A → X □A
(B4)   □A → ◇A
(B5)   □(A → B) → (□A → □B)
(R1)   ↺A ↔ ◇⁺(X A)
(R2)   ↺A → ◇⁺A
(M4)   ◇A ↔ ¬□¬A   (класична LTL-дуальність)
```

**Твердження 11.A.4 (M6).** `□A → ↺A` — без додаткових умов.

**Доведення.** `□A` в `ŝ` тягне `F²(ŝ) ∈ A`, отже `∃k = 2 > 1: Fᵏ(ŝ) ∈ A`, що є означенням `↺A`. ∎

**PROVED ON PAPER.**

### 11.B. Гейтінгова семантика

**Означення 11.B.1.** Нехай Ω — 6-ланцюг (§7). Для `A : S_∞ × ℛ → Ω`:

```
(□_H A)(ŝ) := ⋀_{n ≥ 0} A(Fⁿŝ)
(◇_H A)(ŝ) := ⋁_{n ≥ 0} A(Fⁿŝ)
```

де `⋀`, `⋁` — у Ґратці Ω.

**Твердження 11.B.2 (M4_H не виконується).** `◇_H A ↔ ¬_H □_H ¬_H A` — хибне.

**Контрмодель.** `X = {a, b}`, `F(a) = b`, `F(b) = b`, `A(a) := EVENTUALLY_PERIODIC`, `A(b) := CHAOTIC`.

- `□_H ¬_H A(a) = CHAOTIC ∧ FIXED = CHAOTIC`;
- `¬_H □_H ¬_H A(a) = ¬_H CHAOTIC = INVARIANT_FIXED`;
- `◇_H A(a) = EVENTUALLY_PERIODIC`;
- `INVARIANT_FIXED ≠ EVENTUALLY_PERIODIC`.

**PROVED ON PAPER** (загальне порушення класичної дуальності в логіці Геделя–Даммета).

### 11.C. Узгодження

LTL описує траєкторії; Гейтінг — алгебраїчні значення. Різні системи, не змішуються.

## 12. Межі симуляції

**Твердження 12.1.** Кожен автономний скінченний автомат `(Q, δ)`, `|Q| ≤ 64`, вкладається в SUBIT⁺ як одна траєкторія.

**Доведення.** Ін'єкція `ι : Q → S₀`; правило `ρ : S₀ → S₀`; метаеволюція `g(ρ, s) := ρ`; індукція за `n`: `ι⁻¹(ρⁿ(ι(q₀))) = δⁿ(q₀)`. ∎

**PROVED ON PAPER.**

# Частина IV. SUBIT-∞ — нескінченний простір рекурсивних дерев

## 13. Функтор `F` і оператор `Ψ`

**Означення 13.1 (деревний функтор).**

```
F(X) := A ⊔ X³
```

Функтор на категорії множин. Позначення: `νF` — фінальна коалгебра `F`.

**Означення 13.2 (оператор продуктивності `Ψ`).** На множині підмножин `U_c`:

```
Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

де `LeafSeqs`, `NodeSeqs` визначені в §15.

**Застереження 13.3.** `F` і `Ψ` — різних типів. `F` діє на множинах, `Ψ` — на підмножинах `U_c`. Їх не можна позначати одним символом.

## 14. Скінченні апроксимації

**Означення 14.1 (`T_n`).**

```
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) : a ∈ A }
         ∪ { Bottom_{n+1} }
         ∪ { Node_n(t₁, t₂, t₃) : t₁, t₂, t₃ ∈ T_n }
```

**Конвенція індексів.** `Leaf_n`, `Bottom_n` індексовані за рівнем типу. `Node_n : T_n³ → T_{n+1}` — за рівнем дітей.

**Означення 14.2 (усічення `q_n`).**

```
q_0 : T_1 → T_0
q_0 (Leaf_1 a)          := Leaf_0 a
q_0 (Bottom_1)          := Bottom_0
q_0 (Node_0(t₁,t₂,t₃))  := Bottom_0

q_{n+1} : T_{n+2} → T_{n+1}
q_{n+1} (Leaf_{n+2} a)         := Leaf_{n+1} a
q_{n+1} (Bottom_{n+2})         := Bottom_{n+1}
q_{n+1} (Node_{n+1}(t₁,t₂,t₃)) := Node_n(q_n t₁, q_n t₂, q_n t₃)
```

**Лема 14.3 (типізація).** `q_n(t) ∈ T_n` для всіх `t ∈ T_{n+1}`.

**PROVED ON PAPER** (індукція за `n`).

## 15. Сумісні та продуктивні послідовності

**Означення 15.1 (`U_c`).**

```
U_c := { (t_n) ∈ ∏_n T_n : ∀n ≥ 0, q_n(t_{n+1}) = t_n }
```

**Застереження 15.2.** `U_c ≠ ∏_n T_n`. Контрприклад: `w = (Leaf_0(a), Bottom_1, Bottom_2, …) ∈ ∏T_n`, але `q_0(w_1) = Bottom_0 ≠ Leaf_0(a) = w_0`, отже `w ∉ U_c`.

**Означення 15.3 (`LeafSeqs`, `NodeSeqs`, `Ψ`).**

```
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }

NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0
                ∧ ∃u₁,u₂,u₃ ∈ X
                ∧ ∀n ≥ 0: t_{n+1} = Node_n(u_{1,n}, u_{2,n}, u_{3,n}) }

Ψ(X) := LeafSeqs ∪ NodeSeqs(X)
```

**Означення 15.4 (`L_prod`).**

```
L_prod := νΨ := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Лема 15.5.** `L_prod = Ψ(L_prod)`.

**Доведення.** (⊆) Кожна `X` з `X ⊆ Ψ(X)` міститься в `L_prod`; отже `L_prod ⊆ Ψ(L_prod)` за монотонністю. (⊇) `Y := Ψ(L_prod) ⊆ Ψ(Y)` за монотонністю; отже `Y ⊆ L_prod` за максимальністю. ∎

**PROVED ON PAPER.**

**Лема 15.6 (принцип коіндукції).** Якщо `X ⊆ U_c` і `X ⊆ Ψ(X)`, то `X ⊆ L_prod`.

**Контрприклад (строге включення).** `b = (Bottom_n)_n ∈ U_c \ L_prod`: сумісна, але не продуктивна (перша координата `Bottom_0` не має Node-розкладу в `L_prod`).

**Лема 15.7 (розклад).** Кожен `t ∈ L_prod` має рівно один Leaf- або Node-розклад.

## 16. Адресне кодування `Tree_∞`

**Означення 16.1 (позиції та мітки).**

```
Pos := {1, 2, 3}^{<ω}
Label := A ⊔ {node}
```

**Означення 16.2 (`Tree_∞`).** Підтип `Pos → Option(Label)` з умовами:

- **(T1)** `f(ε) ≠ None`;
- **(T2)** `f(σ) = Some(node)` ⟹ `f(σ·i) ≠ None` для всіх `i ∈ {1,2,3}`;
- **(T3)** `f(σ) = Some(leaf(a))` ⟹ `f(σ·i) = None` для всіх `i`;
- **(T4)** `f(σ) = None` ⟹ `f(σ·τ) = None` для всіх `τ ∈ Pos`.

**Означення 16.3 (`out_Tree`).**

```
out_Tree : Tree_∞ → A ⊔ Tree_∞³
out_Tree(f) := inl(a)            якщо f(ε) = Some(leaf(a))
out_Tree(f) := inr(f₁, f₂, f₃)   якщо f(ε) = Some(node)
```

де `f_i(σ) := f(i·σ)`.

**Лема 16.4 (фінальність).** `(Tree_∞, out_Tree)` — фінальна коалгебра `F`.

**Доведення (схема).** Для будь-якої коалгебри `c : X → A ⊔ X³` будуємо єдиний морфізм `h : X → Tree_∞`:

1. `state_x : Pos ⇀ X` — часткова функція, визначена рекурсивно: `state_x(ε) := x`; якщо `state_x(σ) = y` і `c(y) = inr(y₁,y₂,y₃)`, то `state_x(σ·i) := y_i`; якщо `c(y) = inl(a)`, то `state_x(σ·i)` не визначено.
2. `h(x)(σ) := None` якщо `state_x(σ)` не визначено; `Some(leaf(a))` якщо `c(state_x(σ)) = inl(a)`; `Some(node)` якщо `c(state_x(σ)) = inr(...)`.

Коректність (T1)–(T4) випливає з побудови; коалгебраїчна рівність і єдиність — індукцією за довжиною адреси. ∎

**PROVED ON PAPER.**

**Означення 16.5.** `S_∞ := Tree_∞` — канонічний носій.

## 17. Глибинні апроксимації `d_n`

**Означення 17.1 (база).** Для `f ∈ Tree_∞`:

- якщо `f(ε) = Some(leaf(a))`, то `d_0(f) := Leaf_0(a)`;
- якщо `f(ε) = Some(node)`, то `d_0(f) := Bottom_0`.

Випадок `f(ε) = None` неможливий за (T1).

**Означення 17.2 (крок).** Для `n ≥ 0`:

- якщо `f(ε) = Some(leaf(a))`, то `d_{n+1}(f) := Leaf_{n+1}(a)`;
- якщо `f(ε) = Some(node)`, то `d_{n+1}(f) := Node_n(d_n(f₁), d_n(f₂), d_n(f₃))`.

**Лема 17.3 (типізація).** `d_n(f) ∈ T_n`.

**Лема 17.4 (сумісність).** `q_n(d_{n+1}(f)) = d_n(f)`.

**Лема 17.5 (комутація з піддеревом).** Якщо `f(ε) = Some(node)`, то `d_n(f_i) = (d_{n+1}(f))|_i`.

**PROVED ON PAPER.**

**Означення 17.6 (проєкції).** `p_n : Tree_∞ → T_n`, `p_n(f) := d_n(f)`.

## 18. Стабілізація міток і `lim_tree`

**Означення 18.1 (`at_n`).** Для `t ∈ T_n` і `σ ∈ Pos`:

```
at_n(t, ε)        := Some(t)
at_0(t, i·τ)      := None
at_{n+1}(Leaf_{n+1}(a), i·τ)      := None
at_{n+1}(Bottom_{n+1}, i·τ)       := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ)   := at_n(u_i, τ)
```

**Лема 18.2 (стабілізація міток).** Для `t ∈ L_prod` і позиції `σ ∈ Pos` виконується рівно один із трьох випадків:

- **Z (недосяжна):** `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = None`;
- **L (стабільний листок):** `∃N, a: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Some(Leaf_{m-|σ|}(a))`;
- **N (стабільний вузол):** `∃N: ∀m ≥ N, m > |σ|: at_m(t_m, σ) = Node_{m-|σ|-1}(...)`.

**Доведення.** Індукція за довжиною `σ`. Для `σ = ε` випливає з Leaf/Node-розкладу `L_prod`. Для `σ = i·τ` — редукція до дочірньої послідовності, яка сама належить `L_prod` (замкненість). ∎

**PROVED ON PAPER.**

**Означення 18.3 (`lim_tree`).**

```
lim_tree(t)(σ) := lim_label(t, σ)
```

де:

- `lim_label(t, σ) := Some(leaf(a))` у випадку L;
- `lim_label(t, σ) := Some(node)` у випадку N;
- `lim_label(t, σ) := None` у випадку Z.

**Лема 18.4 (`Tree_∞`-умови).** `lim_tree(t)` задовольняє (T1)–(T4).

**PROVED ON PAPER.**

## 19. Метрика `d_S`

**Лема 19.1 (розділення).** Для всіх `f, g ∈ Tree_∞`:

```
(∀n ≥ 0: d_n(f) = d_n(g)) → f = g
```

**Доведення.** Припустимо `f ≠ g`. Виберемо найкоротшу адресу `σ`, на якій `f(σ) ≠ g(σ)`. Усі строгі префікси `σ` мають однакові мітки (за мінімальністю). Вони не можуть бути `None` (за T4) або листками (за T3). Отже, строгі префікси — вузли. На позиції `σ` розбіжність: різні листки або листок vs вузол. Для `n > |σ|` апроксимації `d_n(f)` і `d_n(g)` зберігають цю розбіжність: `d_n(f) ≠ d_n(g)`. Суперечність. ∎

**PROVED ON PAPER.**

**Означення 19.2 (метрика).**

```
r(f, g) := min{ n ≥ 0 : d_n(f) ≠ d_n(g) }   якщо f ≠ g
d_S(f, g) := 0                                якщо f = g
d_S(f, g) := 2^{−r(f, g)}                     якщо f ≠ g
```

**Лема 19.3 (ультраметрика).** `d_S` — ультраметрика на `Tree_∞`.

**Доведення.** Розглянемо `f, g, h`. Випадки `f = h`, `f = g`, `g = h` — безпосередньо. Для попарно різних: `m := min(r(f,g), r(g,h))`. Для `n < m`: `d_n(f) = d_n(g) = d_n(h)`, отже `r(f,h) ≥ m`, звідки `d_S(f,h) ≤ 2^{-m} = max(d_S(f,g), d_S(g,h))`. ∎

**PROVED ON PAPER.**

**Лема 19.4 (оцінка піддерев).** Для `f, g` з вузловими коренями: `d_S(f_i, g_i) ≤ 2 · d_S(f, g)`.

**Доведення.** Якщо `f = g` — тривіально. Інакше нехай `r := r(f, g) ≥ 1` (обидва корені — вузли). Перша розбіжність дочірніх апроксимацій не раніше `r − 1`. Тому `d_S(f_i, g_i) ≤ 2^{-(r-1)} = 2 · d_S(f, g)`. ∎

**PROVED ON PAPER.**

## 20. Бієкція `Tree_∞ ≅ L_prod`

**Означення 20.1.** `p : Tree_∞ → L_prod`, `p(f) := (d_n(f))_n`.

**Лема 20.2 (продуктивність).** `p(f) ∈ L_prod`.

**Доведення.** Показати `p(Tree_∞) ⊆ Ψ(p(Tree_∞))`. Якщо `f(ε) = Some(leaf(a))` — `p(f) ∈ LeafSeqs`. Якщо `f(ε) = Some(node)` — `p(f) ∈ NodeSeqs(p(Tree_∞))` за комутацією `d_n` з піддеревом. За принципом коіндукції — `p(Tree_∞) ⊆ L_prod`. ∎

**PROVED ON PAPER.**

**Означення 20.3 (`out_L`).**

```
out_L : L_prod → A ⊔ L_prod³
out_L(t) := inl(a)               якщо t_n = Leaf_n(a) для всіх n
out_L(t) := inr(u₁, u₂, u₃)      якщо t_0 = Bottom_0 і t_{n+1} = Node_n(...)
```

**Теорема 20.4 (коалгебраїчний ізоморфізм).** `out_L ∘ p = F(p) ∘ out_Tree`.

**Доведення.** Leaf-випадок тривіально. Node-випадок: обидві частини `inr(d_n(f_i))_i = inr(u_i)` за лемою 17.5. ∎

**PROVED ON PAPER.**

**Теорема 20.5 (перша тотожність).** `lim_tree(p(f)) = f` для всіх `f ∈ Tree_∞`.

**Доведення (незалежне).** Показати `lim_label(p(f), σ) = f(σ)` для всіх `σ`. За лемою 17.5 `at_n(d_n(f), σ) = Some(...)` для всіх `n > |σ|` з міткою, що відповідає `f(σ)`. Отже, у випадку L (відповідно N або Z) `lim_label(p(f), σ) = f(σ)`. ∎

**PROVED ON PAPER.**

**Теорема 20.6 (друга тотожність).** `p(lim_tree(t)) = t` для всіх `t ∈ L_prod`.

**Доведення (незалежне).** Індукція за рівнем `n` з універсальною гіпотезою. Leaf-випадок: `t_n = Leaf_n(a)`, `lim_tree(t) = leaf(a)`, `d_n(lim_tree(t)) = Leaf_n(a)`. Node-випадок: дочірні послідовності належать `L_prod`; за IH кожна реконструюється коректно. ∎

**PROVED ON PAPER.**

**Теорема 20.7 (бієкція).** `p : Tree_∞ → L_prod` — бієкція з оберненим `lim_tree`.

**Доведення.** Ін'єктивність: `p(f) = p(g) ⟹ f = lim_tree(p(f)) = lim_tree(p(g)) = g`. Сюр'єктивність: `p(lim_tree(t)) = t`. ∎

**PROVED ON PAPER.**

## 21. Повнота, цілком обмеженість, компактність

**Передумова 21.1 (`Finite A`).** `A = {T, F, B, N}`, `|A| = 4`.

**Лема 21.2 (скінченність `T_n`).**

```
|T_0| = |A| + 1 = 5
|T_{n+1}| = |A| + 1 + |T_n|³
```

Отже, `Finite(T_n)` для всіх `n`.

**PROVED ON PAPER.**

**Теорема 21.3 (повнота).** `(Tree_∞, d_S)` повний.

**Доведення (схема).** Для послідовності Коші `(s_k)` проєкції `d_n(s_k)` стабілізуються (за Коші й скінченністю `T_n`). Стабілізована послідовність `t^* = (t_n^*)` сумісна. За прямим аргументом (без використання бієкції) `t^* ∈ L_prod`: рівень 0 або Leaf, або Node; дочірні послідовності — межі Коші-підпослідовностей, які залишаються Коші (множник 2 не заважає). За принципом коіндукції `t^* ∈ L_prod`. Покладемо `s^* := lim_tree(t^*)`. Тоді `s_k → s^*`. ∎

**PROVED ON PAPER.**

**Теорема 21.4 (цілком обмеженість).** `(Tree_∞, d_S)` цілком обмежений.

**Доведення.** Класи `C_u := {f ∈ Tree_∞ : d_n(f) = u}` для `u ∈ T_n`. Сімейство класів скінченне (бо `T_n` скінченна). Виберемо представника з кожного непорожнього класу. Якщо `f, g ∈ C_u`, то `d_m(f) = d_m(g)` для `m ≤ n`, отже `d_S(f, g) ≤ 2^{-(n+1)}`. Для `ε > 0` виберемо `n` з `2^{-(n+1)} < ε`. Отримана скінченна множина представників — ε-мережа. ∎

**PROVED ON PAPER.**

**Теорема 21.5 (компактність).** `(Tree_∞, d_S)` компактний.

**Доведення.** Повний + цілком обмежений метричний простір компактний (Гейне–Борель–Больцано–Вейєрштрасс). ∎

**PROVED ON PAPER.**

## 22. Динаміка та класифікація

**Означення 22.1.**

```
F : S_∞ × ℛ → S_∞ × ℛ,   F(s, ρ) = (f_ρ(s), g(ρ, s))
```

**Означення 22.2 (`Fix(F)`).**

```
Fix(F) := { ŝ ∈ S_∞ × ℛ : F(ŝ) = ŝ }
```

Це **найбільша** множина нерухомих точок. **Найменша STABLE-множина** — ∅.

**Означення 22.3 (ω-границя).**

```
ω(ŝ₀) := { x : ∃nₖ → ∞, ŝ_{nₖ} → x }
```

**Означення 22.4 (Att).**

```
ATTAINED    ⟺ ∃n ≥ 0: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC  ⟺ ∀n: ŝₙ ∉ ω(ŝ₀) ∧ dist(ŝₙ, ω(ŝ₀)) → 0
```

Це математичні властивості траєкторії, не результат обмеження часу.

**Означення 22.5 (`S(τ)`).** П'ять класів:

```
FIXED_POINT              ω = {p}, F(p) = p
PERIODIC                 ω скінченна, |ω| > 1
MINIMAL_ZERO_ENTROPY     ω нескінченна, мінімальна, h_top = 0
CHAOTIC                  ω нескінченна, мінімальна, h_top > 0
NON_MINIMAL              ω нескінченна, не мінімальна
```

**Застереження 22.6.** Клас `MINIMAL_CANTOR` (попередні редакції) замінено на `MINIMAL_ZERO_ENTROPY`: нескінченна мінімальна ω-границя з `h_top = 0` **не обов'язково** має топологію Кантора (ірраціональне обертання кола, одометр). `MINIMAL_CANTOR` допустимий лише як уточнювальна підкатегорія за додаткової топологічної умови.

**Означення 22.7 (`Ω_traj`).**

```
Ω_traj := S(τ) × Att(τ)
```

Формально 10 пар, але реалізація всіх 10 не доведена.

**Означення 22.8 (три рівні сертифікації).**

```
PREFIX_CERTIFIED(N)
    Доведено твердження про префікс траєкторії довжини N.
    Не переноситься на всю траєкторію.

GLOBAL_EXACT_CERTIFIED
    Доведено твердження про нескінченну траєкторію.
    Доказ не залежить від горизонту обчислення.

APPROXIMATION_CONVERGED(N)
    Конкретний чисельний алгоритм виконав свій критерій
    збіжності на горизонті N.
```

**Означення 22.9 (COMPUTED / RESOURCE_EXCEEDED).** Окреме поле сертифіката; не входить у `Ω_traj`.

**Означення 22.10 (CHAOTIC і ℛ₀).**

- Для `ρ ∈ ℛ₀` з `g ≡ id`: `h_top(ω(ŝ₀)) = 0` (Bowen, 1971).
- Для `g ≠ id`: **Q10** (❓).

**Означення 22.11 (`P(τ)`).**

```
P(τ) := ( ω(ŝ₀), Ω_traj(τ), certificate )
```

**Означення 22.12 (типологія предикатів префікса).**

Для предиката `φ(k, τ)`:

- **PH** (Prefix-Hereditary): `Φ_PH(N) := ∀k ≤ N: φ(k, τ)`; `Φ_PH(N+1) ⟹ Φ_PH(N)`.
- **EP** (Extension-Preserving): `Φ_EP(N) := ∃k ≤ N: φ(k, τ)`; `Φ_EP(N) ⟹ Φ_EP(N+1)`.
- **PP** (Pointwise): `Φ_PP(k) := φ(k, τ)`; не переноситься на інші `k` без додаткових умов.
- **GP** (Global): `Ψ(τ)` — властивість всієї траєкторії.

**Правила перенесення.**

- `Φ_PH(N+1) ⟹ Φ_PH(N)`; `Φ_EP(N) ⟹ Φ_EP(N+1)`;
- `Φ_PH(N) ⟹ Φ_EP(N)` для `N ≥ 0` (безумовно);
- `Φ_EP(N) ↛ Φ_PH(N)` у загальному випадку;
- `GP` не визначає напрямків імплікацій автоматично; конкретні імплікації доводяться семантично.

## 23. Шість динамічних класів множин

**Означення 23.1 (`μ, π, p_set`).**

```
μ(P) := min{ m ≥ 0 : ∃n > m: F^m(P) = F^n(P) }     (∞ якщо немає)
π(P) := min{ n − μ(P) : n > μ(P), F^n(P) = F^{μ(P)}(P) }    (∞ якщо μ = ∞)
p_set(P) := min{ k ≥ 1 : F^k(P) = P }              (∞ якщо немає)
```

**Означення 23.2 (шість класів).**

```
INVARIANT_FIXED(P)        ⟺ F(P) = P ∧ ∀x ∈ P: f(x) = x
INVARIANT_DYNAMIC(P)      ⟺ F(P) = P ∧ ∃x ∈ P: f(x) ≠ x
PERIODIC_SET(P)           ⟺ p_set(P) = p ≥ 2
EVENTUALLY_FIXED(P)       ⟺ μ(P) ≥ 1 ∧ π(P) = 1
EVENTUALLY_PERIODIC(P)    ⟺ μ(P) ≥ 1 ∧ π(P) ≥ 2
APERIODIC(P)              ⟺ μ(P) = ∞
```

**Твердження 23.3 (вичерпність і взаємовиключність).** Шість класів попарно не перетинаються і вичерпують `2^{S_∞ × ℛ} ∖ {∅}`.

**Доведення.** Розбиття за `(F(P) = P?, μ(P), π(P))`:

- `F(P) = P`: розділення на `INVARIANT_FIXED` та `INVARIANT_DYNAMIC` за квантором.
- `F(P) ≠ P`:
  - `μ(P) = 0` → `PERIODIC_SET(p_set(P))` з `p_set ≥ 2`;
  - `μ(P) ≥ 1, π(P) = 1` → `EVENTUALLY_FIXED`;
  - `μ(P) ≥ 1, π(P) ≥ 2` → `EVENTUALLY_PERIODIC`;
  - `μ(P) = ∞` → `APERIODIC`.

Взаємовиключність — за означеннями. ∎

**PROVED ON PAPER.**

## 24. Топологія простору правил `ℛ`

**Означення 24.1 (`ℛ₀`).** Причинні функції: `d_S(f(s), f(t)) ≤ d_S(s, t)` для всіх `s, t`.

**Означення 24.2 (`ℛ₁`).** Функції зі скінченним обчислюваним описом у фіксованій моделі обчислень.

**Застереження 24.3.** `ℛ₀` і `ℛ₁` не тотожні. `|ℛ₀| = 2^{ℵ₀}`, `|ℛ₁| = ℵ₀` — **Q25** (❓).

**Твердження 24.4.** `(ℛ₀, d_ℛ)` — компактний гаусдорфовий простір.

**Доведення (схема).** `ℛ₀` представлений як обернена границя скінченних просторів функцій `(T_n)^{T_n}` з дискретною топологією; за Тихоновим — компактний.

**PROVED ON PAPER.**

# Частина V. Застосування та методологія

## 25. Епістемологічний статус

**25.1.** Усі теореми SUBIT — твердження про формальну систему. Вони **не доводять**, що фізична, біологічна, соціальна чи психологічна система має ту саму структуру.

**25.2. Призначення.** SUBIT — інструмент структурування гіпотез:

- змушує явно формулювати причинний механізм `ρ`;
- дає компактну мову для розрізнення типів переходу;
- дає кількісну (`d_ω`) або якісну (`Ω`) мову для порівняння гіпотез.

**25.3. Протокол застосування.**

- **Крок 0 (кодування).** Обґрунтувати розбиття неперервного простору вимірів на скінченний алфавіт `A`. Для неперервних даних — процедура дискретизації, пороги, нормалізація, аналіз чутливості. Аналог породжувального розбиття в символічній динаміці.
- **Крок 0' (клас правил).** Визначити, чи належить правило до `ℛ₀`, `ℛ₁` або їхнього перетину. Не робити висновку про причинність лише з обчислюваності.
- **Крок 1.** Визначити `S₀` або `S_∞` з кодуванням.
- **Крок 2.** Задати `F`, `f_ρ`, `g` з точними типами.
- **Крок 3.** Перевірити тотальність, неперервність, причинність.
- **Крок 4.** Обчислити траєкторію з явним горизонтом і політикою зупинки.
- **Крок 5.** Класифікувати, не змішуючи `Ω_point`, `Ω_set`, `S`.
- **Крок 6.** Перевірити чутливість до кодування, альтернативних правил і параметрів.

## Додаток B. Коректність коалгебраїчної конструкції

**Лема B.1.** Кінцева коалгебра функтора `Φ'(X) = X³` — одноелементна: `νX.X³ ≅ 1`.

**Доведення.** Термінальна послідовність `1 ← Φ'(1) ← Φ'²(1) ← …` стабілізується на першому кроці, бо `Φ'(1) = 1³ ≅ 1`. Границя стабільної послідовності — сама ця точка. ∎

**PROVED ON PAPER.**

**Наслідок B.2.** Спроба вкласти `A` (потужності > 1) у `νX.X³` як листки (ототожнюючи `a ∈ A` з розв'язком `s = (s,s,s)`) зазнає невдачі: усі такі розв'язки бісимулярні.

**Лема B.3.** `νX.(A ⊔ X³) ≠ 1` при `|A| > 1`.

**Доведення.** Термінальна послідовність: `X_0 = 1`, `X_1 = A ⊔ 1`, `X_2 = A ⊔ (A ⊔ 1)³`, … На кожному кроці зберігається копія `A` як нескорочувана компонента. Границя містить принаймні `|A|` попарно різних точок, зокрема `S₀ = A³` як дерева глибини 1, `|S₀| = 64`. ∎

**PROVED ON PAPER.**
