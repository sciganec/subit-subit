# SUBIT-∞

## Формальна специфікація ієрархії SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-TOPOS ⊂ SUBIT_∞

**Версія 6.0 (release)**

**Статус:** STABLE

---

## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем: систем, у яких правило еволюції є частиною самого стану, а не зовнішнім параметром. Специфікація побудована як строга кумулятивна ієрархія з чотирьох рівнів, кожен з яких є самодостатньою, завершеною системою і додає до попереднього рівно один новий шар структури:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

**SUBIT-64** фіксує статичний алфавіт із 64 архетипних станів. **SUBIT⁺** додає внутрішнє правило еволюції та оператор, що змінює і стан, і правило. **SUBIT-TOPOS** підносить це до категорії з класифікатором стабільності, типовою системою та модальною логікою. **SUBIT_∞** знімає обмеження скінченності, розширюючи простір станів до рекурсивної коіндуктивної структури дерев із мітками, у якій категорія «хаотичної» динаміки вперше стає математично змістовною.

Версія 6.0 є **першим релізом**, який замінює нашарування рівнів v5.2 на перевірюване ядро. Кожне твердження специфікації має явний статус доказовості (§20). Функція P(τ) переписана (§18): три типи досягнення ω-границі замінюють хибне припущення `m(ŝ₀) < ∞`. Введено топологію простору правил ℛ (§21) з двома класами ℛ₀ (причинні функції, компактний) та ℛ₁ (обчислювані, розривні). Класифікатор Ω розширено до двоосьового Ω_traj = (S, Att) (§22). Аксіома M4 спростована й замінена на M4' + M9 (§11).

Специфікація супроводжується еталонною реалізацією (`subit-core` v0.3.0, `subit-infinity` v0.2.0), формальними доказами в Lean 4 (`subit-proofs` v0.3.0; 7 із 10 цільових теорем повністю доведено), емпіричним протоколом (`pilot-01`) і машинно-перевірюваним реєстром статусів (STATUS.md).

Специфікація завершується нормативним розділом про епістемологічний статус системи: SUBIT-∞ є інструментом формулювання й структурування гіпотез, а не емпіричною теорією.

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

В основі системи лежить скінченна множина примітивних маркерів потужності 4. Специфікація параметризована вибором конкретної реалізації цієї множини; визначено дві стандартні, взаємно ізоморфні реалізації.

**Семантична реалізація** — для прикладного моделювання конкретних емпіричних систем:

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація** — білаттис Белнапа, для формально-логічного трактування:

```
𝔸 = { T, F, B, N }
```

де T = True (Yang), F = False (Yin), B = Both (діалетеїчне значення), N = Neither (паракомплетне значення). Множина 𝔸 несе структуру білаттиса з двома незалежними частковими порядками:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

Кожне значення обох реалізацій кодується двома бітами (bigram = b₁b₂):

| Bigram | Семантична реалізація | Логічна реалізація |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

Відповідність між реалізаціями є ізоморфізмом множин потужності 4: він дозволяє переносити алгебраїчні результати між реалізаціями, не встановлюючи жодного змістовного ототожнення на кшталт «ME означає True» — це технічна, а не інтерпретаційна еквівалентність.

## 2. Простір станів S₀

**Означення 2.1.** Простір станів SUBIT-64 визначається як

```
S₀ = A_WHO × A_WHERE × A_WHEN  (або 𝔸³ у логічній реалізації)
|S₀| = 4³ = 64
```

Кожен стан — трійка s = (α, β, γ), де α ∈ A_WHO, β ∈ A_WHERE, γ ∈ A_WHEN. Стан кодується 6-бітним словом b₁b₂b₃b₄b₅b₆, де b₁b₂ кодує WHO, b₃b₄ — WHERE, b₅b₆ — WHEN.

**Гексаграмна нотація.** Розбивши код на дві тригами — Lower Trigram (b₁b₂b₃) і Upper Trigram (b₄b₅b₆) — кожному стану можна зіставити унікальну гексаграму І-Цзін (повна таблиця відповідності — Додаток A). Ця нотація використовується виключно як компактний, однозначний комбінаторний запис 6-бітного слова; жодне додаткове тлумачення традиційної символіки триграм не є частиною формальної специфікації.

**Властивості рівня.** S₀ є статичним простором: відсутній оператор переходу, відсутня внутрішня динаміка, класифікатор істини тривіальний. SUBIT-64 — необхідний алфавіт архетипів, але сам по собі не описує зміну, причинність чи перехід між станами.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.** Простір правил еволюції на цьому рівні — скінченна множина

```
ℛ = { ρ₁, ρ₂, …, ρₙ },   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширеним станом називається пара

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

де ρ — активне правило еволюції, що належить самому стану. Це — принципова відмінність SUBIT⁺ від класичного скінченного автомата: у автоматі функція переходу δ зовнішня щодо стану q і фіксується раз і назавжди; у SUBIT⁺ правило ρ є компонентою стану ŝ і само підлягає зміні.

## 4. Оператор еволюції та ієрархія рівнів самореференції

**Означення 4.1.** Оператор еволюції

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

де f_ρ : S₀ → S₀ — застосування поточного правила до стану; g : ℛ × S₀ → ℛ — функція метаеволюції, що визначає, як саме правило змінюється залежно від поточного правила й стану.

**Аксіома 4.1 (детермінованість).** F — тотальна функція, визначена для всіх пар (s, ρ) ∈ S₀ × ℛ.

Ця конструкція виявляє чотири рівні самореференції, недоступні класичному автомату:

```
Рівень 0:   s = (α, β, γ)      базовий стан (без правила)
Рівень 1:   ŝ = (s, ρ)         стан із внутрішнім правилом
Рівень 2:   F(ŝ) = (s′, ρ′)    еволюція стану і правила за один крок
Рівень 3:   g(ρ, s) → ρ′       метаеволюція: зміна способу зміни
```

Класичний автомат має лише Рівень 0 і фіксований (незмінний) Рівень 2; SUBIT⁺ додає Рівні 1 і 3, стираючи межу між даними, програмою й метапрограмою.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** Траєкторією розширеного стану ŝ₀ називається послідовність

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),   ŝₙ₊₁ = F(ŝₙ)
```

**Твердження 5.1 (скінченна періодичність).** Оскільки S₀ × ℛ — скінченна множина, а F — детермінована функція цієї множини в саму себе, для будь-якого ŝ₀ існують m ≥ 0 і k ≥ 1 такі, що ŝ_{m+k} = ŝ_m. Іншими словами, кожна траєкторія в SUBIT⁺ рано чи пізно входить у цикл, можливо, після скінченного передперіодичного «хвоста» (принцип Діріхле, застосований до відображення скінченної множини в себе). *(Формальне доведення в Lean 4 — Додаток D, теорема T3.)*

Це дає повний перелік типів одноточкових траєкторій, реалізованих на цьому рівні:

| Тип | Умова |
|---|---|
| Атрактор (нерухома точка) | F(ŝ) = ŝ ⟺ f_ρ(s) = s і g(ρ, s) = ρ |
| Орбіта (цикл довжини k > 1) | Fᵏ(ŝ) = ŝ і ∀i < k: Fⁱ(ŝ) ≠ ŝ |
| Передперіодична траєкторія | ∃m > 0, k ≥ 1: ŝ_{m+k} = ŝ_m, а ŝ₀, …, ŝ_{m−1} — без повторів |

Жодна одноточкова траєкторія на цьому рівні не може бути неперіодичною в строгому сенсі — генуїнно неперіодична динаміка вимагає нескінченного простору станів чи правил (Частина IV).

**Алгоритм 5.1 (класифікація за скінченним наближенням).**

```
Вхід: ŝ₀ = (s₀, ρ₀), горизонт пошуку N_max
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        L ← n − позначку входження ŝₙ до visited
        якщо L = 1: повернути "атрактор"
        інакше:      повернути "цикл довжини L"
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
якщо N_max вичерпано без повтору:
    повернути "цикл довший за N_max" (горизонт пошуку недостатній)
```

# ЧАСТИНА III. SUBIT-TOPOS — категорія, класифікатор, типи

## 6. Класифікатор стабільності Ω

Означення й результати цієї Частини формулюються для довільної множини P ⊆ S₀ × ℛ (а не лише для одноточкової траєкторії, як у Частині II), і залишаються дослівно чинними при заміні S₀ на S_∞ у Частині IV.

### 6.1. Класифікація множин

**Означення 6.1.** Клас стабільності множини P визначається такими умовами:

```
STABLE       ⟺  F(P) = P
METASTABLE   ⟺  F(P) ⊊ P                         (строга власна підмножина)
CYCLIC       ⟺  існує мінімальне k > 1: Fᵏ(P) = P,  і F(P) ≠ P
CHAOTIC      ⟺  F(P) ⊄ P   і   ∀k > 1: Fᵏ(P) ≠ P
```

Ці чотири умови взаємовиключні й вичерпні за побудовою. Дійсно: якщо F(P) ⊆ P і F(P) ≠ P (тобто P метастабільна), то за індукцією Fᵏ(P) ⊆ F(P) ⊊ P для всіх k ≥ 1, тож Fᵏ(P) ≠ P за жодного k — METASTABLE і CYCLIC автоматично несумісні. Якщо ж P задовольняє умову CYCLIC (∃k>1: Fᵏ(P)=P, F(P)≠P), то з щойно наведеного випливає, що F(P) не може бути власною підмножиною P, тобто F(P) ⊄ P — отже, коли F(P) ≠ P, рівно одна з трьох можливостей (METASTABLE, CYCLIC чи CHAOTIC) реалізується, залежно від того, чи F(P) ⊊ P, чи існує k>1 з Fᵏ(P)=P, чи жодне з двох. CHAOTIC, таким чином, є точним доповненням об'єднання трьох інших класів.

**Означення 6.2 (семантична істина).** Множина станів P вважається істинною тоді й лише тоді, коли вона стабільна: P істинне ⟺ F(P) = P. Це — внутрішній критерій: він не апелює до жодного зовнішнього спостерігача, а випливає безпосередньо з динаміки F.

**Зауваження (математична межа скінченного рівня).** Оскільки на рівні SUBIT-64/SUBIT⁺ простір S₀ × ℛ скінченний, а кожна одноточкова траєкторія обов'язково зрештою періодична (Твердження 5.1), клас CHAOTIC для одноточкових траєкторій на цьому рівні не реалізується. Категорія CHAOTIC стає математично змістовною лише для множин P у нескінченному просторі S_∞ (Частина IV).

### 6.2. Точкова класифікація Ω_state

**Означення 6.3 (Ω_state).** Для ŝ ∈ S_∞ × ℛ:

```
Ω_state(ŝ) := Ω_set({ŝ})
```

Явно:

| Ω_state(ŝ) | Умова |
|---|---|
| STABLE | F(ŝ) = ŝ |
| CYCLIC | ∃k > 1: Fᵏ(ŝ) = ŝ, і F(ŝ) ≠ ŝ |
| CHAOTIC | інакше |

**METASTABLE для синглтона неможлива**: образ синглтона — синглтон, ніколи не власна підмножина. Це узгоджується з Твердженням 18.6.

**Твердження 6.3 (узгодженість Ω_set / Ω_state).** Для будь-якої скінченної множини P = {ŝ₁, …, ŝₙ}:

```
Ω_set(P) = STABLE  ⟺  ∀i: Ω_state(ŝᵢ) = STABLE і F(P) = P
```

*Доведення.* Якщо F(P) = P і кожен елемент нерухомий, то P стабільна. Навпаки, якщо P стабільна, то F(P) = P; якщо при цьому якийсь ŝᵢ не нерухомий, то F(ŝᵢ) ≠ ŝᵢ, але F(ŝᵢ) ∈ P, отже F(P) ⊊ P або F(P) ≠ P — суперечність. ∎

## 7. Алгебра Ω

На множині Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC} визначено лінійний порядок:

```
CHAOTIC < CYCLIC < METASTABLE < STABLE
```

Для будь-якого лінійно впорядкованого скінченного ланцюга операції ∧ = min і ∨ = max автоматично утворюють дистрибутивну ґратку. Разом із релятивним псевдодоповненням, визначеним стандартною формулою для ланцюгів (a → b := найбільший елемент ⊤, якщо a ≤ b; інакше b), ця структура утворює **алгебру Гейтінга** (алгебру Ґеделя — лінійну модель інтуїціоністської логіки).

**Кон'юнкція (∧ = min):**

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

**Диз'юнкція (∨ = max):**

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**Заперечення.** Визначаючи ¬a := a → CHAOTIC і застосовуючи формулу релятивного псевдодоповнення: якщо a = CHAOTIC, то a ≤ ⊥, звідки ¬CHAOTIC = ⊤ = STABLE. Для будь-якого іншого a маємо a > ⊥, тож ¬a = ⊥ = CHAOTIC:

| a | ¬a |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

**Твердження 7.1 (недосяжність класичного виключеного третього).**

```
METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CHAOTIC = METASTABLE ≠ STABLE
```

Закон виключеного третього не виконується — Ω_SUBIT є моделлю інтуїціоністської, а не класичної (булевої) логіки.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).** Об'єктом категорії SUBIT є система X = (S_X, ℛ_X, F_X, g_X), де S_X — довільна множина (не обов'язково підмножина S₀), ℛ_X ⊆ ℛ, з аксіомою замкненості F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X. У Частині III розглядаються скінченні S_X; у Частині IV — S_X ⊆ S_∞.

**Означення 8.2 (морфізми).** Морфізм φ: X → Y — пара відображень φ = (φ_S, φ_ℛ), що задовольняє умову динамічної сумісності:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

тобто застосування еволюції з наступним відображенням дає той самий результат, що й відображення з наступною еволюцією. Композиція та тотожні морфізми визначаються покомпонентно; асоціативність і нейтральність тотожного морфізма спадкуються безпосередньо від властивостей композиції функцій. SUBIT — категорія.

**Спеціальні об'єкти й конструкції:**

- *Термінальний об'єкт* **1**: S₁ = {∗}, ℛ₁ = {id}. Для будь-якого X існує рівно один морфізм X → 1.
- *Добуток* X × Y: S_{X×Y} = S_X × S_Y, ℛ_{X×Y} = ℛ_X × ℛ_Y, F_{X×Y}((s₁,s₂),(ρ₁,ρ₂)) = (F_X(s₁,ρ₁), F_Y(s₂,ρ₂)).
- *Експоненціал* Yˣ: S_{Yˣ} — множина динамічно сумісних відображень S_X → S_Y, з оператором евалюації F_{Yˣ}(φ)(s) = F_Y(φ(F_X⁻¹(s))).

**Зауваження про застосовність експоненціала.** Наведена конструкція спирається на існування оберненого відображення F_X⁻¹, тобто застосовна лише до об'єктів X із оборотною динамікою. Для об'єктів із необоротною динамікою ця конструкція не визначена, і статус декартової замкненості категорії SUBIT у повному обсязі є відкритим питанням (розділ 17); вона встановлена лише для повної підкатегорії об'єктів з оборотним F.

**Твердження 8.1.** SUBIT — категорія.

*Доведення.* Асоціативність композиції морфізмів випливає з асоціативності композиції функцій покомпонентно. Тотожний морфізм id_X : X → X визначається як (id_{S_X}, id_{ℛ_X}); він задовольняє умову динамічної сумісності тривіально. ∎

## 9. SUBIT як Ω-класифікована категорія

### 9.1. Діагноз

Специфікація v5.2 стверджувала, що SUBIT є **proto-topos**, спираючись на три умови топосу: скінченні ліміти (T1), експоненціали (T2) і субоб'єктний класифікатор (T3). Аудит v6.0 (Додаток G) показав:

- (T1) доведено лише для скінченних добутків; еквалайзери не побудовані;
- (T2) доведено лише для підкатегорії оборотних об'єктів;
- (T3) **не доведено**: Ω у v5.2 — це множина {STABLE, METASTABLE, CYCLIC, CHAOTIC} **без власної динаміки**, отже вона не є об'єктом SUBIT. Характеристичний морфізм χ_φ : X → Ω не визначено.

Тому в v6.0 назва «proto-topos» замінена на точнішу.

### 9.2. Означення Ω-класифікованої категорії

**Означення 9.1 (Ω-об'єкт).** Нехай C — категорія з термінальним об'єктом 1. Об'єкт Ω ∈ C називається **Ω-об'єктом**, якщо:

1. Ω несе структуру алгебри Гейтінга (∧, ∨, →, ⊤, ⊥);
2. Існує морфізм ⊤ : 1 → Ω;
3. Для кожного об'єкта X ∈ C існує відображення (не обов'язково морфізм) `Sub(X) → Hom(X, Ω)`, яке кожному субоб'єкту U ↪ X зіставляє характеристичне відображення χ_U : X → Ω.

**Означення 9.2 (Ω-класифікована категорія).** Категорія C називається **Ω-класифікованою**, якщо вона має Ω-об'єкт, але відображення Sub(X) → Hom(X, Ω) не вимагається бути бієкцією.

**Зауваження 9.1.** Топос — це Ω-класифікована категорія, у якій Sub(X) → Hom(X, Ω) є бієкцією (і Ω — субоб'єктний класифікатор у строгому сенсі). У SUBIT бієкція не доведена, тому SUBIT не є топосом.

### 9.3. Ω як об'єкт SUBIT

**Означення 9.3 (динамічний Ω).**

```
S_Ω     := {STABLE, METASTABLE, CYCLIC, CHAOTIC}
ℛ_Ω     := {id_Ω}
F_Ω(x)  := x          (тотожна динаміка)
g_Ω(ρ, x) := ρ
```

Тотожна динаміка означає: Ω-класифікація не змінюється сама по собі; вона є **інваріантом** еволюції.

**Твердження 9.1.** Ω = (S_Ω, ℛ_Ω, F_Ω, g_Ω) є об'єктом SUBIT (з урахуванням уточнення 8.1 щодо довільності S_X).

### 9.4. Морфізм ⊤ : 1 → Ω

**Означення 9.4.** ⊤ : 1 → Ω — морфізм, що відображає єдиний елемент ∗ ∈ S₁ у STABLE ∈ S_Ω, і id ∈ ℛ₁ у id_Ω ∈ ℛ_Ω.

**Твердження 9.2.** ⊤ — морфізм SUBIT.

*Доведення.* Умова динамічної сумісності виконується тривіально, оскільки F_1(∗, id) = (∗, id), φ_S(∗) = STABLE, F_Ω(STABLE, id_Ω) = (STABLE, id_Ω). ∎

### 9.5. Характеристичне відображення

**Означення 9.5.** Нехай U ↪ X — субоб'єкт (моно φ : U → X). Характеристичне відображення χ_U : X → Ω визначається:

```
χ_U(x) := 
   STABLE       якщо x ∈ U і F_X(x) ∈ U
   METASTABLE   якщо x ∈ U і F_X(U) ⊊ U
   CYCLIC       якщо x ∈ U і ∃k>1: F_Xᵏ(U) = U
   CHAOTIC      якщо x ∉ U або F_X(U) ⊄ U
```

**Твердження 9.3 (природність χ).** Для будь-якого морфізма f : X → Y і субоб'єкта U ↪ Y маємо χ_{f⁻¹(U)} = χ_U ∘ f.

### 9.6. Підсумковий статус

**Твердження 9.4.** SUBIT є Ω-класифікованою категорією, але не є топосом.

*Доведення.* Ω-об'єкт існує (9.1), ⊤ існує (9.2), χ існує (9.5). Бієкція Sub(X) → Hom(X, Ω) не виконується: існують різні субоб'єкти U₁ ≠ U₂ з однаковим χ. Отже, SUBIT — Ω-класифікована, не топос. ∎

**Відкрите питання Q2.** Чи існує природний підклас C₀ ⊂ SUBIT, на якому Sub(X) → Hom(X, Ω) є бієкцією? Якщо так, C₀ був би топосом.

## 10. Динамічна теорія типів

**Судження.** Γ ⊢ t : A @ τ означає: у контексті Γ стан t має тип A на фазі еволюції τ. Тип A трактується не як статична класифікація, а як клас траєкторій зі спільним режимом стабільності: A = {ŝ | stability_class(ŝ) = mode_A}.

**Правила виведення:**

```
Рефлексивність:    ───────────────────
                   Γ, x:A@τ ⊢ x : A@τ

Еволюція типу:     Γ ⊢ t:A@τ     F(A) ⊆ B
                   ──────────────────────────
                   Γ ⊢ F(t) : B @ (τ+1)

Стабільний тип:    Γ ⊢ t:A@τ     F(A) = A
                   ──────────────────────────
                   Γ ⊢ t : □A @ τ

Потенційний тип:   Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   ─────────────────────────────
                   Γ ⊢ t : ◇B @ τ

Циклічний тип:     Γ ⊢ t:A@τ     ∃k>1: Fᵏ(A) = A
                   ──────────────────────────────
                   Γ ⊢ t : ◯A @ τ
```

Умова циклічного типу обмежена k>1, узгоджено з означенням модальності ◯ у розділі 11 і з означенням CYCLIC у розділі 6.1.

**Атракторна рівність.** Замість класичної ідентичності вводиться відношення s ~_F t ⟺ ∃k: Fᵏ(s) = Fᵏ(t): два стани еквівалентні, якщо їхні траєкторії зрештою збігаються.

## 11. Модальна логіка

### 11.1. Модальності як предикати станів

**Означення 11.1.** Нехай A ⊆ S_∞ × ℛ — множина (клас). Для ŝ ∈ S_∞ × ℛ:

```
ŝ ⊨ □A   ⟺   ∀n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◇A   ⟺   ∃n ≥ 0: Fⁿ(ŝ) ∈ A
ŝ ⊨ ◯A   ⟺   ∃k > 1: Fᵏ(ŝ) ∈ A,  і  ŝ ⊨ ◇A,  і  Fᵏ(A) = A для деякого такого k
```

**Твердження 11.1 (зв'язок з множинним Ω).** Для будь-якої A:

```
F(A) = A  ⟹  (A ⊨ □A)  ⟺  (∀ŝ ∈ A: ŝ ⊨ □A)
```

### 11.2. Аксіоми

| Аксіома | Формулювання | Статус |
|---|---|---|
| M1 | □A → A | ✅ |
| M2 | □A → □□A | ✅ |
| M3 | □(A → B) → (□A → □B) | ✅ |
| **M4** | **◇A ↔ ¬□¬A** | **❌ спростовано** |
| M4' | ◇A → ¬□¬A | ✅ |
| M5 | ◯A → ◇A | ✅ |
| M6 | □A → ◯A | ✅ |
| M7 | ◯◯A ↔ ◯A | ✅ |
| M8 | □A ∧ □B → □(A ∧ B) | ✅ |
| M9 | ¬¬□A → □A | ✅ |

**Твердження 11.2 (M4 не виконується).** Аксіома `◇A ↔ ¬□¬A` не виконується в Ω_SUBIT.

*Контрприклад.* Покладемо A = METASTABLE (як множину станів). Ліва частина: ◇METASTABLE — існує n ≥ 0: Fⁿ(ŝ) ∈ METASTABLE. Права частина: ¬□¬METASTABLE. Обчислимо ¬METASTABLE = CHAOTIC (з таблиці §7). Тепер □CHAOTIC: на скінченному рівні CHAOTIC не реалізується (Твердження 5.1), тому □CHAOTIC = ⊥. Отже ¬□CHAOTIC = ¬⊥ = STABLE. Висновок: STABLE ≠ ◇METASTABLE. Отже, M4 спростовано. *(Формальне доведення в Lean 4 — Додаток D, теорема T5.)*

**Твердження 11.3 (M9).** У Ω_SUBIT подвійне заперечення стабільної істини збігається з нею самою: ¬¬□A ↔ □A.

*Доведення.* ¬□A = CHAOTIC (за таблицею §7). ¬¬□A = ¬CHAOTIC = STABLE. Отже, ¬¬□A ⟺ STABLE ⟺ □A. ∎

### 11.3. Відповідність класифікатору Ω

| Ω-клас | Модальна характеристика |
|---|---|
| STABLE | □A |
| METASTABLE | A ∧ ¬□A |
| CYCLIC | ◯A ∧ ¬□A |
| CHAOTIC | ¬◇A |

Не виконуються ◇A ∨ ◇¬A і □A ∨ □¬A.

## 12. Внутрішня мова, універсальний об'єкт, принцип симуляції

**Внутрішня мова.** Примітивні терми: s, t, u — терми типу State; ρ, σ — терми типу Rule; p, q — терми типу Prop. Конструктори: who(s), where(s), when(s) — проекції на координати стану; rule(ŝ) — витягування правила зі стану; evolve(ŝ) = F(ŝ). Пропозиційні конструктори: stable(p), reaches(s, A), cycle(A), morphism(φ, X, Y), iso(φ).

**Універсальний об'єкт.** U = (S₀ × ℛ*, F*, g*), де ℛ* — коди всіх допустимих локальних правил, F* — інтерпретатор, що приймає код (s, ρ) системи X і обчислює f_ρ(s), g* — оператор переписування правил. Для будь-якого X ∈ SUBIT постулюється існування морфізму φ_X: U → X. Конструкція кодування encode_X, encode_R подається на рівні принципу.

**Принцип симуляції.** Будь-який скінченний автомат (Q, δ) вкладається в SUBIT⁺: обираємо ін'єкцію ι: Q → S₀; для кожного символу a ∈ Σ будуємо правило ρ_a ∈ ℛ таке, що f_{ρ_a}(ι(q)) = ι(δ(q, a)); визначаємо метаеволюцію g: ρ_a ↦ ρ_{наступний символ}. Наслідок: SUBIT⁺ є умовно універсальною симуляційною системою.

# ЧАСТИНА IV. SUBIT_∞ — рекурсивний нескінченний простір

## 13. Простір станів S_∞ як дерева з мітками

**Означення 13.1.** Рекурсивний простір станів визначається як найбільша коалгебраїчна нерухома точка (кінцева коалгебра) функтора `Φ(X) = A ⊔ X³` на категорії множин:

```
S_∞ = νX. (A ⊔ X × X × X)
```

з відповідним відображенням-структурою (out-map)

```
out : S_∞ → A ⊔ S_∞³
```

Цей функтор має два конструктори: **лист**, помічений елементом алфавіту A, і **внутрішній вузол** — трійка піддерев. Явно: S_∞ — множина всіх дерев (скінченних і нескінченних, глибини не більше ω), у яких кожен вузол або є листом із міткою з A, або є внутрішнім вузлом із рівно трьома піддеревами; ототожнення за бісимуляцією (у сенсі антифундаційної аксіоми, Aczel, 1988) допускає нескінченні й циклічні, самореферентні структури серед внутрішніх вузлів.

**Чому потрібен доданок A.** Функтор без базового (листкового) конструктора, Φ'(X) = X³, має кінцеву коалгебру, ізоморфну одноелементній множині (Додаток B): без жодної мітки немає жодної ознаки, за якою можна відрізнити одне нескінченне саморозгортання дерева від іншого, і всі вони ототожнюються бісимуляцією в єдину точку. Додавання підсумовуваного компонента A вносить генуїнну розрізняльність на кожному рівні розгортання.

**Вкладення S₀ ⊂ S_∞.** Означимо

```
S₀ := { (a, b, c) ∈ S_∞ | a, b, c ∈ A ⊂ S_∞ }
```

Тоді S₀ — підмножина S_∞, що складається з дерев глибини рівно 1, |S₀|=64, узгоджено з Частиною I. **SUBIT-64 є скінченною апроксимацією глибини 1 об'єкта S_∞.**

**Простір правил.** У загальному випадку

```
ℛ = { f : S_∞ → S_∞ | f обчислювана в розширеному сенсі (задана скінченним описом) }
```

ℛ тут може бути нескінченною множиною, і сам S_∞ є нескінченним уже за побудовою. Разом це знімає обмеження Твердження 5.1: генуїнно неперіодична (chaotic у строгому сенсі) динаміка стає математично можливою.

## 14. Динаміка й категорія на рівні S_∞

Оператор еволюції F: S_∞ × ℛ → S_∞ × ℛ, F(s, ρ) = (f_ρ(s), g(ρ, s)) — формально ідентичний до Частини II, але тепер визначений на нескінченному S_∞. Усі означення розділів 6–11 переносяться дослівно із заміною S₀ на S_∞, за умови, що топологія простору ℛ визначена (розділ 21).

**Множина атракторів.** Fix(F) = {ŝ ∈ S_∞ × ℛ | F(ŝ) = ŝ} є найменшою STABLE-множиною відносно F.

**Категорія.** Означення 8.1–8.2 переносяться дослівно із заміною S_X ⊆ S₀ на S_X ⊆ S_∞. Застереження щодо оборотності F_X в конструкції експоненціала лишається чинним і на цьому рівні.

**Універсальний об'єкт (повна версія).** U = (S_∞ × ℛ*, F*, g*); для будь-якого X ∈ SUBIT постулюється морфізм φ_X: U → X через кодування encode_X: S_X → S_∞, encode_R: ℛ_X → ℛ*.

## 15. Семантичні ультраметрики d_S і d_ω

### 15.1. Структурна ультраметрика d_S

Побудова не може спиратися на d_Ω (вона сама залежить від Ω — це було б колом). Означимо структурну ультраметрику безпосередньо на деревах.

**Означення 15.1 (глибина розходження).** Для s, t ∈ S_∞:

```
δ(s, t) := 0,  якщо s, t — листки з різними мітками, або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),  якщо s = (w,x,y), t = (w',x',y')
```

**Означення 15.2 (d_S).**

```
d_S(s, t) := 2^(−δ(s,t))
```

**Твердження 15.1 (властивості d_S).** d_S — ультраметрика на S_∞; (S_∞, d_S) — компактний простір.

*Доведення (ескіз).* Ультраметричність — стандартний аргумент «першої розбіжності», застосований до структури дерева. Компактність — за лемою Кеніга; (S_∞, d_S) гомеоморфний зліченному добутку скінченних дискретних просторів, компактність — за теоремою Тихонова. ∎

### 15.2. Метрика першої розбіжності d_ω

**Означення 15.3 (d_ω).** Для ŝ, t̂ ∈ S_∞ × ℛ:

```
n₀(ŝ, t̂) := min{ n ≥ 0 : ω(Fⁿŝ) ≠ ω(Fⁿt̂) }
d_ω(ŝ, t̂) := 2^(−n₀),  якщо n₀ визначено
d_ω(ŝ, t̂) := 0,        якщо ω(Fⁿŝ) = ω(Fⁿt̂) для всіх n ≥ 0
```

**Теорема 15.2 (властивості d_ω).** d_ω — псевдоультраметрика на S_∞ × ℛ; стає ультраметрикою на факторпросторі (S_∞ × ℛ)/~_ω, де ŝ ~_ω t̂ ⟺ ω(Fⁿŝ) = ω(Fⁿt̂) для всіх n.

*Доведення.* Симетричність очевидна. Сильна нерівність трикутника — той самий аргумент транзитивності, що й для d_S. ∎

**Означення 15.4 (d_Ω — факторметрика).**

```
d_Ω(ŝ, t̂) := 2^(−n₁),   n₁ := min{ n : Ω_traj(Fⁿŝ) ≠ Ω_traj(Fⁿt̂) }
```

**Твердження 15.3.** d_Ω є факторметрикою d_ω за відношенням «однакова Ω_traj-траєкторія». Зокрема, d_Ω(ŝ, t̂) = 0 тягне d_ω(ŝ, t̂) = 0, але не навпаки.

**Твердження 15.4 (нульвимірність).** (S_∞ × ℛ₀)/~_ω з d_ω — тотально незв'язний, нульвимірний простір.

*Доведення.* Спадкує від S_∞ × ℛ₀ (компактний, нульвимірний) і факторизації за відкритим відношенням. ∎

**Зауваження (псевдометричність).** d_ω, строго кажучи, є псевдоультраметрикою на S_∞ × ℛ; вона стає справжньою ультраметрикою на факторпросторі.

## 16. Метатеоретичні властивості

**Несуперечність.** У скінченній апроксимації (Частини I–III) усі аксіоми виконуються в скінченній моделі. Для повного S_∞ несуперечність спадкує від коректності побудови кінцевої коалгебри функтора A ⊔ X³ (Додаток B).

**Аналогія з неповнотою.** Якщо ℛ достатньо багата, щоб містити правила самоопису системи, правдоподібно очікувати — за аналогією з теоремами Гьоделя — існування тверджень внутрішньої мови, істинних (F(P) = P), але не виведених синтаксично. Це евристична аналогія, а не доведена теорема (статус ❓).

## 18. Канонічна побудова P(τ): від траєкторії до класифікованої множини

### 18.1. Постановка задачі

Означення 6.1 (класифікатор Ω) і Означення 15.3 (метрика d_ω, що вживає ω(ŝ₀)) разом залишають незамкненою одну передумову: як від спостереженої траєкторії τ(ŝ₀)=(ŝ₀,ŝ₁,…) перейти до множини P ⊆ S_∞ × ℛ, яку класифікує Ω. Потрібна функція

```
P : Траєкторії(S_∞ × ℛ) → Класифіковані об'єкти ∪ {⊥}
```

що задовольняє чотири вимоги:

- **(У0, неколапс)** — P(τ) не повинна апріорно визначати Ω-клас.
- **(У1, узгодженість)** — на скінченному рівні відтворює типологію Твердження 5.1.
- **(У2, інваріантність)** — не залежить від довільних параметрів спостереження.
- **(У3, явність відмови)** — випадок нелокалізованої асимптотичної поведінки позначається явно (⊥), а не мовчки потрапляє в один із чотирьох класів.

### 18.2. ω-границя і чому вона завжди непорожня (для ℛ₀)

**Означення 18.1.** ω(ŝ₀) := {ŝ ∈ S_∞ × ℛ₀ | ∃ підпослідовність (nₖ): ŝ_{nₖ} → ŝ у метриці d_S × d_S}.

**Твердження 18.1 (непорожність).** Для ℛ₀: ω(ŝ₀) ≠ ∅ для будь-якого ŝ₀.

*Доведення.* S_∞ × ℛ₀ компактний (Теорема 21.2); застосовуємо Больцано–Вейєрштрасс. ∎ *(Формальне доведення в Lean 4 — Додаток D, теорема T7, статус ⚠️.)*

**Застереження для ℛ₁.** Для ℛ₁ компактність не гарантована; усі подальші твердження формулюються окремо для ℛ₀ (безумовно) і ℛ₁ (умовно, з явним припущенням неперервності F).

### 18.3. Чому «P(τ) := ω(ŝ₀)» — неправильна відповідь

**Твердження 18.2 (колапс).** Якщо P(τ) := ω(ŝ₀), умова F(P) = P (означення STABLE) виконується завжди — Ω(P(τ)) = STABLE для будь-якої траєкторії за будь-яких обставин.

*Доведення.* F(ω(ŝ₀)) = ω(ŝ₀) за Твердженням 18.4 (інваріантність ω-границі за неперервності F). ∎

Ця побудова відхиляється: вона задовольняє У1–У3 формально, але порушує У0.

### 18.4. Три типи досягнення

**Ключова корекція відносно v5.2.** У v5.2 момент `m(ŝ₀) := min{n : ŝₙ ∈ ω(ŝ₀)}` передбачався існуючим. Це хибно.

**Контрприклад 18.1.** Нехай S_∞ містить траєкторію x_n = 1/(n+1) → 0. Тоді ω = {0}, але жоден x_n ≠ 0. Отже, m(ŝ₀) не існує.

**Означення 18.2 (типи досягнення).** Нехай ω := ω(ŝ₀) ≠ ∅.

- **(A) ATTAINED** — ∃n ≥ 0: ŝₙ ∈ ω. Тоді m(ŝ₀) := min такого n, і m < ∞.
- **(B) ASYMPTOTIC** — ∀n: ŝₙ ∉ ω, але dist(ŝₙ, ω) → 0 в d_S.
- **(C) INDETERMINATE** — ω = ∅, або dist(ŝₙ, ω) ↛ 0, або обчислювальних ресурсів бракує для розрізнення A, B, C.

### 18.5. Двоосьова класифікація

**Означення 18.3 (S-компонента).** Клас інваріантної частини:

| S(τ) | Умова |
|---|---|
| STABLE | ω = {p}, F(p) = p |
| CYCLIC | ω — скінченна орбіта довжини k > 1 |
| METASTABLE | ω ⊊ closure(τ), F(ω) = ω, але ω не мінімальна |
| CHAOTIC | ω нескінченна, мінімальна, з додатною топологічною ентропією |

**Означення 18.4 (Ω_traj).** Остаточна класифікація траєкторії:

```
Ω_traj(τ) := (S(τ), Att(τ)) ∈ Ω × {ATTAINED, ASYMPTOTIC, INDETERMINATE}
```

**Означення 18.5 (підсумкова функція P).**

```
P(τ) := (A(τ), Ω_traj(τ), certificate)
```

де:

- **A(τ)** — атракторна компонента:
  - тип (A): A(τ) := {ŝ_m}, m = m(ŝ₀);
  - тип (B): A(τ) := ω(ŝ₀);
  - тип (C): A(τ) := ⊥.
- **Ω_traj(τ)** — двоосьова класифікація.
- **certificate** — сертифікат класифікації.

### 18.6. Перевірка вимог

**Твердження 18.3 (У0, неколапс).** Існують траєкторії з різними Ω_traj. Зокрема, (STABLE, ATTAINED) ≠ (CHAOTIC, ASYMPTOTIC). *(Формальне доведення в Lean 4 — Додаток D, теорема T9.)*

**Твердження 18.4 (У1, узгодженість).** На скінченному рівні SUBIT⁺: P(τ) відтворює типологію Твердження 5.1. Для нерухомої точки: Ω_traj = (STABLE, ATTAINED). Для орбіти: Ω_traj = (CYCLIC, ATTAINED). Для передперіодичної: Ω_traj = (S(ω), ATTAINED), де S(ω) ∈ {STABLE, CYCLIC}.

**Твердження 18.5 (У2, інваріантність).** P(τ) залежить лише від нескінченної траєкторії τ, не від горизонту спостереження N.

**Твердження 18.6 (У3, явність відмови).** Випадок (C) повертає ⊥, і це не змішується з (B).

### 18.7. Сертифікат класифікації

**Означення 18.6.** Сертифікат для P(τ) — це JSON-об'єкт:

```json
{
  "trajectory_hash": "sha256:...",
  "s_component": "STABLE" | "METASTABLE" | "CYCLIC" | "CHAOTIC",
  "att_type": "ATTAINED" | "ASYMPTOTIC" | "INDETERMINATE",
  "witness": {
    "m": 3,
    "fixed_point": "ME-EAST-SPRING",
    "k": null
  },
  "omega_set": ["..."],
  "core_version": "0.3.0",
  "rule_class": "R_0" | "R_1"
}
```

Сертифікат має бути **машинно перевірюваним**: незалежна реалізація CORE повинна підтвердити його за поліноміальний час.

### 18.8. Наслідок для протоколу застосування: Крок 0 і Крок 0'

Побудова P(τ) передбачає, що емпіричні дані вже подані як траєкторія в S_∞ × ℛ. Тому протокол застосування доповнюється:

- **Крок 0 (кодування).** Обґрунтування розбиття неперервного простору вимірів на скінченний алфавіт A. Точний аналог породжувального розбиття в символічній динаміці (Kolmogorov, 1958; Sinai, 1959).
- **Крок 0' (причинність).** Перевірка, що обрані правила ρ належать ℛ₀ (причинні) або, якщо ℛ₁, то F неперервний. Без цього всі твердження §18.2–18.3 стають умовними.

# ЧАСТИНА V. Застосування та методологія

## 19. Епістемологічний статус і протокол застосування

### 19.1. Природа формальних результатів цієї специфікації

Усі теореми й твердження Частин I–IV є твердженнями про саму нотацію. Жодне з них не встановлює й не може встановити, що будь-яка конкретна емпірична система, до якої застосовують апарат SUBIT-∞, дійсно еволюціонує за правилом ρ, яке дослідник обирає для її опису, або що присвоєння конкретній емпіричній множині станів певного Ω-класу є істинним у сенсі відповідності реальності.

### 19.2. Функція апарату в дослідницькій роботі

SUBIT-∞ функціонує як інструмент структурування гіпотез, а не як їх джерело чи підтвердження:

- змушує явно сформулювати конкретний причинний механізм (ρ) там, де наративний виклад залишає його імпліцитним;
- дає компактну мову для розрізнення типів переходу, яка спрямовує пошук конкретної емпіричної ознаки;
- дає кількісну (d_ω) або якісну (Ω_traj) мову для порівняння того, наскільки й де саме розходяться передбачення конкуруючих гіпотез.

### 19.3. Протокол застосування

**Крок 0 (кодування).** Перш ніж формулювати гіпотези, дослідник повинен явно зафіксувати й обґрунтувати розбиття, через яке емпіричні дані перетворюються на послідовність елементів алфавіту A (розділ 18.8). Для наративних, агентних систем (історичні, соціальні) природним розбиттям зазвичай слугує WHO/WHERE/WHEN (Частина I). Для систем без природного дискретного алфавіту (неперервні фізичні виміри) дослідник повинен: (а) явно застерегти, що результат класифікації Ω може бути артефактом вибору розбиття, а не властивістю самої системи, і (б) перевірити чутливість висновку до вибору розбиття — чи зберігається Ω-клас при його огрубленні чи уточненні.

**Крок 0' (причинність).** Перевірка, що обрані правила ρ ∈ ℛ₀ або, якщо ρ ∈ ℛ₁, то відповідний F неперервний (розділ 18.8). Без цього всі твердження §18 стають умовними (⚠️).

**Основні кроки:**

1. Визначити емпіричну систему та дослідницьке питання.
2. Сформулювати конкуруючі гіпотези як явні, відмінні одне від одного правила ρ₁, ρ₂, …
3. Для кожного ρᵢ вивести емпіричне передбачення, відмінне від передбачень інших гіпотез.
4. Зібрати або розглянути наявні першоджерельні дані, що підтверджують чи спростовують кожне передбачення.
5. Лише після кроку 4 — за потреби — присвоїти Ω_traj-клас переходу (через канонічну побудову P(τ), розділ 18) як компактний підсумковий ярлик уже здобутого емпіричного висновку. Ω_traj-клас ніколи не замінює крок 4.
6. У викладі результатів явно розрізняти: (а) формально доведене в самій нотації; (б) підтверджене конкретним емпіричним джерелом; (в) інтерпретаційна пропозиція дослідника.

## 20. Статуси доказовості

### 20.1. Навіщо цей розділ

Специфікація SUBIT v5.2 змішувала три різні речі: (а) **формальну визначеність** поняття, (б) **доведеність** твердження, (в) **емпіричну підтримку**. Це призводило до ситуацій, коли відкрите питання використовувалося як аксіома на наступному рівні, або коли методологічне застереження плуталося з теоремою.

§20 вводить **нормативну систему статусів** для кожного твердження SUBIT.

### 20.2. Шість статусів

| Позначка | Назва | Значення | Що потрібно для присвоєння |

| ⊥ | Невизначено | Недостатньо підстав для висновку | — |

### 20.3. Правила використання

**Правило 20.1 (заборона на аксіоматизацію).** Твердження зі статусом ❓ або ⊥ **не можна** використовувати як аксіому або передумову на наступному рівні ієрархії.

**Правило 20.2 (обов'язковість передумов).** Твердження зі статусом ⚠️ зобов'язане супроводжуватися **явним** списком додаткових передумов.

**Правило 20.3 (заборона на змішування).** ❌ не можна трактувати як ❓. ❌ означає наявність контрприкладу; ❓ — його відсутність.

**Правило 20.4 (заборона на підміну).** 📊 не можна трактувати як ✅. Емпірична підтримка не є математичним доказом.

**Правило 20.5 (обов'язковість ⊥).** Якщо обчислювальних ресурсів, даних або формальних підстав недостатньо, статус має бути ⊥.

**Правило 20.6 (промоція та демоція).** Зміна статусу можлива лише за наявності нового артефакту: ❓ → ✅ (повний доказ); ❓ → ❌ (контрприклад); ⚠️ → ✅ (усунення передумов); ✅ → ❌ (виявлення помилки в доказі + контрприклад); 📊 → ❌ (суперечливі дані); ⊥ → будь-що (поява ресурсів/даних/доказів).

**Правило 20.7 (успадкування).** Імплікація не переносить статус автоматично.

### 20.4. Відношення до чотирьох значень Белнапа

**Застереження 20.1.** Шість статусів доказовості **не слід** ототожнювати з чотирма значеннями Белнапа T, F, B, N з §1.

| Поняття | Область |
|---|---|

| ✅, ⚠️, ❌, ❓, 📊, ⊥ | Епістемічний статус твердження про SUBIT |

## 21. Топологія простору правил ℛ

### 21.1. Діагноз v5.2

v5.2 не визначає топології на ℛ, але мовчки використовує компактність S_∞ × ℛ у §18.3. Крім того, твердження «F неперервний для будь-якого f_ρ, заданого скінченним описом» хибне: скінченність опису не тягне неперервності.

### 21.2. Причинні функції

**Означення 21.1 (глибина розходження).** Для s, t ∈ S_∞:

```
δ(s, t) := 0,  якщо s, t — листки з різними мітками, або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),  якщо s = (w,x,y), t = (w',x',y')
```

**Означення 21.2 (причинна функція).** f : S_∞ → S_∞ називається **причинною**, якщо:

```
∀s,t ∈ S_∞: δ(s, t) ≥ n ⟹ δ(f(s), f(t)) ≥ n
```

Інтуїтивно: f не «зливає» дерева, які розрізняються лише на глибині ≥ n.

**Означення 21.3.** `ℛ₀ := { f : S_∞ → S_∞ | f причинна }`.
**Означення 21.4.** `ℛ₁ := { f : S_∞ → S_∞ | f обчислювана }` (ширший клас; F на ньому може бути розривним).

### 21.3. Топологія на ℛ₀

**Означення 21.5 (топологія поточкової збіжності).** Для f, g ∈ ℛ₀:

```
d_ℛ(f, g) := 2^(−n₀(f,g)),   n₀(f,g) := min{ n : f|_{S_∞^{(n)}} ≠ g|_{S_∞^{(n)}} }
```

де S_∞^{(n)} — множина дерев глибини ≤ n.

**Твердження 21.1.** d_ℛ — ультраметрика на ℛ₀.

**Теорема 21.2 (компактність ℛ₀).** (ℛ₀, d_ℛ) — компактний гаусдорфовий простір.

*Доведення.* Кожна S_∞^{(n)} скінченна. Причинна f однозначно визначається своїми обмеженнями f_n : S_∞^{(n)} → S_∞^{(n)}, узгодженими: f_{n+1}|_{S_∞^{(n)}} = f_n. Отже,

```
ℛ₀ ≅ lim←_n (S_∞^{(n)})^{S_∞^{(n)}}
```

— обернена границя скінченних множин. За теоремою Тихонова для зліченного добутку скінченних дискретних просторів ця границя компактна. Гаусдорфовість спадкується. ∎ *(Формальне доведення в Lean 4 — Додаток D, теорема T6.)*

**Наслідок 21.1.** S_∞ × ℛ₀ компактний.

**Наслідок 21.2.** Для будь-якого неперервного F : S_∞ × ℛ₀ → S_∞ × ℛ₀ і будь-якого ŝ₀: ω(ŝ₀) ≠ ∅.

### 21.4. Неперервність F на ℛ₀

**Твердження 21.3.** Для f ∈ ℛ₀ відображення F_f : S_∞ → S_∞, F_f(s) := f(s), є неперервним у d_S.

*Доведення.* Причинність f означає: δ(s, t) ≥ n ⟹ δ(f(s), f(t)) ≥ n. Це саме умова рівномірної неперервності в ультраметриці. ∎

**Твердження 21.4.** F : S_∞ × ℛ₀ → S_∞ × ℛ₀ неперервний у топології добутку (за умови, що g причинна за ρ і неперервна за s).

### 21.5. ℛ₁ та її межі

**Застереження 21.1.** Для ℛ₁ компактність не гарантована. Контрприклад: сімейство f_n(s) := s, якщо глибина s < n, інакше — лист з міткою n mod 4, не має збіжної підпослідовності в d_ℛ.

**Нормативне рішення.** Усі твердження, що використовують компактність S_∞ × ℛ, формулюються **окремо**:

- для ℛ₀ — безумовно ✅;
- для ℛ₁ — умовно ⚠️, з явним припущенням: «F неперервний» або «S_∞ × ℛ₁ компактний».

### 21.6. Класифікація правил за причинністю

| Клас | Визначення | Компактність | Неперервність F |
|---|---|---|---|
| ℛ₀ | причинні | ✅ | ✅ |
| ℛ₁ | обчислювані | ❌ | ⚠️ |
| ℛ₀ ∩ ℛ₁ | причинні й обчислювані | ✅ | ✅ |

**Твердження 21.5.** ℛ₀ ∩ ℛ₁ ≠ ∅: тотожне відображення id належить обом.

## 22. Двоосьова класифікація Ω_traj

### 22.1. Мотивація

Скалярна класифікація Ω (4 значення) недостатня, бо змішує два незалежні аспекти динаміки: **структуру границі** (що саме є ω-границею) і **спосіб досягнення** (як траєкторія наближається до цієї границі). Траєкторія, що осідає на нерухому точку за скінченний час, і траєкторія, що асимптотично наближається до неї, мають одну й ту саму ω-границю, але різну динамічну природу.

### 22.2. Означення

**Означення 22.1.** Ω_traj := Ω × {ATTAINED, ASYMPTOTIC, INDETERMINATE} — 12-елементна множина.

**Означення 22.2.** Для траєкторії τ:

```
Ω_traj(τ) := (S(τ), Att(τ))
```

де S(τ) — клас інваріантної частини (§18.5), Att(τ) — тип досягнення (§18.4).

### 22.3. Метрика на Ω_traj

**Означення 22.3.** Відстань між траєкторіями:

```
d_ω(τ₁, τ₂) := 2^(−n₀),   n₀ := min{ n : Ω_traj(Fⁿτ₁) ≠ Ω_traj(Fⁿτ₂) }
```

Це — та сама d_ω з §15.2, переформульована в термінах Ω_traj.

### 22.4. Реалізація

Двоосьова класифікація реалізована в `subit-core` v0.3.0 (`omega::classify_trajectory`) і `subit-infinity` v0.2.0 (`lazy_p_tau::classify`). Демонстраційний бінарник `lazy-demo` показує три різні Ω_traj:

```
identity       S=Stable, Att=Attained, cycle=1
grow_chain     S=Stable, Att=Asymptotic, cycle=0
shift_spine    S=Chaotic, Att=Indeterminate, cycle=0
```

Це — демонстрація У0 (неколапс) у дії.

## Додаток B. Коректність конструкції S_∞

**Лема B.1.** Кінцева коалгебра функтора Φ'(X) = X × X × X на категорії множин ізоморфна одноелементній множині: νX. X³ ≅ 1.

*Доведення.* Кінцеву коалгебру функтора, що зберігає границі, можна обчислити як границю термінальної послідовності 1 ← Φ'(1) ← Φ'²(1) ← …, де 1 — термінальний об'єкт. Оскільки 1×1×1 ≅ 1, послідовність стабілізується на першому кроці: Φ'(1)=1³≅1, і так далі. Границя стабільної послідовності дорівнює самій цій точці, тож νX.X³ ≅ 1. ∎

**Наслідок B.2.** Будь-яка спроба вкласти алфавіт A потужності більшої за 1 у νX.X³ як листки (ототожнюючи a∈A з розв'язком s=(s,s,s)) зазнає невдачі: усі такі розв'язки бісимулярні між собою й ототожнюються в одну точку — точна відповідність Лемі B.1.

**Лема B.3.** Кінцева коалгебра функтора Φ(X)=A ⊔ X³ не вироджується в одноелементну множину, якщо |A|>1.

*Доведення (ескіз).* Термінальна послідовність для Φ: X₀=1, X₁=A ⊔ 1³=A ⊔ 1, X₂=A ⊔ (A ⊔ 1)³, … Оскільки на кожному кроці зберігається копія A як окрема, нескорочувана компонента коопродукту (X ⊔ 1 ≇ 1 для |X|>0), послідовність не стабілізується на одноелементній множині; її границя містить принаймні |A| попарно різних елементів. Отже S_∞=νX.(A ⊔ X³) містить принаймні |A|=4 різних точки, і зокрема містить S₀=A³ як підмножину дерев глибини 1, |S₀|=64. ∎ *(Формальне доведення в Lean 4 — Додаток D, теорема T10.)*

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω_set, Ω_state, Ω_traj, d_S, d_ω, U, ℒ, P ),   
S_∞ = νX.(A ⊔ X × X × X)
```

де S_∞ — рекурсивний простір дерев із мітками з A, що містить S₀=A³ (|S₀|=64) як вкладену скінченну апроксимацію глибини 1; ℛ — простір внутрішніх правил еволюції, розділений на ℛ₀ (причинні, компактний) і ℛ₁ (обчислювані); F — оператор динаміки; g — оператор метадинаміки; Ω_set — динамічний класифікатор стабільності множин, що утворює алгебру Гейтінга на чотирьох значеннях; Ω_state — точкова класифікація; Ω_traj = (S, Att) — двоосьова класифікація траєкторій; d_S — структурна ультраметрика на S_∞; d_ω — метрика першої розбіжності ω-границь; U — універсальний об'єкт-інтерпретатор; ℒ — внутрішня мова динамічної теорії типів і модальної логіки; P — канонічна функція, що зіставляє довільній траєкторії класифікований об'єкт (A(τ), Ω_traj(τ), certificate) або явну відмову ⊥.

**Центральна теза.** Правило належить стану. Істина визначається стабільністю: F(P) = P. Відстань між траєкторіями вимірюється горизонтом їхньої першої розбіжності. Категорія є Ω-класифікованою (не топосом). Простір станів — дерево з мітками, а не немарковане дерево. Класифікатор Ω застосовується не до самої траєкторії безпосередньо, а до канонічно побудованої множини P(τ), і ця побудова сама підлягає явним, доведеним обмеженням.

**Центральне методологічне положення.** Формальна коректність цієї нотації не переносить сама по собі жодного емпіричного змісту на будь-яку конкретну систему, описану її мовою: висновок про те, що щось у світі є «stable» чи «chaotic», завжди залишається інтерпретаційним кроком дослідника, який потребує незалежного емпіричного обґрунтування, і який починається з явного обґрунтування самого кодування емпіричних даних у мову SUBIT (Крок 0).

**Центральне інженерне положення v6.0.** Кожне твердження специфікації має явний статус доказовості (§20): ✅ / ⚠️ / ❌ / ❓ / 📊 / ⊥. Жодне твердження зі статусом ❓ або ⊥ не використовується як аксіома на наступному рівні. Це і є перехід від SUBIT-∞ як формальної мови до SUBIT-VERIFIED як перевірюваної теорії.
