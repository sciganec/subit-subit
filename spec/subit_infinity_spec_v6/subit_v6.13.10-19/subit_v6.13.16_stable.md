## 0. Статус, прапорці, правила читання

Ця редакція консолідує дві лінії: v6.10.1 (мою консолідовану редакцію) і альтернативну редакцію v6.10.1.1 «STABLE». З альтернативної редакції прийнято чотири елементи (контракт (H1)–(H3), повний доказ верхньої оцінки ентропії у W5, типізацію одометра через enc\_αβ, кваліфікатори «за H» у реєстрі); відновлено обґрунтування, які в ній були скорочені (§0.5, §9.2, T9, §11.5); виправлено кілька неточностей (перелік у §0.6). Архітектура SUBIT-∞ не змінена.

**Значення слова «стабільна».** Це редакційна стабільність: текст зафіксовано (архітектурний і математичний freeze), нові твердження в цій лінії не додаються. Це **не** означає перевіреності: у Lean перевірено лише твердження з Додатку Е (перелік у Додатку Е; решта — ні), жоден рядок коду реалізації не запускався проти цього тексту, незалежного рецензування не було. Наступні кроки: Lean-формалізація, реалізація й тести, або v7.x із новою архітектурною ідеєю.

### 0.2. Статуси тверджень

| Позначка | Значення |
| :-- | :-- |
| ВИЗНАЧЕНО | об'єкт чи операція задані явно |
| DP-f | повний доказ виписано у цьому тексті |
| DP-s | схема доведення або посилання на стандартний результат; повного аргументу в тексті немає. Не є «доведенням на папері» в сенсі прапорця PROVED ON PAPER (§0.1) |
| DP-f за EXT-1 | повний доказ, але спирається на зовнішню теорему EXT-1 (§11.4) |
| DP-f за H | повний доказ; (H1)–(H3) із §10.2 входять до гіпотез твердження. Якщо ж (H) перевіряється в самому твердженні чи конструкції (лема E, свідки W1–W5), мітка — просто DP-f |
| УМОВНО | доведено лише за зазначених припущень |
| ВІДКРИТО | не встановлено |
| ВІДКЛИКАНО | не можна використовувати як чинну теорему |
| НЕ ПІДТВЕРДЖЕНО | немає свідчень про реалізацію, тест або доказ |

Правило v6.11: DP-f ставиться тільки тоді, коли доказ справді є в тексті. У v6.9.3 частина тверджень (C1–C7, T3, T4, T7, K1, K3, M1) мала DP-f або DP-s без виписаного аргументу; тут для них доказ дописано. Стандартні теореми (Банаха, Арцела–Асколі, Тихонова) вживаються лише зі статусом DP-s або після виписування локальної леми з повним доказом. Кваліфікатор «за H» не знижує повноти доказу, а лише фіксує його передумови.

### 0.3. Принцип незгортання

Без окремого доказу не можна ототожнювати:

- стан і траєкторію; траєкторію та її ω-границю;
- нерухому точку та періодичний цикл;
- математичний клас і обчислювальний статус;
- причинність (ℛ₀) та обчислюваність (ℛ₁);
- категорію Dyn і повну категорію SUBIT;
- формальну класифікацію та емпіричну інтерпретацію;
- три класифікатори: точок, множин, траєкторій;
- `F_tree` (функтор) і `D₀`/`D∞` (динамічні оператори);
- `NOT_APPLICABLE` і `NON_CHAOTIC`;
- **ентропію і мінімальність**: це незалежні ознаки множини (§4.3);
- `Min`-код і `Min_D(ω)`;
- `O : B → B`, `Õ : C → C` і `T : Y → Y` у W4;
- `emb₃ : A³ → S∞` (§9.1) і `enc_αβ : {0,1}^ℕ → C` (§11.6).

### 0.4. Архітектурна ієрархія

```text
SUBIT-64 ≼ₐ SUBIT⁺ ≼ₐ SUBIT-CAT ≼ₐ SUBIT-∞
```

`X ≼ₐ Y` означає, що `Y` розширює описову архітектуру `X`. Це не гарантує ін'єкції множин чи вкладення категорій.

## 1. Алфавіт і простір S₀

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, 4 елементи.

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. LEAN-CHECKED (`belnap_truth_matches_spec`, `belnap_info_matches_spec`). Порядок інформації: N < F < B і N < T < B. Властивості білаттису не переносяться на динаміку S∞ без окремого означення. ВИЗНАЧЕНО.

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ) із S₀ × `ℛ_fin`. Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`, динаміка

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори, помилки й ресурсні переривання — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО (це означення, перечитане як автомат). Сильніша теза про самореферентну перевагу — ВІДКРИТО.

**Твердження 2.4′ (A4, вкладення автомата довільного розміру).** Нехай (Q, δ) — автономний скінченний автомат без вхідного алфавіту: Q = {0,…,n−1}, n ≥ 1, δ : Q → Q тотальна. Нехай m ∈ {1,…,64}, t ≥ 0, m + t ≤ 64 і k := ⌈n/m⌉ ≤ 64^t. Тоді існують ℛ_fin = {ρ_0,…,ρ_{k−1}} з попарно різними ρ_r : S₀ → S₀ і ін'єкція ι : Q → S₀ × ℛ_fin, для якої D₀(ι(q)) = ι(δ(q)) для всіх q ∈ Q. Для довільної скінченної Q перенумерація на {0,…,n−1} формалізована (LEAN-CHECKED: `A4_fintype`, `A4Fin.lean`). DP-f (Lean: `A4_general`, `Subit/A4.lean`).

*Доведення.* Для q ∈ Q покладемо r(q) := ⌊q/m⌋ і s(q) := q mod m ∈ {0,…,m−1} ⊂ S₀. Для r < k задаємо:

1. ρ_r(s) := δ(mr + s) mod m для s < m (коректно, якщо mr + s < n; інакше — 0);
2. ρ_r(m + j) := j-та цифра числа r у записі за основою 64, для j < t;
3. решту значень S₀ — 0. Тоді ρ_r : S₀ → S₀ коректно, бо всі значення менші за 64.
4. g₀(ρ_r, s) := ρ_{⌊δ(mr+s)/m⌋} для s < m і mr + s < n; інакше ρ_0.

*Попарна різність.* Якщо ρ_r = ρ_{r'}, то їхні значення в точках m + j збігаються для j < t, тобто цифри r і r' у записі за основою 64 збігаються. Оскільки r, r' < k ≤ 64^t, маємо r = r'. Тому ℛ_fin — множина з k різних елементів.

*Вкладення.* Покладемо ι(q) := (s(q), ρ_{r(q)}). Тоді D₀(ι(q)) = (ρ_{r(q)}(s(q)), g₀(ρ_{r(q)}, s(q))) = (δ(q) mod m, ρ_{⌊δ(q)/m⌋}) = ι(δ(q)). Ін'єктивність: з ι(q) = ι(q') випливає r(q) = r(q') (попарна різність) і s(q) = s(q'), тож q = m·r(q) + s(q) = q'. ∎

*Зауваження (чому потрібні мітки).* Конструкція без пунктів 2–3 хибна: правила блоків можуть збігатися як функції. Контрприклад: циклічний зсув на 128 станах дає ρ_0 = ρ_1 (s ↦ s+1 mod 64), і тоді ι(0) = ι(64). Тому версія v6.11.9 не підтримувалася цим доведенням; в Rust-версії з індексами цей збій не було видно.

**Область.** Твердження 2.4′ стосується автономних систем без вхідного алфавіту з довільним скінченним числом станів. Воно не стверджує симуляції DFA зі входом, універсальної симуляції чи універсальності SUBIT⁺ як λ-інтерпретатора.

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7. Q22 закрито твердженням 2.4′.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω\_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀ означимо

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** У Q₀ для кожного ŝ число m(ŝ) скінченне. DP-f. *Доведення.* Стани ŝ, D₀(ŝ), …, D₀^N(ŝ) при N = #Q₀ — це N + 1 елемент множини з N елементів, тож два збігаються (Діріхле): D₀^i(ŝ) = D₀^j(ŝ), i < j. Отже, множина в означенні m непорожня. ∎

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f. *Доведення.* За P1 пара (m, p) визначена однозначно. Класи — це три взаємовиключні умови на неї: m = 0 і p = 1; m = 0 і p ≥ 2; m ≥ 1. ∎

**Твердження 3.1.3 (P3, точний режим).** Алгоритм

```text
вхід: ŝ₀;  visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, #Q₀:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m
        повернути COMPUTED(клас, m, p, цикл)
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
```

завжди завершується з результатом COMPUTED, і m, p збігаються з означенням 3.1. Гілка `RESOURCE_EXCEEDED` недосяжна. DP-f. *Доведення.* За Діріхле повторення настає не пізніше n = #Q₀. Перший повтор ŝₙ = ŝ\_m з найменшим n дає саме мінімальні m і p = n − m. ∎

**Твердження 3.1.4 (P3′, бюджетований режим).** Якщо ліміт кроків N\_max < #Q₀, то для деяких систем, початкових станів і горизонтів гілка `RESOURCE_EXCEEDED` досяжна (недостатній горизонт не гарантує її для кожної системи: повтор може знайтися раніше), і її результат **не є класифікацією**. DP-f (той самий алгоритм, обрізаний цикл).

### 3.2. Нескінченний рівень Ω\_point^∞

Область — S∞ × R за припущення (H) (§10.2). Для ŝ ∈ S∞ × R

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY\_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. DP-f. *Доведення.* Якщо m = ∞, то p = ∞ за означенням; якщо m < ∞, то p < ∞, бо множина в його означенні містить число з означення m. Далі — розбиття за значеннями (m, p), як у 3.1.2. ∎

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. Це область усього §4–§5. Два приклади: Q₀ = S₀ × `ℛ_fin` з дискретною метрикою і D₀; X = S∞ × R з d̂ і D∞ за (H). P ⊆ K — **непорожня**, D\[P\] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT\_FIXED | D\[P\] = P і D(x) = x для всіх x ∈ P |
| INVARIANT\_DYNAMIC | D\[P\] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC\_SET | D\[P\] ≠ P, μ(P) = 0, 2 ≤ p\_set(P) < ∞ |
| EVENTUALLY\_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY\_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

*Доведення.* Довільна P має одне значення μ(P). (a) μ = ∞: клас APERIODIC. (b) μ = 0: є n ≥ 1 з Dⁿ\[P\] = P, тож p\_set ≤ n скінчене. Якщо p\_set = 1, то D\[P\] = P і рівно одна з двох: INVARIANT\_FIXED, якщо D = id на P, інакше INVARIANT\_DYNAMIC. Якщо p\_set ≥ 2, то D\[P\] ≠ P, і маємо PERIODIC\_SET. (c) 1 ≤ μ < ∞: є n > μ з Dⁿ\[P\] = Dᵐ\[P\], тож π ≤ n − μ скінчене; π = 1 дає EVENTUALLY\_FIXED, π ≥ 2 — EVENTUALLY\_PERIODIC. Взаємна виключність: D\[P\] = P влече μ = 0, а PERIODIC\_SET вимагає D\[P\] ≠ P; класи з μ ≥ 1 відрізняються значенням π. ∎

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f. *Доведення.* Якщо D\[P\] = P — перший клас. Інакше: якщо D\[P\] ∩ P = ∅ — другий. Інакше перетин непорожній, D\[P\] ≠ P, і рівно одне з: D\[P\] ⊊ P, P ⊊ D\[P\], або множини непорівнювані. ∎

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна (замкнена в K); (Π2) D\[P\] = P; (Π3) D|ₚ : P → P неперервне (у допустимій системі виконується автоматично). Якщо не виконано хоч одну — «передумови не виконано».

Топологічна ентропія `h_top(D|P)` — за Боуеном: через (n, ε)-роздільні множини в метриці dₙ(x, y) = max\_{i\<n} d(Dⁱx, Dⁱy), `h_top` = lim\_{ε→0} limsup\_n (1/n) log s(n, ε), де s(n, ε) — максимальна потужність такої множини.

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої в P підмножини Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** `NOT_APPLICABLE` ≠ `NON_CHAOTIC`: перше — критерій не застосовується, друге — застосовано і не справджено.

**Застереження 4.3.3 (зміна проти v6.9.3).** У v6.9.3 CHAOTIC вимагав мінімальності, тож повний зсув на {α, β}^ℕ (ентропія log 2, є фіксована точка) не був хаотичним. Тепер хаотичність — це додатна ентропія, а мінімальність — це окрема ознака Min. Комбінація «мінімальна і хаотична» називається `MIN_POS` (§11).

### 4.4. Одне значення CHAOTIC

`IsChaotic_D(P)` :⇔ `ChaosStatus_D(P) = CHAOTIC`; `CHAOTIC_ω(τ)` (§11) :⇔ `IsChaotic_D(ω(τ))`. Це один предикат для множин і для ω-границь. **Зауваження (v6.13.14).** Еквівалентність «CHAOTIC ⇔ h_top > 0» для нескінченних систем є означенням, а не теоремою. Нетривіальна частина — існування свідків: повний зсув на {0,1}^ℕ має h_top = log 2 > 0 (`ChaoticWitness.lean`: `chaotic_witness_fullshift`; аксіоми propext, Classical.choice, Quot.sound). Символ `CHAOTIC_set` — лише назва нижнього елемента Ω (§5); π\_Ω повертає його, якщо `IsChaotic_D(P)`. За (H) передумови для ω(τ) виконуються (D1, §11).

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT\_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. DP-f. *Доведення.* (a) — з означень. (b) Виконано (Π2), тож D\[P\] = P; з h\_top > 0 випливає D|ₚ ≠ id (h\_top(id) = 0), тож є x з D(x) ≠ x. (c) Виконано (Π2) за означенням. ∎

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f. *Доведення.* У скінченній P всі (n, ε)-роздільні множини мають потужність ≤ #P, тому (1/n) log s(n, ε) → 0. ∎

**Твердження 4.5.3 (C4, розділене).**

- **(C4a)** Якщо P скінченна і D\[P\] = P, то D|ₚ — бієкція і кожна точка P періодична. DP-f. *Доведення.* Сюр'єкція скінченної множини на себе є бієкцією, тож D|ₚ — перестановка, а кожна перестановка скінченної множини має скінченні періоди. ∎
- **(C4b)** Для нескінченної P бієктивність D|ₚ не тягне періодичності всіх точок. Контрприклад: одометр (§11.6). DP-f.
- **(C4c)** Для нескінченної P сюр'єктивність D|ₚ не тягне ін'єктивності. Контрприклад: односторонній зсув σ(x)ₙ = xₙ₊₁ на {0, 1}^ℕ: сюр'єктивний (прообраз x — 0x і 1x), не ін'єктивний. DP-f.

**Лема 4.6 (ентропія повного зсуву).** Нехай α ≠ β — два різні елементи A, C = {α, β}^ℕ, σ — односторонній зсув, d\_C(x, y) = 2^{−k} (k — перший індекс розбіжності; d\_C(x, x) = 0). Тоді (C, d\_C, σ) — допустима система, σ\[C\] = C, h\_top(σ) = log 2. DP-f.

*Доведення.* C — компакт (злічений добуток скінченних множин; діагональний аргумент: з довільної послідовності елементів C послідовно виділяємо підпослідовності, що стабілізуються на кожній координаті, і беремо діагональ), σ неперервний і сюр'єктивний (прообрази x: αx, βx). Метрика Боуена: dₙ(x, y) = max\_{0≤i<n} d\_C(σⁱx, σⁱy).
*Нижня оцінка.* Беремо по одному представнику кожного з 2ⁿ префіксів довжини n. Два різні представники розходяться на деякій координаті k < n, тож d\_C(σᵏx, σᵏy) = 1 і dₙ = 1 > ¾. Отже s(n, ¾) ≥ 2ⁿ. Оскільки s(n, ε) не спадає при зменшенні ε, h\_top ≥ log 2.
*Верхня оцінка.* Нехай ε > 0, L таке, що 2^{−(L+1)} < ε. Якщо x, y мають однаковий префікс довжини n + L, то для 0 ≤ i < n точки σⁱx, σⁱy збігаються на перших L + 1 координатах, тож d\_C ≤ 2^{−(L+1)} < ε і dₙ(x, y) < ε. Отже в (n, ε)-роздільній множині немає двох точок з однаковим (n + L)-префіксом, і s(n, ε) ≤ 2^{n+L}. Тому limsup (1/n) log s(n, ε) ≤ log 2 для кожного ε, і h\_top ≤ log 2. ∎

## 5. Алгебра Ω і проєкція π\_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D\_class).** D\_class := { Classify⁺\_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }. Усі координати кортежа обчислюються для тієї самої системи.

**Означення 5.3 (π\_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π\_Ω тотальна на D\_class. DP-f. *Доведення.* Для C = CHAOTIC — перший рядок; інакше O належить рівно одному з шести класів (C1), і кожен ужито у рядках 2–6. ∎

**Твердження 5.5 (C5b, сюр'єктивність).** Образ π\_Ω у D\_class складається з усіх шести елементів Ω. DP-f (безумовно: усі свідки — допустимі системи довільного вигляду, (H) не потрібне). *Свідки.* INVARIANT\_FIXED: P = {p} для нерухомої точки p. INVARIANT\_DYNAMIC: 2-цикл {x, D(x)}. PERIODIC\_SET: у 4-циклі a → b → c → d → a множина P = {a, c}: D\[P\] = {b, d} ≠ P, D²\[P\] = P, p\_set = 2. EVENTUALLY\_PERIODIC: P = {x₀} на системі x₀ → x₁ → x₂ → x₁ (μ = 1, π = 2). APERIODIC\_NON\_CHAOTIC: K = {0,1}^ℕ, D = σ (зсув), a\_n = 1 ⇔ n — степінь двійки, P = {σⁿ(a) : n ≥ 0}. Проміжки між одиницями необмежено зростають, тож a не є ніде періодичною, усі σⁿ(a) різні й `Dᵏ[P] = P ∖ {a, …, σᵏ⁻¹(a)}` — різні множини, μ = ∞. P не замкнена: `σ^(2ᵐ+1)(a) → 0^∞ ∉ P`. Тому (Π1)–(Π2) не виконуються й ChaosStatus = NOT\_APPLICABLE (зауваження 5.6). CHAOTIC\_set: P = C = {α, β}^ℕ (α ≠ β — два елементи A), D = σ (лема 4.6): D\[P\] = P, h\_top = log 2 > 0. Усі системи допустимі. (Той самий приклад, перенесений у S∞ × R, — W5, §11.10.) ∎

**Зауваження 5.6 (`APERIODIC_NON_CHAOTIC` — втратна мітка).** Якщо μ(P) = ∞, то D\[P\] ≠ D⁰\[P\] = P, тож (Π2) не виконується й ChaosStatus = NOT\_APPLICABLE. Отже, поєднання «OrbitType = APERIODIC і ChaosStatus = NON\_CHAOTIC» за означеннями неможливе. Елемент `APERIODIC_NON_CHAOTIC` ланцюга Ω — це мітка образу π\_Ω («аперіодична множина, яка не CHAOTIC»), а не твердження про статус NON\_CHAOTIC. C5b стверджує лише сюр'єктивність відображення π\_Ω; семантично пара «аперіодична й нехаотична» нереалізовна. Назву збережено заради сумісності з v6.9.3; нейтральна назва (наприклад, `APERIODIC_NOT_CHAOTIC`) — відкрита редакційна пропозиція автору.

**Застереження 5.6.1.** Для фіксованої скінченної системи образ π\_Ω не може містити `CHAOTIC_set` (C7).

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥ (⊥ = CHAOTIC\_set, ⊤ = INVARIANT\_FIXED).

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f. *Доведення.* Ланцюг — гратка з 0 і 1. Треба перевірити min(a, c) ≤ b ⇔ c ≤ (a → b). Якщо a ≤ b: ліва частина завжди істинна (min ≤ a ≤ b), права — c ≤ ⊤. Якщо a > b: min(a, c) ≤ b ⇔ c ≤ b і a → b = b. Виключене третє хибне: для a без ⊥ і ⊤ є a ∨ ¬a = a ∨ ⊥ = a ≠ ⊤. ∎

**Застереження 5.9.** π\_Ω втратна (відкидає InclusionType і Min, а також різницю NOT\_APPLICABLE / NON\_CHAOTIC). Ω — синтаксичний інструмент, формально не пов'язана з білаттисом Белнапа.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

Для довільної динамічної системи (K, D), x ∈ K, U ⊆ K; `¬U := K ∖ U` — класичне доповнення, не тотожне `¬_H` з §6.2.

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`F_tree` — виключно функтор `X ↦ A ⊔ X³`; динаміка позначається буквою D.

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. DP-f.

```text
(X1) X U → ◇⁺ U                  (X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)       (D1) ◇U ↔ U ∨ X ◇U
(D2) ◇⁺ U ↔ X ◇U                  (D3) ◇U ↔ U ∨ ◇⁺ U
(B1) □U ↔ U ∧ X □U                (B2) □U → U
(B3) □U → X □U                    (B4) □U → ◇U
(B5) □(U → V) → (□U → □V)       (R1) ↺U ↔ ◇⁺(X U)
(R2) ↺U → ◇⁺ U                  (M4) ◇U ↔ ¬□¬U
```

*Доведення.* Фіксуємо x; uₙ := \[Dⁿ(x) ∈ U\], vₙ — аналогічно для V. Тоді XU істинне ⇔ u₁; ◇U ⇔ ∃n≥0 uₙ; ◇⁺U ⇔ ∃n≥1 uₙ; □U ⇔ ∀n≥0 uₙ; ↺U ⇔ ∃k≥2 uₖ. Для формули φ істина Xφ в x — це істина φ в D(x), а послідовність для D(x) — зсув (uₙ₊₁). Тому X◇U ⇔ ∃m≥0 u\_{m+1} ⇔ ∃n≥1 uₙ; X□U ⇔ ∀n≥1 uₙ; ◇⁺(XU) ⇔ ∃n≥1 u\_{n+1} ⇔ ∃k≥2 uₖ. Тепер кожна аксіома — тавтологія кванторів по ℕ: D1: (∃n≥0 uₙ) ⇔ u₀ ∨ (∃n≥1 uₙ); D2 — це рівність X◇U і ◇⁺U вище; D3 аналогічно D1; B1: (∀n≥0 uₙ) ⇔ u₀ ∧ (∀n≥1 uₙ); B2–B4: n = 0; B5: якщо ∀n (uₙ → vₙ) і ∀n uₙ, то ∀n vₙ; R1, R2: вище (k = n + 1 ≥ 2); X1: u₁ ⇒ ∃n≥1 uₙ; X2, X3: X розподіляється по ∧ і ∨; M4: ¬∀n ¬uₙ ⇔ ∃n uₙ. ∎

**Твердження 6.1.2 (M2, M6 — історичні мітки з попередніх редакцій; у таблиці §6.1 їх немає).** □U → ↺U. DP-f: □U дає D²(x) ∈ U, тобто k = 2 > 1.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** Для предиката U : K → Ω: (□\_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇\_H U)(x) := ⋁ₙ≥0 U(Dⁿx) у решітці Ω; `¬_H a := a → ⊥` — псевдодоповнення в Ω.

**Твердження 6.2.2 (M3).** Рівність ◇\_H U = ¬\_H □\_H ¬\_H U у семантиці §6.2 **хибна**. DP-f. *Контрмодель:* K = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY\_PERIODIC, U(b) = CHAOTIC\_set (= ⊥). Обчислення: (◇\_H U)(a) = max(EVENTUALLY\_PERIODIC, ⊥) = EVENTUALLY\_PERIODIC. (¬\_H U)(a) = ⊥ (бо U(a) > ⊥), (¬\_H U)(b) = ⊤. (□\_H ¬\_H U)(a) = min(⊥, ⊤) = ⊥, тож (¬\_H □\_H ¬\_H U)(a) = ⊤ ≠ EVENTUALLY\_PERIODIC. ∎

**Твердження 6.2.3 (Q6 закрито для §6.2).** M4 у гейтінговій семантиці §6.2 не виконується (це рівність M3). DP-f. **Q6′ (ВІДКРИТО):** чи є інша гейтінгова семантика (інша решітка або інше означення □\_H, ◇\_H), у якій M4 виконується?

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : U @ τ читається в моделі §6.1 як «точка t належить U»; час τ — лише лічильник.

```text
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ
Еволюція:        Γ ⊢ t:U@τ    D[U] ⊆ V         ⇒  Γ ⊢ D(t) : V@(τ+1)
Стабільність:     Γ ⊢ t:U@τ    D[U] ⊆ U         ⇒  Γ ⊢ t : □U@τ
Потенційність:    Γ ⊢ t:U@τ    ∃k≥0: Dᵏ[U] ⊆ V ⇒  Γ ⊢ t : ◇V@τ
```

**Твердження 6.3.1 (коректність правил).** У моделі §6.1 кожне правило коректне. DP-f. *Доведення.* Еволюція: t ∈ U ⇒ D(t) ∈ D\[U\] ⊆ V. Стабільність: з D\[U\] ⊆ U індукцією Dⁿ(t) ∈ U для всіх n. Потенційність: Dᵏ(t) ∈ Dᵏ\[U\] ⊆ V. ∎ Правило стабільності ослаблено до D\[U\] ⊆ U (erratum E-4). Повнота і дальша метатеорія — НЕ ПІДТВЕРДЖЕНО.

### 6.4. Предикати префікса

```text
PH_φ(N) := ∀k ≤ N: φ(k, τ)
EP_φ(N) := ∃k ≤ N: φ(k, τ)
PP_φ(k) := φ(k, τ)
GP_φ(τ)                            (Global)
```

Правила: PH\_φ(N+1) ⇒ PH\_φ(N); EP\_φ(N) ⇒ EP\_φ(N+1); PH\_φ(N) ⇒ EP\_φ(N). Імплікацій між PP і GP немає. Символ Ψ зарезервовано для монотонного оператора з §9.2.

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g): S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. Динаміка D\_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ) з однією умовою сумісності з S-компонентою:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))
```

Умова не включає g.

**Означення 7.3 (SUBIT\_full).** Широка підкатегорія; морфізми додатково задовольняють φ\_ℛ(g\_X(ρ, s)) = g\_Y(φ\_ℛ(ρ), φ\_S(s)).

**Твердження 7.4 (K1).** SUBIT і SUBIT\_full — категорії. DP-f. LEAN-CHECKED для підмножинної моделі (`K123Subset.lean`: `K1_subset`, `K1_full`; аксіоми: немає). *Доведення.* Тотожний морфізм (id\_S, id\_ℛ) задовольняє обидві умови тривіально. Композиція — покомпонентна, тому асоціативна. Якщо φ : X → Y, ψ : Y → Z, то ψ\_S(φ\_S(ρ(s))) = ψ\_S(φ\_ℛ(ρ)(φ\_S s)) = ψ\_ℛ(φ\_ℛ ρ)(ψ\_S φ\_S s). Для SUBIT\_full: ψ\_ℛ(φ\_ℛ(g\_X(ρ, s))) = ψ\_ℛ(g\_Y(φ\_ℛρ, φ\_S s)) = g\_Z(ψ\_ℛφ\_ℛρ, ψ\_Sφ\_S s). ∎

**Твердження 7.5 (K2).** 1 = ({∗}, {id}, g\_triv) — термінальний об'єкт у SUBIT і SUBIT\_full. DP-f. LEAN-CHECKED (`K123Subset.lean`: `K2_subset`, `K2_termF`; аксіоми propext, Classical.choice, Quot.sound). *Доведення.* Морфізм X → 1 має лише одну компоненту кожного типу, бо кодомени — одноточкові; умови виконуються: ∗ = id(∗). ∎

**Твердження 7.6 (K3, добуток).** Для X, Y:

```text
(ρ ⊠ σ)(x, y) := (ρ(x), σ(y))         на S_X × S_Y
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
```

— добуток у SUBIT і у SUBIT\_full. DP-f. LEAN-CHECKED (`K123Subset.lean`: `K3_subset`, `K3_full`; аксіоми propext, Classical.choice, Quot.sound).

*Доведення.* Розклад `ρ ⊠ σ` однозначний, бо `S_X`, `S_Y` непорожні: `ρ` відновлюється з першої координати значення при будь-якому `y`, а `σ` — з другої. Тому `g_{X×Y}` коректно задана й має значення в `ℛ_{X×Y}`. Проєкції: `pr_X = (pr₁, (ρ ⊠ σ) ↦ ρ)` і `pr_Y` аналогічно; умова 7.2: `pr₁((ρ ⊠ σ)(x, y)) = ρ(x) = pr_X,ℛ(ρ ⊠ σ)(pr₁(x, y))`. Нехай `u : Z → X`, `v : Z → Y`. Покладемо `⟨u, v⟩_S(z) := (u_S z, v_S z)` і `⟨u, v⟩_ℛ(τ) := u_ℛ(τ) ⊠ v_ℛ(τ)`. Умова 7.2: `⟨u, v⟩_S(τ(z)) = (u_ℛ(τ)(u_S z), v_ℛ(τ)(v_S z)) = (u_ℛ(τ) ⊠ v_ℛ(τ))(u_S z, v_S z)`. Цей морфізм єдиний, що комутує з проєкціями: його ℛ-компонента має бути `ρ' ⊠ σ'` з `ρ' = u_ℛ(τ)`, `σ' = v_ℛ(τ)`, а S-компонента однозначно визначається проєкціями. Для SUBIT\_full: `φ_ℛ(g_Z(τ, z)) = g_X(u_ℛτ, u_S z) ⊠ g_Y(v_ℛτ, v_S z) = g_{X×Y}(⟨u, v⟩_ℛτ, ⟨u, v⟩_S z)`, тож проєкції теж g-сумісні. ∎

**Застереження 7.7.** Якщо категорія має допускати порожні S, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X` (бо тоді ρ ⊠ σ не відновлює пару). **Відкрито:** Q1 (декартова замкненість). Q19 закрито Твердженням 7.8 (v6.13).

**Твердження 7.8 (Q19, v6.13).** (а) Ізоморфізм φ : X → Y у SUBIT\_full є спряженням: Φ(s, ρ) := (φ\_S(s), φ\_ℛ(ρ)) задовольняє D\_Y∘Φ = Φ∘D\_X. (б) Різні g можуть давати ізоморфні об'єкти: S = {a, b}, ℛ = {ρ\_a ≡ a, ρ\_b ≡ b}, g\_X ≡ ρ\_a, g\_Y ≡ ρ\_b; φ обмінює a ↔ b і ρ\_a ↔ ρ\_b. DP-f. *Доведення.* (а) D\_Y(Φ(s,ρ)) = (φ\_ℛ(ρ)(φ\_S s), g\_Y(φ\_ℛ ρ, φ\_S s)) = (φ\_S(ρ s), φ\_ℛ(g\_X(ρ,s))) за 7.2 і 7.3, що дорівнює Φ(D\_X(s,ρ)). (б) φ\_S(ρ\_a(s)) = b = ρ\_b(φ\_S s) = φ\_ℛ(ρ\_a)(φ\_S s), і аналогічно для ρ\_b; φ\_ℛ(g\_X(ρ,s)) = φ\_ℛ(ρ\_a) = ρ\_b = g\_Y(φ\_ℛ ρ, φ\_S s). ∎


## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — це φ ∘ f = h ∘ φ. Dyn₊ — повна підкатегорія з непорожніми S.

**Твердження 8.2 (K4, топос).** Dyn ≅ Fun(Bℕ, Set), де Bℕ — категорія з одним об'єктом і моноїдом ендоморфізмів (ℕ, +, 0) (не категорія-порядок ℕ). Функтор відправляє єдиний об'єкт у S, а n — у fⁿ. Це прешейфовий топос, тому Dyn — топос (DP-s: стандартна теорема). Класифікатор підоб'єктів виписано явно нижче (твердження 8.4).

**Означення 8.3 (час входу, лише для інваріантних U).** Нехай U ⊆ S підоб'єкт, тобто f\[U\] ⊆ U. Тоді χ\_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U } (∞, якщо ніколи).

**Твердження 8.4 (χ\_U, класифікатор підоб'єктів).** Нехай Ω\_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞, і «істиною» 0. Тоді (a) χ\_U(f(x)) = max(χ\_U(x) − 1, 0), тобто χ\_U — морфізм Dyn; (b) U ↦ χ\_U є бієкцією між підоб'єктами (S, f) і морфізмами (S, f) → Ω\_Dyn, з оберненою U = χ⁻¹(0). DP-f.

*Доведення.* (a) Якщо χ\_U(x) = n ≥ 1, то f(x) потребує рівно n − 1 кроків: бо fᵏ(f(x)) = f^{k+1}(x) ∈ U лише при k + 1 ≥ n (або раніше не входить, бо інакше χ\_U(x) < n). Якщо χ\_U(x) = 0, то f(x) ∈ U за інваріантністю, тож χ\_U(f x) = 0. Якщо χ\_U(x) = ∞ — так само ∞ (інакше f^{k+1}(x) ∈ U для деякого k). (b) Якщо χ : S → Ω\_Dyn — морфізм, то χ⁻¹(0) інваріантна: χ(f x) = max(χ(x) − 1, 0) = 0 при χ(x) = 0. Для U = χ⁻¹(0) і скінченного χ(x) = n: χ(fᵏ x) = n − k > 0 при k < n і χ(fⁿ x) = 0, тому χ\_U(x) = n; при χ(x) = ∞ усі χ(fᵏ x) = ∞ ≠ 0. Відтак, χ\_U = χ. І навпаки χ\_U⁻¹(0) = U. ∎

**Застереження 8.5 (LEAN-CHECKED: `chi_not_dynmor_8_5`).** Для неінваріантної U ⊆ S формула χ\_U загалом **не** еквіваріантна й не є морфізмом. Наприклад, f(0) = 1, f(1) = 1 на S = {0, 1}, U = {0}: χ\_U(0) = 0, але χ\_U(f(0)) = χ\_U(1) = ∞ ≠ max(0 − 1, 0).

**Твердження 8.6 (K5, вкладення).** Функтор E : Dyn₊ → SUBIT, (S, f) ↦ (S, {f}, g\_f), g\_f(f, s) := f, на морфізмах φ ↦ (φ, єдине відображення {f} → {h}) — повний і вірний, і такий самий функтор вкладає Dyn₊ у SUBIT\_full. DP-f. *Доведення.* Умова 7.2 для пари (φ, !) це рівно φ(f(s)) = h(φ(s)), тобто морфізм Dyn. Друга компонента морфізму визначена однозначно, тому E вірний і повний. Умова 7.3 тривіальна, бо ℛ одноелементна. ∎

**Застереження 8.7.** Вкладення всієї Dyn неможливе без перегляду типу правил (S = ∅). Топосна структура Dyn не переноситься на SUBIT автоматично.

## 9. Простір S∞ = Tree∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, алфавіт міток Λ := {None, node} ∪ {leaf(a) : a ∈ A} (6 елементів). Tree∞ — множина f : Pos → Λ, що задовольняють

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None для i = 1, 2, 3;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None для будь-якого τ.

S∞ := Tree∞. Піддерево для f(ε) = node: f\_i(σ) := f(i·σ); для f(ε) = leaf(a) піддерево **не визначене**.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree∞ з out(f) := inl(a) при f(ε) = leaf(a) і out(f) := inr(f₁, f₂, f₃) при f(ε) = node — фінальна коалгебра функтора `F_tree(X) = A ⊔ X³`. DP-s (out — бієкція; фінальність — розгортання за адресами; повний аргумент не виписано).

**Твердження 9.3 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S∞. DP-f: значення f(1), f(2), f(3) відновлюють a, b, c.

### 9.2. Допоміжна конструкція: Ψ і L\_prod

Цей підрозділ не потрібен для компактності чи динаміки (§9.4 не посилається на нього); він про коалгебраїчний опис S∞.

```text
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) } ∪ { Bottom_{n+1} } ∪ { Node_n(t₁, t₂, t₃) : tᵢ ∈ T_n }
q_0 : T_1 → T_0:   Leaf_1 a ↦ Leaf_0 a,  Bottom_1 ↦ Bottom_0,  Node_0(…) ↦ Bottom_0
q_{n+1} : T_{n+2} → T_{n+1}:  Leaf ↦ Leaf,  Bottom ↦ Bottom,
                              Node_{n+1}(t₁,t₂,t₃) ↦ Node_n(q_n t₁, q_n t₂, q_n t₃)
U_c := { (t_n) ∈ ∏ T_n : q_n(t_{n+1}) = t_n для всіх n }
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }
NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0, ∃u₁,u₂,u₃ ∈ X з t_{n+1} = Node_n(u₁_n, u₂_n, u₃_n) для всіх n ≥ 0 }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X);     L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.4.** L\_prod = Ψ(L\_prod). DP-f. *Доведення.* L\_prod — об'єднання всіх X з X ⊆ Ψ(X); Ψ монотонний (X ⊆ Y ⇒ Ψ(X) ⊆ Ψ(Y)). Для кожного такого X: X ⊆ Ψ(X) ⊆ Ψ(L\_prod), тому L\_prod ⊆ Ψ(L\_prod). Звідси Ψ(L\_prod) ⊆ Ψ(Ψ(L\_prod)), тобто Ψ(L\_prod) — постнерухома точка, отже Ψ(L\_prod) ⊆ L\_prod. ∎

**Зауваження 9.5.** `U_c` **строго більша** за L\_prod: послідовність (Bottom\_n)ₙ належить U\_c, але не задовольняє ні LeafSeqs, ні NodeSeqs (бо t₁ вимагає бути Node\_0). Тому «обернена границя» на прямовані q\_n давала би більший простір, і для реконструкції береться коіндуктивне ядро L\_prod.

### 9.3. d\_n, at\_n, lim\_tree

```text
d_0(f) := Leaf_0(a) якщо f(ε) = leaf(a);   Bottom_0 якщо f(ε) = node
d_{n+1}(f) := Leaf_{n+1}(a)                       якщо f(ε) = leaf(a)
d_{n+1}(f) := Node_n(d_n f₁, d_n f₂, d_n f₃)      якщо f(ε) = node

TΣ := Σ_k T_k  (пари (k, u), u ∈ T_k);    at_n : T_n → Pos → Option(TΣ)
at_n(t, ε) := Some((n, t));            at_0(t, i·τ) := None
at_{n+1}(Leaf, i·τ) := None;          at_{n+1}(Bottom, i·τ) := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ) := at_n(u_i, τ)
```

**Лема 9.6 (типізація).** d\_n(f) ∈ T\_n, q\_n(d\_{n+1} f) = d\_n f; якщо at\_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T\_k. DP-f: індукція за n і |σ| за означеннями.

**Означення 9.7 (lim\_tree).** Для t = (t\_m) ∈ L\_prod і σ ∈ Pos, m > |σ| розглядаємо at\_m(t\_m, σ). Рівно один із трьох випадків стабілізується при m → ∞: (Z) усе None для всіх великих m; (L) Some((m − |σ|, Leaf(a))) для фіксованого a; (N) Some((m − |σ|, Node(…))). Тоді lim\_tree(t)(σ) := None, leaf(a), node відповідно.

**Твердження 9.8 (реконструкція).** (a) lim\_tree(t) ∈ Tree∞; (b) p(f) := (d\_n f)ₙ ∈ L\_prod і lim\_tree(p(f)) = f; (c) p(lim\_tree(t)) = t. Тобто p : Tree∞ → L\_prod — бієкція з оберненим lim\_tree. DP-s (індукція за |σ| і адресний доступ з леми 9.6; повний аргумент — в плані Lean).

### 9.4. Метрика d\_S і компактність

```text
r_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) }   (∞, якщо f = g)
d_S(f, g)    := 2^{− r_addr(f, g)}            (0, якщо f = g)
r_app(f, g)  := min{ n ≥ 0 : d_n f ≠ d_n g }
```

**Лема 9.9.** r\_app = r\_addr. DP-s: d\_n(f) відновлює мітки f на всіх адресах довжини ≤ n, і нічого більше (індукція за n).

**Твердження 9.10 (T3).** d\_S — ультраметрика. DP-f. *Доведення.* Симетрія і d\_S(f, g) = 0 ⇔ f = g — з означення. На адресах довжини < min(r\_addr(f, g), r\_addr(g, h)) маємо f = g = h, тому r\_addr(f, h) ≥ min(…), тобто d\_S(f, h) ≤ max(d\_S(f, g), d\_S(g, h)). ∎

**Твердження 9.11 (T4).** Якщо f(ε) = g(ε) = node, то для i = 1, 2, 3: d\_S(f\_i, g\_i) ≤ 2·d\_S(f, g). DP-f. *Доведення.* Якщо f = g, тривіально. Інакше r := r\_addr(f, g) ≥ 1 (корені збігаються). Якщо f\_i(τ) ≠ g\_i(τ), то f(i·τ) ≠ g(i·τ), тож |i·τ| ≥ r, тобто |τ| ≥ r − 1. Відтак r\_addr(f\_i, g\_i) ≥ r − 1 і d\_S(f\_i, g\_i) ≤ 2^{−(r−1)} = 2·d\_S(f, g). ∎

**Твердження 9.12 (T5).** (Tree∞, d\_S) — компактний, повний, цілком обмежений. DP-f. *Доведення.* Множина Λ^Pos з добутковою топологією — компакт (зліченний добуток скінченних дискретних множин; діагональний аргумент, як у лемі 4.6). Кожна з умов (T1)–(T4) замкнена, бо залежить від скінченного набору координат (від однієї до чотирьох: (T2) — σ, σ·1, σ·2, σ·3). Отже Tree∞ замкнена в компакті, також компактна. Куля {g : r\_addr(f, g) > r} збігається з циліндром, що фіксує скінченно багато координат (адреси довжини ≤ r), тому d\_S метризує цю топологію. Компактна метрична → повна й цілком обмежена. ∎

**Твердження 9.13 (адресний доступ).** Для f ∈ Tree∞, σ ∈ Pos, n > |σ|: f(σ) = leaf(a) ⇒ at\_n(d\_n f, σ) = Some((n − |σ|, Leaf(a))); f(σ) = node ⇒ корінь at\_n(d\_n f, σ) — Node; f(σ) = None ⇒ at\_n(d\_n f, σ) = None. DP-s (індукція за |σ|).

### 9.5. «Хребет» і простір Y

Фіксуємо літери α ≠ β та η з A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ:

```text
t(a)(1ᵏ) := node,    t(a)(1ᵏ·2) := leaf(a_k),    t(a)(1ᵏ·3) := leaf(η)
```

інші позиції — за (T2)–(T4).

**Твердження 9.14.** t : {α, β}^ℕ → S∞ неперервне й ін'єктивне; точніше, d\_S(t(a), t(b)) = 2^{−(k+1)}, де k — перший індекс розбіжності a і b (це мітка на адресі 1ᵏ·2 довжини k + 1). Образ Y := t({α, β}^ℕ) — канторів простір, замкнений в S∞. Зсув σ на {α, β}^ℕ спряжений до T := t ∘ σ ∘ t⁻¹ на Y. DP-f (відстань задається формулою; замкненість — з компактності прообразу).

**Зауваження 9.15.** S∞ — нульвимірний компакт; скінченні дерева — ізольовані точки (дерево глибини h має None на глибині h + 1, і куля радіуса 2^{−(h+1)} збігається з ним за (T4)). Множина нескінченних дерев — замкнена й досконала (без ізольованих точок). Y — досконала підмножина, гомеоморфна канторовому простору, але не вся ця множина: повне потрійне дерево (node на всіх адресах) нескінченне, проте не лежить у Y, бо в деревах із Y адреса 2 — листок.

## 10. Правила ℛ₀ і ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні та обчислювані правила

**Означення 10.1.** ℛ₀ := ℛ\_caus := { f : S∞ → S∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) }, метрика d\_ℛ(ρ, σ) := sup\_s d\_S(ρ(s), σ(s)).

**Означення 10.2.** ℛ₁ := ℛ\_comp — функції S∞ → S∞ зі скінченним обчислювальним описом у фіксованій моделі, де дерево подано оракулом (адреса → мітка). **Уточнення (v6.13):** скінченна програма, яка читає оракул за скінченною кількістю адрес і повертає значення зі скінченної таблиці (скінченний список пар дерев), є скінченним описом; ця умова використовується в Твердженні 10.10. **Вибір моделі (v6.13.16).** Фіксована модель: g ∈ ℛ_comp, якщо існує глибина n така, що g залежить лише від міток на адресах довжини ≤ n, і g(s) — скінченне дерево (скінченно багато вузлів з міткою ≠ none) для кожного s. Це еквівалентно скінченній таблиці пар (шаблон на адресах довжини ≤ n ↦ скінченне дерево). Скінченність значень дає злічність ℛ_comp (§10.5). Обмеження моделі: вона не вимагає обчислюваності таблиці — будь-яка скінченна таблиця дозволена; ця модель є формалізацією «скінченного опису», а не теорією обчислюваності.

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ для кожного n мітки виходу на адресах довжини ≤ n залежать лише від міток входу на адресах довжини ≤ n. DP-f. *Доведення.* Нерівність d\_S(f s, f t) ≤ d\_S(s, t) еквівалентна r\_addr(f s, f t) ≥ r\_addr(s, t); тобто якщо s, t збігаються на адресах довжини ≤ n, то й f(s), f(t) збігаються на адресах довжини ≤ n; це й є незалежність префікса. ∎

**Твердження 10.4 (T6).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. LEAN-CHECKED (`RZero.lean`: `isCompact_RZ` через `ArzelaAscoli.isCompact_of_equicontinuous` з Mathlib; ultrametric — `instIsUltrametricDistCM`); елементарний варіант нижче — DP-f (v6.13.2). *Доведення.* (1) d\_ℛ — ультраметрика: значення d\_ℛ(ρ,σ) = sup\_s d\_S(ρ s, σ s) — sup ультраметрик, тож ультраметрична нерівність зберігається; d\_ℛ(ρ,σ) = 0 ⇒ ρ = σ, бо d\_S — метрика; d\_ℛ ≤ 1. (2) Замкненість: нехай ρ\_n → ρ рівномірно, ρ\_n ∈ ℛ₀. Тоді d\_S(ρ s, ρ t) ≤ d\_S(ρ\_n s, ρ\_n t) + 2 d\_ℛ(ρ\_n, ρ) ≤ d\_S(s, t) + 2 d\_ℛ(ρ\_n, ρ) → d\_S(s, t), тож ρ ∈ ℛ₀. (3) Послідовна компактність: S∞ компактний метричний (T3, T5), тому має зліченну щільну множину D = {f₁, f₂, …}. Для послідовності (ρ\_n) ⊆ ℛ₀ діагональним вибором знаходимо підпослідовність, що збігається в кожній точці з D (значення лежать у компакті S∞). Нехай ε > 0, δ = ε/4, і F ⊆ D — скінченна δ-сітка S∞. Для n, m ≥ N(ε) маємо d\_S(ρ\_n f, ρ\_m f) < ε/2 для всіх f ∈ F. Для довільного s вибираємо f ∈ F з d\_S(s, f) < δ; оскільки ρ\_n 1-ліпшицеві, d\_S(ρ\_n s, ρ\_m s) ≤ d\_S(ρ\_n s, ρ\_n f) + d\_S(ρ\_n f, ρ\_m f) + d\_S(ρ\_m f, ρ\_m s) < 2δ + ε/2 = ε. Отже (ρ\_n) рівномірно фундаментальна. Оскільки S∞ повний, ρ(s) := lim ρ\_n(s) існує для кожного s; перехід до границі в d\_S(ρ\_n s, ρ\_n t) ≤ d\_S(s, t) дає, що ρ 1-ліпшицеве, тобто ρ ∈ ℛ₀, і ρ\_n → ρ рівномірно. Отже кожна послідовність в ℛ₀ має збіжну підпослідовність; метричний простір із цією властивістю компактний. ∎ (Це елементарний варіант теореми Арцела–Асколі; потребує лише компактності S∞.)

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀. DP-s: нижня оцінка — константи κ\_c (означено в §11.4, лема E; тут потрібні лише як елементи ℛ₀), щонайменше |Y| = 2^ℵ₀; верхня — бо неперервне відображення сепарабельного простору визначається своїми значеннями на скінченних деревах (щільна зліченна множина). |ℛ₁| ≤ ℵ₀ — за припущення про модель (скінченні описи — зліченна множина). Нижня оцінка: для кожного скінченного дерева tₙ константне правило κ\_{tₙ}(s) = tₙ має скінченний опис, а скінченних дерев нескінченно багато, тож |ℛ₁| = ℵ₀ (за тієї ж моделі). Включення ℛ₁ ⊆ ℛ₀ не стверджується.

### 10.2. Розширений простір і передумови

**Припущення (H) (контракт залежностей для §11).**

- **(H1)** (S∞, d\_S) — компактний ультраметричний простір (T3, T5; §9.4).
- **(H2)** R ⊆ ℛ₀ — непорожній компактний підпростір у метриці d\_ℛ. Компактність R приймається як передумова; для R = ℛ₀ вона виконується за T6 (DP-f, v6.13.2).
- **(H3)** g∞ : R × S∞ → R — неперервна і тотальна.

X := S∞ × R, d̂((s, ρ), (t, σ)) := max(d\_S(s, t), d\_R(ρ, σ)), де d\_R := d\_ℛ∣\_{R×R}. Динаміка D∞(s, ρ) := (ρ(s), g∞(ρ, s)). За (H1)–(H3) простір X компактний, а D∞ неперервний (T7), тож (X, d̂, D∞) — допустима система у сенсі §4.

**Припущення (H₀).** Для скінченної моделі SUBIT⁺: S₀ скінченне з дискретною топологією, D₀ та g₀ тотальні. (H₀) не є екземпляром (H): простори мають інші типи.

**Означення 10.6.** π\_R : R × S∞ → R, π\_R(ρ, s) := ρ. **Тотожна метаеволюція** — це `g∞ = π_R` (запис `g∞ ≡ id` типізований некоректно: id має кодомен R × S∞, а не R).

**Твердження 10.7 (T7).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)); отже за (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. DP-f за H. *Доведення.* d\_S(ρ s, σ t) ≤ max(d\_S(ρ s, σ s), d\_S(σ s, σ t)) ≤ max(d\_ℛ(ρ, σ), d\_S(s, t)), бо σ ∈ ℛ₀. Неперервність другої компоненти — з (H3). X компактний як добуток компактів (S∞ по 9.12, R компактна за H2). ∎

### 11.1. ω-границя і класи S(τ)

**Твердження 11.1 (D1).** За (H) ω(τ) непорожня, компактна і D∞\[ω(τ)\] = ω(τ). **Мета.** Перевірити реалізацію, а не гіпотезу D4. Перевірки: (1) орбіти повторюються в межах |Q₀| + 1; (2) класифікатор правильно визначає m, p і цикл; (3) у скінченній моделі не видається `CHAOTIC`; (4) RESOURCE\_EXCEEDED не подається як класифікація.

**Застереження 13.1.** Для тотальної динаміки на скінченному просторі кожна орбіта зрештою періодична, ω-границя скінченна, h\_top = 0 незалежно від g∞ у нескінченній моделі. Скінченний прогін принципово не може фальсифікувати D4.

**Результат (v6.11.6, Rust).** Pilot-01 проходить: 2000 випадкових систем, розміри 1…40, 40755 точок траєкторій; нерухомі 2033, періодичні 8141, передперіодичні 30581; максимум m + p = 22; CHAOTIC = 0; RESOURCE_EXCEEDED = 0; класифікатори точний і бюджетований збігаються; A4 перевірено для n = 10. Це узгоджується із застереженням 13.1: скінченна модель не фальсифікує D4 і не доводить жодного твердження про нескінченний рівень.

## 14. Протокол змін

Слово «STABLE» не є статусом перевіреності й не змінює жодного прапорця §0. Підвищення статусу (DP-s → DP-f, DP → ДОВЕДЕНО) — лише після (а) успішної компіляції у Lean для формалізованої частини, з матрицею відповідності, мутаційними перевірками гіпотез і прикладами здійсненності (`audit3/`), і (б) перехресної перевірки не менше ніж двома аудиторами з різними постановками завдання, які не спростували твердження. Людська рецензія більше не є умовою підвищення статусу; статус «рецензовано людиною» не присвоюється, доки її не виконано. Перехресна перевірка не замінює рецензування змісту: вона перевіряє відповідність тексту й Lean, а не коректність задуму. Кожна зміна фіксується в Додатку Г; редакційні правки без зміни тверджень не змінюють статусів. Прапорці з §0 змінюються лише разом з відповідним артефактом (лог збірки, звіт аудиту, протокол запуску).
