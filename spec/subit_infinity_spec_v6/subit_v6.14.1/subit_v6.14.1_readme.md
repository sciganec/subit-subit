## Quick Start

**Читання специфікації:**
1. §0 — статуси, прапорці, принцип незгортання, архітектура.
2. §1–§13 — ядро: базовий простір, ALT-алгебра, динаміка, дерева, WARP-геометрія, спектр, реконструкція (незмінне з v6.14.0).
3. §14 — реєстр теорем (включно з ALT-7 та успадкованими рядками).
4. §15–§16 — верифікація, відкриті питання, журнал змін.
5. **§17 — ALT-7: орбітні профілі всіх афінних відображень (головний результат v6.14.1).**
6. §18 — TETRAKSIS (онтологічний каркас).
7. §19 — SUBIT-ECOSYSTEM (універсальна архітектура).
8. §20 — закриття ерратуму.
9. §21–§22 — реєстр відкритих питань і фінальний статус.

**Відтворення ALT-7:**
```bash
python3 verify_alt7_affine.py     # ≈ 90 с; потребує NumPy
```
Очікуваний результат: 79 профілів, 720 896 класів, $\sum\#\text{мап} = 16\,777\,216$, 0 розбіжностей контролю.
