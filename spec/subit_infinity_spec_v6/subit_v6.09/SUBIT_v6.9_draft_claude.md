## 1. Алфавіт і простір станів S₀

Архітектура кумулятивна, але рівні не ототожнюються:

```text
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-CAT  ⊂  SUBIT-∞
```

SUBIT-64 — скінченний статичний алфавіт. SUBIT⁺ додає правило у стані й метаеволюцію. SUBIT-CAT додає класифікатори, логіку й категорії. SUBIT-∞ додає нескінченні рекурсивні дерева. Ця ієрархія — архітектурна; вона не доводить, що кожний наступний рівень строго сильніший за попередній у сенсі обчислювальної виразності.

### 1.1. Алфавіт

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, |A| = 4. Дві рівноправні інтерпретації одного й того ж чотириелементного коду (це не твердження про фізичну тотожність різних понять):

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. N і B непорівнянні за істинністю, F і T — за інформацією. Властивості білаттису не переносяться на динаміку S\_∞ без окремого означення. Статус: ВИЗНАЧЕНО.

### 1.2. Простір S₀

**Означення 1.2 (A2).** S₀ = A × A × A, |S₀| = 64. Стан s = (α, β, γ); 6-бітний код b₁b₂b₃b₄b₅b₆, де b₁b₂ — WHO, b₃b₄ — WHERE, b₅b₆ — WHEN:

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3).** code6 — бієкція S₀ → {0, …, 63}. DP: це двійковий запис числа з шести бітів.

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = WE/SOUTH/SUMMER = 63; 010001 = YOU/NORTH/AUTUMN = 17. Гексаграмний запис (Додаток А) — лише індексація; традиційне тлумачення гексаграм не є аксіомою SUBIT. SUBIT-64 не містить оператора переходу і не визначає траєкторій.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** ℛ — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан ŝ = (s, ρ) ∈ S₀ × ℛ. Метаеволюція g : ℛ × S₀ → ℛ. Оператор еволюції:

```text
F(s, ρ) := ( ρ(s), g(ρ, s) )
```

**Аксіома 2.2 (тотальність).** У базовій детермінованій моделі F — тотальна функція. Якщо реалізація допускає невизначені переходи, помилки чи переривання за ресурсом, їх подають у окремому шарі обчислювального статусу (§11), а не мовчки трактують як тотальну.

Рівні опису: 0 — стан s; 1 — розширений стан ŝ; 2 — крок F(ŝ); 3 — метаеволюція g(ρ, s). Це різні способи опису однієї архітектури, а не ієрархія обчислювальної потужності.

**Твердження 2.3 (E1, еквівалентність автомату).** (S₀ × ℛ, F) — автономний детермінований скінченний автомат з 64·|ℛ| станами без входу. Теза «правило належить стану» — зміна представлення, а не сильніша виразність. DP (означення). Сильніша теза про самореферентну перевагу — ВІДКРИТО: її потрібен додатковий механізм (необмежена пам'ять, зовнішній вхід).

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ), |Q| ≤ 64, вкладається в SUBIT⁺. DP: оберіть ін'єкцію ι : Q → S₀; нехай ℛ = {ρ}, де ρ(ι(q)) := ι(δ(q)) на образі ι і ρ(s) := s поза ним; g(ρ, s) := ρ. Індукцією за n: ι⁻¹(ρⁿ(ι(q₀))) = δⁿ(q₀). ВІДКЛИКАНО: універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT із λ-інтерпретатором. Відкриті: Q7 (універсальний об'єкт з доведеною властивістю), Q22 (|Q| > 64).

## 3. Траєкторії й точкова класифікація Ω\_point

**Означення 3.1.** τ(ŝ₀) = (ŝ₀, ŝ₁, …), ŝₙ₊₁ = F(ŝₙ). Для будь-якого розширеного стану ŝ (у S₀ × ℛ або S\_∞ × ℛ):

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, F^{m+p}(ŝ) = F^m(ŝ) }        (∞ якщо немає)
p(ŝ) := min{ p ≥ 1 : F^{m(ŝ)+p}(ŝ) = F^{m(ŝ)}(ŝ) }    (для m < ∞)
```

Обидва параметри мінімальні, простір будь-який. Це єдина конвенція для скінченного й нескінченного рівня.

**Означення 3.2 (Ω\_point).**

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 (тобто F(ŝ) = ŝ) |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | 1 ≤ m < ∞ (уключно з p = 1: «зрештою нерухома») |
| APERIODIC | m = ∞ |

Назви PREPERIODIC і EVENTUALLY\_PERIODIC означають один клас; в формальному тексті вживається PREPERIODIC. TRANSIENT — лише неформальний синонім.

**Твердження 3.3 (P1, скінченна періодичність).** У S₀ × ℛ для кожного ŝ виконується m(ŝ) < ∞, тому клас APERIODIC порожній. DP: принцип Діріхле для послідовності у скінченній множині.

**Твердження 3.4 (P2, розбиття).** Чотири класи попарно не перетинаються й вичерпують усі стани. DP: пара (m, p) є функцією від ŝ, бо обидва мінімуми беруться по непорожніх множинах ℕ; класи задано неперетинними умовами на (m, p).

**Твердження 3.5 (P3, алгоритм).** Нехай S₀ × ℛ скінченний і N\_max ≥ |S₀ × ℛ|. Алгоритм нижче завжди зупиняється на першому повторенні й повертає саме m(ŝ), p(ŝ). DP: якщо ŝ₀,…,ŝ\_{n−1} попарно різні, а ŝₙ = ŝ\_m, то траєкторія далі повторює цикл довжини n − m, і жоден стан до індексу m не повторюється.

```text
Вхід: ŝ₀, N_max          Вихід: (category, m, p, attractor_cycle) або RESOURCE_EXCEEDED
visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m;  attractor_cycle ← [ŝ_m, …, ŝ_{n−1}]
        category ← FIXED               якщо m = 0 і p = 1
                    PERIODIC(p)         якщо m = 0 і p ≥ 2
                    PREPERIODIC(m, p)   якщо m ≥ 1
        повернути
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← F(ŝₙ)
повернути RESOURCE_EXCEEDED
```

Приклад: F(a) = b, F(b) = b. Для ŝ₀ = a: m = 1, p = 1, PREPERIODIC(1, 1), attractor = \[b\]. Для ŝ₀ = b: FIXED. Для identity на будь-якій точці: m = 0, p = 1, FIXED, attractor = \[ŝ\] (тобто cycle = 1, а не 2).

ВІДКЛИКАНО: ототожнення PREPERIODIC із CHAOTIC. Передперіодичність — звичайна поведінка скінченного автомата; «хаотичність» має окреме визначення через ω-граничну динаміку (§11).

## 4. Класифікація множин Classify⁺

У §4–§5 X — S₀ × ℛ (скінченний рівень) або S\_∞ × R (§10), P ⊆ X — **непорожня** множина, F(P) := {F(x) : x ∈ P}. Порожня множина не класифікується.

### 4.1. OrbitType

**Означення 4.1.** Образи множини — послідовність P, F(P), F²(P), … З мінімальними параметрами:

```text
μ(P)    := min{ m ≥ 0 : ∃n > m, F^n(P) = F^m(P) }           (∞ якщо немає)
π(P)    := min{ n − μ(P) : n > μ(P), F^n(P) = F^{μ(P)}(P) }  (для μ < ∞)
p_set(P) := min{ k ≥ 1 : F^k(P) = P }                         (∞ якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT\_FIXED | F(P) = P і F(x) = x для всіх x ∈ P |
| INVARIANT\_DYNAMIC | F(P) = P і є x ∈ P: F(x) ≠ x |
| PERIODIC\_SET(p) | F(P) ≠ P, μ(P) = 0, p = p\_set(P) ≥ 2 |
| EVENTUALLY\_FIXED(μ) | μ(P) ≥ 1, π(P) = 1 |
| EVENTUALLY\_PERIODIC(μ, π) | μ(P) ≥ 1, π(P) ≥ 2 |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.2 (C1, розбиття).** Шість класів попарно не перетинаються й вичерпують усі непорожні P ⊆ X. DP: F(P) = P еквівалентне μ = 0 і p\_set = 1, і тоді клас визначається квантором над x. Якщо F(P) ≠ P, то клас визначають значення μ(P) і π(P): μ = 0 → PERIODIC\_SET; 1 ≤ μ < ∞ і π = 1 → EVENTUALLY\_FIXED; 1 ≤ μ < ∞ і π ≥ 2 → EVENTUALLY\_PERIODIC; μ = ∞ → APERIODIC. Параметри μ, π, p — функції від P, бо мінімальні.

Увага: скінченна P у нескінченному X може бути APERIODIC (F(n) = n + 1, P = {0}). Твердження про «немає неперіодичних класів» дійсне лише для скінченного X.

### 4.2. InclusionType

```text
EQUAL_IMAGE                F(P) = P
DISJOINT_IMAGE             F(P) ∩ P = ∅
STRICT_SUBIMAGE            F(P) ⊊ P
STRICT_SUPERIMAGE          P ⊊ F(P)
OVERLAPPING_NONCOMPARABLE  інакше
```

**Твердження 4.3 (C2).** Перші чотири класи попарно не перетинаються (пріоритетний порядок не потрібен), п'ятий — решта; усі непорожні P розбиті. DP: для непорожньої P множина F(P) непорожня; тому F(P) ⊊ P виключає F(P) ∩ P = ∅, а P ⊊ F(P) виключає F(P) ∩ P = ∅ і F(P) ⊊ P; EQUAL\_IMAGE виключає всі інші строгі відношення.

### 4.3. Chaos — окремий предикат

**Означення 4.4.** Chaos(P) істинний, якщо: P компактна в d̂; F(P) = P; F|\_P неперервна; P мінімальна (не містить власної непорожньої замкненої F-інваріантної підмножини); h\_top(F|\_P) > 0. Chaos — предикат, а не значення OrbitType.

**Твердження 4.5 (C3, незалежність складових).** Складові Classify⁺(P) = (OrbitType, InclusionType, Chaos) **не незалежні**. Для будь-якої P:

- (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}; зокрема, PERIODIC\_SET узгоджується лише з InclusionType ≠ EQUAL\_IMAGE;
- (b) Chaos(P) ⇒ OrbitType = INVARIANT\_DYNAMIC.

DP: (a) — з означень. (b): Chaos дає F(P) = P, тобто клас у {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. Якби було INVARIANT\_FIXED, кожна точка P нерухома, і кожен синглетон — замкнена інваріантна підмножина; мінімальність дає |P| = 1 і h\_top = 0, суперечність. Інші комбінації (наприклад, які InclusionType можливі для EVENTUALLY\_PERIODIC) не перераховано — ВІДКРИТО.

**Твердження 4.6 (C7).** У скінченному X хаотичних множин немає. DP: мінімальна інваріантна множина у скінченному X — один цикл, h\_top = 0.

### 4.4. Зв'язок точкової й множинної класифікації

**Твердження 4.7 (C4).** (а) Якщо P скінченна й F(P) = P, то `F|_P` — сюр'єкція скінченної множини, тобто бієкція, і кожна точка P — FIXED або PERIODIC. (б) Для нескінченної P це хибне, і контрприклад є в `S_∞ × ℛ₀`:

- Рухома точка дає цифри a\_k ∈ {a, b} ⊂ A на адресах 1ᵏ·2 (§9, кодування «хребта»); правило ρ додає 1 у 2-адичному запису цифр (одометр), невизначені цифри читає як a. Цей ρ причинний (§10: k-та цифра виходу залежить лише від цифр j ≤ k входу), g ≡ id.
- P := {t(n) : n ∈ ℤ}, де t(n) — дерево з цифрами 2-адичного запису n. Тоді F(t(n), ρ) = (t(n+1), ρ), F(P) = P, і F^k(t(n)) = t(n+k) ≠ t(n) для k ≥ 1. Усі точки P — APERIODIC (m = ∞), а P — INVARIANT\_DYNAMIC.

DP (мій приклад; закриває Q23/Q28 у відповіді CE-2).

## 5. Алгебра Ω і проєкція π\_Ω

**Означення 5.1 (6-ланцюг).** Ω з порядком від найменшого до найбільшого:

```text
CHAOTIC < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
        < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (π\_Ω).** π\_Ω : D\_class → Ω, D\_class := {Classify⁺(P)}:

```text
π_Ω(O, I, C) :=
   CHAOTIC                 якщо C = ⊤
   APERIODIC_NON_CHAOTIC   якщо O = APERIODIC
   EVENTUALLY_PERIODIC     якщо O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
   PERIODIC_SET            якщо O = PERIODIC_SET
   INVARIANT_DYNAMIC       якщо O = INVARIANT_DYNAMIC
   INVARIANT_FIXED         якщо O = INVARIANT_FIXED
```

(у всіх рядках крім першого — C = ⊥). Клас Ω\_set вважається **образом** π\_Ω — тобто Ω\_set = π\_Ω ∘ Classify⁺, і ніякого іншого класифікатора множин у специфікації немає.

**Твердження 5.3 (C5).** π\_Ω тотальна на D\_class, втратна (параметри μ, π, p, InclusionType не зберігаються) і має образом увесь Ω. DP. Тотальність: кожний OrbitType має рядок. Втратність: EVENTUALLY\_FIXED і EVENTUALLY\_PERIODIC переходять у один клас. Повнота образу на прикладах (всі — у системі з можливим додатковим діз'єднаним об'єднанням):

| Клас Ω | Приклад |
| :-- | :-- |
| INVARIANT\_FIXED | P = {d}, F(d) = d |
| INVARIANT\_DYNAMIC | P = {b, c}, F(b) = c, F(c) = b |
| PERIODIC\_SET | P = {b} у циклі b ↔ c |
| EVENTUALLY\_PERIODIC | P = {a}, F(a) = b, цикл b ↔ c: μ = 1, π = 2 |
| APERIODIC\_NON\_CHAOTIC | P = {t(0)} у одометрі §4.4 |
| CHAOTIC | приклад §11.4 (D5) |

**Означення 5.4 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b, ¬a := a → ⊥ (⊥ = CHAOTIC, ⊤ = INVARIANT\_FIXED).

**Твердження 5.5 (C6).** Це алгебра Гейтінга (будь-який скінченний ланцюг з найменшим і найбільшим), і виключене третє не виконується: EVENTUALLY\_PERIODIC ∨ ¬EVENTUALLY\_PERIODIC = max(EVENTUALLY\_PERIODIC, CHAOTIC) = EVENTUALLY\_PERIODIC ≠ INVARIANT\_FIXED. DP (стандартний факт про логіку Геделя–Даммета).

Застереження. Ω — синтаксичний інструмент; вона не класифікує об'єкти SUBIT і не пов'язана формально з білаттисом Белнапа. Знак ¬ тут лише алгебраїчний: ¬x = CHAOTIC для будь-якого x ≠ CHAOTIC.

## 6. Модальна логіка і динамічна теорія типів

Дві різні семантики, які не змішуються: LTL-подібна (про траєкторії) і гейтінгова (про значення в Ω).

### 6.1. LTL-подібна семантика

**Означення 6.1.** Для ŝ ∈ X і A ⊆ X (X — простір розширених станів):

```text
ŝ ⊨ X A    ⇔  F(ŝ) ∈ A                 (наступний крок)
ŝ ⊨ ◇ A    ⇔  ∃n ≥ 0: Fⁿ(ŝ) ∈ A       (колись)
ŝ ⊨ ◇⁺ A   ⇔  ∃n ≥ 1: Fⁿ(ŝ) ∈ A       (колись у майбутньому)
ŝ ⊨ □ A    ⇔  ∀n ≥ 0: Fⁿ(ŝ) ∈ A       (завжди)
ŝ ⊨ ↺ A    ⇔  ∃k > 1: Fᵏ(ŝ) ∈ A       (на кроці k > 1)
```

Увага про назву: ↺ A означає лише «на деякому кроці k > 1 стан у A». Це не «повернення в той самий стан» і не «нетривіальний цикл». Оператор X — примітивний і не ототожнюється з ↺. Відкликаний оператор ◯ в цій редакції не вживається. Властивість «множина A відновлюється» — це умова на множину A ⊆ ↺ A (тобто ∀ŝ ∈ A ∃k > 1: Fᵏ(ŝ) ∈ A); вона виконується не для кожної A.

**Твердження 6.2 (M1, аксіоми).** У семантиці 6.1 (A, B — множини, ¬ — доповнення, → — ¬A ∪ B) валідні:

```text
(X1) X A → ◇⁺ A                 (X2) X A ∧ X B ↔ X(A ∧ B)
(X3) X A ∨ X B ↔ X(A ∨ B)      (D1) ◇A ↔ A ∨ X ◇A
(D2) ◇⁺ A ↔ X ◇A                 (D3) ◇A ↔ A ∨ ◇⁺ A
(B1) □A ↔ A ∧ X □A               (B2) □A → A
(B3) □A → X □A                  (B4) □A → ◇A
(B5) □(A → B) → (□A → □B)       (R1) ↺A ↔ ◇⁺(X A)
(R2) ↺A → ◇⁺ A                  (M4) ◇A ↔ ¬□¬A
```

DP: кожна — пряма перевірка за означенням 6.1; наприклад (R1): ◇⁺(XA) дає ∃n ≥ 1: Fⁿ⁺¹(ŝ) ∈ A, тобто ∃k ≥ 2: Fᵏ(ŝ) ∈ A; (M4) — класична дуальність кванторів для множин.

**Твердження 6.3 (M2, M6).** □A → ↺A без додаткових умов. DP: □A у ŝ дає F²(ŝ) ∈ A, тобто k = 2 > 1. Це разом із тим тривіальне твердження: воно нічого не говорить про цикли, і тест реалізації має перевірятися саме на тотожному правилі (F(ŝ) = ŝ), де v6.0 мав порожній діапазон k.

### 6.2. Гейтінгова семантика

**Означення 6.4.** Для A : X → Ω: (□\_H A)(ŝ) := ⋀ₙ≥₀ A(Fⁿŝ), (◇\_H A)(ŝ) := ⋁ₙ≥₀ A(Fⁿŝ) у решітці Ω (§5).

**Твердження 6.5 (M3, M4 у гейтінговій семантиці не виконується).** Рівність ◇\_H A = ¬\_H □\_H ¬\_H A хибна. Контрмодель: X = {a, b}, F(a) = b, F(b) = b, A(a) = EVENTUALLY\_PERIODIC, A(b) = CHAOTIC. Тоді ¬\_H A(a) = CHAOTIC, ¬\_H A(b) = INVARIANT\_FIXED; □\_H ¬\_H A(a) = min(CHAOTIC, INVARIANT\_FIXED) = CHAOTIC; ¬\_H □\_H ¬\_H A(a) = INVARIANT\_FIXED; але ◇\_H A(a) = max(EVENTUALLY\_PERIODIC, CHAOTIC) = EVENTUALLY\_PERIODIC. DP.

§6.1 описує траєкторії, §6.2 — алгебраїчні значення. Це різні системи; питання про M4 як про властивість самого SUBIT — Q6, відкрите. Несуперечність усієї модальної системи разом із Ω — Q9, відкрите.

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : A @ τ — у контексті Γ терм t має тип A (множину станів) у часовому стані τ. Правила:

```text
Рефлексивність:  Γ, x:A@τ ⊢ x : A@τ
Еволюція:        Γ ⊢ t:A@τ    F(A) ⊆ B   ⇒   Γ ⊢ F(t) : B@(τ+1)
Стабільність:     Γ ⊢ t:A@τ    F(A) = A     ⇒   Γ ⊢ t : □A@τ
Потенційність:    Γ ⊢ t:A@τ    ∃k: Fᵏ(A) ⊆ B   ⇒   Γ ⊢ t : ◇B@τ
```

Статус: схема ВИЗНАЧЕНА; метатеорія збереження й повноти — НЕ ПІДТВЕРДЖЕНО.

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g), де S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. Оператор визначено за об'єктом: F\_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ), φ\_S : S\_X → S\_Y, φ\_ℛ : ℛ\_X → ℛ\_Y, з умовою динамічної сумісності:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))     для всіх ρ ∈ ℛ_X, s ∈ S_X
```

Це рівно умова на S-компоненту F; компонента g до умови не входить. Наслідок: два об'єкти з однаковими (S, ℛ) і різними g ізоморфні в SUBIT (тотожний морфізм).

**Означення 7.3 (SUBIT\_full).** Широка підкатегорія (ті самі об'єкти); морфізми додатково задовольняють φ\_ℛ(g\_X(ρ, s)) = g\_Y(φ\_ℛ(ρ), φ\_S(s)).

**Твердження 7.4 (K1).** SUBIT і SUBIT\_full — категорії. DP: тотожний морфізм задовольняє умовам; для композиції ψ∘φ: ψ\_S(φ\_S(ρ(s))) = ψ\_S((φ\_ℛρ)(φ\_S s)) = (ψ\_ℛφ\_ℛρ)(ψ\_Sφ\_S s); аналогічно для g-умови; асоціативність успадковується від функцій.

**Твердження 7.5 (K2, термінальний об'єкт).** 1 = ({∗}, {id}, g\_triv), g\_triv(id, ∗) = id — термінальний в SUBIT і в SUBIT\_full. DP: у кожного X єдиний морфізм (константи); обидві умови виконуються, бо цільова множина одноелементна. Термінальний об'єкт має один стан, а не 64.

**Твердження 7.6 (K3, добуток).** X × Y := (S\_X × S\_Y, ℛ\_X × ℛ\_Y, g\_X × g\_Y), де (ρ₁, ρ₂) діє покомпонентно, — добуток у SUBIT і SUBIT\_full. DP: бо S\_X, S\_Y непорожні, відображення (ρ₁, ρ₂) ↦ ρ₁ × ρ₂ ін'єктивне, тому ℛ\_X × ℛ\_Y ⊆ (S\_X × S\_Y)^(S\_X × S\_Y); проєкції — морфізми; пара ⟨φ, ψ⟩ — морфізм і єдина з потрібними проєкціями.

**Відкрито.** Декартова замкненість SUBIT і SUBIT\_full — Q1; твердження про експоненціали для об'єктів з оберненим F (з попередніх редакцій) не має доведення в наявних матеріалах і тому не заявляється. Ізоморфізм об'єктів SUBIT\_full з різними g — Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — функція з φ∘f = h∘φ.

**Твердження 8.2 (K4, Dyn — топос).** Dyn ≅ Fun(ℕ, Set) — прешейфи на моноїді ℕ; тому це топос. Класифікатор підоб'єктів: Ω\_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞ і «істиною» 0. Підоб'єкт — U ⊆ S з f(U) ⊆ U; час входу χ\_U(x) := min{n ≥ 0 : fⁿ(x) ∈ U} (∞, якщо ніколи). DP, стандартний результат: (i) χ\_U(f(x)) = max(χ\_U(x) − 1, 0): якщо χ\_U(x) = n ≥ 1, то f(x) входить у U за n − 1 кроків; якщо x ∈ U, то й f(x) ∈ U; (ii) астивація U ↦ χ\_U — бієкція Sub(S) → Hom(S, Ω\_Dyn): U = χ\_U⁻¹(0), а морфізм ψ : S → Ω\_Dyn знаходиться як χ підоб'єкта ψ⁻¹(0). Для правильної ідентифікації Ω\_Dyn з правими ідеалами моноїда ℕ (∅ ↔ ∞, nℕ ↔ n) див. стандартну теорію прешейфів.

**Твердження 8.3 (K5, вкладення).** (S, f) ↦ (S, {f}, g) з g(f, s) := f — повне і вірне вкладення Dyn у SUBIT і SUBIT\_full. DP: морфізм між такими об'єктами — це рівно φ\_S з φ\_S∘f = h∘φ\_S (φ\_ℛ єдина), а g-умова тривіальна.

**Застереження.** Топосна структура Dyn не переноситься на SUBIT автоматично. Q2′ (ВІДКРИТО): чи існує категорія C з Dyn ⊆ C ⊆ SUBIT, яка є топосом і зберігає нетривіальну метаеволюцію?

## 9. Простір S\_∞ = Tree\_∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω} (скінченні слова, адреси позицій; ε — порожнє слово), Λ := {None, node} ∪ {leaf(a) : a ∈ A} (|Λ| = 6). Tree\_∞ — множина функцій f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None для i = 1, 2, 3;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None для i = 1, 2, 3;
- (T4) f(σ) = None ⇒ f(σ·τ) = None для всіх τ ∈ Pos.

S\_∞ := Tree\_∞. Піддерево: f\_i(σ) := f(i·σ). Дерево з усіма листками на скінченній глибині — скінченне; інакше нескінченне.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree\_∞ з out(f) := inl(a), якщо f(ε) = leaf(a), і out(f) := inr(f₁, f₂, f₃), якщо f(ε) = node, — фінальна коалгебра функтора F(X) = A ⊔ X³ (це функтор на множинах, не оператор еволюції F з §2). DP (схема): для коалгебри c : Z → A ⊔ Z³ морфізм h(z)(σ) будується рекурсивно: state\_z(ε) := z; якщо c(state\_z(σ)) = inr(y₁, y₂, y₃), то state\_z(σ·i) := y\_i; якщо inl(a) — невизначено; h(z)(σ) = None при невизначеному state, інакше leaf(a) або node за видом c. (T1)–(T4) випливають з побудови; єдиність — індукцією за |σ|. Дерева без додаткових факторізацій задані функціями, тому бісимулятивність = рівність.

**Твердження 9.3 (T2, вкладення S₀).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S\_∞, образ — дерева глибини 1. DP: пряма перевірка (T1)–(T4) і різних значень на позиціях 1, 2, 3.

**Означення 9.4 (кодування «хребта»).** Фіксуємо три різні літери α, β, η ∈ A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ дерево t(a): t(a)(1ᵏ) = node, t(a)(1ᵏ·2) = leaf(aₖ), t(a)(1ᵏ·3) = leaf(η) для всіх k ≥ 0 (1ᵏ — k одиниць); інші позиції — за (T2)–(T4). Тоді t(a)₁ = t(σa), де σ — зсув послідовності, і маємо неперервне вкладення Y := {t(a)} ≅ {α, β}^ℕ зі зсувом «візьми перше піддерево».

### 9.2. Метрика d\_S

**Означення 9.5.** r(f, g) := min{ |σ| : f(σ) ≠ g(σ) } (∞, якщо f = g); d\_S(f, g) := 2^{−r(f, g)} (і 0, якщо f = g). Тобто d\_S(f, g) ≤ 2^{−n} ⇔ f і g збігаються на всіх позиціях глибини < n.

**Твердження 9.6 (T3, ультраметрика).** d\_S — ультраметрика на Tree\_∞. DP: розділення — з рівності функцій; для f, g, h маємо r(f, h) ≥ min(r(f, g), r(g, h)), бо на позиціях глибини менше цього мінімуму f = g = h.

**Твердження 9.7 (T4, оцінка піддерев).** d\_S(f\_i, g\_i) ≤ 2·d\_S(f, g) для всіх f, g з вузловими коренями. DP: позиція i·σ має глибину |σ| + 1, тому r(f\_i, g\_i) ≥ r(f, g) − 1. (Константа 2 досяжна: зсув взяттям піддерева не є причинним правилом.)

**Твердження 9.8 (T5, повнота й компактність).** (Tree\_∞, d\_S) компактний, а значить повний і цілком обмежений. DP (прямий довід, без оберненої границі): метрика d\_S — стандартна метрика добутку топології на Λ^Pos (кожен базовий відкритий — сукупність збігу на скінченному числі позицій глибини < n). Це добуток зліченної кількості скінченних дискретних множин, тому компактний (Тихонов; для зліченного добутку — діагональний аргумент). Умови (T1)–(T4) — кожна стосується скінченного числа координат (T4 — кон'юнкція таких для всіх пар «префікс — нащадок»), тому Tree\_∞ — перетин замкнених множин, тобто замкнена підмножина компакту. Компактний метричний простір повний і цілком обмежений.

**Зауваження 9.9 (що це за простір).** Ізольовані точки Tree\_∞ — рівно скінченні дерева (DP: скінченне дерево глибини h визначається своєю рестрикцією на глибину ≤ h + 1 за (T3), (T4)). Тобто S\_∞ не є канторівським простором; він нульвимірний компакт з перфектною частиною (нескінченні дерева, див. Y) і деякими ізольованими точками. У зауваженнях нижче: застаріла «обернена границя T\_n», яка в попередніх редакціях була пов'язана з S\_∞, не використовується: при кодуванні з міткою Bottom\_n на кожному рівні послідовність (Bottom\_n)\_n сумісна, але не є образом жодного дерева (контрприклад draft 5), тож бієкція з оберненою границею залежить від кодування й тут не заявляється.

## 10. Правила ℛ₀, припущення (H) і метрики

### 10.1. Причинні правила

**Означення 10.1.** ℛ₀ := { f : S\_∞ → S\_∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) для всіх s, t } — 1-ліпшицеві (причинні) функції. Метрика на ℛ₀: d\_ℛ(ρ, σ) := sup\_s d\_S(ρ(s), σ(s)) (рівномірна).

**Твердження 10.2 (T5′, причинність як незалежність від майбутнього).** f ∈ ℛ₀ ⇔ для всіх n: якщо s і t збігаються на глибині < n, то f(s) і f(t) збігаються на глибині < n (n-префікс виходу залежить лише від n-префіксу входу). DP: r(f(s), f(t)) ≥ r(s, t) — це рівно та ж вимога відтворена через r.

**Твердження 10.3 (T6, компактність ℛ₀).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. DP: всі функції з ℛ₀ однаково 1-ліпшицеві, тобто рівноступні; рівномірна границя 1-ліпшицевих функцій знову 1-ліпшицева, тому ℛ₀ замкнена; область значень S\_∞ компактна; отже, за теоремою Арцела–Асколі ℛ₀ компактний. Ультраметричність d\_ℛ — поточкова ультраметрична нерівність, яка лишається під супремумом. Наслідок: питання Q25 про «канонічну бієкцію Comp ↔ причинні» скасовано — Comp у цій редакції не потрібна.

**Твердження 10.4 (T9, потужності).** |ℛ₀| = 2^ℵ₀. DP: ≥ — константи c\_t (t ∈ S\_∞), їх 2^ℵ₀, бо |S\_∞| = 2^ℵ₀ (це нескінченні дерева виду Y); ≤ — неперервна функція на сепарабельному просторі (скінченні дерева щільні) визначається своїми значеннями на зліченній щільній множині, тобто їх не більше (2^ℵ₀)^ℵ₀ = 2^ℵ₀. ℛ₁ — клас функцій зі скінченним обчислюваним описом у фіксованій моделі обчислень (модель, кодування дерев і семантика виконання — частина означення); тому їх не більше зліченної кількості, і їх нескінченно багато (зокрема, константи обчислюваних дерев), так що |ℛ₁| = ℵ₀ при цьому припущенні. Добуток співвідношення ℛ₀ і ℛ₁ — Q20 (ВІДКРИТО); причинність і обчислюваність не тотожні.

### 10.2. Розширений простір і припущення (H)

**Припущення (H).** R ⊆ ℛ₀ — непорожна замкнена (а значить компактна) множина правил, і g : R × S\_∞ → R неперервна. Розширений простір X := S\_∞ × R з d̂((s, ρ), (t, σ)) := max(d\_S(s, t), d\_ℛ(ρ, σ)); F(s, ρ) := (ρ(s), g(ρ, s)). Умова g(ρ, s) ∈ R вбудована в (H) (це те, що в попередніх редакціях називалося NF3′). У скінченному SUBIT⁺ (H) тривіальне.

**Твердження 10.5 (T7, неперервність F).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)) для всіх ρ, σ ∈ ℛ₀, s, t. Отже при (H) F неперервна, а (X, d̂) — компактний ультраметричний простір. DP: d\_S(ρ(s), σ(t)) ≤ max(d\_S(ρ(s), ρ(t)), d\_S(ρ(t), σ(t))) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)), бо ρ 1-ліпшицева. Неперервність першої компоненти F це дає, другої — неперервність g. Компактність X — добуток компактів.

**Застереження.** Правила з ℛ₁, які не неперервні (та такі, що не входять у ℛ₀), у рамки (H) не потрапляють: для них ω-границі й класифікація §11 не визначені, і лише свідчення рівня PREFIX або APPROXIMATION (§11.5) можливі.

### 10.3. Метрики на розширеному просторі

**Твердження 10.6 (T8, d\_finite і d\_ω).** При (H) визначено d\_finite(x, y) := sup\_{n ≥ 0} 2^{−n}·d̂(Fⁿ(x), Fⁿ(y)). Вона — ультраметрика на X, що задає ту саму топологію, що й d̂. DP: масштабована контрольована супремумом ультраметрик (доданок n = 0 дає d\_finite ≥ d̂, тому розрізняє точки); для заданого ε обираємо N з 2^{−N} < ε, а перші N членів — рівномірно неперервні на компакті. Асимптотична метрика d\_ω(x, y) := d\_H(ω(x), ω(y)) (хаусдорфова відстань між непорожніми компактами, §11) — псевдометрика; метрика на факторі за відношенням ω(x) = ω(y). Узгодженість d\_finite і d\_ω для конкретних F — Q12 (ВІДКРИТО). Метрика d\_Ωtraj — §11.3.

## 11. Класифікація траєкторій P(τ)

У цьому розділі всюди припускається гіпотеза (H) з §10: R ⊆ ℛ₀ замкнена, g неперервна, тож F неперервне на компактному ультраметричному просторі X = S\_∞ × R. Без (H) твердження D1–D6 мають статус УМОВНО.

### 11.1 ω-границя, Att і класи S

Для траєкторії τ = (x\_n) з x\_{n+1} = F(x\_n) означимо ω(τ) як множину граничних точок підпослідовностей.

- **D1.** За (H) ω(τ) непорожня, компактна і F(ω(τ)) = ω(τ). Доказ: компактність X дає непорожність; замкненість випливає зі стандартної діагональної побудови; F(ω) = ω — з неперервності F. Статус: DP (доведено на папері, автор не рецензовано).
- **Att.** ATTAINED, якщо τ потрапляє в ω(τ) за скінченний час (∃n: x\_n ∈ ω(τ)). ASYMPTOTIC := ¬ATTAINED. Це **D2**: дві взаємовиключні позначки, без третього значення.
- **D6.** За (H) п'ять класів S(τ) вичерпні й взаємовиключні: FIXED, PERIODIC, QUASI\_PERIODIC\_MINIMAL, MINIMAL\_ZERO\_ENTROPY, CHAOTIC. Вичерпність: будь-яка ω(τ) є або скінченною орбітою, або нескінченною. Нескінченна ω(τ) або мінімальна (тоді нульова чи додатна ентропія), або містить власну мінімальну підмножину і тоді відноситься до складнішого класу; відповідний підклас фіксується окремою ознакою NON\_MINIMAL. Статус: УМОВНО (залежить від (H) і від тонкого розрізнення NON\_MINIMAL; доведення на папері неповне).

### 11.2 Ентропія та CHAOTIC

CHAOTIC означає h\_top(F|\_ω) > 0 і ніяк інакше. Це єдине значення терміна CHAOTIC у цій редакції (див. §0.4, рядок про третє значення).

- **D3.** Якщо F на ω(τ) нерозтягувальне (d(Fx,Fy) ≤ d(x,y)), то h\_top(F|\_ω) = 0. Доказ: нерозтягувальне відображення компактного метричного простору не збільшує (n,ε)-роздільні множини. Статус: DP.
- **D4 (мій результат).** Якщо g ≡ id, то F = (ρ(s), ρ) нерозтягувальне, отже h\_top = 0 і CHAOTIC неможливий. Статус: DP. Застереження: твердження «за g ≡ id клас NON\_MINIMAL порожній» спирається на теорему типу Едельштейна; без явної перевірки умов вона подається як ВІДКРИТО.

### 11.3 Метрика d\_Ω\_traj

Ω\_traj складається з 10 допустимих пар (S, Att) з таблиці 11.5. На Ω\_traj задається d\_Ω\_traj як довжина найкоротшого шляху в графі переходів «відмова від сертифікату»: сусідні пари відрізняються однією ознакою (клас S або Att). Це метрика на скінченній множині; її роль суто діагностична (відстань між двома результатами класифікації), в Ω-логіці не використовується.

### 11.4 Вироджена реалізація CHAOTIC × ATTAINED (D5)

Нехай g ≠ id. Візьмемо мінімальний підзсув Y додатної ентропії (існує за відомою теоремою) і правила-константи ρ\_c, які на кожному кроці ігнорують s і повертають c. Побудований за ними F має ω(τ), ізоморфну (Y, σ), тому h\_top > 0, а траєкторія стартує у Y, тобто ATTAINED. Це **D5**: пара CHAOTIC × ATTAINED реалізується, але вироджено (правило не залежить від стану). Статус: УМОВНО (спирається на існування мінімальних підзсувів додатної ентропії).

### 11.5 Таблиця реалізовності

| S(τ) | ATTAINED | ASYMPTOTIC |
| --- | --- | --- |
| FIXED | так | так |
| PERIODIC | так | так |
| QUASI\_PERIODIC\_MINIMAL | так | так |
| MINIMAL\_ZERO\_ENTROPY | так (одометр) | так |
| CHAOTIC | лише вироджено (D5) | так (ВІДКРИТО щодо невироджених прикладів) |

### 11.6 Одометр: контрприклад і приклад

- **Контрприклад до твердження про скінченну періодичність у S\_∞ × ℛ₀.** Одометр (ℤ₂, +1) вкладається у S\_∞ × ℛ₀ як мінімальна підсистема без періодичних точок. Отже, твердження «кожна ω-границя скінченно-періодична» хибне. Цим закрито питання Q23 і Q28.
- **Приклад MINIMAL\_ZERO\_ENTROPY.** Той самий одометр дає клас MINIMAL\_ZERO\_ENTROPY: мінімальний, нескінченний, h\_top = 0.

Статус обох результатів: DP.

### 11.7 Рівні сертифікації

Кожне виконання класифікації повертає одне з двох значень: COMPUTED (повний результат з указаним рівнем сертифікату) або RESOURCE\_EXCEEDED (обчислення перервано за бюджетом, результат не є класифікацією). Рівні сертифікату:

1. **L0.** Скінченна орбіта в S₀, перевірена обходом (повний доказ).
2. **L1.** Періодичність у розширеному стані (s,ρ), перевірена за скінченну кількість кроків.
3. **L2.** Верхня оцінка ентропії за нерозтягувальністю (D3/D4).
4. **L3.** Лише емпірична оцінка за обмеженим горизонтом (не доказ; позначається РЕЗУЛЬТАТ БЕЗ СЕРТИФІКАТУ).

## 13. Pilot-01 (переглянутий)

Пілот перевіряє не «теорему», а фальсифіковану гіпотезу: «за фіксованих правил g ≡ id усі траєкторії з S₀ мають нульову ентропію» (наслідок D4). Критерій провалу — будь-яка траєкторія, класифікована як CHAOTIC. Пілот не може довести нічого про S∞, лише перевірити реалізацію у малому масштабі.
