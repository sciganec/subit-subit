## 1. Алфавіт і простір S₀

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, 4 елементи.

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. Властивості білаттису не переносяться на динаміку S∞ без окремого означення. ВИЗНАЧЕНО.

**Означення 1.2 (A2).** S₀ = A × A × A, 64 стани. Стан із бітами b₁…b₆ має код

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3).** code6 — бієкція S₀ → {0, …, 63}. DP-f. *Доведення.* Кожен елемент S₀ — це слово з шести бітів (кожна літера A — два біти), а code6 — його двійковий запис. Двійковий запис однозначний, а слів 2⁶ = 64. ∎

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = 63; 010001 = YOU/NORTH/AUTUMN = 17. Гексаграмний запис (Додаток А) — лише індексація.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ) із S₀ × `ℛ_fin`. Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`, динаміка

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори, помилки й ресурсні переривання — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО.

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ) із #Q ≤ 64, тотальною δ : Q → Q і **без вхідного алфавіту** вкладається в SUBIT⁺. DP-f.

*Доведення.*

1. Оскільки #Q ≤ 64, є ін'єкція ι : Q → S₀. Поза образом ι(Q) фіксуємо довільне s₀ ∈ S₀.
2. Означимо ρ : S₀ → S₀ так: ρ(ι(q)) := ι(δ(q)) для q ∈ Q; ρ(s) := s₀ для s поза ι(Q).
3. Візьмемо `ℛ_fin` = {ρ} і g₀(ρ, s) := ρ. Тоді D₀(s, ρ) = (ρ(s), ρ).
4. Індукція за n: якщо початковий стан (ι(q₀), ρ), то n-й стан — (ι(δⁿ(q₀)), ρ). Крок: ρ(ι(δⁿ(q₀))) = ι(δⁿ⁺¹(q₀)). ∎

**Область.** Твердження стосується автономних систем з одним тотальним переходом. Воно не стверджує універсальної симуляції DFA із вхідним алфавітом, симуляції автоматів із #Q > 64 чи універсальності SUBIT⁺ як λ-інтерпретатора.

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀ означимо

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** У Q₀ для кожного ŝ число m(ŝ) скінченне. DP-f. *Доведення.* Стани ŝ, D₀(ŝ), …, D₀^N(ŝ) при N = #Q₀ — це N + 1 елемент множини з N елементів, тож два збігаються (Діріхле). Отже, множина в означенні m непорожня. ∎

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f. *Доведення.* За P1 пара (m, p) визначена однозначно. Класи — три взаємовиключні умови: m = 0 і p = 1; m = 0 і p ≥ 2; m ≥ 1. ∎

**Твердження 3.1.3 (P3, точний режим).** Алгоритм

```text
вхід: ŝ₀;  visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, #Q₀:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m
        повернути COMPUTED(клас, m, p, цикл)
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
```

завжди завершується з результатом COMPUTED, і m, p збігаються з означенням 3.1. Гілка `RESOURCE_EXCEEDED` недосяжна. DP-f. *Доведення.* За Діріхле повторення настає не пізніше n = #Q₀. Перший повтор ŝₙ = ŝ\_m з найменшим n дає саме мінімальні m і p = n − m. ∎

**Твердження 3.1.4 (P3′, бюджетований режим).** Якщо ліміт кроків N\_max < #Q₀, то для деяких систем, початкових станів і горизонтів гілка `RESOURCE_EXCEEDED` досяжна (недостатній горизонт не гарантує її для кожної системи: повтор може знайтися раніше), і її результат **не є класифікацією**. DP-f.

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H) (§10.2). Для ŝ ∈ S∞ × R

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. DP-f. *Доведення.* Якщо m = ∞, то p = ∞ за означенням; якщо m < ∞, то p < ∞, бо множина в його означенні містить число з означення m. Далі — розбиття за значеннями (m, p), як у 3.1.2. ∎

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. Це область усього §4–§5. Два приклади: Q₀ = S₀ × `ℛ_fin` з дискретною метрикою і D₀; X = S∞ × R з d̂ і D∞ за (H). P ⊆ K — **непорожня**, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

*Доведення.* Довільна P має одне значення μ(P). (a) μ = ∞: клас APERIODIC. (b) μ = 0: є n ≥ 1 з Dⁿ[P] = P, тож p_set ≤ n скінчене. Якщо p_set = 1, то D[P] = P і рівно одна з двох: INVARIANT_FIXED, якщо D = id на P, інакше INVARIANT_DYNAMIC. Якщо p_set ≥ 2, то D[P] ≠ P, і маємо PERIODIC_SET. (c) 1 ≤ μ < ∞: є n > μ з Dⁿ[P] = Dᵐ[P], тож π ≤ n − μ скінчене; π = 1 дає EVENTUALLY_FIXED, π ≥ 2 — EVENTUALLY_PERIODIC. Взаємна виключність: D[P] = P влече μ = 0, а PERIODIC_SET вимагає D[P] ≠ P; класи з μ ≥ 1 відрізняються значенням π. ∎

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f. *Доведення.* Якщо D[P] = P — перший клас. Інакше: якщо D[P] ∩ P = ∅ — другий. Інакше перетин непорожній, D[P] ≠ P, і рівно одне з: D[P] ⊊ P, P ⊊ D[P], або множини непорівнювані. ∎

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна (замкнена в K); (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне (у допустимій системі виконується автоматично). Якщо не виконано хоч одну — «передумови не виконано».

Топологічна ентропія `h_top(D|P)` — за Боуеном: через (n, ε)-роздільні множини в метриці dₙ(x, y) = max\_{i\<n} d(Dⁱx, Dⁱy), `h_top` = lim\_{ε→0} limsup\_n (1/n) log s(n, ε), де s(n, ε) — максимальна потужність такої множини.

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** `NOT_APPLICABLE` ≠ `NON_CHAOTIC`: перше — критерій не застосовується, друге — застосовано і не справджено.

**Застереження 4.3.3 (зміна проти v6.9.3).** У v6.9.3 CHAOTIC вимагав мінімальності, тож повний зсув на {α, β}^ℕ (ентропія log 2, є фіксована точка) не був хаотичним. Тепер хаотичність — це додатна ентропія, а мінімальність — це окрема ознака Min. Комбінація «мінімальна і хаотична» називається `MIN_POS` (§11).

### 4.4. Одне значення CHAOTIC

`IsChaotic_D(P)` :⇔ `ChaosStatus_D(P) = CHAOTIC`; `CHAOTIC_ω(τ)` (§11) :⇔ `IsChaotic_D(ω(τ))`. Це один предикат для множин і для ω-границь. Символ `CHAOTIC_set` — лише назва нижнього елемента Ω (§5); π\_Ω повертає його, якщо `IsChaotic_D(P)`. За (H) передумови для ω(τ) виконуються (D1, §11).

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL\_IMAGE ⇔ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT\_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT\_FIXED, INVARIANT\_DYNAMIC}. DP-f. *Доведення.* (a) — з означень. (b) Виконано (Π2), тож D[P] = P; з h\_top > 0 випливає D|ₚ ≠ id (h\_top(id) = 0), тож є x з D(x) ≠ x. (c) Виконано (Π2) за означенням. ∎

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f. *Доведення.* У скінченній P всі (n, ε)-роздільні множини мають потужність ≤ #P, тому (1/n) log s(n, ε) → 0. ∎

**Твердження 4.5.3 (C4, розділене).**

- **(C4a)** Якщо P скінченна і D[P] = P, то D|ₚ — бієкція і кожна точка P періодична. DP-f. *Доведення.* Сюр'єкція скінченної множини на себе є бієкцією, тож D|ₚ — перестановка, а кожна перестановка скінченної множини має скінченні періоди. ∎
- **(C4b)** Для нескінченної P бієктивність D|ₚ не тягне періодичності всіх точок. Контрприклад: одометр (§11.6). DP-f.
- **(C4c)** Для нескінченної P сюр'єктивність D|ₚ не тягне ін'єктивності. Контрприклад: односторонній зсув σ(x)ₙ = xₙ₊₁ на {0, 1}^ℕ: сюр'єктивний (прообраз x — 0x і 1x), не ін'єктивний. DP-f.

## 5. Алгебра Ω і проєкція π\_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D\_class).** D\_class := { Classify⁺\_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }. Усі координати кортежа обчислюються для тієї самої системи.

**Означення 5.3 (π\_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π\_Ω тотальна на D\_class. DP-f. *Доведення.* Для C = CHAOTIC — перший рядок; інакше O належить рівно одному з шести класів (C1), і кожен ужито у рядках 2–6. ∎

**Твердження 5.5 (C5b, сюр'єктивність).** Образ π\_Ω у D\_class складається з усіх шести елементів Ω. **DP-f за H.** *Свідки.* INVARIANT\_FIXED: P = {p} для нерухомої точки p. INVARIANT\_DYNAMIC: 2-цикл {x, D(x)}. PERIODIC\_SET: у 4-циклі a → b → c → d → a множина P = {a, c}: D[P] = {b, d} ≠ P, D²[P] = P, p\_set = 2. EVENTUALLY\_PERIODIC: P = {x₀} на системі x₀ → x₁ → x₂ → x₁ (μ = 1, π = 2). APERIODIC\_NON\_CHAOTIC: K = {0,1}^ℕ, D = σ (зсув), a\_n = 1 ⇔ n — степінь двійки, P = {σⁿ(a) : n ≥ 0}. Проміжки між одиницями необмежено зростають, тож a не є ніде періодичною, усі σⁿ(a) різні й Dᵏ[P] = P ∖ {a, …, σᵏ⁻¹(a)} — різні множини, μ = ∞. P не замкнена: σ^(2ᵐ+1)(a) → 0^∞ ∉ P. Тому (Π1)–(Π2) не виконуються й ChaosStatus = NOT_APPLICABLE. CHAOTIC\_set: множина G з W5 (§11.10). Свідок CHAOTIC\_set залежить від W5, яке у свою чергу залежить від леми E (умовно за H). Решта п'ять свідків — безумовні. ∎

**Зауваження 5.6 (`APERIODIC_NON_CHAOTIC` — втратна мітка).** Якщо μ(P) = ∞, то D[P] ≠ D⁰[P] = P, тож (Π2) не виконується й ChaosStatus = NOT\_APPLICABLE. Отже, поєднання «OrbitType = APERIODIC і ChaosStatus = NON\_CHAOTIC» за означеннями неможливе. Елемент `APERIODIC_NON_CHAOTIC` ланцюга Ω — це мітка образу π\_Ω («аперіодична множина, яка не CHAOTIC»), а не твердження про статус NON\_CHAOTIC.

**Застереження 5.6.1.** Для фіксованої скінченної системи образ π\_Ω не може містити `CHAOTIC_set` (C7).

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥ (⊥ = CHAOTIC\_set, ⊤ = INVARIANT\_FIXED).

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f. *Доведення.* Ланцюг — гратка з 0 і 1. Треба перевірити min(a, c) ≤ b ⇔ c ≤ (a → b). Якщо a ≤ b: ліва частина завжди істинна (min ≤ a ≤ b), права — c ≤ ⊤. Якщо a > b: min(a, c) ≤ b ⇔ c ≤ b і a → b = b. Виключене третє хибне: для a без ⊥ і ⊤ є a ∨ ¬a = a ∨ ⊥ = a ≠ ⊤. ∎

**Застереження 5.9.** π\_Ω втратна (відкидає InclusionType і Min, а також різницю NOT\_APPLICABLE / NON\_CHAOTIC). Ω — синтаксичний інструмент, формально не пов'язана з білаттисом Белнапа.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

Для довільної динамічної системи (K, D), x ∈ K, U ⊆ K; `¬U := K ∖ U` — класичне доповнення, не тотожне `¬_H` з §6.2.

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`F_tree` — виключно функтор `X ↦ A ⊔ X³`; динаміка позначається буквою D.

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. DP-f.

```text
(X1) X U → ◇⁺ U                  (X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)       (D1) ◇U ↔ U ∨ X ◇U
(D2) ◇⁺ U ↔ X ◇U                  (D3) ◇U ↔ U ∨ ◇⁺ U
(B1) □U ↔ U ∧ X □U                (B2) □U → U
(B3) □U → X □U                    (B4) □U → ◇U
(B5) □(U → V) → (□U → □V)       (R1) ↺U ↔ ◇⁺(X U)
(R2) ↺U → ◇⁺ U                  (M4) ◇U ↔ ¬□¬U
```

*Доведення.* Фіксуємо x; uₙ := [Dⁿ(x) ∈ U], vₙ — аналогічно для V. Тоді XU ⇔ u₁; ◇U ⇔ ∃n≥0 uₙ; ◇⁺U ⇔ ∃n≥1 uₙ; □U ⇔ ∀n≥0 uₙ; ↺U ⇔ ∃k≥2 uₖ. Для формули φ істина Xφ в x — це істина φ в D(x), а послідовність для D(x) — зсув (uₙ₊₁). Тому X◇U ⇔ ∃m≥0 u\_{m+1} ⇔ ∃n≥1 uₙ; X□U ⇔ ∀n≥1 uₙ; ◇⁺(XU) ⇔ ∃n≥1 u\_{n+1} ⇔ ∃k≥2 uₖ. Тепер кожна аксіома — тавтологія кванторів по ℕ. ∎

**Твердження 6.1.2 (M2, M6).** □U → ↺U. DP-f: □U дає D²(x) ∈ U, тобто k = 2 > 1.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** Для предиката U : K → Ω: (□\_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇\_H U)(x) := ⋁ₙ≥0 U(Dⁿx) у решітці Ω; `¬_H a := a → ⊥` — псевдодоповнення в Ω.

**Твердження 6.2.2 (M3).** Рівність ◇\_H U = ¬\_H □\_H ¬\_H U у семантиці §6.2 **хибна**. DP-f. *Контрмодель:* K = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY\_PERIODIC, U(b) = CHAOTIC\_set (= ⊥). Обчислення: (◇\_H U)(a) = max(EVENTUALLY\_PERIODIC, ⊥) = EVENTUALLY\_PERIODIC. (¬\_H U)(a) = ⊥ (бо U(a) > ⊥), (¬\_H U)(b) = ⊤. (□\_H ¬\_H U)(a) = min(⊥, ⊤) = ⊥, тож (¬\_H □\_H ¬\_H U)(a) = ⊤ ≠ EVENTUALLY\_PERIODIC. ∎

**Твердження 6.2.3 (Q6 закрито для §6.2).** M4 у гейтінговій семантиці §6.2 не виконується (це рівність M3). DP-f. **Q6′ (ВІДКРИТО):** чи є інша гейтінгова семантика (інша решітка або інше означення □\_H, ◇\_H), у якій M4 виконується?

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : U @ τ читається в моделі §6.1 як «точка t належить U»; час τ — лише лічильник.

```text
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ
Еволюція:        Γ ⊢ t:U@τ    D[U] ⊆ V         ⇒  Γ ⊢ D(t) : V@(τ+1)
Стабільність:     Γ ⊢ t:U@τ    D[U] ⊆ U         ⇒  Γ ⊢ t : □U@τ
Потенційність:    Γ ⊢ t:U@τ    ∃k≥0: Dᵏ[U] ⊆ V ⇒  Γ ⊢ t : ◇V@τ
```

**Твердження 6.3.1 (коректність правил).** У моделі §6.1 кожне правило коректне. DP-f. *Доведення.* Еволюція: t ∈ U ⇒ D(t) ∈ D[U] ⊆ V. Стабільність: з D[U] ⊆ U індукцією Dⁿ(t) ∈ U для всіх n. Потенційність: Dᵏ(t) ∈ Dᵏ[U] ⊆ V. ∎ Правило стабільності ослаблено до D[U] ⊆ U (erratum E-4). Повнота і дальша метатеорія — НЕ ПІДТВЕРДЖЕНО.

### 6.4. Предикати префікса

```text
PH_φ(N) := ∀k ≤ N: φ(k, τ)
EP_φ(N) := ∃k ≤ N: φ(k, τ)
PP_φ(k) := φ(k, τ)
GP_φ(τ)                            (Global)
```

Правила: PH\_φ(N+1) ⇒ PH\_φ(N); EP\_φ(N) ⇒ EP\_φ(N+1); PH\_φ(N) ⇒ EP\_φ(N). Імплікацій між PP і GP немає. Символ Ψ зарезервовано для оператора продуктивності (§9.2).

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g): S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. Динаміка D\_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ\_S, φ\_ℛ) з однією умовою сумісності з S-компонентою:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))
```

Умова не включає g.

**Означення 7.3 (SUBIT\_full).** Широка підкатегорія; морфізми додатково задовольняють φ\_ℛ(g\_X(ρ, s)) = g\_Y(φ\_ℛ(ρ), φ\_S(s)).

**Твердження 7.4 (K1).** SUBIT і SUBIT\_full — категорії. DP-f. *Доведення.* Тотожний морфізм (id\_S, id\_ℛ) задовольняє обидві умови тривіально. Композиція — покомпонентна, тому асоціативна. Якщо φ : X → Y, ψ : Y → Z, то ψ\_S(φ\_S(ρ(s))) = ψ\_S(φ\_ℛ(ρ)(φ\_S s)) = ψ\_ℛ(φ\_ℛ ρ)(ψ\_S φ\_S s). Для SUBIT\_full: ψ\_ℛ(φ\_ℛ(g\_X(ρ, s))) = ψ\_ℛ(g\_Y(φ\_ℛρ, φ\_S s)) = g\_Z(ψ\_ℛφ\_ℛρ, ψ\_Sφ\_S s). ∎

**Твердження 7.5 (K2).** 1 = ({∗}, {id}, g\_triv) — термінальний об'єкт у SUBIT і SUBIT\_full. DP-f. *Доведення.* Морфізм X → 1 має лише одну компоненту кожного типу, бо кодомени — одноточкові; умови виконуються. ∎

**Твердження 7.6 (K3, добуток).** Для X, Y:

```text
(ρ ⊠ σ)(x, y) := (ρ(x), σ(y))         на S_X × S_Y
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
```

— добуток у SUBIT і у SUBIT\_full. DP-f.

*Доведення.* Розклад `ρ ⊠ σ` однозначний, бо `S_X`, `S_Y` непорожні: `ρ` відновлюється з першої координати значення при будь-якому `y`, а `σ` — з другої. Тому `g_{X×Y}` коректно задана й має значення в `ℛ_{X×Y}`. Проєкції: `pr_X = (pr₁, (ρ ⊠ σ) ↦ ρ)` і `pr_Y` аналогічно; умова 7.2: `pr₁((ρ ⊠ σ)(x, y)) = ρ(x) = pr_X,ℛ(ρ ⊠ σ)(pr₁(x, y))`. Нехай `u : Z → X`, `v : Z → Y`. Покладемо `⟨u, v⟩_S(z) := (u_S z, v_S z)` і `⟨u, v⟩_ℛ(τ) := u_ℛ(τ) ⊠ v_ℛ(τ)`. Умова 7.2: `⟨u, v⟩_S(τ(z)) = (u_ℛ(τ)(u_S z), v_ℛ(τ)(v_S z)) = (u_ℛ(τ) ⊠ v_ℛ(τ))(u_S z, v_S z)`. Цей морфізм єдиний, що комутує з проєкціями. Для SUBIT\_full: `φ_ℛ(g_Z(τ, z)) = g_X(u_ℛτ, u_S z) ⊠ g_Y(v_ℛτ, v_S z) = g_{X×Y}(⟨u, v⟩_ℛτ, ⟨u, v⟩_S z)`, тож проєкції теж g-сумісні. ∎

**Застереження 7.7.** Якщо категорія має допускати порожні S, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X`. **Відкрито:** Q1, Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — це φ ∘ f = h ∘ φ. Dyn₊ — повна підкатегорія з непорожніми S.

**Твердження 8.2 (K4, топос).** Dyn ≅ Fun(Bℕ, Set), де Bℕ — категорія з одним об'єктом і моноїдом ендоморфізмів (ℕ, +, 0) (не категорія-порядок ℕ). Функтор відправляє єдиний об'єкт у S, а n — у fⁿ. Це прешейфовий топос, тому Dyn — топос (DP-s: стандартна теорема). Класифікатор підоб'єктів виписано явно нижче (твердження 8.4).

**Означення 8.3 (час входу, лише для інваріантних U).** Нехай U ⊆ S підоб'єкт, тобто f[U] ⊆ U. Тоді χ\_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U } (∞, якщо ніколи).

**Твердження 8.4 (χ\_U, класифікатор підоб'єктів).** Нехай Ω\_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞, і «істиною» 0. Тоді (a) χ\_U(f(x)) = max(χ\_U(x) − 1, 0), тобто χ\_U — морфізм Dyn; (b) U ↦ χ\_U є бієкцією між підоб'єктами (S, f) і морфізмами (S, f) → Ω\_Dyn, з оберненою U = χ⁻¹(0). DP-f.

*Доведення.* (a) Якщо χ\_U(x) = n ≥ 1, то f(x) потребує рівно n − 1 кроків: бо fᵏ(f(x)) = f^{k+1}(x) ∈ U лише при k + 1 ≥ n. Якщо χ\_U(x) = 0, то f(x) ∈ U за інваріантністю, тож χ\_U(f x) = 0. Якщо χ\_U(x) = ∞ — так само ∞. (b) Якщо χ : S → Ω\_Dyn — морфізм, то χ⁻¹(0) інваріантна: χ(f x) = max(χ(x) − 1, 0) = 0 при χ(x) = 0. Для U = χ⁻¹(0) і скінченного χ(x) = n: χ(fᵏ x) = n − k > 0 при k < n і χ(fⁿ x) = 0, тому χ\_U(x) = n; при χ(x) = ∞ усі χ(fᵏ x) = ∞ ≠ 0. Відтак χ\_U = χ. І навпаки χ\_U⁻¹(0) = U. ∎

**Застереження 8.5.** Для неінваріантної U ⊆ S формула χ\_U загалом **не** еквіваріантна й не є морфізмом. Наприклад, f(0) = 1, f(1) = 1 на S = {0, 1}, U = {0}: χ\_U(0) = 0, але χ\_U(f(0)) = χ\_U(1) = ∞ ≠ max(0 − 1, 0).

**Твердження 8.6 (K5, вкладення).** Функтор E : Dyn₊ → SUBIT, (S, f) ↦ (S, {f}, g\_f), g\_f(f, s) := f, на морфізмах φ ↦ (φ, єдине відображення {f} → {h}) — повний і вірний, і такий самий функтор вкладає Dyn₊ у SUBIT\_full. DP-f. *Доведення.* Умова 7.2 для пари (φ, !) це рівно φ(f(s)) = h(φ(s)), тобто морфізм Dyn. Друга компонента морфізму визначена однозначно, тому E вірний і повний. Умова 7.3 тривіальна, бо ℛ одноелементна. ∎

**Застереження 8.7.** Вкладення всієї Dyn неможливе без перегляду типу правил (S = ∅). Топосна структура Dyn не переноситься на SUBIT автоматично.

## 9. Простір S∞ = Tree∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, алфавіт міток Λ := {None, node} ∪ {leaf(a) : a ∈ A} (6 елементів). Tree∞ — множина f : Pos → Λ, що задовольняють

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None для i = 1, 2, 3;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None для будь-якого τ.

S∞ := Tree∞. Піддерево для f(ε) = node: f\_i(σ) := f(i·σ); для f(ε) = leaf(a) піддерево **не визначене**.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree∞ з out(f) := inl(a) при f(ε) = leaf(a) і out(f) := inr(f₁, f₂, f₃) при f(ε) = node — фінальна коалгебра функтора `F_tree(X) = A ⊔ X³`. DP-s.

**Твердження 9.3 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S∞. DP-f: значення f(1), f(2), f(3) відновлюють a, b, c.

### 9.2. Допоміжна конструкція: Ψ і L\_prod

```text
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) } ∪ { Bottom_{n+1} } ∪ { Node_n(t₁, t₂, t₃) : tᵢ ∈ T_n }
q_0 : T_1 → T_0:   Leaf_1 a ↦ Leaf_0 a,  Bottom_1 ↦ Bottom_0,  Node_0(…) ↦ Bottom_0
q_{n+1} : T_{n+2} → T_{n+1}:  Leaf ↦ Leaf,  Bottom ↦ Bottom,
                              Node_{n+1}(t₁,t₂,t₃) ↦ Node_n(q_n t₁, q_n t₂, q_n t₃)
U_c := { (t_n) ∈ ∏ T_n : q_n(t_{n+1}) = t_n для всіх n }
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }
NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0, ∃u₁,u₂,u₃ ∈ X з t_{n+1} = Node_n(u₁_n, u₂_n, u₃_n) для всіх n ≥ 0 }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X);     L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.4.** L\_prod = Ψ(L\_prod). DP-f. *Доведення.* L\_prod — об'єднання всіх X з X ⊆ Ψ(X); Ψ монотонний. Для кожного такого X: X ⊆ Ψ(X) ⊆ Ψ(L\_prod), тому L\_prod ⊆ Ψ(L\_prod). Звідси Ψ(L\_prod) ⊆ Ψ(Ψ(L\_prod)), тобто Ψ(L\_prod) — постнерухома точка, отже Ψ(L\_prod) ⊆ L\_prod. ∎

**Зауваження 9.5.** `U_c` **строго більша** за L\_prod: послідовність (Bottom\_n)ₙ належить U\_c, але не задовольняє ні LeafSeqs, ні NodeSeqs.

### 9.3. d\_n, at\_n, lim\_tree

```text
d_0(f) := Leaf_0(a) якщо f(ε) = leaf(a);   Bottom_0 якщо f(ε) = node
d_{n+1}(f) := Leaf_{n+1}(a)                       якщо f(ε) = leaf(a)
d_{n+1}(f) := Node_n(d_n f₁, d_n f₂, d_n f₃)      якщо f(ε) = node

TΣ := Σ_k T_k  (пари (k, u), u ∈ T_k);    at_n : T_n → Pos → Option(TΣ)
at_n(t, ε) := Some((n, t));            at_0(t, i·τ) := None
at_{n+1}(Leaf, i·τ) := None;          at_{n+1}(Bottom, i·τ) := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ) := at_n(u_i, τ)
```

**Лема 9.6 (типізація).** d\_n(f) ∈ T\_n, q\_n(d\_{n+1} f) = d\_n f; якщо at\_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T\_k. DP-f: індукція за n і |σ|.

**Означення 9.7 (lim\_tree).** Для t = (t\_m) ∈ L\_prod і σ ∈ Pos, m > |σ| розглядаємо at\_m(t\_m, σ). Рівно один із трьох випадків стабілізується при m → ∞: (Z) усе None; (L) Some((m − |σ|, Leaf(a))) для фіксованого a; (N) Some((m − |σ|, Node(…))). Тоді lim\_tree(t)(σ) := None, leaf(a), node відповідно.

**Твердження 9.8 (реконструкція).** (a) lim\_tree(t) ∈ Tree∞; (b) p(f) := (d\_n f)ₙ ∈ L\_prod і lim\_tree(p(f)) = f; (c) p(lim\_tree(t)) = t. DP-s.

### 9.4. Метрика d\_S і компактність

```text
r_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) }   (∞, якщо f = g)
d_S(f, g)    := 2^{− r_addr(f, g)}            (0, якщо f = g)
r_app(f, g)  := min{ n ≥ 0 : d_n f ≠ d_n g }
```

**Лема 9.9.** r\_app = r\_addr. DP-s.

**Твердження 9.10 (T3).** d\_S — ультраметрика. DP-f. *Доведення.* Симетрія і d\_S(f, g) = 0 ⇔ f = g — з означення. На адресах довжини < min(r\_addr(f, g), r\_addr(g, h)) маємо f = g = h, тому r\_addr(f, h) ≥ min(…), тобто d\_S(f, h) ≤ max(d\_S(f, g), d\_S(g, h)). ∎

**Твердження 9.11 (T4).** Якщо f(ε) = g(ε) = node, то для i = 1, 2, 3: d\_S(f\_i, g\_i) ≤ 2·d\_S(f, g). DP-f. *Доведення.* Якщо f = g, тривіально. Інакше r := r\_addr(f, g) ≥ 1. Якщо f\_i(τ) ≠ g\_i(τ), то f(i·τ) ≠ g(i·τ), тож |i·τ| ≥ r, тобто |τ| ≥ r − 1. Відтак r\_addr(f\_i, g\_i) ≥ r − 1 і d\_S(f\_i, g\_i) ≤ 2^{−(r−1)} = 2·d\_S(f, g). ∎

**Твердження 9.12 (T5).** (Tree∞, d\_S) — компактний, повний, цілком обмежений. DP-f. *Доведення.* Множина Λ^Pos з добутковою топологією — компакт (зліченний добуток скінченних дискретних множин). Кожна з умов (T1)–(T4) замкнена, бо залежить лише від пари координат. Отже Tree∞ замкнена в компакті, також компактна. Куля {g : r\_addr(f, g) > r} збігається з циліндром, що фіксує скінченно багато координат, тому d\_S метризує цю топологію. Компактна метрична → повна й цілком обмежена. ∎

**Твердження 9.13 (адресний доступ).** Для f ∈ Tree∞, σ ∈ Pos, n > |σ|: f(σ) = leaf(a) ⇒ at\_n(d\_n f, σ) = Some((n − |σ|, Leaf(a))); f(σ) = node ⇒ корінь at\_n(d\_n f, σ) — Node; f(σ) = None ⇒ at\_n(d\_n f, σ) = None. DP-s.

### 9.5. «Хребет» і простір Y

Фіксуємо літери α ≠ β та η з A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ:

```text
t(a)(1ᵏ) := node,    t(a)(1ᵏ·2) := leaf(a_k),    t(a)(1ᵏ·3) := leaf(η)
```

інші позиції — за (T2)–(T4).

**Твердження 9.14.** t : {α, β}^ℕ → S∞ неперервне й ін'єктивне; d\_S(t(a), t(b)) = 2^{−(k+1)}, де k — перший індекс розбіжності a і b. Y := t({α, β}^ℕ) — канторів простір, замкнений в S∞. Зсув σ спряжений до T := t ∘ σ ∘ t⁻¹ на Y. DP-f.

**Зауваження 9.15.** S∞ — нульвимірний компакт; скінченні дерева — ізольовані точки. Множина нескінченних дерев — замкнена й досконала. Y — досконала підмножина, гомеоморфна канторовому простору, але не вся ця множина: повне потрійне дерево (node на всіх адресах) нескінченне, проте не лежить у Y.

## 10. Правила ℛ₀ і ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні та обчислювані правила

**Означення 10.1.** ℛ₀ := ℛ\_caus := { f : S∞ → S∞ : d\_S(f(s), f(t)) ≤ d\_S(s, t) }, метрика d\_ℛ(ρ, σ) := sup\_s d\_S(ρ(s), σ(s)).

**Означення 10.2.** ℛ₁ := ℛ\_comp — функції S∞ → S∞ зі скінченним обчислювальним описом у фіксованій моделі (дерево подано оракулом).

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ для кожного n мітки виходу на адресах довжини ≤ n залежать лише від міток входу на адресах довжини ≤ n. DP-f. *Доведення.* Нерівність d\_S(f s, f t) ≤ d\_S(s, t) еквівалентна r\_addr(f s, f t) ≥ r\_addr(s, t). ∎

**Твердження 10.4 (T6).** (ℛ₀, d\_ℛ) — компактний ультраметричний простір. DP-s.

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀; |ℛ₁| = ℵ₀ за припущення про модель. DP-s.

### 10.2. Розширений простір і передумови (контракт H1–H3)

**Припущення (H).** Явний контракт залежностей для всіх тверджень §11:

- **(H1)** (S∞, d\_S) є компактним ультраметричним простором (встановлюється T3 і T5 у §9.4).
- **(H2)** R ⊆ ℛ₀ — непорожній компактний підпростір у метриці d\_ℛ. Компактність R приймається як пряма передумова, а не виводиться з непідтвердженого T6 у цій редакції.
- **(H3)** g∞ : R × S∞ → R — неперервна і тотальна.

Покладемо X := S∞ × R, d̂((s, ρ), (t, σ)) := max(d\_S(s, t), d\_R(ρ, σ)), де d\_R := d\_ℛ∣\_{R×R}. Динаміка D∞(s, ρ) := (ρ(s), g∞(ρ, s)).

За (H1)–(H3) простір X компактний, а D∞ неперервний за T7. Відтак D1 і Lemma про скінченну ω (§11.1) є DP-f **умовно за (H1)–(H3)**.

**Припущення (H₀).** Для скінченної моделі SUBIT⁺: S₀ скінченне з дискретною топологією, D₀ та g₀ тотальні. (H₀) не є екземпляром (H).

**Означення 10.6.** π\_R : R × S∞ → R, π\_R(ρ, s) := ρ. **Тотожна метаеволюція** — це `g∞ = π_R` (запис `g∞ ≡ id` типізований некоректно: id має кодомен R × S∞, а не R).

### 10.3. Метрики на X

**Твердження 10.7 (T7).** d\_S(ρ(s), σ(t)) ≤ max(d\_S(s, t), d\_ℛ(ρ, σ)); отже за (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. **DP-f за H.** *Доведення.* d\_S(ρ s, σ t) ≤ max(d\_S(ρ s, σ s), d\_S(σ s, σ t)) ≤ max(d\_ℛ(ρ, σ), d\_S(s, t)), бо σ ∈ ℛ₀. Неперервність другої компоненти — з (H3). X компактний як добуток компактів (S∞ по T5, R замкнена в компактному ℛ₀ за H2). ∎

**Твердження 10.8 (T8).** d\_finite(x, y) := sup\_{n≥0} 2^{−n}·d̂(D∞ⁿ x, D∞ⁿ y) — ультраметрика, що задає ту саму топологію, що d̂. **DP-f за H.** *Доведення.* Кожен член 2^{−n} d̂(Dⁿ x, Dⁿ y) задовольняє ультраметричну нерівність, тож і їхній sup. Член n = 0 дорівнює d̂, тому d\_finite ≥ d̂ і d\_finite(x, y) = 0 ⇒ x = y. Топологія: d\_finite ≥ d̂, а для обраного беремо N з 2^{−N} < ε; члени n ≥ N менші за ε; для n < N неперервність D∞ⁿ (за H) дає δ. ∎

**Означення 10.9 (d\_H, d\_H^X).** Для непорожніх компактних P, Q: d\_H(P, Q) := max{ sup\_{p∈P} inf\_{q∈Q} d(p, q), sup\_{q∈Q} inf\_{p∈P} d(p, q) }; для P, Q ⊆ S∞ це d\_H з d = d\_S, для P, Q ⊆ X — d\_H^X з d = d̂.

**Означення 10.10 (d\_ω).** Для x, y ∈ X: d\_ω(x, y) := d\_H^X(ω(x), ω(y)) — псевдометрика на X; метрика — на факторі X/\~, де x \~ y ⇔ ω(x) = ω(y). DP-f за H.

**Застереження 10.11.** Правила з ℛ₁, що не є неперервними, у (H) не потрапляють.

## 11. Класифікація траєкторій P(τ)

Усюди припускається (H). Траєкторія τ = (x\_n) має x\_{n+1} = D∞(x\_n); ω(τ) — множина граничних точок підпослідовностей.

### 11.1. ω-границя і класи S(τ)

**Твердження 11.1 (D1).** За (H) ω(τ) непорожня, компактна і D∞[ω(τ)] = ω(τ). **DP-f за H.** *Доведення.* ω(τ) = ⋂\_N cl{x\_n : n ≥ N} — перетин вкладених непорожніх компактів, тому непорожній і компактний. Включення D∞[ω] ⊆ ω: якщо y = lim x\_{n\_i}, то D∞(y) = lim x\_{n\_i + 1} за неперервністю. Включення ω ⊆ D∞[ω]: для y = lim x\_{n\_i} обираємо підпослідовність, для якої x\_{n\_i − 1} → z; тоді z ∈ ω і D∞(z) = y. ∎

**Означення 11.2 (Att).** ATTAINED ⇔ ∃n: x\_n ∈ ω(τ). NONATTAINED := ¬ATTAINED.

**Означення 11.3 (класи S(τ)).**

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω = {p} |
| PERIODIC | ω скінченна, #ω > 1 |
| MIN\_ZERO | ω нескінченна, мінімальна, h\_top = 0 |
| MIN\_POS | ω нескінченна, мінімальна, h\_top > 0 |
| NONMIN\_ZERO | ω нескінченна, не мінімальна, h\_top = 0 |
| NONMIN\_POS | ω нескінченна, не мінімальна, h\_top > 0 |

`QUASI_PERIODIC_MINIMAL` — підклас MIN\_ZERO. `CHAOTIC_ω(τ)` — це «h\_top > 0».

**Твердження 11.4 (D6).** За (H) шість класів попарно не перетинаються й вичерпують усі траєкторії. **DP-f за H.** *Доведення.* За D1 ω непорожня компактна інваріантна. Якщо вона скінченна, то або #ω = 1 (FIXED), або #ω > 1 (PERIODIC); ентропія скінченної системи нульова (C7). Якщо нескінченна, маємо дві незалежні дихотомії: мінімальна або ні, h\_top = 0 або h\_top > 0 — чотири взаємовиключні класи. ∎

### 11.2. Ентропія

**Твердження 11.5 (D3).** Якщо D нерозтягувальне на компактній множині P (d(Dx, Dy) ≤ d(x, y)), то h\_top(D|P) = 0. DP-f. *Доведення.* З нерозтягувальності d ≤ dₙ ≤ d, тобто dₙ = d. Отже (n, ε)-роздільна множина — це просто ε-роздільна, і її потужність обмежена числом, незалежним від n (цілком обмеженість). Тоді (1/n) log s(n, ε) → 0. ∎

**Твердження 11.6 (D4).** Якщо g∞ = π\_R, то D∞(s, ρ) = (ρ(s), ρ) нерозтягувальне на X, отже h\_top = 0 на кожній замкненій інваріантній множині і жодна множина не є CHAOTIC. **DP-f за H.** *Доведення.* d̂(D(s, ρ), D(t, σ)) = max(d\_S(ρ s, σ t), d\_R(ρ, σ)) ≤ max(d\_S(s, t), d\_R(ρ, σ)) = d̂((s, ρ), (t, σ)) за T7; далі D3. ∎

**Твердження 11.7 (D3′).** Якщо g∞(ρ, s) = ρ для одного ρ і всіх s, то K\_ρ := S∞ × {ρ} додатно інваріантна. Обмеження D∞|K\_ρ спряжене з ρ через проєкцію на першу координату; h\_top(D∞|K\_ρ) = 0. **DP-f за H.** *Доведення.* D∞[K\_ρ] = ρ[S∞] × {ρ} ⊆ K\_ρ; проєкція q(s, ρ) = s — топологічне спряження з ρ. ρ ∈ ℛ₀ нерозтягувальне, тож за D3 h\_top = 0. Рівність D∞[K\_ρ] = K\_ρ виконується лише для сюр'єктивного ρ. ∎

### 11.3. Метрика d\_Ω\_traj

Кожна пара (S, Att) — це чотири ознаки (розмір, Min, ентропія, Att), де «—» — окреме значення-код «не стосується» (метрика вимірює відстань між кодами класифікації, а не між фактичними властивостями ω-множин):

| Клас | Розмір | Min | Ентропія |
| :-- | :-- | :-- | :-- |
| FIXED | 1 | — | 0 |
| PERIODIC | скінченна > 1 | — | 0 |
| MIN\_ZERO | нескінченна | MIN | 0 |
| MIN\_POS | нескінченна | MIN | + |
| NONMIN\_ZERO | нескінченна | NONMIN | 0 |
| NONMIN\_POS | нескінченна | NONMIN | + |

d\_Ω\_traj — відстань Геммінга між цими чотирикомпонентними кортежами. Це метрика на скінченній множині з 12 елементів. DP-f.

### 11.4. Лема про вкладення, D5 і W5

**Лема 11.8 (E).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна **сюр'єктивна**. κ\_c(s) := c, R\_Y := {κ\_c : c ∈ Y}, g∞(κ\_c, s) := κ\_{T(c)}. Тоді:

1. R\_Y ⊆ ℛ₀ компактна, g∞ неперервна, (H) виконано;
2. G := {(c, κ\_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. для x₀ = (c, κ\_{T(c)}): ω(x₀) ↔ ω\_T(c), h\_top(D∞|G) = h\_top(T), Min(G) = Min(T), x₀ ATTAINED ⇔ ∃n: Tⁿ(c) ∈ ω\_T(c).

**DP-f за H.** *Доведення.* d\_ℛ(κ\_c, κ\_{c'}) = d\_S(c, c'), тож R\_Y ізометрична копія Y (компактна), константи 1-ліпшицеві; g∞ не залежить від s і неперервна. G — граф неперервної функції на компакті, тому компактний, і pr₁ — гомеоморфізм G → Y. D∞(c, κ\_{T(c)}) = (κ\_{T(c)}(c), g∞(κ\_{T(c)}, c)) = (T(c), κ\_{T(T(c))}) ∈ G, тож D∞[G] ⊆ G і pr₁∘D∞ = T∘pr₁. Для G ⊆ D∞[G]: кожна точка (d, κ\_{T(d)}) ∈ G дорівнює D∞(c, κ\_{T(c)}) для c з T(c) = d, що існує, бо T сюр'єктивна (не потрібна ін'єктивність). Спряженість зберігає ω-границі, ентропію, мінімальність і досяжність: нехай h : G → Y — гомеоморфізм із h∘D∞ = T∘h. Тоді h[ω(x)] = ω(h x), бо границі підпослідовностей переходять у границі за неперервністю h і h⁻¹. Мінімальність: h має бієктивний образ замкнених інваріантних підмножин. Досяжність: xₙ ∈ ω(x) ⇔ h(xₙ) ∈ ω(h x). Ентропія: h рівномірно неперервний на компакті та такий самий для h⁻¹, тому (n, ε)-роздільні множини переходять у (n, δ)-роздільні й навпаки, а h\_top збігаються. ∎

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {α, β}^ℕ з h\_top(σ|Z) > 0. Посилання: Grillenberger (1973), Jewett (1970), Krieger (1972); для одностороннього зсуву — права половина двостороннього.

**Твердження 11.9 (D5, MIN\_POS × ATTAINED).** За EXT-1: нехай Y := t[Z], T := t∘σ∘t⁻¹. Зсув на мінімальній нескінченній Z сюр'єктивний, тож лема E застосовна. Для будь-якого c ∈ Y точка x₀ = (c, κ\_{T(c)}) має ω(x₀) = G (мінімальна, нескінченна, h\_top > 0) і x₀ ∈ G, отже MIN\_POS × ATTAINED; g∞ ≠ π\_R. Система задовольняє (H). **DP-f за H та EXT-1.**

**Твердження 11.10 (W5, NONMIN\_POS × ATTAINED).** Нехай C := {α, β}^ℕ, σ : C → C — односторонній повний зсув, Y := t[C], T := t ∘ σ ∘ t⁻¹. Виберімо a ∈ C, у якому кожне скінченне слово над {α, β} трапляється нескінченно багато разів, і c := t(a). Для x₀ := (c, κ\_{T(c)}) маємо ω(x₀) = G, x₀ ∈ G, тому ATTAINED; G нескінченна, не мінімальна, h\_top(D∞|G) = log 2 > 0. Отже реалізовано NONMIN\_POS × ATTAINED і CHAOTIC\_set. **DP-f за H.**

*Доведення.*

**(1) Побудова точки з повною ω-границею.** Нехай a ∈ C — послідовність, у якій кожне скінченне слово над алфавітом {α, β} зустрічається нескінченно багато разів. Таку послідовність можна побудувати конкатенацією списків усіх слів довжини не більшої за m, послідовно для m = 1, 2, …

Для будь-якого z ∈ C і кожного N ≥ 1 префікс z довжини N трапляється в a на нескінченно багатьох позиціях. Тому можна вибрати індекси n\_N → ∞, для яких σ^{n\_N}(a) збігається до z. Отже, ω\_σ(a) = C.

За спряженням t → Y та лемою 11.8: ω\_{D∞}(x\_c) = G. Оскільки x\_c ∈ G, траєкторія досягає своєї ω-границі: ATTAINED.

**(2) Нижня оцінка ентропії повного зсуву.** Нехай d\_C(x, y) = 2^{−k} (k — перший індекс розбіжності), d\_C(x, x) := 0. Метрика Боуена: d\_n(x, y) = max\_{0 ≤ i < n} d\_C(σⁱx, σⁱy).

Виберімо по одному представнику кожного з 2ⁿ префіксів довжини n. Два різні представники розходяться на деякій координаті k < n, отже після зсуву σᵏ їхня відстань дорівнює 1. Ця множина є (n, 3/4)-розділеною, тому s(n, 3/4) ≥ 2ⁿ.

Якщо дві послідовності мають однаковий префікс довжини n, то після кожного зсуву σⁱ (0 ≤ i < n) вони збігаються принаймні за першою координатою. Тому d\_n(x, y) ≤ 1/2 < 3/4. Отже s(n, 3/4) ≤ 2ⁿ.

Таким чином, s(n, 3/4) = 2ⁿ, і h\_top(σ) ≥ log 2.

**(3) Верхня оцінка ентропії.** Нехай ε > 0. Виберімо L ≥ 0 так, щоб 2^{−(L+1)} < ε. Якщо дві послідовності мають однаковий префікс довжини n + L, то після кожного зсуву σⁱ (0 ≤ i < n) вони збігаються щонайменше за першими L + 1 координатами. Тому d\_n(x, y) ≤ 2^{−(L+1)} < ε.

Отже, у (n, ε)-розділеній множині не може бути двох послідовностей з однаковим префіксом довжини n + L. Тому s(n, ε) ≤ 2^{n+L}. Для фіксованого ε величина L стала, тож

```text
limsup_{n→∞} (1/n) log s(n, ε) ≤ log 2.
```

Переходячи до ε → 0⁺, одержуємо h\_top(σ) ≤ log 2. Разом із нижньою оцінкою: h\_top(σ) = log 2.

**(4) Перенесення на SUBIT.** За лемою 11.8 система D∞|G спряжена з σ → C, отже h\_top(D∞|G) = log 2 > 0. Множина G нескінченна й не мінімальна: вона містить нерухому точку, що відповідає α^∞, але не є одноточковою множиною.

Таким чином, реалізовано `NONMIN_POS × ATTAINED` і `CHAOTIC_set`. ∎

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення).** Нехай (X, d) — непорожній повний метричний простір, Φ : X → X, d(Φ(x), Φ(y)) ≤ q·d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x\*, і Φⁿ(x₀) → x\* для кожного x₀. **DP-f.**

*Доведення.* Нехай x\_n = Φⁿ(x₀). d(x\_{n+1}, x\_n) ≤ qⁿ d(x₁, x₀). Для m > n: d(x\_m, x\_n) ≤ ∑\_{k=n}^{m−1} d(x\_{k+1}, x\_k) ≤ qⁿ / (1 − q) · d(x₁, x₀). Отже (x\_n) — Коші; за повнотою X існує x\* = lim x\_n. Неперервність Φ дає Φ(x\*) = x\*. Якщо y\* — інша нерухома, d(x\*, y\*) = d(Φ(x\*), Φ(y\*)) ≤ q·d(x\*, y\*), звідки x\* = y\*. ∎

**Прищеплення.** Для a ∈ A: ρ\_a(f) := node(f, leaf(a), leaf(a)). ρ\_a ін'єктивне, r\_addr(ρ\_a f, ρ\_a g) = r\_addr(f, g) + 1, тож ρ\_a ∈ ℛ₀ і стискаюче з коефіцієнтом ½.

- **W1 (FIXED × ATTAINED).** R = {ρ\_a}, g∞ = π\_R, x₀ = (p\_a, ρ\_a). **DP-f за H.** ∎
- **W2 (FIXED × NONATTAINED).** s ≠ p\_a, x₀ = (s, ρ\_a). x\_n → (p\_a, ρ\_a); ω = {(p\_a, ρ\_a)}. Потрапило б на кроці n лише при s = p\_a. **DP-f за H.** ∎
- **W3 (PERIODIC, обидва).** R = {ρ\_a, ρ\_b}, g∞(ρ\_a, s) = ρ\_b, g∞(ρ\_b, s) = ρ\_a. Φ := ρ\_b∘ρ\_a стискаюче з коефіцієнтом ¼, єдина нерухома точка q. Цикл {z₀, z₁} довжини 2. ATTAINED: старт на циклі. NONATTAINED: s ≠ q; на циклі опинились б лише при Φᵏ s = q ⇒ s = q. **DP-f за H.** ∎
- **W4 (MIN\_ZERO × ATTAINED; одометр).** Нехай B := {0, 1}^ℕ, C := {α, β}^ℕ (α ≠ β ∈ A). Визначимо O : B → B як додавання 1 у двійковому записі з переносом від координати 0 праворуч. Нехай **enc_αβ : B → C** — координатна бієкція: enc\_αβ(a)\_i = α при a\_i = 0, β при a\_i = 1. Визначимо **Õ := enc\_αβ ∘ O ∘ enc\_αβ⁻¹ : C → C** (не Y → Y!). Нехай t : C → S∞ — вкладення §9.5, Y := t[C], і **T := t ∘ Õ ∘ t⁻¹ : Y → Y**. Тоді t ∘ enc\_αβ : B → Y — гомеоморфізм, що спряжує O і T.

**Ізометричність O.** 2-адичне число A = Σ a\_i 2^i. Якщо a ≠ b, k — перший індекс розбіжності, то A ≡ B (mod 2ᵏ), але A ≢ B (mod 2ᵏ⁺¹). Додавання 1 не змінює різниці A − B, тому перша розбіжність O(a), O(b) залишається на координаті k.

**Мінімальність O.** Перші n координат Oᵐ(a) відповідають (N\_n(a) + m) mod 2ⁿ. При m = 0, …, 2ⁿ−1 отримуємо всі 2ⁿ префіксів. Тому кожна орбіта щільна в B; непорожня замкнена Q з O[Q] ⊆ Q містить повну щільну орбіту, отже Q = B.

**Відсутність періодичних точок.** Oᵖ(a) = a ⇒ p ≡ 0 (mod 2ⁿ) для всіх n — неможливо.

**Завершення.** За координатним кодуванням T на Y є ізометрією відносно d\_S. За D3 h\_top(T) = 0. За лемою E h\_top(D∞|G) = h\_top(T) = 0; лема E також переносить мінімальність і відсутність періодичних точок. Отже G — нескінченна мінімальна ω-границя з нульовою ентропією. Для x\_c ∈ G: ω(x\_c) = G, x\_c ∈ G. Отже MIN\_ZERO × ATTAINED. **DP-f за H.** ∎
