## 1. Алфавіт і простір S₀

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, 4 елементи.

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. Властивості білаттису не переносяться на динаміку S∞ без окремого означення. ВИЗНАЧЕНО.

**Означення 1.2 (A2).** S₀ = A × A × A, 64 стани. Стан із бітами b₁…b₆ має код

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3).** code6 — бієкція S₀ → {0, …, 63}. DP-f. *Доведення.* Кожен елемент S₀ — слово з шести бітів; code6 — його двійковий запис; двійковий запис однозначний; слів 2⁶ = 64. ∎

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = 63; 010001 = YOU/NORTH/AUTUMN = 17. Гексаграмний запис (Додаток А) — лише індексація.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ) із S₀ × `ℛ_fin`. Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`, динаміка

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори, помилки й ресурсні переривання — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО (перечитання означення). Сильніша теза про самореферентну перевагу — ВІДКРИТО.

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ) із **непорожнім** Q, #Q ≤ 64, тотальною δ : Q → Q і **без вхідного алфавіту** вкладається в SUBIT⁺. DP-f.

*Доведення.*

1. Оскільки Q ≠ ∅ і #Q ≤ 64, є ін'єкція ι : Q → S₀. Поза образом ι(Q) фіксуємо довільне s₀ ∈ S₀.
2. Означимо ρ : S₀ → S₀: ρ(ι(q)) := ι(δ(q)) для q ∈ Q; ρ(s) := s₀ для s поза ι(Q).
3. Візьмемо `ℛ_fin` = {ρ} і g₀(ρ, s) := ρ. Тоді D₀(s, ρ) = (ρ(s), ρ).
4. Індукція за n: якщо початковий стан (ι(q₀), ρ), то n-й стан — (ι(δⁿ(q₀)), ρ). Крок: ρ(ι(δⁿ(q₀))) = ι(δⁿ⁺¹(q₀)). ∎

**Область.** Твердження стосується автономних систем із непорожнім Q, одним тотальним переходом. Воно не стверджує універсальної симуляції DFA з вхідним алфавітом, симуляції автоматів із #Q > 64 чи універсальності SUBIT⁺ як λ-інтерпретатора.

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** У Q₀ для кожного ŝ число m(ŝ) скінченне. DP-f. *Доведення.* Стани ŝ, D₀(ŝ), …, D₀^N(ŝ) при N = #Q₀ — це N + 1 елемент множини з N елементів; Діріхле дає повторення. ∎

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f.

**Твердження 3.1.3 (P3, точний режим).** Алгоритм першого повтору завжди завершується з COMPUTED; m, p збігаються з означенням 3.1; гілка `RESOURCE_EXCEEDED` недосяжна. DP-f.

**Твердження 3.1.4 (P3′, бюджетований режим).** Якщо ліміт N_max < #Q₀, гілка `RESOURCE_EXCEEDED` досяжна для деяких систем; результат **не є класифікацією**. DP-f.

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H) (§10.2). Для ŝ ∈ S∞ × R:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. DP-f.

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. Два приклади: Q₀ = S₀ × `ℛ_fin` з дискретною метрикою; X = S∞ × R з d̂ і D∞ за (H). P ⊆ K — **непорожня**, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f.

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна; (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне.

Топологічна ентропія `h_top(D|P)` — через (n, ε)-роздільні множини в метриці dₙ(x, y) = max_{i<n} d(Dⁱx, Dⁱy); `h_top = lim_{ε→0} limsup_n (1/n) log s(n, ε)`.

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** `NOT_APPLICABLE` ≠ `NON_CHAOTIC`.

**Застереження 4.3.3.** У v6.9.3 CHAOTIC вимагав мінімальності; тепер хаотичність = h_top > 0, а мінімальність — окрема ознака Min. Комбінація «мінімальна і хаотична» — `MIN_POS` (§11).

### 4.4. Одне значення CHAOTIC

`IsChaotic_D(P)` :⇔ `ChaosStatus_D(P) = CHAOTIC`; `CHAOTIC_ω(τ)` :⇔ `IsChaotic_D(ω(τ))`. `CHAOTIC_set` — лише назва нижнього елемента Ω.

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL_IMAGE ⇔ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. DP-f.

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f.

**Твердження 4.5.3 (C4).** (C4a) скінченна P + D[P] = P ⇒ D|ₚ — бієкція і кожна точка періодична. DP-f. (C4b) для нескінченної P бієктивність не тягне періодичності всіх точок (одометр, §11.6). DP-f. (C4c) для нескінченної P сюр'єктивність не тягне ін'єктивності (односторонній зсув σ на {0,1}^ℕ). DP-f.

## 5. Алгебра Ω і проєкція π_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D_class).** D_class := { Classify⁺_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }.

**Означення 5.3 (π_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. DP-f.

**Твердження 5.5 (C5b, сюр'єктивність).** Образ π_Ω у D_class складається з усіх шести елементів Ω. DP-f. *Свідки.* INVARIANT_FIXED: P = {p}. INVARIANT_DYNAMIC: 2-цикл. PERIODIC_SET: P = {a, c} у 4-циклі. EVENTUALLY_PERIODIC: P = {x₀} на x₀ → x₁ → x₂ → x₁. APERIODIC_NON_CHAOTIC: K = {0,1}^ℕ, D = σ, a_n = 1 ⇔ n степінь двійки, P = {σⁿ(a)}; P не замкнена (σ^(2ᵐ+1)(a) → 0^∞ ∉ P); (Π1)–(Π2) не виконуються, ChaosStatus = NOT_APPLICABLE. CHAOTIC_set: множина G з W5 (§11.10). ∎

**Зауваження 5.6 (`APERIODIC_NON_CHAOTIC` — втратна мітка).** Якщо μ(P) = ∞, то D[P] ≠ P, тож (Π2) не виконується й ChaosStatus = NOT_APPLICABLE. Поєднання «OrbitType = APERIODIC і ChaosStatus = NON_CHAOTIC» за означеннями неможливе. Елемент ланцюга Ω — мітка образу π_Ω, не твердження про NON_CHAOTIC.

**Застереження 5.6.1.** Для фіксованої скінченної системи образ π_Ω не може містити `CHAOTIC_set` (C7).

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥.

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f.

**Застереження 5.9.** π_Ω втратна (відкидає InclusionType і Min, а також різницю NOT_APPLICABLE / NON_CHAOTIC).

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

Для довільної динамічної системи (K, D), x ∈ K, U ⊆ K; `¬U := K ∖ U` — класичне доповнення, не тотожне `¬_H` з §6.2.

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`F_tree` — виключно функтор `X ↦ A ⊔ X³`; динаміка позначається буквою D.

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. DP-f.


## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g): S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. D_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ_S, φ_ℛ) з умовою φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s)).

**Означення 7.3 (SUBIT_full).** Широка підкатегорія; морфізми додатково: φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s)).

**Твердження 7.4 (K1).** SUBIT і SUBIT_full — категорії. DP-f.

**Твердження 7.5 (K2).** 1 = ({∗}, {id}, g_triv) — термінальний об'єкт. DP-f.

**Твердження 7.6 (K3, добуток).** Для X, Y:

```text
(ρ ⊠ σ)(x, y) := (ρ(x), σ(y))
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
```

— добуток у SUBIT і у SUBIT_full. DP-f.

**Застереження 7.7.** Якщо категорія має допускати порожні S, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X`. **Відкрито:** Q1, Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — φ ∘ f = h ∘ φ. Dyn₊ — повна підкатегорія з непорожніми S.

**Твердження 8.2 (K4, топос).** Dyn ≅ Fun(Bℕ, Set), де Bℕ — категорія з одним об'єктом і моноїдом ендоморфізмів (ℕ, +, 0). Це прешейфовий топос, тому Dyn — топос (DP-s).

**Примітка 8.2.1.** У конвенції, де presheaf category на C означає Fun(C^op, Set), `Fun(Bℕ, Set) = Fun((Bℕ)^op, Set)`, оскільки Bℕ^op ≅ Bℕ. Тому Dyn — топос незалежно від конвенції.

**Означення 8.3 (час входу).** Для підоб'єкта U ⊆ S (f[U] ⊆ U): χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U } (∞, якщо ніколи).

**Твердження 8.4 (χ_U).** (a) χ_U(f(x)) = max(χ_U(x) − 1, 0); (b) U ↦ χ_U — бієкція між підоб'єктами та морфізмами (S, f) → Ω_Dyn, обернена U = χ⁻¹(0). DP-f.

**Застереження 8.5.** Для неінваріантної U формула χ_U не еквіваріантна.

**Твердження 8.6 (K5, вкладення).** E : Dyn₊ → SUBIT, (S, f) ↦ (S, {f}, g_f), g_f(f, s) := f — повний і вірний; аналогічно в SUBIT_full. DP-f.

**Застереження 8.7.** Вкладення всієї Dyn неможливе без перегляду типу правил (S = ∅). Топосна структура Dyn не переноситься на SUBIT.

## 9. Простір S∞ = Tree∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, Λ := {None, node} ∪ {leaf(a) : a ∈ A}. Tree∞ — множина f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None.

S∞ := Tree∞. Піддерево для f(ε) = node: f_i(σ) := f(i·σ); для f(ε) = leaf(a) не визначене.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree∞ — фінальна коалгебра `F_tree(X) = A ⊔ X³`. DP-s.

**Твердження 9.3 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S∞. DP-f.

### 9.2. Допоміжна конструкція: Ψ і L_prod

```text
T_0     := { Leaf_0(a) } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) } ∪ { Bottom_{n+1} } ∪ { Node_n(t₁, t₂, t₃) : tᵢ ∈ T_n }
q_0 : T_1 → T_0:   Leaf_1 a ↦ Leaf_0 a,  Bottom_1 ↦ Bottom_0,  Node_0(…) ↦ Bottom_0
q_{n+1} : T_{n+2} → T_{n+1}:  Leaf ↦ Leaf,  Bottom ↦ Bottom,
                              Node_{n+1}(t₁,t₂,t₃) ↦ Node_n(q_n t₁, q_n t₂, q_n t₃)
U_c := { (t_n) ∈ ∏ T_n : q_n(t_{n+1}) = t_n }
LeafSeqs := { (Leaf_n(a))_n }
NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0, ∃u₁,u₂,u₃ ∈ X: t_{n+1} = Node_n(u₁_n, u₂_n, u₃_n) }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X);     L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.4.** L_prod = Ψ(L_prod). DP-f.

**Зауваження 9.5.** U_c строго більша за L_prod: (Bottom_n)ₙ ∈ U_c ∖ L_prod.

### 9.3. d_n, at_n, lim_tree

```text
d_0(f) := Leaf_0(a) якщо f(ε) = leaf(a);   Bottom_0 якщо f(ε) = node
d_{n+1}(f) := Leaf_{n+1}(a)                       якщо f(ε) = leaf(a)
d_{n+1}(f) := Node_n(d_n f₁, d_n f₂, d_n f₃)      якщо f(ε) = node

TΣ := Σ_k T_k;    at_n : T_n → Pos → Option(TΣ)
at_n(t, ε) := Some((n, t));            at_0(t, i·τ) := None
at_{n+1}(Leaf, i·τ) := None;          at_{n+1}(Bottom, i·τ) := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ) := at_n(u_i, τ)
```

**Лема 9.6 (типізація).** d_n(f) ∈ T_n, q_n(d_{n+1} f) = d_n f; якщо at_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T_k. DP-f.

**Означення 9.7 (lim_tree).** Для t ∈ L_prod і σ ∈ Pos, m > |σ| розглядаємо at_m(t_m, σ). При m → ∞ стабілізується **коренева форма**:

- (Z) для всіх достатньо великих m: at_m(t_m, σ) = None;
- (L) для всіх достатньо великих m: кореневий конструктор Leaf із сталою міткою a;
- (N) для всіх достатньо великих m: кореневий конструктор Node.

Індекс глибини (m − |σ|) і скінченний опис піддерева у випадку Node можуть змінюватися з m; стабілізується лише коренева форма. Тоді:

```text
lim_tree(t)(σ) := None, leaf(a), node відповідно до Z, L, N
```

**Твердження 9.8 (реконструкція).** (a) lim_tree(t) ∈ Tree∞; (b) p(f) := (d_n f)ₙ ∈ L_prod і lim_tree(p(f)) = f; (c) p(lim_tree(t)) = t. p : Tree∞ → L_prod — бієкція. DP-s.

### 9.4. Метрика d_S

```text
r_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) }   (∞, якщо f = g)
d_S(f, g)    := 2^{− r_addr(f, g)}            (0, якщо f = g)
r_app(f, g)  := min{ n ≥ 0 : d_n f ≠ d_n g }
```

**Лема 9.9.** r_app = r_addr. DP-s.

**Твердження 9.10 (T3).** d_S — ультраметрика. DP-f.

**Твердження 9.11 (T4).** Якщо f(ε) = g(ε) = node, то d_S(f_i, g_i) ≤ 2·d_S(f, g). DP-f.

**Твердження 9.12 (T5).** (Tree∞, d_S) — компактний, повний, цілком обмежений. **DP-s.**

*Доведення.* Λ^Pos із добутковою топологією — компакт; кожна з (T1)–(T4) замкнена; Tree∞ замкнена в компакті, тому компактна. Куля {g : r_addr(f, g) > r} збігається з циліндром, тому d_S метризує топологію. Компактна метрична → повна й цілком обмежена. ∎

**Примітка про статус доказу (P-04).** Доведення використовує стандартну компактність зліченного добутку скінченних компактних просторів і стандартний факт, що компактний метричний простір є повним і цілком обмеженим. Оскільки повний доказ цих загальних результатів у тексті не наведено, T5 позначено DP-s відповідно до §0.2. Це зміна статусу доказу, а не зміна математичного твердження.

**Твердження 9.13 (адресний доступ).** Для f ∈ Tree∞, σ ∈ Pos, n > |σ|: f(σ) = leaf(a) ⇒ at_n(d_n f, σ) = Some((n − |σ|, Leaf(a))); f(σ) = node ⇒ корінь at_n(d_n f, σ) — Node; f(σ) = None ⇒ at_n(d_n f, σ) = None. DP-s.

### 9.5. «Хребет» і простір Y

Фіксуємо літери α ≠ β та η з A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ:

```text
t(a)(1ᵏ) := node,    t(a)(1ᵏ·2) := leaf(a_k),    t(a)(1ᵏ·3) := leaf(η)
```

Інші позиції — за (T2)–(T4).

**Твердження 9.14.** t : {α, β}^ℕ → S∞ неперервне й ін'єктивне; d_S(t(a), t(b)) = 2^{−(k+1)}, де k — перший індекс розбіжності. Y := t({α, β}^ℕ) — канторів простір, замкнений в S∞. Зсув σ на {α, β}^ℕ спряжений до T := t ∘ σ ∘ t⁻¹. DP-f.

**Зауваження 9.15.** S∞ — нульвимірний компакт; скінченні дерева — ізольовані точки. Множина нескінченних дерев — замкнена й досконала. Y — досконала підмножина, гомеоморфна канторовому простору, але не вся: повне потрійне дерево (node на всіх адресах) нескінченне, проте не лежить у Y, бо в деревах із Y адреса 2 — листок.

### 11.4. Лема про вкладення і D5

**Лема 11.8 (E).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна **сюр'єктивна**. κ_c(s) := c, R_Y := {κ_c}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна (H виконано);
2. G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. ω(x₀) ↔ ω_T(c), h_top(D∞|G) = h_top(T), Min(G) = Min(T), x₀ ATTAINED ⇔ ∃n: Tⁿ(c) ∈ ω_T(c).

DP-f.

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {α, β}^ℕ з h_top(σ|Z) > 0.

Бібліографічний орієнтир: C. Grillenberger, "Construction of strictly ergodic systems I. Given entropy", *Zeitschrift für Wahrscheinlichkeitstheorie und verwandte Gebiete*, 25 (1973), 323–334. Додаткове джерело: E. Glasner and B. Weiss, "Strictly ergodic, uniform positive entropy models", *Bulletin de la Société Mathématique de France*, 122(3) (1994), 399–412, DOI: 10.24033/bsmf.2239.

**Застереження про точну форму EXT-1 (P-06).** Бібліографічний запис про існування строго ергодичних систем із додатною ентропією сам собою ще не замінює аргументу для саме одностороннього двійкового підзсуву Z. У фінальній публікації потрібно або навести точне джерело цього твердження, або додати доведення переходу до зазначеної символічної моделі. До цього EXT-1 залишається окремою зовнішньою передумовою, а D5 має статус DP-f за EXT-1, не безумовний DP-f.

**Твердження 11.9 (D5, MIN_POS × ATTAINED).** За EXT-1: Y := t[Z], T := t∘σ∘t⁻¹. Для будь-якого c ∈ Y точка x₀ = (c, κ_{T(c)}) має ω(x₀) = G (мінімальна, нескінченна, h_top > 0) і x₀ ∈ G, отже MIN_POS × ATTAINED; g∞ ≠ π_R. Система задовольняє (H). DP-f за EXT-1.

**Твердження 11.10 (W5, NONMIN_POS × ATTAINED).** Нехай Y := t[{α, β}^ℕ], T := t ∘ σ ∘ t⁻¹, де σ — односторонній повний зсув на двох символах. Виберімо c = t(a), де кожне скінченне слово над {α, β} трапляється в a нескінченно багато разів. Для x₀ = (c, κ_{T(c)}) маємо ω(x₀) = G, x₀ ∈ G, отже ATTAINED; G ≅ повний двійковий зсув, h_top = log 2 > 0, G не мінімальна (містить нерухому точку α^∞). Тому реалізовано NONMIN_POS × ATTAINED і CHAOTIC_set. **DP-f.**

*Доведення (P-01).* Кожна точка z повного зсуву — гранична точка орбіти a: для кожного N префікс z довжини N зустрічається в a на нескінченно багатьох позиціях; відповідні зсуви збігаються до z. Отже ω_σ(a) = {α, β}^ℕ.

Обчислимо топологічну ентропію повного зсуву в метриці d(x, y) = 2⁻ᵏ (k — індекс першої розбіжності; d(x, x) = 0). Нехай dₙ(x, y) = max_{0 ≤ i < n} d(σⁱx, σⁱy).

**Нижня оцінка.** Для ε = ¾ представники всіх 2ⁿ різних префіксів довжини n утворюють (n, ε)-розділену множину: дві різні послідовності розходяться в одній із перших n координат, тому після відповідного зсуву їхня відстань дорівнює 1. Дві послідовності з однаковим префіксом довжини n мають dₙ ≤ ½. Тому s(n, ¾) = 2ⁿ, звідки h_top(σ) ≥ log 2.

**Верхня оцінка.** Для довільного ε > 0 виберімо ціле L ≥ 0 так, щоб 2^{−(L+1)} < ε. Якщо дві послідовності мають однакові перші n + L символів, то після кожного зсуву σⁱ, 0 ≤ i < n, вони збігаються щонайменше на перших L + 1 символах. Отже dₙ(x, y) ≤ 2^{−(L+1)} < ε.

Тому в кожній (n, ε)-розділеній множині може бути не більше одного представника для кожного префікса довжини n + L. Звідси s(n, ε) ≤ 2^{n+L}. Отже

```text
limsup_{n→∞} (1/n) log s(n, ε) ≤ log 2
```

(бо L фіксоване для обраного ε, і L log 2 / n → 0). Переходячи до границі ε → 0, одержуємо h_top(σ) ≤ log 2. Разом із нижньою оцінкою це дає h_top(σ) = log 2.

За лемою 11.8 ентропія зберігається при топологічному спряженні, тому h_top(D∞|G) = log 2. Множина G нескінченна й не мінімальна, оскільки містить нерухому точку α^∞, але не збігається з нею. Нарешті, x₀ ∈ G = ω(x₀), тому ATTAINED. ∎

**Наслідок.** W5 залишається DP-f за наведеним доказом; залежність від EXT-1 не потрібна. Через W5 доступний свідок CHAOTIC_set у C5b.

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення).** Нехай (X, d) — непорожній повний метричний простір, Φ : X → X задовольняє d(Φx, Φy) ≤ q · d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x*, і Φⁿ(x₀) → x*. DP-f.

**Прищеплення.** Для a ∈ A: ρ_a(f) := node(f, leaf(a), leaf(a)). ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, тож ρ_a ∈ ℛ₀ і стискаюче з коефіцієнтом ½.

- **W1 (FIXED × ATTAINED).** R = {ρ_a}, g∞ = π_R, x₀ = (p_a, ρ_a), де p_a — єдина нерухома точка ρ_a. DP-f.
- **W2 (FIXED × NONATTAINED).** x₀ = (s, ρ_a), s ≠ p_a. x_n → (p_a, ρ_a); ω = {(p_a, ρ_a)}. Потрапило б на кроці n лише при s = p_a. DP-f.
- **W3 (PERIODIC, обидва).** R = {ρ_a, ρ_b}, g∞(ρ_a, s) = ρ_b, g∞(ρ_b, s) = ρ_a. Φ := ρ_b∘ρ_a стискаюче з коефіцієнтом ¼, єдина нерухома точка q. Цикл {(q, ρ_a), (ρ_a q, ρ_b)}. ATTAINED: старт на циклі. NONATTAINED: s ≠ q, на циклі опинились б лише при Φᵏ s = q ⇒ s = q. DP-f.

- **W4 (MIN_ZERO × ATTAINED; одометр) — P-02.** Нехай B := {0, 1}^ℕ. Для a ≠ b: k(a, b) := min{i ≥ 0 : aᵢ ≠ bᵢ}, d_B(a, b) := 2⁻ᵏ⁽ᵃ,ᵇ⁾; d_B(a, a) := 0. Визначимо O : B → B як додавання 1 у двійковому записі з переносом від координати 0 праворуч.

Виберімо різні α, β ∈ A і координатне відображення e : B → {α, β}^ℕ, де e(a)ᵢ = α при aᵢ = 0 та e(a)ᵢ = β при aᵢ = 1. Це бієкція, що зберігає метрику першої розбіжності.

Нехай Y := t[{α, β}^ℕ], Õ := e ∘ O ∘ e⁻¹ : Y → Y, T := t ∘ Õ ∘ t⁻¹. За §9.5 d_S(t(e(a)), t(e(b))) = ½ d_B(a, b). Отже O — ізометрія, а T — ізометрія Y.

**Властивості O.** Ізометрія: якщо два слова збігаються на координатах 0, …, k − 1 і різняться на координаті k, то переноси до координати k однакові, тому після додавання 1 слова й далі збігаються на координатах нижче k та різняться на k. Мінімальність: за будь-якими першими n координатами орбіта a проходить усі 2ⁿ можливих префіксів, оскільки значення префікса змінюється за модулем 2ⁿ; отже орбіта щільна. Кожна непорожня замкнена додатно-інваріантна множина містить повну щільну орбіту, тому збігається з B. Періодичних точок немає: якби Oᵖ(a) = a, то p ≡ 0 (mod 2ⁿ) для кожного n — неможливо для фіксованого додатного p.

Застосуємо лему 11.8 до Y і T. Одержуємо компактну інваріантну множину G, спряжену з одометром. Вона мінімальна, нескінченна, не має періодичних точок і має h_top = 0 за D3, оскільки T — ізометрія. Для будь-якого x₀ ∈ G маємо ω(x₀) = G та x₀ ∈ G. Отже реалізовано MIN_ZERO × ATTAINED. Це також контрприклад C4b. **DP-f.**
