## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ). Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`.

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна.

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО.

**Твердження 2.4 (A4, P-46).** Кожний автономний скінченний автомат (Q, δ) із непорожнім Q, #Q ≤ 64, тотальною δ : Q → Q і без вхідного алфавіту вкладається в SUBIT⁺. **DP-f.**

*Доведення.* Нехай (Q, δ) — скінченний непорожній автомат з |Q| ≤ 64. Виберемо ін'єкцію i : Q ↪ S₀. Побудуємо функцію ρ : S₀ → S₀, задавши ρ(i(q)) = i(δ(q)) для всіх q ∈ Q, а на решті S₀ продовживши її довільно (наприклад, константою s₀).

Покладемо `ℛ_fin` = {ρ} і g₀(ρ, s) = ρ. Тоді вкладення e(q) = (i(q), ρ) задовольняє

```text
D₀(e(q)) = (ρ(i(q)), ρ) = (i(δ(q)), ρ) = e(δ(q)).
```

Отже e ін'єктивне та зберігає перехід автомата. Образ e[Q] є інваріантною підсистемою SUBIT⁺, ізоморфною (Q, δ). ∎

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** Для кожного ŝ ∈ Q₀: m(ŝ) < ∞. DP-f (Діріхле).

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f.

**Твердження 3.1.3 (P3, точний режим; P-44).** Нехай N := #Q₀. Алгоритм першого повтору:

```text
вхід: s₀ ∈ Q₀
visited : Map<State, ℕ> := ∅
states  : Array<State> := []
s := s₀

для n := 0, …, N:
    якщо s ∈ visited:
        m := visited[s]
        p := n − m
        cycle := states[m:n]
        повернути COMPUTED(class(m, p), m, p, cycle)

    visited[s] := n
    states.append(s)

    якщо n < N:
        s := D₀(s)
```

Завжди завершується з `COMPUTED`; повернені m і p збігаються з означеннями §3.1. Сегмент `states[m:n]` містить саме стани s_m, …, s_{n−1}. **DP-f.**

*Доведення.* Множина Q₀ містить N станів, а алгоритм перевіряє послідовно N + 1 станів s₀, …, s_N. За Діріхле принаймні один повториться. Алгоритм повертає результат при першому повторі; індекс попередньої появи m — початок циклу; p = n − m — його довжина. Якби існував раніший початок циклу або коротший період, повтор знайшовся б раніше. На кроці N повтор уже гарантований, тому неповернення результату недосяжне. ∎

**Твердження 3.1.4 (P3′, бюджетований режим; P-44).**

```text
вхід: s₀ ∈ Q₀, N_max ∈ ℕ
visited : Map<State, ℕ> := ∅
states  : Array<State> := []
s := s₀

для n := 0, …, N_max:
    якщо s ∈ visited:
        m := visited[s]
        p := n − m
        cycle := states[m:n]
        повернути COMPUTED(class(m, p), m, p, cycle)

    visited[s] := n
    states.append(s)

    якщо n = N_max:
        повернути RESOURCE_EXCEEDED

    s := D₀(s)
```

Повтор перевіряється до перевірки вичерпання бюджету. **DP-f.**

*Доведення.* Якщо повтор знайдено на кроці n ≤ N_max, результат коректний за P3. Якщо повтор не знайдено до кроку N_max, усі переглянуті стани різні, але цього недостатньо для повної класифікації, тому результат — `RESOURCE_EXCEEDED`. Гілка досяжна, наприклад, для 64-циклу при N_max = 63. ∎

*Уточнення.* Недостатній горизонт не означає, що `RESOURCE_EXCEEDED` виникне для кожної системи: повтор може знайтися раніше.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. P ⊆ K — непорожня, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f.

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна; (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне.

**Означення 4.3.0 (топологічна ентропія).** Метрика Боуена d_n(x, y) := max_{0 ≤ i < n} d(Dⁱx, Dⁱy), n ≥ 1. E ⊆ P є **(n, ε)-розділеною**, якщо для різних x, y ∈ E: d_n(x, y) > ε. s(n, ε) — максимальна потужність такої множини.

```text
h_top(D) := lim_{ε→0⁺} limsup_{n→∞} (1/n) log s(n, ε).
```

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** NOT_APPLICABLE ≠ NON_CHAOTIC.

**Застереження 4.3.3.** Хаотичність = h_top > 0; мінімальність — окрема ознака Min.

### 4.4. Одне значення CHAOTIC

IsChaotic_D(P) :⇔ ChaosStatus_D(P) = CHAOTIC; CHAOTIC_ω(τ) :⇔ IsChaotic_D(ω(τ)). CHAOTIC_set — лише назва нижнього елемента Ω.

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** Залежності складових. DP-f.

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f.

**Твердження 4.5.3 (C4).** (C4a) скінченна P: D|P — бієкція, кожна точка періодична. DP-f. (C4b) нескінченна P: бієктивність ⇏ періодичність (одометр W4). DP-f. (C4c) нескінченна P: сюр'єктивність ⇏ ін'єктивність (односторонній зсув σ на {0,1}^ℕ). DP-f.

## 5. Алгебра Ω і проєкція π_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D_class).** D_class := { Classify⁺_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }.

**Означення 5.3 (π_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. DP-f.

**Твердження 5.5 (C5b).** Образ π_Ω у D_class складається з усіх шести елементів Ω. DP-f.

*Свідки.*

- INVARIANT_FIXED: K = {p}, D(p) = p, P = {p}. Classify⁺ = (INVARIANT_FIXED, EQUAL_IMAGE, NON_CHAOTIC, MINIMAL). π_Ω = INVARIANT_FIXED.
- INVARIANT_DYNAMIC: K = {x, y}, D(x) = y, D(y) = x, P = {x, y}. OrbitType = INVARIANT_DYNAMIC. π_Ω = INVARIANT_DYNAMIC.
- PERIODIC_SET: K = {a, b, c, d}, D — 4-цикл, P = {a, c}. D[P] = {b, d} ≠ P; D²[P] = {a, c} = P; p_set = 2. π_Ω = PERIODIC_SET.
- EVENTUALLY_PERIODIC: K = {x₀, x₁, x₂}, D(x₀) = x₁, D(x₁) = x₂, D(x₂) = x₁, P = {x₀}. D[P] = {x₁}, μ = 1, π = 2. π_Ω = EVENTUALLY_PERIODIC.
- APERIODIC_NON_CHAOTIC: K = {0,1}^ℕ, D = σ, a_n = 1 ⇔ n степінь двійки, P = {σⁿ(a) : n ≥ 0}. μ(P) = ∞ (попарна різність зсувів). P не замкнена (σ^{2ᵏ+1}(a) → 0^∞ ∉ P), тому Π1 не виконано; ChaosStatus = NOT_APPLICABLE. π_Ω повертає APERIODIC_NON_CHAOTIC.
- CHAOTIC_set: множина G з W5 (§11.4). π_Ω = CHAOTIC_set.

**Зауваження 5.6.** APERIODIC_NON_CHAOTIC — втратна мітка: якщо μ(P) = ∞, то D[P] ≠ P, (Π2) не виконано, ChaosStatus = NOT_APPLICABLE. Тому поєднання «OrbitType = APERIODIC і ChaosStatus = NON_CHAOTIC» за означеннями неможливе.

**Застереження 5.6.1.** Для скінченної системи образ π_Ω не містить CHAOTIC_set.

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥.

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f.

**Застереження 5.9.** π_Ω втратна.

### 11.1. ω-границя і класи S(τ)

**Твердження 11.1 (D1).** ω(τ) непорожня, компактна і D∞[ω(τ)] = ω(τ). DP-f.

**Лема 11.0 (скінченна ω — один цикл; P-45).** Нехай ω := ω(τ) — непорожня скінченна ω-границя. Тоді D|ω — перестановка, і ω складається з одного циклу. **DP-f.**

*Доведення.* За D1 маємо D∞[ω] = ω. Обмеження D∞|ω є сюр'єкцією скінченної множини на себе, отже перестановкою.

Якщо |ω| = 1, єдина точка ω-границі нерухома, і твердження доведено.

Нехай тепер |ω| > 1, а δ := min{ d(x, y) : x, y ∈ ω, x ≠ y } > 0. За неперервністю D∞ можна вибрати η > 0, де η < δ/3, таке, що для кожного w ∈ ω:

```text
d(x, w) < η ⇒ d(D∞x, D∞w) < δ/3.
```

Відстань від x_n = D∞ⁿ(x₀) до ω прямує до нуля. Тому для всіх достатньо великих n існує єдина w_n ∈ ω з d(x_n, w_n) < η. Тоді d(w_{n+1}, D∞(w_n)) < η + δ/3 < δ. Оскільки обидві точки належать ω, за означенням δ вони рівні: w_{n+1} = D∞(w_n). Отже, послідовність w_n з деякого моменту рухається по одному циклу перестановки D∞|ω.

Оскільки d(x_n, w_n) → 0, множина граничних точок орбіти збігається з множиною точок цього циклу. За означенням це вся ω. Таким чином ω-границя складається рівно з одного циклу. ∎

**Означення 11.2 (Att).** ATTAINED ⇔ ∃n: x_n ∈ ω(τ). NONATTAINED := ¬ATTAINED.

### 11.4. Лема про вкладення, D5, W5

**Лема 11.8 (E; P-43).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна сюр'єктивна. κ_c(s) := c, R_Y := {κ_c : c ∈ Y}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна (H виконано);
2. G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. Для кожного c ∈ Y покладемо x_c := (c, κ_{T(c)}) ∈ G і h := pr₁|G : G → Y. Тоді:

```text
h[ω_{D∞}(x_c)] = ω_T(c);
h_top(D∞|G) = h_top(T);
Min_{D∞|G}(G) = Min_T(Y);
x_c ATTAINED ⇔ ∃n ≥ 0: Tⁿ(c) ∈ ω_T(c).
```

Тут рівність `Min_{D∞|G}(G) = Min_T(Y)` означає рівність результатів класифікації — `MINIMAL` або `NON_MINIMAL`, — а не рівність двох неозначених функцій. Для обох систем передумови мінімальності виконуються, оскільки G і Y компактні й інваріантні. **DP-f.**

*Доведення.* j : Y → ℛ₀, j(c) := κ_c. d_ℛ(κ_c, κ_{c'}) = d_S(c, c'), тож j — ізометричне вкладення; R_Y компактна і міститься в ℛ₀. g∞(κ_c, s) = κ_{T(c)} відповідає неперервному T і не залежить від s. Отже (H) виконано.

Граф G компактний; h := pr₁|G — гомеоморфізм. D∞[G] ⊆ G; навпаки, через сюр'єктивність T для (d, κ_{T(d)}) ∈ G існує c з T(c) = d, звідки D∞(c, κ_{T(c)}) = (d, κ_{T(d)}). Отже D∞[G] = G і h ∘ D∞|G = T ∘ h.

Через h[ω_{D∞}(x_c)] = ω_T(c) зберігаються ω-границі та ATTAINED. h — бієкція між непорожніми замкненими інваріантними підмножинами G і Y, тому мінімальність зберігається.

**Збереження топологічної ентропії.** Нехай h : G → Y — гомеоморфізм. Для кожного ε_Y > 0 рівномірна неперервність h дає δ_G > 0, таке що d_G(x, x') < δ_G тягне d_Y(h(x), h(x')) < ε_Y. За контрапозицією, якщо d_Y(u, v) > ε_Y, то d_G(h⁻¹u, h⁻¹v) ≥ δ_G > δ_G/2. Застосовуючи цю нерівність до траєкторій: s_Y(n, ε_Y) ≤ s_G(n, δ_G/2), звідки h_top(T) ≤ h_top(D∞|G).

Навпаки, для кожного ε_G > 0 рівномірна неперервність h⁻¹ дає δ_Y > 0, таке що d_Y(u, v) < δ_Y тягне d_G(h⁻¹u, h⁻¹v) < ε_G. Тому кожна пара, розділена в G на відстань понад ε_G на деякому кроці, після застосування h залишається розділеною в Y на відстань понад δ_Y/2. Отже s_G(n, ε_G) ≤ s_Y(n, δ_Y/2), звідки h_top(D∞|G) ≤ h_top(T). Обидві нерівності дають h_top(D∞|G) = h_top(T). ∎

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {0,1}^ℕ з h_top(σ|Z) > 0.

Бібліографічні орієнтири:

- C. Grillenberger, "Construction of strictly ergodic systems I. Given entropy", *Z. Wahrscheinlichkeitstheorie verw. Geb.* 25 (1973), 323–334.
- E. Glasner and B. Weiss, "Strictly ergodic, uniform positive entropy models", *Bull. Soc. Math. France* 122(3) (1994), 399–412, DOI 10.24033/bsmf.2239.
- T. K. Subrahmonian Moothathu, P. Oprocha, "Shadowing, entropy and minimal subsystems", *Monatshefte für Mathematik* 172 (2013), 357–378, DOI 10.1007/s00605-013-0504-3. Доведення теореми 5.2 прямо використовує мінімальний підзсув Q ⊆ {0,1}^ℕ із додатною топологічною ентропією.

**Застереження про точну форму EXT-1.** Бібліографічний запис про існування строго ергодичних систем із додатною ентропією сам собою не замінює аргументу для саме одностороннього двійкового підзсуву Z. У цій редакції конструкцію Z не побудовано й не доведено заново, тому EXT-1 залишається окремою зовнішньою передумовою.

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення; P-48).** (X, d) — непорожній повний метричний простір, Φ : X → X, d(Φ(x), Φ(y)) ≤ q·d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x*, і Φⁿ(x₀) → x*. **DP-f.**

*Доведення.* Покладемо x_n = Φⁿ(x₀). За умовою стискання d(x_{n+1}, x_n) ≤ qⁿ d(x₁, x₀). Тому для m > n:

```text
d(x_m, x_n) ≤ Σ_{k=n}^{m−1} d(x_{k+1}, x_k) ≤ qⁿ / (1 − q) · d(x₁, x₀).
```

Отже (x_n) — послідовність Коші. Повнота X дає границю x* ∈ X. За неперервністю Φ маємо Φ(x*) = x*. Якщо y* — інша нерухома точка, то d(x*, y*) = d(Φ(x*), Φ(y*)) ≤ q·d(x*, y*). Оскільки q < 1, звідси d(x*, y*) = 0, тобто x* = y*. ∎

**Прищеплення.** Для a ∈ A: ρ_a(f) := node(f, leaf(a), leaf(a)). ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, ρ_a ∈ ℛ₀, стискаюче з коефіцієнтом ½.

**W1 (FIXED × ATTAINED).** R = {ρ_a}, g∞ = π_R. За лемою 11.11 ρ_a має єдину нерухому точку p_a. D∞(p_a, ρ_a) = (p_a, ρ_a). ω(x₀) = {(p_a, ρ_a)}, x₀ ∈ ω(x₀). **DP-f.**

**W2 (FIXED × NONATTAINED).** s ≠ p_a, x₀ = (s, ρ_a). x_n = (ρ_aⁿ(s), ρ_a) → (p_a, ρ_a). ω(x₀) = {(p_a, ρ_a)}. Якщо x_n = (p_a, ρ_a), то ρ_aⁿ(s) = p_a = ρ_aⁿ(p_a), звідки s = p_a — суперечність. **DP-f.**

**W3 (PERIODIC × ATTAINED/NONATTAINED; P-40).** R = {ρ_a, ρ_b}, g∞ чергує правила. Φ := ρ_b ∘ ρ_a стискаюче з коефіцієнтом ¼, єдина нерухома точка q. Цикл {z₀ := (q, ρ_a), z₁ := (ρ_a(q), ρ_b)} довжини 2. ATTAINED: старт на циклі. NONATTAINED: s ≠ q. Якби x₂ₖ = z₀, то Φᵏ(s) = q. Якби x₂ₖ₊₁ = z₁, то ρ_a(Φᵏ(s)) = ρ_a(q), звідки Φᵏ(s) = q. В обох випадках Φᵏ(s) = Φᵏ(q), а Φ ін'єктивне, тому s = q — суперечність. **DP-f.**

**W4 (MIN_ZERO × ATTAINED; P-38).** B := {0,1}^ℕ, C := {α, β}^ℕ (α ≠ β ∈ A). O : B → B — додавання 1. enc_αβ : B → C — координатна бієкція: enc_αβ(a)ᵢ = α при aᵢ = 0, β при aᵢ = 1. Õ := enc_αβ ∘ O ∘ enc_αβ⁻¹ : C → C. T := t ∘ Õ ∘ t⁻¹ : Y → Y.

**Ізометричність O.** 2-адичне число A = Σ aᵢ2ⁱ. Якщо a ≠ b, k — перший індекс розбіжності, то A ≡ B (mod 2ᵏ), але A ≢ B (mod 2ᵏ⁺¹). Додавання 1 не змінює різниці A − B, тому O(a), O(b) зберігають ту саму першу розбіжність. Отже d_B(O(a), O(b)) = d_B(a, b).

**Мінімальність O.** Перші n координат Oᵐ(a) відповідають (N_n(a) + m) mod 2ⁿ. При m = 0, …, 2ⁿ−1 отримуємо всі 2ⁿ префіксів. Тому кожна орбіта щільна; непорожня замкнена Q з O[Q] ⊆ Q містить повну щільну орбіту, отже Q = B.

**Відсутність періодичних точок.** Oᵖ(a) = a ⇒ p ≡ 0 (mod 2ⁿ) для всіх n — неможливо для фіксованого p > 0.

**Завершення.** За координатним кодуванням T на Y є ізометрією відносно d_S. За D3 h_top(T) = 0. За лемою E h_top(D∞|G) = h_top(T) = 0; лема E також переносить мінімальність і відсутність періодичних точок. Отже G — нескінченна мінімальна ω-границя з нульовою ентропією. Для x_c ∈ G: ω(x_c) = G, x_c ∈ G. Отже MIN_ZERO × ATTAINED. **DP-f.**
