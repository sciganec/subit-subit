## 1. Алфавіт і простір S₀

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, 4 елементи.

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. Властивості білаттису не переносяться на динаміку S∞ без окремого означення. ВИЗНАЧЕНО.

**Означення 1.2 (A2).** S₀ = A × A × A, 64 стани. Стан із бітами b₁…b₆ має код

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3).** code6 — бієкція S₀ → {0, …, 63}. DP-f. *Доведення.* Кожен елемент S₀ — слово з шести бітів; code6 — його двійковий запис; двійковий запис однозначний; слів 2⁶ = 64. ∎

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = 63; 010001 = YOU/NORTH/AUTUMN = 17. Гексаграмний запис (Додаток А) — лише індексація.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ) із S₀ × `ℛ_fin`. Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`, динаміка

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори, помилки й ресурсні переривання — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО (це означення, перечитане як автомат). Сильніша теза про самореферентну перевагу — ВІДКРИТО.

**Твердження 2.4 (A4, вкладення автомата).** Кожний автономний скінченний автомат (Q, δ) із **непорожнім** Q, #Q ≤ 64, тотальною δ : Q → Q і **без вхідного алфавіту** вкладається в SUBIT⁺. DP-f.

*Доведення.*

1. Оскільки Q ≠ ∅ і #Q ≤ 64, є ін'єкція ι : Q → S₀. Поза образом ι(Q) фіксуємо довільне s₀ ∈ S₀.
2. Означимо ρ : S₀ → S₀: ρ(ι(q)) := ι(δ(q)) для q ∈ Q (коректно, бо ι ін'єктивна); ρ(s) := s₀ для s поза ι(Q).
3. Візьмемо `ℛ_fin` = {ρ} і g₀(ρ, s) := ρ. Тоді D₀(s, ρ) = (ρ(s), ρ).
4. Індукція за n: якщо початковий стан (ι(q₀), ρ), то n-й стан — (ι(δⁿ(q₀)), ρ). Крок: ρ(ι(δⁿ(q₀))) = ι(δⁿ⁺¹(q₀)). ∎

**Область.** Твердження стосується автономних систем із непорожнім Q, одним тотальним переходом. Воно не стверджує універсальної симуляції DFA з вхідним алфавітом, симуляції автоматів із #Q > 64 чи універсальності SUBIT⁺ як λ-інтерпретатора.

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀ означимо

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** У Q₀ для кожного ŝ число m(ŝ) скінченне. DP-f. *Доведення.* Стани ŝ, D₀(ŝ), …, D₀^N(ŝ) при N = #Q₀ — це N + 1 елемент множини з N елементів, тож два збігаються (Діріхле). Отже, множина в означенні m непорожня. ∎

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f. *Доведення.* За P1 пара (m, p) визначена однозначно. Класи — три взаємовиключні умови: m = 0 і p = 1; m = 0 і p ≥ 2; m ≥ 1. ∎

**Твердження 3.1.3 (P3, точний режим).** Алгоритм

```text
вхід: ŝ₀;  visited : Map<State, ℕ> ← ∅
для n = 0, 1, …, #Q₀:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ];  p ← n − m
        повернути COMPUTED(клас, m, p, цикл)
    visited[ŝₙ] ← n;  ŝₙ₊₁ ← D₀(ŝₙ)
```

завжди завершується з COMPUTED; m, p збігаються з означенням 3.1; гілка `RESOURCE_EXCEEDED` недосяжна. DP-f. *Доведення.* За Діріхле повторення не пізніше n = #Q₀; перший повтор ŝₙ = ŝ_m з найменшим n дає мінімальні m і p = n − m. ∎

**Твердження 3.1.4 (P3′, бюджетований режим).** Якщо ліміт N_max < #Q₀, гілка `RESOURCE_EXCEEDED` досяжна для деяких систем; її результат **не є класифікацією**. DP-f (той самий алгоритм, обрізаний цикл).

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H) (§10.2). Для ŝ ∈ S∞ × R

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. DP-f. *Доведення.* Якщо m = ∞, то p = ∞ за означенням; якщо m < ∞, то p < ∞, бо множина в його означенні містить число з означення m. Далі — розбиття за (m, p), як у 3.1.2. ∎

**ВІДКЛИКАНО:** використання `Ω_point` (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. Це область усього §4–§5. Два приклади: Q₀ = S₀ × `ℛ_fin` з дискретною метрикою і D₀; X = S∞ × R з d̂ і D∞ за (H). P ⊆ K — **непорожня**, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас OrbitType | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

*Доведення.* Довільна P має одне значення μ(P). (a) μ = ∞: APERIODIC. (b) μ = 0: є n ≥ 1 з Dⁿ[P] = P, тож p_set ≤ n скінчене. p_set = 1: D[P] = P і рівно одна з двох: INVARIANT_FIXED, якщо D = id на P, інакше INVARIANT_DYNAMIC. p_set ≥ 2: D[P] ≠ P → PERIODIC_SET. (c) 1 ≤ μ < ∞: є n > μ з Dⁿ[P] = Dᵐ[P], тож π ≤ n − μ скінчене; π = 1 → EVENTUALLY_FIXED, π ≥ 2 → EVENTUALLY_PERIODIC. Взаємна виключність: D[P] = P влече μ = 0, а PERIODIC_SET вимагає D[P] ≠ P; класи з μ ≥ 1 відрізняються значенням π. ∎

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f. *Доведення.* Якщо D[P] = P — перший клас. Інакше: якщо D[P] ∩ P = ∅ — другий. Інакше перетин непорожній, D[P] ≠ P, і рівно одне з: D[P] ⊊ P, P ⊊ D[P], або множини непорівнювані. ∎

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна (замкнена в K); (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне (у допустимій системі виконується автоматично). Якщо не виконано хоч одну — «передумови не виконано».

Топологічна ентропія `h_top(D|P)` — за Боуеном: через (n, ε)-роздільні множини в метриці dₙ(x, y) = max_{i<n} d(Dⁱx, Dⁱy), `h_top` = lim_{ε→0} limsup_n (1/n) log s(n, ε), де s(n, ε) — максимальна потужність такої множини.

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** `NOT_APPLICABLE` ≠ `NON_CHAOTIC`: перше — критерій не застосовується, друге — застосовано і не справджено.

**Застереження 4.3.3 (зміна проти v6.9.3).** У v6.9.3 CHAOTIC вимагав мінімальності, тож повний зсув на {α, β}^ℕ (ентропія log 2, є фіксована точка) не був хаотичним. Тепер хаотичність — це додатна ентропія, а мінімальність — це окрема ознака Min. Комбінація «мінімальна і хаотична» називається `MIN_POS` (§11).

### 4.4. Одне значення CHAOTIC

`IsChaotic_D(P)` :⇔ `ChaosStatus_D(P) = CHAOTIC`; `CHAOTIC_ω(τ)` (§11) :⇔ `IsChaotic_D(ω(τ))`. Це один предикат для множин і для ω-границь. Символ `CHAOTIC_set` — лише назва нижнього елемента Ω (§5); π_Ω повертає його, якщо `IsChaotic_D(P)`. За (H) передумови для ω(τ) виконуються (D1, §11).

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL_IMAGE ⇔ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. DP-f. *Доведення.* (a) з означень. (b) Виконано (Π2), тож D[P] = P; з h_top > 0 випливає D|ₚ ≠ id (h_top(id) = 0), тож є x з D(x) ≠ x. (c) Виконано (Π2) за означенням. ∎

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f. *Доведення.* У скінченній P усі (n, ε)-роздільні множини мають потужність ≤ #P, тому (1/n) log s(n, ε) → 0. ∎

**Твердження 4.5.3 (C4, розділене).**

- **(C4a)** Якщо P скінченна і D[P] = P, то D|ₚ — бієкція і кожна точка P періодична. DP-f. *Доведення.* Сюр'єкція скінченної множини на себе є бієкцією, тож D|ₚ — перестановка, а кожна перестановка скінченної множини має скінченні періоди. ∎
- **(C4b)** Для нескінченної P бієктивність D|ₚ не тягне періодичності всіх точок. Контрприклад: одометр (§11.6). DP-f.
- **(C4c)** Для нескінченної P сюр'єктивність D|ₚ не тягне ін'єктивності. Контрприклад: односторонній зсув σ(x)ₙ = xₙ₊₁ на {0, 1}^ℕ: сюр'єктивний, не ін'єктивний. DP-f.

## 5. Алгебра Ω і проєкція π_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D_class).** D_class := { Classify⁺_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }. Усі координати кортежа обчислюються для тієї самої системи.

**Означення 5.3 (π_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. DP-f. *Доведення.* Для C = CHAOTIC — перший рядок; інакше O належить рівно одному з шести класів (C1), і кожен ужито у рядках 2–6. ∎

**Твердження 5.5 (C5b, сюр'єктивність).** Образ π_Ω у D_class складається з усіх шести елементів Ω. DP-f. *Свідки.* INVARIANT_FIXED: P = {p}. INVARIANT_DYNAMIC: 2-цикл {x, D(x)}. PERIODIC_SET: у 4-циклі a → b → c → d → a множина P = {a, c}: D[P] = {b, d} ≠ P, D²[P] = P, p_set = 2. EVENTUALLY_PERIODIC: P = {x₀} на системі x₀ → x₁ → x₂ → x₁ (μ = 1, π = 2). APERIODIC_NON_CHAOTIC: K = {0,1}^ℕ, D = σ (зсув), a_n = 1 ⇔ n — степінь двійки, P = {σⁿ(a) : n ≥ 0}; проміжки між 1 необмежено зростають; Dᵏ[P] — різні множини, μ = ∞; P не замкнена (σ^(2ᵐ+1)(a) → 0^∞ ∉ P); (Π1)–(Π2) не виконуються, ChaosStatus = NOT_APPLICABLE. CHAOTIC_set: множина G з W5 (§11.4). Усі системи допустимі. ∎

**Зауваження 5.6 (`APERIODIC_NON_CHAOTIC` — втратна мітка).** Якщо μ(P) = ∞, то D[P] ≠ D⁰[P] = P, тож (Π2) не виконується й ChaosStatus = NOT_APPLICABLE. Отже, поєднання «OrbitType = APERIODIC і ChaosStatus = NON_CHAOTIC» за означеннями неможливе. Елемент `APERIODIC_NON_CHAOTIC` ланцюга Ω — це мітка образу π_Ω, а не твердження про статус NON_CHAOTIC. C5b стверджує лише сюр'єктивність відображення π_Ω; семантично пара «аперіодична й нехаотична» нереалізовна. Назву збережено заради сумісності з v6.9.3; нейтральна назва (`APERIODIC_NOT_CHAOTIC`) — відкрита редакційна пропозиція автору.

**Застереження 5.6.1.** Для фіксованої скінченної системи образ π_Ω не може містити `CHAOTIC_set` (C7).

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥ (⊥ = CHAOTIC_set, ⊤ = INVARIANT_FIXED).

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f. *Доведення.* Ланцюг — гратка з 0 і 1. Треба перевірити min(a, c) ≤ b ⇔ c ≤ (a → b). Якщо a ≤ b: ліва частина завжди істинна (min ≤ a ≤ b), права — c ≤ ⊤. Якщо a > b: min(a, c) ≤ b ⇔ c ≤ b і a → b = b. Виключене третє хибне: для a без ⊥ і ⊤ є a ∨ ¬a = a ∨ ⊥ = a ≠ ⊤. ∎

**Застереження 5.9.** π_Ω втратна (відкидає InclusionType і Min, а також різницю NOT_APPLICABLE / NON_CHAOTIC). Ω — синтаксичний інструмент, формально не пов'язана з білаттисом Белнапа.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

Для довільної динамічної системи (K, D), x ∈ K, U ⊆ K; `¬U := K ∖ U` — класичне доповнення, не тотожне `¬_H` з §6.2.

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`F_tree` — виключно функтор `X ↦ A ⊔ X³`; динаміка позначається буквою D.

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. DP-f.

```text
(X1) X U → ◇⁺ U                  (X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)       (D1) ◇U ↔ U ∨ X ◇U
(D2) ◇⁺ U ↔ X ◇U                  (D3) ◇U ↔ U ∨ ◇⁺ U
(B1) □U ↔ U ∧ X □U                (B2) □U → U
(B3) □U → X □U                    (B4) □U → ◇U
(B5) □(U → V) → (□U → □V)       (R1) ↺U ↔ ◇⁺(X U)
(R2) ↺U → ◇⁺ U                  (M4) ◇U ↔ ¬□¬U
```

*Доведення.* Фіксуємо x; uₙ := [Dⁿ(x) ∈ U], vₙ — для V. Тоді XU ⇔ u₁; ◇U ⇔ ∃n≥0 uₙ; ◇⁺U ⇔ ∃n≥1 uₙ; □U ⇔ ∀n≥0 uₙ; ↺U ⇔ ∃k≥2 uₖ. Для формули φ істина Xφ в x — це істина φ в D(x), а послідовність для D(x) — зсув (uₙ₊₁). Тому X◇U ⇔ ∃n≥1 uₙ; X□U ⇔ ∀n≥1 uₙ; ◇⁺(XU) ⇔ ∃k≥2 uₖ. Кожна аксіома — тавтологія кванторів по ℕ: D1: (∃n≥0 uₙ) ⇔ u₀ ∨ (∃n≥1 uₙ); D2 — рівність X◇U і ◇⁺U; D3 аналогічно D1; B1: (∀n≥0 uₙ) ⇔ u₀ ∧ (∀n≥1 uₙ); B2–B4: n = 0; B5: якщо ∀n (uₙ → vₙ) і ∀n uₙ, то ∀n vₙ; R1, R2: k = n + 1 ≥ 2; X1: u₁ ⇒ ∃n≥1 uₙ; X2, X3: X розподіляється по ∧ і ∨; M4: ¬∀n ¬uₙ ⇔ ∃n uₙ. ∎

**Твердження 6.1.2 (M2, M6).** □U → ↺U. DP-f: □U дає D²(x) ∈ U, тобто k = 2 > 1.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** Для предиката U : K → Ω: (□_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇_H U)(x) := ⋁ₙ≥0 U(Dⁿx) у решітці Ω; `¬_H a := a → ⊥` — псевдодоповнення в Ω.

**Твердження 6.2.2 (M3).** Рівність ◇_H U = ¬_H □_H ¬_H U у семантиці §6.2 **хибна**. DP-f. *Контрмодель:* K = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY_PERIODIC, U(b) = CHAOTIC_set (= ⊥). (◇_H U)(a) = max(EVENTUALLY_PERIODIC, ⊥) = EVENTUALLY_PERIODIC. (¬_H U)(a) = ⊥, (¬_H U)(b) = ⊤. (□_H ¬_H U)(a) = min(⊥, ⊤) = ⊥, тож (¬_H □_H ¬_H U)(a) = ⊤ ≠ EVENTUALLY_PERIODIC. ∎

**Твердження 6.2.3 (Q6 закрито для §6.2).** M4 у гейтінговій семантиці §6.2 не виконується (це рівність M3). DP-f. **Q6′ (ВІДКРИТО):** чи є інша гейтінгова семантика, у якій M4 виконується?

### 6.3. Динамічна теорія типів

Судження Γ ⊢ t : U @ τ читається в моделі §6.1 як «точка t належить U»; час τ — лічильник.

```text
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ
Еволюція:        Γ ⊢ t:U@τ    D[U] ⊆ V         ⇒  Γ ⊢ D(t) : V@(τ+1)
Стабільність:     Γ ⊢ t:U@τ    D[U] ⊆ U         ⇒  Γ ⊢ t : □U@τ
Потенційність:    Γ ⊢ t:U@τ    ∃k≥0: Dᵏ[U] ⊆ V ⇒  Γ ⊢ t : ◇V@τ
```

**Твердження 6.3.1 (коректність правил).** У моделі §6.1 кожне правило коректне. DP-f. *Доведення.* Еволюція: t ∈ U ⇒ D(t) ∈ D[U] ⊆ V. Стабільність: з D[U] ⊆ U індукцією Dⁿ(t) ∈ U для всіх n. Потенційність: Dᵏ(t) ∈ Dᵏ[U] ⊆ V. ∎ Правило стабільності ослаблено до D[U] ⊆ U (erratum E-4). Повнота і дальша метатеорія — НЕ ПІДТВЕРДЖЕНО.

### 6.4. Предикати префікса

```text
PH_φ(N) := ∀k ≤ N: φ(k, τ)
EP_φ(N) := ∃k ≤ N: φ(k, τ)
PP_φ(k) := φ(k, τ)
GP_φ(τ)                            (Global)
```

Правила: PH_φ(N+1) ⇒ PH_φ(N); EP_φ(N) ⇒ EP_φ(N+1); PH_φ(N) ⇒ EP_φ(N). Імплікацій між PP і GP немає. Символ Ψ зарезервовано для оператора продуктивності (§9.2).

## 7. Категорія SUBIT

**Означення 7.1 (об'єкт).** X = (S, ℛ, g): S ≠ ∅, ℛ ⊆ S^S непорожня, g : ℛ × S → ℛ. Динаміка D_X(s, ρ) := (ρ(s), g(ρ, s)).

**Означення 7.2 (морфізм).** φ = (φ_S, φ_ℛ) з умовою:

```text
φ_S(ρ(s)) = (φ_ℛ(ρ))(φ_S(s))
```

Умова не включає g.

**Означення 7.3 (SUBIT_full).** Широка підкатегорія; морфізми додатково задовольняють φ_ℛ(g_X(ρ, s)) = g_Y(φ_ℛ(ρ), φ_S(s)).

**Твердження 7.4 (K1).** SUBIT і SUBIT_full — категорії. DP-f. *Доведення.* Тотожний морфізм (id_S, id_ℛ) задовольняє обидві умови тривіально. Композиція — покомпонентна, тому асоціативна. Якщо φ : X → Y, ψ : Y → Z, то ψ_S(φ_S(ρ(s))) = ψ_S(φ_ℛ(ρ)(φ_S s)) = ψ_ℛ(φ_ℛ ρ)(ψ_S φ_S s). Для SUBIT_full: ψ_ℛ(φ_ℛ(g_X(ρ, s))) = ψ_ℛ(g_Y(φ_ℛρ, φ_S s)) = g_Z(ψ_ℛφ_ℛρ, ψ_Sφ_S s). ∎

**Твердження 7.5 (K2).** 1 = ({∗}, {id}, g_triv) — термінальний об'єкт у SUBIT і SUBIT_full. DP-f. *Доведення.* Морфізм X → 1 має лише одну компоненту кожного типу, бо кодомени — одноточкові; умови виконуються. ∎

**Твердження 7.6 (K3, добуток).** Для X, Y:

```text
(ρ ⊠ σ)(x, y) := (ρ(x), σ(y))         на S_X × S_Y
ℛ_{X×Y} := { ρ ⊠ σ : ρ ∈ ℛ_X, σ ∈ ℛ_Y }
g_{X×Y}(ρ ⊠ σ, (x, y)) := g_X(ρ, x) ⊠ g_Y(σ, y)
```

— добуток у SUBIT і у SUBIT_full. DP-f.

*Доведення.* Розклад `ρ ⊠ σ` однозначний, бо `S_X`, `S_Y` непорожні: `ρ` відновлюється з першої координати при будь-якому `y`, `σ` — з другої. Тому `g_{X×Y}` коректно задана й має значення в `ℛ_{X×Y}`. Проєкції: `pr_X = (pr₁, (ρ ⊠ σ) ↦ ρ)`; умова 7.2: `pr₁((ρ ⊠ σ)(x, y)) = ρ(x) = pr_X,ℛ(ρ ⊠ σ)(pr₁(x, y))`. Нехай `u : Z → X`, `v : Z → Y`. `⟨u, v⟩_S(z) := (u_S z, v_S z)`, `⟨u, v⟩_ℛ(τ) := u_ℛ(τ) ⊠ v_ℛ(τ)`. Умова 7.2: `⟨u, v⟩_S(τ(z)) = (u_ℛ(τ)(u_S z), v_ℛ(τ)(v_S z)) = (u_ℛ(τ) ⊠ v_ℛ(τ))(u_S z, v_S z)`. Єдиність: ℛ-компонента має бути `ρ' ⊠ σ'` з `ρ' = u_ℛ(τ)`, `σ' = v_ℛ(τ)`, а S-компонента — з проєкцій. Для SUBIT_full: `φ_ℛ(g_Z(τ, z)) = g_X(u_ℛτ, u_S z) ⊠ g_Y(v_ℛτ, v_S z) = g_{X×Y}(⟨u, v⟩_ℛτ, ⟨u, v⟩_S z)`. ∎

**Застереження 7.7.** Якщо категорія має допускати порожні S, потрібні окремі типи кодів правил із `eval_X : ℛ_X × S_X → S_X`. **Відкрито:** Q1, Q19.

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f), f : S → S. Морфізм φ : (S, f) → (T, h) — φ ∘ f = h ∘ φ. Dyn₊ — повна підкатегорія з непорожніми S.

**Твердження 8.2 (K4, топос).** Dyn ≅ Fun(Bℕ, Set), де Bℕ — категорія з одним об'єктом і моноїдом ендоморфізмів (ℕ, +, 0). Функтор відправляє єдиний об'єкт у S, а n — у fⁿ. Це прешейфовий топос, тому Dyn — топос (DP-s: стандартна теорема). Класифікатор підоб'єктів виписано явно нижче (8.4).

**Примітка 8.2.1.** У конвенції, де presheaf category на C означає Fun(C^op, Set), `Fun(Bℕ, Set) = Fun((Bℕ)^op, Set)`, оскільки Bℕ^op ≅ Bℕ (моноїд ℕ комутативний, а Bℕ як категорія має один об'єкт і морфізми ℕ). Тому Dyn — топос незалежно від конвенції.

**Означення 8.3 (час входу, лише для інваріантних U).** Нехай U ⊆ S підоб'єкт, тобто f[U] ⊆ U. Тоді χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U } (∞, якщо ніколи).

**Твердження 8.4 (χ_U, класифікатор підоб'єктів).** Нехай Ω_Dyn = ℕ ∪ {∞} з дією n·k := max(n − k, 0), ∞·k := ∞, і «істиною» 0. Тоді (a) χ_U(f(x)) = max(χ_U(x) − 1, 0), тобто χ_U — морфізм Dyn; (b) U ↦ χ_U є бієкцією між підоб'єктами (S, f) і морфізмами (S, f) → Ω_Dyn, з оберненою U = χ⁻¹(0). DP-f.

*Доведення.* (a) Якщо χ_U(x) = n ≥ 1, то f(x) потребує рівно n − 1 кроків; якщо χ_U(x) = 0, то f(x) ∈ U за інваріантністю, тож χ_U(f x) = 0; якщо χ_U(x) = ∞ — так само ∞. (b) Якщо χ : S → Ω_Dyn — морфізм, то χ⁻¹(0) інваріантна: χ(f x) = max(χ(x) − 1, 0) = 0 при χ(x) = 0. Для U = χ⁻¹(0) і скінченного χ(x) = n: χ(fᵏ x) = n − k > 0 при k < n і χ(fⁿ x) = 0, тому χ_U(x) = n; при χ(x) = ∞ усі χ(fᵏ x) = ∞ ≠ 0. Отже, χ_U = χ. І навпаки χ_U⁻¹(0) = U. ∎

**Застереження 8.5.** Для неінваріантної U ⊆ S формула χ_U загалом **не** еквіваріантна й не є морфізмом. Приклад: f(0) = 1, f(1) = 1 на S = {0, 1}, U = {0}: χ_U(0) = 0, але χ_U(f(0)) = χ_U(1) = ∞ ≠ max(0 − 1, 0).

**Твердження 8.6 (K5, вкладення).** Функтор E : Dyn₊ → SUBIT, (S, f) ↦ (S, {f}, g_f), g_f(f, s) := f, на морфізмах φ ↦ (φ, єдине відображення {f} → {h}) — повний і вірний, і такий самий функтор вкладає Dyn₊ у SUBIT_full. DP-f. *Доведення.* Умова 7.2 для пари (φ, !) це рівно φ(f(s)) = h(φ(s)), тобто морфізм Dyn. Друга компонента визначена однозначно, тому E вірний і повний. Умова 7.3 тривіальна, бо ℛ одноелементна. ∎

**Застереження 8.7.** Вкладення всієї Dyn неможливе без перегляду типу правил (S = ∅). Топосна структура Dyn не переноситься на SUBIT автоматично.

**Q2′ (ВІДКРИТО).** Чи існує категорія C, що містить образ Dyn₊ у SUBIT і має топосну структуру, яка зберігає нетривіальну метаеволюцію?

## 9. Простір S∞ = Tree∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, алфавіт міток Λ := {None, node} ∪ {leaf(a) : a ∈ A} (6 елементів). Tree∞ — множина f : Pos → Λ, що задовольняють

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None для i = 1, 2, 3;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None для будь-якого τ.

S∞ := Tree∞. Піддерево для f(ε) = node: f_i(σ) := f(i·σ); для f(ε) = leaf(a) піддерево **не визначене**.

**Твердження 9.2 (T1, фінальна коалгебра).** Tree∞ з out(f) := inl(a) при f(ε) = leaf(a) і out(f) := inr(f₁, f₂, f₃) при f(ε) = node — фінальна коалгебра функтора `F_tree(X) = A ⊔ X³`. DP-s (out — бієкція; фінальність — розгортання за адресами; повний аргумент не виписано).

**Твердження 9.3 (T2).** e(a, b, c) := node(leaf(a), leaf(b), leaf(c)) — ін'єкція A³ → S∞. DP-f: значення f(1), f(2), f(3) відновлюють a, b, c.

### 9.2. Допоміжна конструкція: Ψ і L_prod

Цей підрозділ не потрібен для компактності чи динаміки (§9.4 не посилається на нього); він про коалгебраїчний опис S∞.

```text
T_0     := { Leaf_0(a) : a ∈ A } ∪ { Bottom_0 }
T_{n+1} := { Leaf_{n+1}(a) } ∪ { Bottom_{n+1} } ∪ { Node_n(t₁, t₂, t₃) : tᵢ ∈ T_n }
q_0 : T_1 → T_0:   Leaf_1 a ↦ Leaf_0 a,  Bottom_1 ↦ Bottom_0,  Node_0(…) ↦ Bottom_0
q_{n+1} : T_{n+2} → T_{n+1}:  Leaf ↦ Leaf,  Bottom ↦ Bottom,
                              Node_{n+1}(t₁,t₂,t₃) ↦ Node_n(q_n t₁, q_n t₂, q_n t₃)
U_c := { (t_n) ∈ ∏ T_n : q_n(t_{n+1}) = t_n для всіх n }
LeafSeqs := { (Leaf_n(a))_n : a ∈ A }
NodeSeqs(X) := { t ∈ U_c : t_0 = Bottom_0, ∃u₁,u₂,u₃ ∈ X з t_{n+1} = Node_n(u₁_n, u₂_n, u₃_n) для всіх n ≥ 0 }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X);     L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.4.** L_prod = Ψ(L_prod). DP-f. *Доведення.* L_prod — об'єднання всіх X з X ⊆ Ψ(X); Ψ монотонний. Для кожного такого X: X ⊆ Ψ(X) ⊆ Ψ(L_prod), тому L_prod ⊆ Ψ(L_prod). Звідси Ψ(L_prod) ⊆ Ψ(Ψ(L_prod)), тобто Ψ(L_prod) — постнерухома точка, отже Ψ(L_prod) ⊆ L_prod. ∎

**Зауваження 9.5.** `U_c` **строго більша** за L_prod: послідовність (Bottom_n)ₙ належить U_c, але не задовольняє ні LeafSeqs, ні NodeSeqs (бо t₁ вимагає бути Node_0). Тому «обернена границя» на прямовані q_n давала би більший простір, і для реконструкції береться коіндуктивне ядро L_prod.

### 9.3. d_n, at_n, lim_tree

```text
d_0(f) := Leaf_0(a) якщо f(ε) = leaf(a);   Bottom_0 якщо f(ε) = node
d_{n+1}(f) := Leaf_{n+1}(a)                       якщо f(ε) = leaf(a)
d_{n+1}(f) := Node_n(d_n f₁, d_n f₂, d_n f₃)      якщо f(ε) = node

TΣ := Σ_k T_k  (пари (k, u), u ∈ T_k);    at_n : T_n → Pos → Option(TΣ)
at_n(t, ε) := Some((n, t));            at_0(t, i·τ) := None
at_{n+1}(Leaf, i·τ) := None;          at_{n+1}(Bottom, i·τ) := None
at_{n+1}(Node_n(u₁,u₂,u₃), i·τ) := at_n(u_i, τ)
```

**Лема 9.6 (типізація).** d_n(f) ∈ T_n, q_n(d_{n+1} f) = d_n f; якщо at_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T_k. DP-f: індукція за n і |σ|.

**Означення 9.7 (lim_tree, стабілізація кореневого конструктора).** Для t = (t_m) ∈ L_prod і σ ∈ Pos, m > |σ| розглядаємо at_m(t_m, σ). При m → ∞ стабілізується **коренева форма** at_m(t_m, σ):

- (Z) для всіх достатньо великих m: at_m(t_m, σ) = None;
- (L) для всіх достатньо великих m: at_m(t_m, σ) має кореневий конструктор Leaf, і мітка a ∈ A стала;
- (N) для всіх достатньо великих m: at_m(t_m, σ) має кореневий конструктор Node.

**Індекс глибини (m − |σ|) і скінченний опис піддерева у випадку Node можуть змінюватися з m**; стабілізується лише коренева форма. Тоді:

```text
lim_tree(t)(σ) := None      у випадку Z
lim_tree(t)(σ) := leaf(a)   у випадку L (для сталого a)
lim_tree(t)(σ) := node      у випадку N
```

**Твердження 9.8 (реконструкція).** (a) lim_tree(t) ∈ Tree∞; (b) p(f) := (d_n f)ₙ ∈ L_prod і lim_tree(p(f)) = f; (c) p(lim_tree(t)) = t. Тобто p : Tree∞ → L_prod — бієкція з оберненим lim_tree. DP-s (індукція за |σ|; повний аргумент — у плані Lean).

### 9.4. Метрика d_S і компактність

```text
r_addr(f, g) := min{ |σ| : f(σ) ≠ g(σ) }   (∞, якщо f = g)
d_S(f, g)    := 2^{− r_addr(f, g)}            (0, якщо f = g)
r_app(f, g)  := min{ n ≥ 0 : d_n f ≠ d_n g }
```

**Лема 9.9.** r_app = r_addr. DP-s: d_n(f) відновлює мітки f на адресах довжини ≤ n, і нічого більше.

**Твердження 9.10 (T3).** d_S — ультраметрика. DP-f. *Доведення.* Симетрія і d_S(f, g) = 0 ⇔ f = g — з означення. На адресах довжини < min(r_addr(f, g), r_addr(g, h)) маємо f = g = h, тому r_addr(f, h) ≥ min(…), тобто d_S(f, h) ≤ max(d_S(f, g), d_S(g, h)). ∎

**Твердження 9.11 (T4).** Якщо f(ε) = g(ε) = node, то для i = 1, 2, 3: d_S(f_i, g_i) ≤ 2·d_S(f, g). DP-f. *Доведення.* Якщо f = g, тривіально. Інакше r := r_addr(f, g) ≥ 1 (корені збігаються). Якщо f_i(τ) ≠ g_i(τ), то f(i·τ) ≠ g(i·τ), тож |i·τ| ≥ r, тобто |τ| ≥ r − 1. Відтак r_addr(f_i, g_i) ≥ r − 1 і d_S(f_i, g_i) ≤ 2^{−(r−1)} = 2·d_S(f, g). ∎

**Твердження 9.12 (T5).** (Tree∞, d_S) — компактний, повний, цілком обмежений. DP-f. *Доведення.* Λ^Pos із добутковою топологією — компакт (зліченний добуток скінченних дискретних множин). Кожна з (T1)–(T4) замкнена (залежить від пари координат). Tree∞ замкнена в компакті, тому компактна. Куля {g : r_addr(f, g) > r} збігається з циліндром на адресах довжини ≤ r, тому d_S метризує топологію. Компактна метрична → повна й цілком обмежена. ∎

**Твердження 9.13 (адресний доступ).** Для f ∈ Tree∞, σ ∈ Pos, n > |σ|: f(σ) = leaf(a) ⇒ at_n(d_n f, σ) = Some((n − |σ|, Leaf(a))); f(σ) = node ⇒ корінь at_n(d_n f, σ) — Node; f(σ) = None ⇒ at_n(d_n f, σ) = None. DP-s (індукція за |σ|).

### 9.5. «Хребет» і простір Y

Фіксуємо літери α ≠ β та η з A. Для a = (a₀, a₁, …) ∈ {α, β}^ℕ:

```text
t(a)(1ᵏ) := node,    t(a)(1ᵏ·2) := leaf(a_k),    t(a)(1ᵏ·3) := leaf(η)
```

інші позиції — за (T2)–(T4).

**Твердження 9.14.** t : {α, β}^ℕ → S∞ неперервне й ін'єктивне; точніше, d_S(t(a), t(b)) = 2^{−(k+1)}, де k — перший індекс розбіжності a і b. Образ Y := t({α, β}^ℕ) — канторів простір, замкнений в S∞. Зсув σ на {α, β}^ℕ спряжений до T := t ∘ σ ∘ t⁻¹ на Y. DP-f.

**Зауваження 9.15.** S∞ — нульвимірний компакт; скінченні дерева — ізольовані точки (дерево глибини h має None на глибині h + 1, і куля радіуса 2^{−(h+1)} збігається з ним за (T4)). Множина нескінченних дерев — замкнена й досконала (без ізольованих точок). Y — досконала підмножина, гомеоморфна канторовому простору, але не вся ця множина: повне потрійне дерево (node на всіх адресах) нескінченне, проте не лежить у Y, бо в деревах із Y адреса 2 — листок.

## 10. Правила ℛ₀ і ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні та обчислювані правила

**Означення 10.1.** ℛ₀ := ℛ_caus := { f : S∞ → S∞ : d_S(f(s), f(t)) ≤ d_S(s, t) }, метрика d_ℛ(ρ, σ) := sup_s d_S(ρ(s), σ(s)).

**Означення 10.2.** ℛ₁ := ℛ_comp — функції S∞ → S∞ зі скінченним обчислювальним описом у фіксованій моделі, де дерево подано оракулом (адреса → мітка).

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ для кожного n мітки виходу на адресах довжини ≤ n залежать лише від міток входу на адресах довжини ≤ n. DP-f. *Доведення.* Нерівність d_S(f s, f t) ≤ d_S(s, t) еквівалентна r_addr(f s, f t) ≥ r_addr(s, t); це і є незалежність префікса. ∎

**Твердження 10.4 (T6).** (ℛ₀, d_ℛ) — компактний ультраметричний простір. DP-s: ультраметричність — sup ультраметрик; компактність — Арцела–Асколі.

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀. DP-s: нижня оцінка — константи κ_c (§11.4), щонайменше |Y| = 2^ℵ₀; верхня — неперервне відображення сепарабельного простору визначається значеннями на зліченній щільній множині. |ℛ₁| ≤ ℵ₀ — за припущення про модель. Нижня оцінка: для кожного скінченного дерева t_n константне правило κ_{t_n}(s) = t_n має скінченний опис; скінченних дерев нескінченно багато, тож |ℛ₁| = ℵ₀ (за тієї ж моделі). Включення ℛ₁ ⊆ ℛ₀ не стверджується.

### 10.2. Розширений простір і передумови

**Припущення (H).** R ⊆ ℛ₀ — непорожня замкнена (а отже компактна) множина правил; g∞ : R × S∞ → R — неперервна і тотальна на всій області. X := S∞ × R, d̂((s, ρ), (t, σ)) := max(d_S(s, t), d_R(ρ, σ)), де d_R := d_ℛ|_{R×R}. Динаміка D∞(s, ρ) := (ρ(s), g∞(ρ, s)).

**Припущення (H₀).** Для скінченної моделі SUBIT⁺: S₀ скінченне з дискретною топологією, D₀ та g₀ тотальні. (H₀) не є екземпляром (H).

**Означення 10.6.** π_R : R × S∞ → R, π_R(ρ, s) := ρ. **Тотожна метаеволюція** — це `g∞ = π_R` (запис `g∞ ≡ id` типізовано некоректний).

**Твердження 10.7 (T7).** d_S(ρ(s), σ(t)) ≤ max(d_S(s, t), d_ℛ(ρ, σ)); отже за (H) D∞ неперервна, а (X, d̂) — компактний ультраметричний простір. DP-f. *Доведення.* d_S(ρ s, σ t) ≤ max(d_S(ρ s, σ s), d_S(σ s, σ t)) ≤ max(d_ℛ(ρ, σ), d_S(s, t)), бо σ ∈ ℛ₀. Неперервність другої компоненти — з (H). X компактний як добуток компактів. ∎

### 10.3. Метрики на X

**Твердження 10.8 (T8).** d_finite(x, y) := sup_{n≥0} 2^{−n}·d̂(D∞ⁿ x, D∞ⁿ y) — ультраметрика, що задає ту саму топологію, що d̂. DP-f. *Доведення.* Кожен член 2^{−n} d̂(Dⁿ x, Dⁿ y) задовольняє ультраметричну нерівність; тож і їхній sup. Член n = 0 дорівнює d̂, тому d_finite ≥ d̂ і d_finite(x, y) = 0 ⇒ x = y. Топологія: d_finite ≥ d̂; для ε > 0 беремо N з 2^{−N} < ε; члени n ≥ N менші за ε; для n < N неперервність D∞ⁿ дає δ. ∎

**Означення 10.9 (d_H, d_H^X).** Для непорожніх компактних P, Q: d_H(P, Q) := max{ sup_{p∈P} inf_{q∈Q} d(p, q), sup_{q∈Q} inf_{p∈P} d(p, q) }; для P, Q ⊆ S∞ це d_H з d = d_S, для P, Q ⊆ X — d_H^X з d = d̂.

**Означення 10.10 (d_ω).** Для x, y ∈ X: d_ω(x, y) := d_H^X(ω(x), ω(y)) — псевдометрика на X; метрика — на факторі X/~, де x ~ y ⇔ ω(x) = ω(y). DP-f.

**Застереження 10.11.** Правила з ℛ₁, що не є неперервними, у (H) не потрапляють.

## 11. Класифікація траєкторій P(τ)

Усюди припускається (H). Траєкторія τ = (x_n) має x_{n+1} = D∞(x_n); ω(τ) — множина граничних точок підпослідовностей. Без (H) твердження D1–D6 — УМОВНО.

### 11.1. ω-границя і класи S(τ)

**Твердження 11.1 (D1).** За (H) ω(τ) непорожня, компактна і D∞[ω(τ)] = ω(τ). DP-f. *Доведення.* `ω(τ) = ⋂_N cl{x_n : n ≥ N}` — перетин вкладених непорожніх компактів. D∞[ω] ⊆ ω: якщо y = lim x_{n_i}, то D∞(y) = lim x_{n_i + 1} за неперервністю. ω ⊆ D∞[ω]: для y = lim x_{n_i} обираємо підпослідовність, для якої x_{n_i − 1} → z; тоді z ∈ ω і D∞(z) = y. ∎

**Лема 11.0 (скінченна ω — один цикл).** Нехай ω — непорожня скінченна D∞-інваріантна множина (D∞[ω] = ω). Тоді D∞|ω — перестановка ω, і ω розкладається в об'єднання циклів D∞. Якщо ω = ω(τ) для деякої траєкторії, то ω — один цикл. DP-f. *Доведення.* D∞|ω — сюр'єкція скінченної множини на себе, отже бієкція, отже перестановка; кожна перестановка розкладається в цикли. Якщо ω = ω(τ), то ω — мінімальна підсистема: будь-яка непорожня замкнена D∞-інваріантна підмножина ω знову є ω-границею тієї ж орбіти (за побудовою ω як перетину замикань хвостів). Отже, ω — один цикл. ∎

**Означення 11.2 (Att).** ATTAINED ⇔ ∃n: x_n ∈ ω(τ). NONATTAINED := ¬ATTAINED (D2). `ASYMPTOTIC` — історичний синонім NONATTAINED; не означає стандартної асимптотичної збіжності. У формальному тексті вживається NONATTAINED.

**Означення 11.3 (класи S(τ)).** Ознаки множини ω = ω(τ): розмір (1, скінченна > 1, нескінченна), Min_D(ω) і ентропія h_top(D∞|ω). Шість класів:

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω = {p} |
| PERIODIC | ω скінченна, #ω > 1 |
| MIN_ZERO | ω нескінченна, мінімальна, h_top = 0 |
| MIN_POS | ω нескінченна, мінімальна, h_top > 0 |
| NONMIN_ZERO | ω нескінченна, не мінімальна, h_top = 0 |
| NONMIN_POS | ω нескінченна, не мінімальна, h_top > 0 |

`QUASI_PERIODIC_MINIMAL` — підклас MIN_ZERO. `CHAOTIC_ω(τ)` — це «h_top > 0», тобто MIN_POS або NONMIN_POS (§4.4).

**Твердження 11.4 (D6).** За (H) шість класів попарно не перетинаються й вичерпують усі траєкторії. DP-f. *Доведення.* За D1 ω непорожня компактна інваріантна. Якщо вона скінченна, то за лемою 11.0 ω — один цикл; #ω = 1 → FIXED, #ω > 1 → PERIODIC. Ентропія скінченної системи нульова (C7). Якщо нескінченна, маємо дві незалежні дихотомії: мінімальна або ні, h_top = 0 або h_top > 0 — чотири взаємовиключні класи. Лема Цорна не потрібна. ∎

### 11.2. Ентропія

**Твердження 11.5 (D3).** Нехай P — непорожня компактна множина, D[P] ⊆ P, а D|_P нерозтягувальне: d(Dx, Dy) ≤ d(x, y) для всіх x, y ∈ P. Тоді h_top(D|_P) = 0. DP-f. *Доведення.* З нерозтягувальності d ≤ d_n ≤ d на P, тобто d_n = d. Отже (n, ε)-роздільна множина — це просто ε-роздільна, і її потужність обмежена числом, незалежним від n (цілком обмеженість P). Тоді (1/n) log s(n, ε) → 0. ∎

**Твердження 11.6 (D4).** Якщо g∞ = π_R, то D∞(s, ρ) = (ρ(s), ρ) нерозтягувальне на X, отже h_top = 0 на кожній замкненій інваріантній множині і жодна множина не є CHAOTIC (зокрема, CHAOTIC_ω неможливий). DP-f. *Доведення.* d̂(D(s, ρ), D(t, σ)) = max(d_S(ρ s, σ t), d_R(ρ, σ)) ≤ max(d_S(s, t), d_R(ρ, σ)) = d̂((s, ρ), (t, σ)) за T7; далі D3. ∎

**Твердження 11.7 (D3′).** Якщо g∞(ρ, s) = ρ для одного ρ і всіх s, то K_ρ := S∞ × {ρ} додатно інваріантна: D∞[K_ρ] = ρ[S∞] × {ρ} ⊆ K_ρ. Обмеження D∞|K_ρ спряжене з ρ через проєкцію на першу координату, а ρ ∈ ℛ₀ нерозтягувальне, тож h_top(D∞|K_ρ) = 0 за D3. Рівність D∞[K_ρ] = K_ρ виконується лише для сюр'єктивного ρ; тоді K_ρ допустима для ChaosStatus. DP-f.

### 11.3. Метрика d_Ω_traj

**Означення 11.3.1 (код класу).** Для S ∈ {FIXED, PERIODIC, MIN_ZERO, MIN_POS, NONMIN_ZERO, NONMIN_POS} і Att ∈ {ATTAINED, NONATTAINED}:

```text
code(S, Att) := (SizeCode(S), MinCode(S), EntropyCode(S), Att)
```

де SizeCode ∈ {1, FINITE_>1, INFINITE}, MinCode ∈ {MINIMAL, NON_MINIMAL}, EntropyCode ∈ {0, +}, Att ∈ {ATTAINED, NONATTAINED}. Таблиця кодів:

| Клас | SizeCode | MinCode | EntropyCode |
| :-- | :-- | :-- | :-- |
| FIXED | 1 | MINIMAL | 0 |
| PERIODIC | FINITE_>1 | MINIMAL | 0 |
| MIN_ZERO | INFINITE | MINIMAL | 0 |
| MIN_POS | INFINITE | MINIMAL | + |
| NONMIN_ZERO | INFINITE | NON_MINIMAL | 0 |
| NONMIN_POS | INFINITE | NON_MINIMAL | + |

**Зауваження 11.3.1a.** Для FIXED і PERIODIC `MinCode = MINIMAL` випливає з леми 11.0: ω — один цикл, а один цикл мінімальний. Це узгоджено з фактичним `Min_D(ω) = MINIMAL`.

**Означення 11.3.2 (метрика d_Ω_traj).** Для пар (S, a), (S′, a′):

```text
d_Ω_traj((S, a), (S′, a′)) := # { i ∈ {1,2,3,4} : code_i(S, a) ≠ code_i(S′, a′) }
```

Це відстань Геммінга на 12 кодах; вона є метрикою. DP-f.

### 11.4. Лема про вкладення, D5 і W5

**Лема 11.8 (E).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна **сюр'єктивна**. Константне правило κ_c(s) := c, R_Y := {κ_c : c ∈ Y}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна, тобто (H) виконано;
2. Граф G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, і pr₁ : G → Y задає спряження між D∞|G і T;
3. для x₀ = (c, κ_{T(c)}): ω(x₀) ↔ ω_T(c), h_top(D∞|G) = h_top(T), Min(G) = Min(T), і x₀ ATTAINED ⇔ ∃n: Tⁿ(c) ∈ ω_T(c).

DP-f. *Доведення.* d_ℛ(κ_c, κ_{c'}) = d_S(c, c'), тож R_Y ізометрична копія Y (компактна), константи 1-ліпшицеві; g∞ = (c ↦ κ_c)∘T∘(c ↦ κ_c)⁻¹ не залежить від s і неперервна. G — граф неперервної функції на компакті, тому компактний, і pr₁ — гомеоморфізм G → Y. D∞(c, κ_{T(c)}) = (κ_{T(c)}(c), g∞(κ_{T(c)}, c)) = (T(c), κ_{T(T(c))}) ∈ G, тож D∞[G] ⊆ G і pr₁∘D∞ = T∘pr₁. Для G ⊆ D∞[G]: кожна точка (d, κ_{T(d)}) ∈ G дорівнює D∞(c, κ_{T(c)}) для c з T(c) = d, що існує, бо T сюр'єктивна. Спряженість зберігає ω-границі, ентропію, мінімальність і досяжність: нехай h : G → Y — гомеоморфізм pr₁ із h∘D∞ = T∘h. Тоді h[ω(x)] = ω(h x); мінімальність: h переводить замкнені інваріантні підмножини в замкнені інваріантні; досяжність: x_n ∈ ω(x) ⇔ h(x_n) ∈ ω(h x); ентропія: h рівномірно неперервний на компакті (і h⁻¹), тому (n, ε)-роздільні множини переходять у (n, δ)-роздільні й навпаки. ∎

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {α, β}^ℕ з h_top(σ|Z) > 0.

*Посилання.*

- Grillenberger, C. (1973). Constructions of strictly ergodic systems I. *Z. Wahrscheinlichkeitstheorie verw. Geb.* **25**, 323–334. Містить конструкцію строго ергодичних (отже, мінімальних) підзсувів на двох символах з додатною топологічною ентропією.
- Jewett, R. I. (1970). The prevalence of uniquely ergodic systems. *J. Math. Mech.* **19**, 717–729.
- Krieger, W. (1972). On unique ergodicity. *Proc. Sixth Berkeley Symp. Math. Statist. Probab.*, 327–346.

Перехід від двостороннього підзсуву Z₂ ⊆ {α, β}^ℤ до одностороннього Z ⊆ {α, β}^ℕ через праву половину: мінімальність зберігається (права половина мінімальної системи мінімальна); h_top зберігається (топологічна ентропія підзсуву дорівнює ентропії його правої половини). **Цей крок залишається НЕ ПЕРЕВІРЕНО автором**; твердження D5 — DP-f за EXT-1 із цим застереженням.

**Твердження 11.9 (D5, MIN_POS × ATTAINED).** За EXT-1: Y := t[Z], T := t∘σ∘t⁻¹. Зсув на мінімальній нескінченній Z сюр'єктивний, тож лема E застосовна. Для будь-якого c ∈ Y точка x₀ = (c, κ_{T(c)}) має ω(x₀) = G (мінімальна, нескінченна, h_top > 0) і x₀ ∈ G, отже MIN_POS × ATTAINED; g∞ ≠ π_R. Система задовольняє (H). DP-f за EXT-1.

**Твердження 11.10 (W5, NONMIN_POS × ATTAINED, без зовнішніх теорем).** Нехай Y := t[{α, β}^ℕ], T := t∘σ∘t⁻¹ (сюр'єктивний) і c = t(a), де a містить кожне скінченне слово нескінченно багато разів. Тоді для x₀ = (c, κ_{T(c)}): ω(x₀) = G, x₀ ∈ G → ATTAINED; G ≅ повний зсув, h_top = log 2 > 0; G не мінімальна (містить нерухому точку, що відповідає α^∞); нескінченна. DP-f. *Доведення.* Кожна точка z повного зсуву — гранична точка орбіти a, бо кожен префікс z довжини N виступає в a на нескінченно багато позиціях; тому ω_σ(a) — увесь простір і далі лема E. Відповідна a існує: перелік усіх скінченних слів. Ентропія (d — метрика 2⁻ᵏ простору {α, β}^ℕ, k — перший індекс розбіжності; на G переносимо через спряження, бо ентропія — інваріант): якщо x, y різняться на координаті i < n, то при ε = ¾ маємо d(σⁱx, σⁱy) = 1, тож s(n, ¾) ≥ 2ⁿ; точки з однаковим n-префіксом мають d_n ≤ ½ і не (n, ¾)-роздільні, тож s(n, ¾) ≤ 2ⁿ. Отже h_top = log 2. ∎

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення на повному просторі).** Нехай (X, d) — непорожній повний метричний простір, Φ : X → X задовольняє d(Φx, Φy) ≤ q · d(x, y) для деякого 0 ≤ q < 1 і всіх x, y ∈ X. Тоді Φ має єдину нерухому точку x* ∈ X, і для будь-якого x₀ ∈ X послідовність Φⁿ(x₀) збігається до x*. DP-f. *Доведення.* Єдиність: якщо Φx = x і Φy = y, то d(x, y) = d(Φx, Φy) ≤ q · d(x, y), звідки (1 − q) d(x, y) ≤ 0 і d(x, y) = 0. Існування: для довільного x₀ ∈ X послідовність x_n := Φⁿ(x₀) задовольняє d(x_n, x_{n+1}) ≤ qⁿ · d(x₀, x₁), тож для m > n: d(x_n, x_m) ≤ qⁿ · d(x₀, x₁)/(1 − q) → 0 при n → ∞. Отже (x_n) — Коші; X повний, тому x_n → x* ∈ X. Неперервність Φ дає Φx* = lim Φx_n = lim x_{n+1} = x*. ∎

**Прищеплення.** Для a ∈ A покладемо ρ_a(f) := node(f, leaf(a), leaf(a)), тобто ρ_a(f)(ε) = node, ρ_a(f)(1σ) = f(σ), ρ_a(f)(2) = ρ_a(f)(3) = leaf(a). Побудова коректна (T1–T4), ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, тож ρ_a ∈ ℛ₀ і стискаюче з коефіцієнтом ½.

- **W1 (FIXED × ATTAINED).** R = {ρ_a}, g∞ = π_R, x₀ = (p_a, ρ_a), де p_a — єдина нерухома точка ρ_a за лемою 11.11. DP-f.
- **W2 (FIXED × NONATTAINED).** Та сама система, x₀ = (s, ρ_a), s ≠ p_a. x_n = (ρ_aⁿ s, ρ_a) → (p_a, ρ_a), тож ω = {(p_a, ρ_a)}. У ω точка потрапила б на кроці n лише при ρ_aⁿ s = p_a = ρ_aⁿ p_a, що за ін'єктивністю дає s = p_a. DP-f.
- **W3 (PERIODIC, обидва).** R = {ρ_a, ρ_b}, a ≠ b, g∞(ρ_a, s) = ρ_b, g∞(ρ_b, s) = ρ_a. Φ := ρ_b∘ρ_a стискаюче з коефіцієнтом ¼; за лемою 11.11 має єдину нерухому точку q. Цикл {(q, ρ_a), (ρ_a q, ρ_b)} довжини 2 (точки різні, бо ρ_a ≠ ρ_b). ATTAINED: старт на циклі. NONATTAINED: x₀ = (s, ρ_a), s ≠ q; x_{2k} = (Φᵏ s, ρ_a), x_{2k+1} = (ρ_a Φᵏ s, ρ_b); на циклі вони опинились б лише при Φᵏ s = q, що за ін'єктивністю Φ і ρ_a дає s = q. DP-f.
- **W4 (MIN_ZERO × ATTAINED; одометр).** Нехай O — одометр a ↦ a + 1 (з переносом вправо) на {α, β}^ℕ при α = 0, β = 1. Це гомеоморфізм, ізометрія за метрикою 2^{−k}, мінімальний і без періодичних точок. Лема E з Y = t[{α, β}^ℕ], T = t∘O∘t⁻¹ дає G, на якій D∞ спряжене з O: мінімальна, нескінченна, h_top = 0 за D3, ATTAINED. Це й **C4b**. DP-f. *Властивості O.* Ізометрія: якщо a, b збігаються на координатах < k і різняться на k, то перенос у координату k при додаванні 1 однаковий для обох. Мінімальність: число з перших n координат a + m дорівнює (N_n(a) + m) mod 2ⁿ, тому орбіта проходить усі 2ⁿ слів довжини n — щільна. Непорожня замкнена інваріантна множина містить орбіту, отже збігається з усім простором. Періодичних точок немає: скінченна орбіта була б замкненою власною інваріантною підмножиною.
