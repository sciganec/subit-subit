## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** Для кожного ŝ ∈ Q₀: m(ŝ) < ∞. DP-f (Діріхле).

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. DP-f.

**Твердження 3.1.3 (P3, точний режим; P-41).** Нехай N := #Q₀. Алгоритм першого повтору:

```text
вхід: s₀ ∈ Q₀
visited : Map<State, ℕ> := ∅
s := s₀

для n := 0, …, N:
    якщо s ∈ visited:
        m := visited[s]
        p := n − m
        cycle := (s_m, …, s_{n−1})
        повернути COMPUTED(class(m, p), m, p, cycle)

    visited[s] := n
    якщо n < N:
        s := D₀(s)
```

Завжди завершується з `COMPUTED`, а m і p збігаються з означеннями §3.1. **DP-f.**

*Доведення.* Множина Q₀ містить N станів, а алгоритм перевіряє послідовно N + 1 станів s₀, …, s_N. За принципом Діріхле принаймні один стан повториться. Алгоритм повертає результат при першому повторі: індекс попередньої появи m є початком циклу, а p = n − m — його довжина. Якби існував раніший початок циклу або коротший період, алгоритм знайшов би повтор раніше. Тому повернені m і p мінімальні та відповідають означенням. ∎

**Твердження 3.1.4 (P3′, бюджетований режим; P-41).** За бюджету N_max переходів алгоритм перевіряє s₀, …, s_{N_max}. Якщо повтору не виявлено, він повертає `RESOURCE_EXCEEDED`, що не є класифікацією. **DP-f.**

*Доведення.* Якщо повтор знайдений до вичерпання бюджету, результат коректний за P3. Інакше переглянуті стани попарно різні, але цього недостатньо, щоб установити повний період орбіти. Тому результат позначається `RESOURCE_EXCEEDED`, а не FIXED, PERIODIC чи PREPERIODIC. Гілка досяжна, наприклад, для 64-циклу, утвореного однією циклічною перестановкою S₀ при бюджеті 63 переходи. ∎

*Уточнення.* Недостатній горизонт не означає, що `RESOURCE_EXCEEDED` виникне для кожної системи: повтор може знайтися раніше за вичерпання бюджету.

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H). Для ŝ ∈ S∞ × R:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. DP-f.

**ВІДКЛИКАНО:** використання Ω_point (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. P ⊆ K — непорожня, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. DP-f.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. DP-f.

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна; (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне.

**Означення 4.3.0 (топологічна ентропія).** Метрика Боуена d_n(x, y) := max_{0 ≤ i < n} d(Dⁱx, Dⁱy), n ≥ 1. E ⊆ P є **(n, ε)-розділеною**, якщо для різних x, y ∈ E: d_n(x, y) > ε. s(n, ε) — максимальна потужність такої множини.

```text
h_top(D) := lim_{ε→0⁺} limsup_{n→∞} (1/n) log s(n, ε).
```

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** NOT_APPLICABLE ≠ NON_CHAOTIC.

**Застереження 4.3.3.** Хаотичність = h_top > 0; мінімальність — окрема ознака Min.

### 4.4. Одне значення CHAOTIC

IsChaotic_D(P) :⇔ ChaosStatus_D(P) = CHAOTIC; CHAOTIC_ω(τ) :⇔ IsChaotic_D(ω(τ)). CHAOTIC_set — лише назва нижнього елемента Ω.

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL_IMAGE ⇔ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. DP-f.

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. DP-f.

**Твердження 4.5.3 (C4).**

- **(C4a) DP-f.** Сюр'єкція скінченної P на себе є бієкцією, тож D|P — перестановка; кожна точка перестановки періодична. ∎
- **(C4b) DP-f.** Одометр O з W4 (§11.6) є бієкцією нескінченної множини B без періодичних точок. ∎
- **(C4c) DP-f.** Односторонній зсув σ(x)ₙ = xₙ₊₁ на {0,1}^ℕ сюр'єктивний (прообрази x: 0x і 1x), не ін'єктивний. ∎

## 5. Алгебра Ω і проєкція π_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC
            < PERIODIC_SET < INVARIANT_DYNAMIC < INVARIANT_FIXED
```

**Означення 5.2 (D_class).** D_class := { Classify⁺_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }.

**Означення 5.3 (π_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. DP-f.

**Твердження 5.5 (C5b, P-42).** Образ π_Ω у D_class складається з усіх шести елементів Ω. DP-f.

*Свідки.* INVARIANT_FIXED: P = {p}. INVARIANT_DYNAMIC: 2-цикл. PERIODIC_SET: P = {a, c} у 4-циклі. EVENTUALLY_PERIODIC: P = {x₀} на x₀ → x₁ → x₂ → x₁. CHAOTIC_set: G з W5 (§11.4).

**Перевірка свідка APERIODIC_NON_CHAOTIC (P-42).** Нехай a ∈ {0,1}^ℕ, причому a_n = 1 тоді й лише тоді, коли n є степенем двійки, та P := {σⁿ(a) : n ≥ 0}.

Проміжки між послідовними одиницями необмежено зростають, тому a не є зрештою періодичною. Якби σⁱ(a) = σʲ(a) для i < j, тоді a була б зрештою періодичною з періодом j − i. Отже всі σⁿ(a) попарно різні.

Для кожного k ≥ 0: σᵏ[P] = {σⁿ(a) : n ≥ k}. Через попарну різність зсувів це власна підмножина P, тому σᵐ[P] ≠ σⁿ[P] для будь-яких m < n. Отже μ(P) = ∞ та OrbitType(P) = APERIODIC.

Водночас σ^{2ᵏ+1}(a) → 0^∞: відстань до наступної одиниці зростає без обмеження. Точка 0^∞ не належить P (кожен зсув a містить нескінченно багато одиниць). Тому P не замкнена й не компактна, а передумова Π1 не виконується. Звідси ChaosStatus_D(P) = NOT_APPLICABLE.

Отже π_Ω повертає мітку APERIODIC_NON_CHAOTIC для цього свідка; назва мітки не є твердженням, що ChaosStatus = NON_CHAOTIC. ∎

**Зауваження 5.6.** APERIODIC_NON_CHAOTIC — втратна мітка.

**Застереження 5.6.1.** Для скінченної системи образ π_Ω не містить CHAOTIC_set.

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥.

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. DP-f.

**Застереження 5.9.** π_Ω втратна.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. DP-s.

**Твердження 6.1.2 (M2, M6).** □U → ↺U. DP-f.

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** (□_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇_H U)(x) := ⋁ₙ≥0 U(Dⁿx); ¬_H a := a → ⊥.

### 11.4. Лема про вкладення, D5 і W5

**Лема 11.8 (E).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна сюр'єктивна. κ_c(s) := c, R_Y := {κ_c}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна (H виконано);
2. G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. ω(x₀) ↔ ω_T(c), h_top(D∞|G) = h_top(T), Min(G) = Min(T), x₀ ATTAINED ⇔ ∃n: Tⁿ(c) ∈ ω_T(c).

**DP-f.**

*Доведення.* j : Y → ℛ₀, j(c) := κ_c. d_ℛ(κ_c, κ_{c'}) = d_S(c, c'), тож j — ізометричне вкладення; R_Y компактна і міститься в ℛ₀. g∞ відповідає T і не залежить від s. Отже (H) виконано.

Граф G компактний; h := pr₁|G — гомеоморфізм. D∞[G] ⊆ G; навпаки, через сюр'єктивність T для (d, κ_{T(d)}) ∈ G існує c з T(c) = d, звідки D∞(c, κ_{T(c)}) = (d, κ_{T(d)}). Отже D∞[G] = G і h ∘ D∞|G = T ∘ h. Мінімальність, ω-границі та ATTAINED зберігаються через h.

**Збереження топологічної ентропії (P-39).** Нехай h : G → Y — гомеоморфізм, який спряжує D∞|G і T.

Для кожного ε_Y > 0 рівномірна неперервність h дає δ_G > 0, таке що d_G(x, x') < δ_G тягне d_Y(h(x), h(x')) < ε_Y. За контрапозицією, якщо d_Y(u, v) > ε_Y, то d_G(h⁻¹u, h⁻¹v) ≥ δ_G > δ_G/2. Застосовуючи цю нерівність до траєкторій, отримуємо s_Y(n, ε_Y) ≤ s_G(n, δ_G/2), звідки h_top(T) ≤ h_top(D∞|G).

Навпаки, для кожного ε_G > 0 рівномірна неперервність h⁻¹ дає δ_Y > 0, таке що d_Y(u, v) < δ_Y тягне d_G(h⁻¹u, h⁻¹v) < ε_G. Тому кожна пара, розділена в G на відстань понад ε_G на деякому кроці, після застосування h залишається розділеною в Y на відстань понад δ_Y/2. Отже s_G(n, ε_G) ≤ s_Y(n, δ_Y/2), звідки h_top(D∞|G) ≤ h_top(T). Обидві нерівності дають h_top(D∞|G) = h_top(T). ∎

Бібліографічний орієнтир: C. Grillenberger, "Construction of strictly ergodic systems I. Given entropy", *Z. Wahrscheinlichkeitstheorie verw. Geb.* 25 (1973), 323–334. E. Glasner and B. Weiss, "Strictly ergodic, uniform positive entropy models", *Bull. Soc. Math. France* 122(3) (1994), 399–412, DOI 10.24033/bsmf.2239.

**Застереження про точну форму EXT-1.** Бібліографічний запис сам собою не замінює аргументу для саме одностороннього двійкового підзсуву Z.

**Твердження 11.10 (W5, P-37).** Нехай C := {α, β}^ℕ, σ : C → C — односторонній повний зсув, t : C → S∞ — вкладення з §9.5, Y := t[C], T := t ∘ σ ∘ t⁻¹. Виберімо a ∈ C, у якому кожне скінченне слово над {α, β} трапляється нескінченно багато разів, і c := t(a). У системі леми E, для x₀ := (c, κ_{T(c)}) маємо ω(x₀) = G, x₀ ∈ G, тому ATTAINED; крім того, G нескінченна, не мінімальна, а h_top(D∞|G) = log 2 > 0. Отже реалізовано NONMIN_POS × ATTAINED і CHAOTIC_set. **DP-f.**

*Доведення.*

**1. Побудова точки з повною ω-границею.** Існування a випливає з побудови: для кожного m перелічимо всі скінченні слова довжини не більшої за m і послідовно конкатенуємо ці списки для m = 1, 2, 3, … Кожне фіксоване скінченне слово з'являється в кожному достатньо пізньому списку, отже нескінченно багато разів. Для довільного z ∈ C і кожного N префікс z довжини N з'являється в a на нескінченно багатьох позиціях. Тому існує послідовність n_j → ∞, для якої σⁿʲ(a) → z. Отже ω_σ(a) = C. За спряженням t та лемою E одержуємо ω(x₀) = G. Оскільки x₀ ∈ G, маємо x₀ ∈ ω(x₀), тобто ATTAINED.

**2. Ентропія повного зсуву.** Метрика d_C(x, y) := 2⁻ᵏ (k — індекс першої розбіжності), d_C(x, x) := 0. Метрика Боуена d_n(x, y) := max_{0 ≤ i < n} d_C(σⁱx, σⁱy).

*Нижня оцінка.* Для ε = ¾ виберімо по одному представнику кожного з 2ⁿ різних префіксів довжини n. Будь-які два представники мають різні символи на деякій координаті k < n. Після зсуву σᵏ їхня відстань дорівнює 1. Отже множина є (n, ¾)-розділеною й s(n, ¾) ≥ 2ⁿ. Якщо дві послідовності мають однаковий префікс довжини n, то для кожного i < n їхні зсуви збігаються щонайменше на першому символі; тому d_n ≤ ½ < ¾. Отже s(n, ¾) ≤ 2ⁿ. Таким чином s(n, ¾) = 2ⁿ і h_top(σ) ≥ log 2.

*Верхня оцінка.* Нехай ε > 0. Виберімо L ≥ 0 так, щоб 2⁻⁽ᴸ⁺¹⁾ < ε. Якщо дві послідовності збігаються на перших n + L символах, то після будь-якого зсуву σⁱ (0 ≤ i < n) вони збігаються щонайменше на перших L + 1 символах. Тому d_n(x, y) ≤ 2⁻⁽ᴸ⁺¹⁾ < ε. Отже в (n, ε)-розділеній множині не може бути двох послідовностей з однаковим префіксом довжини n + L. Кількість таких префіксів дорівнює 2ⁿ⁺ᴸ, тому s(n, ε) ≤ 2ⁿ⁺ᴸ. Звідси

```text
limsup_{n→∞} (1/n) log s(n, ε) ≤ log 2,
```

оскільки L фіксоване для обраного ε. Переходячи до ε → 0⁺, одержуємо h_top(σ) ≤ log 2. Разом із нижньою оцінкою: h_top(σ) = log 2.

**3. Перенесення на SUBIT.** За лемою E система D∞|G топологічно спряжена з σ. Тому h_top(D∞|G) = log 2. Простір G не мінімальний: він містить нерухому точку, що відповідає α^∞, але не є одноточковою множиною. Отже ω(x₀) = G — нескінченна, немінімальна, з додатною ентропією.

Таким чином реалізовано NONMIN_POS × ATTAINED і CHAOTIC_set без використання EXT-1. ∎

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення).** (X, d) — непорожній повний метричний простір, Φ : X → X, d(Φ(x), Φ(y)) ≤ q·d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x*, і Φⁿ(x₀) → x*. **DP-f.**

**Прищеплення.** Для a ∈ A: ρ_a(f) := node(f, leaf(a), leaf(a)). ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, ρ_a ∈ ℛ₀, стискаюче з коефіцієнтом ½.

**W1 (FIXED × ATTAINED).** За лемою 11.11 ρ_a має єдину нерухому точку p_a. При R = {ρ_a}, g∞ = π_R: D∞(p_a, ρ_a) = (p_a, ρ_a). Тому ω(x₀) = {(p_a, ρ_a)} і x₀ ∈ ω(x₀), тобто ATTAINED. **DP-f.**

**W2 (FIXED × NONATTAINED).** Візьмемо s ≠ p_a та x₀ = (s, ρ_a). xₙ = (ρ_aⁿ(s), ρ_a) → (p_a, ρ_a), тому ω(x₀) = {(p_a, ρ_a)}. Якщо траєкторія досягла б цієї точки на кроці n, то ρ_aⁿ(s) = p_a = ρ_aⁿ(p_a). Оскільки ρ_a ін'єктивне, s = p_a — суперечність. Отже NONATTAINED. **DP-f.**

**W3 (PERIODIC × ATTAINED/NONATTAINED; P-40).** Нехай a ≠ b, R = {ρ_a, ρ_b}, g∞ чергує ці два правила. Φ := ρ_b ∘ ρ_a стискаюче з коефіцієнтом ¼; за лемою 11.11 має єдину нерухому точку q. Визначимо z₀ := (q, ρ_a), z₁ := (ρ_a(q), ρ_b). Тоді D∞(z₀) = z₁ і D∞(z₁) = z₀, причому z₀ ≠ z₁ (різні координати правил). Старт на цьому циклі дає PERIODIC × ATTAINED.

Для NONATTAINED візьмемо x₀ = (s, ρ_a), де s ≠ q. Тоді x₂ₖ = (Φᵏ(s), ρ_a), x₂ₖ₊₁ = (ρ_a(Φᵏ(s)), ρ_b). Оскільки Φ стискаюче, x₂ₖ → z₀, x₂ₖ₊₁ → z₁; тому ω(x₀) = {z₀, z₁}.

Якби траєкторія досягла циклу за скінченну кількість кроків, то на парному кроці 2k мало б виконуватися Φᵏ(s) = q. На непарному кроці 2k+1 мало б виконуватися ρ_a(Φᵏ(s)) = ρ_a(q); через ін'єктивність ρ_a це знову дає Φᵏ(s) = q. В обох випадках Φᵏ(s) = Φᵏ(q). Оскільки Φ — композиція ін'єктивних прищеплень, Φ ін'єктивне, тому s = q — суперечність із вибором s ≠ q. Отже траєкторія не досягає циклу, тобто NONATTAINED. **DP-f.** ∎

**W4 (MIN_ZERO × ATTAINED; P-38).** Нехай B := {0,1}^ℕ, C := {α, β}^ℕ (α ≠ β ∈ A). Нехай O : B → B — додавання 1 у двійковому записі з переносом від координати 0 праворуч. Нехай enc_αβ : B → C — координатна бієкція: enc_αβ(a)ᵢ = α при aᵢ = 0, enc_αβ(a)ᵢ = β при aᵢ = 1. Визначимо Õ := enc_αβ ∘ O ∘ enc_αβ⁻¹ : C → C. Нехай t : C → S∞ — вкладення §9.5, Y := t[C], і T := t ∘ Õ ∘ t⁻¹ : Y → Y.

**Ізометричність O.** Послідовність a інтерпретуємо як 2-адичне число A = Σᵢ≥₀ aᵢ2ⁱ. Відображення O додає 1, обернене — віднімає 1. Якщо a ≠ b, а k — перший індекс розбіжності, то A ≡ B (mod 2ᵏ), але A ≢ B (mod 2ᵏ⁺¹). Додавання 1 не змінює різниці A − B, тому A+1 і B+1 так само збігаються за модулем 2ᵏ, але не за модулем 2ᵏ⁺¹. Отже перша розбіжність O(a), O(b) залишається на координаті k, і d_B(O(a), O(b)) = d_B(a, b).

**Мінімальність O.** Для кожного n перші n координат Oᵐ(a) відповідають числу (N_n(a) + m) mod 2ⁿ, де N_n(a) — число, утворене першими n координатами a. Коли m проходить 0, …, 2ⁿ−1, отримуємо всі 2ⁿ можливих префіксів. Тому кожна орбіта щільна в B. Будь-яка непорожня замкнена Q з O[Q] ⊆ Q містить повну щільну орбіту, отже Q = B. Система мінімальна.

**Відсутність періодичних точок.** Якщо Oᵖ(a) = a для деякого p ≥ 1, тоді додавання p залишає всі перші n координат незмінними. Отже p ≡ 0 (mod 2ⁿ) для кожного n, що неможливо для фіксованого додатного p. Тому періодичних точок немає.

**Завершення.** За координатним кодуванням enc_αβ та вкладенням t відображення T на Y є ізометрією відносно d_S. За D3 ентропія h_top(T) = 0. Застосовуючи лему E, отримуємо h_top(D∞|G) = h_top(T) = 0. Лема E також переносить мінімальність і відсутність періодичних точок на G.

Тому G є нескінченною мінімальною ω-границею з нульовою ентропією. Для кожного x₀ ∈ G маємо ω(x₀) = G та x₀ ∈ ω(x₀), отже реалізовано MIN_ZERO × ATTAINED. **DP-f.** ∎
