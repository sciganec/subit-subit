## 1. Алфавіт і простір S₀

**Означення 1.1 (A1).** A = {00, 01, 10, 11}, 4 елементи.

| Код | Белнап | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 10 | T | ME | EAST | SPRING |
| 11 | B | WE | SOUTH | SUMMER |
| 01 | F | YOU | WEST | AUTUMN |
| 00 | N | THEY | NORTH | WINTER |

Порядок істинності: F < N < T і F < B < T. Порядок інформації: N < F < B і N < T < B. Властивості білаттису не переносяться на динаміку S∞ без окремого означення. **ВИЗНАЧЕНО.**

**Означення 1.2 (A2).** S₀ = A × A × A, 64 стани. Стан із бітами b₁…b₆ має код

```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

**Твердження 1.3 (A3; P-58).** code6 — бієкція S₀ → {0, …, 63}. **DP-f.**

*Доведення.* Кожний елемент S₀ = A³ однозначно визначає слово з шести бітів. Функція `code6` інтерпретує це слово як двійковий запис числа від 0 до 63. Різні шестибітні слова задають різні числа, а кожне число з цього діапазону має рівно один шестибітний запис. Отже, `code6` — бієкція. ∎

Приклади: 101010 = ME/EAST/SPRING = 42; 111111 = 63; 010001 = YOU/NORTH/AUTUMN = 17.

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ). Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`.

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори не входять до цієї редакції; для них потрібен окремий формальний розділ, якого тут не визначено.

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. **ВИЗНАЧЕНО.**

**Твердження 2.4 (A4).** Кожний автономний скінченний автомат (Q, δ) із непорожнім Q, #Q ≤ 64, тотальною δ : Q → Q і без вхідного алфавіту вкладається в SUBIT⁺. **DP-f.**

*Доведення.* Нехай (Q, δ) — скінченний непорожній автомат з |Q| ≤ 64. Виберемо ін'єкцію i : Q ↪ S₀. Побудуємо ρ : S₀ → S₀: ρ(i(q)) = i(δ(q)) для q ∈ Q; на решті S₀ визначимо ρ довільно. Покладемо `ℛ_fin` = {ρ}, g₀(ρ, s) = ρ. Тоді e(q) := (i(q), ρ) задовольняє

```text
D₀(e(q)) = (ρ(i(q)), ρ) = (i(δ(q)), ρ) = e(δ(q)).
```

Отже e ін'єктивне та зберігає перехід автомата. Образ e[Q] — інваріантна підсистема, ізоморфна (Q, δ). ∎

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** Для кожного ŝ ∈ Q₀: m(ŝ) < ∞. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Принцип Діріхле для #Q₀ + 1 станів дає повтор.

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. **НЕ ПІДТВЕРДЖЕНО.**

**Твердження 3.1.3 (P3, точний режим).**

```text
вхід: s₀ ∈ Q₀
visited : Map<State, ℕ> := ∅
states  : Array<State> := []
s := s₀

для n := 0, …, N (N := #Q₀):
    якщо s ∈ visited:
        m := visited[s]; p := n − m; cycle := states[m:n]
        повернути COMPUTED(class(m, p), m, p, cycle)
    visited[s] := n
    states.append(s)
    якщо n < N: s := D₀(s)
```

де `class(m, p)` визначено: `FIXED`, якщо m = 0, p = 1; `PERIODIC(p)`, якщо m = 0, p ≥ 2; `PREPERIODIC(m, p)`, якщо m ≥ 1.

**НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Принцип Діріхле гарантує повтор не пізніше кроку N; перший повтор дає мінімальні m, p.

**Твердження 3.1.4 (P3′, бюджетований режим; P-61).**

```text
вхід: s₀ ∈ Q₀, N_max ∈ ℕ
visited : Map<State, ℕ> := ∅
states  : Array<State> := []
s := s₀

для n := 0, …, N_max:
    якщо s ∈ visited:
        m := visited[s]
        p := n − m
        cycle := states[m:n]
        повернути COMPUTED(class(m, p), m, p, cycle)

    visited[s] := n
    states.append(s)

    якщо n = N_max:
        повернути RESOURCE_EXCEEDED

    s := D₀(s)
```

**Уточнення.** Умова N_max < #Q₀ сама по собі не гарантує повернення `RESOURCE_EXCEEDED` для кожної системи: повтор може знайтися раніше. Коректне формулювання — гілка `RESOURCE_EXCEEDED` може бути досяжною, наприклад, на орбіті циклічної перестановки довжини 64 при N_max < 64 і `ℛ_fin` = {ρ}.

**НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H). Для ŝ ∈ S∞ × R:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. P ⊆ K — непорожня, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. **DP-f (P-73).**

*Доведення.* Розгляньмо послідовність множин Pₙ := Dⁿ[P]. Якщо жодні два Pₙ не збігаються, то μ(P) = ∞ і P належить класу APERIODIC. Інакше μ(P) — найменший індекс, з якого Pₘ повторюється на деякому пізнішому індексі, а π(P) — найменша додатна довжина відповідного повтору.

Якщо μ(P) = 0 і D[P] = P, то P інваріантна; залежно від того, чи всі точки P нерухомі, маємо відповідно INVARIANT_FIXED або INVARIANT_DYNAMIC. Якщо μ(P) = 0 і D[P] ≠ P, то p_set(P) скінченне й не менше 2, отже маємо PERIODIC_SET. Якщо 1 ≤ μ(P) < ∞, то π(P) = 1 дає EVENTUALLY_FIXED, а π(P) ≥ 2 дає EVENTUALLY_PERIODIC. Ці випадки взаємно виключні через різні умови на μ, π, інваріантність і рух точок; вони охоплюють усі можливі значення μ та π. ∎

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  D[P] ∩ P ≠ ∅, D[P] ⊄ P і P ⊄ D[P]
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. **DP-f (P-73).**

*Доведення.* Для множин D[P] і P рівно один із таких випадків має місце: вони рівні; вони диз'юнктні; D[P] є власною підмножиною P; P є власною підмножиною D[P]; або множини перетинаються, але жодна не містить іншу. Це п'ять попарно неперетинних і вичерпних випадків, наведених у визначенні InclusionType. ∎

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна; (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне.

**Означення 4.3.0 (топологічна ентропія).** Метрика Боуена d_n(x, y) := max_{0 ≤ i < n} d(Dⁱx, Dⁱy), n ≥ 1. E ⊆ P є **(n, ε)-розділеною**, якщо для різних x, y ∈ E: d_n(x, y) > ε. s(n, ε) — максимальна потужність такої множини.

```text
h_top(D) := lim_{ε→0⁺} limsup_{n→∞} (1/n) log s(n, ε).
```

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** NOT_APPLICABLE ≠ NON_CHAOTIC.

**Застереження 4.3.3.** Хаотичність = h_top > 0; мінімальність — окрема ознака Min.

### 4.4. Одне значення CHAOTIC

IsChaotic_D(P) :⇔ ChaosStatus_D(P) = CHAOTIC; CHAOTIC_ω(τ) :⇔ IsChaotic_D(ω(τ)). CHAOTIC_set — лише назва нижнього елемента Ω.

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).**

(a) `InclusionType = EQUAL_IMAGE` ⇔ `OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}`.

(b) `ChaosStatus = CHAOTIC` ⇒ `OrbitType = INVARIANT_DYNAMIC`.

(c) `Min = MINIMAL` ⇒ `OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}`.

**DP-f.**

*Доведення.* (a) випливає безпосередньо з означень `InclusionType` та `OrbitType`. Для (b): якщо D[P] = P і всі точки P нерухомі, то D|_P — тотожне відображення, його топологічна ентропія дорівнює нулю, а не є додатною. Для (c): значення `MINIMAL` можливе лише за виконання передумов Π1–Π3, зокрема D[P] = P. Тому `OrbitType` — один із двох інваріантних класів. ∎

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. **DP-f.**

*Доведення.* Якщо передумови Π1–Π3 не виконано, статус не може бути `CHAOTIC`, оскільки він дорівнює `NOT_APPLICABLE`. Якщо їх виконано та K скінченна, тоді P ⊆ K також скінченна, а D|_P : P → P є сюр'єкцією скінченної множини на себе, отже перестановкою. Тому s(n, ε) ≤ |P| для всіх n, ε, звідки h_top(D|_P) = 0. Отже, хаотичних множин у скінченному K немає. ∎

**Твердження 4.5.3 (C4; P-65, P-72).**

(a) Якщо P скінченна та D[P] = P, то D|P — бієкція; кожна точка періодична. **DP-f.**

(b) Для нескінченної P бієктивність не тягне періодичності. **DP-f (P-72).**

(c) Для нескінченної P сюр'єктивність не тягне ін'єктивності. **DP-f (P-72).**

*Доведення C4(a).* Оскільки D[P] = P, обмеження D|P є сюр'єктивним відображенням скінченної множини P на себе. Кожна сюр'єкція скінченної множини на себе є ін'єктивною, отже бієктивною. Будь-яка бієкція скінченної множини розкладається на неперетинні цикли; тому кожна точка P періодична.

*Доведення C4(b).* Нехай B := {0,1}^ℕ з 2-адичною метрикою d_B(a,b) := 2⁻ᵏ, де k — перший індекс розбіжності, а O : B → B — додавання 1 у 2-адичних координатах, як у W4 (§11.6). Додавання 1 є ізометрією цієї метрики: воно зберігає перший індекс розбіжності, бо різниця двох 2-адичних чисел не змінюється. O є бієкцією, оскільки його обернене відображення — віднімання 1. Припустімо, що Oᵖ(a) = a для деякого p ≥ 1. Для кожного n перші n координат тоді задовольняють (N_n(a)+p) mod 2ⁿ = N_n(a), отже p ≡ 0 (mod 2ⁿ). Це мало б виконуватися для всіх n, що неможливо для фіксованого додатного p. Отже, O не має періодичних точок: бієктивність на нескінченному P не гарантує періодичності.

*Доведення C4(c).* Нехай B := {0,1}^ℕ і σ : B → B — односторонній зсув σ(a₀,a₁,a₂,…) = (a₁,a₂,…). Він сюр'єктивний, бо кожна послідовність b має прообрази (0,b₀,b₁,…) та (1,b₀,b₁,…). Він не ін'єктивний, оскільки ці два різні прообрази мають однаковий образ. B нескінченний компактний метричний простір, а σ неперервний. ∎

## 5. Алгебра Ω і проєкція π_Ω

**Означення 5.1 (6-ланцюг).**

```text
CHAOTIC_set < APERIODIC_NON_CHAOTIC < EVENTUALLY_PERIODIC

```

**Означення 5.2 (D_class).** D_class := { Classify⁺_D(P) : (K, d, D) допустима, ∅ ≠ P ⊆ K }.

**Означення 5.3 (π_Ω).** Для (O, I, C, M):

```text
π_Ω = CHAOTIC_set            якщо C = CHAOTIC
    = APERIODIC_NON_CHAOTIC  якщо C ≠ CHAOTIC і O = APERIODIC
    = EVENTUALLY_PERIODIC    якщо C ≠ CHAOTIC і O ∈ {EVENTUALLY_FIXED, EVENTUALLY_PERIODIC}
    = PERIODIC_SET           якщо C ≠ CHAOTIC і O = PERIODIC_SET
    = INVARIANT_DYNAMIC      якщо C ≠ CHAOTIC і O = INVARIANT_DYNAMIC
    = INVARIANT_FIXED        якщо C ≠ CHAOTIC і O = INVARIANT_FIXED
```

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. **DP-f (P-73).**

*Доведення.* Нехай (O, I, C, M) ∈ D_class. Якщо C = CHAOTIC, π_Ω однозначно визначається першим рядком. Якщо C ≠ CHAOTIC, за C1 координата O має одне із шести значень OrbitType. Значення APERIODIC покривається другим рядком; EVENTUALLY_FIXED та EVENTUALLY_PERIODIC — третім; PERIODIC_SET — четвертим; INVARIANT_DYNAMIC — п'ятим; INVARIANT_FIXED — шостим. В усіх випадках визначено рівно одне значення π_Ω. Отже, π_Ω тотальна на D_class. ∎

**Твердження 5.5 (C5b; P-64, P-67, P-68).** Образ π_Ω у D_class складається з усіх шести елементів Ω. **DP-f.**

*Свідки.*

- **INVARIANT_FIXED.** K = {p}, D(p) = p, P = {p}. D[P] = P і D(x) = x. Classify⁺ = (INVARIANT_FIXED, EQUAL_IMAGE, NON_CHAOTIC, MINIMAL). π_Ω = INVARIANT_FIXED.
- **INVARIANT_DYNAMIC.** K = {x, y}, D(x) = y, D(y) = x, P = {x, y}. D[P] = P, D(x) ≠ x. Classify⁺ = (INVARIANT_DYNAMIC, EQUAL_IMAGE, NON_CHAOTIC, MINIMAL). π_Ω = INVARIANT_DYNAMIC.
- **PERIODIC_SET.** K = {a, b, c, d}, D — 4-цикл, P = {a, c}. D[P] = {b, d} ≠ P; D²[P] = {a, c} = P; p_set = 2. μ(P) = 0, D[P] ≠ P. Classify⁺ = (PERIODIC_SET, DISJOINT_IMAGE, NOT_APPLICABLE, NOT_APPLICABLE), оскільки D[P] ≠ P і Π2 не виконується. π_Ω = PERIODIC_SET.
- **EVENTUALLY_PERIODIC.** K = {x₀, x₁, x₂}, D(x₀) = x₁, D(x₁) = x₂, D(x₂) = x₁, P = {x₀}. D[P] = {x₁}, μ = 1, π = 2. Classify⁺ = (EVENTUALLY_PERIODIC, DISJOINT_IMAGE, NOT_APPLICABLE, NOT_APPLICABLE), оскільки D[P] ∩ P = ∅ і Π2 не виконується. π_Ω = EVENTUALLY_PERIODIC.
- **APERIODIC_NON_CHAOTIC.** K = {0,1}^ℕ, D = σ (зсув), a_n = 1 ⇔ n є степенем двійки, P = {σⁿ(a) : n ≥ 0}.

  *Перевірка.* Проміжки між послідовними одиницями необмежено зростають, тому a не є зрештою періодичною. Якби σⁱ(a) = σʲ(a) для i < j, то a була б зрештою періодичною з періодом j − i, суперечність. Отже всі σⁿ(a) попарно різні.

  Для кожного k ≥ 0: σᵏ[P] = {σⁿ(a) : n ≥ k}. Через попарну різність зсувів σᵏ[P] ⊊ P (бо σᵏ[P] не містить σ⁰(a), …, σᵏ⁻¹(a)). Тому всі σᵐ[P] при m ≥ 0 попарно різні, μ(P) = ∞.

  Водночас σ^{2ᵏ+1}(a) → 0^∞: відстань до наступної одиниці зростає без обмеження. Точка 0^∞ ∉ P (кожен зсув a містить нескінченно багато одиниць). Тому P не замкнена й не компактна; передумова Π1 не виконується; ChaosStatus_D(P) = NOT_APPLICABLE.

  Отже, Classify⁺ = (APERIODIC, STRICT_SUBIMAGE, NOT_APPLICABLE, NOT_APPLICABLE), оскільки P не компактна та Π1–Π3 не виконуються. π_Ω повертає APERIODIC_NON_CHAOTIC.
- **CHAOTIC_set.** Множина G з W5 (§11.4), розглянута як компактний динамічний простір (G, d̂|G, D∞|G). Вона інваріантна, має додатну топологічну ентропію та не є мінімальною; на G існують точки, які не є нерухомими. Тому `Classify⁺ = (INVARIANT_DYNAMIC, EQUAL_IMAGE, CHAOTIC, NON_MINIMAL)` і π_Ω = CHAOTIC_set.

Отже, усі шість елементів Ω лежать в образі π_Ω. ∎

**Зауваження 5.6.** APERIODIC_NON_CHAOTIC — втратна мітка: якщо μ(P) = ∞, то D[P] ≠ P, (Π2) не виконано, ChaosStatus = NOT_APPLICABLE. Тому поєднання «OrbitType = APERIODIC і ChaosStatus = NON_CHAOTIC» за означеннями неможливе.

**Застереження 5.6.1.** Для скінченної системи образ π_Ω не містить CHAOTIC_set.

**Означення 5.7 (алгебра Гейтінга).** Ω з ∧ = min, ∨ = max, a → b := ⊤ якщо a ≤ b, інакше b; ¬a := a → ⊥.

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга; виключене третє не виконується. **DP-f.**

*Доведення.* Оскільки Ω — ланцюг, операції ∧ = min і ∨ = max утворюють ґратку. Для заданої імплікації виконується умова Гейтінга a ∧ x ≤ b ⇔ x ≤ (a → b): якщо a ≤ b, обидві частини істинні для всіх x; якщо a > b, обидві еквівалентні x ≤ b. Отже, Ω — алгебра Гейтінга. Для кожного проміжного a ∈ Ω маємо ¬a = ⊥, тому a ∨ ¬a = a ≠ ⊤. Закон виключеного третього не є загальним законом цієї алгебри. ∎

**Застереження 5.9.** π_Ω втратна.

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

Для довільної динамічної системи (K, D), x ∈ K, U ⊆ K; ¬U := K ∖ U (класичне доповнення, не тотожне ¬_H з §6.2):

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

`F_tree` — виключно функтор `X ↦ A ⊔ X³`; динаміка позначається буквою D.

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. Позначки LTL-D1…LTL-D3 належать лише цьому переліку; D1, D3 тощо в §11 — окремі динамічні твердження:

```text
(X1) X U → ◇⁺ U                  (X2) X U ∧ X V ↔ X(U ∧ V)
(X3) X U ∨ X V ↔ X(U ∨ V)       (LTL-D1) ◇U ↔ U ∨ X ◇U
(LTL-D2) ◇⁺ U ↔ X ◇U                  (LTL-D3) ◇U ↔ U ∨ ◇⁺ U
(B1) □U ↔ U ∧ X □U                (B2) □U → U
(B3) □U → X □U                    (B4) □U → ◇U
(B5) □(U → V) → (□U → □V)       (R1) ↺U ↔ ◇⁺(X U)
(R2) ↺U → ◇⁺ U                  (M4) ◇U ↔ ¬□¬U
```

**DP-s.** *Схема.* Редукція до послідовностей u_n := [Dⁿ(x) ∈ U] дає тавтології кванторів по ℕ; повний розбір кожної з 14 аксіом у цій редакції скорочено до схеми.

**Твердження 6.1.2 (M2, M6; P-62).** □U → ↺U. **DP-f.**

*Доведення.* □U означає ∀n ≥ 0: Dⁿ(x) ∈ U. Зокрема, D²(x) ∈ U, тобто існує k = 2 > 1 з Dᵏ(x) ∈ U. Отже, ↺U виконується в x. ∎

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** Для предиката U : K → Ω: (□_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇_H U)(x) := ⋁ₙ≥0 U(Dⁿx) у решітці Ω; ¬_H a := a → ⊥ — псевдодоповнення в Ω (не тотожне класичному ¬ з §6.1).

**Твердження 6.2.2 (M3; P-62).** Рівність ◇_H U = ¬_H □_H ¬_H U у семантиці §6.2 хибна. **DP-f.**

*Контрмодель.* K = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY_PERIODIC, U(b) = CHAOTIC_set = ⊥.

Обчислення:

```text
(◇_H U)(a) = max_{n≥0} U(Dⁿ(a)) = max(EVENTUALLY_PERIODIC, CHAOTIC_set) = EVENTUALLY_PERIODIC.
(¬_H U)(a) = ⊥ (бо U(a) > ⊥).
(¬_H U)(b) = ⊤ (бо U(b) = ⊥).
(□_H ¬_H U)(a) = min_{n≥0} (¬_H U)(Dⁿ(a)) = min(⊥, ⊤) = ⊥.
(¬_H □_H ¬_H U)(a) = ⊤.
```

Оскільки EVENTUALLY_PERIODIC ≠ ⊤, рівність хибна. ∎

**Твердження 6.2.3 (Q6 закрито для §6.2).** M4 у гейтінговій семантиці §6.2 не виконується — це рівність із твердження 6.2.2. **DP-f.**

### 6.3. Динамічна теорія типів (P-78)

**Модель.** Нехай (K,D) — динамічна система, терми породжуються змінними та конструкцією наступника D(t), а інтерпретація термів задається оцінкою ν: `⟦x⟧ν := ν(x)` і `⟦D(t)⟧ν := D(⟦t⟧ν)`. Контекст Γ — множина припущень виду `x:U@τ`, де U ⊆ K, τ ∈ ℕ. Оцінка ν задовольняє Γ, якщо для кожного `x:U@τ` у Γ маємо `D^τ(⟦x⟧ν) ∈ U`.

**Семантика судження.**

```text
ν ⊨ t : U @ τ       ⇔ D^τ(⟦t⟧ν) ∈ U
ν ⊨ t : □U @ τ      ⇔ ∀n ≥ 0: D^{τ+n}(⟦t⟧ν) ∈ U
ν ⊨ t : ◇V @ τ      ⇔ ∃n ≥ 0: D^{τ+n}(⟦t⟧ν) ∈ V
Γ ⊨ t : U @ τ       ⇔ для кожної ν, що задовольняє Γ, ν ⊨ t : U @ τ
```

**Правила виведення.**

```text
Рефлексивність:
  Γ, x:U@τ ⊢ x : U @ τ

Еволюція часу:
  Γ ⊢ t : U @ τ       D[U] ⊆ V
  --------------------------------
  Γ ⊢ t : V @ (τ+1)

Перехід терма (еквівалентна форма):
  Γ ⊢ t : U @ τ       D[U] ⊆ V
  --------------------------------
  Γ ⊢ D(t) : V @ τ

Стабільність:
  Γ ⊢ t : U @ τ       D[U] ⊆ U
  --------------------------------
  Γ ⊢ t : □U @ τ

Потенційність:
  Γ ⊢ t : U @ τ       ∃k≥0: Dᵏ[U] ⊆ V
  --------------------------------------
  Γ ⊢ t : ◇V @ τ
```

**Уточнення.** Не можна одночасно застосовувати синтаксичний перехід D(t) та збільшувати τ на одиницю в одному й тому самому правилі: це врахувало б один крок динаміки двічі. Тому попередня форма `D(t):V@(τ+1)` замінена двома еквівалентними правилами вище.

**Твердження 6.3.1 (коректність правил).** За наведеної семантики кожне правило зберігає істинність суджень. **DP-f.**

*Доведення.* Рефлексивність випливає з означення того, що ν задовольняє Γ. Для еволюції часу покладемо x_τ := D^τ(⟦t⟧ν). Якщо x_τ ∈ U і D[U] ⊆ V, то x_{τ+1}=D(x_τ) ∈ V. Перехід терма еквівалентний цій самій рівності, бо `⟦D(t)⟧ν=D(⟦t⟧ν)`. Для стабільності індукція за n із D[U] ⊆ U дає Dⁿ(x_τ) ∈ U для всіх n ≥ 0, отже ν ⊨ t:□U@τ. Для потенційності існує k ≥ 0 з Dᵏ[U] ⊆ V; оскільки x_τ ∈ U, маємо Dᵏ(x_τ) ∈ V, а тому ν ⊨ t:◇V@τ. Усі правила семантично коректні. ∎

## 8. Dyn як категорія динамічних систем

**Означення 8.1.** Об'єкт Dyn — пара (S, f). Морфізм φ : (S, f) → (T, h) — φ ∘ f = h ∘ φ. Dyn₊ — повна підкатегорія з непорожніми S.

**Твердження 8.2 (K4).** Dyn ≅ Fun(Bℕ, Set) — прешейфовий топос. **DP-s.**

**Примітка 8.2.1.** Bℕ^op ≅ Bℕ, тому конвенція presheaf на C як Fun(C^op, Set) узгоджується з Fun(Bℕ, Set).

### 8.3. Час входу та об'єкт Ω_Dyn

```text
Ω_Dyn := ℕ ∪ {∞}, δ(n) := max(n − 1, 0) для n ∈ ℕ, δ(∞) := ∞.
```

Тоді (Ω_Dyn, δ) — об'єкт Dyn; distinguished truth value — 0. Дія моноїда ℕ: n·k := max(n − k, 0), ∞·k := ∞.

Нехай U ⊆ S — підоб'єкт (f[U] ⊆ U). Визначимо час входу

```text
χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U },
```

χ_U(x) := ∞, якщо орбіта x ніколи не входить у U.

### 8.4. Класифікатор підоб'єктів χ_U

**Твердження 8.4.** U ↦ χ_U — бієкція між підоб'єктами (S, f) та морфізмами (S, f) → (Ω_Dyn, δ). Обернене — U = χ⁻¹({0}). **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Еквіваріантність χ_U(f(x)) = δ(χ_U(x)) перевіряється розбором випадків χ_U(x) = 0, n ≥ 1, ∞; обернено — U = χ⁻¹({0}).

## 9. Простір S∞ = Tree∞

### 9.1. Означення

**Означення 9.1.** Pos := {1, 2, 3}^{<ω}, Λ := {None, node} ∪ {leaf(a) : a ∈ A}. Tree∞ — множина f : Pos → Λ, що задовольняють:

- (T1) f(ε) ≠ None;
- (T2) f(σ) = node ⇒ f(σ·i) ≠ None;
- (T3) f(σ) = leaf(a) ⇒ f(σ·i) = None;
- (T4) f(σ) = None ⇒ f(σ·τ) = None.

**Означення 9.1.1.** S∞ := Tree∞.

**Означення 9.1.2 (emb₃).** emb₃(a, b, c) := node(leaf(a), leaf(b), leaf(c)).

**Твердження 9.2 (T1).** Tree∞ — фінальна коалгебра F_tree(X) = A ⊔ X³. **DP-s.**

**Твердження 9.3 (T2).** emb₃ — ін'єкція A³ → S∞. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

### 9.2. Ψ і L_prod

```text
T₀ := { Leaf₀(a) : a ∈ A } ∪ { Bottom₀ }
Tₙ₊₁ := { Leafₙ₊₁(a) : a ∈ A } ∪ { Bottomₙ₊₁ } ∪ { Nodeₙ(t₁, t₂, t₃) : tᵢ ∈ Tₙ }

q₀ : T₁ → T₀:
    Leaf₁(a) ↦ Leaf₀(a),  Bottom₁ ↦ Bottom₀,  Node₀(t₁, t₂, t₃) ↦ Bottom₀

qₙ₊₁ : Tₙ₊₂ → Tₙ₊₁:
    Leafₙ₊₂(a) ↦ Leafₙ₊₁(a),
    Bottomₙ₊₂ ↦ Bottomₙ₊₁,
    Nodeₙ₊₁(t₁, t₂, t₃) ↦ Nodeₙ(qₙ(t₁), qₙ(t₂), qₙ(t₃))

U_c := { (tₙ) ∈ ∏ Tₙ : qₙ(tₙ₊₁) = tₙ для всіх n ≥ 0 }
LeafSeqs := { (Leafₙ(a))ₙ : a ∈ A }
```

**Означення 9.2.1 (NodeSeqs(X)).** Для X ⊆ U_c:

```text
NodeSeqs(X) := { t = (tₙ)_{n≥0} ∈ U_c :
                 t₀ = Bottom₀
                 ∧ ∃ u₁, u₂, u₃ ∈ X, ∀n ≥ 0:
                   tₙ₊₁ = Nodeₙ((u₁)ₙ, (u₂)ₙ, (u₃)ₙ) }
```

Квантор ∀n ≥ 0 застосовується до всіх рівнянь Node одночасно.

**Означення 9.2.2.** Ψ(X) := LeafSeqs ∪ NodeSeqs(X); L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }.

**Лема 9.3.1 (коректність Ψ).** Для кожного X ⊆ U_c: Ψ(X) ⊆ U_c; X ⊆ Y ⇒ Ψ(X) ⊆ Ψ(Y). **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Сумісність qₙ з Nodeₙ — індукція за n; монотонність Ψ очевидна з означення NodeSeqs.

**Твердження 9.4.** L_prod = Ψ(L_prod). **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

**Зауваження 9.5.** U_c строго більша за L_prod: (Bottomₙ)ₙ ∈ U_c ∖ L_prod.

### 9.3. d_n, at_n, lim_tree

```text
d₀(f) := Leaf₀(a) якщо f(ε) = leaf(a);  Bottom₀ якщо f(ε) = node
dₙ₊₁(f) := Leafₙ₊₁(a) якщо f(ε) = leaf(a)
dₙ₊₁(f) := Nodeₙ(dₙ(f₁), dₙ(f₂), dₙ(f₃)) якщо f(ε) = node

TΣ := Σₖ Tₖ  (пари (k, u), u ∈ Tₖ)
at_n : Tₙ → Pos → Option(TΣ)

at_n(t, ε) := Some((n, t))
at₀(t, i·τ) := None
atₙ₊₁(Leafₙ₊₁(a), i·τ) := None
atₙ₊₁(Bottomₙ₊₁, i·τ) := None
atₙ₊₁(Nodeₙ(u₁, u₂, u₃), i·τ) := atₙ(uᵢ, τ)
```

**Лема 9.6.** dₙ(f) ∈ Tₙ, qₙ(dₙ₊₁ f) = dₙ f; якщо at_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T_k. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Індукція за n і |σ|.

**Означення 9.7 (lim_tree).** Для t = (t_m) ∈ L_prod і σ ∈ Pos, m > |σ| розглядаємо at_m(t_m, σ). При m → ∞ стабілізується **коренева форма** at_m(t_m, σ): (Z) усе None; (L) кореневий конструктор Leaf із сталою міткою a; (N) кореневий конструктор Node. Індекс глибини та опис піддерева можуть змінюватися з m. lim_tree(t)(σ) := None, leaf(a), node відповідно до (Z), (L), (N).

**Твердження 9.8 (реконструкція).** (a) lim_tree(t) ∈ Tree∞; (b) p(f) := (dₙ f)ₙ ∈ L_prod і lim_tree(p(f)) = f; (c) p(lim_tree(t)) = t. **DP-s.**

### 9.4. Метрика d_S

```text
r_addr(f, g) := ∞ якщо f = g; min{ |σ| : f(σ) ≠ g(σ) } якщо f ≠ g
d_S(f, g)    := 0 якщо f = g; 2^{− r_addr(f, g)} якщо f ≠ g
r_app(f, g)  := min{ n ≥ 0 : dₙ(f) ≠ dₙ(g) }
```

**Лема 9.9.** r_app = r_addr. **DP-s.**

**Твердження 9.10 (T3).** d_S — ультраметрика. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Симетрія; r_addr(f, h) ≥ min(r_addr(f, g), r_addr(g, h)).

**Твердження 9.11 (T4).** Якщо f(ε) = g(ε) = node, то d_S(fᵢ, gᵢ) ≤ 2·d_S(f, g). **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

**Твердження 9.12 (T5).** (Tree∞, d_S) — компактний, повний, цілком обмежений. **DP-s.**

**Твердження 9.13.** Адресний доступ. **DP-s.**

### 9.5. «Хребет» і простір Y (P-60)

**Означення 9.14.** Фіксуємо α ≠ β та η ∈ A.

**Кодування C і метрика d_C.** Нехай C := {α, β}^ℕ. Для a, b ∈ C: d_C(a, a) := 0; при a ≠ b — d_C(a, b) := 2^{−k}, де k — перший індекс, на якому a_k ≠ b_k.

**Вкладення t.** Для a ∈ C задаємо t(a) на адресах:

```text
t(a)(1ᵏ) := node,
t(a)(1ᵏ·2) := leaf(aₖ),
t(a)(1ᵏ·3) := leaf(η),   k ≥ 0,
```

а на всіх інших адресах σ задаємо t(a)(σ) := None.

**Твердження 9.15 (P-60).** t : C → S∞ — гомеоморфізм C на Y := t[C]; d_S(t(a), t(b)) = ½ d_C(a, b). Y компактна й замкнена в S∞. Зсув σ спряжений із T := t ∘ σ ∘ t⁻¹. **DP-f.**

*Доведення.* Усі вузли t(a) розташовані на адресах 1ᵏ, а кожний такий вузол має трьох дітей: наступний вузол хребта (на адресі 1ᵏ⁺¹) і два листки (на адресах 1ᵏ·2 і 1ᵏ·3). Усі не задані адреси мають значення None. Тому виконуються умови T1–T4, і t(a) ∈ S∞.

Нехай a ≠ b, а k — перший індекс розбіжності. Дерева t(a) і t(b) збігаються на всіх адресах до глибини k (обидва є node на 1ʲ для j ≤ k, обидва leaf(η) на 1ʲ·3 для j < k, і мають однакові мітки leaf(a_j) = leaf(b_j) на 1ʲ·2 для j < k). Вперше вони відрізняються на адресі 1ᵏ·2, глибина якої дорівнює k + 1. Отже, r_addr(t(a), t(b)) = k + 1 і

```text
d_S(t(a), t(b)) = 2^{−(k+1)} = ½ d_C(a, b).
```

Таким чином, t — неперервне ін'єктивне відображення. Простір C компактний як зліченний добуток скінченних дискретних просторів, а S∞ — гаусдорфів метричний простір. Тому t — гомеоморфізм на свій образ Y = t[C]. Звідси Y компактна й замкнена (компактна підмножина метричного простору замкнена). Відображення T = t ∘ σ ∘ t⁻¹ спряжене з σ за означенням. ∎

**Зауваження 9.16.** S∞ — нульвимірний компакт; скінченні дерева — ізольовані точки; множина нескінченних дерев замкнена й досконала; Y — власна досконала підмножина.

## 10. Правила ℛ₀ і ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні та обчислювані правила

**Означення 10.1.** ℛ₀ := ℛ_caus := { f : S∞ → S∞ : d_S(f(s), f(t)) ≤ d_S(s, t) }, d_ℛ(ρ, σ) := sup_s d_S(ρ(s), σ(s)).

**Означення 10.2.** ℛ₁ := ℛ_comp — функції зі скінченним обчислювальним описом у фіксованій моделі (дерево подано оракулом).

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ n-префікс виходу залежить лише від n-префіксу входу. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* r_addr(f(s), f(t)) ≥ r_addr(s, t).

**Твердження 10.4 (T6).** (ℛ₀, d_ℛ) — компактний ультраметричний простір. **DP-s.**

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀; |ℛ₁| = ℵ₀ за припущення про модель. **DP-s.**

### 10.2. Розширений простір

**Припущення (H; явний контракт залежностей).** Для всіх тверджень, що посилаються на (H), явно приймаються такі передумови: (H1) (S∞, d_S) є компактним ультраметричним простором (це використовує T3 і T5; T3 у цій редакції ще не має повного доказу, T5 має статус DP-s); (H2) R ⊆ ℛ₀ — непорожній компактний підпростір у метриці d_ℛ (компактність R є прямою передумовою, а не висновком із непідтвердженого твердження T6); (H3) g∞ : R × S∞ → R неперервна і тотальна. Покладемо X := S∞ × R, d̂((s, ρ), (t, σ)) := max(d_S(s, t), d_R(ρ, σ)), де d_R := d_ℛ|_{R×R}, і D∞(s, ρ) := (ρ(s), g∞(ρ, s)). За (H1)–(H3) простір X компактний, а D∞ неперервний за T7. Відтак D1 і Lemma 11.0 є DP-f **умовно за (H1)–(H3)**; це не замінює незалежного доведення T3/T5.

**Припущення (H₀).** Для SUBIT⁺: S₀ скінченне з дискретною топологією; D₀ і g₀ тотальні.

**Означення 10.6.** π_R : R × S∞ → R. Тотожна метаеволюція: g∞ = π_R.

### 10.3. Метрики на X

**Означення 10.9 (d_H, d_H^X).** Для непорожніх компактних P, Q у метричному просторі (M, d):

```text
d_H(P, Q) := max { sup_{p∈P} inf_{q∈Q} d(p, q),
                   sup_{q∈Q} inf_{p∈P} d(p, q) }
```

Для P, Q ⊆ S∞ — d = d_S і позначення d_H; для P, Q ⊆ X — d = d̂ і d_H^X.

**Означення 10.10 (d_ω).** Для x, y ∈ X: d_ω(x, y) := d_H^X(ω(x), ω(y)). Псевдометрика на X; метрика — на факторі X/~, де x ~ y ⇔ ω(x) = ω(y).

**Твердження 10.7 (T7).** Для всіх s,t ∈ S∞ та ρ,σ ∈ R:

```text
d_S(ρ(s), σ(t)) ≤ max(d_S(s, t), d_ℛ(ρ, σ)).
```

За (H) відображення D∞ неперервне, а (X, d̂) — компактний ультраметричний простір. **DP-f за T3 та H.**

*Доведення.* Оскільки ρ,σ ∈ ℛ₀, обидва відображення нерозтягувальні. За ультраметричною нерівністю трикутника:

```text
d_S(ρ(s), σ(t))
≤ max(d_S(ρ(s), σ(s)), d_S(σ(s), σ(t)))
≤ max(d_ℛ(ρ, σ), d_S(s, t)).
```

Це доводить потрібну оцінку. Метрика d_ℛ є ультраметрикою: покоординатна ультраметрична нерівність для d_S після взяття супремуму дає

```text
d_ℛ(ρ, υ) ≤ max(d_ℛ(ρ, σ), d_ℛ(σ, υ)).
```

Тому d̂, як максимум двох ультраметрик, є ультраметрикою. За (H1)–(H2) добуток X компактний. Для неперервності першої координати D∞ застосовуємо доведену оцінку; друга координата (ρ,s) ↦ g∞(ρ,s) неперервна за (H3). Отже D∞ неперервне як добуток неперервних координатних відображень. ∎

**Твердження 10.8 (T8).**

```text
d_finite(x, y) := sup_{n≥0} 2^{−n}·d̂(D∞ⁿ x, D∞ⁿ y)
```

є ультраметрикою з тією самою топологією, що й d̂. **DP-f за T3 та H.**

*Доведення.* Для кожного n функція δₙ(x,y) := d̂(D∞ⁿx,D∞ⁿy) є псевдоультраметрикою, бо це pullback ультраметрики d̂ уздовж D∞ⁿ. Множення на 2⁻ⁿ зберігає ультраметричну нерівність. Супремум сімейства псевдоультраметрик із цією нерівністю також задовольняє її:

```text
d_finite(x,z) ≤ max(d_finite(x,y), d_finite(y,z)).
```

Оскільки член n = 0 дорівнює d̂(x,y), маємо d_finite(x,y) ≥ d̂(x,y); тому d_finite(x,y)=0 тягне x=y. Отже це метрика. Метрика d̂ обмежена зверху одиницею, оскільки d_S ≤ 1 і d_ℛ ≤ 1. Для всіх N:

```text
sup_{n≥N} 2^{−n} d̂(D∞ⁿx,D∞ⁿy) ≤ 2^{−N}.
```

Якщо d̂(x_j,x) → 0, то для кожного фіксованого n неперервність D∞ⁿ дає d̂(D∞ⁿx_j,D∞ⁿx) → 0. Розбивши супремум на скінченну частину n < N та хвіст n ≥ N, спершу вибираємо N із малим 2⁻ᴺ, а потім j достатньо великим для скінченної частини. Тоді d_finite(x_j,x) → 0. Навпаки, d_finite → 0 тягне d̂ → 0, бо d̂ ≤ d_finite. Отже метрики задають ту саму топологію. ∎

**Застереження 10.11.** Правила з ℛ₁, що не є неперервними, у (H) не потрапляють.

## 11. Класифікація траєкторій P(τ)

Всюди припускається (H).

### 11.1. ω-границя і класи S(τ)

Нехай xₙ := D∞ⁿ(x₀) — траєкторія в компактному метричному просторі X := S∞ × R. Її ω-границя визначається як

```text
ω(x₀) := { y ∈ X : існує n_j → ∞, для яких x_{n_j} → y }
       = ⋂_{N≥0} cl{ x_n : n ≥ N }.
```

**Твердження 11.1 (D1; P-66).** ω(x₀) непорожня, компактна і D∞[ω(x₀)] = ω(x₀). **DP-f за (H1)–(H3).**

*Доведення.* Для кожного N ≥ 0 множина K_N := cl{ x_n : n ≥ N } непорожня і компактна, оскільки є замкненою підмножиною компактного X. Множини K_N вкладені: K_{N+1} ⊆ K_N. За властивістю перетину вкладених непорожніх компактних множин ω(x₀) = ⋂_{N≥0} K_N непорожня і компактна.

Покажемо D∞[ω(x₀)] ⊆ ω(x₀). Нехай y ∈ ω(x₀). Тоді існує n_j → ∞, для якого x_{n_j} → y. За неперервністю D∞ маємо x_{n_j+1} = D∞(x_{n_j}) → D∞(y). Оскільки n_j + 1 → ∞, D∞(y) ∈ ω(x₀).

Для зворотного включення візьмімо довільне y ∈ ω(x₀). Виберімо послідовність індексів n_j → ∞ таку, що x_{n_j} → y; відкинувши скінченну кількість членів, можна вважати n_j ≥ 1. Послідовність x_{n_j−1} лежить у компактному X, тому має збіжну підпослідовність x_{n_{j_k}−1} → z. Оскільки n_{j_k}−1 → ∞, маємо z ∈ ω(x₀). За неперервністю

```text
D∞(z) = lim_{k→∞} D∞(x_{n_{j_k}−1})
      = lim_{k→∞} x_{n_{j_k}} = y.
```

Отже y ∈ D∞[ω(x₀)], тобто ω(x₀) ⊆ D∞[ω(x₀)]. Разом з першим включенням отримуємо D∞[ω(x₀)] = ω(x₀). ∎

**Лема 11.0 (скінченна ω — один цикл; P-57, P-66).** Нехай ω := ω(x₀) — непорожня скінченна ω-границя. Тоді D∞|ω — перестановка, і ω складається з одного циклу. **DP-f за (H1)–(H3).**

*Доведення.* За D1 маємо D∞[ω] = ω. Отже, обмеження D∞|ω є сюр'єкцією скінченної множини на себе, тобто перестановкою.

Якщо |ω| = 1, ω складається з єдиної нерухомої точки.

Нехай |ω| > 1 і

```text
δ := min{ d̂(u, v) : u, v ∈ ω, u ≠ v } > 0.
```

За неперервністю D∞ та скінченністю ω існує η, 0 < η < δ/3, таке, що для всіх w ∈ ω:

```text
d̂(x, w) < η ⇒ d̂(D∞x, D∞w) < δ/3.
```

Відстань d̂(xₙ, ω) прямує до нуля. Справді, якби це було не так, існувала б підпослідовність (x_{n_j}) з d̂(x_{n_j}, ω) ≥ ε для деякого ε > 0. За компактністю X деяка її підпослідовність збігалася б до y ∈ ω, що суперечило б d̂(x_{n_j}, ω) ≥ ε та неперервності функції відстані до ω.

Тому для всіх достатньо великих n існує єдина wₙ ∈ ω, для якої d̂(xₙ, wₙ) < η: існування випливає з d̂(xₙ, ω) → 0, а єдиність — з 2η < δ. Крім того, d̂(xₙ,wₙ) = d̂(xₙ,ω) → 0.

Для всіх достатньо великих n маємо

```text
d̂(wₙ₊₁, D∞(wₙ))
≤ d̂(wₙ₊₁, xₙ₊₁) + d̂(D∞xₙ, D∞wₙ)
< η + δ/3 < 2δ/3 < δ.
```

Обидві точки wₙ₊₁ і D∞(wₙ) належать ω. За означенням δ різні точки ω не можуть бути на відстані меншій за δ, тому wₙ₊₁ = D∞(wₙ).

Отже, починаючи з деякого індексу, послідовність wₙ рухається по одному циклу перестановки D∞|ω. Оскільки d̂(xₙ,wₙ) → 0, послідовності (xₙ) та (wₙ) мають однакові множини граничних точок. Множина граничних точок хвоста періодичної послідовності (wₙ) є саме циклом, яким вона рухається. З іншого боку, множина граничних точок (xₙ) дорівнює ω за означенням. Тому ω і є одним циклом. ∎

**Означення 11.2 (Att).** ATTAINED ⇔ ∃n: x_n ∈ ω(x₀). NONATTAINED := ¬ATTAINED. `ASYMPTOTIC` — історичний синонім NONATTAINED.

**Означення 11.3 (класи S(τ)).**

| Клас S(τ) | Умова |
| :-- | :-- |
| FIXED | ω — одноточкова множина |
| PERIODIC | ω скінченна, #ω > 1 |
| MIN_ZERO | ω нескінченна, мінімальна, h_top = 0 |
| MIN_POS | ω нескінченна, мінімальна, h_top > 0 |
| NONMIN_ZERO | ω нескінченна, не мінімальна, h_top = 0 |
| NONMIN_POS | ω нескінченна, не мінімальна, h_top > 0 |

`QUASI_PERIODIC_MINIMAL` — підклас MIN_ZERO. `CHAOTIC_ω(τ)` — «h_top > 0».

**Твердження 11.4 (D6).** Шість класів попарно не перетинаються й вичерпують усі траєкторії. **DP-f за (H1)–(H3), D1 та Lemma 11.0.**

*Доведення.* За D1 множина ω непорожня, компактна й інваріантна. Якщо ω скінченна, за лемою 11.0 вона є одним циклом: #ω = 1 → FIXED; #ω > 1 → PERIODIC; ентропія скінченної системи — 0. Якщо ω нескінченна, то вона або мінімальна, або ні, і h_top або 0, або > 0; це дає чотири класи MIN_ZERO, MIN_POS, NONMIN_ZERO, NONMIN_POS. Класи попарно не перетинаються. ∎

### 11.2. Ентропія

**Твердження 11.5 (D3; P-63).** Нехай P — непорожня компактна, D[P] ⊆ P, D|_P нерозтягувальне. Тоді h_top(D|_P) = 0. **DP-f.**

*Доведення.* Якщо D|_P нерозтягувальне, то d(Dⁱx, Dⁱy) ≤ d(x, y) для всіх i ≥ 0. Оскільки метрика Боуена включає i = 0, маємо d_n(x, y) = d(x, y). Тому s(n, ε) = s(1, ε), незалежно від n. Для кожного фіксованого ε > 0 ця величина скінченна, бо P компактна (цілком обмежена). Отже,

```text
h_top(D|_P) = lim_{ε→0⁺} limsup_{n→∞} (1/n) log s(n, ε) = 0.
```

∎

**Твердження 11.6 (D4; P-76).** Якщо g∞ = π_R, то D∞ нерозтягувальне, а на кожній непорожній компактній D∞-інваріантній множині топологічна ентропія дорівнює нулю; значення CHAOTIC неможливе. **DP-f за T7 та D3.**

*Доведення.* За g∞ = π_R маємо D∞(s,ρ) = (ρ(s),ρ). Для x=(s,ρ), y=(t,σ) оцінка T7 дає

```text
d̂(D∞x,D∞y)
= max(d_S(ρ(s),σ(t)), d_R(ρ,σ))
≤ max(d_S(s,t),d_R(ρ,σ))
= d̂(x,y).
```

Отже D∞ нерозтягувальне. Нехай P — непорожня компактна множина з D∞[P] = P. Обмеження D∞|P нерозтягувальне, тому за D3 h_top(D∞|P)=0. За означенням ChaosStatus це виключає CHAOTIC. ∎

**Твердження 11.7 (D3′; P-76).** Нехай існує ρ ∈ R, для якого ∀s ∈ S∞: g∞(ρ,s)=ρ. Тоді K_ρ := S∞ × {ρ} додатно інваріантна, D∞|K_ρ спряжене з ρ через проєкцію на першу координату, h_top(D∞|K_ρ)=0, а D∞[K_ρ]=K_ρ тоді й лише тоді, коли ρ сюр'єктивне. **DP-f за H та D3.**

*Доведення.* Для кожного (s,ρ) ∈ K_ρ маємо D∞(s,ρ)=(ρ(s),ρ) ∈ K_ρ, отже D∞[K_ρ] ⊆ K_ρ. Проєкція q:K_ρ→S∞, q(s,ρ)=s, є ізометрією (бо d̂((s,ρ),(t,ρ))=d_S(s,t)) з оберненим відображенням s↦(s,ρ), і

```text
q(D∞(s,ρ)) = ρ(s) = ρ(q(s,ρ)).
```

Тому q задає топологічне спряження D∞|K_ρ та ρ. Простір K_ρ компактний за H; оскільки ρ∈ℛ₀, воно нерозтягувальне. Застосувавши D3, одержуємо h_top(D∞|K_ρ)=0. Нарешті,

```text
D∞[K_ρ] = { (ρ(s),ρ) : s∈S∞ } = K_ρ
```

тоді й лише тоді, коли ρ[S∞]=S∞, тобто коли ρ сюр'єктивне. ∎

### 11.3. Метрика d_Ω_traj

Кожна пара (S, Att) кодується чотирикомпонентним діагностичним вектором (size-code, Min-code, entropy-code, Att). Min-code для FIXED і PERIODIC — OMITTED.

| Клас | Розмір | Min-code | Ентропія |
| :-- | :-- | :-- | :-- |
| FIXED | 1 | OMITTED | 0 |
| PERIODIC | скінченна > 1 | OMITTED | 0 |
| MIN_ZERO | нескінченна | MINIMAL | 0 |
| MIN_POS | нескінченна | MINIMAL | + |
| NONMIN_ZERO | нескінченна | NON_MINIMAL | 0 |
| NONMIN_POS | нескінченна | NON_MINIMAL | + |

**Означення 11.12.0.** Кожний клас S кодується вектором v(S, Att) = (s, m, e, a), де s — категорія розміру, m — Min-code, e — entropy-code, a ∈ {0, 1} — код Att (a = 1 для ATTAINED, a = 0 для NONATTAINED). Категорії розміру, Min-code та entropy-code трактуються як символи, а не як числові величини.

Для двох кодів u = (u₁, u₂, u₃, u₄) і v = (v₁, v₂, v₃, v₄):

```text
d_Ω_traj(u, v) := Σ_{j=1}^{4} 𝟙[u_j ≠ v_j]
```

Це відстань Геммінга на множині кодів.

**Твердження 11.12 (P-64).** d_Ω_traj — метрика на множині 12 діагностичних кодів. **DP-f.**

*Доведення.* Шість класів S мають різні базові коди вже за першими трьома координатами. Кожен базовий код утворює дві різні версії за четвертою координатою (Att ∈ {0, 1}). Тому множина містить рівно 12 різних векторів.

Відстань Геммінга між векторами невід'ємна, симетрична, дорівнює нулю лише для однакових векторів. Нерівність трикутника виконується покоординатно: якщо u та w відрізняються в деякій координаті j, то принаймні одна з пар (u, v) або (v, w) також відрізняється в координаті j. Отже, d_Ω_traj(u, w) ≤ d_Ω_traj(u, v) + d_Ω_traj(v, w). Обмеження відстані Геммінга на 12 різних кодів — метрика. ∎

*Примітка.* Ця метрика визначена на множині формальних діагностичних кодів. Вона не означає, що всі 12 комбінацій реалізовано конкретними траєкторіями (див. таблицю §11.5).

### 11.4. Лема про вкладення, D5, W5

**Лема 11.8 (E; P-59).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна сюр'єктивна. κ_c(s) := c, R_Y := {κ_c : c ∈ Y}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна (H виконано);
2. G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. Для кожного c ∈ Y покладемо x_c := (c, κ_{T(c)}) ∈ G і h := pr₁|G. Тоді:

```text
h[ω_{D∞}(x_c)] = ω_T(c);
h_top(D∞|G) = h_top(T);
Min_{D∞|G}(G) = Min_T(Y);
x_c ATTAINED ⇔ ∃n ≥ 0: Tⁿ(c) ∈ ω_T(c).
```

Тут рівність `Min_{D∞|G}(G) = Min_T(Y)` означає рівність результатів класифікації (`MINIMAL` або `NON_MINIMAL`). **DP-f за H.**

*Доведення.* j : Y → ℛ₀, j(c) := κ_c. d_ℛ(κ_c, κ_{c'}) = d_S(c, c'), тож j — ізометричне вкладення; R_Y компактна і міститься в ℛ₀. g∞(κ_c, s) = κ_{T(c)} відповідає неперервному T і не залежить від s. Отже (H) виконано.

Граф G компактний як неперервний образ Y; h := pr₁|G : G → Y — гомеоморфізм. Для c ∈ Y: D∞(c, κ_{T(c)}) = (T(c), κ_{T(T(c))}) ∈ G, тож D∞[G] ⊆ G. Навпаки, якщо (d, κ_{T(d)}) ∈ G, через сюр'єктивність T існує c з T(c) = d; тоді D∞(c, κ_{T(c)}) = (d, κ_{T(d)}). Отже D∞[G] = G і h ∘ D∞|G = T ∘ h.

**Збереження ω-границь і ATTAINED.** Нехай y ∈ ω_{D∞}(x_c), тобто існує n_k → ∞ з D∞^{n_k}(x_c) → y. За спряженістю h(D∞^{n_k}(x_c)) = T^{n_k}(c) → h(y), тому h(y) ∈ ω_T(c). Отже h[ω_{D∞}(x_c)] ⊆ ω_T(c). Обернене: якщо z ∈ ω_T(c), існує n_k → ∞ з T^{n_k}(c) → z; через h⁻¹ маємо D∞^{n_k}(x_c) = h⁻¹(T^{n_k}(c)) → h⁻¹(z); отже h⁻¹(z) ∈ ω_{D∞}(x_c). Рівність доведено. ATTAINED зберігається: x_n ∈ ω(x_c) ⇔ h(x_n) ∈ ω_T(c).

**Збереження мінімальності.** h — бієкція між замкненими інваріантними підмножинами G і Y. Тому G мінімальна ⇔ Y мінімальна.

**Збереження топологічної ентропії.** Нехай h : G → Y — гомеоморфізм спряження.

Для ε_Y > 0 рівномірна неперервність h дає δ_G > 0, для якого d_G(x, x') < δ_G ⇒ d_Y(h(x), h(x')) < ε_Y.

Якщо пара траєкторій розділена в Y на відстань понад ε_Y на деякому кроці, то відповідна пара в G на цьому кроці має відстань щонайменше δ_G, а отже понад δ_G/2. Тому

```text
s_Y(n, ε_Y) ≤ s_G(n, δ_G/2),
```

і h_top(T) ≤ h_top(D∞|G).

Навпаки, для ε_G > 0 рівномірна неперервність h⁻¹ дає δ_Y > 0, для якого d_Y(u, v) < δ_Y ⇒ d_G(h⁻¹u, h⁻¹v) < ε_G. Тому кожна пара траєкторій, розділена в G на відстань понад ε_G, після застосування h залишається розділеною в Y на відстань понад δ_Y/2. Звідси

```text
s_G(n, ε_G) ≤ s_Y(n, δ_Y/2),
```

і h_top(D∞|G) ≤ h_top(T).

Отже, h_top(D∞|G) = h_top(T). ∎

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {0,1}^ℕ з h_top(σ|_Z) > 0.

Бібліографічні орієнтири:

- C. Grillenberger, "Construction of strictly ergodic systems I. Given entropy", *Z. Wahrscheinlichkeitstheorie verw. Geb.* 25 (1973), 323–334.
- E. Glasner, B. Weiss, "Strictly ergodic, uniform positive entropy models", *Bull. Soc. Math. France* 122(3) (1994), 399–412, DOI 10.24033/bsmf.2239.
- T. K. Subrahmonian Moothathu, P. Oprocha, "Shadowing, entropy and minimal subsystems", *Monatshefte für Mathematik* 172 (2013), 357–378, DOI 10.1007/s00605-013-0504-3. Доведення теореми 5.2 прямо використовує мінімальний підзсув Q ⊆ {0,1}^ℕ із додатною топологічною ентропією.

**Застереження.** Конструкцію Z не побудовано й не доведено заново всередині специфікації. EXT-1 залишається окремою зовнішньою передумовою.

**Твердження 11.9 (D5; P-50, P-64).** Нехай E := {0,1}^ℕ, а Z ⊆ E — непорожній замкнений мінімальний підзсув із h_top(σ|_Z) > 0, існування якого постулює EXT-1.

Нехай enc_αβ : E → C — покоординатне кодування (0 ↦ α, 1 ↦ β), а Z_αβ := enc_αβ[Z] ⊆ C. Визначимо

```text
σ_C := enc_αβ ∘ σ ∘ enc_αβ⁻¹,
Y_Z := t[Z_αβ],
T_Z := t ∘ σ_C ∘ t⁻¹ |_{Y_Z}.
```

Система (T_Z → Y_Z) спряжена з σ|_Z, отже Y_Z компактна, T_Z мінімальна та h_top(T_Z) > 0. Застосовуючи лему 11.8 до (Y_Z, T_Z), одержуємо компактну інваріантну множину G_Z, мінімальну, нескінченну та з додатною топологічною ентропією.

Для кожного c ∈ Y_Z точка x_c = (c, κ_{T_Z(c)}) задовольняє ω(x_c) = G_Z і x_c ∈ G_Z. Тому реалізовано `MIN_POS × ATTAINED`.

**Перевірка g∞ ≠ π_R (P-79; без залежності від D4).** За побудовою g∞(κ_c,s)=κ_{T_Z(c)}, тоді як π_R(κ_c,s)=κ_c. Оскільки h_top(T_Z)>0, відображення T_Z не може бути тотожним: тотожне відображення має нульову топологічну ентропію. Отже існує c∈Y_Z з T_Z(c)≠c, а тому κ_{T_Z(c)}≠κ_c і g∞≠π_R. Цей аргумент не використовує D4.

**DP-f за H та EXT-1.** ∎

**Твердження 11.10 (W5).** Нехай C := {α, β}^ℕ, σ : C → C — односторонній повний зсув, Y := t[C], T := t ∘ σ ∘ t⁻¹. Виберімо a ∈ C, у якому кожне скінченне слово над {α, β} трапляється нескінченно багато разів, і c := t(a). Для x_c := (c, κ_{T(c)}): ω(x_c) = G, x_c ∈ G, ATTAINED; G нескінченна, не мінімальна, h_top(D∞|G) = log 2 > 0. Отже NONMIN_POS × ATTAINED і CHAOTIC_set. **DP-f за H.**

*Доведення.*

**(1) Побудова точки з повною ω-границею.** Нехай a ∈ C — послідовність, у якій кожне скінченне слово над алфавітом {α, β} зустрічається нескінченно багато разів. Таку послідовність можна побудувати конкатенацією списків усіх слів довжини не більшої за m, послідовно для m = 1, 2, …

Для будь-якого z ∈ C і кожного N ≥ 1 префікс z довжини N трапляється в a на нескінченно багатьох позиціях. Тому можна вибрати індекси n_N → ∞, для яких σ^{n_N}(a) збігається до z. Отже, ω_σ(a) = C.

За спряженням t → Y та лемою 11.8: ω_{D∞}(x_c) = G. Оскільки x_c ∈ G, траєкторія досягає своєї ω-границі: ATTAINED.

**(2) Нижня оцінка ентропії повного зсуву.** Нехай d_C(x, y) = 2^{−k} (k — перший індекс розбіжності), d_C(x, x) := 0. Метрика Боуена: d_n(x, y) = max_{0 ≤ i < n} d_C(σⁱx, σⁱy).

Виберімо по одному представнику кожного з 2ⁿ префіксів довжини n. Два різні представники розходяться на деякій координаті k < n, отже після зсуву σᵏ їхня відстань дорівнює 1. Ця множина є (n, 3/4)-розділеною, тому s(n, 3/4) ≥ 2ⁿ.

Якщо дві послідовності мають однаковий префікс довжини n, то після кожного зсуву σⁱ (0 ≤ i < n) вони збігаються принаймні за першою координатою. Тому d_n(x, y) ≤ 1/2 < 3/4. Отже s(n, 3/4) ≤ 2ⁿ.

Таким чином, s(n, 3/4) = 2ⁿ, і h_top(σ) ≥ log 2.

**(3) Верхня оцінка ентропії.** Нехай ε > 0. Виберімо L ≥ 0 так, щоб 2^{−(L+1)} < ε. Якщо дві послідовності мають однаковий префікс довжини n + L, то після кожного зсуву σⁱ (0 ≤ i < n) вони збігаються щонайменше за першими L + 1 координатами. Тому d_n(x, y) ≤ 2^{−(L+1)} < ε.

Отже, у (n, ε)-розділеній множині не може бути двох послідовностей з однаковим префіксом довжини n + L. Тому s(n, ε) ≤ 2^{n+L}. Для фіксованого ε величина L стала, тож

```text
limsup_{n→∞} (1/n) log s(n, ε) ≤ log 2.
```

Переходячи до ε → 0⁺, одержуємо h_top(σ) ≤ log 2. Разом із нижньою оцінкою: h_top(σ) = log 2.

**(4) Перенесення на SUBIT.** За лемою 11.8 система D∞|G спряжена з σ → C, отже h_top(D∞|G) = log 2 > 0. Множина G нескінченна й не мінімальна: вона містить нерухому точку, що відповідає α^∞, але не є одноточковою множиною.

Таким чином, реалізовано `NONMIN_POS × ATTAINED` і `CHAOTIC_set`. ∎

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення; P-58).** (X, d) — непорожній повний метричний простір, Φ : X → X, d(Φ(x), Φ(y)) ≤ q·d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x*, і Φⁿ(x₀) → x*. **DP-f.**

*Доведення.* Нехай x_n = Φⁿ(x₀). За умовою стискання

```text
d(x_{n+1}, x_n) ≤ qⁿ d(x₁, x₀).
```

Для m > n маємо

```text
d(x_m, x_n) ≤ Σ_{k=n}^{m−1} d(x_{k+1}, x_k) ≤ qⁿ / (1 − q) · d(x₁, x₀).
```

Отже, (x_n) — послідовність Коші. За повнотою X існує границя x* ∈ X. Неперервність Φ дає Φ(x*) = x*.

Якщо y* — інша нерухома точка, то

```text
d(x*, y*) = d(Φ(x*), Φ(y*)) ≤ q·d(x*, y*).
```

Оскільки q < 1, маємо d(x*, y*) = 0, отже x* = y*. Єдиність нерухомої точки доведено. ∎

**Прищеплення.** Для a ∈ A: ρ_a(f) := node(f, leaf(a), leaf(a)), тобто ρ_a(f)(ε) = node, ρ_a(f)(1σ) = f(σ), ρ_a(f)(2) = ρ_a(f)(3) = leaf(a). ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, тож ρ_a ∈ ℛ₀ і стискаюче з коефіцієнтом ½.

**W1 (FIXED × ATTAINED).** R = {ρ_a}, g∞ = π_R. За лемою 11.11 ρ_a має єдину нерухому точку p_a. D∞(p_a, ρ_a) = (ρ_a(p_a), ρ_a) = (p_a, ρ_a). ω(x₀) = {(p_a, ρ_a)}, x₀ ∈ ω(x₀), ATTAINED. **DP-f.**

**W2 (FIXED × NONATTAINED).** s ≠ p_a, x₀ = (s, ρ_a). x_n = (ρ_aⁿ(s), ρ_a) → (p_a, ρ_a), тому ω(x₀) = {(p_a, ρ_a)}. Якщо x_n = (p_a, ρ_a), то ρ_aⁿ(s) = p_a = ρ_aⁿ(p_a), звідки s = p_a — суперечність із s ≠ p_a. Отже NONATTAINED. **DP-f.**

**W3 (PERIODIC × ATTAINED/NONATTAINED).** R = {ρ_a, ρ_b}, a ≠ b, g∞(ρ_a, s) = ρ_b, g∞(ρ_b, s) = ρ_a. Φ := ρ_b ∘ ρ_a стискаюче з коефіцієнтом ¼, за лемою 11.11 має єдину нерухому точку q. Визначимо z₀ := (q, ρ_a), z₁ := (ρ_a(q), ρ_b). Тоді D∞(z₀) = z₁ і D∞(z₁) = z₀, причому z₀ ≠ z₁ (різні координати правил). Старт на цьому циклі дає PERIODIC × ATTAINED.

Для NONATTAINED: x₀ = (s, ρ_a), s ≠ q. x_{2k} = (Φᵏ(s), ρ_a), x_{2k+1} = (ρ_a(Φᵏ(s)), ρ_b). Оскільки Φ стискаюче, x_{2k} → z₀, x_{2k+1} → z₁; тому ω(x₀) = {z₀, z₁}.

Якби траєкторія досягла циклу за скінченну кількість кроків, то на парному кроці 2k мало б виконуватися Φᵏ(s) = q. На непарному кроці 2k+1 мало б виконуватися ρ_a(Φᵏ(s)) = ρ_a(q); через ін'єктивність ρ_a це знову дає Φᵏ(s) = q. В обох випадках Φᵏ(s) = Φᵏ(q). Оскільки Φ — композиція ін'єктивних прищеплень, Φ ін'єктивне, тому s = q — суперечність із s ≠ q. Отже NONATTAINED. **DP-f.**

**W4 (MIN_ZERO × ATTAINED).** B := {0,1}^ℕ, C := {α, β}^ℕ. O : B → B — додавання 1 у двійковому записі з переносом від координати 0 праворуч. enc_αβ : B → C — координатна бієкція: enc_αβ(a)_i = α при a_i = 0, β при a_i = 1. Визначимо Õ := enc_αβ ∘ O ∘ enc_αβ⁻¹ : C → C. Нехай t : C → S∞ — вкладення §9.5, Y := t[C], T := t ∘ Õ ∘ t⁻¹ : Y → Y.

**Ізометричність O.** Послідовність a інтерпретуємо як 2-адичне число A = Σ a_i 2^i. Якщо a ≠ b, k — перший індекс розбіжності, то A ≡ B (mod 2ᵏ), але A ≢ B (mod 2ᵏ⁺¹). Додавання 1 не змінює різниці A − B, тому перша розбіжність O(a), O(b) залишається на координаті k. Отже d_B(O(a), O(b)) = d_B(a, b).

**Мінімальність O.** Перші n координат Oᵐ(a) відповідають (N_n(a) + m) mod 2ⁿ, де N_n(a) — число, утворене першими n координатами a. При m = 0, …, 2ⁿ−1 отримуємо всі 2ⁿ префіксів. Тому кожна орбіта щільна в B. Непорожня замкнена Q з O[Q] ⊆ Q містить повну щільну орбіту, отже Q = B. Система мінімальна.

**Відсутність періодичних точок.** Якщо Oᵖ(a) = a для деякого p ≥ 1, тоді додавання p залишає всі перші n координат незмінними. Отже p ≡ 0 (mod 2ⁿ) для кожного n, що неможливо для фіксованого додатного p.

**Завершення.** За координатним кодуванням T на Y є ізометрією відносно d_S. За D3 h_top(T) = 0. За лемою E h_top(D∞|G) = h_top(T) = 0; лема E також переносить мінімальність і відсутність періодичних точок. Отже G — нескінченна мінімальна ω-границя з нульовою ентропією. Для x_c ∈ G: ω(x_c) = G, x_c ∈ G. Отже MIN_ZERO × ATTAINED. **DP-f.** ∎
