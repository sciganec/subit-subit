```text
code6(s) := 32·b₁ + 16·b₂ + 8·b₃ + 4·b₄ + 2·b₅ + b₆  ∈ [0, 63]
```

## 2. SUBIT⁺ — скінченна динаміка з правилом у стані

**Означення 2.1.** `ℛ_fin` — непорожня скінченна множина функцій ρ : S₀ → S₀. Розширений стан — пара (s, ρ) із S₀ × `ℛ_fin`. Метаеволюція g₀ : `ℛ_fin` × S₀ → `ℛ_fin`, динаміка

```text
D₀(s, ρ) := ( ρ(s), g₀(ρ, s) )
```

**Аксіома 2.2 (тотальність).** D₀ тотальна. Часткові оператори — окремий шар (§11.7).

**Твердження 2.3 (E1).** (S₀ × `ℛ_fin`, D₀) — автономний детермінований скінченний автомат із 64·`#ℛ_fin` станами. ВИЗНАЧЕНО.

**Твердження 2.4 (A4).** Кожний автономний скінченний автомат (Q, δ) із непорожнім Q, #Q ≤ 64, тотальною δ : Q → Q і без вхідного алфавіту вкладається в SUBIT⁺. DP-f. *Доведення.* Ін'єкція ι : Q → S₀; ρ(ι(q)) := ι(δ(q)) на образі, ρ(s) := s₀ поза образом; g₀(ρ, s) := ρ. Індукція за n: стан ŝₙ = (ι(δⁿ(q₀)), ρ). ∎

**ВІДКЛИКАНО:** універсальний принцип симуляції DFA, універсальний об'єкт, ототожнення SUBIT⁺ із λ-інтерпретатором. Відкриті: Q7, Q22.

## 3. Траєкторії і точкова класифікація

### 3.1. Скінченний рівень Ω_point^fin

Область — Q₀ := S₀ × `ℛ_fin`. Для ŝ ∈ Q₀:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D₀^{m+p}(ŝ) = D₀^m(ŝ) }
p(ŝ) := min{ p ≥ 1 : D₀^{m(ŝ)+p}(ŝ) = D₀^{m(ŝ)}(ŝ) }
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, p ≥ 2 |
| PREPERIODIC(m, p) | m ≥ 1 |

**Твердження 3.1.1 (P1).** Для кожного ŝ ∈ Q₀: m(ŝ) < ∞. DP-f. *Доведення.* Діріхле: серед #Q₀ + 1 станів ŝ, D₀(ŝ), …, D₀^{#Q₀}(ŝ) є повтор. ∎

**Твердження 3.1.2 (P2).** Три класи попарно не перетинаються й вичерпують Q₀. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* За P1 пара (m, p) визначена однозначно; три умови m = 0 ∧ p = 1, m = 0 ∧ p ≥ 2, m ≥ 1 взаємовиключні та вичерпні. Повний аргумент не виписано.

**Твердження 3.1.3 (P3, точний режим).** Алгоритм першого повтору завершується з COMPUTED; RESOURCE_EXCEEDED недосяжна. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Діріхле дає повтор не пізніше n = #Q₀. Повний аргумент не виписано.

**Твердження 3.1.4 (P3′, бюджетований режим).** Якщо ліміт N_max < #Q₀, гілка RESOURCE_EXCEEDED досяжна для деяких систем. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

### 3.2. Нескінченний рівень Ω_point^∞

Область — S∞ × R за припущення (H). Для ŝ ∈ S∞ × R:

```text
m(ŝ) := min{ m ≥ 0 : ∃p ≥ 1, D∞^{m+p}(ŝ) = D∞^m(ŝ) }   (∞, якщо таких немає)
p(ŝ) := min{ p ≥ 1 : D∞^{m(ŝ)+p}(ŝ) = D∞^{m(ŝ)}(ŝ) }   (∞, якщо m(ŝ) = ∞)
```

| Клас | Умова |
| :-- | :-- |
| FIXED | m = 0, p = 1 |
| PERIODIC(p) | m = 0, 2 ≤ p < ∞ |
| EVENTUALLY_PERIODIC(m, p) | 1 ≤ m < ∞, p < ∞ |
| APERIODIC | m = ∞ (тоді p = ∞) |

**Твердження 3.2.1.** Чотири класи попарно не перетинаються й вичерпують S∞ × R. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** *Ескіз.* Якщо m = ∞, то p = ∞ за означенням; якщо m < ∞, то p < ∞. Повний аргумент не виписано.

**ВІДКЛИКАНО:** використання Ω_point (три класи) поза Q₀.

## 4. Класифікація множин `Classify⁺_D`

**Область.** Допустима система (K, d, D) — компактний метричний простір K і неперервне D : K → K. P ⊆ K — непорожня, D[P] := {D(x) : x ∈ P}.

### 4.1. OrbitType

```text
μ(P)     := min{ m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P] }          (∞, якщо немає)
π(P)     := min{ k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P] }    (тільки при μ < ∞)
p_set(P) := min{ k ≥ 1 : Dᵏ[P] = P }                       (∞, якщо немає)
```

| Клас | Умова |
| :-- | :-- |
| INVARIANT_FIXED | D[P] = P і D(x) = x для всіх x ∈ P |
| INVARIANT_DYNAMIC | D[P] = P і є x ∈ P з D(x) ≠ x |
| PERIODIC_SET | D[P] ≠ P, μ(P) = 0, 2 ≤ p_set(P) < ∞ |
| EVENTUALLY_FIXED | 1 ≤ μ(P) < ∞, π(P) = 1 |
| EVENTUALLY_PERIODIC | 1 ≤ μ(P) < ∞, 2 ≤ π(P) < ∞ |
| APERIODIC | μ(P) = ∞ |

**Твердження 4.1.1 (C1).** Шість класів попарно не перетинаються й вичерпують непорожні P. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** Повний розбір за значеннями μ і π у цій редакції скорочено.

### 4.2. InclusionType

```text
EQUAL_IMAGE                D[P] = P
DISJOINT_IMAGE             D[P] ∩ P = ∅
STRICT_SUBIMAGE            D[P] ⊊ P
STRICT_SUPERIMAGE          P ⊊ D[P]
OVERLAPPING_NONCOMPARABLE  у інших випадках
```

**Твердження 4.2.1 (C2).** П'ять класів розбивають непорожні P. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

### 4.3. Ентропія, мінімальність, ChaosStatus

**Передумови.** (Π1) P компактна; (Π2) D[P] = P; (Π3) D|ₚ : P → P неперервне.

Топологічна ентропія h_top(D|P) — через (n, ε)-роздільні множини в метриці dₙ(x, y) = max_{i<n} d(Dⁱx, Dⁱy); h_top = lim_{ε→0} limsup_n (1/n) log s(n, ε).

**Означення 4.3.1.**

```text
ChaosStatus_D(P) =
   NOT_APPLICABLE   якщо передумови (Π1)–(Π3) не виконано
   CHAOTIC          якщо виконано і h_top(D|P) > 0
   NON_CHAOTIC      якщо виконано і h_top(D|P) = 0

Min_D(P) =
   NOT_APPLICABLE   якщо передумови не виконано
   MINIMAL          якщо виконано і P не має власної непорожньої замкненої Q з D[Q] ⊆ Q
   NON_MINIMAL      якщо виконано і така Q є
```

**Застереження 4.3.2.** NOT_APPLICABLE ≠ NON_CHAOTIC.

**Застереження 4.3.3.** Хаотичність = h_top > 0; мінімальність — окрема ознака Min.

### 4.4. Одне значення CHAOTIC

IsChaotic_D(P) :⇔ ChaosStatus_D(P) = CHAOTIC; CHAOTIC_ω(τ) :⇔ IsChaotic_D(ω(τ)). CHAOTIC_set — лише назва нижнього елемента Ω.

### 4.5. `Classify⁺_D`

```text
Classify⁺_D(P) := ( OrbitType_D(P), InclusionType_D(P), ChaosStatus_D(P), Min_D(P) )
```

**Твердження 4.5.1 (C3).** (a) InclusionType = EQUAL_IMAGE ⇔ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. (b) ChaosStatus = CHAOTIC ⇒ OrbitType = INVARIANT_DYNAMIC. (c) Min = MINIMAL ⇒ OrbitType ∈ {INVARIANT_FIXED, INVARIANT_DYNAMIC}. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

**Твердження 4.5.2 (C7).** У скінченному K хаотичних множин немає. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

**Твердження 4.5.3 (C4).** **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).** Контрприклади для C4b і C4c — одометр (§11.6) і односторонній зсув — збережено як ілюстрації.

**Твердження 5.4 (C5a).** π_Ω тотальна на D_class. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

**Твердження 5.8 (C6).** Ω — алгебра Гейтінга. **НЕ ПІДТВЕРДЖЕНО (повний доказ не включено).**

## 6. Модальна логіка і динамічна теорія типів

### 6.1. LTL-подібна семантика

```text
x ⊨ X U    ⇔  D(x) ∈ U
x ⊨ ◇ U    ⇔  ∃n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ◇⁺ U   ⇔  ∃n ≥ 1: Dⁿ(x) ∈ U
x ⊨ □ U    ⇔  ∀n ≥ 0: Dⁿ(x) ∈ U
x ⊨ ↺ U    ⇔  ∃k > 1: Dᵏ(x) ∈ U
```

**Твердження 6.1.1 (M1).** Усі 14 аксіом валідні. **DP-s.** Редукція до послідовностей uₙ := [Dⁿ(x) ∈ U] дає тавтології кванторів по ℕ; повний розбір кожної з 14 аксіом у цій редакції скорочено до схеми.

**Твердження 6.1.2 (M2, M6).** □U → ↺U. DP-f. *Доведення.* □U дає D²(x) ∈ U, тобто k = 2 > 1. ∎

### 6.2. Гейтінгова семантика

**Означення 6.2.1.** (□_H U)(x) := ⋀ₙ≥0 U(Dⁿx), (◇_H U)(x) := ⋁ₙ≥0 U(Dⁿx); ¬_H a := a → ⊥.

**Твердження 6.2.2 (M3).** Рівність ◇_H U = ¬_H □_H ¬_H U у семантиці §6.2 хибна. DP-f. *Контрмодель.* K = {a, b}, D(a) = b, D(b) = b, U(a) = EVENTUALLY_PERIODIC, U(b) = CHAOTIC_set. (◇_H U)(a) = EVENTUALLY_PERIODIC; (¬_H □_H ¬_H U)(a) = ⊤. ∎

**Твердження 6.2.3.** M4 у гейтінговій семантиці §6.2 не виконується. DP-f. **Q6′ (ВІДКРИТО).**

### 6.3. Динамічна теорія типів

```text
Рефлексивність:  Γ, x:U@τ ⊢ x : U@τ
```

## 9. Простір S∞ = Tree∞

### 9.1. Означення

### 9.2. Ψ і L_prod

```text
T₀     := { Leaf₀(a) : a ∈ A } ∪ { Bottom₀ }
Tₙ₊₁   := { Leafₙ₊₁(a) : a ∈ A } ∪ { Bottomₙ₊₁ }
         ∪ { Nodeₙ(t₁,t₂,t₃) : tᵢ ∈ Tₙ }
q₀ : T₁ → T₀:   Leaf₁ a ↦ Leaf₀ a,  Bottom₁ ↦ Bottom₀,  Node₀(…) ↦ Bottom₀
qₙ₊₁ : Tₙ₊₂ → Tₙ₊₁:  Leaf ↦ Leaf,  Bottom ↦ Bottom,
                     Nodeₙ₊₁(t₁,t₂,t₃) ↦ Nodeₙ(qₙ t₁, qₙ t₂, qₙ t₃)
U_c := { (tₙ) ∈ ∏ Tₙ : qₙ(tₙ₊₁) = tₙ }
LeafSeqs := { (Leafₙ(a))ₙ : a ∈ A }
NodeSeqs(X) := { t ∈ U_c : t₀ = Bottom₀, ∃u₁,u₂,u₃ ∈ X: tₙ₊₁ = Nodeₙ(u₁,ₙ, u₂,ₙ, u₃,ₙ) }
Ψ(X) := LeafSeqs ∪ NodeSeqs(X);     L_prod := ⋃{ X ⊆ U_c : X ⊆ Ψ(X) }
```

**Твердження 9.4.** L_prod = Ψ(L_prod). **DP-f (P-17).** *Доведення.* Ψ монотонний: X ⊆ Y ⇒ Ψ(X) ⊆ Ψ(Y). Для кожного X з X ⊆ Ψ(X) маємо X ⊆ Ψ(X) ⊆ Ψ(L_prod), тож L_prod ⊆ Ψ(L_prod). Застосувавши монотонність: Ψ(L_prod) ⊆ Ψ(Ψ(L_prod)), тобто Ψ(L_prod) — постнерухома точка й входить у сім'ю, об'єднанням якої є L_prod. Отже Ψ(L_prod) ⊆ L_prod. ∎

**Зауваження 9.5.** U_c строго більша за L_prod: (Bottomₙ)ₙ ∈ U_c ∖ L_prod.

### 9.3. d_n, at_n, lim_tree

```text

dₙ₊₁(f) := Leafₙ₊₁(a)                        якщо f(ε) = leaf(a)
```

**Лема 9.6.** dₙ(f) ∈ Tₙ, qₙ(dₙ₊₁ f) = dₙ f; якщо at_n(t, σ) = Some((k, u)), то |σ| ≤ n, k = n − |σ|, u ∈ T_k. **DP-f.** *Доведення.* Індукція за n і |σ| за означеннями. ∎

**Означення 9.7 (lim_tree).** Для t ∈ L_prod, σ ∈ Pos, m > |σ|. При m → ∞ стабілізується коренева форма at_m(t_m, σ): (Z) усе None; (L) кореневий конструктор Leaf із сталою міткою a; (N) кореневий конструктор Node. ## 10. Правила ℛ₀ і ℛ₁, припущення (H) і (H₀), метрики

### 10.1. Причинні та обчислювані правила

**Означення 10.1.** ℛ₀ := ℛ_caus := { f : S∞ → S∞ : d_S(f(s), f(t)) ≤ d_S(s, t) }, d_ℛ(ρ, σ) := sup_s d_S(ρ(s), σ(s)).

**Означення 10.2.** ℛ₁ := ℛ_comp — функції зі скінченним обчислювальним описом (дерево подано оракулом).

**Твердження 10.3 (T5′).** f ∈ ℛ₀ ⇔ n-префікс виходу залежить лише від n-префіксу входу. **DP-f (P-17).** *Доведення.* Нерівність d_S(f(s),f(t)) ≤ d_S(s,t) еквівалентна r_addr(f(s),f(t)) ≥ r_addr(s,t). Якщо s,t збігаються на всіх адресах довжини ≤ n, то r_addr(s,t) ≥ n+1, отже r_addr(f(s),f(t)) ≥ n+1, тому f(s),f(t) збігаються на адресах довжини ≤ n — це незалежність n-префікса. Навпаки, якщо вихідний n-префікс залежить лише від вхідного, то пара з r_addr(s,t) = r має виходи, що збігаються на адресах довжини < r, тож r_addr(f(s),f(t)) ≥ r_addr(s,t). ∎

**Твердження 10.4 (T6).** (ℛ₀, d_ℛ) — компактний ультраметричний простір. DP-s.

**Твердження 10.5 (T9).** |ℛ₀| = 2^ℵ₀; |ℛ₁| = ℵ₀ за припущення про модель. DP-s.

### 10.2. Розширений простір

### 11.1. ω-границя і класи S(τ)

**Твердження 11.1 (D1, P-15).** За (H) ω(τ) непорожня, компактна і D∞[ω(τ)] = ω(τ). **DP-f.** *Доведення.* ω(τ) = ⋂ₙ≥₀ cl{xₖ : k ≥ n} — перетин вкладених непорожніх компактних множин, отже непорожній і компактний. Отже ω ⊆ D∞[ω]. ∎

**Лема 11.0 (скінченна ω — один цикл; P-13).** Нехай D : K → K — неперервне відображення компактного метричного простору, τ = (xₙ) — траєкторія, ω := ω(τ) — непорожня скінченна ω-границя. Тоді D|ω є перестановкою, а ω складається з одного циклу. **DP-f.**

*Доведення.* D|ω — сюр'єкція скінченної множини на себе, отже перестановка; ω розпадається на неперетинні цикли.

Спочатку dist(xₙ, ω) → 0. Інакше ∃ ε > 0 та підпослідовність x_{nᵢ} з dist(x_{nᵢ}, ω) ≥ ε; за компактністю підпослідовність мала б границю y ∈ ω, що суперечить dist(y, ω) = 0.

Нехай δ := min{ d(p, q) : p, q ∈ ω, p ≠ q } > 0. Виберімо η < δ/3 так, щоб для кожного p ∈ ω умова d(x, p) < η давала d(D(x), D(p)) < δ/3 (можливо через неперервність D і скінченність ω).

Для всіх достатньо великих n існує єдина точка pₙ ∈ ω з d(xₙ, pₙ) < η. Маємо d(xₙ₊₁, D(pₙ)) = d(D(xₙ), D(pₙ)) < δ/3 і d(xₙ₊₁, pₙ₊₁) < η < δ/3. Якби pₙ₊₁ ≠ D(pₙ), відстань між двома різними точками ω була б < 2δ/3, що суперечить означенню δ. Отже pₙ₊₁ = D(pₙ) для всіх достатньо великих n. Послідовність pₙ після певного моменту рухається по одному циклу D|ω; кожна точка циклу трапляється нескінченно багато разів; dist(xₙ, pₙ) → 0. Тому ω — саме цей цикл. Для #ω = 1 твердження очевидне. ∎

### 11.2. Ентропія

**Твердження 11.5 (D3, P-15).** Нехай P — непорожня компактна множина, D[P] ⊆ P, D|_P нерозтягувальне. Тоді h_top(D|_P) = 0. **DP-f.** *Доведення.* Для x, y ∈ P та i ≥ 0: d(Dⁱx, Dⁱy) ≤ d(x, y). У метриці Боуена dₙ член i = 0 дорівнює d(x,y), тож dₙ(x,y) = d(x,y). Кількість (n, ε)-розділених точок обмежена числом, що залежить від ε, але не від n (P цілком обмежена). Тому limsupₙ (1/n) log s(n, ε) = 0 для кожного ε, звідки h_top = 0. ∎

**Твердження 11.6 (D4, P-15).** Якщо g∞ = π_R, то D∞ нерозтягувальне, h_top = 0 на кожній замкненій інваріантній множині; CHAOTIC неможливий. **DP-f.** *Доведення.* D∞(s, ρ) = (ρ(s), ρ). За T7:

```text
d̂(D∞(s,ρ), D∞(t,σ)) = max(d_S(ρ(s),σ(t)), d_ℛ(ρ,σ))
                    ≤ max(d_S(s,t), d_ℛ(ρ,σ)).
```

D∞ нерозтягувальне на X. Обмеження на замкнену інваріантну множину також нерозтягувальне; за D3 h_top = 0, тому CHAOTIC неможливий. ∎

**Твердження 11.7 (D3′, P-15).** Якщо g∞(ρ, s) = ρ для одного ρ, то K_ρ := S∞ × {ρ} додатно інваріантна; D∞|K_ρ спряжене з ρ; h_top = 0. **DP-f.** *Доведення.* На K_ρ: (s, ρ) ↦ (ρ(s), ρ). Проєкція на першу координату — топологічне спряження з ρ. ρ ∈ ℛ₀ нерозтягувальне, за D3 h_top(D∞|K_ρ) = h_top(ρ) = 0. D∞[K_ρ] ⊆ K_ρ; рівність тоді й лише тоді, коли ρ сюр'єктивне. ∎

### 11.4. Лема про вкладення і D5

**Лема 11.8 (E, P-14).** Нехай Y ⊆ S∞ компактна, T : Y → Y неперервна сюр'єктивна. κ_c(s) := c, R_Y := {κ_c}, g∞(κ_c, s) := κ_{T(c)}. Тоді:

1. R_Y ⊆ ℛ₀ компактна, g∞ неперервна (H виконано);
2. G := {(c, κ_{T(c)}) : c ∈ Y} компактний, D∞[G] = G, pr₁ : G → Y задає спряження D∞|G і T;
3. ω(x₀) ↔ ω_T(c), h_top(D∞|G) = h_top(T), Min(G) = Min(T), x₀ ATTAINED ⇔ ∃n: Tⁿ(c) ∈ ω_T(c).

**DP-f.** *Доведення.* j : Y → ℛ₀, j(c) := κ_c. Для c, c' ∈ Y: d_ℛ(κ_c, κ_{c'}) = sup_s d_S(c, c') = d_S(c, c'). Отже j — ізометричне вкладення; R_Y = j[Y] компактна і міститься в ℛ₀. За ідентифікацією R_Y ≅ Y відображення g∞(κ_c, s) = κ_{T(c)} відповідає неперервному T, не залежить від s, тому неперервне на R_Y × S∞. Отже (H) виконано.

Граф G компактний як неперервний образ компактного Y. Відображення h := pr₁|G : G → Y — гомеоморфізм з оберненим h⁻¹(c) = (c, κ_{T(c)}). Для c ∈ Y: D∞(c, κ_{T(c)}) = (T(c), κ_{T(T(c))}) ∈ G, тож D∞[G] ⊆ G. Навпаки, якщо (d, κ_{T(d)}) ∈ G, через сюр'єктивність T існує c ∈ Y з T(c) = d; тоді D∞(c, κ_{T(c)}) = (d, κ_{T(d)}). Отже D∞[G] = G і h ∘ D∞|G = T ∘ h.

Для x₀ = (c, κ_{T(c)}): xₙ = (Tⁿ(c), κ_{Tⁿ⁺¹(c)}). Через спряженість h переводить ω(x₀) у ω_T(c). Звідси збереження ATTAINED. Спряженість зберігає мінімальність: h — бієкція між непорожніми замкненими інваріантними підмножинами G і Y. Ентропія зберігається: h і h⁻¹ рівномірно неперервні на компактах, тому (n, ε)-роздільні множини переносяться з відповідними змінами ε, які не впливають на граничний показник. ∎

**EXT-1 (зовнішня теорема).** Існує непорожній замкнений мінімальний підзсув Z ⊆ {α, β}^ℕ з h_top(σ|Z) > 0.

Бібліографічний орієнтир: C. Grillenberger, "Construction of strictly ergodic systems I. Given entropy", *Z. Wahrscheinlichkeitstheorie verw. Geb.* 25 (1973), 323–334. Додаткове джерело: E. Glasner and B. Weiss, "Strictly ergodic, uniform positive entropy models", *Bull. Soc. Math. France* 122(3) (1994), 399–412, DOI 10.24033/bsmf.2239.

**Застереження про точну форму EXT-1.** Бібліографічний запис про існування строго ергодичних систем із додатною ентропією сам собою не замінює аргументу для саме одностороннього двійкового підзсуву Z. У фінальній публікації потрібно або навести точне джерело, або додати доведення переходу до зазначеної символічної моделі. До цього EXT-1 залишається окремою зовнішньою передумовою.

**Твердження 11.9 (D5, P-15).** За EXT-1: Y := t[Z], T := t∘σ∘t⁻¹. Для c ∈ Y точка x₀ = (c, κ_{T(c)}) має ω(x₀) = G (мінімальна, нескінченна, h_top > 0) і x₀ ∈ G, отже MIN_POS × ATTAINED; g∞ ≠ π_R. **DP-f за EXT-1.** *Доведення.* За лемою E G спряжене з Y. Спряженість зберігає мінімальність і ентропію; G нескінченна (Y нескінченна), мінімальна (Z мінімальний), h_top(D∞|G) > 0. Для x₀ ∈ G через мінімальність ω(x₀) = G, тож x₀ ∈ ω(x₀) — ATTAINED. ∎

**Твердження 11.10 (W5).** Y := t[{α, β}^ℕ], T := t∘σ∘t⁻¹. c = t(a), де кожне скінченне слово над {α, β} трапляється в a нескінченно багато разів. Для x₀ = (c, κ_{T(c)}): ω(x₀) = G, x₀ ∈ G, ATTAINED; G ≅ повний двійковий зсув, h_top = log 2 > 0, G не мінімальна. Отже NONMIN_POS × ATTAINED і CHAOTIC_set. **DP-f.** *Доведення (P-01).* ω_σ(a) = {α, β}^ℕ: кожен префікс z довжини N зустрічається нескінченно багато разів; відповідні зсуви збігаються до z. Ентропія повного зсуву d(x,y) = 2⁻ᵏ: для ε = ¾ s(n, ¾) = 2ⁿ (нижня оцінка: 2ⁿ різних префіксів); для довільного ε > 0 виберемо L з 2^{−(L+1)} < ε; якщо x, y збігаються на перших n + L символах, то dₙ(x, y) ≤ 2^{−(L+1)} < ε, тож s(n, ε) ≤ 2^{n+L}; отже limsup (1/n) log s(n, ε) ≤ log 2, і h_top = log 2. За лемою E h_top(D∞|G) = log 2. G містить α^∞ (нерухома), тому не мінімальна. ∎

### 11.6. Свідки W1–W4

**Лема 11.11 (стискаюче відображення; P-12).** Нехай (X, d) — непорожній повний метричний простір, Φ : X → X, d(Φ(x), Φ(y)) ≤ q·d(x, y), 0 ≤ q < 1. Тоді Φ має єдину нерухому точку x*, і Φⁿ(x₀) → x* для кожного x₀. **DP-f.**

*Доведення.* x₀ ∈ X, xₙ₊₁ := Φ(xₙ). d(xⱼ₊₁, xⱼ) ≤ qʲ d(x₁, x₀). Для m > n: d(xₘ, xₙ) ≤ ∑ⱼ₌ₙ^{m−1} d(xⱼ₊₁, xⱼ) ≤ d(x₁, x₀) qⁿ / (1 − q). Оскільки q < 1, (xₙ) — Коші. За повнотою X існує x* = lim xₙ. Φ неперервне (ліпшицеве), тому Φ(x*) = lim Φ(xₙ) = lim xₙ₊₁ = x*. Якщо y* — інша нерухома, d(x*, y*) = d(Φ(x*), Φ(y*)) ≤ q d(x*, y*), звідки x* = y*. ∎

**Прищеплення.** Для a ∈ A: ρ_a(f) := node(f, leaf(a), leaf(a)). ρ_a ін'єктивне, r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1, тож ρ_a ∈ ℛ₀ і стискаюче з коефіцієнтом ½.

- **W1 (FIXED × ATTAINED).** R = {ρ_a}, g∞ = π_R, x₀ = (p_a, ρ_a), де p_a — єдина нерухома точка ρ_a за лемою 11.11. DP-f.
- **W2 (FIXED × NONATTAINED).** x₀ = (s, ρ_a), s ≠ p_a. x_n → (p_a, ρ_a); ω = {(p_a, ρ_a)}. Потрапило б на кроці n лише при s = p_a. DP-f.
- **W3 (PERIODIC, обидва).** R = {ρ_a, ρ_b}, g∞(ρ_a, s) = ρ_b, g∞(ρ_b, s) = ρ_a. Φ := ρ_b∘ρ_a стискаюче з коефіцієнтом ¼, єдина нерухома точка q. Цикл {(q, ρ_a), (ρ_a q, ρ_b)}. ATTAINED: старт на циклі. NONATTAINED: s ≠ q, на циклі опинились б лише при Φᵏ s = q ⇒ s = q. DP-f.

- **W4 (MIN_ZERO × ATTAINED; одометр; P-11).** Нехай B := {0,1}^ℕ, C := {α, β}^ℕ (α ≠ β ∈ A). Визначимо O : B → B як додавання 1 у двійковому записі з переносом від координати 0 праворуч. Нехай e : B → C — координатна бієкція: e(a)ᵢ = α при aᵢ = 0, e(a)ᵢ = β при aᵢ = 1. Визначимо **Õ := e ∘ O ∘ e⁻¹ : C → C** (не Y → Y!). Нехай t : C → S∞ — вкладення §9.5, Y := t[C], і **T := t ∘ Õ ∘ t⁻¹ : Y → Y**. Тоді t ∘ e : B → Y — гомеоморфізм, що спряжує O і T.

Відображення e зберігає метрику першої розбіжності; за §9.5 d_S(t(e(a)), t(e(b))) = ½ d_B(a, b). Отже T — ізометрія на Y.

**Властивості O.** Ізометрія: якщо два слова збігаються на координатах 0, …, k − 1 і різняться на k, переноси до k однакові, тож після додавання 1 слова далі збігаються на координатах нижче k та різняться на k. Мінімальність: перші n координат орбіти a проходять усі 2ⁿ префіксів (зміна за модулем 2ⁿ); орбіта щільна; кожна непорожня замкнена додатно-інваріантна множина містить повну щільну орбіту, тому збігається з B. Періодичних точок немає: Oᵖ(a) = a вимагало б p ≡ 0 (mod 2ⁿ) для всіх n — неможливо.

Застосуємо лему 11.8 до Y і T. Одержуємо компактну інваріантну G ≅ одометр: мінімальна, нескінченна, без періодичних точок, h_top = 0 за D3 (T — ізометрія). Для x₀ ∈ G: ω(x₀) = G і x₀ ∈ G. Отже MIN_ZERO × ATTAINED. Також контрприклад C4b. **DP-f.**
