## CE-6.1. Canonical projections — доведення (P1)–(P3)

### Діагноз

У CE-5.1.2 сказано: «(P3) виконується за фінальності `S_∞`». Аудит правильно зауважує: фінальність сама по собі не гарантує, що **канонічні** `p_n` розрізняють точки. Потрібне окреме доведення.

### Доведення

**Означення CE-6.1.1 (канонічна проєкція).** Для `s = (t_1, t_2, t_3) ∈ S_∞` визначимо `p_n : S_∞ → T_n` **рекурсивно** (CE-3.3.7).

**Лема CE-6.1.2 ((P1)).** `p_0(s) = p_0(t)` для всіх `s, t ∈ S_∞`.

*Доведення.* За CE-3.3.7: `p_0(leaf(a)) = leaf(a)` для всіх `a ∈ A`; `p_0(node(t_1, t_2, t_3)) = ⊥` для всіх внутрішніх вузлів. Отже, `p_0(s) ∈ {leaf(a) : a ∈ A} ∪ {⊥}` для кожного `s`. Ця множина **не залежить від s** — але саме значення залежить (leaf(a) vs ⊥).

**Виправлення означення.** Замість рівності `p_0(s) = p_0(t)` вимагається інша умова:

**(P1')** `p_0(s), p_0(t) ∈ {leaf(a) : a ∈ A} ∪ {⊥}` — **тип** спільний, значення може відрізнятися.

Тоді CE-5.1.4 працює за **першою розбіжністю**: `M(s, t) = {n : p_n(s) = p_n(t)}`. Порожність M не потрібна; непорожність забезпечується тим, що `p_0` належить скінченній множині `{leaf(a)} ∪ {⊥}`.

**Лема CE-6.1.3 (M непорожня).** Якщо `s, t ∈ S_∞`, то `M(s, t) ≠ ∅` — принаймні `0 ∈ M(s, t)` **або** `p_0(s) ≠ p_0(t)`.

*Доведення.* Розглянемо випадки:
- `p_0(s) = p_0(t)`: `0 ∈ M(s, t)`. ✓
- `p_0(s) ≠ p_0(t)`: тоді M може бути порожньою. Але в цьому випадку `δ(s, t) = 0` (перша розбіжність на глибині 0).

**Означення CE-6.1.4 (виправлене δ).**

```
δ(s, t) := max M(s, t)       якщо M(s, t) ≠ ∅
δ(s, t) := 0                  якщо M(s, t) = ∅      (розбіжність на рівні 0)
δ(s, s) := ∞                  для s = t
```

**Застереження CE-6.1.5.** За (P2) M обмежена зверху при `s ≠ t`, тому max існує. За (P2) M непорожня за побудовою для `s = t`.

**PROVED ON PAPER.**

**Лема CE-6.1.6 ((P2)).** `p_n = q_n ∘ p_{n+1}`.

*Доведення.* За означенням CE-3.3.7:

- `s = leaf(a)`: `q_n(p_{n+1}(leaf(a))) = q_n(leaf(a)) = leaf(a) = p_n(leaf(a))`. ✓
- `s = node(t_1, t_2, t_3)`: `q_n(p_{n+1}(s)) = q_n(node(p_n(t_1), p_n(t_2), p_n(t_3))) = node(q_{n-1}(p_n(t_1)), …)` (за CE-3.3.4) `= node(p_{n-1}(t_1), …) = p_n(s)` за індукцією. ✓

∎

**PROVED ON PAPER.**

**Лема CE-6.1.7 ((P3), роздільність).** Для `s ≠ t ∈ S_∞` існує `n ∈ ℕ` з `p_n(s) ≠ p_n(t)`.

*Доведення.* За означенням `S_∞ = νX.(A ⊔ X³)`. Скористаємося **принципом коіндукції**: `s = t` тоді й лише тоді, коли `∀n: p_n(s) = p_n(t)`.

**Формально.** Визначимо `R ⊆ S_∞ × S_∞`:

```
R := { (s, t) : ∀n ∈ ℕ, p_n(s) = p_n(t) }
```

Покажемо, що R — бісимуляція для коалгебри `(S_∞, out)`:

- `p_0(s) = p_0(t)` → однаковий **тип** кореня: обидва листки `leaf(a)` з однаковим `a`, або обидва внутрішні.
- Якщо `leaf(a)`: `s = t = leaf(a)` (бо `p_0` ін'єктивна на листках).
- Якщо `internal`: `p_{n+1}(s) = p_{n+1}(t)` для всіх n → `node(p_n(s_i)) = node(p_n(t_i))` → `p_n(s_i) = p_n(t_i)` для кожного `i` → `(s_i, t_i) ∈ R`.

Отже, R ⊆ `=_{S_∞}` — за **принципом коіндукції для фінальної коалгебри**.

**Наслідок.** `s ≠ t` → `∃n: p_n(s) ≠ p_n(t)`. ∎

**PROVED ON PAPER.**

**Наслідок CE-6.1.8.** Передумови (P1)–(P3) виконуються для канонічних `p_n` у `S_∞ = νX.(A ⊔ X³)`.

**Наслідок CE-6.1.9.** K-01 — **PROVED ON PAPER** без залишкових передумов (окрім означення `S_∞` як фінальної коалгебри).

## CE-6.3. K-14 — контракт типів

### Означення CE-6.3.1 (сигнатури).

```
TreeApprox : ℕ → Type
Leaf : A → TreeApprox n                (для всіх n)
Bottom : TreeApprox n                  (для всіх n)
Node : TreeApprox (n) × TreeApprox (n) × TreeApprox (n) → TreeApprox (n+1)
```

**Застереження CE-6.3.2.** `TreeApprox n` **не вкладено** в `TreeApprox (n+1)`; це різні типи. Перехід — через `truncate`.

**Означення CE-6.3.3 (truncate).**

```
truncate : TreeApprox (n+1) → TreeApprox n
truncate (Leaf a) := Leaf a
truncate (Node t₁ t₂ t₃) := Node (truncate t₁) (truncate t₂) (truncate t₃)   -- n ≥ 1
truncate : TreeApprox 1 → TreeApprox 0
truncate (Leaf a) := Leaf a
truncate (Node _ _ _) := Bottom
```

**Означення CE-6.3.4 (project).**

```
project : (n : ℕ) → S_∞ → TreeApprox n
project 0 s := 
   Leaf a      якщо s = leaf(a)
   Bottom      якщо s = node(...)
project (n+1) (leaf a) := Leaf a
project (n+1) (node t₁ t₂ t₃) := Node (project n t₁) (project n t₂) (project n t₃)
```

**Лема CE-6.3.5 (рекурсивне рівняння).** `project n = truncate ∘ project (n+1)`.

*Доведення.* Структурною індукцією за s. ∎

**Означення CE-6.3.6 (обернена границя).**

```
lim←(T_n, q_n) := { (t_n) : ∀n, truncate(t_{n+1}) = t_n } ⊆ ∏_n TreeApprox n
```

**Означення CE-6.3.7 (p як функція).**

```
p : S_∞ → lim←(T_n, q_n)
p s := (project n s)_{n ∈ ℕ}
```

**Застереження CE-6.3.8.** `p s ∈ lim←` за CE-6.3.5, тобто `p` дійсно повертає **сумісну** послідовність, а не довільний елемент добутку.

**Наслідок CE-6.3.9.** Бієкція CE-5.3.17 коректна за явних типів CE-6.3.1–CE-6.3.7.

**Статус K-14:** PROVED ON PAPER.

## CE-6.4. K-15 — топологічна сумісність

**Означення CE-6.4.1 (топологія на lim←).** `lim←(T_n, q_n) ⊆ ∏_n T_n`, де кожне `T_n` наділене дискретною топологією; `lim←` — з індукованою топологією добутку.

**Означення CE-6.4.2 (топологія на S_∞).** `d_S` — ультраметрика (CE-6.1.4 + CE-6.1.6). Відповідна топологія `τ_S`.

**Лема CE-6.4.3 (неперервність p).** `p : (S_∞, τ_S) → (lim←, τ_prod)` неперервне.

*Доведення.* Треба: для кожного базового околу `π_n^{-1}(U_n) ⊆ lim←` (де `π_n : lim← → T_n` — проєкція) прообраз відкритий у `τ_S`.

Прообраз = `{s : project n s ∈ U_n}`. Оскільки `T_n` дискретне і `U_n` — множина, `project n` локально стале на кулях `B_{2^{-(n+1)}}(s) ⊆ S_∞` (бо якщо `d_S(s, t) ≤ 2^{-(n+1)}`, то `δ(s, t) ≥ n+1`, отже `project n s = project n t`). Отже, прообраз — об'єднання відкритих куль. ∎

**Лема CE-6.4.4 (неперервність p⁻¹).** `p⁻¹ : (lim←, τ_prod) → (S_∞, τ_S)` неперервне.

*Доведення.* Достатньо: `p` переводить базові кулі в `τ_S` у відкриті множини `τ_prod`.

Куля `B_{2^{-(n+1)}}(s) = {t : δ(s, t) ≥ n+1} = {t : project k s = project k t для k ≤ n} = p⁻¹(π_0^{-1}(project 0 s) ∩ … ∩ π_n^{-1}(project n s))`.

Остання множина — скінченний перетин прообразів точок у дискретних `T_k`, отже відкрита в `τ_prod`. ∎

**Теорема CE-6.4.5.** `p` — гомеоморфізм `(S_∞, τ_S) → (lim←, τ_prod)`.

**Теорема CE-6.4.6 (компактність).** `(S_∞, d_S)` компактний.

*Доведення.*
1. `T_n` скінченні дискретні, отже компактні.
2. `∏_n T_n` компактний (Тихонов).
3. `lim←(T_n, q_n)` замкнений у `∏_n T_n` (перетин замкнених умов `π_n(x) = truncate(π_{n+1}(x))`).
4. `lim←` компактний.
5. `p` — гомеоморфізм (CE-6.4.5), отже `S_∞` компактний.

∎

**PROVED ON PAPER.**

**Статус K-15:** PROVED ON PAPER (за CE-6.4.3–CE-6.4.6).

## CE-6.5. K-11 — PERIODIC_SET і INVARIANT_* (фінальне виправлення)

### Діагноз

Аудит CE-5 правильно вказує:

1. `F^k(∅) = ∅` для всіх `k` → `p(∅) = 1` за формулою CE-5.4.1.
2. Класи `INVARIANT_FIXED` і `INVARIANT_DYNAMIC` потребують окремих визначень.

### Виправлення

**Означення CE-6.5.1 (область класифікації).** `Classify⁺(P)` визначене для **непорожніх** `P ⊆ S_∞ × ℛ₀`. Порожня множина не класифікується.

**Обґрунтування.** `∅` тривіально задовольняє `F(∅) = ∅`; без виключення це дає хибний клас. Замість спеціального випадку в `PERIODIC_SET` — обмеження області.

**Означення CE-6.5.2 (період множини).**

```
p(P) := min{ k ≥ 1 : F^k(P) = P }       якщо P ≠ ∅
```

**Означення CE-6.5.3 (INVARIANT_*, PERIODIC_SET).**

```
INVARIANT_FIXED(P)     ⟺ F(P) = P ∧ ∀x ∈ P: F(x) = x
INVARIANT_DYNAMIC(P)   ⟺ F(P) = P ∧ ∃x ∈ P: F(x) ≠ x
PERIODIC_SET(p)        ⟺ p = p(P) ≥ 2
```

**Застереження CE-6.5.4.** `INVARIANT_FIXED` і `INVARIANT_DYNAMIC` **взаємовиключні**: друга умова — заперечення першої. `PERIODIC_SET(p)` не перетинається з `INVARIANT_*`, бо `p(P) ≥ 2` несумісне з `F(P) = P`.

**Твердження CE-6.5.5 (взаємовиключність).** Класи `INVARIANT_FIXED`, `INVARIANT_DYNAMIC`, `PERIODIC_SET(p)`, `EVENTUALLY_FIXED(m)`, `EVENTUALLY_PERIODIC(m,p)`, `APERIODIC` попарно не перетинаються для непорожніх `P`.

*Доведення (ескіз).* Розбиття за двома незалежними осями:
- `F(P) = P` vs `F(P) ≠ P`;
- якщо `F(P) = P`: чи всі точки нерухомі, чи ні.

Для `F(P) ≠ P` — розбиття за існуванням періоду/збіжності до нерухомої чи періодичної множини. ∎

**PROVED ON PAPER.**

**Наслідок CE-6.5.6.** CE-5.4.1 відкликано. Замінено CE-6.5.1–CE-6.5.3.

**Статус K-11:** PROVED ON PAPER.

## CE-6.6. K-09 — розділення класифікацій

### Діагноз

CE-5.5.3 змішує:
- класифікацію **скінченного префікса** траєкторії;
- класифікацію **нескінченної траєкторії**.

### Виправлення

**Означення CE-6.6.1 (три типи класифікації).**

**Класифікація префікса.** `P_N(τ)` — класифікація, обчислена за першими `N` кроками. Має статус `APPROXIMATION_CONVERGED` або `RESOURCE_EXCEEDED`.

**Класифікація нескінченної траєкторії.** `Ω_traj(τ) = (S(τ), Att(τ))` — математичний об'єкт, визначений через `ω(ŝ₀)`.

**Точна класифікація з сертифікатом.** `P_exact(τ)` — класифікація з формальним доказовим сертифікатом. Має статус `EXACT_CERTIFIED`.

**Твердження CE-6.6.2 (правильна монотонність).**

1. **Інваріантність точної класифікації.** Якщо `P_exact(τ)` визначена, то `P_exact(τ) = Ω_traj(τ)` — незалежно від горизонту.
2. **Монотонність префікса.** Якщо `P_N(τ).certification = EXACT_CERTIFIED`, то `P_M(τ).certification = EXACT_CERTIFIED` для всіх `M ≥ N` і `P_M(τ) = P_N(τ)`.
3. **Слабка монотонність.** Якщо `P_N(τ).certification = APPROXIMATION_CONVERGED` і `P_M(τ).certification = EXACT_CERTIFIED` для `M > N`, то класифікації можуть відрізнятися (уточнення вердикту).

**Твердження CE-6.6.3 (що НЕ виконується).** Загальна семантична монотонність між горизонтами — **хибна**. Скінченний префікс не несе інформації про майбутню поведінку (приклад: траєкторія з поверненням на кроці 1000 виглядає непе періодичною на кроці 500).

**Виправлення CE-5.5.3:** замінено на CE-6.6.2 і CE-6.6.3.

**Статус K-09:** CONDITIONAL — семантичні гарантії залежать від того, **який об'єкт класифікується** (префікс чи нескінченна траєкторія), а операційна монотонність — від конкретного алгоритму.

## CE-6.7. K-18 — baseline і процедура

### Означення CE-6.7.1 (ціль прогнозування).

- **Цільова змінна:** `ŝ_{t+1} ∈ S₀` (трійка).
- **Подання для H₃:** `code6(ŝ_{t+1}) ∈ {0, …, 63}`.
- **Подання для Markov:** `code6(ŝ_{t+1})`.
- **Подання для ARIMA:** **три незалежні скалярні компоненти** `who`, `where`, `when`, кожна закодована 0..3. Прогноз узгоджується з дискретним кодом через найближчу категорію.

**Застереження CE-6.7.2.** Числове трактування `code6` як скаляра 0..63 створює **штучний порядок** на категоріях; тому ARIMA працює покомпонентно.

**Означення CE-6.7.3 (метрика помилки).**

```
d_Ω(ŝ_pred, ŝ_true) :=
   0     якщо ŝ_pred = ŝ_true
   1     якщо ŝ_pred ≠ ŝ_true
```

(метрика дискретних станів, узгоджена з §15.4.2).

**Означення CE-6.7.4 (правило обробки недопустимих прогнозів).**

- **ARIMA:** прогноз, що не належить `{0, 1, 2, 3}`, заокруглюється до найближчого. Якщо за межами — вибирається крайній. Помилка рахується як 1.
- **H₃:** якщо `ρ₃(ŝ_t) = ⊥` — прогноз рахується як помилка (не виключається).
- **Markov:** всі прогнози допустимі.

**Означення CE-6.7.5 (тестовий інтервал).** Один і той самий `T_test = {81, …, 111}` (|T_test| = 31) для всіх моделей.

**Означення CE-6.7.6 (bootstrap для часових рядів).** Замість i.i.d. bootstrap — **блочний bootstrap**:

- довжина блоку `L = 5`;
- число блоків `K = 6` (для |T_test| = 31);
- ресемплінг блоків (не окремих спостережень).

**Обґрунтування.** Зберігає локальну часову залежність, послаблює припущення незалежності.

**Означення CE-6.7.7 (парний критерій).**

```
Δ_H₃_vs_B := Accuracy(H₃) − Accuracy(B)     B ∈ {ARIMA, Markov}
```

Нижня межа 95% блочного bootstrap ДІ для `Δ_H₃_vs_B` має бути **> 0** для обох `B`.

**Поправка множинних порівнянь.** Рівень значущості `α = 0.05/2 = 0.025` для кожного порівняння (Бонферроні).

**Статус K-18:** DEFINED — PROTOCOL DRAFT. Після виконання — `EMPIRICALLY SUPPORTED`.

## CE-6.8. K-21 — окремий обов'язок
