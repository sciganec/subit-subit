# P-01. Повне доведення ентропії W5

Місце: §11.4, твердження 11.10.

Проблема: початковий доказ обчислює кількість розділених множин лише для ε = ¾. Це доводить нижню оцінку ентропії, але не верхню.

Замінити доказ твердження W5 на такий:

**Твердження 11.10 (W5, NONMIN_POS × ATTAINED, без зовнішніх теорем).** Нехай Y := t[{α, β}^ℕ], T := t ∘ σ ∘ t⁻¹, де σ — односторонній повний зсув на двох символах. Виберімо c = t(a), де кожне скінченне слово над {α, β} трапляється в a нескінченно багато разів. Для x₀ = (c, κ\_{T(c)}) маємо ω(x₀) = G, x₀ ∈ G, а отже ATTAINED; G ≅ повний двійковий зсув, h_top = log 2 > 0, G не мінімальна. Тому реалізовано NONMIN_POS × ATTAINED і CHAOTIC_set. DP-f.

*Доведення.* Кожна точка z повного зсуву є граничною точкою орбіти a: для кожного N префікс z довжини N зустрічається в a на нескінченно багатьох позиціях. Можна вибрати зростаючу послідовність позицій появи; відповідні зсуви збігаються до z. Отже ω_σ(a) = {α, β}^ℕ.

Обчислимо топологічну ентропію повного зсуву в метриці d(x, y) = 2⁻ᵏ, де k — індекс першої розбіжності, а d(x, x) = 0. Нехай dₙ(x, y) = max\_{0 ≤ i < n} d(σⁱx, σⁱy).

Для ε = ¾ представники всіх 2ⁿ різних префіксів довжини n утворюють (n, ε)-розділену множину: дві різні послідовності розходяться в одній із перших n координат, тому після відповідного зсуву їхня відстань дорівнює 1. Водночас дві послідовності з однаковим префіксом довжини n мають dₙ ≤ ½. Тому s(n, ¾) = 2ⁿ, звідки h_top(σ) ≥ log 2.

Тепер доведемо верхню оцінку для довільного ε > 0. Виберімо ціле L ≥ 0 так, щоб 2⁻⁽ᴸ⁺¹⁾ < ε. Якщо дві послідовності мають однакові перші n + L символів, то після кожного зсуву σⁱ, 0 ≤ i < n, вони збігаються щонайменше на перших L + 1 символах. Отже dₙ(x, y) ≤ 2⁻⁽ᴸ⁺¹⁾ < ε.

Тому в кожній (n, ε)-розділеній множині може бути не більше одного представника для кожного префікса довжини n + L. Звідси s(n, ε) ≤ 2ⁿ⁺ᴸ. Отже

limsupₙ→∞ (1/n) log s(n, ε) ≤ log 2.

Оскільки L фіксоване для обраного ε, при n → ∞ доданок L log 2 / n прямує до нуля. Переходячи до границі ε → 0, одержуємо h_top(σ) ≤ log 2. Разом із нижньою оцінкою це дає h_top(σ) = log 2.

За лемою 11.8 ентропія зберігається при топологічному спряженні, тому h_top(D∞|G) = log 2. Множина G нескінченна й не мінімальна, оскільки містить нерухому точку, що відповідає α^∞, і водночас не збігається з нею. Нарешті, x₀ ∈ G = ω(x₀), тому ATTAINED. ∎

Наслідок: W5 залишається DP-f за наведеного доказу; залежність від EXT-1 не потрібна. Через W5 залишається доступним і свідок CHAOTIC_set у C5b.

## Підсумок застосування патчів

Математичні виправлення

W5 отримує повний доказ ентропії; W4 — узгоджені типи; `Min-code` більше не плутається з `Min_D`.
