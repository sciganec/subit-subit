## R3.1. Єдині позначення динаміки

### R3.1.1. Конфлікт позначень

У §6.1 та §11 v6.9.1 символ `F` досі використовується для динаміки, хоча деревний функтор уже позначено `F_tree`.

### Нормативна заміна

У LTL-семантиці §6.1 використовується довільна динамічна система `(X,D)`:

`x ⊨ XU ⟺ D(x) ∈ U`

`x ⊨ ◇U ⟺ ∃n ≥ 0: Dⁿ(x) ∈ U`

`x ⊨ ◇⁺U ⟺ ∃n ≥ 1: Dⁿ(x) ∈ U`

`x ⊨ □U ⟺ ∀n ≥ 0: Dⁿ(x) ∈ U`

`x ⊨ ↺U ⟺ ∃k > 1: Dᵏ(x) ∈ U`.

У §11 усі твердження про ω-граничні множини використовують `D∞`:

- `F(ω) = ω` → `D∞[ω] = ω`;
- `F(p) = p` → `D∞(p) = p`;
- `h_top(F|ω)` → `h_top(D∞|ω)`;
- `F`-інваріантна множина → `D∞`-інваріантна множина;
- «нерозтягувальність `F`» → нерозтягувальність `D∞`.

`F_tree` резервується виключно для функтора `X ↦ A ⊔ X³`.

**Статус:** редакційно-типізаційне виправлення; математична модель не змінюється.

## R3.2. Точне означення `μ(P)`, `π(P)` і шестикласової класифікації

### R3.2.1. Нормативні означення

Для непорожньої `P ⊆ X` та тотальної динаміки `D : X → X`:

`μ(P) := min{m ≥ 0 : ∃n > m, Dⁿ[P] = Dᵐ[P]}`,

якщо відповідна множина індексів непорожня; інакше `μ(P) := ∞`.

Якщо `μ(P) < ∞`, визначимо:

`π(P) := min{k ≥ 1 : D^{μ(P)+k}[P] = D^{μ(P)}[P]}`.

Якщо `μ(P) = ∞`, покладемо `π(P) := ∞`.

Також:

`p_set(P) := min{k ≥ 1 : Dᵏ[P] = P}`,

якщо такий `k` існує; інакше `p_set(P) := ∞`.

### R3.2.2. Виправлені умови класів

| Клас | Нормативна умова |
|---|---|
| `INVARIANT_FIXED` | `D[P] = P ∧ ∀x ∈ P, D(x) = x` |
| `INVARIANT_DYNAMIC` | `D[P] = P ∧ ∃x ∈ P, D(x) ≠ x` |
| `PERIODIC_SET` | `D[P] ≠ P ∧ μ(P) = 0 ∧ 2 ≤ p_set(P) < ∞` |
| `EVENTUALLY_FIXED` | `1 ≤ μ(P) < ∞ ∧ π(P) = 1` |
| `EVENTUALLY_PERIODIC` | `1 ≤ μ(P) < ∞ ∧ 2 ≤ π(P) < ∞` |
| `APERIODIC` | `μ(P) = ∞` |

Ця редакція замінює §4.1 таблицю умов, де для двох класів використовувалось `μ(P) ≥ 1` без явного обмеження `μ(P) < ∞`.

### R3.2.3. Розбиття

Для кожної непорожньої `P` виконується рівно один із шести випадків.

Якщо `D[P] = P`, множина належить `INVARIANT_FIXED` або `INVARIANT_DYNAMIC`.

Якщо `D[P] ≠ P`, але `μ(P) = 0`, існує період повернення множини до початкового образу; оскільки `D[P] ≠ P`, його мінімальний період не менший за два. Отримуємо `PERIODIC_SET`.

Якщо `1 ≤ μ(P) < ∞`, значення `π(P)` визначене й скінченне. Воно дорівнює або 1, або числу не меншому за 2, що дає `EVENTUALLY_FIXED` або `EVENTUALLY_PERIODIC`.

Нарешті, якщо повторення образів не існує, маємо `APERIODIC`.

**Статус C1:** `DP` після інтеграції R3.2.2 і за тотальності `D`.

## R3.3. Уточнення семантики проєкції `π_Ω`

### R3.3.1. Область проєкції

Попереднє формулювання `D_class := {Classify⁺(P)}` не вказує, за якими системами береться множина класифікацій.

Визначимо глобальну область:

`D_class := {Classify_D⁺(P) : (K,D) — допустима система, ∅ ≠ P ⊆ K}`.

Усі координати конкретного кортежу `Classify_D⁺(P)` обчислюються для тієї самої системи `(K,D)`.

### R3.3.2. Статус `NOT_APPLICABLE`

`ChaosStatus_D(P) = NOT_APPLICABLE` означає, що топологічний критерій хаотичності не має застосування до цієї множини за поточними передумовами.

Це не еквівалентно твердженню `NON_CHAOTIC`, оскільки останнє означає, що передумови виконані, але критерій хаотичності не виконується.

Оскільки `π_Ω` є грубою синтаксичною проєкцією, значення `APERIODIC_NON_CHAOTIC` за `ChaosStatus = NOT_APPLICABLE` читається лише як мітка відповідного класу проєкції. Воно **не доводить** нульової ентропії чи відсутності хаотичної поведінки в іншому, не заданому топологічному сенсі.

### R3.3.3. Тотальність і сюр’єктивність

**Твердження C5(a).** `π_Ω` тотальна на `D_class`, оскільки кожен кортеж має визначені `OrbitType`, `InclusionType` і `ChaosStatus`.

**Твердження C5(b).** Образ `π_Ω` є підмножиною шестикласової алгебри `Ω`.

Сюр’єктивність на всі шість класів дозволено заявляти лише для глобальної області, у якій наведені свідчення реалізовності кожного класу. Вона не є автоматичною властивістю проєкції для довільної фіксованої динаміки.

Для фіксованої скінченної системи образ `π_Ω` не може містити `CHAOTIC_set`, оскільки скінченні системи не мають додатної топологічної ентропії. Тому попереднє безумовне формулювання сюр’єктивності для довільної динаміки відкликається.

**Статус:** тотальність — `DP`; глобальна сюр’єктивність — `CONDITIONAL` до пред’явлення свідків для кожного класу.

## R3.4. Узгодження категорії Dyn з обмеженням `S ≠ ∅`

### R3.4.1. Діагноз

У §7 SUBIT допускає лише непорожні простори станів. Стандартна категорія `Dyn ≅ Fun(Bℕ, Set)` включає також об’єкт на порожній множині. Тому відображення всієї `Dyn` у поточну SUBIT не визначене для кожного об’єкта.

### R3.4.2. Мінімальне виправлення

Позначимо `Dyn₊` — повну підкатегорію `Dyn`, чиї об’єкти мають непорожній простір станів.

Тоді твердження про вкладення замінюється на:

**Твердження K5.** Існує повне й вірне вкладення:

`Dyn₊ ↪ SUBIT`

за формулою:

`(S,f) ↦ (S,{f},g_f)`, де `g_f(f,s) := f`.

Таке саме вкладення існує в `SUBIT_full`.

Доведення залишається покомпонентним: морфізм між одноелементними просторами правил визначений однозначно, а умова на станах рівносильна `φ ∘ f = h ∘ φ`.

Твердження `Dyn ≅ Fun(Bℕ,Set)` залишається чинним для стандартної категорії `Dyn`, але його не можна автоматично ототожнювати з вкладеною підкатегорією `Dyn₊`.

### R3.4.3. Поправка до Q2′

Замість запитання про буквальне включення `Dyn ⊆ C ⊆ SUBIT` запитувати:

> Чи існує категорія `C`, що містить образ `Dyn₊` у SUBIT і має топосну структуру, яка зберігає нетривіальну метаеволюцію?

Якщо принципово потрібне вкладення всієї `Dyn`, то SUBIT потребує окремого перегляду типу правил: замість обмеження `ℛ ⊆ S^S` слід використовувати ідентифікатори правил із функцією обчислення. Це вже зміна архітектури, не локальна правка.

## R3.5. Типізація асимптотичної метрики `d_ω`

### R3.5.1. Діагноз

`d_H` у §10.7 визначено для непорожніх компактних підмножин `S_∞`. Однак ω-граничні множини з §11 лежать у розширеному просторі `X = S_∞ × R`.

Тому вираз `d_H(ω(x),ω(y))` не типізується через метрику Хаусдорфа з §10.7 без додаткового означення.

### R3.5.2. Нормативна заміна

Нехай `(X,d̂)` — компактний метричний простір із гіпотези (H).

Для непорожніх компактних `P,Q ⊆ X` визначимо:

`d_H^X(P,Q) := max{ sup_{p∈P} inf_{q∈Q} d̂(p,q), sup_{q∈Q} inf_{p∈P} d̂(p,q) }`.

Тоді для `x,y ∈ X`:

`d_ω(x,y) := d_H^X(ω_D(x),ω_D(y)`.

Це псевдометрика на `X`: невід’ємність, симетрія та трикутна нерівність випливають із властивостей метрики Хаусдорфа. Вона дорівнює нулю для пар точок із однаковими ω-граничними множинами.

На факторі `X / ~`, де `x ~ y ⟺ ω_D(x)=ω_D(y)`, `d_ω` є метрикою.

Метрику `d_H` з §10.7 зберігаємо для компактних підмножин `S_∞`. Вона не замінює `d_H^X`.

**Статус:** `DP` за компактності `X` і визначеності ω-граничних множин.

## R3.6. Узгодження гіпотези (H) зі скінченною моделлю

У §10.2 сказано, що (H) для скінченного SUBIT⁺ тривіальна. Проте початкова (H) використовує простір дерев `S_∞` і метрику `d_S`, тому буквальне перенесення на `S₀` некоректне.

Замінити фразу «У скінченному SUBIT⁺ (H) тривіальне» на:

> Для скінченної моделі вводиться окрема передумова `(H₀)`: простір станів скінченний із дискретною топологією, динаміка `D₀` тотальна, а метаеволюція `g₀` тотальна. Будь-яке відображення між дискретними скінченними просторами неперервне. Передумова (H₀) не є екземпляром (H), оскільки простори станів і правил мають інші типи.

Це відокремлює топологічну теорію нескінченної моделі від скінченної автоматної реалізації.

## R3.7. Уточнення Pilot-01

### R3.7.1. Неможливість фальсифікації на скінченному просторі

У §13 гіпотеза сформульована як твердження про нульову ентропію при фіксованому правилі, але пілот проводиться на скінченній моделі.

Для тотальної динаміки на скінченному просторі кожна орбіта зрештою періодична, а ω-гранична множина скінченна. Її топологічна ентропія дорівнює нулю незалежно від додаткової гіпотези про `g∞` у нескінченній моделі.

Отже, такий пілот не може фальсифікувати твердження про нескінченну модель. Відсутність `CHAOTIC_ω` у скінченному тесті — очікувана властивість скінченного простору, а не незалежне свідчення на користь (D4).

### R3.7.2. Нормативна мета пілота

Pilot-01 визначається як **smoke-test реалізації**, а не експериментальна перевірка теореми D4.

Його перевірки:

1. усі орбіти у скінченній моделі повторюються в межах `|Q₀|+1` відвідувань станів;
2. класифікатор правильно визначає `m`, `p` і періодичний цикл;
3. у скінченній моделі класифікатор не видає `CHAOTIC_ω`;
4. результат `RESOURCE_EXCEEDED` не подається як доведена класифікація.

**Критерій провалу:** порушення хоча б однієї з цих властивостей.

Для тестування (D4) у нескінченній моделі потрібен незалежний математичний доказ або формальна перевірка, а не скінченний прогін.

## R3.8. Одометр і питання Q28

### R3.8.1. Конкретна побудова для замкненого підпростору правил

Нехай `Y ⊆ S_∞` — неперервно закодований простір двійкових послідовностей із топологією Кантора. Розгляньмо на `Y` одометр `T`, тобто додавання одиниці в 2-адичних координатах.

Для кожного `y ∈ Y` визначимо константне правило:

`ρ_y(s) := y`.

Кожне `ρ_y` належить `ℛ₀`, бо:

`d_S(ρ_y(s),ρ_y(t)) = 0 ≤ d_S(s,t)`.

Визначимо:

`R_Y := {ρ_y : y ∈ Y}`.

Оскільки `Y` компактний, а відображення `y ↦ ρ_y` неперервне, `R_Y` є компактною, отже замкненою підмножиною `ℛ₀`.

Задамо:

`g∞(ρ_y,s) := ρ_{T(y)}` для всіх `s ∈ S_∞`.

Це неперервна функція `R_Y × S_∞ → R_Y`, оскільки `T` неперервний. Отже, гіпотеза (H) виконується для `R = R_Y`.

Розгляньмо граф:

`Γ := {(y,ρ_{T(y)}) : y ∈ Y}`.

На ньому:

`D∞(y,ρ_{T(y)}) = (T(y),ρ_{T²(y)})`.

Отже, обмеження `D∞|_Γ` спряжене з одометром `T`. Оскільки одометр мінімальний і не має періодичних точок, `Γ` є нескінченною компактною інваріантною множиною з нетривіальною динамікою.

Таким чином, для допустимої системи з `R = R_Y ⊆ ℛ₀` існує приклад `INVARIANT_DYNAMIC`, у якому жодна точка не є періодичною.

### R3.8.2. Межа результату

Наведена конструкція працює для замкненого підпростору `R_Y` константних правил. Вона не доводить існування глобально неперервної метаеволюції на повному просторі `ℛ₀ × S_∞`, що реалізує ту саму поведінку.

Тому Q28 розділяється на два питання:

- **Q28a — CLOSED:** існування відповідного прикладу для деякого допустимого замкненого `R ⊆ ℛ₀`. Свідчення — конструкція R3.8.1.
- **Q28b — OPEN:** існування такого прикладу з глобально визначеною неперервною метаеволюцією на повному просторі `ℛ₀ × S_∞`.

Якщо старе Q28 стосувалося саме повного простору всіх причинних правил, його не можна оголошувати закритим лише на підставі R3.8.1.

## R3.9. Узгодити `d_S` та глибинні апроксимації

У §9.3 `d_S` визначено через першу адресу, де дві функції відрізняються, а попередні теореми реконструкції використовували апроксимації `d_n`.

Щоб виключити неоднозначність нормування, вводиться лема.

**Лема R3.9.1 (адресна глибина та апроксимації).** Для `f,g ∈ Tree_∞`, `f ≠ g`, визначимо:

`r_addr(f,g) := min{|σ| : f(σ) ≠ g(σ)}`,

`r_app(f,g) := min{n ≥ 0 : d_n(f) ≠ d_n(g)}`.

За індексацією `T_n` і рекурсивним означенням `d_n`:

`r_addr(f,g) = r_app(f,g)`.

**Обґрунтування.** Апроксимація `d_n` розрізняє мітки на глибині до `n` включно: листок зберігає мітку `a`, а вузол на фронтирі представляється `Bottom`. Якщо перша адресна розбіжність має глибину `k`, то всі мітки строго вище неї однакові, а відмінність листка/вузла або різних листкових міток уже видима в `d_k`. Для всіх `n < k` відповідні апроксимації збігаються. Отже, мінімальний рівень розбіжності дорівнює `k`.

Тому означення:

`d_S(f,g) := 2^{-r_addr(f,g)}`

узгоджується з попереднім формулюванням через `r_app`.

**Статус:** `DP`, за нормативного рекурсивного означення `d_n`.

## R3.10. Повнота означення `d_finite`

Твердження T8 використовує:

`d_finite(x,y) := sup_{n≥0} 2^{-n} d̂(D∞ⁿ(x),D∞ⁿ(y))`.

Для самодостатнього доведення додати таке обґрунтування.

1. Кожне відображення `(x,y) ↦ d̂(D∞ⁿ(x),D∞ⁿ(y))` задає псевдоультраметрику.
2. Її масштабування додатним коефіцієнтом `2^{-n}` також задає псевдоультраметрику.
3. Супремум сімейства псевдоультраметрик задовольняє ультраметричну нерівність.
4. Член із `n=0` дорівнює `d̂(x,y)`, тому `d_finite(x,y)=0` тягне `x=y`. Отже, це метрика.
5. Оскільки простір `X` компактний, `d̂` обмежена. Для великих `n` хвіст `2^{-n}d̂(D∞ⁿ(x),D∞ⁿ(y))` рівномірно малий.
6. Кожний скінченний набір ітерацій `D∞ⁿ` неперервний. Тому контроль перших скінченних членів разом із рівномірно малим хвостом показує, що `d_finite` і `d̂` задають ту саму топологію.

### R3.11.3. Залежність від L_prod

У §0.5 змінити формулювання «`d_S` прибирає залежність від `L_prod` і оберненої границі» на:

Це узгоджує історію змін з фактом, що §9.2 усе ще містить `L_prod`.
