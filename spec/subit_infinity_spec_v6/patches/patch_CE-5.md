## CE-5.1. Metric and Causality — K-01 (виправлення)

### Діагноз

CE-4.1.1 визначає `δ(s, t) := max{n : p_n(s) = p_n(t)}`. Доведення CE-4.1.3 (ключова тотожність) припускає:

- що множина `{n : p_n(s) = p_n(t)}` **непорожня** (містить принаймні 0);
- що вона **обмежена** (інакше max = ∞ для `s ≠ t`);
- що `δ(s, t) ≥ n ⟺ p_n(s) = p_n(t)`.

Без явних передумов ці властивості не випливають.

### Виправлення

**Означення CE-5.1.1 (передумови проєкцій).**

Система проєкцій `(p_n : S_∞ → T_n)_{n ∈ ℕ}` задовольняє:

**(P1) Коректність T_0.** `p_0(s) = p_0(t)` для всіх `s, t ∈ S_∞` (усі дерева однакові на рівні 0).

**(P2) Узгодженість.** `p_n = q_n ∘ p_{n+1}` для всіх `n ∈ ℕ`, де `q_n : T_{n+1} → T_n` — усічення з CE-3.3.4.

**(P3) Роздільність.** Для будь-яких `s ≠ t ∈ S_∞` існує `n ∈ ℕ` з `p_n(s) ≠ p_n(t)`.

**Застереження CE-5.1.2.** (P3) не випливає з означення `S_∞ = νX.(A ⊔ X³)` автоматично. Це окрема властивість коалгебри, яка еквівалентна екстенсіональності: два дерева рівні тоді й лише тоді, коли збігаються всі їхні скінченні усічення.

Для `S_∞ := νX.(A ⊔ X³)` (P3) **виконується** (стандартний результат теорії коалгебр: фінальні коалгебри екстенсіональні).

**Означення CE-5.1.3 (метрика).** Для `s, t ∈ S_∞`:

```
M(s, t) := { n ∈ ℕ : p_n(s) = p_n(t) }

δ(s, t) := max M(s, t)       якщо M(s, t) обмежена
δ(s, t) := ∞                  якщо M(s, t) = ℕ

d_S(s, t) := 2^{−δ(s, t)}    якщо δ < ∞
d_S(s, t) := 0                якщо δ = ∞
```

**Лема CE-5.1.4 (M обмежена).** Для `s ≠ t` множина `M(s, t)` обмежена.

*Доведення.* За (P3) існує `n` з `p_n(s) ≠ p_n(t)`. Тоді `n ∉ M(s, t)`. За (P2) усі `m ≥ n` також поза `M(s, t)` (бо якщо `p_m(s) = p_m(t)` для `m ≥ n`, то `p_n(s) = q_n(p_m(s)) = q_n(p_m(t)) = p_n(t)` — суперечність). Отже, `M(s, t) ⊆ {0, 1, …, n−1}`, обмежена. ∎

**PROVED ON PAPER** за передумов (P1)–(P3).

**Застереження CE-5.1.5.** Для `s = t`: `M(s, s) = ℕ`, отже `δ(s, s) = ∞` і `d_S(s, s) = 0` за означенням.

**Лема CE-5.1.6 (ключова тотожність, виправлена).** Для всіх `n ∈ ℕ` і `s, t ∈ S_∞`:

```
δ(s, t) ≥ n  ⟺  p_n(s) = p_n(t)
```

*Доведення.*

(⟹) Нехай `δ(s, t) ≥ n`. Якщо `δ(s, t) = ∞`, то `s = t` (за (P3)), отже `p_n(s) = p_n(t)`. Якщо `δ(s, t) = k < ∞`, то `k ∈ M(s, t)`, отже `p_k(s) = p_k(t)`. За (P2) для `m ≤ k`: `p_m(s) = q_m^k(p_k(s)) = q_m^k(p_k(t)) = p_m(t)`. Зокрема для `m = n ≤ k`. ✓

(⟸) Нехай `p_n(s) = p_n(t)`. Тоді `n ∈ M(s, t)`, отже `max M(s, t) ≥ n` (бо M обмежена зверху за CE-5.1.4 при `s ≠ t`; для `s = t` тривіально). Тому `δ(s, t) ≥ n`. ✓

∎

**PROVED ON PAPER.**

**Твердження CE-5.1.7 (еквівалентність причинності).** За передумов (P1)–(P3):

- **Префіксна причинність:** `f` причинна ⟺ `∀n, ∀s,t: p_n(s) = p_n(t) ⟹ p_n(f(s)) = p_n(f(t))`.
- **Метрична причинність:** `f` причинна ⟺ `∀s,t: d_S(f(s), f(t)) ≤ d_S(s, t)`.

Обидва означення еквівалентні.

*Доведення.* Як у CE-4.1.6, але з використанням виправленої CE-5.1.6 замість CE-4.1.3. ∎

**PROVED ON PAPER** за передумов (P1)–(P3).

**Наслідок CE-5.1.8.** §21.1.2 (`ℛ₀ ≅ {причинні функції}`) — **CONDITIONAL** до явного доведення:
- коректності `Comp` як коалгебри (`q_n ∘ f_{n+1} = f_n ∘ q_n`);
- взаємної оберненості двох відображень.

Раніше статус у CE-4.6 був PROVED; **знижено до CONDITIONAL**.

## CE-5.2. Finite Dynamical Metric — K-04 (виправлення)

### Діагноз

CE-4.2.3 виводить ультраметричність `d_finite` з ультраметричності `d̂`. Аудит правильно зауважує: потрібна **умова скінченності супрему** — інакше `d_finite` може дорівнювати ∞ для деяких пар.

### Виправлення

**Означення CE-5.2.1 (умова обмеженості).**

**(B1)** `d̂ : (S_∞ × ℛ₀)² → [0, 1]` (обмежена зверху 1).

**Застереження CE-5.2.2.** (B1) виконується автоматично за побудовою:
- `d_S(s, t) = 2^{-δ(s, t)} ≤ 2^0 = 1`;
- `d_ℛ(f, g) = 2^{-n₀(f, g)} ≤ 1`;
- `d̂ = max(d_S, d_ℛ) ≤ 1`.

Отже, (B1) — **теорема**, а не додаткова аксіома. Але її треба **явно вказати** як передумову, щоб уникнути неявного припущення.

**Твердження CE-5.2.3 (скінченність супрему).** За (B1) і за умови NF3':

```
d_finite(ŝ, t̂) := sup_{n ≥ 0} 2^{-n} · d̂(F^n ŝ, F^n t̂) ≤ 1
```

*Доведення.* Кожен член `2^{-n} · d̂(F^n ŝ, F^n t̂) ≤ 2^{-n} · 1 = 2^{-n} ≤ 1`. Супремум скінченної обмеженої послідовності скінченний. ∎

**PROVED ON PAPER.**

**Твердження CE-5.2.4 (ультраметрика).** За передумов CE-5.2.1, CE-4.2.2 (ультраметричність `d̂`) і NF3':

`d_finite` — ультраметрика на `S_∞ × ℛ₀`.

*Доведення.* Як у CE-4.2.3, з покликанням на скінченність супрему (CE-5.2.3). ∎

**PROVED ON PAPER.**

**Наслідок CE-5.2.5.** Якщо `d̂` не обмежена (не наш випадок) або `d̂` не ультраметрика, теорема не виконується. Обидві умови **явно перевіряються** у CE-5.2.1 і CE-4.2.2.

**Застереження CE-5.2.6.** NF3' не забезпечує ультраметричності `d_finite` — це функція `d̂`. NF3' забезпечує лише **визначеність** `F^n(ŝ)` для всіх `n`.

## CE-5.3. Inverse-Limit Reconstruction — K-14 (виправлення)

### Діагноз

CE-4.3.2 правильно відокремив неіснуючі позиції, але:

1. сигнатури типів (T_n, q_n, p_n, піддерева) не зафіксовані явно;
2. доказ сюр'єктивності залежить від фінальності `S_∞`, але це не доведено незалежно;
3. ін'єктивність `p` посилається на «стандартну бісимуляцію» без явного доведення.

### Виправлення

**Означення CE-5.3.1 (типи, явно).**

```
TreeApprox : ℕ → Type                  -- T_n (CE-3.3.1)
truncate : (n : ℕ) → TreeApprox (n+1) → TreeApprox n        -- q_n
project : (n : ℕ) → S_∞ → TreeApprox n                       -- p_n
```

**Застереження CE-5.3.2.** `S_∞ := νX.(A ⊔ X³)` — фінальна коалгебра функтора `Φ(X) := A ⊔ X³`.

**Передумова (C1).** `S_∞` існує як фінальна коалгебра `Φ` (за теоремою Ламбека–Руттена).

**Передумова (C2).** `truncate` і `project` задовольняють факторизацію: `project n = truncate n ∘ project (n+1)` (аналог CE-3.3.8).

**Передумова (C3).** Проєкції розділяють точки (P3 з CE-5.1.1).

**Означення CE-5.3.3 (позиція).** `σ ∈ {1, 2, 3}^{<ω}`.

**Означення CE-5.3.4 (існування позиції в t ∈ T_n).**

- `∅` існує в кожному `t ∈ T_n` (корінь).
- `σ · i` існує в `t`, якщо σ існує, `t(σ) = internal`, і `(t(σ))_i` визначене.

**Означення CE-5.3.5 (частковий state).** Для `(t_n) ∈ lim←` і позиції σ:

```
state(σ) := Some (t_{|σ|+1}(σ))   якщо σ існує в t_{|σ|+1}
state(σ) := None                   інакше
```

**Застереження CE-5.3.6.** `None` — позначка «позиція не існує»; відрізняється від значення ⊥-листка в `T_n`.

**Лема CE-5.3.7 (стабілізація існуючих позицій).** Якщо σ існує в `t_{|σ|+1}`, то:

1. σ існує в `t_n` для всіх `n ≥ |σ| + 1`;
2. `t_n(σ) = t_{n+1}(σ)` для всіх `n ≥ |σ| + 1`;
3. `state(σ) ∈ {leaf(a) : a ∈ A} ∪ {internal}`.

*Доведення.* Як у CE-4.3.4. ∎

**PROVED ON PAPER** за (C2).

**Означення CE-5.3.8 (коалгебра L).**

```
out_L : lim←(T_n, q_n) → A ⊔ (lim←(T_n, q_n))³

out_L((t_n)) :=
   inl a                            якщо state(∅) = Some (leaf(a))
   inr (u^{(1)}, u^{(2)}, u^{(3)})   якщо state(∅) = Some (internal)
```

де `u_m^{(i)} := (t_{m+1})|_i`.

**Застереження CE-5.3.9.** `state(∅)` визначений завжди (∅ існує в кожному `t_n`). Значення `state(∅) ∈ {leaf(a), internal}` (не ⊥, бо позиція ∅ не на фронтирному рівні).

**Лема CE-5.3.10 (L — коалгебра Φ).** `out_L` коректно визначена і `(lim←, out_L)` — коалгебра функтора Φ.

*Доведення.*

1. `state(∅) ∈ {leaf(a), internal}` (CE-5.3.7(3)).
2. Для гілки `internal`: `u^{(i)} ∈ lim←(T_m, q_m)` (сумісність дочірніх підпослідовностей, як у CE-4.3.6). ∎

**PROVED ON PAPER.**

**Означення CE-5.3.11 (реконструкція s).** За фінальністю `S_∞` (передумова C1) існує єдиний морфізм коалгебр:

```
s : (lim←, out_L) → (S_∞, out)
```

**Застереження CE-5.3.12 (незалежність).** Фінальність `S_∞` — **передумова** (C1), а не наслідок бієкції `p`. Це усуває кругову залежність CE-4.3.7.

**Твердження CE-5.3.13 (p ∘ s = id_lim←).** Для всіх `t ∈ lim←`, `n ∈ ℕ`: `p_n(s(t)) = t_n`.

*Доведення (індукція за n з універсальною гіпотезою IH(n)).*

**IH(n):** `∀u ∈ lim←, p_n(s(u)) = u_n`.

**База n = 0.**

- `state(∅) = leaf(a)`: `out(s(t)) = inl a`, `s(t) = leaf(a)`, `p_0(s(t)) = leaf(a)`. З іншого боку, `t_1(∅) = leaf(a)`, `t_0 = q_0(t_1) = leaf(a)`. ✓
- `state(∅) = internal`: `out(s(t)) = inr (s(u^{(1)}), s(u^{(2)}), s(u^{(3)}))`, `s(t) = node(...)`, `p_0(s(t)) = ⊥`. `t_1(∅) = internal`, `t_1 = node(...)`, `t_0 = q_0(t_1) = ⊥`. ✓

**Крок n → n+1.** Аналогічно, з використанням IH(n) на кожному `u^{(i)}` і узгодженості `t_{n+1} = node(u_n^{(1)}, u_n^{(2)}, u_n^{(3)})`. ∎

**PROVED ON PAPER.**

**Наслідок CE-5.3.14 (сюр'єктивність p).** Для будь-якого `t ∈ lim←` маємо `p(s(t)) = t`, отже `t ∈ p(S_∞)`. Тому `p` — сюр'єкція.

**Твердження CE-5.3.15 (ін'єктивність p).** Якщо `∀n, p_n(s) = p_n(t)`, то `s = t`.

*Доведення (через роздільність C3).*

Припустимо `s ≠ t`. За (C3) існує `n` з `p_n(s) ≠ p_n(t)` — суперечність з умовою. Отже, `s = t`. ∎

**PROVED ON PAPER.**

**Застереження CE-5.3.16 (виправлення CE-4.3).** У CE-4.3 ін'єктивність доводилася посиланням на «стандартну бісимуляцію». Тут — пряме доведення через (C3), яке не вимагає окремого визначення бісимуляції.

**Теорема CE-5.3.17 (бієкція).** `p : S_∞ → lim←(T_n, q_n)` — бієкція.

*Доведення.* Сюр'єктивність (CE-5.3.14) + ін'єктивність (CE-5.3.15). ∎

**PROVED ON PAPER** за передумов (C1)–(C3).

**Наслідок CE-5.3.18.** §13.4.2 — **PROVED** за (C1)–(C3).

## CE-5.4. PERIODIC_SET — K-11 (виправлення)

### Діагноз

**CE-4.5.2 містить логічну помилку.**

Запропоновано `p := min{k ≥ 2 : F^k(P) = P}`.

**Контрприклад.** Нехай `F(P) = P` (P інваріантна). Тоді `F²(P) = F(F(P)) = F(P) = P`, отже `p = 2`. Але множина інваріантна з періодом 1, а не 2.

**Наслідок.** Формула CE-4.5.2 класифікує **інваріантні множини** як `PERIODIC_SET(2)`.

**Це серйозна помилка в класифікації.**

### Виправлення

**Означення CE-5.4.1 (період множини).**

```
p(P) := min{ k ≥ 1 : F^k(P) = P }       якщо множина непорожня
p(P) := ∞                                інакше
```

**Застереження CE-5.4.2.** Рівність `F^k(P) = P` — **точна** (не ⊆). Для неін'єктивного `F` це суттєво.

**Означення CE-5.4.3 (PERIODIC_SET, остаточно).**

```
PERIODIC_SET(p) ⟺ p = p(P) ≥ 2
```

**Застереження CE-5.4.4.** Випадок `p(P) = 1` відповідає `INVARIANT_FIXED` або `INVARIANT_DYNAMIC`, а не `PERIODIC_SET`.

**Твердження CE-5.4.5 (взаємовиключність).** За CE-5.4.3:
- `p(P) = 1` → `INVARIANT_*`;
- `p(P) ≥ 2` → `PERIODIC_SET(p)`;
- `F^k(P) ≠ P` для всіх k ≥ 1 → ні `INVARIANT_*`, ні `PERIODIC_SET`; застосовується `EVENTUALLY_*` або `APERIODIC`.

*Доведення.* Пряме з визначень. ∎

**PROVED ON PAPER.**

**Наслідок CE-5.4.6.** CE-4.5.2 **відкликано**. Його замінює CE-5.4.1 і CE-5.4.3.

**Застереження CE-5.4.7 (для EVENTUALLY_*).** Класи `EVENTUALLY_FIXED(m)` і `EVENTUALLY_PERIODIC(m, p)` визначені **окремо** (див. §6.2.1). Вони не охоплюють автоматично всі множини з `F^k(P) ≠ P` для всіх k. Множини без жодного повернення належать `APERIODIC`.

## CE-5.5. Certification Semantics — K-18 (виправлення)

### Діагноз

CE-3.9 і CE-4.4 вводять три рівні сертифікації. Але:

1. узгодженість двох `EXACT_CERTIFIED` запусків вимагає, щоб вони стосувалися **того самого входу** і щоб класифікація була **однозначною функцією** входу;
2. емпіричний критерій CE-3.17 позначений `PROVED`, хоча це **протокол**, а не теорема.

### Виправлення

**Означення CE-5.5.1 (передумови узгодженості).**

1. **Ідентичність входу.** Сертифікати `C_1`, `C_2` стосуються **того самого** входу `τ` (формально визначеного, а не лише названого однаково).
2. **Однозначність класифікації.** Функція `Ω_traj(τ)` — однозначна: для фіксованого `τ` існує рівно одне значення `Ω_traj`.
3. **Коректність перевіряльника.** Незалежний перевіряльник підтверджує не лише формат сертифіката, а й те, що він доводить заявлений результат.

**Твердження CE-5.5.2.** За CE-5.5.1: якщо `C_1`, `C_2` — обидва `EXACT_CERTIFIED` для того самого `τ`, то `Ω_traj(C_1) = Ω_traj(C_2)`.

*Доведення.* Пряме з CE-5.5.1(1, 2). ∎

**PROVED ON PAPER.**

**Застереження CE-5.5.3 (семантична vs операційна монотонність).**

- **Семантична монотонність.** Якщо властивість `Ω_traj(τ)` доведена за горизонтом `N_1`, вона залишається істинною за будь-якого `N_2` (бо `Ω_traj` — властивість `τ`, а не `N`).
- **Операційна монотонність.** Довший запуск **не обов'язково** повертає не гірший сертифікат; він може вичерпати бюджет і повернути `RESOURCE_EXCEEDED`.

Це різні властивості. Семантична — властивість математичного об'єкта `τ`. Операційна — властивість конкретного алгоритму.

**Твердження CE-5.5.4 (що НЕ виконується).**

1. `EXACT_CERTIFIED_N_1` **не тягне** `EXACT_CERTIFIED_N_2` для `N_2 > N_1`.
2. `APPROXIMATION_CONVERGED_N_1` **не гарантує** узгодженості з `EXACT_CERTIFIED_N_2`.

**PROVED ON PAPER** (як заперечення загального твердження).

### CE-5.5.5. Емпіричний протокол (виправлення CE-3.17)

**Статус:** DEFINED — PROTOCOL DRAFT (не PROVED).

**Означення CE-5.5.6 (методологічні вимоги).**

1. **Часовий поділ.** Для часових рядів поділ `80 / 32` використовується лише за умови, що порядок даних відповідає реальному сценарію прогнозування. Випадкове перемішування не допускається.
2. **Довірчі інтервали.** Замість порівняння окремих ДІ для H₃, ARIMA, Markov — **парний bootstrap** для різниці:

```
Δ_B := Accuracy(H₃) − Accuracy(B)     B ∈ {ARIMA, Markov}
```

3. **Критерій переваги.** H₃ переважає базову модель `B`, якщо **нижня межа 95% ДІ** для `Δ_B` строго додатна.
4. **Множинні порівняння.** Якщо висувається перевага над двома baseline одночасно, застосовується поправка Бонферроні (рівень `α / 2` для кожного).
5. **Baseline подання.** Ціль прогнозу — трійка `ŝ_{t+1} ∈ S₀`. Для Markov-моделі — той самий `code6`. Для ARIMA — **числове** подання (цільове значення — скалярний `code6`, або три окремі компоненти — має бути зафіксовано в протоколі заздалегідь).
6. **Bootstrap.** 10 000 ресемплів тестової вибірки. Параметр процедури, а не гарантія.

**Статус:** DEFINED — PROTOCOL DRAFT.

**Застереження CE-5.5.7.** Емпіричний результат матиме статус `EMPIRICALLY SUPPORTED` лише після виконання за протоколом на фіксованих даних із SHA-256.

## CE-5.7. Контрольні моделі

**Модель A — префіксна метрика.**

- `M(s, s) = ℕ`, `δ(s, s) = ∞`, `d_S(s, s) = 0`.
- `s ≠ t`: знайти мінімальне `n` з `p_n(s) ≠ p_n(t)`; перевірити `δ(s, t) = n − 1`.
- Узгодженість `p_n = q_n ∘ p_{n+1}`.
- Роздільність: знайти пару `s ≠ t` з `p_n(s) = p_n(t)` для всіх `n < N` і `p_N(s) ≠ p_N(t)`.

**Модель B — d_finite.**

- Обмеженість `d̂ ∈ [0, 1]`.
- Тотальність `F` і NF3'.
- Контрприклад з **необмеженою** `d̂` (штучний, щоб показати, що CE-5.2.1 потрібна).

**Модель C — обернена границя.**

- Дві гілки: `state(∅) = leaf(a)` і `state(∅) = internal`.
- Позиція σ, яка **не існує** через предка-листок.
- Несумісна послідовність `(t_n)` (порушує `q_n(t_{n+1}) = t_n`) — має бути відкинута.
- Ін'єктивність: `s ≠ t ⟹ ∃n: p_n(s) ≠ p_n(t)`.

**Модель D — сертифікація.**

- `EXACT_CERTIFIED` для скінченної ω-границі.
- `APPROXIMATION_CONVERGED` для нескінченної ω.
- `RESOURCE_EXCEEDED` при вичерпанні бюджету.
- `PERIODIC_SET(1)`: інваріантна множина, не PERIODIC_SET(2).
- `PERIODIC_SET(2)`: множина з нетривіальним періодом.
