## CE-8.1. δ і d_S — повна дефініція (K-01)

### Діагноз

CE-7.1.4 записує `d_S(s, t) := 2^{−δ(s, t)}` без розгляду випадку `δ(s, t) = ∞`. Формально `2^{−∞}` не визначено в арифметиці дійсних чисел.

### Виправлення

**Означення CE-8.1.1 (δ).**

```
D(s, t) := { n ∈ ℕ : p_n(s) ≠ p_n(t) }

δ(s, t) := min D(s, t)           якщо D(s, t) ≠ ∅
δ(s, t) := ∞                      якщо D(s, t) = ∅
```

**Означення CE-8.1.2 (d_S, повне).**

```
d_S(s, t) := 0                    якщо δ(s, t) = ∞
d_S(s, t) := 2^{−δ(s, t)}         якщо δ(s, t) < ∞
```

**Застереження CE-8.1.3.** `δ(s, t) = ∞ ⟺ D(s, t) = ∅ ⟺ s = t` (за P3). Отже, `d_S(s, s) = 0` коректно, а `d_S(s, t) > 0` для `s ≠ t`.

**Твердження CE-8.1.4 (ультраметричність).** `d_S` — ультраметрика.

*Доведення.* Як у CE-7.1.5, з використанням повного означення CE-8.1.2. ∎

**Статус K-01:** PROVED ON PAPER — **CONDITIONAL** на K-14 (well-typed `p_n`, `q_n`, факторизація). Без цієї передумови доказ CE-7.1.3 не завершений.

## CE-8.2. Явна бієкція S_∞ ≅ lim← (K-14)

### Діагноз

CE-7.2.7 доводить лише `p(s) ∈ lim←`. Бієкція вимагає явної реконструкції `r : lim← → S_∞` і двох законів: `r ∘ p = id_{S_∞}`, `p ∘ r = id_{lim←}`.

### Виправлення

**Означення CE-8.2.1 (коалгебра L).** `L := lim←(T_n, q_n)`. Визначимо `out_L : L → A ⊔ L³`:

```
out_L((t_n)) :=
    inl a                             якщо state(∅) = Some (leaf(a))
    inr (u^(1), u^(2), u^(3))          якщо state(∅) = Some (internal)
```

де:
- `state(∅) := t_1(∅)` (позиція ∅ у дереві `t_1`);
- `u_m^(i) := (t_{m+1})|_i` (піддерево `t_{m+1}` на позиції `i`).

**Лема CE-8.2.2 (L — коалгебра Φ).** `(L, out_L)` — коалгебра функтора `Φ(X) = A ⊔ X³`.

*Доведення.*
1. `state(∅) ∈ {Some (leaf(a)), Some (internal)}` — бо ∅ не на фронтирному рівні `t_1`.
2. Для гілки `internal`: `u^(i) ∈ L`. Перевірка сумісності: `truncate_m(u_{m+1}^(i)) = u_m^(i)`, бо `t_{m+1} = truncate_{m+1}(t_{m+2})` і усічення комутує з піддеревами. ∎

**Означення CE-8.2.3 (реконструкція r).** За **фінальністю `S_∞`** (передумова C1 з CE-5.3) існує **єдиний** морфізм коалгебр:

```
r : (L, out_L) → (S_∞, out)
```

**Застереження CE-8.2.4.** `r` — це та сама `s`, що визначена в CE-5.3.7, але тут вона фіксується явно як функція `lim← → S_∞`.

**Лема CE-8.2.5 (p ∘ r = id_L).** Для всіх `t ∈ L` і `n ∈ ℕ`: `p_n(r(t)) = t_n`.

*Доведення (індукція за n з універсальною гіпотезою IH(n)).*

**IH(n):** `∀u ∈ L, p_n(r(u)) = u_n`.

**База n = 0.** За `out_L(t)`:
- `state(∅) = Some (leaf(a))`: `out(r(t)) = inl a`, отже `r(t) = leaf(a)`, `p_0(r(t)) = leaf(a)`. З іншого боку, `t_1(∅) = leaf(a)`, отже `t_0 = truncate_0(t_1) = leaf(a)`. ✓
- `state(∅) = Some (internal)`: `out(r(t)) = inr (r(u^(1)), r(u^(2)), r(u^(3)))`, отже `r(t) = node(...)`, `p_0(r(t)) = ⊥`. З іншого боку, `t_1(∅) = internal`, отже `t_0 = truncate_0(t_1) = ⊥`. ✓

**Крок n → n+1.**
- `state(∅) = Some (leaf(a))`: `r(t) = leaf(a)`, `p_{n+1}(r(t)) = leaf(a)`. Стабілізація: `t_m(∅) = leaf(a)` для всіх `m ≥ 1`, зокрема `t_{n+1} = leaf(a)`. ✓
- `state(∅) = Some (internal)`: `r(t) = node(r(u^(1)), r(u^(2)), r(u^(3)))`. Тоді `p_{n+1}(r(t)) = node(p_n(r(u^(1))), p_n(r(u^(2))), p_n(r(u^(3))))` за CE-7.2.5. За IH(n): `p_n(r(u^(i))) = u_n^(i) = (t_{n+1})|_i`. Отже `p_{n+1}(r(t)) = node((t_{n+1})|_1, (t_{n+1})|_2, (t_{n+1})|_3) = t_{n+1}` (бо `t_{n+1}(∅) = internal`). ✓

∎

**PROVED ON PAPER.**

**Лема CE-8.2.6 (p ін'єктивне).** Якщо `∀n: p_n(s) = p_n(t)`, то `s = t`.

*Доведення (через бісимуляцію).* Визначимо `R ⊆ S_∞ × S_∞`:

```
R := { (s, t) : ∀n ∈ ℕ, p_n(s) = p_n(t) }
```

Покажемо, що `R` — бісимуляція для коалгебри `(S_∞, out)`.

Нехай `(s, t) ∈ R`. Треба: `out(s) = (id_A ⊔ R³)(out(t))`.

- `p_0(s) = p_0(t) ∈ A ∪ {⊥}`.
- Якщо `p_0(s) = p_0(t) = leaf(a)`, то `s = t = leaf(a)` (бо `p_0` ін'єктивна на листках за CE-7.2.5). Тоді `out(s) = inl a = out(t)`. ✓
- Якщо `p_0(s) = p_0(t) = ⊥`, то `s, t` — внутрішні вузли. З `p_{n+1}(s) = p_{n+1}(t)` випливає `node(p_n(s_i)) = node(p_n(t_i))` для `i = 1, 2, 3`, отже `p_n(s_i) = p_n(t_i)`, отже `(s_i, t_i) ∈ R`. ✓

За **теоремою про бісимуляцію для фінальної коалгебри**: `R ⊆ =_{S_∞}`, тобто `(s, t) ∈ R ⟹ s = t`.

Отже `s ≠ t ⟹ ∃n: p_n(s) ≠ p_n(t)`. ∎

**PROVED ON PAPER** (за C1 — існування `S_∞` як фінальної коалгебри).

**Лема CE-8.2.7 (r ∘ p = id_{S_∞}).**

*Доведення.* Нехай `s ∈ S_∞`. Тоді `p(s) ∈ L`. За CE-8.2.5: `p_n(r(p(s))) = p_n(s)` для всіх n. За CE-8.2.6 (ін'єктивність): `r(p(s)) = s`. ∎

**PROVED ON PAPER.**

**Теорема CE-8.2.8 (бієкція).** `p : S_∞ → L` — бієкція з оберненим `r : L → S_∞`.

*Доведення.* CE-8.2.5 (`p ∘ r = id_L`) + CE-8.2.7 (`r ∘ p = id_{S_∞}`). ∎

**PROVED ON PAPER** за передумов C1 (фінальність), CE-7.2 (типізація).

**Застереження CE-8.2.9.** У CE-7.2 було лише показано, що `p` відображає `S_∞` у `L` — це **не** доводило бієкції. CE-8.2.8 завершує доведення через явне `r` і два закони.

**Статус K-14:** **PROVED ON PAPER**.

## CE-8.3. Топологія — виправлення радіуса (K-15)

### Діагноз

CE-7.3.2 стверджувало `C_n(s) = B_{2^{-(n+1)}}(s)`. Але за означенням `C_n(s)`:

```
C_n(s) = { t : p_k(t) = p_k(s) для всіх k ≤ n }
```

Це означає `δ(s, t) > n` (перша розбіжність після рівня n), отже `d_S(s, t) = 2^{−δ} < 2^{−n}`. Це **відкрита куля радіуса `2^{−n}`**, а не `2^{−(n+1)}`.

**Контрприклад.** Нехай `δ(s, t) = n + 1`. Тоді `d_S(s, t) = 2^{−(n+1)}`. За формулюванням CE-7.3.2 `t ∈ C_n(s)` (бо перша розбіжність на рівні `n + 1 > n`). Але `2^{−(n+1)} < 2^{−(n+1)}` — хиба. Отже, `t` не належить `B_{2^{-(n+1)}}(s)` (де строга нерівність).

### Виправлення

**Означення CE-8.3.1 (база циліндрів).** Для `s ∈ S_∞` і `n ∈ ℕ`:

```
C_n(s) := { t : p_k(t) = p_k(s) для всіх k ≤ n }
```

**Лема CE-8.3.2 (зв'язок з кулями).** `C_n(s) = B_{2^{-n}}(s)`.

*Доведення.*

(⊆) Якщо `t ∈ C_n(s)`, то `p_k(t) = p_k(s)` для `k ≤ n`, отже `δ(s, t) > n`, отже `d_S(s, t) < 2^{−n}`. ✓

(⊇) Якщо `d_S(s, t) < 2^{−n}`, то `δ(s, t) > n`, отже `p_k(t) = p_k(s)` для всіх `k ≤ n`, отже `t ∈ C_n(s)`. ✓ ∎

**PROVED ON PAPER.**

**Наслідок CE-8.3.3.** `{C_n(s)}_{s, n}` — база топології `τ_S`.

**Твердження CE-8.3.4 (p переводить базу в базу).** `p(C_n(s)) = D_n(p(s))`, де `D_n((t_k)) := { (u_k) ∈ L : u_k = t_k для k ≤ n }`.

*Доведення.* Пряме з означень. ∎

**PROVED ON PAPER.**

**Теорема CE-8.3.5 (гомеоморфізм).** За CE-8.2.8 (бієкція) і CE-8.3.4: `p : (S_∞, τ_S) → (L, τ_prod)` — гомеоморфізм.

**PROVED ON PAPER.**

**Статус K-15:** **PROVED ON PAPER** (за CE-8.2 і CE-8.3).

## CE-8.4. Динамічні класи — мінімальний період (K-11)

### Діагноз

CE-7.5.2 `EVENTUALLY_PERIODIC(m, p)` **перетинається** з `EVENTUALLY_FIXED(m)`.

**Контрприклад.** Нехай `P` така, що `F^{m+1}(P) = F^m(P) ≠ P` для мінімального `m ≥ 1`, і `∀k ≥ 1: F^k(P) ≠ P`.

Тоді:
- `EVENTUALLY_FIXED(m)` виконується.
- Для `p = 2`: `F^{m+2}(P) = F^{m+1}(P) = F^m(P)`. Отже `EVENTUALLY_PERIODIC(m, 2)` теж виконується (за умов CE-7.5.2).

Отже, попарна взаємовиключність CE-7.5.4 **хибна**.

### Виправлення

**Означення CE-8.4.1 (мінімальний період множини).** Для `P ≠ ∅` і `k ≥ 1`:

```
F^k(P) = P
```

визначає **точне повернення**. Мінімальний період:

```
p_set(P) := min{ k ≥ 1 : F^k(P) = P }       якщо множина непорожня
p_set(P) := ∞                                інакше
```

**Застереження CE-8.4.2.** `F^k(P) = P` — **точна рівність множин** (не ⊆). Для неін'єктивного `F` це суттєво.

**Означення CE-8.4.3 (шість класів, виправлено).**

```
INVARIANT_FIXED(P)      ⟺ F(P) = P ∧ ∀x ∈ P: F(x) = x
INVARIANT_DYNAMIC(P)    ⟺ F(P) = P ∧ ∃x ∈ P: F(x) ≠ x
PERIODIC_SET(p)         ⟺ p_set(P) = p ≥ 2
EVENTUALLY_FIXED(m)     ⟺ m = min{m ≥ 1 : F^{m+1}(P) = F^m(P) ≠ P}
                          ∧ F(P) ≠ P
                          ∧ ∀k ≥ 1: F^k(P) ≠ P
EVENTUALLY_PERIODIC(m, p)
                        ⟺ m = min{m ≥ 1 : ∃p ≥ 2: F^{m+p}(P) = F^m(P), F^m(P) ≠ P}
                          ∧ p_set(F^m(P)) = p ≥ 2
                          ∧ F^m(P) ≠ P
                          ∧ ∀k ≥ 1: F^k(P) ≠ P
APERIODIC(P)            ⟺ ∀m ≥ 1, ∀k ≥ 1: F^{m+k}(P) ≠ F^m(P)
```

**Застереження CE-8.4.4.** У `EVENTUALLY_PERIODIC` умова `p_set(F^m(P)) = p ≥ 2` **істотно**: вона вимагає, щоб стабілізована множина `F^m(P)` мала **нетривіальний** мінімальний період. Без неї випадок `p_set(F^m(P)) = 1` (стабілізація до нерухомої множини) потрапляв би в обидва класи.

**Твердження CE-8.4.5 (взаємовиключність).** Шість класів попарно не перетинаються.

*Доведення.*

Розбиття за двома осями.

**Ось 1: `F(P) = P`?**
- **Так:** `INVARIANT_FIXED` або `INVARIANT_DYNAMIC` (за умовою «всі точки нерухомі»).
- **Ні:**
  - `p_set(P) ≥ 2` → `PERIODIC_SET(p)`.
  - `∀k ≥ 1: F^k(P) ≠ P` (немає точного повернення):
    - `∃m ≥ 1: F^{m+1}(P) = F^m(P) ≠ P` з мінімальним m → `EVENTUALLY_FIXED(m)`.
    - `∃m ≥ 1, p ≥ 2: p_set(F^m(P)) = p` з мінімальним m → `EVENTUALLY_PERIODIC(m, p)`.
    - Інакше → `APERIODIC`.

**Взаємовиключність `EVENTUALLY_FIXED` і `EVENTUALLY_PERIODIC`:**
- Якщо `EVENTUALLY_FIXED(m)` виконується: `F^{m+1}(P) = F^m(P)`, отже `p_set(F^m(P)) = 1 < 2`. Умова `EVENTUALLY_PERIODIC` вимагає `p ≥ 2`, тому не виконується.
- Якщо `EVENTUALLY_PERIODIC(m, p)` виконується: `p_set(F^m(P)) = p ≥ 2`, отже `F^{m+1}(P) ≠ F^m(P)`. Умова `EVENTUALLY_FIXED` вимагає `F^{m+1}(P) = F^m(P)`, тому не виконується.

Інші пари взаємовиключні за побудовою. ∎

**PROVED ON PAPER.**

**Застереження CE-8.4.6 (вичерпність).** Шість класів вичерпні: будь-яка `P ≠ ∅` потрапляє рівно в один клас.

**Застереження CE-8.4.7 (INVARIANT_DYNAMIC ≠ періодичність точок).** Правильне твердження: `INVARIANT_DYNAMIC(P)` **не тягне** періодичність кожної точки `P`.

**Контрприклад (абстрактний, не S_∞).** `P = ℕ`, `F(n) = max(n − 1, 0)`. Тоді `F(P) = P`, `F(1) = 0 ≠ 1`, отже `INVARIANT_DYNAMIC(P)` виконується. Але точка `1` не періодична (`F^k(1) = 0` для `k ≥ 1`).

**Контрприклад у `S_∞ × ℛ₀`** — окремий обов'язок (Q28 ❓).

**Статус K-11:** **PROVED ON PAPER**.

## CE-8.5. Семантика сертифікації (K-09)

### Діагноз

CE-7.6.2.4 стверджує: `GLOBAL_EXACT_CERTIFIED` тягне `APPROXIMATION_CONVERGED(N)` для всіх N. Це **не випливає** з означень: точний математичний доказ може існувати навіть тоді, коли конкретний чисельний алгоритм не задовольняє свій критерій збіжності на короткому горизонті.

### Виправлення

**Означення CE-8.5.1 (три рівні, уточнено).**

```
PREFIX_CERTIFIED(N)
    Доведено твердження про префікс траєкторії довжини N.
    Не переноситься на всю траєкторію.

GLOBAL_EXACT_CERTIFIED
    Доведено твердження про нескінченну траєкторію.
    Доказ не залежить від горизонту обчислення.

APPROXIMATION_CONVERGED(N)
    Конкретний чисельний алгоритм виконав свій критерій збіжності
    на горизонті N. Не еквівалентно GLOBAL_EXACT_CERTIFIED.
```

**Твердження CE-8.5.2 (що виконується).**

1. `GLOBAL_EXACT_CERTIFIED` не залежить від горизонту N (об'єкт — вся траєкторія).
2. `PREFIX_CERTIFIED(N_1)` і `PREFIX_CERTIFIED(N_2)` для `N_1 ≠ N_2` — різні твердження.
3. `APPROXIMATION_CONVERGED(N_1)` і `APPROXIMATION_CONVERGED(N_2)` — можуть бути неузгодженими.

**Твердження CE-8.5.3 (що НЕ виконується).**

1. `PREFIX_CERTIFIED(N_1)` **не тягне** `PREFIX_CERTIFIED(N_2)`.
2. `APPROXIMATION_CONVERGED(N_1)` **не гарантує** `GLOBAL_EXACT_CERTIFIED`.
3. **Відкликано з CE-7.6.2.4:** `GLOBAL_EXACT_CERTIFIED` **не тягне** `APPROXIMATION_CONVERGED(N)` автоматично.

**Застереження CE-8.5.4.** Пункт 3 може бути відновлений як **додаткова аксіома** для конкретного алгоритму, який довів, що його критерій збіжності виконується для всіх N, де існує `GLOBAL_EXACT_CERTIFIED`. Це властивість алгоритму, а не загальна теорема.

**PROVED ON PAPER** (як контрприклади до попередніх формулювань).

**Статус K-09:** **CONDITIONAL** (потребує узгодження рівнів сертифікації з конкретними алгоритмами).

## CE-8.6. Статистичний протокол — часові індекси (K-18)

### Діагноз

CE-7.7.8 визначає `T_test = {81, …, 111}` як прогнозні моменти і цільові стани `ŝ_{t+1}`. Але тоді цільові стани — `ŝ_{82}, …, ŝ_{112}`, а не `ŝ_{81}, …, ŝ_{111}`. Потрібна явна схема.

### Виправлення

**Означення CE-8.6.1 (схема A — остаточно).**

- **Навчальні трійки:** `ŝ_1, …, ŝ_80`.
- **Прогнозні моменти (тест):** `t ∈ T_test = {81, 82, …, 111}` (31 момент).
- **Цільові стани:** `ŝ_{t+1}` для `t ∈ T_test`, тобто `ŝ_{82}, …, ŝ_{112}` (31 ціль).
- **Загальний ряд:** `ŝ_1, …, ŝ_{112}` — 112 трійок.

**Застереження CE-8.6.2.** Трійка `ŝ_{112}` використовується **лише** як ціль; вона не є входом прогнозу.

**Означення CE-8.6.3 (метрика і політика).**

- Метрика: `d_Ω(ŝ_pred, ŝ_true) ∈ {0, 1}` (CE-7.7.6).
- `|T_test| = 31`.
- H₃: якщо `ρ₃(ŝ_t) = ⊥` — помилка.
- ARIMA: три компоненти, заокруглення до `{0, 1, 2, 3}` за CE-7.7.6.
- Markov: всі прогнози допустимі.

**Означення CE-8.6.4 (рухомий блок bootstrap).**

- Довжина блоку `L = 5`.
- Кількість можливих блоків: `K = |T_test| − L + 1 = 27`.
- Кількість блоків у ресемплі: `⌈|T_test| / L⌉ = 7`.
- Нижня межа одностороннього 97.5% ДІ для `Δ_B = Accuracy(H₃) − Accuracy(B)`: 250-та порядкова статистика з 10000 bootstrap-реплік (для 97.5% квантиля).

**Застереження CE-8.6.5.** Обґрунтування `L = 5` — попередній аналіз автокореляції. Аналіз чутливості: `L ∈ {3, 5, 10}` — звітується окремо. Конкретні значення автокореляції потребують перевірки на фактичному ряді (Q27 ❓).

**Статус K-18:** **DEFINED — PROTOCOL DRAFT** (до виконання експерименту).
