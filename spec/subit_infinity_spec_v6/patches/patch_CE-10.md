## CE-10.0. Принцип

Модель D підтвердила контрприклад `b = (Bottom₀, Bottom₁, …) ∈ lim← ∖ L_prod` і тим самим остаточно відкинула бієкцію `S_∞ ≅ lim←`. Разом із цим аудит виявив три **залишкові** проблеми в CE-9:

1. **K-14.** Доведення бієкції `S_∞ ≅ L_prod` вимагає **окремої леми про рекурсивну продуктивність** дочірніх гілок. Без неї індукційний крок у CE-9.2.1 спирається на неявне припущення.
2. **K-15.** Доведення компактності потребує завершення двох частин — повноти і цілковитої обмеженості — із правильним вибором представників (повні дерева, а не усічені об'єкти).
3. **K-09.** Правило перенесення сертифікатів містить **логічну помилку в напрямку імплікації**: властивість «перші N кроків не повторюються» не монотонна в бік зростання N; типовим є **спадний** напрям `P(N+1) ⟹ P(N)`.

Крім того, аудит D5 правильно зауважує: класифікація орбіти в CE-9.7 має розглядати **будь-яку пару** елементів орбіти, а не лише рівність `F^k(P) = P`.

**Правило CE-10:** кожне з чотирьох виправлень має явне доведення і, де застосовно, контрприклад-перевірку.

## CE-10.1. Рекурсивна продуктивність дочірніх гілок (K-14)

### Діагноз

CE-9.2.1 у кроці сюр'єктивності застосовує індукційну гіпотезу до `u^{(i)} = (u_m^{(i)})_m`, але **не доводить**, що кожне `u^{(i)} ∈ L_prod`. Крок `(ii) → всі дочірні lim_tree визначені` — це **не наслідок** означення `L_prod`, а окрема властивість, яку треба довести.

### Формальна лема

**Означення CE-10.1.1 (зсув позиції).** Для `σ ∈ {1, 2, 3}^{<ω}` і `i ∈ {1, 2, 3}`:

```
σ · i := (σ₁, …, σₖ, i) ∈ {1, 2, 3}^{<ω}
```

**Лема CE-10.1.2 (продуктивність).**

Нехай `(t_n) ∈ L_prod`. Тоді:

**(a)** Для будь-якої позиції `σ` такої, що `lim_tree(σ) = Node`, і для кожного `i ∈ {1, 2, 3}`: `lim_tree(σ · i)` визначено.

**(b)** Для будь-якої позиції `σ` такої, що `lim_tree(σ) = Node`, послідовність `u^{(σ, i)} := ((t_{m+|σ|+1})|_{σ·i})_m` належить `L_prod`.

*Доведення.*

**(a)** Нехай `lim_tree(σ) = Node`. За означенням `lim_tree` існує `N` таке, що для всіх `n ≥ N`: `t_n(σ) = Node_{...}` (внутрішній вузол). Отже, у дереві `t_n` позиція `σ` має трьох нащадків `σ · 1, σ · 2, σ · 3`. За означенням `T_n` (CE-7.2.1), нащадки мають мітки з `A ∪ {Bottom_n}`. Отже, для `n ≥ N + 1`: `t_n(σ · i) ∈ Leaf(A) ∪ Node ∪ {Bottom}`.

Треба: `lim_tree(σ · i)` **визначено**, тобто існує `M` таке, що для всіх `m ≥ M`: `t_m(σ · i) ≠ Bottom_m`.

Припустимо супротивне: `t_m(σ · i) = Bottom_m` для всіх `m` (або для нескінченно багатьох m без стабілізації). За (P2) `t_m(σ · i) = truncate_m(t_{m+1})(σ · i) = truncate_m(t_{m+1}(σ · i))`. Якщо `t_{m+1}(σ · i)` — внутрішній вузол, то `t_m(σ · i)` — теж внутрішній вузол. Отже, якщо `t_m(σ · i) = Bottom_m` для деякого m, то `t_{m+1}(σ · i) = Bottom_{m+1}` (усічення не може «підняти» Bottom до вузла).

Отже, `t_m(σ · i) = Bottom_m` для всіх m ≥ деякого m₀ ⟹ `lim_tree(σ · i)` не визначено. Це суперечить умові (ii) з CE-9.1.5, яка вимагає: для кожного σ з `lim_tree(σ) = Node` і кожного i, `lim_tree(σ · i)` **визначено**. Отже, такого m₀ не існує; `lim_tree(σ · i)` визначено. ✓

**(b)** Нехай `u^{(σ, i)} := ((t_{m+|σ|+1})|_{σ·i})_m`. Треба:

- `u^{(σ, i)} ∈ lim←`. Перевіримо сумісність. Для кожного m:
  ```
  truncate_m(u_{m+1}^{(σ, i)}) = truncate_m((t_{m+|σ|+2})|_{σ·i})
                                = (truncate_{m+|σ|+1}(t_{m+|σ|+2}))|_{σ·i}
                                = (t_{m+|σ|+1})|_{σ·i}
                                = u_m^{(σ, i)}
  ```
  (використано, що `truncate` комутує з піддеревами за CE-7.2.3).
- `u^{(σ, i)} ∈ L_prod`. Треба: (i) і (ii) з CE-9.1.5.

  **(i)** `lim_tree` для `u^{(σ, i)}`: корінь відповідає позиції `∅` у кожному `(t_{m+|σ|+1})|_{σ·i}`. За (a) `lim_tree(σ · i)` визначено, отже корінь `u^{(σ, i)}` визначено. ✓

  **(ii)** Для будь-якої позиції `τ` у `u^{(σ, i)}` з `lim_tree(τ) = Node`: за (a), застосованою до `σ · i · τ`, `lim_tree(σ · i · τ · j)` визначено для кожного j. Отже, у `u^{(σ, i)}` всі дочірні гілки визначені. ✓

∎

**PROVED ON PAPER.**

### Застосування до бієкції

**Твердження CE-10.1.3 (сюр'єктивність, фінальне).** `p : S_∞ → L_prod` — сюр'єкція.

*Доведення.*

Нехай `(t_n) ∈ L_prod`. Покладемо `s := lim_tree((t_n)) ∈ S_∞` (за означенням `L_prod`).

**Індукція за рівнем n** (як у CE-9.2.1, але з явним використанням CE-10.1.2):

**База n = 0.** За (i) CE-9.1.5 `lim_tree(∅) ∈ {Leaf(a), Node}`.
- `Leaf(a)`: `t_0 = truncate_0(t_1) = Leaf(a) = p_0(leaf(a)) = p_0(s)`. ✓
- `Node`: `t_0 = truncate_0(t_1) = Bottom_0 = p_0(node(...)) = p_0(s)`. ✓

**Крок n → n+1.** Нехай `lim_tree(∅) = Node`. Тоді `s = node(s_1, s_2, s_3)`, де `s_i := lim_tree((u^{(i)}))` з `u^{(i)} := u^{(∅, i)}`.

За CE-10.1.2(b): `u^{(i)} ∈ L_prod`. За індукційною гіпотезою, застосованою до `u^{(i)}`: `p_n(s_i) = u_n^{(i)} = (t_{n+1})|_i`.

Тоді:
```
p_{n+1}(s) = Node_n(p_n(s_1), p_n(s_2), p_n(s_3))
           = Node_n((t_{n+1})|_1, (t_{n+1})|_2, (t_{n+1})|_3)
           = t_{n+1}
```
(остання рівність — бо `t_{n+1}(∅) = Node` і `t_{n+1}` = Node з трьома піддеревами).

Для `lim_tree(∅) = Leaf(a)`: `s = leaf(a)`, `p_{n+1}(s) = leaf(a) = t_{n+1}` (бо `t_m(∅) = leaf(a)` для всіх `m ≥ 1`). ✓

∎

**PROVED ON PAPER.**

**Теорема CE-10.1.4 (бієкція).** `p : S_∞ → L_prod` — бієкція.

*Доведення.* Ін'єктивність — CE-8.2.6 (як у CE-9.2.1). Сюр'єктивність — CE-10.1.3. ∎

**PROVED ON PAPER.**

**Наслідок CE-10.1.5.** K-14 — **PROVED ON PAPER** (з урахуванням CE-10.1.2).

## CE-10.2. Компактність S_∞ через повноту і цілковиту обмеженість (K-15)

### Діагноз

CE-9.5 визнав компактність `CONDITIONAL` і запропонував два шляхи. Аудит D4.2 правильно зауважує:

- «представники `s ∈ S_∞^{(N)}`» мають бути **повними** деревами, а не об'єктами `T_n` з `Bottom`;
- потрібна явна фіксація скінченності `A` і того, що кожен внутрішній вузол має рівно три дочірні гілки.

### Шлях A: прямий доказ компактності

**Передумови CE-10.2.1.**

- **(P-Fin)** `A` — скінченний (|A| = 4 за §1.1).
- **(P-Tree)** `S_∞ = νX.(A ⊔ X³)` — фінальна коалгебра; кожен вузол або `Leaf(a)` з `a ∈ A`, або `Node` із рівно трьома піддеревами.

**Означення CE-10.2.2 (усічення на глибині n).** Нехай `p_n : S_∞ → T_n` — проєкція (CE-7.2.5).

**Твердження CE-10.2.3 (повнота).** `(S_∞, d_S)` повний.

*Доведення.*

Нехай `(s_k)_{k ∈ ℕ}` — послідовність Коші. Треба: збіжна.

**Стабілізація префіксів.** Для кожного `n ∈ ℕ` виберемо `N(n)` так, щоб `∀k, l ≥ N(n): d_S(s_k, s_l) < 2^{-n}`. За означенням `d_S`: `δ(s_k, s_l) > n ⟺ p_m(s_k) = p_m(s_l) для m ≤ n`. Отже, `(p_n(s_k))_k` стабілізується при `k ≥ N(n)`.

Позначимо `t_n^* := lim_k p_n(s_k) ∈ T_n` (межа стабілізованої послідовності).

**Сумісність граничних апроксимацій.** За (P2): `p_n = truncate_n ∘ p_{n+1}`. Отже, `t_n^* = truncate_n(t_{n+1}^*)`.

**Граничне дерево.** За `(t_n^*)_n ∈ lim←(T_n, q_n)`. Треба перевірити `∈ L_prod`:
- **Умова (i).** `t_1^*(∅) ∈ Leaf(A) ∪ Node ∪ {Bottom}`. Але для `k ≥ N(1)`, `p_1(s_k) ≠ Bottom_1` (бо `s_k ∈ S_∞` — повне дерево, корінь не Bottom). Отже, `t_1^*(∅) ≠ Bottom`; `lim_tree(∅)` визначено. ✓
- **Умова (ii).** Аналогічно для будь-якої позиції σ з `lim_tree(σ) = Node`.

Отже, `(t_n^*) ∈ L_prod`, і `s^* := lim_tree((t_n^*)) ∈ S_∞` за бієкцією CE-10.1.4.

**Збіжність.** Для `k ≥ N(n)`: `p_m(s_k) = t_m^* для m ≤ n`, отже `d_S(s_k, s^*) < 2^{-n}`. Тому `s_k → s^*`. ✓ ∎

**PROVED ON PAPER.**

**Означення CE-10.2.4 (представники).** Для `N ∈ ℕ` визначимо:

```
S_∞^{(N)} := { s ∈ S_∞ : depth(s) ≤ N або усі гілки s глибини N вже встановлені }
```

**Застереження CE-10.2.5.** Це **не** `T_N`. `S_∞^{(N)}` — множина **повних** дерев, у яких усі вузли глибини `≥ N` замінені на фіксований шаблон (наприклад, `Node(Leaf(a₀), Leaf(a₀), Leaf(a₀))` для всіх листків). Отже, `S_∞^{(N)} ⊆ S_∞`.

**Лема CE-10.2.6 (скінченність представників).** `|S_∞^{(N)}| < ∞` для кожного N.

*Доведення.* Індукція за N.
- `N = 0`: `S_∞^{(0)} = { τ₀ }`, де `τ₀` — фіксований шаблон. `|S_∞^{(0)}| = 1`.
- `N + 1`: `S_∞^{(N+1)}` скінченне, бо кожен вузол визначається за скінченним префіксом глибини ≤ N+1; загальна кількість таких префіксів — `∏_{k=0}^{N+1} (|A| + 1)^{3^k}` — скінченне. ∎

**PROVED ON PAPER.**

**Твердження CE-10.2.7 (цілковита обмеженість).** `(S_∞, d_S)` цілком обмежений.

*Доведення.*

Нехай `ε > 0`. Виберемо N так, щоб `2^{-N} < ε`.

**ε-мережа.** Множина `S_∞^{(N)}` скінченна (CE-10.2.6) і `ε`-щільна: для будь-якого `s ∈ S_∞` існує `s' ∈ S_∞^{(N)}` таке, що `p_m(s) = p_m(s')` для всіх `m ≤ N`. Тоді `δ(s, s') ≥ N + 1`, отже `d_S(s, s') ≤ 2^{-(N+1)} < 2^{-N} < ε`.

Отже, `S_∞^{(N)}` — скінченна ε-мережа. ∎

**PROVED ON PAPER.**

**Теорема CE-10.2.8 (компактність S_∞).** `(S_∞, d_S)` компактний.

*Доведення.* Повний (CE-10.2.3) і цілком обмежений (CE-10.2.7) метричний простір компактний (Гейне–Борель–Больцано–Вейєрштрасс). ∎

**PROVED ON PAPER** за передумов (P-Fin), (P-Tree).

**Наслідок CE-10.2.9.** K-15 — **PROVED ON PAPER**.

**Застереження CE-10.2.10.** Якщо `A` нескінченний, доказ не працює: `S_∞^{(N)}` нескінченне для N = 0. Це **Q26 (❓)**, і воно лишається відкритим.

**Застереження CE-10.2.11.** Доведення **не** використовує компактності `lim←`; воно не залежить від `L_prod ⊊ lim←`.

## CE-10.3. Правила перенесення сертифікатів (K-09)

### Діагноз

CE-9.6 визначив MP так: «перші N кроків не повторюються». Але ця властивість **не є** MP у сенсі `P(N) ⟹ P(N+1)`. Навпаки: вона **спадна**: якщо перші N+1 кроків не повторюються, то перші N кроків тим більше не повторюються. Тобто:

```
P(N+1) ⟹ P(N).
```

Це **протилежний** напрямок від того, який був у CE-9.6.1.

### Виправлення

**Означення CE-10.3.1 (типи властивостей префікса).**

- **PH (Prefix-Hereditary).** `P(N+1) ⟹ P(N)`.
  Приклад: «на перших N кроках немає повторень».
- **EP (Extension-Preserving).** `P(N) ⟹ P(N+1)`.
  Приклад: **потрібно обґрунтовувати окремо** для кожного алгоритму; не є типовою властивістю.
- **PP (Pointwise).** `P(k)` для фіксованого `k ∈ ℕ`. Не переноситься на інші k без додаткових умов.
- **GP (Global).** Властивість всієї нескінченної траєкторії (наприклад, «траєкторія входить у цикл»).

**Твердження CE-10.3.2 (правила перенесення).**

1. **PH(N+1) ⟹ PH(N).** Доводиться безпосередньо з означення PH.
2. **PH(N) не тягне PH(M) для M > N.** Контрприклад: «немає повторень на перших N кроках» не тягне «немає повторень на перших M кроках».
3. **EP(N) ⟹ EP(N+1).** Доводиться з означення EP (для конкретного алгоритму).
4. **PP(k) не тягне PP(k') для k ≠ k'.**
5. **GP ⟹ PH(N)** для будь-якого N, якщо PH(N) є наслідком GP.
6. **GP не тягне EP(N)** для жодного N (бо EP — властивість префіксів, не траєкторії).

**PROVED ON PAPER.**

**Приклади.**

| Властивість | Тип |
|---|---|
| «Немає повторень на перших N кроках» | PH |
| «На кроці k стан = ŝ*» | PP(k) |
| «Траєкторія входить у цикл довжини p» | GP |
| «Перші N кроків належать множині M» | PH |
| «Перші N кроків покривають всі 64 стани» | EP (обґрунтовується окремо) |

**Наслідок CE-10.3.3.** Сертифікат `PREFIX_CERTIFIED(N)` має містити `property_type ∈ {PH, EP, PP}`. Сертифікат `GLOBAL_EXACT_CERTIFIED` має `property_type = GP`.

**Наслідок CE-10.3.4.** Правила перенесення між горизонтами:

- `PREFIX_CERTIFIED(N)` типу **PH** тягне `PREFIX_CERTIFIED(M)` для всіх **M ≤ N**;
- `PREFIX_CERTIFIED(N)` типу **EP** тягне `PREFIX_CERTIFIED(M)` для всіх **M ≥ N** (за умови EP);
- `PREFIX_CERTIFIED(N)` типу **PP** не тягне нічого без додаткових умов;
- `GLOBAL_EXACT_CERTIFIED` не залежить від горизонту.

**PROVED ON PAPER.**

**Застереження CE-10.3.5.** У CE-9.6.2.1 було записано: «MP(N) ⟹ MP(M) для M ≥ N». Це **відкликається**. Правильне правило — CE-10.3.2.1 і CE-10.3.2.2.

**Наслідок CE-10.3.6.** K-09 — **PROVED ON PAPER** (за явною типологією властивостей).

## CE-10.4. Орбітальна класифікація — уточнення (K-11)

### Діагноз

CE-9.7 доводив вичерпність, розглядаючи випадки: `F^k(P) = P`, `F^{m+1}(P) = F^m(P)`, `F^{m+p}(P) = F^m(P)`, `APERIODIC`. Але пропущено загальний випадок: **будь-які два** елементи орбіти `F^m(P)` і `F^n(P)` з `m < n` можуть збігатися, не утворюючи цикл довжиною 1 чи 2.

**Приклад.** Орбіта `P, Q, R, Q, R, Q, R, …` — повторення `Q` після 2 кроків не означає `F^k(P) = P`. Класифікація має це враховувати.

### Виправлення

**Означення CE-10.4.1 (повторення в орбіті).**

Для `P ≠ ∅` і `F` тотального на просторі множин, розглянемо орбіту `O(P) := (F^n(P))_{n ∈ ℕ}`.

**Перше повторення.** Якщо `∃m < n: F^m(P) = F^n(P)`, визначимо:

```
μ(P) := min{ m ≥ 0 : ∃n > m: F^m(P) = F^n(P) }     (індекс початку циклу)
π(P) := min{ n − μ(P) : n > μ(P), F^n(P) = F^{μ(P)}(P) }     (період)
```

Якщо такого повторення немає, `μ(P) := ∞` і `π(P) := ∞`.

**Лема CE-10.4.2 (класифікація за μ, π).**

**(a)** `F(P) = P`:
- усі точки `P` нерухомі — `INVARIANT_FIXED`;
- не всі — `INVARIANT_DYNAMIC`.

**(b)** `F(P) ≠ P` і `μ(P) = 0`, `π(P) ≥ 2`: `PERIODIC_SET(π)`.

**(c)** `F(P) ≠ P`, `μ(P) ≥ 1`, `π(P) = 1`: `EVENTUALLY_FIXED(μ)`.

**(d)** `F(P) ≠ P`, `μ(P) ≥ 1`, `π(P) ≥ 2`: `EVENTUALLY_PERIODIC(μ, π)`.

**(e)** `μ(P) = ∞`: `APERIODIC`.

*Доведення.*

**Розбиття за μ.**

- **μ = ∞:** жодна пара не збігається, отже жодного повернення. За означенням `APERIODIC`. ✓
- **μ = 0:** `F^0(P) = P = F^n(P)` для деякого n ≥ 1, отже `∃k = n: F^k(P) = P`. При k = 1 — випадок (a); при k ≥ 2 — випадок (b). ✓
- **1 ≤ μ < ∞:** перше повторення не включає `P`. Отже, `∀k ≥ 1: F^k(P) ≠ P`. Треба розрізнити π = 1 і π ≥ 2:
  - π = 1: `F^{μ}(P) = F^{μ+1}(P)`, звідки `F^{μ}(P)` нерухома — `EVENTUALLY_FIXED(μ)`. ✓
  - π ≥ 2: `F^{μ}(P), …, F^{μ+π−1}(P)` — цикл довжини π ≥ 2 — `EVENTUALLY_PERIODIC(μ, π)`. ✓

**Взаємовиключність.** μ(P) і π(P) визначені однозначно (як мінімуми), тому випадки (a)–(e) не перетинаються. ✓

∎

**PROVED ON PAPER** за припущення, що `F` індукує **тотальне** відображення на просторі множин `2^{S_∞ × ℛ}` (або його підмножині, яку ми класифікуємо).

**Застереження CE-10.4.3 (область визначення).** `Classify⁺` визначене для `P ∈ 2^{S_∞ × ℛ} ∖ {∅}`. Порожня множина класифікується окремо (`EMPTY`) або виключається з області.

**Твердження CE-10.4.4 (вичерпність і взаємовиключність).** Шість класів + `EMPTY` утворюють розбиття простору `2^{S_∞ × ℛ}`.

**PROVED ON PAPER.**

**Наслідок CE-10.4.5.** K-11 — **PROVED ON PAPER**.

**Застереження CE-10.4.6 (Q28).** Контрприклад для `INVARIANT_DYNAMIC` без періодичності точок у `S_∞ × ℛ₀` — окремий обов'язок (Q28 ❓).
