## CE-3.1. Причинність і метрика (K-01)

### Діагноз

§13.5.1 визначає `δ(s, t) := 1 + min_i δ(s_i, t_i)`.

§18.7.1 визначає причинність як `d_S(f(s), f(t)) ≤ d_S(s, t)`.

**Проблема:** метрична умова Ліпшиця і префіксна умова («однакові входи до рівня n → однакові виходи до рівня n») **не тотожні без доведення**. Перша — умова на відстань; друга — умова на усічення.

### Виправлення

**Означення CE-3.1.1 (нормативна метрика).** У §13.5.1 обирається єдина метрика `d_S`, визначена як **гранична метрика першого розходження**:

```
δ(s, t) := min{ n ≥ 0 : p_n(s) ≠ p_n(t) }        якщо таке n існує
δ(s, t) := ∞                                      якщо p_n(s) = p_n(t) для всіх n

d_S(s, t) := 2^{−δ(s, t)}                         якщо δ < ∞
d_S(s, t) := 0                                    якщо δ = ∞
```

**Застереження CE-3.1.2.** Рекурсивна формула `δ(s,t) = 1 + min_i δ(s_i, t_i)` — **еквівалентне подання** граничного означення (для внутрішніх вузлів). Вона не є окремим означенням; це лема.

**Означення CE-3.1.3 (два означення причинності).**

**Метрична причинність:**
```
∀s, t ∈ S_∞:  d_S(f(s), f(t)) ≤ d_S(s, t)
```

**Префіксна причинність:**
```
∀n ∈ ℕ, ∀s, t ∈ S_∞:  p_n(s) = p_n(t) ⟹ p_{n'}(f(s)) = p_{n'}(f(t))
```
для деякого `n' = n' (n)` (найчастіше `n' = n`).

**Твердження CE-3.1.4 (еквівалентність).** Метрична причинність еквівалентна префіксній причинності з `n' = n`.

*Доведення (ескіз).*

(⟸) Якщо `p_n(s) = p_n(t) ⟹ p_n(f(s)) = p_n(f(t))` для всіх `n`, то для будь-якої пари `s, t`:
- `δ(s, t) ≥ n` ⟹ `p_n(s) = p_n(t)` ⟹ `p_n(f(s)) = p_n(f(t))` ⟹ `δ(f(s), f(t)) ≥ n`.
- Отже, `δ(f(s), f(t)) ≥ δ(s, t)` ⟹ `d_S(f(s), f(t)) ≤ d_S(s, t)`.

(⟹) Якщо `d_S(f(s), f(t)) ≤ d_S(s, t)`, то для `p_n(s) = p_n(t)` маємо `δ(s, t) ≥ n`, отже `δ(f(s), f(t)) ≥ n`, отже `p_n(f(s)) = p_n(f(t))`. ∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

**Застереження CE-3.1.5.** §21.1.2 (ℛ₀ ≅ {причинні функції}) — **умовне** до завершення цього доведення для конкретного представлення `ℛ₀ := Comp`.

**Виправлення формулювань:**

- §13.5.1: метрика визначена **гранично** (не рекурсивно). Рекурсивна форма — лема.
- §18.7.1: причинність визначена **префіксно**. Метрична форма — еквівалентна за CE-3.1.4.
- §21.1.2: статус ⚠️ умовно (залежить від CE-3.1.4).

## CE-3.2. Вичерпність S(τ) і класифікації інваріантних множин (K-02)

### Діагноз

§18.6.1 пропонує п'ять класів `S(τ)`. Аудит правильно зауважує: **п'ять класів класифікують ω-границі окремих траєкторій**, а не довільні інваріантні множини. Контрприклад з двома нерухомими точками `X = {a, b}`, `F(a) = a`, `F(b) = b`, розглянутий як **множина** `{a, b}`, не класифікується жодним із п'яти класів. Але ω-границя будь-якої конкретної траєкторії в цій системі — одна точка.

### Виправлення

**Розділення двох класифікацій.**

**Означення CE-3.2.1 (класифікація ω-границь).** `S(τ)` — класифікація **ω-границі окремої траєкторії** `ω(ŝ₀)`. Це цільовий об'єкт §18.6.

**Означення CE-3.2.2 (класифікація інваріантних множин).** Окремо визначимо `Ω_inv(P)` для **довільних** непорожніх компактних інваріантних підмножин `P ⊆ S_∞ × ℛ`:

```
Ω_inv(P) :=
   1. INVARIANT_FINITE
         P скінченна, |P| ≥ 1
   2. MINIMAL_ZERO_ENTROPY
         P нескінченна, мінімальна, h_top = 0
   3. CHAOTIC
         P нескінченна, мінімальна, h_top > 0
   4. NON_MINIMAL
         P нескінченна, не мінімальна
```

**Твердження CE-3.2.3 (вичерпність Ω_inv).** Ці чотири класи вичерпні для всіх непорожніх компактних інваріантних `P`.

*Доведення.* Нехай `P ≠ ∅`, компактна, `F(P) = P`.
- Якщо `P` скінченна — INVARIANT_FINITE.
- Якщо `P` нескінченна: або мінімальна (з `h_top = 0` або `> 0`), або не мінімальна. ∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

**Твердження CE-3.2.4 (вичерпність S(τ) для ω-границь).** П'ять класів §18.6.1 вичерпні для `ω(ŝ₀)` — ω-границі окремої траєкторії.

*Доведення (ескіз).*
Нехай `ω := ω(ŝ₀) ≠ ∅`, компактна, `F(ω) = ω`.

**Крок 1.** `ω` як інваріантна компактна множина класифікується за CE-3.2.3 як `INVARIANT_FINITE`, `MINIMAL_ZERO_ENTROPY`, `CHAOTIC`, або `NON_MINIMAL`.

**Крок 2.** Якщо `ω` — `INVARIANT_FINITE`, то треба довести, що `ω` — **періодична орбіта** (не довільна скінченна інваріантна множина).

Це випливає з **внутрішньої ланцюгової транзитивності ω-границі**: для будь-яких `x, y ∈ ω` і будь-якого `ε > 0` існує скінченний `ε`-ланцюг у `ω`, що веде від `x` до `y`. Якщо `ω` скінченна, то для `ε < min{d(x, y) : x ≠ y ∈ ω}` жоден `ε`-ланцюг не може перейти між різними компонентами зв'язності. Отже, `ω` — одна компонента, тобто `F|_ω` — переклад, тобто періодична орбіта.

**Наслідок.** Скінченна ω-границя класифікується як `FIXED_POINT` (|ω| = 1) або `PERIODIC` (|ω| > 1).

**Крок 3.** Якщо `ω` нескінченна: мінімальна з `h_top = 0` (MINIMAL_ZERO_ENTROPY), мінімальна з `h_top > 0` (CHAOTIC), або немінімальна (NON_MINIMAL).

∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ з опорою на внутрішню ланцюгову транзитивність ω-границі (стандартний результат топологічної динаміки).

**Виправлення формулювань:**

- §18.6.1: явно вказати, що це класифікація **ω-границь окремих траєкторій**, не довільних інваріантних множин.
- Додати §18.6.0 (Classification of invariant subsets): Означення CE-3.2.2 і Твердження CE-3.2.3.
- Позначити §18.6.1 як **Твердження 18.6.1** (не означення), з посиланням на доведення CE-3.2.4.

## CE-3.3. T_n, q_n, p_n — типізовані означення (K-03)

### Діагноз

§13.3.2 допускає `depth(t) ≤ n` і одночасно вимагає, щоб кожен ⊥-листок був на глибині рівно `n`. Це створює граничні випадки: дерево може мати листки `A` на глибині < n і ⊥-листки на глибині n. Формально це коректно, але породжує неоднозначності для `T_0`, `q_0`, `p_0`.

### Виправлення

**Означення CE-3.3.1 (T_n, остаточно).** T_n — множина скінченних тернарних дерев `t` таких, що:

1. кожен листок `t` позначений елементом `A ∪ {⊥}`;
2. кожен внутрішній вузол `t` має рівно трьох нащадків;
3. **якщо** листок позначений `⊥`, то його глибина рівно `n`;
4. `depth(t) ≤ n`.

**Застереження CE-3.3.2.** Листки `A` можуть бути на будь-якій глибині ≤ n.

**Означення CE-3.3.3 (T_0).**

```
T_0 := { leaf(a) : a ∈ A } ∪ { ⊥ }
```

де `⊥` — дерево з одним коренем-листком.

**Означення CE-3.3.4 (q_n : T_{n+1} → T_n, остаточно).**

```
q_0(leaf(a))            := leaf(a)
q_0(node(t₁, t₂, t₃))   := ⊥

q_n(leaf(a))            := leaf(a)                       (n ≥ 1)
q_n(node(t₁, t₂, t₃))   := node(q_{n-1}(t₁), q_{n-1}(t₂), q_{n-1}(t₃))
```

**Застереження CE-3.3.5.** `q_n` визначена **тотально** на T_{n+1} для всіх n ≥ 0. Гілка `q_n(⊥)` **не виникає** в жодному випадку, бо `⊥ ∉ T_{n+1}` для `n+1 ≥ 1` (⊥ як корінь належить лише T_0).

**Лема CE-3.3.6 (коректність типів q_n).** `q_n(t) ∈ T_n` для всіх `t ∈ T_{n+1}`.

*Доведення.* Індукція за n. Для `t = leaf(a)` — тривіально. Для `t = node(t₁, t₂, t₃)`: `t_i ∈ T_n`, `q_{n-1}(t_i) ∈ T_{n-1}`, отже `node(...) ∈ T_n`. ∎

**Означення CE-3.3.7 (p_n : S_∞ → T_n).**

```
p_0(leaf(a))            := leaf(a)
p_0(node(t₁, t₂, t₃))   := ⊥

p_{n+1}(leaf(a))            := leaf(a)
p_{n+1}(node(t₁, t₂, t₃))   := node(p_n(t₁), p_n(t₂), p_n(t₃))
```

**Лема CE-3.3.8 (факторизація).** `q_n(p_{n+1}(s)) = p_n(s)` для всіх `s ∈ S_∞`, `n ∈ ℕ`.

*Доведення.* Індукція за n і структуру s. Див. попередню редакцію §13.3.5. ∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

**Застереження CE-3.3.9 (для Lean).** У Lean-пакеті `TreeApprox : ℕ → Type`, `truncate : TreeApprox (n+1) → TreeApprox n`, `project : S_∞ → TreeApprox n` — три окремі типи. Замість доведення компактності спочатку доводимо факторизацію `truncate ∘ project = project`.

**Статус §13.4.2:** залишається ДОВЕДЕНО НА ПАПЕРІ **за умови** повного формального доведення сюр'єктивності (див. CE-3.14).

## CE-3.4. d_finite — умова в теоремі (K-04)

### Діагноз

§15.2.1 визначає `d_finite` без явного включення NF3' у формулювання.

### Виправлення

**Означення CE-3.4.1 (d_finite, остаточно).**

**Передумова.** Нехай `F : S_∞ × ℛ₀ → S_∞ × ℛ₀` задовольняє умову збереження:

```
(NF3')  g(ρ, s) ∈ ℛ₀  для всіх ρ ∈ ℛ₀, s ∈ S_∞
```

**Означення.**

```
d_finite(ŝ, t̂) := sup_{n ≥ 0} 2^{-n} · d̂(Fⁿ(ŝ), Fⁿ(t̂))
```

**Твердження CE-3.4.2.** За умови NF3', `d_finite` — ультраметрика на `S_∞ × ℛ₀`.

**Застереження CE-3.4.3.** Якщо NF3' не виконується, `d_finite` не визначена (супремум береться по невизначених значеннях). Це не дефект, а обмеження області визначення.

**Виправлення формулювань:** у §15.2.1 явно вказати NF3' як передумову; у §15.2.3 явно вказати, що теорема — умовна.

## CE-3.5. Attainment — вичерпність (K-05, K-16)

### Діагноз

§18.4 визначає `ATTAINED` і `ASYMPTOTIC`. Аудит правильно зауважує: вичерпність цих двох класів не випливає з означень.

### Виправлення

**Означення CE-3.5.1 (клас систем).** Нехай `Σ_c` — клас систем `(X, F)` таких, що:

- `X` — компактний метричний простір;
- `F : X → X` — неперервне;
- `d̂` — метрика на `X`, узгоджена з топологією.

**Твердження CE-3.5.2 (вичерпність Att).** Для всіх траєкторій `τ = τ(ŝ₀)` у системах `(X, F) ∈ Σ_c`:

```
Att(τ) ∈ { ATTAINED, ASYMPTOTIC }.
```

*Доведення.* Нехай `ω := ω(ŝ₀) ≠ ∅` (непорожність за компактністю). Розглянемо `dist(ŝ_n, ω) → ?`.

За компактністю `X` і неперервністю `F`, `ω` — непорожня компактна інваріантна підмножина (стандартний результат, Walters 1982, теорема 5.6). Оскільки `ω` — множина точок накопичення траєкторії, для будь-якого `ε > 0` множина `{ n : dist(ŝ_n, ω) > ε }` скінченна (інакше збіжна підпослідовність до точки поза ω, суперечність). Отже, `dist(ŝ_n, ω) → 0`.

**Два випадки.**
1. `∃n: ŝ_n ∈ ω` — `ATTAINED`.
2. `∀n: ŝ_n ∉ ω`, але `dist(ŝ_n, ω) → 0` — `ASYMPTOTIC`.

∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

**Виправлення:** §18.4 явно посилається на клас `Σ_c` і Твердження CE-3.5.2.

## CE-3.6. Термінальний об'єкт — явні леми (K-06)

### Виправлення

Додати до §8.4 як окремі леми:

**Лема CE-3.6.1 (тотожний морфізм).** Для будь-якого об'єкта `X ∈ SUBIT`: `(id_{S_X}, id_{ℛ_X})` — морфізм за §8.2.2.

*Доведення.* `φ_S(p_S(F_X(s, ρ))) = p_S(F_X(s, ρ))` (бо φ_S = id). Аналогічно RHS. ∎

**Лема CE-3.6.2 (композиція).** Композиція морфізмів `φ : X → Y`, `ψ : Y → Z` — морфізм `ψ ∘ φ : X → Z`.

*Доведення.* За §8.2.2 для φ і ψ: `φ_S(p_S(F_X(s, ρ))) = p_S(F_Y(φ_S(s), φ_ℛ(ρ)))`. Застосуємо ψ_S до обох частин і використаємо умову ψ:
`ψ_S(φ_S(p_S(F_X(s, ρ)))) = ψ_S(p_S(F_Y(φ_S(s), φ_ℛ(ρ)))) = p_S(F_Z(ψ_S(φ_S(s)), ψ_ℛ(φ_ℛ(ρ))))`. Оскільки `ψ ∘ φ = (ψ_S ∘ φ_S, ψ_ℛ ∘ φ_ℛ)`, отримуємо умову §8.2.2 для композиції. ∎

**Лема CE-3.6.3 (термінальний об'єкт).** `1 = ({∗}, {id}, F_triv, g_triv)` — термінальний.

*Доведення.* Для будь-якого `X` існує єдине відображення `(φ_S, φ_ℛ)` з компонентами `φ_S : S_X → {∗}`, `φ_ℛ : ℛ_X → {id}`. Умова §8.2.2 виконується тривіально. Єдиність очевидна. ∎

**Застереження CE-3.6.4.** Для SUBIT_full додатково треба перевірити умову §8.3.1. Вона виконується тривіально: `φ_ℛ(g_X(ρ, s)) = id = g_triv(id, ∗)`. ∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

## CE-3.7. Dyn ≅ Fun(ℕ, Set) — категоріальне уточнення (K-07)

### Виправлення

**Означення CE-3.7.1.** Нехай `ℕ` — **моноїд як однооб'єктна категорія**: один об'єкт `•`, `Hom(•, •) = ℕ` з композицією `+`, тотожність `0`.

**Твердження CE-3.7.2.** `Dyn ≅ Fun(ℕ, Set)`.

*Доведення.*
- Об'єкт `Fun(ℕ, Set)` — функтор `F : ℕ → Set`. Задається значенням `F(•) = S` і образом генератора `F(1) : S → S`.
- Об'єкт `Dyn` — пара `(S, f)`. Ідентифікація: `F ↔ (F(•), F(1))`.
- Морфізм `Fun(ℕ, Set)` — натуральне перетворення `η : F → G`, тобто функція `η_• : F(•) → G(•)`, що комутує з `F(1), G(1)`: `η_• ∘ F(1) = G(1) ∘ η_•`.
- Морфізм `Dyn` — функція `φ : S → T` з `φ ∘ f = g ∘ φ`.
- Ідентичність очевидна. ∎

**Застереження CE-3.7.3.** Дія моноїда на `S` визначається: `n · s := fⁿ(s)`. Це ліва дія `ℕ` на `S`, узгоджена з моноїдною структурою: `(m + n) · s = m · (n · s)`.

**Твердження CE-3.7.4 (топосна структура).** `Fun(ℕ, Set)` — топос (Mac Lane–Moerdijk 1992, теорема про топоси прешейвів). Отже, `Dyn` — топос.

**Означення CE-3.7.5 (класифікатор, явно).** `Ω_Dyn : ℕ → Set`:

- `Ω_Dyn(•) := ℕ ∪ {∞}`;
- дія `1 · n := max(n − 1, 0)`, `1 · ∞ := ∞`.

**Твердження CE-3.7.6 (універсальна властивість).** Для будь-якого `X = (S, f) ∈ Dyn`: бієкція `Sub_Dyn(X) ≅ Hom_Dyn(X, Ω_Dyn)`, де `U ↦ χ_U` з `χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U }` (∞ якщо ніколи).

*Доведення.*
1. `χ_U` — морфізм `Dyn`: `χ_U(f(x)) = max(χ_U(x) − 1, 0)` (перевірка за випадками).
2. Сюр'єктивність: для `ψ : X → Ω_Dyn` покладемо `U_ψ := { x : ψ(x) = 0 }`. Індукція за `ψ(x)`: `χ_{U_ψ} = ψ`.
3. Ін'єктивність: якщо `χ_U = χ_V`, то `U = χ_U⁻¹(0) = χ_V⁻¹(0) = V`.

∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

## CE-3.8. PREPERIODIC — алгоритм і сертифікат (K-08)

### Виправлення

**Означення CE-3.8.1 (точне означення класів).**

- **FIXED:** `F(ŝ) = ŝ` (період 1).
- **PERIODIC(p_per):** `p_per := min{ k > 1 : Fᵏ(ŝ) = ŝ }`; початкова точка **належить** циклу довжини `p_per`.
- **PREPERIODIC:** початкова точка **не належить** жодному циклу, але її орбіта містить періодичну точку після скінченного префікса.

**Алгоритм CE-3.8.2 (уточнений §5.5).**

```
Вхід: ŝ₀, горизонт N_max
Вихід: PointClass(ŝ₀) := (category, m, p, attractor_cycle, certificate)

visited : Map<State, ℕ> ← ∅     # стан → індекс першого входження
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        m ← visited[ŝₙ]
        p ← n − m
        attractor_cycle ← [ŝ_m, …, ŝ_{n-1}]
        якщо m = 0:
            category ← FIXED якщо p = 1, інакше PERIODIC(p)
        інакше:
            category ← PREPERIODIC        # m — індекс першого входження
        certificate ← {
            index_first_entry: m,
            period: p,
            attractor_cycle: attractor_cycle,
            trajectory_prefix: [ŝ_0, …, ŝ_{m-1}]   # якщо m > 0
        }
        повернути (category, m, p, attractor_cycle, certificate)
    visited[ŝₙ] ← n
    ŝₙ₊₁ ← F(ŝₙ)
повернути RESOURCE_EXCEEDED
```

**Застереження CE-3.8.3.** Сертифікат для PREPERIODIC **обов'язково** містить `index_first_entry = m` і `trajectory_prefix` (передперіодичну частину). Без цього сертифікат неповний.

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

## CE-3.9. Тест §23.2 — переформулювання (K-09)

### Діагноз

APPROXIMATION_CONVERGED

## CE-3.14. Бієкція S_∞ ≅ lim← — повна сюр'єктивність (K-14)

### Виправлення

**Схема доказу CE-3.14.1 (сюр'єктивність p).**

Нехай `(t_n)_{n ∈ ℕ} ∈ lim←(T_n, q_n)`.

**Крок 1 (state).** Для позиції `σ ∈ {1,2,3}^{<ω}`:

```
state(σ) := t_{|σ|+1}(σ)
```

Коректність: для `|σ| < n`: `t_n(σ) = t_{n+1}(σ)` (усічення не змінює позиції з глибиною < n).

**Крок 2 (класифікація state).** `state(σ) ∈ {leaf(a) : a ∈ A} ∪ {internal}`. Випадок ⊥ виключений, бо `|σ| + 1 > |σ|`, отже позиція σ не на фронтирному рівні.

**Крок 3 (коалгебра L = lim←).**

```
out_←((t_n)) :=
   a ∈ A                            якщо state(∅) = leaf(a)
   (u^{(1)}, u^{(2)}, u^{(3)})       якщо state(∅) = internal
```

де `u_m^{(i)} := (t_{m+1})|_i ∈ T_m`.

**Крок 4 (сумісність u^{(i)}).** За сумісністю `t_{m+1} = q_{m+1}(t_{m+2})`; для внутрішнього кореня:

```
q_m(u_{m+1}^{(i)}) = q_m((t_{m+2})|_i) = (q_{m+1}(t_{m+2}))|_i = (t_{m+1})|_i = u_m^{(i)}
```

**Крок 5 (реконструкція s).** За фінальністю `S_∞` існує єдиний морфізм коалгебр `s : (L, out_←) → (S_∞, out)`.

**Крок 6 (p_n(s(t)) = t_n).** Індукція за n з універсальною гіпотезою:

`IH(n): ∀u ∈ L, p_n(s(u)) = u_n`.

- База `n = 0`: або `state(∅) = leaf(a)` (тоді `s(t) = leaf(a)`, `p_0(s(t)) = leaf(a) = t_0`), або `internal` (тоді `s(t) = node(...)`, `p_0(s(t)) = ⊥ = t_0` за узгодженістю з `q_0`).
- Крок `n → n + 1`: за IH(n) на `u^{(i)}` і узгодженістю `t_{n+1} = node(u_n^{(1)}, u_n^{(2)}, u_n^{(3)})`.

∎

**Статус:** ДОВЕДЕНО НА ПАПЕРІ.

**Застереження CE-3.14.2.** Для Lean формалізації потрібно окремо довести:
- `lim←` як коалгебра функтора `Φ`;
- коректність `state(σ)` (не залежить від n);
- сумісність `u^{(i)}` з `q_m`.
