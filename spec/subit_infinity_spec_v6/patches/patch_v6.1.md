## К1 + К4. Термінологія CHAOTIC і доля Твердження 6.3

### Проблема

> Одне слово «CHAOTIC» використовується для двох різних понять у двох класифікаторах. Точкова класифікація (CHAOTIC = «не повертається») не узгоджується з множинною (CHAOTIC = мінімальна ω з додатною ентропією). Твердження 6.3 хибне: двоелементний цикл P = {a, b} має F(P) = P (STABLE як множина), але обидві точки CYCLIC.

### Пропоноване виправлення

**Замінити §6.3 повністю на:**

#### §6.3. Точкова класифікація Ω_point

**Означення 6.3.1 (Ω_point).** Для ŝ ∈ S_∞ × ℛ:

```
Ω_point(ŝ) :=
   FIXED      якщо F(ŝ) = ŝ
   PERIODIC   якщо ∃k > 1: Fᵏ(ŝ) = ŝ
   TRANSIENT  інакше
```

**Зауваження 6.3.1.** Слово CHAOTIC **не вживається** для точок. Воно зарезервоване виключно для ω-границь у §18.5. Це розділяє два різні поняття, які v6.0 помилково ототожнила.

**Твердження 6.3.2 (TRANSIENT реалізується навіть на скінченному рівні).** Нехай ŝ₀ лежить у передперіодичному хвості траєкторії. Тоді F(ŝ₀) ≠ ŝ₀ і ∃k > 1: Fᵏ(ŝ₀) = ŝ₀ (бо траєкторія зрештою періодична за Твердженням 5.1), тому Ω_point(ŝ₀) = TRANSIENT.

**Зауваження 6.3.2.** Це прямо суперечить помилковому зауваженню v6.0 («CHAOTIC не реалізується на скінченному рівні»). Правильне формулювання: **TRANSIENT реалізується**; CHAOTIC (у сенсі §18.5) — ні, бо CHAOTIC визначене тільки для ω-границь.

**Відкликати Твердження 6.3 v6.0** («Ω_set(P) = STABLE ⟺ ∀i: Ω_state(ŝᵢ) = STABLE і F(P) = P»).

**Замінити на:**

**Твердження 6.3.3.** Для скінченної P ⊆ S_∞ × ℛ:

```
Ω_set(P) = STABLE ⟹ ∀ŝ ∈ P: Ω_point(ŝ) ∈ {FIXED, PERIODIC}
```

Зворотне не виконується: P = {a, b}, F(a) = b, F(b) = a дає F(P) = P і PERIODIC на обох точках, але Ω_point ≠ FIXED.

**Замінити §18.5 повністю на:**

#### §18.5. S-компонента як динамічний тип ω-границі

**Означення 18.5.1 (S-компонента).** S(τ) визначається через структуру ω(ŝ₀), а не через Ω_set:

```
S(τ) :=
   FIXED_POINT     якщо ω(ŝ₀) = {p}, F(p) = p
   PERIODIC        якщо ω(ŝ₀) скінченна, |ω(ŝ₀)| > 1
   MINIMAL_CANTOR  якщо ω(ŝ₀) нескінченна, мінімальна, h_top = 0
   CHAOTIC         якщо ω(ŝ₀) нескінченна, мінімальна, h_top > 0
   NON_MINIMAL     якщо ω(ŝ₀) нескінченна й не мінімальна
```

**Зауваження 18.5.1.** Ці п'ять класів **вичерпні й взаємовиключні** (див. К6). v6.0 мала лише чотири (STABLE/METASTABLE/CYCLIC/CHAOTIC) і не покривала випадок нескінченної мінімальної ω з нульовою ентропією (одометр).

**Зауваження 18.5.2.** S(τ) **не є** застосуванням Ω_set до P(τ). Це незалежна динамічна класифікація ω-границі. v6.0 помилково ототожнювала ці дві речі.

### Наслідки

- §6.1 (зауваження про скінченний рівень): виправити — TRANSIENT реалізується, CHAOTIC ні.
- §18.7 (визначення Ω_traj): замінити Ω на нову 5-елементну S-множину.

- Rust `subit-core::omega`: переробити `OmegaState` → `OmegaPoint`.

### Новий статус

- Твердження 6.3 v6.0 — ⛔ відкликано.
- §18.5 — ✅ (вичерпність п'яти класів).

## К2. Метрики d_ω і d_Ω

### Проблема

> ω(Fⁿŝ) = ω(ŝ) для всіх n. Тому n₀ або 0, або не визначено, і d_ω ∈ {0, 1}. «Горизонт першої розбіжності» порожній. Твердження 15.3 хибне.

### Пропоноване виправлення

**Відкликати §15.2–15.3 v6.0 повністю.**

**Замінити на:**

#### §15.2. Метрика d_traj на просторі траєкторій

**Означення 15.2.1 (розбіжність траєкторій).** Для ŝ, t̂ ∈ S_∞ × ℛ:

```
n₀(ŝ, t̂) := min{ n ≥ 0 : Fⁿŝ ≠ Fⁿt̂ }
```

якщо траєкторії розходяться; `n₀ := ∞` якщо Fⁿŝ = Fⁿt̂ для всіх n.

**Означення 15.2.2 (d_traj).**

```
d_traj(ŝ, t̂) := 2^(−n₀(ŝ, t̂))   якщо n₀ < ∞
d_traj(ŝ, t̂) := 0                якщо n₀ = ∞
```

**Теорема 15.2.3.** d_traj — ультраметрика на факторпросторі (S_∞ × ℛ)/~_traj, де ŝ ~_traj t̂ ⟺ Fⁿŝ = Fⁿt̂ для всіх n.

*Доведення.* Симетричність очевидна. Сильна нерівність трикутника: якщо Fⁿŝ = Fⁿt̂ для всіх n < n₁ і Fⁿt̂ = Fⁿû для всіх n < n₂, то Fⁿŝ = Fⁿû для всіх n < min(n₁, n₂). ∎

**Зауваження 15.2.4.** d_traj **не вироджена**: `grow_chain` і `shift_spine` розходяться на кроці 1, тому d_traj = 1/2.

#### §15.3. Відкликано

**Відкликати Твердження 15.3 v6.0** («d_Ω — факторметрика d_ω»). Воно хибне: два ŝ з однаковою ω і різним Att мають d_ω = 0 і d_Ω = 1, отже жодна імплікація між нулями не випливає.

**Відкликати Твердження 15.4 v6.0** («нульвимірність спадкується від факторизації за відкритим відношенням»). Обґрунтування неправильне: відношення «однакова ω-границя» не відкрите й не замкнене.

**Замінити на:**

**Твердження 15.3'.** Відношення ~_traj є замкненим у S_∞ × ℛ (рівність траєкторій — замкнена умова). Тому фактор (S_∞ × ℛ)/~_traj коректно визначений як топологічний простір.

**Твердження 15.4'.** (S_∞ × ℛ₀)/~_traj з d_traj — компактний гаусдорфовий простір. Нульвимірність не стверджується: вона не доведена.

**Ввести §15.5 — метрика d_ω на ω-границях (як множинах):**

**Означення 15.5.1.** Для ŝ, t̂ ∈ S_∞ × ℛ:

```
d_ω(ŝ, t̂) := d_H( ω(ŝ), ω(t̂) )
```

де d_H — метрика Хаусдорфа, індукована d_S на підмножинах S_∞.

**Зауваження 15.5.2.** Ця метрика не вироджена: `identity` (ω = {s₀}) і `grow_chain` (ω = {нерухома точка на нескінченному дереві}) мають d_ω > 0.

### Наслідки

- §22.3 (d_ω визначена через Ω_traj): перевизначити через d_H.
- Rust `subit-infinity::d_omega`: переробити.

## К3. Характеристичне відображення χ_U

### Проблема

> Гілки χ_U перекриваються. Субоб'єкт замкнений, тому CYCLIC і «F(U) ⊄ U» недосяжні. Якщо брати першу гілку — χ_U стає булевою функцією, Sub → Hom ін'єктивне. χ_U не є морфізмом. Справжній класифікатор для систем (S, F) з морфізмами, що комутують із F, — це Ω = ℕ ∪ {∞}, χ_U(x) = min{n : Fⁿx ∈ U}. Це топос Set^ℕ.

### Пропоноване виправлення

**Повністю переписати §9.**

#### §9. SUBIT і топосна структура

**§9.1. Діагноз.** SUBIT у формі v6.0 **не має** субоб'єктного класифікатора. Спроба побудувати χ_U через Ω_SUBIT = {STABLE, METASTABLE, CYCLIC, CHAOTIC} із тотожною динамікою не працює з трьох причин:

1. Гілки χ_U перекриваються: для x ∈ U з F(x) ∈ U одночасно виконуються умови STABLE і (якщо F(U) ⊊ U) METASTABLE.
2. χ_U не є морфізмом: для Ω з тотожним F потрібно χ(F x) = χ(x), але для x ∉ U, F(x) ∈ U маємо χ(x) = CHAOTIC ≠ STABLE = χ(F x).
3. Субоб'єкт U ↪ X у SUBIT замкнений (F_X(U) ⊆ U), тому гілки CYCLIC і «F(U) ⊄ U» недосяжні.

**§9.2. Відкликання.** Твердження 9.3 (природність χ), 9.4 (Sub → Hom не бієкція), 9.5 — **відкликаються**.

**§9.3. Позитивний результат: підкатегорія Dyn.**

Розглянемо підкатегорію **Dyn** ⊆ SUBIT:

- Об'єкти: пари (S, f), де S — множина, f : S → S — довільна функція. (Тут S_∞ не потрібен; достатньо категорії Set.)
- Морфізми: φ : (S, f) → (T, g) — функція φ : S → T, що задовольняє φ ∘ f = g ∘ φ.

Ця категорія — класичний **топос прешейвів на моноїді ℕ**, еквівалентний `Set^ℕ` (Lawvere).

**Твердження 9.3'.** Категорія Dyn ≅ `Set^ℕ` є топосом (Lawvere, 1964; Mac Lane & Moerdijk, 1992).

**Твердження 9.4'.** Субоб'єктний класифікатор у Dyn:

```
Ω_Dyn := ℕ ∪ {∞}
```

з дією моноїда: `n · k := max(n − k, 0)`, `∞ · k := ∞`. Характеристичне відображення:

```
χ_U(x) := min{ n ≥ 0 : fⁿ(x) ∈ U }   (∞ якщо ніколи)
```

**Твердження 9.5'.** χ_U є морфізмом у Dyn: χ_U(f(x)) = max(χ_U(x) − 1, 0).

*Доведення.* Якщо χ_U(x) = n, то fⁿ(x) ∈ U, тому f^{n−1}(f(x)) ∈ U, отже χ_U(f(x)) ≤ n − 1. І навпаки, якщо f^m(f(x)) ∈ U, то f^{m+1}(x) ∈ U, отже χ_U(x) ≤ m + 1. Разом χ_U(f(x)) = max(χ_U(x) − 1, 0). ∎

**§9.4. Співвідношення SUBIT і Dyn.** SUBIT ⊃ Dyn як повна підкатегорія (кожна динамічна система (S, f) є об'єктом SUBIT із порожньою метаеволюцією). Але:

- SUBIT не є топосом (немає класифікатора для повної категорії).
- Dyn ≅ Set^ℕ є топосом із класифікатором Ω_Dyn = ℕ ∪ {∞}.

**§9.5. Чому SUBIT не є топосом.** У SUBIT об'єкти несуть метаеволюцію g, яка не враховується морфізмами §8.2. Тому природне відображення Dyn → SUBIT не зберігає топосну структуру. Розширення морфізмів SUBIT до «морфізмів, що комутують із g» можливе, але тоді класифікатор Ω_Dyn повинен враховувати дію g — це відкрите питання (Q2 переформульоване).

**Q2'. Переформульоване відкрите питання.** Чи існує розширення Dyn ⊆ C ⊆ SUBIT, яке є топосом і класифікатор якого враховує метаеволюцію g?

### Наслідки

- §8.2: морфізми треба або (а) залишити як є і визнати, що SUBIT не топос, або (б) розширити так, щоб вони комутували з g (що змінює структуру).
- §9.6 (Q2): переформулювати як Q2'.
- Твердження 9.3, 9.4, 9.5 у STATUS.md: ⛔.
- Додати Твердження 9.3'–9.5'.
- Lean: файл `Subit/ToposDyn.lean` із доведенням 9.5' (тривіальне) і описом Ω_Dyn.

### Новий статус

- §9.3 (χ_U v6.0) — ⛔.
- §9.5 (Sub → Hom не бієкція) — ⛔.
- §9.3'–9.5' (Dyn — топос) — ✅.

## К5. Модальна логіка

### Проблема

> У семантиці 11.1 (∀n / ∃n) M4 є теоремою. «Спростування» працює лише після непомітного переходу до Ω-значного ¬. M6 хибна за 11.1. Доведення M9 неявно припускає □A ∈ {STABLE, CHAOTIC}. Таблиця §11.3 суперечить 11.1.

### Пропоноване виправлення

**Розділити §11 на три частини з різними семантиками.**

#### §11.A. Модальна логіка траєкторій (LTL-подібна)

**Означення 11.A.1.** Для ŝ ∈ S_∞ × ℛ і A ⊆ S_∞ × ℛ:

```
ŝ ⊨ □A  ⟺  ∀n ≥ 0: Fⁿŝ ∈ A
ŝ ⊨ ◇A  ⟺  ∃n ≥ 0: Fⁿŝ ∈ A
ŝ ⊨ ◯A  ⟺  ∃k > 1: Fᵏŝ ∈ A
```

**Заперечення ¬** — класичне заперечення множин.

**Твердження 11.A.2 (аксіоми).**

```
(M1)  □A → A          ✅ (тривіально)
(M2)  □A → □□A        ✅
(M3)  □(A→B) → (□A→□B) ✅
(M4)  ◇A ↔ ¬□¬A       ✅ (теорема, як у LTL)
(M5)  ◯A → ◇A         ✅
(M6)  □A → ◯A         ⚠️ лише якщо F сюр'єктивна на A
(M7)  ◯◯A ↔ ◯A        ✅
(M8)  □A ∧ □B → □(A∧B) ✅
(M9)  ¬¬□A → □A       ✅ (у класичній логіці тривіально)
```

**Відкликати Твердження 11.2 v6.0** («M4 не виконується»). У цій семантиці M4 виконується.

**Відкликати Твердження 11.6 v6.0** («M9 виконується»). M9 тут тривіальне (класичне подвійне заперечення), а не властивість Ω_SUBIT.

**Твердження 11.A.3 (M6 умовна).** □A → ◯A виконується тоді й лише тоді, коли існує k > 1 з Fᵏ(A) = A. Якщо F не сюр'єктивна на A, M6 може не виконуватись.

*Контрприклад.* Нехай A = S_∞ × ℛ, F не сюр'єктивна. Тоді □A істинне (усі стани в A), але F^k(A) ≠ A для k > 1, отже ◯A хибне.

#### §11.B. Модальні оператори на Ω-значеннях (Гейтінгові)

**Означення 11.B.1.** Нехай Ω_SUBIT = {CHAOTIC < CYCLIC < METASTABLE < STABLE} з ∧, ∨, →, ¬ з §7. Модальні оператори □_H, ◇_H визначаються через Гейтінгові операції.

**Твердження 11.B.2.** У цій семантиці M4_H (◇_H A ↔ ¬□_H ¬A) **не виконується**: у ланцюгу Гейтінга подвійне заперечення ¬¬x → x має місце лише для x ∈ {⊥, ⊤}.

*Доведення.* ¬¬METASTABLE = ¬CHAOTIC = STABLE ≠ METASTABLE. ∎

**Зауваження 11.B.3.** Це **не** новий контрприклад до SUBIT. Це застосування загальної теореми про логіку Геделя–Даммета до конкретної Ґратки. M4_H не виконується в **будь-якій** нетривіальній логіці Геделя–Даммета, а не через специфіку SUBIT.

#### §11.C. Відповідність між семантиками

**Твердження 11.C.1.** §11.A і §11.B описують **різні** модальні системи. У §11.A □ і ◇ — дуальні (M4 виконується). У §11.B вони не дуальні (M4_H не виконується). Це не суперечність, а різні рівні аналізу: §11.A — про траєкторії, §11.B — про алгебру значень.

**Відкликати §11.3 v6.0** (таблиця відповідності Ω-клас → модальна формула). Вона змішує семантики §11.A і §11.B.

## К6. Двоосьова класифікація

### Проблема

> Таблиця S(τ) не вичерпна (одометр). CHAOTIC недосяжний для ℛ₀ (причинні f нерозтягуючі, h_top = 0). Ресурсна клаузула §18.2(C) суперечить У2. Сертифікат для ASYMPTOTIC/CHAOTIC неможливий. A(τ) для типу (A) має бути вся орбіта.

### Пропоноване виправлення

**(а) Вичерпність S(τ).** Уже виправлено в К1 (§18.5 з п'ятьма класами).

**(б) CHAOTIC у ℛ₀ недосяжний — визнати явно.**

**Твердження 18.6.1.** Якщо f ∈ ℛ₀, то h_top(ω(ŝ₀)) = 0 для будь-якого ŝ₀.

*Доведення.* f причинна ⟹ 1-ліпшицева в d_S. За теоремою Боуена для нерозтягуючих відображень на компактному метричному просторі топологічна ентропія дорівнює 0. ∎

**Наслідок 18.6.2.** Клас CHAOTIC у S(τ) **не реалізується** для траєкторій під правилами з ℛ₀.

**Наслідок 18.6.3.** Хаотична динаміка вимагає або:
- (i) не-причинних правил ρ ∈ ℛ₁ з додатковими припущеннями (неперервність у слабшій топології, ніж d_ℛ), або
- (ii) розширеного простору, де картина інваріантна під причинними правилами.

**Зауваження 18.6.4.** Демонстрація `shift_spine` у `subit-infinity` v0.2.0 лежить у ℛ₁ (зсув не причинний: δ падає на 1). У §18.6.2 це відображається: CHAOTIC досяжний лише **умовно** (⚠️), за припущення, що F неперервний у слабшій топології.

**(в) Ресурсна клаузула — винести з Att.**

**Означення 18.4.1 (переформульоване Att).** Att(τ) — **математичне** поняття:

```
ATTAINED      якщо ∃n: ŝₙ ∈ ω(ŝ₀)
ASYMPTOTIC    якщо ∀n: ŝₙ ∉ ω(ŝ₀) і dist(ŝₙ, ω(ŝ₀)) → 0
```

**Прибрати гілку INDETERMINATE з математичного означення.**

**Означення 18.4.2 (обчислювальний статус).** Обчислювальний статус — окреме поле сертифіката:

```
COMPUTED      якщо класифікація завершена
RESOURCE_EXCEEDED  якщо горизонт вичерпано до завершення
```

**Зауваження 18.4.3.** У ℛ₀ компактність гарантує dist(ŝₙ, ω(ŝ₀)) → 0 для всіх траєкторій (Твердження 18.1), отже в ℛ₀ гілка RESOURCE_EXCEEDED — єдиний спосіб не отримати класифікацію. У ℛ₁ можливі обидві гілки.

**(г) Сертифікат для ASYMPTOTIC і CHAOTIC.**

**Означення 18.7.1 (сертифікат ATTAINED).** Сертифікат містить: `trajectory_hash`, `s_component`, `att_type = ATTAINED`, `witness.m = min{n : ŝₙ ∈ ω(ŝ₀)}`, `omega_set = (скінченна множина)`. Перевіряється за поліноміальний час.

**Означення 18.7.2 (сертифікат ASYMPTOTIC).** Не може бути скінченним: свідок — це послідовність усічень π_n(ω(ŝ₀)) разом із межею збіжності dist(ŝₙ, ω(ŝ₀)) → 0. Перевіряється покроково, не за поліноміальний час.

**Означення 18.7.3 (сертифікат CHAOTIC).** Потребує свідка h_top > 0 (наприклад, експоненційного зростання кількості (n, ε)-розділених орбіт). Не має скінченного свідка. Для ℛ₀ (де h_top = 0) — не існує.

**(д) A(τ) для типу (A) — вся орбіта.**

**Означення 18.5'.**

```
A(τ) :=
   ω(ŝ₀)                              якщо Att = ATTAINED і ω скінченна
   ω(ŝ₀)                              якщо Att = ASYMPTOTIC
   (не визначено)                     якщо Att не визначено (RESOURCE_EXCEEDED)
```

Тобто A(τ) **завжди** дорівнює ω(ŝ₀), а не «точці входу». Для циклу це вся орбіта, а не одна точка.

### Наслідки

- §18.5 (означення S): узгоджено з К1.
- §18.7 (сертифікати): розділено на три типи.
- Rust `subit-infinity::p_tau`: переробити Att (без INDETERMINATE в математиці; обчислювальний статус — окремо).
- Rust `subit-infinity::lazy_p_tau`: те саме.
- Демо `lazy-demo`: переформулювати — `shift_spine` дає S = MINIMAL_CANTOR або CHAOTIC (умовно) + Att = ASYMPTOTIC, не INDETERMINATE.
- Lean `Subit/NonCollapse.lean`: переробити під нові класи.

### Новий статус

- §18.5 — ✅ (п'ять класів S).
- §18.6 — ✅ (CHAOTIC недосяжний у ℛ₀, умовно досяжний у ℛ₁).

## К7. Компактність ℛ₀/ℛ₁

### Проблема

### Пропоноване виправлення

**Відкликати Контрприклад 21.1 v6.0.**

**Переписати §21.3–21.5.**

#### §21.3. Топологія на ℛ₀ (переписано)

**Означення 21.3.1 (усічення).** Нехай T_n — множина скінченних дерев глибини ≤ n над алфавітом A. Означимо усічення π_n : S_∞ → T_n, яке замінює всі вузли на глибині n на лист із фіксованою міткою (наприклад, N).

**Означення 21.3.2.** Для f ∈ ℛ₀ і n ∈ ℕ означимо f_n : T_n → T_n, f_n := π_n ∘ f ∘ ι_n, де ι_n : T_n → S_∞ — канонічне вкладення (дерева з T_n як дерева з S_∞, усі листки глибини n).

**Твердження 21.3.3.** f ∈ ℛ₀ однозначно визначається послідовністю (f_n)_{n ∈ ℕ}, узгодженою: π_n ∘ f_{n+1} = f_n ∘ π_n.

**Означення 21.3.4 (d_ℛ).**

```
d_ℛ(f, g) := 2^(−n₀(f, g)),   n₀(f, g) := min{ n : f_n ≠ g_n }
```

**Теорема 21.3.5 (компактність ℛ₀).** (ℛ₀, d_ℛ) — компактний гаусдорфовий простір.

*Доведення.* Кожне T_n скінченне, тому (T_n)^{T_n} скінченне. Простір ℛ₀ ізоморфний оберненій границі:

```
ℛ₀ ≅ lim←_n (T_n)^{T_n}
```

за відображеннями π_n. За теоремою Тихонова (для зліченного добутку скінченних дискретних просторів) границя компактна. Гаусдорфовість спадкується. ∎

## Суттєві проблеми — короткі патчі

### S1. Fix(F) не найменша STABLE-множина

**§14, виправити:**

> Fix(F) = {ŝ : F(ŝ) = ŝ} — **найбільша** підмножина S_∞ × ℛ, усі точки якої нерухомі. Найменша STABLE-множина — ∅ (порожня множина інваріантна тривіально). Найменша **непорожня** STABLE-множина — будь-який атрактор.

### S3. S₀ = A³ vs семантичні алфавіти

**§1, уточнити:**

> Існує **один** алфавіт A = {00, 01, 10, 11} потужності 4. Логічна реалізація називає елементи T, F, B, N; семантична — ME/THEY/... на кожній осі окремо, але всі три осі використовують **той самий** A. Ізоморфізм між реалізаціями — це перейменування, а не ототожнення різних множин.

Тому |S₀| = 4³ = 64, і S_∞ = νX.(A ⊔ X³) із тим самим A.

### S4. S₀ ⊂ S_∞ — не апроксимація

**§13, виправити:**

> S₀ ⊂ S_∞ — вкладення, а не апроксимація. Справжні апроксимації — усічення π_n : S_∞ → T_n. S₀ ≅ T_1 (дерева глибини ≤ 1 з мітками лише в листках).

**Вкладення SUBIT⁺ ⊂ SUBIT_∞** вимагає продовження ρ : S₀ → S₀ до ρ̃ : S_∞ → S_∞ причинним способом. У v6.1 це вважається окремим питанням (Q8).

### S5. d_S — профінітний метризований простір

**§15.1, виправити:**

> δ(s, t) := ∞ якщо s = t. d_S — ультраметрика, але (S_∞, d_S) **не** гомеоморфний зліченному добутку скінченних просторів (листки ізольовані). Правильно: S_∞ — **профінітний** метризований простір, границя скінченних T_n.

**Компактність** все ще виконується (профінітна границя скінченних дискретних просторів компактна).

### S6. Морфізми §8.2 не зберігають g

**§8.2, уточнити:**

> Умова динамічної сумісності зберігає S-проєкцію. Метаеволюція g не зберігається. Це означає, що категорія SUBIT не має природних експоненціалів для об'єктів із нетривіальною g. Статус CCC залишається умовним (для об'єктів з g ≡ id).

### S7. pilot-01 — переробити

**Е.2, виправити:**

> **Розбиття.** Лише 4 біни дають S₀ = A³ (64 стани). 2 і 8 бінів дають інші простори (8 і 512), які не є S₀. Для пілота використовуються лише 4 біни; перевірка стійкості — через **перестановку** квантилів, а не зміну числа бінів.

**Е.6, виправити критерій спростування:**
