Цей документ — перший практичний крок дорожньої карти v5.2 → v6.0, заявленої в супровідному файлі. Його мета — не переписати специфікацію, а **зафіксувати для кожного нормативного твердження v5.2 його точний статус** і **запропонувати конкретні виправлення** там, де статус виявляється нижчим за заявлений. Аудит сфокусовано на чотирьох проблемах, явно названих у дорожній карті (P(τ), топологія ℛ, узгодження Ω, статус proto-topos).

У v6.0 кожне твердження отримує один із шести статусів. Це — не метафора, а робоча класифікація, яка визначає, що саме можна використовувати як аксіому на наступному рівні.

| **Доведено** | ✅ | Є повний доказ із явними передумовами; доказ відтворюваний. |

## 2. Проблема 1: виправлена конструкція P(τ)

### 2.1. Діагноз

v5.2 визначає `m(ŝ₀) := min{n ≥ 0 : ŝₙ ∈ ω(ŝ₀)}` і будує `P_pt(τ) := {ŝ_{m(ŝ₀)}}`. Але `m(ŝ₀)` може не існувати. Контрприклад із дорожньої карти:

> x_n = 1/(n+1) → 0. ω-границя = {0}. Жоден x_n ≠ 0. m не існує.

Це не крайовий випадок: будь-яка траєкторія, що асимптотично наближається до атрактора, не торкаючись його, має ту саму проблему. У S_∞×ℛ це трапляється, щойно F не є нільпотентним на своєму атракторі.

### 2.2. Коректна конструкція

**Означення 2.1 (три типи поведінки траєкторії).** Нехай τ(ŝ₀) = (ŝ₀, ŝ₁, …), ω := ω(ŝ₀) ≠ ∅. Визначимо:

- **(A) Досягнення** (attainment): ∃n ≥ 0: ŝₙ ∈ ω. Тоді m(ŝ₀) := min такого n, і m < ∞.
- **(B) Асимптотичне наближення** (asymptotic approach): ∀n: ŝₙ ∉ ω, але dist(ŝₙ, ω) → 0 в d_S.
- **(C) Недосяжність** (indeterminate): ω = ∅, або дистанція не прямує до 0, або обчислювальних ресурсів бракує для розрізнення A, B, C.

**Означення 2.2 (виправлене P(τ)).** Замість пари (P_pt, P_nbhd) вводимо **трійку**:

```
P(τ) := (A(τ), Ω_set(ω(ŝ₀)), Att(τ))
```

де:

- **A(τ)** — атракторна компонента:
  - якщо тип (A): `A(τ) := {ŝ_m}`, m = m(ŝ₀);
  - якщо тип (B): `A(τ) := ω(ŝ₀)` (множина, не точка);
  - якщо тип (C): `A(τ) := ⊥`.
- **Ω_set(ω)** — клас стабільності ω-границі як множини (за Означенням 6.1): завжди STABLE, якщо F неперервний.
- **Att(τ) ∈ {ATTAINED, ASYMPTOTIC, INDETERMINATE}** — тип досягнення.

**Означення 2.3 (двоосьова класифікація).** Остаточна класифікація траєкторії — це пара

```
Ω_traj(τ) := (S(τ), Att(τ)) ∈ Ω × {ATTAINED, ASYMPTOTIC, INDETERMINATE}
```

де S(τ) ∈ Ω — клас *інваріантної* частини:

| S(τ) | Умова |
|---|---|
| STABLE | ω = {p}, F(p) = p |
| CYCLIC | ω — скінченна орбіта довжини k > 1 |
| METASTABLE | ω ⊊ closure(τ) і F(ω) = ω (не мінімальна інваріантна підмножина) |
| CHAOTIC | ω нескінченна, мінімальна, з додатною топологічною ентропією |

### 2.3. Наслідки

**Твердження 2.1 (узгодженість зі скінченним рівнем — У1').** На скінченному рівні SUBIT⁺ траєкторія завжди типу (A): m(ŝ₀) < ∞, і (S, Att) = (STABLE, ATTAINED) для атрактора, (CYCLIC, ATTAINED) для орбіти. Це відтворює таблицю Твердження 5.1. ✅

**Твердження 2.2 (незалежність — У2').** m(ŝ₀) (або його відсутність) — власна характеристика всієї нескінченної траєкторії, не залежить від довільного горизонту спостереження N. ✅

**Твердження 2.3 (явність відмови — У3').** Випадок (C) повертає ⊥, і це не змішується з (B): `Att = INDETERMINATE` не означає `Att = ASYMPTOTIC`. ✅

**Твердження 2.4 (неколапс — У0).** Ω_traj(τ) не є константою: існують траєкторії з S = STABLE і S = CHAOTIC, і обидва класи реалізуються в S_∞×ℛ_0 (див. §4). ✅

### 2.4. Ціна виправлення

Розширення Ω до Ω × {ATTAINED, ASYMPTOTIC, INDETERMINATE} (12 комірок замість 4) означає, що метрика d_Ω у §15 має бути перевизначена на цьому добутку. Пропозиція для v6.0:

```
d_Ω(ŝ, t̂) := 2^(−n₀),   n₀ := min{n : Ω_traj(Fⁿŝ) ≠ Ω_traj(Fⁿt̂)}
```

Це зберігає принцип першої розбіжності. Ультраметричність зберігається (той самий аргумент транзитивності, Теорема 15.1).

## 3. Проблема 2: топологія простору правил ℛ

### 3.1. Діагноз

v5.2 (§13, §18.3) мовчки ототожнює дві різні речі:
1. Компактність **S_∞** (доведена, §18.1);
2. Компактність **S_∞ × ℛ** (потрібна для ω-границь, але не доведена).

Крім того, твердження «F неперервний відносно d_S для будь-якого f_ρ, заданого скінченним описом» **хибне**. Контрприклад: програма, яка обчислює значення функції, розгалужуючись за нескінченною кількістю бітів входу, може бути розривною в d_S. Скінченність опису не тягне неперервності.

### 3.2. Коректна топологія

**Означення 3.1 (причинна функція).** f : S_∞ → S_∞ називається **причинною** (causal), якщо для всіх s, t ∈ S_∞:

```
δ(s, t) ≥ n  ⟹  δ(f(s), f(t)) ≥ n
```

Інтуїтивно: f не «зливає» два дерева, які розрізняються лише на глибині ≥ n. Причинні функції — це точно функції, які обчислюються синхронними трансдюсерами дерев.

**Означення 3.2 (ℛ_0).** `ℛ_0 := { f : S_∞ → S_∞ | f причинна }`.

**Теорема 3.1 (компактність ℛ_0).** ℛ_0 з топологією поточкової збіжності на деревах скінченної глибини є компактним гаусдорфовим простором.

*Доведення (ескіз).* Позначимо S_∞^{(n)} — множину дерев глибини ≤ n. Кожна S_∞^{(n)} скінченна (|S_∞^{(0)}| = 4, |S_∞^{(1)}| = 4 + 4³ = 68, …). Причинна f однозначно визначається своїми обмеженнями f_n : S_∞^{(n)} → S_∞^{(n)}, які узгоджені: f_{n+1}|_{S_∞^{(n)}} = f_n. Отже,

```
ℛ_0 ≅ lim←_n (S_∞^{(n)})^{S_∞^{(n)}}
```

— обернена границя скінченних множин. За теоремою Тихонова (для зліченного добутку скінченних дискретних просторів) ця границя компактна. ∎

**Наслідок 3.1.** S_∞ × ℛ_0 компактний. Отже, для будь-якого неперервного F : S_∞ × ℛ_0 → S_∞ × ℛ_0 ω(ŝ₀) ≠ ∅ для всіх ŝ₀ (Больцано–Вейєрштрасс).

**Наслідок 3.2.** F неперервний на S_∞ × ℛ_0 у топології добутку.

### 3.3. Двоярусна система

**ℛ_0** (причинні функції) — компактний, топологічно добрий, але вужчий за потрібне.
**ℛ_1** (обчислювані функції) — ширший, але **не компактний**, і F на ньому може бути розривним.

**Нормативне рішення v6.0.** Усі твердження розділів 15–18 формулюються **окремо** для ℛ_0 (безумовно) і ℛ_1 (умовно, з явним припущенням неперервності F). Там, де в v5.2 стояло «для будь-якого f_ρ», у v6.0 має стояти «для f_ρ ∈ ℛ_0» або «для f_ρ ∈ ℛ_1, неперервного в d_S».

## 4. Проблема 3: узгодження Ω_set і Ω_state

### 4.1. Діагноз

Означення 6.1 визначає Ω **для множин** P ⊆ S_∞ × ℛ. Означення 15.1 вживає **Ω(Fⁿŝ)** — застосування Ω до окремого стану. Це не те саме.

### 4.2. Коректне узгодження

**Означення 4.1 (точкова класифікація).** Для ŝ ∈ S_∞ × ℛ:

```
Ω_state(ŝ) := Ω_set( {ŝ} )
```

Явно:

| Ω_state(ŝ) | Умова |
|---|---|
| STABLE | F(ŝ) = ŝ |
| CYCLIC | ∃k > 1: Fᵏ(ŝ) = ŝ, і F(ŝ) ≠ ŝ |
| CHAOTIC | інакше |

**METASTABLE для синглтона неможлива**: образ синглтона — синглтон, ніколи не власна підмножина. Це узгоджується з Твердженням 18.6 v5.2.

**Твердження 4.1 (узгодженість).** Для будь-якої скінченної множини P = {ŝ₁, …, ŝₙ}:

```
Ω_set(P) = STABLE  ⟺  ∀i: Ω_state(ŝᵢ) = STABLE і F(P) = P
```

Це дає міст між точковою і множинною класифікацією. ✅

### 4.3. Тонкість для d_Ω

Метрика d_Ω у §15 використовує Ω(Fⁿŝ) — точкову класифікацію. Це призводить до **дуже грубої** метрики: два стани, які обидва прямують до різних хаотичних атракторів, матимуть Ω_state = CHAOTIC на всіх n, отже d_Ω = 0 — хоча вони поводяться абсолютно по-різному.

**Пропозиція v6.0.** Замінити d_Ω на **d_ω**:

```
d_ω(ŝ, t̂) := 2^(−n₀),   n₀ := min{ n : ω(Fⁿŝ) ≠ ω(Fⁿt̂) }
```

де ω(·) — ω-границя орбіти. Це розрізняє траєкторії за їхніми граничними множинами, а не лише за грубим класом. Ультраметричність зберігається (той самий аргумент першої розбіжності). ✅

Для сумісності з §15 збережемо d_Ω як **факторметрику** d_ω за відношенням «однакова ω-границя», а d_ω — як основну.

## 5. Проблема 4: чесний статус proto-topos

### 5.1. Що насправді доведено

| Властивість | Статус v5.2 | Статус v6.0 |
|---|---|---|
| SUBIT — категорія | ✅ | ✅ |
| Термінальний об'єкт 1 | ✅ | ✅ |
| Добуток X × Y | ✅ | ✅ |
| Скінченні ліміти (T1) | Заявлено ✅ | ✅ для скінченних добутків; ❓ для загальних лімітів (еквалайзери не побудовані) |
| Експоненціал (T2) | ⚠️ для оборотних F | ⚠️ для підкатегорії оборотних об'єктів; ❓ для загального випадку |
| Субоб'єктний класифікатор (T3) | Заявлено «в динамічній формі» | ❌ **не доведено**; Ω — лише алгебра Гейтінга, не класифікатор |

### 5.2. Чому T3 не доведено

Для топосу потрібен **універсальний субоб'єкт** ⊤ : 1 → Ω такий, що для кожного моно φ : U ↪ X існує єдиний характеристичний морфізм χ_φ : X → Ω, який робить квадрат

```
U  ──→  1
│         │ ⊤
↓         ↓
X  ──→  Ω
```

декартовим (pullback). У SUBIT:

- **Об'єкт Ω** — це множина {STABLE, METASTABLE, CYCLIC, CHAOTIC} **без внутрішньої динаміки**. Але об'єкти SUBIT — це системи X = (S_X, ℛ_X, F_X, g_X), тобто вони містять F. Отже, Ω як об'єкт SUBIT має мати власний F_Ω — а його в v5.2 немає.
- **⊤ : 1 → Ω** має бути морфізмом у SUBIT, тобто зберігати динаміку. Але 1 — термінальний об'єкт з S₁ = {∗}, а Ω — множина без динаміки; морфізм не визначено.

**Висновок.** SUBIT **не є топосом** і **не є доведеним proto-topos**. Правильна назва для v6.0 — **Ω-класифікована категорія** (Ω-classified category): категорія з виділеним об'єктом Ω, що несе структуру алгебри Гейтінга, але без доведеної універсальної властивості.

### 5.3. Що потрібно для відновлення статусу proto-topos

Одне з двох:

**(а)** Побудувати F_Ω : Ω → Ω, g_Ω : Ω × Ω → Ω, що робить Ω об'єктом SUBIT, і довести універсальну властивість характеристичного морфізму. Це нетривіальна програма.

**(б)** Послабити вимогу: замінити T3 на **T3'**: «SUBIT має об'єкт Ω зі структурою алгебри Гейтінга та природним перетворенням Sub(-) → Hom(-, Ω), яке не є ізоморфізмом». Це дає **динамічно збагачену категорію**, а не топос.

**Рекомендація для v6.0:** прийняти (б) як основний шлях, (а) — як відкрите питання (розділ 17).

## 6. Дрібніші виправлення, виявлені аудитом

### 6.1. Аксіома M4 модальної логіки

v5.2 §11 постулює `(M4) ◇A ↔ ¬□¬A`. У Ω_SUBIT заперечення ¬ визначене як ¬a := a → CHAOTIC, і для a = METASTABLE: ¬METASTABLE = CHAOTIC, ¬CHAOTIC = STABLE. Тоді:

```
◇METASTABLE  (існує k: Fᵏ(s) ∈ METASTABLE)
¬□¬METASTABLE = ¬□CHAOTIC
```

Якщо CHAOTIC на скінченному рівні не реалізується (Твердження 5.1), то □CHAOTIC = ⊥, отже ¬□CHAOTIC = ¬⊥ = STABLE ≠ ◇METASTABLE.

**M4 не виконується в Ω_SUBIT.** Це не помилка v5.2 — це наслідок інтуїціоністської семантики. У v6.0 M4 має бути **понижена до гіпотези** або замінена на слабшу:

```
(M4')  ◇A → ¬□¬A
```

(одна імплікація замість еквівалентності). Це стандартна інтуїціоністська форма.

### 6.2. Твердження 18.5 (існування m(ŝ₀))

Спростовано контрприкладом x_n = 1/(n+1). У v6.0 має бути замінено на Означення 2.1–2.3 (див. §2 вище).

### 6.3. Твердження 18.3 (непорожність ω(ŝ₀))

Доведення спирається на компактність S_∞ × ℛ, якої немає без топології ℛ. У v6.0 — розділено на два твердження: для ℛ_0 (✅) і для ℛ_1 (⚠️, з припущенням компактності або неперервності F).

## 8. Що далі

Цей аудит — лише перший шар роботи v6.0. Наступні кроки, у порядку дорожньої карти:

1. **SUBIT-CORE (крок 02 дорожньої карти).** Реалізувати скінченне ядро: 64 стани, правило ρ, метаеволюція g, класифікація траєкторій за Алгоритмом 5.1. Це безпечно, бо спирається лише на ✅-твердження.
