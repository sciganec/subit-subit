## WP1.4. §9 (v6.0). SUBIT як Ω-класифікована категорія

### 9.1. Діагноз v5.2

v5.2 §9 стверджує, що SUBIT є **proto-topos**, спираючись на три умови:

- (T1) скінченні ліміти — заявлено ✅;
- (T2) експоненціали — заявлено ⚠️ (лише для оборотних F);
- (T3) субоб'єктний класифікатор — заявлено «в динамічній формі».

Аудит (Частина 1, §5) показав:

- (T1) доведено лише для скінченних добутків; еквалайзери не побудовані;
- (T2) доведено лише для підкатегорії оборотних об'єктів;
- (T3) **не доведено**: Ω у v5.2 — це множина {STABLE, METASTABLE, CYCLIC, CHAOTIC} **без власної динаміки**, отже вона не є об'єктом SUBIT. Характеристичний морфізм χ_φ : X → Ω не визначено.

**Висновок.** Назва «proto-topos» у v5.2 не виправдана. У v6.0 вона замінюється на точнішу.

### 9.2. Означення Ω-класифікованої категорії

**Означення 9.1 (Ω-об'єкт).** Нехай C — категорія з термінальним об'єктом 1. Об'єкт Ω ∈ C називається **Ω-об'єктом**, якщо:

1. Ω несе структуру алгебри Гейтінга (∧, ∨, →, ⊤, ⊥);
2. Існує морфізм ⊤ : 1 → Ω;
3. Для кожного об'єкта X ∈ C існує відображення (не обов'язково морфізм)
   ```
   Sub(X) → Hom(X, Ω)
   ```
   яке кожному субоб'єкту U ↪ X зіставляє характеристичне відображення χ_U : X → Ω.

**Означення 9.2 (Ω-класифікована категорія).** Категорія C називається **Ω-класифікованою**, якщо вона має Ω-об'єкт, але відображення Sub(X) → Hom(X, Ω) не вимагається бути бієкцією.

**Зауваження 9.1.** Топос — це Ω-класифікована категорія, у якій Sub(X) → Hom(X, Ω) є бієкцією (і Ω — субоб'єктний класифікатор у строгому сенсі). У SUBIT бієкція не доведена, тому SUBIT не є топосом.

### 9.3. Ω як об'єкт SUBIT

Щоб Ω був об'єктом SUBIT, він має нести динаміку: Ω = (S_Ω, ℛ_Ω, F_Ω, g_Ω).

**Означення 9.3 (динамічний Ω).**

```
S_Ω     := {STABLE, METASTABLE, CYCLIC, CHAOTIC}
ℛ_Ω     := {id_Ω}
F_Ω(x)  := x          (тотожна динаміка)
g_Ω(ρ, x) := ρ
```

Тотожна динаміка означає: Ω-класифікація не змінюється сама по собі; вона є **інваріантом** еволюції. Це узгоджується з семантикою Ω як класифікатора стабільності.

**Твердження 9.1.** Ω = (S_Ω, ℛ_Ω, F_Ω, g_Ω) є об'єктом SUBIT.

*Доведення.* S_Ω ⊆ S₀? Ні, S_Ω — це множина з 4 елементів, не підмножина S₀. Але означення 8.1 v5.2 вимагає S_X ⊆ S₀. Тому потрібне уточнення: об'єкти SUBIT можуть мати довільну S_X, а не лише підмножину S₀. Або альтернативно: Ω кодується як підмножина S₀ через ін'єкцію. Обидва варіанти технічно можливі; обираємо перший — розширення класу об'єктів.

**Уточнення 9.1 (об'єкти SUBIT).** Об'єктом SUBIT є система X = (S_X, ℛ_X, F_X, g_X), де S_X — довільна множина (не обов'язково підмножина S₀), ℛ_X — множина функцій S_X → S_X, з аксіомою замкненості F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

Це узгоджується з v5.2 §8 для випадку S_X ⊆ S₀ і розширює його для Ω.

### 9.4. Морфізм ⊤ : 1 → Ω

**Означення 9.4.** ⊤ : 1 → Ω — морфізм, що відображає єдиний елемент ∗ ∈ S₁ у STABLE ∈ S_Ω, і id ∈ ℛ₁ у id_Ω ∈ ℛ_Ω.

**Твердження 9.2.** ⊤ — морфізм SUBIT.

*Доведення.* Потрібно перевірити умову динамічної сумісності (Означення 8.2 v5.2):

```
φ_S(π_S(F_1(ŝ))) = π_S(F_Ω(φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ))))
```

Ліва частина: F_1(∗, id) = (∗, id), отже π_S = ∗. φ_S(∗) = STABLE.

Права частина: φ_S(∗) = STABLE, φ_ℛ(id) = id_Ω. F_Ω(STABLE, id_Ω) = (STABLE, id_Ω). π_S = STABLE.

Отже, STABLE = STABLE. ✅

### 9.5. Характеристичне відображення

**Означення 9.5.** Нехай U ↪ X — субоб'єкт (моно φ : U → X). Характеристичне відображення χ_U : X → Ω визначається:

```
χ_U(x) := 
   STABLE       якщо x ∈ U і F_X(x) ∈ U
   METASTABLE   якщо x ∈ U і F_X(U) ⊊ U
   CYCLIC       якщо x ∈ U і ∃k>1: F_Xᵏ(U) = U
   CHAOTIC      якщо x ∉ U або F_X(U) ⊄ U
```

**Твердження 9.3 (природність χ).** Для будь-якого морфізма f : X → Y і субоб'єкта U ↪ Y маємо:

```
χ_{f⁻¹(U)} = χ_U ∘ f
```

*Доведення (ескіз).* Випливає з динамічної сумісності f і означення χ. ∎

**Зауваження 9.2.** χ_U **не** є єдиним: два різні субоб'єкти U₁ ≠ U₂ можуть мати однакове χ. Саме тому Sub(X) → Hom(X, Ω) не є бієкцією, і SUBIT не є топосом.

**Приклад 9.1 (неединичність).** Нехай X — система з двома нерухомими точками p, q ∈ S_X. Нехай U₁ = {p}, U₂ = {q}. Тоді χ_{U₁}(p) = STABLE, χ_{U₁}(q) = CHAOTIC; χ_{U₂}(p) = CHAOTIC, χ_{U₂}(q) = STABLE. Це різні відображення. Але якщо U₁ = {p}, U₂ = {p, r}, де r — транзитна точка, що веде до p, то χ_{U₁} і χ_{U₂} можуть збігатися на всіх x, якщо класифікація не розрізняє «бути в U» від «бути в U і досягти p». Отже, бієкція не виконується.

### 9.6. Підсумковий статус

**Твердження 9.4.** SUBIT є Ω-класифікованою категорією, але не є топосом.

*Доведення.* Ω-об'єкт існує (Твердження 9.1), ⊤ існує (Твердження 9.2), χ існує (Означення 9.5). Бієкція Sub(X) → Hom(X, Ω) не виконується (Приклад 9.1). Отже, SUBIT — Ω-класифікована, не топос. ∎

**Відкрите питання Q2 (переформульоване).** Чи існує природний підклас C₀ ⊂ SUBIT, на якому Sub(X) → Hom(X, Ω) є бієкцією? Якщо так, C₀ був би топосом.

## WP1.2. §21 (v6.0). Топологія простору правил ℛ

### 21.1. Діагноз v5.2

v5.2 не визначає топології на ℛ, але мовчки використовує компактність S_∞ × ℛ у §18.3. Крім того, твердження «F неперервний для будь-якого f_ρ, заданого скінченним описом» хибне: скінченність опису не тягне неперервності.

### 21.2. Причинні функції

**Означення 21.1 (глибина розходження).** Для s, t ∈ S_∞:

```
δ(s, t) := 0,  якщо s, t — листки з різними мітками, або один лист, інший вузол
δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')),  якщо s = (w,x,y), t = (w',x',y')
```

**Означення 21.2 (причинна функція).** f : S_∞ → S_∞ називається **причинною**, якщо:

```
∀s,t ∈ S_∞: δ(s, t) ≥ n ⟹ δ(f(s), f(t)) ≥ n
```

Інтуїтивно: f не «зливає» дерева, які розрізняються лише на глибині ≥ n.

**Означення 21.3.** `ℛ_0 := { f : S_∞ → S_∞ | f причинна }`.

**Означення 21.4.** `ℛ_1 := { f : S_∞ → S_∞ | f обчислювана }` (ширший клас; F на ньому може бути розривним).

### 21.3. Топологія на ℛ_0

**Означення 21.5 (топологія поточкової збіжності).** Для f, g ∈ ℛ_0:

```
d_ℛ(f, g) := 2^(−n₀(f,g)),   n₀(f,g) := min{ n : f|_{S_∞^{(n)}} ≠ g|_{S_∞^{(n)}} }
```

де S_∞^{(n)} — множина дерев глибини ≤ n.

**Твердження 21.1.** d_ℛ — ультраметрика на ℛ_0.

*Доведення.* Стандартний аргумент першої розбіжності. ∎

**Теорема 21.2 (компактність ℛ_0).** (ℛ_0, d_ℛ) — компактний гаусдорфовий простір.

*Доведення.* Кожна S_∞^{(n)} скінченна. Причинна f однозначно визначається своїми обмеженнями f_n : S_∞^{(n)} → S_∞^{(n)}, узгодженими: f_{n+1}|_{S_∞^{(n)}} = f_n. Отже,

```
ℛ_0 ≅ lim←_n (S_∞^{(n)})^{S_∞^{(n)}}
```

— обернена границя скінченних множин. За теоремою Тихонова для зліченного добутку скінченних дискретних просторів ця границя компактна. Гаусдорфовість спадкується. ∎

**Наслідок 21.1.** S_∞ × ℛ_0 компактний.

**Наслідок 21.2.** Для будь-якого неперервного F : S_∞ × ℛ_0 → S_∞ × ℛ_0 і будь-якого ŝ₀: ω(ŝ₀) ≠ ∅.

### 21.4. Неперервність F на ℛ_0

**Твердження 21.3.** Для f ∈ ℛ_0 відображення F_f : S_∞ → S_∞, F_f(s) := f(s), є неперервним у d_S.

*Доведення.* Причинність f означає: δ(s, t) ≥ n ⟹ δ(f(s), f(t)) ≥ n. Це саме умова рівномірної неперервності в ультраметриці. ∎

**Твердження 21.4.** F : S_∞ × ℛ_0 → S_∞ × ℛ_0 неперервний у топології добутку.

*Доведення (ескіз).* F(s, ρ) = (f_ρ(s), g(ρ, s)). Неперервність за s — Твердження 21.3. Неперервність за ρ — з топології поточкової збіжності. Неперервність g — припущення (g має бути причинним за ρ і неперервним за s). ∎

### 21.5. ℛ_1 та її межі

**Застереження 21.1.** Для ℛ_1 компактність не гарантована. Контрприклад: сімейство f_n(s) := s, якщо глибина s < n, інакше — лист з міткою n mod 4, не має збіжної підпослідовності в d_ℛ.

**Нормативне рішення v6.0.** Усі твердження, що використовують компактність S_∞ × ℛ, формулюються **окремо**:

- для ℛ_0 — безумовно ✅;
- для ℛ_1 — умовно ⚠️, з явним припущенням: «F неперервний» або «S_∞ × ℛ_1 компактний».

### 21.6. Класифікація правил за причинністю

| Клас | Визначення | Компактність | Неперервність F |
|---|---|---|---|
| ℛ_0 | причинні | ✅ | ✅ |
| ℛ_1 | обчислювані | ❌ | ⚠️ |
| ℛ_0 ∩ ℛ_1 | причинні й обчислювані | ✅ | ✅ |

**Твердження 21.5.** ℛ_0 ∩ ℛ_1 ≠ ∅: тотожне відображення id належить обом.

## WP1.3. §6.3 (v6.0) і §15 (v6.0). Узгодження Ω_set / Ω_state

### 6.3. Точкова та множинна класифікація

**Означення 6.3 (Ω_state).** Для ŝ ∈ S_∞ × ℛ:

```
Ω_state(ŝ) := Ω_set({ŝ})
```

Явно:

| Ω_state(ŝ) | Умова |
|---|---|
| STABLE | F(ŝ) = ŝ |
| CYCLIC | ∃k > 1: Fᵏ(ŝ) = ŝ, і F(ŝ) ≠ ŝ |
| CHAOTIC | інакше |

**METASTABLE для синглтона неможлива**: образ синглтона — синглтон, ніколи не власна підмножина.

**Твердження 6.3 (узгодженість).** Для будь-якої скінченної множини P = {ŝ₁, …, ŝₙ}:

```
Ω_set(P) = STABLE  ⟺  ∀i: Ω_state(ŝᵢ) = STABLE і F(P) = P
```

*Доведення.* Якщо F(P) = P і кожен елемент нерухомий, то P стабільна. Навпаки, якщо P стабільна, то F(P) = P; якщо при цьому якийсь ŝᵢ не нерухомий, то F(ŝᵢ) ≠ ŝᵢ, але F(ŝᵢ) ∈ P, отже F(P) ⊊ P або F(P) ≠ P — суперечність. ∎

### 15 (v6.0). Семантичні метрики d_ω та d_Ω

**Діагноз v5.2.** d_Ω у §15 вживає Ω(Fⁿŝ) — точкову класифікацію. Це призводить до дуже грубої метрики: два стани, які прямують до різних хаотичних атракторів, матимуть Ω_state = CHAOTIC на всіх n, отже d_Ω = 0.

**Означення 15.1 (d_ω — основна метрика).** Для ŝ, t̂ ∈ S_∞ × ℛ:

```
n₀(ŝ, t̂) := min{ n ≥ 0 : ω(Fⁿŝ) ≠ ω(Fⁿt̂) }
d_ω(ŝ, t̂) := 2^(−n₀),  якщо n₀ визначено
d_ω(ŝ, t̂) := 0,        якщо ω(Fⁿŝ) = ω(Fⁿt̂) для всіх n ≥ 0
```

**Теорема 15.1 (властивості d_ω).** d_ω — псевдоультраметрика на S_∞ × ℛ; стає ультраметрикою на факторпросторі (S_∞ × ℛ)/~_ω, де ŝ ~_ω t̂ ⟺ ω(Fⁿŝ) = ω(Fⁿt̂) для всіх n.

*Доведення.* Симетричність очевидна. Сильна нерівність трикутника: той самий аргумент транзитивності, що й у Теоремі 15.1 v5.2. ∎

**Означення 15.2 (d_Ω — факторметрика).**

```
d_Ω(ŝ, t̂) := 2^(−n₁),   n₁ := min{ n : Ω_traj(Fⁿŝ) ≠ Ω_traj(Fⁿt̂) }
```

де Ω_traj — двоосьова класифікація з §18.7.

**Твердження 15.2.** d_Ω є факторметрикою d_ω за відношенням «однакова Ω_traj-траєкторія». Зокрема, d_Ω(ŝ, t̂) = 0 тягне d_ω(ŝ, t̂) = 0, але не навпаки.

*Доведення.* Якщо Ω_traj(Fⁿŝ) = Ω_traj(Fⁿt̂) для всіх n, то зокрема S-компоненти збігаються, що означає ω(Fⁿŝ) = ω(Fⁿt̂) (за означенням S). Отже, d_ω = 0. Зворотне не виконується: два стани з однаковою ω-границею, але різними Att (один ATTAINED, інший ASYMPTOTIC), мають d_ω = 0, але d_Ω > 0. ∎

**Твердження 15.3 (нульвимірність).** (S_∞ × ℛ_0)/~_ω з d_ω — тотально незв'язний, нульвимірний простір.

*Доведення.* Спадкує від S_∞ × ℛ_0 (компактний, нульвимірний) і факторизації за відкритим відношенням. ∎

**Застереження 15.1.** Для ℛ_1 твердження 15.3 стає умовним: потребує компактності S_∞ × ℛ_1 або неперервності F.
