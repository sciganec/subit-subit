## D0.3. Вибір proof assistant

**Рішення: Lean 4 + mathlib.**

Обґрунтування:
- Активна екосистема, mathlib покриває категорії, топологію, ґратки.
- `lake` — простий менеджер пакетів.
- Краща підтримка коіндуктивних типів, ніж у Coq (критично для S_∞).
- Спільнота: активна, є досвід формалізації коалгебр.

Резервний варіант: Coq + MathComp — якщо Lean виявить прогалини в теорії коалгебр.

## D0.4. Вибір мови для CORE

**Рішення: Rust.**

Обґрунтування:
- Строга типізація — узгоджується з духом SUBIT (типи як класи траєкторій).
- Продуктивність для траєкторій довжиною 10⁶+.
- `serde` для JSON-сертифікатів.
- `proptest` для property-based тестування інваріантів.
- Детермінізм: однакові входи → однакові виходи (критично для відтворюваності).

Прототип може бути на Python (`subit-core-py`) — але нормативна реалізація лише Rust.

## §18 (v6.0). Канонічна побудова P(τ): від траєкторії до класифікованої множини

### 18.1. Постановка задачі

Означення 6.1 (Ω для множин) і Означення 15.1 (метрика d_Ω, що вживає Ω(Fⁿŝ)) залишають незамкненою передумову: як від траєкторії τ(ŝ₀) = (ŝ₀, ŝ₁, …) перейти до об'єкта, який класифікує Ω. Потрібна функція

```
P : Траєкторії(S_∞ × ℛ) → Класифіковані об'єкти ∪ {⊥}
```

що задовольняє чотири вимоги:

- **(У0, неколапс)** — P(τ) не повинна апріорно визначати Ω-клас.
- **(У1, узгодженість)** — на скінченному рівні відтворює типологію Твердження 5.1.
- **(У2, інваріантність)** — не залежить від довільних параметрів спостереження.
- **(У3, явність відмови)** — випадок нелокалізованої асимптотичної поведінки позначається явно (⊥).

### 18.2. Незалежна від Ω топологія на S_∞

Побудова не може спиратися на d_Ω (вона сама залежить від Ω — це було б колом). Означимо структурну ультраметрику безпосередньо на деревах:

```
d_S(s, t) := 2^(−δ(s,t))
```

де δ(s, t) — найменша глибина розходження піддерев `out(s)`, `out(t)`:

- δ(s, t) = 0, якщо s, t — листки з різними мітками, або один із них лист, інший — вузол;
- δ(s, t) := 1 + min(δ(w, w'), δ(x, x'), δ(y, y')) для вузлів (w, x, y) і (w', x', y').

**Твердження 18.1.** d_S — ультраметрика на S_∞; (S_∞, d_S) — компактний простір.

*Доведення (ескіз).* Ультраметричність — стандартний аргумент «першої розбіжності», застосований до структури дерева (той самий, що й у Теоремі 15.1). Компактність — за лемою Кеніга; (S_∞, d_S) гомеоморфний зліченному добутку скінченних дискретних просторів, компактність — за теоремою Тихонова. ∎

### 18.3. Топологія простору правил ℛ

**Ключова корекція відносно v5.2.** У v5.2 компактність S_∞ мовчки переносилася на S_∞ × ℛ. Це хибно: компактність добутку вимагає компактності обох множників.

**Означення 18.1 (причинна функція).** f : S_∞ → S_∞ називається **причинною**, якщо для всіх s, t ∈ S_∞:

```
δ(s, t) ≥ n  ⟹  δ(f(s), f(t)) ≥ n
```

Інтуїтивно: f не «зливає» дерева, які розрізняються лише на глибині ≥ n.

**Означення 18.2.** `ℛ_0 := { f : S_∞ → S_∞ | f причинна }`.

**Означення 18.3.** `ℛ_1 := { f : S_∞ → S_∞ | f обчислювана }` (ширший клас; F на ньому може бути розривним).

**Теорема 18.2 (компактність ℛ_0).** ℛ_0 з топологією поточкової збіжності на деревах скінченної глибини є компактним гаусдорфовим простором.

*Доведення.* Позначимо S_∞^{(n)} — множину дерев глибини ≤ n. Кожна S_∞^{(n)} скінченна. Причинна f однозначно визначається своїми обмеженнями f_n : S_∞^{(n)} → S_∞^{(n)}, узгодженими: f_{n+1}|_{S_∞^{(n)}} = f_n. Отже,

```
ℛ_0 ≅ lim←_n (S_∞^{(n)})^{S_∞^{(n)}}
```

— обернена границя скінченних множин. За теоремою Тихонова (для зліченного добутку скінченних дискретних просторів) ця границя компактна. Гаусдорфовість — спадкується від скінченних дискретних просторів. ∎

**Наслідок 18.1.** S_∞ × ℛ_0 компактний.

**Наслідок 18.2.** Для будь-якого неперервного F : S_∞ × ℛ_0 → S_∞ × ℛ_0 і будь-якого ŝ₀: ω(ŝ₀) ≠ ∅.

**Застереження для ℛ_1.** Для ℛ_1 компактність не гарантована; усі подальші твердження формулюються окремо для ℛ_0 (безумовно) і ℛ_1 (умовно, з явним припущенням неперервності F).

### 18.4. ω-границя

**Означення 18.4.** ω(ŝ₀) := {ŝ ∈ S_∞ × ℛ_0 | ∃ підпослідовність (nₖ): ŝ_{nₖ} → ŝ у метриці d_S × d_S}.

**Твердження 18.3 (непорожність).** Для ℛ_0: ω(ŝ₀) ≠ ∅ для будь-якого ŝ₀. Для ℛ_1: за умови компактності S_∞ × ℛ_1 або неперервності F.

*Доведення.* Для ℛ_0 — безпосередньо з Наслідку 18.1 і теореми Больцано–Вейєрштрасса. ∎

**Твердження 18.4 (інваріантність).** Якщо F неперервний, то F(ω(ŝ₀)) = ω(ŝ₀).

*Доведення.* Стандартний результат топологічної динаміки (Walters, 1982). ∎

### 18.5. Чому P(τ) := ω(ŝ₀) — неправильна відповідь

**Твердження 18.5 (колапс).** Якщо P(τ) := ω(ŝ₀), то Ω(P(τ)) = STABLE для будь-якої траєкторії за будь-яких обставин.

*Доведення.* За Твердженням 18.4, F(ω) = ω, тобто ω задовольняє означення STABLE. ∎

Ця побудова відхиляється: вона задовольняє У1–У3 формально, але порушує У0.

### 18.6. Три типи досягнення

**Ключова корекція відносно v5.2.** У v5.2 момент `m(ŝ₀) := min{n : ŝₙ ∈ ω(ŝ₀)}` передбачався існуючим. Це хибно.

**Контрприклад 18.1.** Нехай S_∞ містить траєкторію x_n = 1/(n+1) → 0. Тоді ω = {0}, але жоден x_n ≠ 0. Отже, m(ŝ₀) не існує.

**Означення 18.5 (типи досягнення).** Нехай ω := ω(ŝ₀) ≠ ∅.

- **(A) ATTAINED** — ∃n ≥ 0: ŝₙ ∈ ω. Тоді m(ŝ₀) := min такого n, і m < ∞.
- **(B) ASYMPTOTIC** — ∀n: ŝₙ ∉ ω, але dist(ŝₙ, ω) → 0 в d_S.
- **(C) INDETERMINATE** — ω = ∅, або dist(ŝₙ, ω) ↛ 0, або обчислювальних ресурсів бракує для розрізнення A, B, C.

### 18.7. Двоосьова класифікація

**Означення 18.6 (S-компонента).** Клас інваріантної частини:

| S(τ) | Умова |
|---|---|
| STABLE | ω = {p}, F(p) = p |
| CYCLIC | ω — скінченна орбіта довжини k > 1 |
| METASTABLE | ω ⊊ closure(τ) і F(ω) = ω, але ω не мінімальна |
| CHAOTIC | ω нескінченна, мінімальна, з додатною топологічною ентропією |

**Означення 18.7 (Ω_traj).** Остаточна класифікація траєкторії:

```
Ω_traj(τ) := (S(τ), Att(τ)) ∈ Ω × {ATTAINED, ASYMPTOTIC, INDETERMINATE}
```

**Означення 18.8 (функція P).** 

```
P(τ) := (A(τ), Ω_traj(τ), certificate)
```

де:

- **A(τ)** — атракторна компонента:
  - тип (A): A(τ) := {ŝ_m}, m = m(ŝ₀);
  - тип (B): A(τ) := ω(ŝ₀);
  - тип (C): A(τ) := ⊥.
- **Ω_traj(τ)** — двоосьова класифікація.
- **certificate** — сертифікат (див. §18.9).

### 18.8. Перевірка вимог

**Твердження 18.6 (У0, неколапс).** Існують траєкторії з різними Ω_traj. Зокрема, (STABLE, ATTAINED) ≠ (CHAOTIC, ASYMPTOTIC).

*Доведення.* На скінченному рівні: атрактор дає (STABLE, ATTAINED); орбіта — (CYCLIC, ATTAINED). У S_∞ × ℛ_0 існують хаотичні траєкторії (приклад будується явно; див. Фазу 4). ∎

**Твердження 18.7 (У1, узгодженість).** На скінченному рівні SUBIT⁺: P(τ) відтворює типологію Твердження 5.1.

*Доведення.* На скінченному рівні кожна траєкторія типу (A). Для нерухомої точки: Ω_traj = (STABLE, ATTAINED). Для орбіти: Ω_traj = (CYCLIC, ATTAINED). Для передперіодичної: Ω_traj = (S(ω), ATTAINED), де S(ω) ∈ {STABLE, CYCLIC}. ∎

**Твердження 18.8 (У2, інваріантність).** P(τ) залежить лише від нескінченної траєкторії τ, не від горизонту спостереження N.

*Доведення.* ω(ŝ₀), m(ŝ₀) і Att(τ) визначені через усю τ. ∎

**Твердження 18.9 (У3, явність відмови).** Випадок (C) повертає ⊥, і це не змішується з (B).

*Доведення.* За означенням 18.5. ∎

### 18.9. Сертифікат класифікації

**Означення 18.9.** Сертифікат для P(τ) — це JSON-об'єкт:

```json
{
  "trajectory_hash": "sha256:...",
  "s_component": "STABLE" | "METASTABLE" | "CYCLIC" | "CHAOTIC",
  "att_type": "ATTAINED" | "ASYMPTOTIC" | "INDETERMINATE",
  "witness": {
    "m": 3,                    // якщо ATTAINED
    "fixed_point": "ME-EAST-SPRING",
    "k": null                  // якщо CYCLIC
  },
  "omega_set": ["..."],
  "core_version": "1.0.0",
  "rule_class": "R_0" | "R_1"
}
```

Сертифікат має бути **машинно перевірюваним**: незалежна реалізація CORE повинна підтвердити його за поліноміальний час.

### 18.10. Наслідок для протоколу застосування: Крок 0 і Крок 0'

Побудова P(τ) передбачає, що емпіричні дані вже подані як траєкторія в S_∞ × ℛ. Тому протокол застосування доповнюється:

- **Крок 0 (кодування).** Обґрунтування розбиття неперервного простору вимірів на скінченний алфавіт A. Точний аналог породжувального розбиття в символічній динаміці (Kolmogorov, 1958; Sinai, 1959).
- **Крок 0' (причинність).** Перевірка, що обрані правила ρ належать ℛ_0 (причинні) або, якщо ℛ_1, то F неперервний. Без цього всі твердження §18.3–18.4 стають умовними.
