# 1. Мета

Цей модуль визначає систему виявлення закономірностей у просторі морфологічного різноманіття мушель.

Попередні модулі SUBIT-SHELL дозволили:

- описувати мушлі параметрами W, D, T;
- генерувати синтетичні морфології;
- досліджувати безперервну динаміку росту;
- перевіряти геометричну й топологічну допустимість;
- оцінювати механічну здійсненність;
- порівнювати моделі з природними зразками;
- відновлювати параметри за неповними даними.

Тепер об'єктом дослідження стає не окрема мушля, а множина морфологічних конфігурацій.

Основне завдання:

**Виявити приховану структуру простору форм і встановити, які закономірності визначають його заповнення природними організмами.**

Модуль повинен розрізняти чотири поняття:

1. Математично можливі форми.
2. Геометрично допустимі форми.
3. Біологічно реалізовані форми.
4. Історично зафіксовані форми.

Ці множини не можна ототожнювати.

# 2. Фундаментальна модель морфологічного простору

Базовий параметричний простір:

Ω_R = {(W,D,T) | W>0, D>0, T∈ℝ}

Це простір моделі Раупа.

Однак повний морфологічний простір SUBIT-SHELL повинен включати додаткові характеристики:

Ω_SHELL = Ω_R × P × C × H

де:

- Ω_R — базові параметри Раупа;
- P — параметри поперечного перерізу та поверхні;
- C — контекст;
- H — історія росту.

Тому однакові W, D, T не гарантують однакової кінцевої геометрії.

Наприклад, дві мушлі з однаковими базовими параметрами можуть відрізнятися через:

- еліптичність перерізу;
- змінну товщину стінки;
- асиметрію устя;
- орнаментацію;
- локальні зміни росту;
- пошкодження;
- відмінності матеріальної структури.

Відповідно, модель Раупа є базовою проєкцією ширшого простору.

# 3. Багаторівнева структура морфологічного простору

Визначимо п'ять просторів.

## 3.1. Ω₀ — Mathematical Morphospace

Усі конфігурації, які допускаються математичними визначеннями параметрів.

## 3.2. Ω₁ — Geometric Morphospace

Конфігурації, для яких можна побудувати геометрично коректну поверхню.

## 3.3. Ω₂ — Structural Morphospace

Конфігурації, які проходять визначені структурні та механічні критерії.

## 3.4. Ω₃ — Biological Morphospace

Конфігурації, для яких існують достатні підстави вважати їх біологічно реалізованими або біологічно правдоподібними.

## 3.5. Ω₄ — Observed Morphospace

Конфігурації, підтверджені конкретними природними зразками.

Ці рівні не є автоматично вкладеними множинами без додаткових припущень.

Наприклад, геометрично коректна форма може не пройти механічну перевірку. Біологічно правдоподібна форма може бути ще не знайдена у викопному матеріалі.

Кожна конфігурація повинна отримувати незалежні статуси:

- MATHEMATICAL;
- GEOMETRIC;
- STRUCTURAL;
- BIOLOGICAL;
- OBSERVED.

Статус UNKNOWN повинен залишатися допустимим результатом.

# 4. SUBIT-64 як дискретна проєкція

SUBIT-64 описує простір із 64 дискретних конфігурацій.

Три параметри:

- W — розширення;
- D — радіальна відстань;
- T — осьове зміщення.

Кожен параметр має чотири дискретні рівні.

Код:

WWDDTT

Ідентифікатор:

ID = 32b₁ + 16b₂ + 8b₃ + 4b₄ + 2b₅ + b₆

Важливе розрізнення:

SUBIT-64 не є повним морфологічним простором.

Він є дискретною координатною картою частини безперервного простору.

Відображення:

Q: Ω_R → SUBIT-64

може втрачати інформацію.

Тому кожен дискретний стан повинен зберігати посилання на:

- точні безперервні параметри;
- межі відповідного інтервалу;
- правило дискретизації;
- профіль калібрування;
- невизначеність;
- контекст.

Два зразки з однаковим SUBIT-64 кодом не обов'язково мають однакову форму.

# 5. Морфологічні закономірності

SUBIT-SHELL повинен виявляти кілька типів закономірностей.

## 5.1. PARAMETRIC PATTERNS

Закономірності у W, D, T.

Приклади дослідницьких питань:

- Чи зустрічаються певні діапазони W частіше за інші?
- Чи існує залежність між W та D?
- Чи корелює T із W?
- Чи є області параметричного простору, де природні зразки особливо рідкісні?

## 5.2. GEOMETRIC PATTERNS

Закономірності у кінцевій геометрії:

- компактність;
- витягнутість;
- кількість витків;
- перекриття;
- форма устя;
- просторове розташування витків.

## 5.3. DYNAMIC PATTERNS

Закономірності траєкторій росту:

- стабільна експансія;
- прискорення росту;
- уповільнення;
- зміна осьового зміщення;
- періодичні зміни;
- локальні переходи.

## 5.4. STRUCTURAL PATTERNS

Закономірності, пов'язані з механічною структурою:

- відносна товщина стінки;
- локальні концентрації напружень;
- геометрична стійкість;
- схильність до деформації;
- механічні компроміси.

## 5.5. HISTORICAL PATTERNS

Закономірності розподілу морфологій у часі.

Вони можуть бути пов'язані з:

- появою нових форм;
- зникненням морфологічних конфігурацій;
- змінами частоти;
- конвергенцією;
- локальними еволюційними переходами.

Проте морфологічна подібність сама по собі не доводить спільного походження.

# 8. Метрики морфологічного різноманіття

## 8.1. Shannon Morphological Entropy

H = −Σᵢ pᵢ log₂(pᵢ)

де pᵢ — частка зразків у відповідній категорії.

Для 64 рівноймовірних станів:

H_max = log₂64 = 6 біт.

Але цей максимум справедливий для дискретного розподілу з 64 рівноймовірними категоріями.

## 8.2. Simpson Diversity

D_S = 1 − Σᵢ pᵢ²

Цей показник характеризує різноманіття та концентрацію розподілу.

## 8.3. Morphological Dispersion

Визначимо середню відстань між конфігураціями:

M_D = (1/N²) ΣᵢΣⱼ d(mᵢ,mⱼ)

де d — обрана метрика морфологічної відстані.

## 8.4. Morphological Coverage

Покриття простору:

Coverage = V_occupied / V_reference

де:

- V_occupied — оцінений обсяг зайнятої області;
- V_reference — обсяг визначеного досліджуваного простору.

Для високовимірних просторів ця оцінка залежить від способу семплювання, масштабу та визначення зайнятості.

Тому Coverage повинен супроводжуватися методологічним описом.

# 9. Природне заповнення морфологічного простору

Центральне дослідницьке питання:

Чому природні мушлі займають одні області параметричного простору частіше, ніж інші?

Позначимо:

ρ(W,D,T)

як оцінку щільності природних спостережень.

Вона не є безпосередньою мірою біологічної можливості.

На розподіл впливають:

- реальна частота форм;
- таксономічний склад;
- географічне охоплення;
- геологічне збереження;
- доступність колекцій;
- методи вимірювання;
- похибки ідентифікації;
- упередження вибірки.

Тому необхідно розділяти:

**Observed Density** — щільність наявних спостережень.

**Estimated Biological Occupancy** — оцінка біологічного заповнення простору.

**Potential Feasibility** — оцінка потенційної допустимості конфігурації.

Ці показники не можна підміняти один одним.

# 10. Незайняті області морфологічного простору

Особливий інтерес становлять області, де синтетична модель генерує форми, але природні зразки відсутні.

Визначимо:

Ω_unobserved = Ω_reference − Ω_observed

Але відсутність спостережень не доводить неможливості форми.

Кожна незайнята область отримує один із статусів:

- NOT_SAMPLED;
- INSUFFICIENT_DATA;
- GEOMETRICALLY_INVALID;
- STRUCTURALLY_UNTESTED;
- STRUCTURALLY_INFEASIBLE;
- BIOLOGICALLY_UNTESTED;
- BIOLOGICALLY_IMPLAUSIBLE;
- HISTORICALLY_UNOBSERVED;
- UNKNOWN.

Це принципово важливо.

SUBIT-SHELL не повинен автоматично перетворювати відсутність даних на твердження про природний закон.

# 12. Морфологічна конвергенція

Конвергенція — один із найцікавіших напрямів дослідження.

Можлива ситуація:

Дві різні еволюційні лінії мають схожі морфологічні конфігурації.

SUBIT-SHELL повинен визначати:

1. Геометричну подібність.
2. Параметричну подібність.
3. Подібність динаміки росту, якщо вона доступна.
4. Подібність механічних характеристик.
5. Подібність функціонального контексту.
6. Незалежність або спільність походження, якщо це встановлено зовнішніми філогенетичними даними.

Перші чотири пункти можуть бути предметом морфометричного аналізу.

Останній потребує незалежних доказів.

**Морфологічна конвергенція не може бути встановлена лише через близькість у просторі W, D, T.**

# 13. Raup–Gould Research Framework

Цей модуль створює основу для дослідження класичного питання:

Чи визначається природне різноманіття мушель переважно фізичними та біологічними обмеженнями, чи історичною випадковістю?

SUBIT-SHELL не повинен наперед приймати одну відповідь.

Пропонується п'ять класів гіпотез.

## H-RG1 — Geometric Constraint

Деякі області параметричного простору не можуть породжувати регулярні геометричні поверхні.

## H-RG2 — Mechanical Constraint

Частина геометрично допустимих форм може бути механічно нестійкою за визначених матеріальних і навантажувальних умов.

## H-RG3 — Developmental Constraint

Не всі математично задані траєкторії W(t), D(t), T(t) можуть бути реалізовані конкретною системою росту.

## H-RG4 — Ecological Constraint

Певні морфології можуть мати різні функціональні наслідки в конкретних середовищах.

## H-RG5 — Historical Contingency

Історичні події, походження ліній, випадковість і доступні еволюційні переходи можуть впливати на те, які області морфопростору фактично заповнені.

Ці гіпотези можуть діяти одночасно.

# 17. Вимоги до статистичної достовірності

SUBIT-SHELL не повинен вважати виявлену закономірність реальною лише тому, що алгоритм знайшов кластер або кореляцію.

Для кожного результату потрібно зберігати:

- розмір вибірки;
- правила включення зразків;
- пропущені дані;
- розподіл похибок;
- спосіб нормалізації;
- обраний алгоритм;
- його параметри;
- перевірку стійкості;
- результати незалежної валідації.

Особливо важливо перевіряти, чи не виникає кластеризація через різницю масштабів вимірювання.

Параметри W, D, T можуть мати різні розподіли та різні масштаби варіації.

Тому нормалізація повинна бути явною частиною кожного експерименту.

# 18. Інваріанти

**INV-P01 — Space Distinction**

Математичний, геометричний, структурний, біологічний та спостережуваний простори не ототожнюються.

**INV-P02 — No False Absence**

Відсутність спостережень не доводить неможливості форми.

**INV-P03 — No False Causality**

Кореляція параметрів не є доказом причинності.

**INV-P04 — Continuous Preservation**

Безперервні параметри зберігаються після дискретизації у SUBIT-64.

**INV-P05 — Morphological Independence**

Параметрична подібність не гарантує геометричної ідентичності.

**INV-P06 — Taxonomic Separation**

Морфологічна подібність не доводить таксономічної спорідненості.

**INV-P07 — Historical Uncertainty**

Еволюційні траєкторії повинні зберігати невизначеність датування та походження.

**INV-P08 — Sampling Transparency**

Усі оцінки природного заповнення простору повинні містити інформацію про вибірку.

**INV-P09 — Residual Preservation**

Нетипові морфологічні властивості не видаляються лише через невідповідність базовій моделі.

**INV-P10 — Reproducibility**

Результати повинні бути відтворюваними за однакових даних, алгоритмів і конфігурацій.

# 20. Головний науковий результат

SUBIT-SHELL тепер має три взаємопов'язані рівні дослідження:

**GENERATIVE MORPHOLOGY**

Які форми можна породити?

**INFERENTIAL MORPHOLOGY**

Які параметри та процеси могли породити спостережувану форму?

**DISCOVERY MORPHOLOGY**

Які закономірності існують у просторі можливих і природних форм?

Ці рівні створюють основу для нового підходу до морфології.

Замість того щоб розглядати кожну мушлю як ізольований об'єкт класифікації, SUBIT-SHELL розглядає її як конкретну реалізацію у структурованому просторі можливостей.
