# 2. Основна концепція

Морфологічний стан визначається трьома координатами:

S = (W, D, T)

де:

W — Whorl Expansion;

D — Distance;

T — Translation.

Кожна координата має чотири дискретні рівні.

W ∈ {W₀, W₁, W₂, W₃}

D ∈ {D₀, D₁, D₂, D₃}

T ∈ {T₀, T₁, T₂, T₃}

Загальна кількість станів:

N = 4 × 4 × 4 = 64.

Таким чином:

SUBIT-SHELL-64 = W × D × T.

Це дискретний морфологічний простір.

Він є скінченною координатною системою для навігації у значно більшому безперервному просторі геометричних форм.

# 3. Семантика трьох координат

## 3.1. W — Expansion Dimension

W визначає швидкість масштабування трубки.

Чотири категорії:

- W₀ — мінімальне розширення;
- W₁ — помірне розширення;
- W₂ — виражене розширення;
- W₃ — екстремальне розширення.

Для фізичного моделювання W має бути додатним.

W = 1 означає незмінний характерний розмір трубки за один оберт.

W > 1 означає збільшення.

0 < W < 1 означає зменшення.

Дискретні категорії визначаються через калібровані інтервали.

## 3.2. D — Radial Dimension

D визначає відстань центра трубки від осі закручування відносно її характерного радіуса.

Категорії:

- D₀ — мінімальна радіальна відстань;
- D₁ — мала радіальна відстань;
- D₂ — велика радіальна відстань;
- D₃ — екстремальна радіальна відстань.

Для базової моделі:

D = R / a.

де R — радіус розташування центральної лінії, a — радіус трубки.

Важливо: значення D саме по собі не визначає перекриття витків. Для цього необхідно враховувати також W, T та кількість обертів.

## 3.3. T — Translation Dimension

T визначає осьове зміщення за один оберт.

Категорії:

- T₀ — мінімальне зміщення;
- T₁ — невелике зміщення;
- T₂ — значне зміщення;
- T₃ — екстремальне зміщення.

Для фізичної моделі допускаються:

T = 0;

T > 0;

T < 0.

У базовому атласі рівні визначаються за абсолютною величиною T, а знак зберігається як додаткова орієнтаційна характеристика.

Це дозволяє не змішувати морфологічну категорію зі спрямованістю закручування.

# 4. Система кодування

Кожний морфологічний стан отримує шестибітний код.

Формат:

WWDDTT.

Де:

- перші два біти — W;
- наступні два — D;
- останні два — T.

Числовий ідентифікатор:

ID = 32b₁ + 16b₂ + 8b₃ + 4b₄ + 2b₅ + b₆.

Діапазон:

0–63.

# 6. Геометрична класифікація

Параметричний код не повинен автоматично визначати остаточну назву форми.

Для кожного стану система спочатку обчислює геометричні характеристики.

## 6.1. Expansion Profile

Визначає характер розширення.

Можливі результати:

- CONSTANT;
- CONTRACTING;
- SLOW_EXPANSION;
- MODERATE_EXPANSION;
- RAPID_EXPANSION;
- EXTREME_EXPANSION.

## 6.2. Radial Profile

Визначає просторове розташування витків.

Можливі результати:

- COMPACT;
- OVERLAPPING;
- ADJACENT;
- OPEN;
- HIGHLY_OPEN.

Ці характеристики встановлюються геометричним аналізом, а не тільки значенням D.

## 6.3. Axial Profile

Визначає просторовий розвиток уздовж осі.

Можливі результати:

- PLANAR;
- LOW_AXIAL;
- MODERATE_AXIAL;
- HIGH_AXIAL;
- EXTREME_AXIAL.

## 6.4. Composite Morphology

Результати трьох аналізів об'єднуються:

M = (Expansion, Radial, Axial).

Так формується вторинний морфологічний опис.

# 7. Геометричні індикатори

Кожна згенерована модель повинна мати набір вимірюваних характеристик.

## 7.1. Whorl Expansion Ratio

Відношення характерного розміру сусідніх витків:

Ew = a(n+1) / a(n).

Для сталої моделі Ew = W.

## 7.2. Axial Displacement Ratio

Відношення осьового зміщення до характерного розміру трубки:

Et = Δz / a.

## 7.3. Radial Separation

Відношення відстані між центральними лініями сусідніх витків до локального діаметра трубки.

Цей індикатор використовується для оцінки перекриття.

## 7.4. Whorl Overlap

Показник взаємного перекриття сусідніх витків.

Його необхідно визначати на основі фактичної геометрії поверхонь.

## 7.5. Axial Aspect Ratio

Відношення висоти до максимальної ширини:

A = Height / Width.

## 7.6. Compactness

Показник компактності геометрії.

Може визначатися як відношення об'єму до куба характерного лінійного розміру.

Конкретна формула та нормалізація повинні бути зафіксовані в реалізації.

# 8. Морфологічні сусідства

SUBIT-SHELL розглядає 64 стани як вершини дискретного графа.

G = (V, E).

Де:

V — множина 64 морфологічних станів.

E — множина допустимих переходів.

## 8.1. Базове сусідство

Два стани є сусідніми, якщо відрізняються одним бітом.

Це утворює шестимірний гіперкуб Q6.

Кожна вершина має шість безпосередніх сусідів.

## 8.2. Морфологічні переходи

Перехід може змінювати:

- рівень W;
- рівень D;
- рівень T.

Система повинна зберігати різницю між:

- зміною одного параметра;
- зміною кількох параметрів;
- безперервною трансформацією;
- дискретним переходом між класами.

## 8.3. Геометрична доступність

Не кожен перехід гарантує геометричну коректність.

Тому:

Parameter Transition ≠ Valid Morphological Transition.

Геометричну доступність необхідно перевіряти окремо.

# 10. Морфологічна еквівалентність

Дві структури можуть бути різними за походженням, але геометрично подібними.

Визначимо:

M₁ ≈g M₂.

Це означає геометричну подібність.

Однак:

M₁ ≈g M₂

не означає:

M₁ ≈e M₂.

Де:

≈g — геометрична еквівалентність;

≈e — еволюційна спорідненість.

SUBIT-SHELL повинен зберігати цю відмінність.

# 11. Морфологічна новизна

Визначимо три типи новизни.

## 11.1. PARAMETRIC NOVELTY

Нова комбінація параметрів.

## 11.2. GEOMETRIC NOVELTY

Нова геометрична конфігурація відносно вибраного каталогу.

## 11.3. STRUCTURAL NOVELTY

Нова структура, що відрізняється топологічними або просторовими характеристиками.

Новизна повинна оцінюватися незалежно за кожним критерієм.

# 12. Морфологічна ентропія

Нехай pᵢ — частка спостережень у класі i.

Тоді:

H = -Σ pᵢ log₂(pᵢ).

Для 64 рівноймовірних класів:

H = 6 бітів.

Ентропія використовується для оцінювання розподілу форм у вибраній вибірці.

Вона не є показником складності окремої мушлі.

Додатково можна визначати умовну ентропію:

H(M|C).

Вона дозволяє досліджувати морфологічну різноманітність за певних контекстуальних умов.
