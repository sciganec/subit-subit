# 1. Вступ

SUBIT-SHELL GROWTH DYNAMICS досліджує закономірності виникнення та розвитку морфологічних структур.

Вихідна гіпотеза:

Складна геометрична форма може виникати внаслідок повторення відносно простих локальних правил росту.

Морфологічна складність не обов'язково потребує складного початкового опису.

Вона може виникати через взаємодію:

- локального масштабування;
- просторового переміщення;
- часової послідовності;
- геометричних обмежень;
- контексту;
- історії попередніх станів.

SUBIT-SHELL формалізує цей процес як обчислювальний морфогенез.

# 2. Базова модель морфогенезу

Нехай:

M(t) — морфологічний стан у момент часу t.

Тоді:

M(t) = F(W(t), D(t), T(t), P(t), C(t), H(t)).

Де:

W(t) — функція розширення;

D(t) — функція радіального розташування;

T(t) — функція осьового зміщення;

P(t) — параметри поперечного перерізу;

C(t) — контекст;

H(t) — історія росту.

Основна відмінність від статичної моделі полягає в тому, що параметри більше не обов'язково залишаються постійними.

Морфологія є результатом їхньої часової еволюції.

# 3. Часова структура

SUBIT-SHELL використовує два представлення часу.

## 3.1. Безперервний час

t ∈ [0, τ].

Він описує математично безперервний процес росту.

## 3.2. Дискретний час

t₀, t₁, t₂, ..., tₙ.

Він використовується для комп'ютерного моделювання.

Кожний дискретний крок відповідає певному приросту структури.

## 3.3. Зв'язок між часом і ростом

Необхідно розрізняти:

- біологічний час;
- параметричний час;
- кут росту;
- матеріальний приріст.

Ці величини можуть бути пов'язані, але не є тотожними.

Для початкової моделі використовуємо кутову координату θ як незалежну змінну морфогенезу.

# 4. Динаміка розширення

## 4.1. Базова модель

Для сталої швидкості розширення:

a(θ) = a₀ · W^(θ / 2π).

## 4.2. Змінна швидкість

Якщо W залежить від θ:

a(θ) = a₀ · exp(∫₀^θ ln(W(u)) / 2π du).

Тут W(u) — локальний коефіцієнт розширення за один повний оберт у відповідному положенні.

## 4.3. Локальне розширення

Визначимо швидкість масштабування:

gW(θ) = d(ln a) / dθ.

Тоді:

a(θ) = a₀ · exp(∫₀^θ gW(u)du).

Це загальніша форма, яка дозволяє моделювати довільні закони розширення.

## 4.4. Режими

EXPANSION:

gW(θ) > 0.

CONSTANT:

gW(θ) = 0.

CONTRACTION:

gW(θ) < 0.

NONUNIFORM:

gW(θ) змінюється в процесі росту.

# 5. Динаміка радіального розташування

У класичній моделі:

R(θ) = D · a(θ).

Однак для складнішої морфології:

R(θ) = D(θ) · a(θ).

Тоді радіальна структура залежить від двох незалежних процесів:

1. Зміни розміру трубки.
2. Зміни відстані від осі.

Визначимо:

gD(θ) = dD(θ) / dθ.

Це дозволяє створювати:

- компактні спіралі;
- відкриті спіралі;
- спіралі зі змінною відстанню між витками;
- асиметричні спіральні структури;
- перехідні морфологічні форми.

# 6. Динаміка осьового зміщення

Для сталої моделі:

z(θ) = z₀ + T · a₀ · θ / 2π.

Для змінного T:

z(θ) = z₀ + ∫₀^θ T(u) · a₀ / 2π du.

Однак для біологічно реалістичного моделювання краще використовувати локальний масштаб:

dz/dθ = T(θ) · a(θ) / 2π.

Тоді:

z(θ) = z₀ + ∫₀^θ T(u) · a(u) / 2π du.

Це дозволяє враховувати зміну осьового зміщення відповідно до локального розміру трубки.

# 7. Оператор морфогенезу

Визначимо основний оператор:

Mₙ₊₁ = MORPHOGENESIS(Mₙ, Δθ, Cₙ).

Оператор виконує:

1. Зчитування попереднього стану.
2. Аналіз поточних параметрів.
3. Обчислення локального приросту.
4. Побудову нової ділянки.
5. Перевірку геометричних обмежень.
6. Приєднання нової ділянки.
7. Фіксацію історії.
8. Створення наступного стану.

## 7.1. Інваріант історії

Нехай Gₙ — геометрія на кроці n.

Тоді для моделі без деформації:

Gₙ ⊆ Gₙ₊₁.

Це принцип історичної незмінності сформованої структури.

Він є одним із найважливіших принципів SUBIT-SHELL.

## 7.2. Винятки

У природних системах можливі:

- ерозія;
- пошкодження;
- ремонт;
- мінералізація;
- вторинне нашарування.

Тому реальна модель повинна розрізняти первинний ріст і подальшу модифікацію.

# 8. Growth History

Кожна мушля повинна зберігати власну історію.

Визначимо:

H(t) = {e₀, e₁, ..., eₙ}.

Кожна подія:

GrowthEvent:

```text
GrowthEvent:
    event_id
    timestamp
    theta_start
    theta_end

    parameters_before
    parameters_after

    geometry_added
    context_snapshot

    event_type
    provenance
```

Типи подій:

- INITIALIZATION;
- EXPANSION;
- RADIAL_CHANGE;
- AXIAL_CHANGE;
- CROSS_SECTION_CHANGE;
- GROWTH_PAUSE;
- REPAIR;
- DAMAGE;
- TERMINATION.

Історія не повинна зводитися до останнього набору параметрів.

Дві мушлі з однаковою кінцевою геометрією можуть мати різну історію формування.

# 9. Контекстуальний морфогенез

Це один із центральних напрямів SUBIT-SHELL.

Морфогенез не відбувається у вакуумі.

На ріст можуть впливати:

- доступність ресурсів;
- механічне навантаження;
- середовище;
- температура;
- хімічні умови;
- генетично зумовлені механізми;
- фізіологічний стан організму.

Для обчислювальної моделі:

C(t) = {c₁(t), c₂(t), ..., cₙ(t)}.

Тоді:

W(t) = fW(C(t), H(t)).

D(t) = fD(C(t), H(t)).

T(t) = fT(C(t), H(t)).

Важливо: це загальна архітектура залежностей, а не твердження про встановлені біологічні закони.

Конкретні функції повинні калібруватися на емпіричних даних.

# 10. SUBIT MORPHOGENETIC STATE

Кожний момент росту представляється як окремий стан.

S(t) = (W, D, T, P, G, H, C).

Це дозволяє зберігати:

- параметри;
- геометрію;
- історію;
- контекст;
- властивості попередніх станів.

Важливо не ототожнювати стан і процес.

Стан є описом структури в конкретний момент.

Процес є послідовністю переходів між станами.

# 11. Морфологічні переходи

Визначимо оператор:

TRANSFORM(Sᵢ, Sⱼ).

Він створює перехід між двома морфологічними конфігураціями.

Розрізняємо три типи.

## 11.1. PARAMETRIC TRANSITION

Зміна W, D або T.

## 11.2. GEOMETRIC TRANSITION

Зміна просторової конфігурації.

## 11.3. HISTORICAL TRANSITION

Зміна історії формування.

Ці переходи не повинні автоматично вважатися еквівалентними.

# 12. Неперервність морфогенезу

Нехай G(θ) — геометрія, що залежить від параметра росту.

Для неперервного морфогенезу необхідно, щоб:

lim(Δθ→0) d(G(θ), G(θ+Δθ)) = 0.

Тут d — визначена метрика геометричної відмінності.

Однак геометрична неперервність не гарантує:

- механічної стабільності;
- біологічної реалізованості;
- відсутності самоперетинів.

Ці властивості перевіряються окремо.

# 13. Морфогенетична стабільність

Введемо три категорії стабільності.

STRUCTURAL STABILITY:

Збереження геометричної цілісності.

DYNAMIC STABILITY:

Стійкість процесу росту до малих змін параметрів.

BIOLOGICAL STABILITY:

Здатність реального організму підтримувати відповідний процес формування.

Остання категорія потребує експериментального підтвердження.

# 14. Морфогенетична складність

Морфологічна складність не повинна визначатися лише кількістю параметрів.

Визначимо умовну функцію:

K(M) = F(G, H, P, C).

Де:

G — геометрична складність;

H — історична складність;

P — складність локальних правил;

C — контекстуальна складність.

Для практичного застосування необхідно створити незалежні метрики кожного компонента.

Не слід передчасно зводити їх до одного універсального числа.

# 15. Морфогенез і SUBIT-64

SUBIT-64 описує дискретні параметричні координати.

Морфогенез відбувається в безперервному просторі.

Тому необхідно розрізняти:

SUBIT-64 — дискретний атлас;

SUBIT-SHELL-∞ — безперервний простір генеративних конфігурацій.

Визначимо:

Q: Ω → SUBIT-64.

Функція Q відображає безперервну конфігурацію до відповідного дискретного класу.

Але:

Q(S₁) = Q(S₂)

не означає:

S₁ = S₂.

Два різні набори параметрів можуть належати одному дискретному класу.

Це фундаментальна умова збереження морфологічної різноманітності.

# 16. Морфогенетична ентропія

Для дослідження різноманітності процесів росту введемо:

H_growth = H(M₀, M₁, ..., Mₙ).

Це інформаційна характеристика розподілу морфогенетичних переходів.

Окремо визначимо:

H_parameters;

H_geometry;

H_history;

H_context.

Їх не можна механічно ототожнювати.

Мета — дослідити, наскільки різноманітними є траєкторії формування структур.

# 17. Алгоритм симуляції

```text
function simulate_morphogenesis(
    initial_state,
    growth_steps
):

    state = initial_state

    for step in growth_steps:

        context = evaluate_context(state)

        parameters = update_parameters(
            state,
            context
        )

        segment = generate_growth_segment(
            state,
            parameters,
            step.delta_theta
        )

        validation = validate_segment(
            segment,
            state.geometry
        )

        if validation.is_valid:

            state.geometry = append_segment(
                state.geometry,
                segment
            )

            state.history.append(
                create_growth_event(
                    state,
                    parameters,
                    segment
                )
            )

        else:

            state.history.append(
                create_rejected_growth_event(
                    state,
                    parameters,
                    validation
                )
            )

        state = update_state(state)

    return state
```

Відхилення приросту не повинно знищувати попередній коректний стан.

# 18. Наукові гіпотези

SUBIT-SHELL пропонує дослідити такі гіпотези.

H1.

Велика частина морфологічної різноманітності може виникати через зміну невеликої кількості генеративних параметрів.

H2.

Історія росту може містити інформацію, яку неможливо відновити лише з кінцевої геометрії.

H3.

Нерівномірне заповнення морфологічного простору може бути пов'язане з геометричними та фізичними обмеженнями.

H4.

Динамічні параметри дозволяють отримувати морфології, недоступні в моделі зі сталими параметрами.

H5.

Контекстуальні умови можуть змінювати траєкторії морфогенезу навіть за однакових початкових умов.

Усі п'ять гіпотез потребують окремої математичної або емпіричної перевірки.
