# 2. Математичний простір

Визначимо базовий простір параметрів:

Ω = W × D × T

де:

- W — простір розширення;
- D — простір радіального розташування;
- T — простір осьового зміщення.

Для базової моделі:

W ∈ ℝ⁺

D ∈ ℝ⁺

T ∈ ℝ

Додатне W забезпечує коректне масштабування.

D задає радіальне співвідношення.

T допускає як позитивне, так і негативне осьове зміщення, якщо система використовує орієнтовану вісь.

Нульове T відповідає площинній моделі.

Важливо: параметри повинні бути нормалізовані відносно початкового масштабу.

# 3. Геометрія центральної траєкторії

## 3.1. Кутова координата

Нехай:

θ ∈ [0, 2πN]

де N — кількість повних обертів.

## 3.2. Радіус трубки

Визначимо закон розширення:

a(θ) = a₀ · W^(θ / 2π)

де:

- a₀ — початковий радіус трубки;
- W — коефіцієнт розширення за оберт.

Еквівалентна форма:

a(θ) = a₀ · exp(kθ)

де:

k = ln(W) / 2π.

Ця модель описує експоненційне масштабування поперечного розміру.

## 3.3. Радіальна відстань

Нехай:

R(θ) = D · a(θ).

Тоді R визначає відстань від осі закручування до центра трубки.

Для сталого D відношення R/a залишається незмінним.

## 3.4. Центральна лінія

Координати центральної лінії трубки:

x(θ) = R(θ) · cos(θ)

y(θ) = R(θ) · sin(θ)

z(θ) = z₀ + T · a₀ · θ / 2π

Таким чином:

C(θ) = (x(θ), y(θ), z(θ)).

Це базова тривимірна траєкторія.

# 4. Геометрія поперечного перерізу

Центральної лінії недостатньо для створення повноцінної мушлі.

Необхідно побудувати трубку навколо C(θ).

## 4.1. Локальний базис

Для кожного θ визначаються три ортогональні вектори:

- t(θ) — дотична;
- n(θ) — нормаль;
- b(θ) — бінормаль.

Вони формують локальну систему координат.

Для уникнення нестабільності при чисельному обчисленні базис необхідно транспортувати вздовж траєкторії методом паралельного перенесення.

## 4.2. Круглий переріз

Для круглого перерізу:

P(θ, φ) = C(θ) + a(θ) · [n(θ)cos(φ) + b(θ)sin(φ)]

де:

φ ∈ [0, 2π].

## 4.3. Еліптичний переріз

Визначимо два масштаби:

a₁(θ) = q₁ · a(θ)

a₂(θ) = q₂ · a(θ)

Тоді:

P(θ, φ) = C(θ) + a₁(θ)cos(φ)n(θ) + a₂(θ)sin(φ)b(θ).

q₁ і q₂ визначають форму перерізу.

## 4.4. Змінний переріз

Для більш складних форм:

q₁ = q₁(θ)

q₂ = q₂(θ)

Це дозволяє моделювати нерівномірний ріст.

# 5. Оператор росту

## 5.1. Дискретний час

Нехай мушля формується послідовно:

S₀ → S₁ → S₂ → ... → Sₙ.

Кожний стан містить:

Sₙ = (Gₙ, Pₙ, Hₙ, Cₙ)

де:

- Gₙ — геометрія;
- Pₙ — параметри;
- Hₙ — історія;
- Cₙ — контекст.

## 5.2. Оператор Grow

Визначимо:

Grow(Sₙ, Δθ) = Sₙ₊₁.

Оператор додає нову ділянку поверхні на інтервалі:

[θₙ, θₙ + Δθ].

## 5.3. Збереження попередньої геометрії

У базовій моделі:

Gₙ ⊆ Gₙ₊₁.

Це означає, що сформована частина мушлі не змінюється.

Якщо модель допускає деформацію старих ділянок, це повинно бути окремим режимом.

## 5.4. Адаптивний ріст

Для моделювання складних форм:

W = W(θ)

D = D(θ)

T = T(θ).

Тоді:

a(θ) = a₀ · exp(∫₀^θ ln(W(u)) / 2π du).

Це дозволяє моделювати змінну швидкість розширення.

# 6. Простір SUBIT-SHELL-64

## 6.1. Дискретизація

Кожна координата має чотири рівні:

L = {00, 01, 10, 11}.

Тоді:

SHELL-64 = L × L × L.

Кількість станів:

|SHELL-64| = 4³ = 64.

## 6.2. Кодування

Кожний стан:

s = (w₁w₂, d₁d₂, t₁t₂).

Бінарний код:

b = w₁w₂d₁d₂t₁t₂.

Числовий ідентифікатор:

ID(s) = 32w₁ + 16w₂ + 8d₁ + 4d₂ + 2t₁ + t₂.

## 6.3. Відповідність фізичним параметрам

Функції дискретизації:

QW: ℝ⁺ → L

QD: ℝ⁺ → L

QT: ℝ → L.

Фізичні інтервали кожного рівня повинні бути визначені конфігурацією конкретної моделі.

Заборонено автоматично трактувати двобітові коди як рівномірні числові інтервали.

## 6.4. Морфологічна відстань

Для двох станів sᵢ та sⱼ визначимо:

dH(sᵢ, sⱼ) = кількість бітів, що відрізняються.

Це відстань Геммінга.

Для фізичного аналізу додатково використовується:

dP = √[(ΔW)² + (ΔD)² + (ΔT)²].

Важливо розрізняти дискретну відстань між кодами та фізичну відстань між параметричними конфігураціями.

# 7. Морфологічні оператори

SUBIT-SHELL визначає такі базові оператори:

## 7.1. EXPAND

Змінює W.

EXPAND(S, ΔW).

## 7.2. RADIAL-SHIFT

Змінює D.

RADIAL-SHIFT(S, ΔD).

## 7.3. AXIAL-TRANSLATE

Змінює T.

AXIAL-TRANSLATE(S, ΔT).

## 7.4. CROSS-SECTION-TRANSFORM

Змінює поперечний переріз.

## 7.5. SURFACE-TRANSFORM

Змінює поверхневу структуру.

## 7.6. GROW

Додає нову ділянку структури.

## 7.7. CONTEXTUALIZE

Додає або змінює контекстальні характеристики, не стираючи попередню історію.

# 8. Геометричні обмеження

## 8.1. Числова коректність

Усі координати повинні бути скінченними.

Заборонені:

- NaN;
- Infinity;
- некоректні радіуси;
- невизначені параметри.

## 8.2. Самоперетини

Геометрія повинна перевірятися на самоперетини.

Необхідно розрізняти:

- допустиме з'єднання сусідніх ділянок;
- перекриття поверхонь;
- геометричне проникнення;
- топологічну помилку.

## 8.3. Стабільність

Стабільність не можна визначати лише за відсутністю самоперетинів.

Потрібно окремо перевіряти:

- геометричну стабільність;
- механічну стабільність;
- структурну цілісність;
- біологічну допустимість.

# 10. Морфологічна ентропія

Введемо поняття різноманітності морфологічного простору.

Нехай pᵢ — частка зразків у класі i.

Тоді ентропія:

H = -Σ pᵢ log₂(pᵢ).

Максимальне значення для 64 рівноймовірних класів:

Hmax = 6 бітів.

Ця метрика може використовуватися для аналізу розподілу природних форм.

Важливо: морфологічна ентропія не тотожна складності окремої мушлі.

# 11. Простір новизни

Визначимо:

N = Ω₁ \ Ω₃.

Це множина математично можливих форм, для яких немає відповідників у вибраному каталозі природних зразків.

N не обов'язково є біологічно допустимою множиною.

Для цього потрібне додаткове обмеження:

N₂ = Ω₂ \ Ω₃.

Дослідницьке завдання:

Визначити структуру N₂ та знайти форми, які геометрично відрізняються від відомих природних морфологій, але залишаються потенційно реалізованими.
