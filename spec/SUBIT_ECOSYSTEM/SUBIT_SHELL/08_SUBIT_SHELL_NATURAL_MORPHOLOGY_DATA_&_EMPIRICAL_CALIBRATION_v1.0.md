# 1. Мета

SUBIT-SHELL переходить до наступного фундаментального завдання: встановлення зв'язку між математично можливими мушлями та реально спостережуваними природними формами.

Модель Девіда Раупа дозволяє генерувати широкий спектр спіральних мушель за допомогою трьох основних параметрів:

- W — Whorl Expansion;
- D — Distance;
- T — Translation.

Однак параметрична модель не є повним описом природного різноманіття.

Реальні мушлі мають:

- нерівномірну геометрію;
- змінні поперечні перерізи;
- локальні деформації;
- особливості поверхні;
- відмінності товщини;
- морфологічні структури, не представлені трьома параметрами;
- індивідуальні та онтогенетичні варіації.

Тому необхідно створити емпіричну систему, яка дозволить:

1. Збирати дані про природні мушлі.
2. Стандартизувати морфологічні вимірювання.
3. Визначати параметри W, D, T.
4. Оцінювати точність моделі Раупа.
5. Виявляти відхилення від ідеалізованої спіралі.
6. Порівнювати природні та синтетичні форми.
7. Визначати області простору, недостатньо представлені природними зразками.
8. Формувати перевірювані гіпотези про обмеження морфогенезу.

**Головна мета — перетворити SUBIT-SHELL із генератора можливих форм на дослідницьку систему порівняльної морфології.**

Основне правило:

**OBSERVATION ≠ MODEL ≠ INTERPRETATION**

Необхідно розділяти три рівні.

## 2.1. Observation

Те, що безпосередньо отримано з природного зразка:

- фотографія;
- 3D-скан;
- мікротомографія;
- координати поверхні;
- вимірювання;
- таксономічне визначення;
- відомості про місце та умови збору.

## 2.2. Model

Математичне представлення спостережуваного об'єкта:

- центральна лінія;
- радіус трубки;
- профіль розширення;
- осьове зміщення;
- геометрія витків;
- поперечні перерізи;
- параметри Раупа.

## 2.3. Interpretation

Наукові висновки:

- морфологічна категорія;
- можливі механізми росту;
- геометричні обмеження;
- функціональні гіпотези;
- еволюційні інтерпретації.

Система не повинна автоматично перетворювати модель на біологічне пояснення.

# 6. Оцінювання параметрів Раупа

## 6.1. Основна задача

Для природної мушлі необхідно знайти параметри:

(W,D,T)

які найкраще описують її геометрію.

Визначимо спостережувану геометрію:

G_obs

Ідеалізовану геометрію:

G_model(W,D,T)

Тоді задача оцінювання:

(W*,D*,T*) = argmin L(G_obs,G_model)

де L — функція геометричної похибки.

## 6.2. Оцінювання W

У базовій моделі:

a(θ) = a₀ · W^(θ/2π)

Після логарифмування:

ln(a(θ)/a₀) = θ · ln(W)/2π

Тому W можна оцінювати через лінійну регресію:

y = βθ

де:

y = ln(a(θ)/a₀)

β = ln(W)/2π

Отже:

W = exp(2πβ)

Це дає початкову оцінку W для моделі зі сталим коефіцієнтом розширення.

Якщо радіус виміряний із похибкою або дані нерівномірні, необхідно використовувати відповідну статистичну модель.

## 6.3. Оцінювання D

За моделлю:

R(θ) = D · a(θ)

Тоді:

D(θ) = R(θ)/a(θ)

Для ідеалізованої моделі зі сталим D можна оцінити його за сукупністю вимірювань.

Наприклад:

D* = argmin_D Σᵢ [Rᵢ − D·aᵢ]²

Ця оцінка залежить від коректності визначення осі спіралі та центральної лінії.

## 6.4. Оцінювання T

Для сталої T:

dz/dθ = T·a(θ)/2π

Тому:

T(θ) = 2π · (dz/dθ)/a(θ)

Для дискретних вимірювань:

Tᵢ ≈ 2π · Δzᵢ/(aᵢΔθᵢ)

Якщо T змінюється під час росту, його необхідно оцінювати як функцію кута:

T = T(θ)

## 6.5. Оцінювання спільної моделі

Окремі оцінки W, D і T можуть бути недостатніми.

Тому передбачено спільну оптимізацію:

p* = argminₚ L(G_obs,G_model(p))

де:

p = (W,D,T,a₀,z₀,orientation)

Додаткові параметри орієнтації та масштабу потрібні для узгодження моделі з системою координат зразка.

# 7. Геометрична функція втрат

Один показник не повинен повністю визначати якість відповідності.

Визначимо:

L_total = λ₁L_surface + λ₂L_centerline + λ₃L_crosssection + λ₄L_landmarks

де:

- L_surface — похибка поверхні;
- L_centerline — похибка центральної лінії;
- L_crosssection — похибка поперечних перерізів;
- L_landmarks — похибка анатомічних орієнтирів;
- λᵢ — вагові коефіцієнти.

## 7.1. Surface Distance

Для порівняння поверхонь можна використовувати симетричну відстань Chamfer:

L_chamfer(A,B) =

meanₐ minᵦ ‖a−b‖² +

meanᵦ minₐ ‖b−a‖²

Ця метрика вимірює геометричну близькість, але не гарантує топологічної еквівалентності.

## 7.2. Hausdorff Distance

Для оцінки найбільшого відхилення:

d_H(A,B) = max{

supₐ infᵦ d(a,b),

supᵦ infₐ d(a,b)

}

Цей показник чутливий до локальних викидів і пошкоджених ділянок.

Його необхідно використовувати разом з іншими метриками.

## 7.3. Нормалізована похибка

Для порівняння мушель різного масштабу:

L_normalized = L_total / S_ref

де S_ref — обґрунтований масштабний параметр.

Наприклад, ним може бути характерний діаметр або діагональ обмежувального об'єму.

# 8. Відхилення від моделі Раупа

Природна мушля не зобов'язана точно відповідати ідеалізованій спіралі.

Тому SUBIT-SHELL повинен зберігати залишкову морфологію:

R_morph = G_obs − G_model

Це не обов'язково звичайна різниця координат. Для поверхонь вона може бути представлена через локальні відстані, зміни кривини та відхилення перерізів.

## 8.1. Типи відхилень

- локальна асиметрія;
- зміна швидкості розширення;
- нерівномірне осьове зміщення;
- зміна форми перерізу;
- поверхневі ребра;
- вузли та шипи;
- деформація устя;
- пошкодження;
- ремонтні структури.

## 8.2. Морфологічний залишок

Визначимо:

R(θ) = {r₁(θ),r₂(θ),...,rₙ(θ)}

де компоненти описують різні типи локального відхилення.

Залишок не повинен автоматично трактуватися як шум.

Він може містити біологічно важливу інформацію.

# 9. Онтогенетичний аналіз

## 9.1. Мета

Окремо від аналізу кінцевої форми необхідно досліджувати, як мушля змінювалася під час росту.

Це дозволить встановити:

- чи залишаються W, D, T приблизно сталими;
- чи змінюються вони з віком;
- чи існують локальні фази росту;
- чи з'являються зміни геометрії після певних подій.

## 9.2. Growth Trajectory

Позначимо:

P(t) = (W(t),D(t),T(t))

Це траєкторія параметрів росту.

У базовій моделі:

P(t) = constant

У розширеній:

P(t) = variable

## 9.3. Реконструкція

Дані для реконструкції можуть надходити з:

- послідовних зображень росту;
- мікротомографії;
- ліній росту;
- поперечних перерізів;
- мікроструктурних ознак;
- серійних вимірювань.

Метод реконструкції повинен залежати від джерела даних.

Необхідно зберігати рівень впевненості кожної реконструйованої точки.

# 10. Калібрування SUBIT-64

SUBIT-64 розбиває простір параметрів на 64 дискретні стани.

Природні зразки повинні бути відображені в цьому просторі.

Однак відображення не повинно втрачати безперервні значення.

## 10.1. Подвійне представлення

Для кожного зразка зберігаються:

ContinuousParameters = (W,D,T)

DiscreteState = SUBIT64(W,D,T)

Таким чином, стан SUBIT-64 є класифікацією, а не заміною початкових вимірювань.

## 10.2. Калібрування інтервалів

Для кожної координати визначаються чотири рівні:

W₀,W₁,W₂,W₃

D₀,D₁,D₂,D₃

T₀,T₁,T₂,T₃

Межі інтервалів мають визначатися на основі:

- емпіричного розподілу;
- морфологічних відмінностей;
- фізичного змісту;
- дослідницької мети.

Не можна автоматично ділити діапазон на чотири однакові частини й вважати це природною класифікацією.

## 10.3. Динамічне калібрування

Система повинна підтримувати різні профілі:

- GLOBAL_CALIBRATION;
- TAXONOMIC_CALIBRATION;
- ECOLOGICAL_CALIBRATION;
- TEMPORAL_CALIBRATION;
- EXPERIMENTAL_CALIBRATION.

Це дозволить порівнювати глобальну морфологічну структуру з локальними закономірностями.

# 11. Невизначеність вимірювань

Кожне вимірювання має похибку.

Позначимо:

W = W* ± δW

D = D* ± δD

T = T* ± δT

де δ — невизначеність оцінки.

## 11.1. Джерела невизначеності

- роздільна здатність зображення;
- точність сканера;
- пошкодження зразка;
- неоднозначність осі спіралі;
- похибка сегментації;
- похибка визначення центральної лінії;
- невизначеність початкового витка;
- вибір математичної моделі.

## 11.2. Поширення невизначеності

Для оцінювання параметрів можна використовувати:

- bootstrap;
- Monte Carlo;
- Bayesian estimation;
- confidence intervals;
- sensitivity analysis.

Метод має бути зафіксований у результатах.

## 11.3. Впевненість не дорівнює істинності

Confidence — це оцінка надійності результату за певних припущень.

Вона не є абсолютною гарантією правильності морфологічної інтерпретації.

# 12. Таксономічна та екологічна контекстуалізація

Природні мушлі не можна аналізувати без контексту.

Для кожного зразка необхідно зберігати:

- таксономічну групу;
- середовище існування;
- геологічний вік;
- географічне походження;
- умови збереження;
- доступні відомості про спосіб життя.

## 12.1. Таксономічні рівні

Система повинна підтримувати:

- Kingdom;
- Phylum;
- Class;
- Order;
- Family;
- Genus;
- Species.

Для викопних зразків може бути невідомим або дискусійним навіть видове визначення.

Тому таксономічний статус повинен мати рівень упевненості.

## 12.2. Важливе обмеження

Морфологічна подібність не доводить еволюційної спорідненості.

Два зразки можуть мати подібні W, D і T, але належати до різних еволюційних ліній.

SUBIT-SHELL повинен зберігати морфологічну та філогенетичну інформацію окремо.

```text
    assumptions
    provenance
```

Для кожного зразка необхідно зберігати не лише найкращу оцінку, але й інформацію про якість відповідності.

Дослідити морфологічні відмінності між екологічними групами.

Оцінити вплив похибки вимірювань.

Перевірити результати на незалежній вибірці, яка не використовувалася для калібрування.

# 18. Дослідницькі гіпотези

**H1.** Три параметри Раупа пояснюють значну частину глобальної геометрії певних класів спіральних мушель, але не всієї локальної морфологічної варіативності.

**H2.** Для деяких природних груп змінні W, D і T забезпечують суттєво кращу відповідність, ніж сталі параметри.

**H3.** Морфологічні залишки можуть містити систематичні ознаки, пов'язані з функцією або способом росту.

**H4.** Розподіл природних зразків у SUBIT-64 буде нерівномірним.

**H5.** Деякі морфологічні області можуть бути представлені лише окремими таксономічними або екологічними групами.

**H6.** Однаковий стан SUBIT-64 може відповідати суттєво різним природним формам.

**H7.** Врахування історії росту може покращити пояснення морфологічних відмінностей.

Жодна з цих гіпотез не вважається підтвердженою до виконання відповідних експериментів.

# 19. Зв'язок із питанням Раупа та Гулда

Емпіричний атлас дозволить перейти до центральної проблеми еволюційної морфології.

Чому природні мушлі займають лише певні області простору можливих форм?

SUBIT-SHELL розділяє можливі пояснення.

**A. GEOMETRIC CONSTRAINTS**

Форма не може бути побудована без порушення геометричних умов.

**B. MECHANICAL CONSTRAINTS**

Форма геометрично можлива, але структурно нестійка за визначених умов.

**C. DEVELOPMENTAL CONSTRAINTS**

Форма може бути механічно можливою, але недоступною для конкретного біологічного процесу росту.

**D. ECOLOGICAL CONSTRAINTS**

Форма може існувати, але не забезпечувати достатньої функціональної відповідності певному середовищу.

**E. HISTORICAL CONTINGENCY**

Форма може бути можливою та біологічно допустимою, але не виникла в конкретній еволюційній історії.

Ці пояснення можуть діяти одночасно.

Мета емпіричного дослідження — не оголосити одну причину універсальною, а визначити внесок кожної з них у межах доступних даних.

# 20. Інваріанти

**INV-E01 — Observation Preservation**

Оригінальні спостереження не змінюються під час калібрування.

**INV-E02 — Model Separation**

Похідна модель зберігається окремо від природного зразка.

**INV-E03 — Uncertainty Preservation**

Кожна оцінка параметра має супроводжуватися інформацією про невизначеність.

**INV-E04 — Provenance Preservation**

Кожен результат має простежуване походження.

**INV-E05 — Taxonomy Separation**

Таксономічна класифікація не виводиться лише з геометричної подібності.

**INV-E06 — Continuous Parameter Preservation**

SUBIT-64 не замінює початкові безперервні значення W, D, T.

**INV-E07 — Independent Validation**

Калібрування та незалежна перевірка повинні розділятися.

**INV-E08 — No False Absence**

Відсутність зразків у базі не означає відсутності відповідної форми в природі.

**INV-E09 — Model Residual Preservation**

Відхилення природної форми від моделі зберігаються як дані.

**INV-E10 — Contextual Interpretation**

Морфологічний результат інтерпретується разом із біологічним і геологічним контекстом.

# 22. Наступний модуль

**SUBIT-SHELL MORPHOLOGICAL INFERENCE & PARAMETER IDENTIFICATION v1.0**

Наступний документ має перейти від вимірювання до інтелектуального аналізу.

Його завдання:

1. Визначити параметри W, D, T за неповними даними.
2. Відновлювати центральну лінію з пошкоджених або неповних зразків.
3. Розрізняти сталі та змінні параметри.
4. Визначати морфологічні класи.
5. Оцінювати альтернативні моделі.
6. Порівнювати кілька можливих реконструкцій.
7. Аналізувати невизначеність.
8. Виявляти структурні закономірності.
9. Знаходити природні та синтетичні морфологічні відповідності.
10. Формувати перевірювані висновки без передчасної біологічної інтерпретації.

**Підсумкова ідея:** SUBIT-SHELL повинен навчитися не просто відтворювати мушлю за трьома параметрами, а відновлювати параметричну структуру природної форми, визначати межі точності реконструкції та пояснювати, які властивості мушлі модель Раупа здатна описати, а які потребують розширення.
