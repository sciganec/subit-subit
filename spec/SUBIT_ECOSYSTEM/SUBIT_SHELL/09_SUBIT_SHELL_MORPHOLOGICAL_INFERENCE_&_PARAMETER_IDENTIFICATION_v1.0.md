# 1. Мета

Цей модуль визначає інтелектуальне ядро SUBIT-SHELL, призначене для відновлення параметричної структури природних і синтетичних мушель.

Попередні модулі визначили:

- математичну модель Раупа;
- генеративну архітектуру;
- 64 морфологічні стани;
- динаміку росту;
- геометричну та топологічну валідацію;
- матеріальну механіку;
- структуру емпіричних даних;
- процедури калібрування.

Тепер виникає нове завдання:

**Як за спостережуваною формою відновити процес і параметри, які могли її породити?**

Це обернена задача морфогенезу.

Генеративна задача:

(W,D,T) → G

Обернена задача:

G → (W,D,T)

Але природна форма може містити інформацію, яку неможливо однозначно відновити лише за трьома параметрами.

Тому повна постановка:

G_obs → P* + R + U + A

де:

- P* — оцінені параметри;
- R — залишкова морфологія;
- U — невизначеність;
- A — множина альтернативних пояснень.

# 2. Фундаментальний принцип: Inverse Morphogenesis

Визначимо генеративну функцію:

G = F(P,C,H)

де:

- P — параметри форми;
- C — контекст;
- H — історія росту.

Тоді обернена задача:

(P*,C*,H*) = F⁻¹(G_obs)

Однак F⁻¹ загалом не є однозначною функцією.

Одна й та сама кінцева геометрія може бути отримана різними траєкторіями росту.

Тому SUBIT-SHELL повинен використовувати не лише точкову оцінку, а множину можливих реконструкцій.

Позначимо:

R(G_obs) = {r₁,r₂,...,rₙ}

Кожна реконструкція містить:

- параметри;
- модель росту;
- похибку;
- невизначеність;
- припущення;
- походження.

Система не повинна довільно обирати одну реконструкцію та видавати її за єдину істину.

# 4. Відновлення центральної лінії

Центральна лінія є одним із найважливіших об'єктів оберненої задачі.

Для трубчастої мушлі:

C(θ) = (x(θ),y(θ),z(θ))

## 4.1. Джерела відновлення

Центральна лінія може бути отримана з:

- 3D-скану;
- сегментованої поверхні;
- послідовності поперечних перерізів;
- мікротомографії;
- реконструйованої внутрішньої порожнини.

## 4.2. Основні труднощі

- часткове перекриття витків;
- неповне устя;
- пошкоджені ділянки;
- асиметрія перерізів;
- недостатня роздільна здатність;
- неоднозначність початкової осі.

## 4.3. Алгоритм

```text
FUNCTION RECOVER_CENTERLINE(mesh):

    validate_mesh(mesh)

    regions = SEGMENT_TUBULAR_STRUCTURE(mesh)

    sections = GENERATE_CROSS_SECTIONS(regions)

    centers = []

    FOR section IN sections:

        center = ESTIMATE_SECTION_CENTER(section)

        confidence = ESTIMATE_CENTER_CONFIDENCE(section)

        centers.append(center, confidence)

    centerline = FIT_SMOOTH_CURVE(centers)

    centerline = CHECK_CURVATURE(centerline)

    centerline = VALIDATE_TOPOLOGY(centerline)

    RETURN centerline
```

Це архітектурний алгоритм. Конкретний метод сегментації та визначення центрів повинен залежати від типу зразка.

# 5. Відновлення W — Whorl Expansion

## 5.1. Стала модель

Базова формула:

a(θ) = a₀ · exp(kθ)

k = ln(W)/2π

Отже:

W = exp(2πk)

Задача полягає у визначенні k за виміряним профілем a(θ).

## 5.2. Лінійна регресія

Перетворимо:

ln(a(θ)) = ln(a₀) + kθ

Після цього можна оцінити k методом найменших квадратів.

Однак необхідно враховувати:

- нерівномірність вибірки;
- похибку вимірювання радіуса;
- локальні пошкодження;
- змінну швидкість росту.

## 5.3. Змінна модель

Для змінного W:

gW(θ) = d(ln a)/dθ

Тоді:

a(θ) = a₀ · exp(∫₀^θ gW(u)du)

Локальний еквівалентний параметр:

W_local(θ) = exp(2πgW(θ))

Це дозволяє досліджувати мушлі, які не мають сталого коефіцієнта розширення.

## 5.4. Класи результатів

- CONSTANT_EXPANSION;
- VARIABLE_EXPANSION;
- ACCELERATING_EXPANSION;
- DECELERATING_EXPANSION;
- CONTRACTING_PROFILE;
- INSUFFICIENT_DATA.

# 6. Відновлення D — Distance

Базова модель:

R(θ) = D · a(θ)

Тоді:

D(θ) = R(θ)/a(θ)

## 6.1. Стала модель

D* = argmin_D Σᵢ [Rᵢ − D·aᵢ]²

## 6.2. Змінна модель

D = D(θ)

Для оцінювання можуть використовуватися:

- локальна регресія;
- згладжування;
- сплайни;
- регуляризовані функції;
- Bayesian estimation.

## 6.3. Морфологічна інтерпретація

D визначає відносну радіальну відстань центральної лінії від осі.

Проте оцінка D залежить від правильного визначення осі.

Якщо вісь обрана неправильно, отриманий D може бути математично стабільним, але морфологічно хибним.

Тому вісь повинна бути окремим об'єктом оцінювання.

---

# 7. Відновлення T — Translation

Базова модель:

dz/dθ = T(θ) · a(θ)/2π

Отже:

T(θ) = 2π · (dz/dθ)/a(θ)

## 7.1. Стала модель

Якщо T приблизно постійний, система оцінює його через глобальну апроксимацію.

## 7.2. Змінна модель

Якщо осьовий приріст змінюється:

T = T(θ)

Необхідно визначати:

- напрямок зміщення;
- локальну швидкість;
- зони зміни;
- можливі перерви росту.

## 7.3. Знак T

Знак параметра повинен зберігатися.

Не можна замінювати T на |T| без окремого запису напрямку.

Це важливо для розрізнення геометрично різних конфігурацій.

# 8. Вибір між сталою та змінною моделями

Одна з основних проблем оберненої задачі — надмірна складність моделі.

Якщо для кожного зразка дозволити довільно змінювати W, D і T, модель може надмірно підлаштуватися до шуму.

Тому SUBIT-SHELL повинен мати ієрархію моделей.

## MODEL 0 — CONSTANT RAUP

W = const

D = const

T = const

## MODEL 1 — VARIABLE EXPANSION

W = W(θ)

D = const

T = const

## MODEL 2 — VARIABLE RADIAL

W = const

D = D(θ)

T = const

## MODEL 3 — VARIABLE AXIAL

W = const

D = const

T = T(θ)

## MODEL 4 — COMBINED VARIABLE

W = W(θ)

D = D(θ)

T = T(θ)

## MODEL 5 — EXTENDED MORPHOLOGY

Додаткові параметри:

- q₁(θ);
- q₂(θ);
- asymmetry;
- local ornamentation;
- aperture geometry.

Вибір моделі повинен враховувати не лише похибку апроксимації, а й складність.

## 8.1. Критерії вибору

Можна використовувати:

- AIC;
- BIC;
- cross-validation;
- Bayesian model comparison;
- predictive error.

Наприклад:

AIC = 2k − 2ln(L)

де k — кількість параметрів, L — максимальне значення функції правдоподібності.

Це дозволяє штрафувати надмірно складні моделі.

# 9. Регуляризація

Для змінних параметрів необхідно контролювати надмірні коливання.

Визначимо:

L_total = L_data + λR

де:

- L_data — похибка відповідності даним;
- R — регуляризаційний член;
- λ — коефіцієнт регуляризації.

Для параметра W:

R_W = ∫₀^θmax |d²W/dθ²|² dθ

Аналогічно:

R_D = ∫₀^θmax |d²D/dθ²|² dθ

R_T = ∫₀^θmax |d²T/dθ²|² dθ

Ці штрафи сприяють гладкості параметричних профілів.

Однак надмірне згладжування може приховати реальні морфологічні переходи.

Тому λ має підбиратися та перевірятися, а не задаватися як універсальна константа.

SUBIT-SHELL повинен підтримувати реконструкцію за неповними даними.

## 10.1. Missing Data

Позначимо:

G_obs ⊂ G_true

Тобто спостерігається лише частина початкової геометрії.

## 10.2. Реконструкція

Можливі підходи:

1. Параметрична апроксимація.
2. Симетрійне відновлення, якщо симетрія обґрунтована.
3. Продовження центральної лінії.
4. Інтерполяція поперечних перерізів.

6. Генерація множини альтернативних моделей.

## 10.3. Заборона прихованого відновлення

Відновлена частина не повинна візуально або інформаційно маскуватися під спостережувану.

Кожен елемент реконструкції має мати provenance:

- OBSERVED;
- INTERPOLATED;
- EXTRAPOLATED;
- MODEL_GENERATED;
- UNKNOWN.

# 11. Невизначеність та множинні реконструкції

## 11.1. Параметрична невизначеність

Для кожного параметра:

P = P* ± δP

Але симетричний інтервал не завжди достатній.

Тому система повинна підтримувати повні розподіли:

p(W,D,T | G_obs)

Це умовний розподіл параметрів за спостережуваною геометрією.

## 11.2. Bayesian Inference

Загальна формула:

p(P | G) ∝ p(G | P) · p(P)

де:

- p(P | G) — апостеріорний розподіл;
- p(G | P) — правдоподібність спостережень;
- p(P) — апріорний розподіл.

Апріорні припущення повинні бути явними.

Не можна видавати апріорний розподіл за емпірично встановлений закон природної морфології.

## 11.3. Alternative Reconstruction Set

Результат:

R = {r₁,r₂,...,rₙ}

Для кожної реконструкції:

- параметри;
- похибка;
- невизначеність;
- модель;
- припущення;
- якість даних.

# 12. Residual Morphology

Це один із найважливіших компонентів SUBIT-SHELL.

Якщо модель Раупа не пояснює певну особливість мушлі, її не потрібно відкидати.

Її необхідно дослідити.

Визначимо:

G_obs = G_Raup + R_morph

Це концептуальне розділення, а не буквальна операція додавання поверхонь.

R_morph включає:

- асиметрію;
- локальні потовщення;
- зміну поперечного перерізу;
- нерегулярність витків;
- поверхневий орнамент;
- шипи;
- ребра;
- деформації;
- сліди ремонту.

## 12.1. Residual Classification

Кожне відхилення отримує:

- residual_id;
- spatial_region;
- deviation_type;
- magnitude;
- scale;
- confidence;
- possible_origin;
- provenance.

## 12.2. Розрізнення причин

Відхилення може бути:

- природною морфологічною ознакою;
- результатом росту;
- механічною деформацією;
- пошкодженням;
- артефактом сканування;
- похибкою сегментації.

Система не повинна автоматично обирати одну причину.

# 13. SUBIT-64 Parameter Identification

Після оцінювання безперервних параметрів виконується дискретизація.

ContinuousState:

P = (W,D,T)

DiscreteState:

Q(P) = SUBIT64

## 13.1. Кілька можливих станів

Якщо параметр знаходиться поблизу межі двох інтервалів, система може повертати кілька можливих станів.

Наприклад:

PrimaryState = 101010

AlternativeStates = {101011,101110}

Це умовний приклад представлення невизначеності, а не наперед визначений морфологічний результат.

## 13.2. State Confidence

Для кожного можливого стану:

P(Sᵢ | G_obs)

Це дозволяє створювати не лише категоріальний атлас, але й імовірнісний атлас.

# 14. Псевдокод повного Inference Pipeline

```text
FUNCTION INFER_SHELL_MORPHOLOGY(input):

    data = PREPROCESS(input)

    quality = ASSESS_DATA_QUALITY(data)

    IF quality == Q0:
        RETURN INSUFFICIENT_DATA

    landmarks = DETECT_LANDMARKS(data)

    centerline = RECOVER_CENTERLINE(data)

    sections = ANALYZE_CROSS_SECTIONS(data)

    initial_parameters = ESTIMATE_RAUP_PARAMETERS(
        centerline,
        sections,
        landmarks
    )

    candidate_models = GENERATE_MODEL_HIERARCHY(
        initial_parameters
    )

    FOR model IN candidate_models:

        fit = FIT_MODEL(model, data)

        uncertainty = ESTIMATE_UNCERTAINTY(fit)

        score = EVALUATE_MODEL(
            fit,
            uncertainty,
            model_complexity
        )

        STORE_CANDIDATE(model, fit, score)

    best_models = SELECT_MODELS(candidate_models)

    residuals = ANALYZE_RESIDUAL_MORPHOLOGY(
        data,
        best_models
    )

    reconstructions = GENERATE_ALTERNATIVES(
        best_models,
        residuals
    )

    states = MAP_TO_SUBIT64(
        best_models,
        uncertainty
    )

    validation = VALIDATE_RECONSTRUCTIONS(
        reconstructions
    )

    result = BUILD_INFERENCE_RESULT(
        best_models,
        residuals,
        uncertainty,
        states,
        validation
    )

    SAVE_PROVENANCE(result)

    RETURN result
```

Обернена задача не вважається однозначною без доказу.

**INV-I02 — Model Complexity Control**

Складніша модель повинна виправдовувати додаткові параметри покращенням якості пояснення або прогнозу.

**INV-I03 — Uncertainty Preservation**

Невизначеність не видаляється під час класифікації.

**INV-I04 — Residual Preservation**

Невідповідності моделі зберігаються.

**INV-I05 — Reconstruction Provenance**

Спостережувані та реконструйовані частини розрізняються.

**INV-I06 — Continuous Before Discrete**

Спочатку оцінюються безперервні параметри, потім SUBIT-64.

**INV-I07 — No False Biological Inference**

Геометрична реконструкція не є доказом конкретного біологічного механізму.

**INV-I08 — Independent Validation**

Якість реконструкції перевіряється на даних, які не використовувалися для підгонки, де це можливо.

**INV-I09 — Context Preservation**

Усі параметри та висновки зберігаються разом із контекстом зразка.

**INV-I10 — Reproducibility**

Однакові вхідні дані, алгоритм, версія та конфігурація повинні давати відтворюваний результат у межах визначеної числової точності.

# 18. Теоретичне значення

Цей модуль відкриває новий напрям SUBIT-SHELL: дослідження не лише форми, а й можливості відновлення її породжувальної структури.

Виникає принципова різниця між двома питаннями:

**Генеративне питання:**

Які форми можуть бути породжені заданими параметрами?

**Інференційне питання:**

Які параметри та процеси могли породити спостережувану форму?

Це не тотожні задачі.

У першому випадку ми досліджуємо простір можливостей.

У другому — обмежуємо цей простір спостереженнями.

Саме тут SUBIT-SHELL починає працювати як система структурного висновування.

**SUBIT-SHELL MORPHOLOGICAL PATTERN DISCOVERY & EVOLUTIONARY SPACE ANALYSIS v1.0**

Наступний етап повинен перейти від аналізу окремих мушель до дослідження великих множин морфологічних форм.

5. Аналіз незаповнених областей простору.
6. Порівняння природних і синтетичних форм.
7. Дослідження морфологічної конвергенції.
8. Аналіз еволюційних траєкторій за доступними даними.
9. Розрізнення геометричних, механічних, біологічних та історичних обмежень.
