# 1. Зафіксовані передумови

Нехай:

`b ∈ ℕ`, `b ≥ 2`.

`B_b = {1,…,b}`.

`Pos_b = B_b^{<ω}`.

`Σ_b = B_b^ℕ`.

Нехай `A` — скінченна множина значень листків.

`S_A = {ABSENT, INTERNAL} ∪ {LEAF(a):a∈A}`.

`Code_b(A) = S_A^{Pos_b}`.

Кожне дерево:

`t : Pos_b → S_A`.

## 1.1. Локальні умови

Якщо:

`t(u)=ABSENT`,

то:

`∀i∈B_b, t(ui)=ABSENT`.

Якщо:

`t(u)=LEAF(a)`,

то:

`∀i∈B_b, t(ui)=ABSENT`.

Корінь дерева з `C_Partial` не може бути `ABSENT`.

## 1.2. Нескінченне продовження

Визначимо:

`IB(u,t) ⇔ t(u)=INTERNAL ∧ ∃ξ∈Σ_b, u⊑ξ ∧ ∀k≥|u|, t(ξ|k)=INTERNAL`.

Важлива конвенція:

`ξ|k`

означає префікс адреси `ξ` довжини `k`.

## 1.3. Простір нескінченно продовжуваних дерев

`Tω_P = {t∈C_Partial : ∀u, t(u)=INTERNAL ⇒ IB(u,t)}`.

`Tω_P⁺ = {t∈Tω_P : t(ε)=INTERNAL}`.

З попередніх означень:

`Tω_P⁺ = {t∈Tω_P : ∂t≠∅}`.

Ця рівність є наслідком теореми про непорожність межі, а не незалежною аксіомою.

# 2. Метрики

## 2.1. Метрика кодів

Для `f≠g`:

`r_code(f,g)=min{|u|:f(u)≠g(u)}`.

Для `f=g`:

`r_code(f,g)=∞`.

Тоді:

`d_code(f,g)=2^(−r_code(f,g))`.

На `Tω_P⁺` використовується обмеження цієї метрики.

## 2.2. Метрика адрес

Для `ξ≠η`:

`ℓ(ξ,η)=max{n:ξ|n=η|n}`.

Для `ξ=η`:

`ℓ(ξ,η)=∞`.

Визначимо:

`d_Σ(ξ,η)=2^(−ℓ(ξ,η))`.

Це ультраметрика на `Σ_b`.

## 2.3. Метрика Гаусдорфа

Для непорожніх компактних множин `K,L⊆Σ_b`:

`d_H,Σ(K,L) = max { sup_{ξ∈K} inf_{η∈L} d_Σ(ξ,η), sup_{η∈L} inf_{ξ∈K} d_Σ(ξ,η) }`.

У W41 ця метрика застосовується лише до непорожніх компактних меж.

# 5. Лема W41-L03: спільний префікс меж

Нехай:

`f,g∈Tω_P⁺`.

Нехай перша координатна відмінність виникає на глибині:

`m=r_code(f,g)`.

Тоді:

`m≥1`.

Для кожної адреси `ξ∈∂f` існує адреса `η∈∂g`, така що:

`ξ|m−1=η|m−1`.

І симетрично, для кожної адреси `η∈∂g` існує адреса `ξ∈∂f` із тією самою довжиною спільного префікса.

**Доведення.**

Візьмемо:

`ξ∈∂f`.

Позначимо:

`u=ξ|m−1`.

Оскільки `ξ∈∂f`:

`f(u)=INTERNAL`.

За визначенням першої відмінності:

`∀v, |v|<m ⇒ f(v)=g(v)`.

Звідси:

`g(u)=INTERNAL`.

Оскільки `g∈Tω_P`, кожен INTERNAL-вузол має нескінченне продовження.

Тому:

`IB(u,g)`.

Існує нескінченна адреса `η`, яка продовжує `u` і залишається INTERNAL у кожній координаті після `u`.

Для всіх координат до `u` дерева `f` і `g` збігаються, а шлях `ξ` у `f` має лише INTERNAL-вузли.

Отже, спільний префікс `u` також є INTERNAL у `g`.

Тому:

`η∈∂g`.

За побудовою:

`ξ|m−1=η|m−1`.

Симетричне твердження доводиться аналогічно.

Доведено.

**Статус:** PROVED IN TEXT.

# 6. Основна теорема W41-T007

## Boundary Map Lipschitz Theorem

Для всіх:

`f,g∈Tω_P⁺`

виконується:

`d_H,Σ(∂f,∂g) ≤ 2d_code(f,g)`.

### Доведення

Якщо `f=g`, тоді:

`∂f=∂g`

і:

`d_H,Σ(∂f,∂g)=0`.

Нехай `f≠g`.

Позначимо:

`m=r_code(f,g)`.

З W41-L03 для кожного `ξ∈∂f` існує `η∈∂g`, така що:

`ℓ(ξ,η)≥m−1`.

Отже:

`d_Σ(ξ,η)≤2^(−(m−1))`.

Тобто:

`d_Σ(ξ,η)≤2·2^(−m)`.

За означенням `d_code`:

`d_Σ(ξ,η)≤2d_code(f,g)`.

Тому:

`sup_{ξ∈∂f} inf_{η∈∂g}d_Σ(ξ,η)≤2d_code(f,g)`.

Симетрично:

`sup_{η∈∂g} inf_{ξ∈∂f}d_Σ(ξ,η)≤2d_code(f,g)`.

Отже:

`d_H,Σ(∂f,∂g)≤2d_code(f,g)`.

Доведено.

# 7. Лема W41-L04: константа 2 є оптимальною

Оцінка:

`d_H,Σ(∂f,∂g)≤2d_code(f,g)`

не може бути універсально покращена до константи `C<2`.

## Побудова

Нехай `b≥2`.

Візьмемо дві різні дочірні позиції кореня:

`i≠j`.

Побудуємо дерево `f`, у якому нескінченна гілка проходить через `i`, та дерево `g`, у якому нескінченна гілка проходить через `j`.

На всіх рівнях до першої відмінності коди збігаються.

Нехай перша відмінність виникає на глибині `m≥1`.

Виберемо структуру так, щоб усі нескінченні продовження `f` після спільного префікса проходили через одну дочірню позицію, а всі нескінченні продовження `g` — через іншу.

Тоді для будь-яких:

`ξ∈∂f`, `η∈∂g`

маємо:

`ℓ(ξ,η)=m−1`.

Отже:

`d_H,Σ(∂f,∂g)=2^(−(m−1))`.

Водночас:

`d_code(f,g)=2^(−m)`.

Тому:

`d_H,Σ(∂f,∂g)=2d_code(f,g)`.

Отже, константа 2 є оптимальною для загального класу розглянутих дерев.

**Статус:** PROVED IN TEXT, за умови доступності двох різних дочірніх позицій, що гарантовано `b≥2`.

**Статус:** IMPOSSIBLE CASE.

## E-003: перша відмінність на глибині 1

`d_H,Σ(∂f,∂g)≤1`.

**Статус:** PASS.

## E-004: велика глибина першої відмінності

Для `m→∞`:

`d_code(f,g)=2^(−m)→0`.

Теорема дає:

`d_H,Σ(∂f,∂g)≤2^(−(m−1))→0`.

**Статус:** PASS.

## E-005: скінченні гілки

Скінченна гілка може існувати в `Tω_P⁺`, але кожен INTERNAL-вузол повинен мати хоча б одне нескінченне продовження.

Тому скінченні гілки не перешкоджають визначенню непорожньої межі.

**Статус:** PASS.

## E-006: вузол із кількома нескінченними продовженнями

Доведення не вимагає єдиності нескінченної гілки.

Для кожного префікса достатньо існування хоча б одного продовження.

**Статус:** PASS.

## E-007: порожній алфавіт листків

Якщо `A=∅`, множина `S_A` все одно містить `ABSENT` та `INTERNAL`.

Граничне відображення залишається визначеним.

**Статус:** PASS.

## E-008: `b=1`

Цей випадок виключений передумовою `b≥2`.

Для `b=1` простір адрес має іншу структуру, а доказ оптимальності константи 2 через дві дочірні позиції не працює.

**Статус:** OUT OF SCOPE.

# 9. Наслідок: неперервність граничного відображення

З основної теореми:

`d_H,Σ(∂f,∂g)≤2d_code(f,g)`.

Отже, відображення:

`∂:Tω_P⁺→K(Σ_b)`

є Lipschitz-неперервним із константою 2.

Звідси автоматично випливає рівномірна неперервність.

Для кожного `ε>0` достатньо взяти:

`δ=ε/2`.

Тоді:

`d_code(f,g)<δ`

гарантує:

`d_H,Σ(∂f,∂g)<ε`.

Цей результат сильніший за звичайну неперервність у кожній точці.

# 10. Візуальна метрика

Нехай:

`0<γ≤1`.

Визначимо:

`d_v(ξ,η)=d_Σ(ξ,η)^γ`.

Для цього діапазону `γ` функція `d_v` є метрикою.

Оскільки піднесення до додатного степеня зберігає порядок:

`d_H,v(K,L)=d_H,Σ(K,L)^γ`.

Тому:

`d_H,v(∂f,∂g)≤2^γ d_code(f,g)^γ`.

Отже, граничне відображення є Hölder-неперервним із показником `γ` щодо візуальної метрики.

Для `γ=1` відновлюється початкова Lipschitz-оцінка.

Для `γ>1` не слід автоматично називати `d_v` метрикою: ультраметрична нерівність для `d_Σ` не гарантує звичайної метричності `d_Σ^γ` у такому діапазоні.
