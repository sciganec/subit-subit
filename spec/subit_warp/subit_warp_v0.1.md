## 0. Призначення та межі

SUBIT-WARP досліджує, чи можна на рекурсивному просторі Tree∞ строго означити експоненційну ієрархію масштабів, аналогічну за структурою (але не за змістом) warp-фактору e^(−kπr_c) у моделях Randall–Sundrum, і які властивості такої ієрархії виводяться з уже наявних теорем SUBIT-∞.

### 0.1. Що модуль не заявляє

* фізичної теорії гравітації та формули G_eff = G₀·2⁻ⁿ (у RS warp-фактор змінює масові масштаби; G_eff визначається окремо через 5-вимірну сталу та кривину);
* ізоморфізму Tree∞ (чи Pos) і AdS₅: дерево є лише грубою (δ = 0) моделлю гіперболічної геометрії, без сигнатури, часу й рівнянь поля;
* тотожності параметра α і кривини k; відповідність α ↔ k має статус PHYSICAL-CORRESPONDENCE-OPEN;
* існування брани, зокрема що S₀ відповідає TeV-брані або Leaf(a) — локалізованому гравітону;
* виведення гравітаційної динаміки з SUBIT-теорем.

### 0.2. Походження

Модуль випливає з аналізу есе «SUBIT і гравітація Рендалл–Сандрума». Від нього успадковано три положення: розмежування глибини, відстані й масштабу; параметр α > 0 як окремий параметр; вимога не ототожнювати аналогію з фізикою. Три положення есе виправлено (§2.2, §3, §6), бо вони суперечили структурі Tree∞.

## 2. Об'єкти

### 2.1. Індексне дерево й межа

* Pos = {1,2,3}^{<ω} — індексне дерево (§9.1); |σ| — довжина адреси.
* Σ = {1,2,3}^ℕ — множина кінців Pos («межа»).
* Для ξ ∈ Σ: ξ|n — префікс довжини n; для ξ ≠ η: ξ∧η := довжина найдовшого спільного префікса.
* Входження: Occ := {(f, σ) : f ∈ Tree∞, f(σ) ≠ None}; піддерево f_σ ∈ Tree∞ задано, якщо f(σ) = node.

### 2.2. Глибина належить входженню, а не стану (виправлення 1)

Глибина визначена як h(f, σ) := |σ| на Occ. Функції h : Tree∞ → ℕ₀ не існує як функції стану (див. WT0). Усі конструкції масштабування задаються на Occ або на Pos, а не на Tree∞.

### 2.3. Візуальна метрика на межі

Для α > 0 і ξ ≠ η: d_α(ξ, η) := e^(−α·(ξ∧η)); d_α(ξ, ξ) = 0. Це метрика межі дерева у сенсі Громова з візуальним параметром α. Її зв'язок з d_S: на множині кінців при α = ln 2 маємо d_α = 2^(−(ξ∧η)), тобто ту саму шкалу 2^(−r).

### 2.4. Градуювання правил за глибиною (виправлення 2)

Для h ∈ ℕ₀: ℛ^(h) := {ρ : Tree∞ → Tree∞ : ∀ f ≠ g, r_addr(ρf, ρg) ≥ r_addr(f, g) + h}.

* ℛ^(0) = ℛ₀ (твердження 10.3, T5′);
* ℛ^(h) складається з правил, що множать d_S принаймні на 2^(−h).

Масштабна функція: Ω_α(h) := e^(−αh). Для α = ln 2: Ω(h) = 2^(−h).

## 3. Теореми

### WT0. Глибина не є функцією стану

**Твердження.** Не існує h : Tree∞ → ℕ₀ зі властивістю h(f_i) = h(f) + 1 для всіх f з коренем node і i ∈ {1,2,3}.

**Доведення.** Нехай ρ_a(f) := node(f, leaf a, leaf a). За W1 ρ_a ∈ ℛ₀ є стисканням з коефіцієнтом ½, тому має єдину нерухому точку p_a = node(p_a, leaf a, leaf a). Тоді (p_a)₁ = p_a, і h(p_a) = h((p_a)₁) = h(p_a) + 1: суперечність. ∎

**Статус:** DP-f. FINITE-TESTED: ρ_a(p_a) = p_a на всіх 9841 адресах довжини ≤ 8; піддерево p_a за адресою «1» збігається з p_a на всіх 3280 адресах довжини ≤ 7.

**Наслідок.** Вираз Ω(h) на станах некоректний; коректна форма — Ω_α(|σ|) на Occ. Це виправляє запис «S∞ → Ω(h) → S₀» з есе.

### WT1. Градуювання за Ліпшицем

**Твердження.**
1. ℛ^(h) ∘ ℛ^(k) ⊆ ℛ^(h+k); id ∈ ℛ^(0); ℛ^(h+1) ⊆ ℛ^(h).
2. ρ_a ∈ ℛ^(1), точніше r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1; отже ρ_a^h ∈ ℛ^(h).
3. ∩_h ℛ^(h) = {сталі правила κ_c}.
4. Кожна ℛ^(h) замкнена в ℛ₀, отже компактна (T6).
5. Відображення h ↦ Ω_α(h) є гомоморфізмом моноїдів (ℕ₀, +) → ((0,1], ×).

**Доведення.** (1) r_addr(ρσf, ρσg) ≥ r_addr(σf, σg) + h ≥ r_addr(f, g) + k + h. (2) Прищеплення зсуває першу розбіжність рівно на одну адресу: ρ_a(f)(1σ) = f(σ), а на адресах 2, 3 обидва дерева мають leaf a (§11.6). (3) Якщо ρ у всіх ℛ^(h), то r_addr(ρf, ρg) = ∞, тобто ρf = ρg. (4) Для фіксованих f ≠ g і h умова стосується скінченного набору адрес; поточкова границя правил, що її задовольняють, її також задовольняє. (5) e^(−α(h+k)) = e^(−αh)·e^(−αk). ∎

**Статус:** DP-f. FINITE-TESTED: 285 пар випадкових скінченних дерев; r_addr(ρ_a f, ρ_a g) = r_addr(f, g) + 1 і r_addr(ρ_b ρ_a f, ρ_b ρ_a g) = r_addr(f, g) + 2 у всіх випадках.

**Зміст.** Експоненційне масштабування не потребує окремого оператора: воно вже міститься в ℛ₀ як градуювання за глибиною. Сталі правила з леми E (κ_c) — це «нескінченно зведені» правила (п. 3).

### WT2. Експоненційний потік до нерухомої точки

**Твердження.** Для всіх f ∈ Tree∞: d_S(ρ_a^h f, p_a) = Ω_{ln 2}(h) · d_S(f, p_a).

**Доведення.** p_a = ρ_a^h(p_a), тому d_S(ρ_a^h f, p_a) = d_S(ρ_a^h f, ρ_a^h p_a), і за WT1(2) r_addr зростає рівно на h. ∎

**Статус:** DP-f. Узгоджено з W2 (x_n → (p_a, ρ_a)). Динаміка D∞ з g∞ = π_R має h_top = 0 (D4), тож потік є дискретним «RG-потоком» без ентропії; нетривіальна динаміка потребує некаузальної g∞ (див. SUBIT-CelestialHolography v0.2, CH-T4).

### WT3. Візуальна метрика

**Твердження.** (Σ, d_α): компактна ультраметрика; усі d_α при різних α задають одну топологію, причому d_β = d_α^(β/α).

**Статус:** DP-f. FINITE-TESTED: ультраметрична нерівність на 3000 випадкових трійках (α = ln 2 і α = 0,9) і співвідношення «сніжинки» на 1000 парах.

### WT4. Розмірність межі

**Твердження.** dim_H(Σ, d_α) = ln 3 / α.

**Доведення (схема).** Куль радіуса e^(−αn) рівно 3ⁿ, тож box-розмірність дорівнює n·ln 3/(αn) = ln 3/α. Рівномірна міра дає μ(куля радіуса e^(−αn)) = 3^(−n), тому за принципом розподілу маси dim_H ≥ ln 3/α; верхня оцінка — з покриття. ∎

**Статус:** DP-f (посилання на стандартний принцип розподілу маси). FINITE-TESTED: оцінка log N / log(1/ε) збігається з ln 3/α для n = 1, 4, 8 і α ∈ {ln 2, ln 3/2, ln 3}.

| α | dim_H(Σ, d_α) |
| :-- | :-- |
| ln 2 | ≈ 1,585 |
| ln 3 / 2 | 2 |
| ln 3 | 1 |

**Зауваження.** α не є вільним, якщо вимагати заданої розмірності D межі: α = ln 3 / D. Проте Σ цілком незв'язна (CH-T0), тому рівність розмірності з S² не дає гомеоморфізму.

### WT5. Карта «об'єм → межа»

Для f ∈ Tree∞: ∂f := {ξ ∈ Σ : f(ξ|n) = node для всіх n} — множина нескінченних гілок.

**WT5a (розрив).** ∂ : Tree∞ → 2^Σ розривне. Послідовність ρ_a^n(leaf a) скінченних дерев збігається до p_a за d_S (d_S = 2^(−n)), проте ∂ρ_a^n(leaf a) = ∅, а ∂p_a = {1^∞}. **Статус:** DP-f, FINITE-TESTED для n ≤ 7.

**WT5b (регулярні дерева).** Нехай T^ω — множина f, у яких кожний вузол (f(σ) = node) має нескінченну гілку під собою, і корінь є node. Тоді T^ω замкнена в Tree∞ і ∂ : (T^ω, d_S) → (непорожні компакти Σ, d_H) задовольняє d_H(∂f, ∂g) ≤ 2·d_S(f, g) для α = ln 2.

**Доведення.** *Замкненість.* Нехай f_n → f, f_n ∈ T^ω, і вузол ν у f має скінченне піддерево глибини D. Для n з r_addr(f_n, f) > |ν| + D + 1 піддерево f_n під ν теж скінченне — суперечність. *Оцінка.* Нехай r := r_addr(f, g) ≥ 1 і ξ ∈ ∂f. Дерева збігаються на адресах довжини < r, тож g(ξ|(r−1)) = node; за регулярністю під цим вузлом є η ∈ ∂g з ξ∧η ≥ r−1, отже d_α(ξ, η) ≤ e^(−α(r−1)) = 2·2^(−r). Симетрично. ∎

**Статус:** DP-f.

**Зміст.** Карта «об'єм → межа» неперервна лише на регулярних деревах; вибір області визначення є частиною моделі, а не технічною деталлю.

### WT6. Дві моделі локалізації

Нехай (f, σ), (f, τ) ∈ Occ, j := σ∧τ — глибина спільного предка.

* **K_root** (радіальна): K₀·e^(−α|σ|) — залежить від положення входження.
* **K_anc** (спільного предка): K₀·e^(−αj) — залежить від відношення двох входжень, збігається з d_α.
* **K_Vl** (типу Владімірова): K₀·d_α^(−(D+β)), D = ln 3/α, β > 0.

**Проблема монотонності (з есе).** K_anc спадає зі зростанням j, тобто структурно ближчі входження взаємодіють слабше. K_Vl зростає з j і є стандартним ядром ультраметричної (p-адичної) математичної фізики.

| j (спільний префікс) | d_α при α = ln 2 | K_anc | K_Vl при β = 1 |
| :-- | :-- | :-- | :-- |
| 0 | 1 | 1 | 1 |
| 1 | 0,5 | 0,5 | 6 |
| 2 | 0,25 | 0,25 | 36 |
| 3 | 0,125 | 0,125 | 216 |
| 5 | 0,03125 | 0,03125 | 7776 |

**Статус:** ABSTRACT (вибір ядра є модельним). Обчислено таблицю.

### WT7. Спектр ультраметричного лапласіана

На V_n = {1,2,3}ⁿ (3ⁿ точок) нехай w_j := e^(αj(D+β)) і (Δf)(x) := Σ_{y≠x} (f(y) − f(x))·w_{x∧y}.

**Твердження.** Δ симетричний, сума рядків дорівнює нулю, і спектр складається з:
* λ = 0, кратність 1;
* λ_k = −( Σ_{j<k} 2·3^(n−j−1)·w_j + 3^(n−k)·w_k ), k = 0, …, n−1, кратність 2·3^k.

Зокрема λ₀ = −3ⁿ (бо w₀ = 1) не залежить від α, β. Разом 1 + Σ_k 2·3^k = 3ⁿ.

**Доведення (схема).** Власні функції — вейвлети типу Хаара: для кулі префікса довжини k функція, стала на трьох дочірніх кулях зі значеннями c₁, c₂, c₃, Σcᵢ = 0, нуль поза кулею. Точки поза кулею дають внесок −ψ(x)·w_j·(кількість), де кількість = 2·3^(n−j−1); точки в інших дочірніх кулях дають −3cᵢ·3^(n−k−1)·w_k. ∎

**Статус:** DP-f (схема розрахунку), FINITE-TESTED: n = 3, 4, 5 при α = ln 2, β = 0,5 і n = 4 при α = ln 3/2, β = 1; максимальна розбіжність із замкненою формулою ≤ 6,4·10⁻¹², кратності збігаються.

**Зміст.** Спектр має рівневу структуру з чітко відокремленими рівнями; ефективна динаміка (Етап IV) може мати ієрархію швидкостей затухання за рівнями, але перехід n → ∞ не досліджено.

## 6. Виправлення відносно вихідного есе

1. Глибина — функція входження, а не стану (WT0).
2. Експоненційне масштабування — не окремий оператор, а градуювання ℛ^(h) (WT1); при цьому витягання піддерева (T4) розтягує відстань не більш ніж у 2 рази, тобто грає роль «руху вгору на один рівень», обернену до прищеплення.
3. Ультраметрика й warp не є протилежностями: d_α на межі є візуальною метрикою з параметром α (WT3). Друга модель локалізації з есе («спільний предок») — це відстань на межі; перша — радіальне положення. Обидві вводяться окремо (WT6).

Застереження щодо дерева: Pos — кореневе 3-арне дерево, а дерево Брюа–Тітса для Q₃ є 4-регулярним. Вони споріднені (обидва мають цілком незв'язну ультраметричну межу), але не тотожні; відповідність p-адичній AdS/CFT є орієнтиром, а не твердженням.

## Підсумковий принцип

SUBIT-WARP v0.1 — це градуювання за глибиною всередині ℛ₀ і геометрія межі Σ. Це не фізична теорія гравітації, не AdS₅ і не RS-1. Його цінність у тому, що «експоненційне масштабування» стає виведеним фактом про відомий клас правил ℛ₀.

Не ототожнювати. Формалізувати. Перевіряти. Документувати межі висновків.
