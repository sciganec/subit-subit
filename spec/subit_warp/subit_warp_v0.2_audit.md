# SUBIT-WARP v0.2 — аудит і математичні виправлення

## 1. Загальний висновок

**v0.2 має послідовну математичну архітектуру, але ще не готова до статусу STABLE.**

Найважливіше: базова конструкція дерева в цілому узгоджується із SUBIT-∞, а кілька ключових тверджень — зокрема коефіцієнт стискання прищеплення та нормування граничної метрики — можна підтвердити без додаткових припущень.

Водночас є питання, які необхідно закрити до фіксації специфікації:

1. точна типізація дерева та його граничних гілок;
2. топологія простору, до якого належать межі дерев;
3. строгий доказ замкненості підпростору `Tω`;
4. формальне доведення оцінки для оператора межі;
5. коректність спектральної апроксимації;
6. розмежування теоретичних доказів і результатів обчислювальних тестів.

# 2. W0 — онтологічна основа

У базовій специфікації задано:

* `A = {00, 01, 10, 11}` — алфавіт листків, 4 елементи;
* `B = {1, 2, 3}` — алфавіт адрес, 3 елементи;
* `Pos = B^{<ω}` — множина скінченних адрес;
* `Λ = {None, node} ∪ {leaf(a) : a ∈ A}` — алфавіт міток дерева.

`Tree∞` — множина функцій `f : Pos → Λ`, які задовольняють умови T1–T4. 

### 2.1. Правильна коалгебраїчна типізація

Основне рівняння:

**Tree∞ ≅ A ⊔ Tree∞³**

є узгодженим із базовою конструкцією.

Але необхідно зберегти розрізнення:

* `A` — значення листка;
* `B` — позиційний алфавіт;
* `Tree∞³` — три впорядковані піддерева.

Не можна використовувати одну й ту саму літеру для обох алфавітів без явного пояснення.

### 2.2. Уточнення для v0.2

Рекомендую закріпити:

```text
A := {00, 01, 10, 11}
B := {1, 2, 3}

Pos := B^{<ω}

F_tree(X) := A ⊔ X³

Tree∞ ≅ F_tree(Tree∞)
```

Це не просто технічна деталь. Саме тут встановлюється типова межа між семантичним значенням і структурною позицією.

**Вердикт W0:** підтверджено з редакційним уточненням.

# 3. W1 — причинна фільтрація

У v0.2 використано простір операторів:

`ℛ₀ = {ρ : Tree∞ → Tree∞ | d_S(ρ(f), ρ(g)) ≤ d_S(f,g)}`

та метрику:

`d_ℛ(ρ, σ) = sup_f d_S(ρ(f), σ(f))`.

Це узгоджується з базовим означенням `ℛ₀` та метрики на ньому. 

Для підкласів:

`ℛ^(m) = {ρ ∈ ℛ₀ : Lip(ρ) ≤ 2⁻ᵐ}`

отримуємо:

`ℛ^(m) ∘ ℛ^(k) ⊆ ℛ^(m+k)`.

Доказ безпосередній:

`d_S(ρ(σ(f)), ρ(σ(g)))`

`≤ 2⁻ᵐ · d_S(σ(f), σ(g))`

`≤ 2⁻ᵐ · 2⁻ᵏ · d_S(f,g)`

`= 2⁻⁽ᵐ⁺ᵏ⁾ · d_S(f,g)`.

### 3.1. Перетин фільтрації

Твердження:

`⋂ₘ ℛ^(m) = {constant maps}`

є правильним.

Якщо `ρ ∈ ℛ^(m)` для кожного `m`, тоді:

`d_S(ρ(f), ρ(g)) ≤ 2⁻ᵐ d_S(f,g)`.

При `m → ∞` права частина прямує до нуля. Отже:

`ρ(f) = ρ(g)`.

Тому `ρ` є сталою.

### 3.2. Компактність

Тут потрібно розрізнити два твердження:

* `Tree∞` компактний;
* `ℛ₀` компактний у метриці `d_ℛ`.

Перше доведено в базовій специфікації. Друге потребує застосування відповідного результату компактності сімейства рівномірно неперервних відображень або окремого доказу через Арцела—Асколі.

**Вердикт W1:** математично коректно; компактність слід залишити з явним доказовим посиланням.

# 4. W2 — прищеплення та стискання

Базове означення:

`ρₐ(f) = node(f, leaf(a), leaf(a))`.

У базовій специфікації вже встановлено:

`r_addr(ρₐ(f), ρₐ(g)) = r_addr(f,g) + 1`.

Звідси:

`d_S(ρₐ(f), ρₐ(g)) = ½ d_S(f,g)`.

Отже:

**Lip(ρₐ) = ½.**

Це не припущення WARP, а прямий наслідок базової метрики. 

### 4.1. Нерухома точка

За теоремою Банаха, оскільки `Tree∞` повний, існує єдина нерухома точка `pₐ`:

`ρₐ(pₐ) = pₐ`.

Також:

`ρₐⁿ(f) → pₐ`.

Це дає WARP важливий приклад:

* скінченна структура;
* послідовне прищеплення;
* граничне нескінченне дерево;
* нерухома точка оператора.

### 4.2. Уточнення

Не слід ототожнювати:

`ρₐⁿ(f) → pₐ`

із твердженням, що кожне дерево має таку саму граничну структуру.

`pₐ` — нерухома точка конкретного оператора `ρₐ`, а не універсальна межа простору `Tree∞`.

**Вердикт W2:** підтверджено.

# 5. W3 — геометрія простору межі

Нехай:

`Σ = B^ℕ = {1,2,3}^ℕ`.

Для двох різних нескінченних гілок `ξ, η ∈ Σ` визначимо `ℓ(ξ,η)` як довжину їхнього найдовшого спільного початкового префікса.

Метрика:

`dᵥ(ξ,η) = exp(−αᵥ ℓ(ξ,η))`

і `dᵥ(ξ,ξ)=0`.

### 5.1. Ультраметричність

Для трьох гілок:

`ℓ(ξ,ζ) ≥ min(ℓ(ξ,η), ℓ(η,ζ))`.

Тому:

`dᵥ(ξ,ζ) ≤ max(dᵥ(ξ,η), dᵥ(η,ζ))`.

Отже, `dᵥ` — ультраметрика.

### 5.2. Топологічна еквівалентність

Для будь-яких `αᵥ > 0` метрики породжують ту саму топологію на `Σ`.

Зміна `αᵥ` змінює геометричний масштаб, але не топологічну структуру простору.

Це важливо для WARP: параметр `αᵥ` не повинен інтерпретуватися як зміна самої множини граничних гілок.

**Вердикт W3:** підтверджено.

# 6. W4 — розмірність Гаусдорфа

Для рівномірної ймовірнісної міри:

`μ(C(σ)) = 3⁻ⁿ`, де `|σ|=n`.

Діаметр циліндра:

`diam(C(σ)) = exp(−αᵥ n)`.

Отже, для розмірності `s`:

`μ(C(σ)) = 3⁻ⁿ`

і

`diam(C(σ))ˢ = exp(−αᵥ s n)`.

Рівність масштабів вимагає:

`3⁻ⁿ = exp(−αᵥ s n)`.

Тому:

**dim_H(Σ) = ln 3 / αᵥ.**

Це правильна формула.

### 6.1. Що треба додати

У v0.2 необхідно подати повний доказ, а не тільки рівність масштабів:

1. верхня оцінка через покриття циліндрами;
2. нижня оцінка через масову міру;
3. висновок про точну розмірність.

Також слід уточнити, що це розмірність саме повного простору `Σ`, а не довільної межі окремого дерева `∂f`.

**Вердикт W4:** формула підтверджена; доказ потребує розширення.

# 7. W5 — оператор межі дерева

Це один із найважливіших модулів.

Визначимо:

`∂f = {ξ ∈ Σ : ξ проходить лише через вузли дерева f}`.

Тобто нескінченна гілка належить межі, якщо кожен її скінченний префікс позначений `node`.

Проблема полягає в тому, що для скінченного дерева:

`∂f = ∅`.

Для нескінченного дерева межа може бути непорожньою.

### 7.1. Глобальна неперервність

Якщо використовувати лише простір непорожніх компактних підмножин `K(Σ)`, оператор `∂` не буде навіть всюди визначений.

Тому v0.2 правильно вводить розширений простір:

`K₀(Σ) = K(Σ) ∪ {∅}`.

Але треба явно задати топологію.

Один допустимий вибір:

* на `K(Σ)` — метрика Гаусдорфа;
* `∅` — ізольована точка;
* відстань між `∅` та будь-яким непорожнім компактним набором — фіксована додатна константа.

Це математично допустима конструкція, але не єдина можлива.

### 7.2. Контрприклад неперервності

Нехай:

`fₙ = ρₐⁿ(leaf(a))`.

Тоді:

`fₙ → pₐ`.

Для кожного скінченного `fₙ`:

`∂fₙ = ∅`.

Але:

`∂pₐ ≠ ∅`.

Отже:

`∂fₙ ↛ ∂pₐ`.

Таким чином, оператор межі не є глобально неперервним.

### 7.3. Обмеження на підпростір Tω

Визначимо:

`Tω = {f ∈ Tree∞ : кожен внутрішній вузол має хоча б одну нескінченну гілку нижче нього}`.

Це правильне обмеження для побудови неперервного оператора межі.

Але v0.2 має містити окремий доказ:

**Твердження W5.1.** `Tω` замкнений у `Tree∞`.

Ідея доказу: якщо послідовність дерев із `Tω` збігається до дерева `f`, то для кожного внутрішнього вузла граничного дерева відповідні вузли в наближеннях існують на достатньо великих рівнях. Оскільки розгалуження скінченне, діагональний аргумент дає нескінченну гілку, що проходить через цей вузол.

Цей аргумент треба виписати формально, з урахуванням адресної топології.

### 7.4. Оцінка Ліпшиця

Для `αᵥ = ln 2` очікувана оцінка:

`d_H(∂f, ∂g) ≤ 2 d_S(f,g)`, для `f,g ∈ Tω`.

Множник 2 виникає через можливу розбіжність на першій адресі, де дерева відрізняються: граничні гілки можуть зберігати спільний префікс лише на один рівень коротший.

Це узгоджується з масштабом базової метрики `d_S(f,g)=2⁻ᵐ`. 

**Вердикт W5:** архітектура правильна; замкненість `Tω` та оцінка Ліпшиця мають бути оформлені як окремі повні теореми.

# 8. W6 — ядра взаємодії

Тут необхідно чітко відділити два різні типи взаємодії.

Нехай:

`q = exp(−α𝑤)`.

### 8.1. Ядро спільного предка

`K_anc(ξ,η) = q^ℓ(ξ,η)`, якщо `ξ ≠ η`.

`K_anc(ξ,ξ)=0`.

Для `0<q<1` ядро обмежене й неперервне.

Однак **не можна автоматично називати його додатно визначеним**. Це окрема властивість, яку потрібно довести або не заявляти.

### 8.2. Ядро зростаючої близькості

`K_Vl(ξ,η) = exp(α𝑤 ℓ(ξ,η))`, якщо `ξ ≠ η`.

На діагоналі воно сингулярне.

Його інтегровність визначається умовою:

`α𝑤 < ln 3`.

За рівномірної міри:

`∫ K_Vl(ξ,η) dμ(η) = 2/(3 − exp(α𝑤))`.

Це значення не залежить від вибору `ξ`.

Для обчислювального використання можна ввести обрізане ядро:

`K_Vl⁽ᴺ⁾(ξ,η) = exp(α𝑤 min(ℓ(ξ,η),N))`.

### 8.3. Принцип незгортання

Ці два ядра описують різні моделі:

* `K_anc` — взаємодія слабшає зі збільшенням спільного префікса;
* `K_Vl` — взаємодія посилюється зі збільшенням спільного префікса.

Це не дві нормалізації одного ядра, а дві різні функції взаємодії.

**Вердикт W6:** формули узгоджені; позитивна визначеність `K_anc` залишається окремим відкритим питанням.

# 9. W7 — ієрархічний оператор і спектр

Це найскладніший математичний модуль WARP.

Візьмемо:

`H = L²(Σ, μ)`.

Визначимо інтегральний оператор:

`(T_q f)(ξ) = ∫ q^ℓ(ξ,η) f(η) dμ(η)`.

Позначимо:

`c_q = 2/(3−q)`.

І оператор:

`L_q = T_q − c_q I`.

Оскільки ядро обмежене, а `Σ` має скінченну міру, `T_q` є оператором Гільберта—Шмідта, отже компактним.

`L_q` загалом **не є компактним**, бо містить доданок `−c_q I`.

Це принципове уточнення для спектральної теорії.

### 9.1. Ієрархічні підпростори

Нехай `H_n` — простір функцій, сталих на циліндрах довжини `n`.

Тоді:

`H₀ ⊂ H₁ ⊂ H₂ ⊂ …`

і:

`W_j = H_j ⊖ H_{j−1}`.

Розмірність:

`dim(W_j) = 2 · 3^(j−1)`.

Це правильна кратність для повного трійкового дерева.

### 9.2. Спектральна формула

Для `q ∈ (0,1)` маємо:

`τ_j(q) = −[Σₖ₌₀ʲ⁻¹ 2qᵏ/3^(k+1) + q^(j−1)/3ʲ]`.

Це власне значення оператора `L_q` на рівні `W_j`.

Перевірка граничного значення:

`lim(j→∞) τ_j(q) = −2/(3−q) = −c_q`.

Отже, спектральна множина:

`Spec(L_q) = {0} ∪ {τ_j(q) : j≥1} ∪ {−c_q}`.

Тут:

* `0` відповідає сталим функціям;
* `τ_j(q)` — ієрархічним хвильовим рівням;
* `−c_q` — граничній точці спектра, що виникає через доданок `−c_q I`.

### 9.3. Що необхідно довести

Для повної специфікації потрібно подати:

1. ортогональність `W_j`;
2. повноту розкладу `H`;
3. дію `T_q` на кожному `W_j`;
4. точну формулу власних значень;
5. кратності;
6. спектральний висновок;
7. окрему теорему про скінченні апроксимації.

Особливо важливо: не можна називати `L_q` компактним оператором.

**Вердикт W7:** спектральна конструкція математично перспективна й формули узгоджуються з ієрархічною моделлю; потрібен повний доказ спектральної декомпозиції та окреме обґрунтування скінченних апроксимацій.

# 11. Що я пропоную змінити в архітектурі

Я рекомендую не просто виправляти v0.2, а закріпити чотири незалежні шари:

```text
SUBIT-WARP
│
├── W0  STRUCTURAL
│   └── Tree∞, Pos, A, B, Occ
│
├── W1–W2  DYNAMICAL
│   └── ℛ₀, filtration, grafting, fixed points
│
├── W3–W5  BOUNDARY
│   └── Σ, dᵥ, ∂, Tω, Hausdorff geometry
│
└── W6–W7  SPECTRAL
    └── interaction kernels, L², operators, spectrum
```

Це дасть змогу незалежно перевіряти кожний шар і не змішувати:

* структуру дерева;
* динаміку перетворень;
* геометрію межі;
* спектральні властивості операторів.
