# SUBIT-WARP v0.3 — незалежний аудит W9: Parameter Separation

**Головний висновок:** W9 потребує не просто розмежування параметрів, а формального опису їхніх залежностей. Параметри αᵥ та α𝑤 мають різні первинні функції, але вони не є цілком незалежними, якщо спектральне ядро інтерпретується через метрику на межі дерева.

Під час аудиту виявлено три принципові рівні:

1. **Геометрія:** αᵥ визначає масштаб ультраметрики та розмірність межі.
2. **Взаємодія:** α𝑤 визначає швидкість згасання ядра вздовж спільного префікса.
3. **Відносна геометрична взаємодія:** відношення α𝑤/αᵥ визначає степінь ядра відносно метрики межі.

Це розрізнення варто зробити частиною формальної архітектури.

---

## 1. Первинні параметри

Розглянемо три основні величини.

| Параметр | Визначення    | Первинна функція            |
| -------- | ------------- | --------------------------- |
| αᵥ       | αᵥ > 0        | Геометрія межі              |
| α𝑤      | α𝑤 > 0       | Згасання взаємодії          |
| q        | q = exp(−α𝑤) | Параметр спектрального ядра |

Маємо:

0 < q < 1.

Важливо: q не є третім незалежним параметром. Це альтернативне представлення α𝑤.

Отже, первинний простір параметрів:

**P = {(αᵥ, α𝑤) ∈ ℝ² : αᵥ > 0, α𝑤 > 0}.**

Параметр q є координатним перетворенням:

q = e⁻ᵅʷ.

Зворотне перетворення:

α𝑤 = −ln q.

Таким чином, α𝑤 та q не повинні одночасно трактуватися як незалежні змінні.

### Висновок аудиту

Якщо W9 називає αᵥ, α𝑤 та q трьома незалежними параметрами, це помилка параметризації.

Правильна модель має два незалежні параметри та одну похідну змінну.

## 2. Геометричний параметр αᵥ

Метрика межі визначена як:

dᵥ(ξ,η) = exp(−αᵥℓ(ξ,η)),

де ℓ(ξ,η) — довжина найбільшого спільного початку двох нескінченних послідовностей.

Для будь-якого αᵥ > 0 це ультраметрика.

Вона задовольняє:

dᵥ(ξ,ζ) ≤ max{dᵥ(ξ,η), dᵥ(η,ζ)}.

Зміна αᵥ не змінює множину Σ і не змінює її топологію. Вона змінює геометричний масштаб.

### 2.1. Зв'язок із базовою метрикою

У SUBIT-WARP також використовується:

d_S(ξ,η) = 2⁻ˡ.

Оскільки:

dᵥ(ξ,η) = e⁻ᵅᵥˡ,

отримуємо:

**dᵥ = d_S^(αᵥ/ln 2).**

Позначимо:

γ = αᵥ/ln 2.

Тоді:

dᵥ = d_Sᵞ.

Це важлива залежність.

| Значення αᵥ   | Відношення метрик         |
| ------------- | ------------------------- |
| αᵥ = ln 2     | dᵥ = d_S                  |
| αᵥ > ln 2     | dᵥ < d_S для різних точок |
| 0 < αᵥ < ln 2 | dᵥ > d_S для різних точок |

В усіх випадках метрики задають ту саму топологію, але не однакову геометрію.

### 2.2. Зв'язок із розмірністю Гаусдорфа

Для повного трійкового дерева:

dim_H(Σ,dᵥ) = ln 3 / αᵥ.

Позначимо:

**Dᵥ = ln 3 / αᵥ.**

Це розмірність межі в метриці dᵥ.

Якщо αᵥ = ln 2:

Dᵥ = ln 3 / ln 2 ≈ 1.585.

Якщо αᵥ збільшується, розмірність зменшується.

Якщо αᵥ зменшується, розмірність збільшується.

Тобто αᵥ не є лише технічним параметром метрики: він безпосередньо визначає фрактальну розмірність простору.

## 3. Параметр взаємодії α𝑤

Ядро W6:

K_q(ξ,η) = q^ℓ(ξ,η), якщо ξ ≠ η,

і

K_q(ξ,ξ) = 0.

Оскільки q = e⁻ᵅʷ:

**K_q(ξ,η) = exp(−α𝑤ℓ(ξ,η)).**

Отже, α𝑤 визначає швидкість згасання взаємодії залежно від довжини спільного префікса.

Чим більше α𝑤, тим швидше згасає взаємодія.

Чим менше α𝑤, тим повільніше вона згасає.

Але тепер можна виразити це ядро через геометричну метрику.

Маємо:

dᵥ(ξ,η) = exp(−αᵥℓ).

Тому:

**K_q(ξ,η) = dᵥ(ξ,η)^(α𝑤/αᵥ), ξ ≠ η.**

Введемо новий похідний параметр:

β = α𝑤/αᵥ.

Тоді:

**K_q(ξ,η) = dᵥ(ξ,η)ᵝ.**

Це один із найважливіших результатів аудиту W9.

Він показує, що взаємодія WARP може бути інтерпретована як степенева функція геометричної відстані.

### 3.1. Геометричний зміст β

| β     | Інтерпретація                                       |
| ----- | --------------------------------------------------- |
| β < 1 | Повільніше згасання відносно геометричного масштабу |
| β = 1 | Лінійна залежність ядра від метрики                 |
| β > 1 | Швидше згасання відносно геометричного масштабу     |

β не є незалежним параметром, якщо αᵥ та α𝑤 вже задані.

Однак β є важливим похідним інваріантом для аналізу взаємодії.

## 4. Важлива залежність: інтегровність оберненого ядра

У W6 також розглядається ядро з протилежним знаком експоненти:

K_Vl(ξ,η) = exp(α𝑤ℓ(ξ,η)), ξ ≠ η.

Через метрику dᵥ:

**K_Vl(ξ,η) = dᵥ(ξ,η)⁻ᵝ.**

Це вже сингулярне ядро.

Для незалежно вибраних ξ та η:

P(ℓ(ξ,η) = k) = 2/3ᵏ⁺¹.

Тому:

∫Σ K_Vl(ξ,η)dμ(η)

= Σₖ₌₀∞ (2/3ᵏ⁺¹)eᵅʷᵏ

= (2/3)Σₖ₌₀∞(eᵅʷ/3)ᵏ.

Геометричний ряд збігається тоді й лише тоді, коли:

eᵅʷ < 3.

Отже:

**α𝑤 < ln 3.**

Але оскільки:

Dᵥ = ln 3 / αᵥ,

і

β = α𝑤/αᵥ,

можемо переписати цю умову:

**β < Dᵥ.**

Це важливий результат: інтегровність оберненого ядра еквівалентна тому, що степінь сингулярності менший за розмірність межі.

Отже, умова W6 має дві еквівалентні форми:

α𝑤 < ln 3

⇔

β < dim_H(Σ,dᵥ).

Це не просто алгебраїчна залежність. Вона пов'язує геометрію межі з допустимою силою сингулярної взаємодії.

### Важливе уточнення

Не можна переносити цю умову на звичайне спадне ядро K_q.

Для K_q = exp(−α𝑤ℓ) інтегровність забезпечується для всіх α𝑤 > 0.

Обмеження α𝑤 < ln 3 стосується саме оберненого, зростаючого ядра K_Vl.

## 5. Не плутати дві інтегральні константи

У W6 і W7 з'являються дві різні величини.

Для спадного ядра:

K_q = q^ℓ,

маємо:

**c_q = ∫Σ K_q(ξ,η)dμ(η) = 2/(3 − q).**

Для оберненого ядра:

K_Vl = eᵅʷˡ,

маємо:

**c_Vl = 2/(3 − eᵅʷ),**

за умови α𝑤 < ln 3.

Оскільки eᵅʷ = 1/q:

c_Vl = 2/(3 − 1/q).

Тому:

c_Vl = 2q/(3q − 1),

за умови q > 1/3.

Ці константи не можна ототожнювати:

* c_q характеризує інтеграл спадного ядра;
* c_Vl характеризує інтеграл оберненого ядра.

Вони належать до різних операторних конструкцій.

**Рекомендація:** у W6/W9 використовувати окремі позначення c_−(q) та c_+(q), якщо обидва ядра залишаються в специфікації.

## 6. Межові режими параметрів

Для коректної специфікації необхідно визначити не лише внутрішню область параметрів, а й граничні режими.

### 6.1. α𝑤 → 0⁺, q → 1⁻

Для фіксованих ξ ≠ η:

K_q(ξ,η) → 1.

Але на діагоналі:

K_q(ξ,ξ) = 0.

Отже, граничне ядро має вигляд:

K₁(ξ,η) = 1, якщо ξ ≠ η;

K₁(ξ,ξ) = 0.

Це розривне ядро.

Тому режим q = 1 не належить до первинної області W7, яка використовує неперервне ядро.

Водночас оператор має граничну поведінку:

T_q → J,

де:

Jf = ∫Σ f dμ.

J є проєкцією на простір сталих функцій.

Отже:

L_q = T_q − c_qI → J − I.

Для фіксованого j:

λⱼ(q) → 0,

τⱼ(q) → −1.

Це узгоджується зі спектральною структурою.

### 6.2. α𝑤 → ∞, q → 0⁺

Тут:

K₀(ξ,η) = 1, якщо ℓ(ξ,η) = 0;

K₀(ξ,η) = 0, якщо ℓ(ξ,η) ≥ 1.

Тобто взаємодія зберігається лише між гілками, які відрізняються вже першим символом.

Маємо:

c₀ = 2/3.

Спектральні значення:

λ₁(0) = −1/3,

λⱼ(0) = 0 для j ≥ 2.

Отже, оператор T₀ має скінченний ранг.

Це цікавий граничний режим: нескінченна ієрархія взаємодій редукується до взаємодії між трьома первинними гілками.

Проте q = 0 відповідає границі α𝑤 → ∞, а не скінченному значенню α𝑤.

### 6.3. αᵥ → 0⁺

У цьому режимі:

dᵥ(ξ,η) → 1 для будь-яких різних ξ,η.

Топологія залишається незмінною для кожного αᵥ > 0, але гранична функція при αᵥ = 0 вже не є метрикою.

Розмірність:

Dᵥ = ln 3/αᵥ → ∞.

Тому αᵥ = 0 потрібно виключити з області допустимих параметрів.

### 6.4. αᵥ → ∞

Для різних ξ,η:

dᵥ(ξ,η) → 0.

Водночас:

Dᵥ → 0.

Гранична функція не є метрикою на всій Σ, оскільки відстань між різними точками стає нульовою.

Отже, αᵥ = ∞ не належить до простору параметрів.

## W9. PARAMETER SEPARATION AND GEOMETRIC COUPLING

**Status:** PROVED, conditional on W0–W8 definitions.

### W9.1. Primary parameter space

Define the primary parameter space:

P = {(αᵥ, α𝑤) ∈ ℝ² : αᵥ > 0, α𝑤 > 0}.

The spectral decay parameter is derived:

q = exp(−α𝑤).

Thus:

0 < q < 1.

The parameters αᵥ and α𝑤 are primary independent parameters.

The parameter q is not independent of α𝑤.

### W9.2. Boundary geometry

Define:

dᵥ(ξ,η) = exp(−αᵥℓ(ξ,η)).

For every αᵥ > 0, dᵥ is an ultrametric inducing the standard product topology on Σ.

Relative to:

d_S(ξ,η) = 2⁻ˡ(ξ,η),

we have:

dᵥ = d_S^(αᵥ/ln 2).

The Hausdorff dimension is:

Dᵥ = dim_H(Σ,dᵥ) = ln 3/αᵥ.

### W9.3. Interaction kernel

Define:

K_q(ξ,η) = exp(−α𝑤ℓ(ξ,η)), ξ ≠ η,

and:

K_q(ξ,ξ) = 0.

Equivalently:

K_q(ξ,η) = q^ℓ(ξ,η).

The row integral is:

c_q = ∫Σ K_q(ξ,η)dμ(η) = 2/(3 − q).

The kernel is bounded and integrable for every α𝑤 > 0.

### W9.4. Geometric coupling

Define the derived exponent:

β = α𝑤/αᵥ.

Then, off the diagonal:

**K_q(ξ,η) = dᵥ(ξ,η)^β.**

Thus the interaction kernel is a power of the boundary metric.

The parameter β is derived, not independent.

The parameter space may equivalently be represented by (αᵥ,β), with:

α𝑤 = αᵥβ.

This representation is useful when studying the interaction relative to geometric scale.

### W9.5. Inverse interaction kernel

Define:

K_Vl(ξ,η) = exp(α𝑤ℓ(ξ,η)), ξ ≠ η.

Equivalently:

K_Vl(ξ,η) = dᵥ(ξ,η)⁻ᵝ.

Its row integral is finite if and only if:

α𝑤 < ln 3.

Equivalently:

**β < Dᵥ.**

When this condition holds:

c_Vl = ∫Σ K_Vl(ξ,η)dμ(η)
= 2/(3 − exp(α𝑤)).

This integrability condition applies to the inverse interaction kernel, not to K_q.

### W9.6. Parameter roles

The parameters have distinct primary roles:

* αᵥ controls the boundary metric and Hausdorff dimension.
* α𝑤 controls interaction decay per symbolic level.
* q is the exponential representation of α𝑤.
* β controls interaction decay relative to the geometric metric.

The parameters αᵥ and α𝑤 are independent coordinates, but their ratio β couples geometry and interaction.

### W9.7. Boundary regimes

The primary domain is:

αᵥ > 0, α𝑤 > 0.

The limits:

* α𝑤 → 0⁺ (q → 1⁻);
* α𝑤 → ∞ (q → 0⁺);
* αᵥ → 0⁺;
* αᵥ → ∞;

are boundary regimes, not additional points in the primary parameter space.

At q → 1⁻, the kernel converges pointwise off the diagonal to 1, while remaining zero on the diagonal. The limiting kernel is discontinuous.

At q → 0⁺, the kernel retains interaction only between branches with zero common-prefix length. The corresponding operator has finite rank.

At αᵥ → 0⁺ or αᵥ → ∞, the limiting distance function is not a metric on the full boundary.

### W9.8. Parameter consistency conditions

A valid parameter configuration must satisfy:

1. αᵥ > 0.
2. α𝑤 > 0.
3. q = exp(−α𝑤).
4. β = α𝑤/αᵥ.
5. Dᵥ = ln 3/αᵥ.
6. K_q = dᵥ^β off the diagonal.
7. K_Vl is integrable if and only if β < Dᵥ.

No implementation may treat q and α𝑤 as independent parameters.

No implementation may treat β as independent when αᵥ and α𝑤 are already fixed.

### Окреме зауваження щодо W5

Маємо:

dᵥ = d_Sᵞ,

де γ = αᵥ/ln 2.

Тому тотожне відображення між цими метричними просторами є γ-гельдеровим.

Воно є 1-Lipschitz у напрямку:

(Σ,d_S) → (Σ,dᵥ)

при αᵥ ≥ ln 2.

Якщо αᵥ < ln 2, таке відображення вже не є Lipschitz у цьому напрямку.

Це не спростовує твердження W5 про оператор межі ∂, але означає, що його константу та клас регулярності потрібно доводити окремо для кожного режиму αᵥ. Не можна автоматично переносити результат, доведений при αᵥ = ln 2, на довільне αᵥ > 0.
