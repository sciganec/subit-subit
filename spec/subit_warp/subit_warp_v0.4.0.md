## 2.1. Тип вузлів

Встановлюється тип:

Λ={None,node}∪{leaf(a):a∈A}.

Інтерпретація:

* None — відсутній вузол;
* node — внутрішній вузол;
* leaf(a) — листок зі значенням a.

Це типова модель стану вузла, а не автоматичне твердження про повноту будь-якого дерева.

## 2.2. Деревна структура

Дерево f є функцією:

f:Pos→Λ.

Допустиме дерево повинно задовольняти умови узгодженості префіксів:

1. якщо f(u)=None, то всі строгі продовження u також відсутні;
2. якщо f(u)=leaf(a), то u не має нащадків;
3. якщо f(u)=node, то його нащадки визначаються структурними правилами відповідного класу дерев;
4. корінь ε є присутнім у кожному непорожньому дереві.

Для канонічної повної трійкової моделі:

Tree∞ ≅ A ⊔ Tree∞³.

Це рекурсивне рівняння визначає тип повного дерева, де дерево або є листком, або внутрішнім вузлом із трьома дочірніми деревами.

Для часткових, скінченних та неоднорідних дерев потрібні окремі класи допустимості.

## 2.3. Множина нескінченних адрес

# PART III. TREE METRIC AND GRAFTING

## 3. Метрика на просторі дерев

Для двох дерев f,g визначається адресна відстань:

r_addr(f,g)=min{|u| : f(u)≠g(u)}.

Якщо f=g, покладаємо:

r_addr(f,g)=∞.

Метрика:

d_S(f,g)=2^(−r_addr(f,g)),

де:

2^(−∞)=0.

Це ультраметрична конструкція за умови, що простір дерев та порівнювані адреси визначені узгоджено.

## 3.1. Контрактні перетворення

Нехай:

ℛ₀={ρ:Tree∞→Tree∞ : Lip(ρ)≤1}.

Для m≥0:

ℛ⁽ᵐ⁾={ρ∈ℛ₀ : Lip(ρ)≤2^(−m)}.

Ці класи визначають перетворення з різною силою скорочення.

## 3.2. Канонічне grafting

Для a∈A:

ρₐ(f)=node(f,leaf(a),leaf(a)).

За відповідної ультраметричної структури:

Lip(ρₐ)=1/2.

Оскільки ρₐ є стискальним відображенням повного метричного простору, теорема Банаха забезпечує єдину нерухому точку:

pₐ=ρₐ(pₐ).

**Статус:** PROVED за умов повноти простору та коректності визначення ρₐ.

# PART IV. BOUNDARY GEOMETRY

Для ξ,η∈Σ, ξ≠η, нехай:

Для рівномірного b-арного простору:

Σ_b={1,...,b}^ℕ

з метрикою:

dim_H(Σ_b)=ln b/αᵥ.

Цей результат залежить від однорідності дерева та однакової довжини ребер.

## 4.2. Регулярність граничного відображення

Нехай для базової адресної метрики встановлено:

d_H,S(∂f,∂g)≤2d_S(f,g).

Попереднє твердження про універсальну 2-Lipschitz регулярність не застосовується без умови на αᵥ.

# PART VI. CANONICAL SPECTRAL THEORY

## 6. Ієрархічний розклад

Нехай Hₙ — простір функцій, сталих на циліндрах довжини n.

Тоді:

H₀⊂H₁⊂H₂⊂...

Позначимо:

W₀=H₀,

Wⱼ=Hⱼ⊖Hⱼ₋₁, j≥1.

Тоді:

H=⊕ⱼ≥0Wⱼ.

Розмірності:

dim W₀=1,

dim Wⱼ=(b−1)b^(j−1).

## 6.1. Власні значення

Для константного підпростору:

λ₀(q)=c_q=(b−1)/(b−q).

Для j≥1:

λⱼ(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)].

Для T_q:

T_q|Wⱼ=λⱼ(q)I.

## 6.2. Спектр

Spec(T_q)={c_q}∪{λⱼ(q):j≥1}∪{0}.

Нуль є точкою накопичення власних значень λⱼ.

Оператор T_q є компактним.

## 6.3. Центрований оператор

Визначаємо:

L_q=T_q−c_qI.

Тоді:

τ₀=0,

τⱼ(q)=λⱼ(q)−c_q.

Спектр:

Spec(L_q)={0}∪{τⱼ(q):j≥1}∪{−c_q}.

Точка −c_q є точкою накопичення та належить істотному спектру.

Вона не є власним значенням.

Ker(L_q)=W₀.

## 6.4. Знак оператора

Для 0<q<1:

λⱼ(q)<0, j≥1.

Отже:

T_q не є додатно напіввизначеним.

Однак:

L_q є від'ємно напіввизначеним.

Це принципове розрізнення між оператором взаємодії та його центрованою версією.

# PART XII. PERTURBATION THEORY

## 12. Скінченновимірна оцінка

Для самоспряжених матриць A,E:

|λₖ(A+E)−λₖ(A)|≤‖E‖.

Це оцінка Вейля.

Для операторів:

A'=A+E,

B'=B+F

маємо:

[A',B']−[A,B]
=[E,B]+[A,F]+[E,F].

Тому:

‖[A',B']−[A,B]‖
≤2‖E‖‖B‖
+2‖A‖‖F‖
+2‖E‖‖F‖.

## 12.1. Спектральні підпростори

Близькість операторів сама по собі не гарантує близькості окремих власних векторів.

Для ізольованих спектральних підмножин використовуються оцінки спектральних проєкторів, зокрема теорема Девіса—Кахана.

Для кратних власних значень порівнюються підпростори, а не довільно вибрані базиси.

## 12.2. Різні простори

Операторні норми:

‖A−B‖

не визначені, якщо A і B діють на різних просторах без спільного представлення.

Для порівняння потрібне явне вкладення, унітарна ідентифікація або інша математично визначена схема перенесення.

Відстань між листками:

d_T(ξᵢ,ξⱼ)
=h(ξᵢ)+h(ξⱼ)−2A_LCA[i,j].

## 14.2. Структурний fingerprint

Визначаємо:

SF(X)=(L,h,A_LCA,P_arity).

Де P_arity — профіль арності внутрішніх вузлів.

Профіль арності є корисним контрольним інваріантом, але не потрібний для самої реконструкції, якщо повні дані листків, глибин і LCA вже задані.

## 14.3. Теорема структурної реконструкції

Для скінченних кореневих дерев заданого класу, якщо бієкція листків зберігає глибини та глибини найглибших спільних предків, то вона індукує ізоморфізм кореневих дерев, що зберігає відповідні рівні.

### Схема доведення

Для кожного рівня k визначаємо активні листки:

L_k={ξ∈L:h(ξ)≥k}.

На L_k:

ξ~ₖη ⇔ ℓ(ξ,η)≥k.

Класи еквівалентності відповідають вузлам рівня k.

Вкладення класів між сусідніми рівнями визначає відношення батьківства.

Листки приєднуються на власних глибинах.

Отже, повна система класів та вкладень відновлює дерево.

**Статус:** PROVED за умов скінченності, кореневості, одиничних ребер і заданого класу дерев.

## 14.4. Критерії валідності

SF-C1: матриця LCA симетрична.

SF-C2: діагональні елементи дорівнюють глибинам листків.

SF-C3: 0≤ℓ(ξ,η)≤min(h(ξ),h(η)).

SF-C4: відношення ~ₖ є еквівалентністю на L_k.

SF-C5: класи рівня k+1 вкладені рівно в один клас рівня k.

SF-C6: кожен листок приєднаний до відповідного класу на власній глибині.

SF-C7: кожен термінальний клас має листок, що завершується на відповідному рівні.

SF-C8: реконструйована структура має єдиний корінь і є деревом.

Важливо: не кожен клас на проміжному рівні повинен містити листок, який завершується саме на цьому рівні. Він може містити лише нащадків глибшого рівня.

## 14.5. Граничні випадки

Обов'язково підтримуються:

* unary nodes;
* листки різної глибини;
* корінь-листок;
* дерева з різною кількістю листків;
* дерева з однаковими глибинами, але різною топологією.

# PART XV. STRUCTURAL DISTANCE

## 15. Відстань fingerprints

Для двох fingerprints із фіксованою множиною міток листків:

D_depth=maxξ|h_X(ξ)−h_Y(ξ)|.

D_LCA=maxξ,η|A_X(ξ,η)−A_Y(ξ,η)|.

За строго додатних ваг:

w_h>0, w_LCA>0,

w_h+w_LCA=1,

визначаємо:

D_SF=w_hD_depth+w_LCAD_LCA.

Це метрика на просторі валідних fingerprints із фіксованими мітками листків.

Для немаркованих листків:

D_unlab(X,Y)=minπ D_SF(X,πY).

Це метрика на класах еквівалентності за перестановками міток.

Структурна відстань не ототожнюється зі спектральною відстанню.
