# 1. Мета аудиту

W33.3 завершує аналітичну перевірку скінченновимірних апроксимацій спадного ієрархічного оператора та його граничних режимів.

4. розмежувати режими q = 0, 0 < q < 1 та q = 1;
5. встановити точну поведінку сімейства T_q при q → 1⁻.

W33.3 не замінює чисельний протокол W25 і не є Lean-формалізацією. Його призначення — завершити аналітичне обґрунтування результатів T-013–T-018 та доповнити їх точними граничними оцінками.

# 2. Канонічна модель

Нехай:

B_b = {1, 2, …, b}, b ≥ 2,

Σ_b = B_b^ℕ,

μ_b — рівномірна бернуллівська міра,

H = L²(Σ_b, μ_b).

Для двох різних адрес ξ, η ∈ Σ_b позначимо через ℓ(ξ,η) довжину найбільшого спільного префікса.

Спадне ядро:

K_q(ξ,η) = q^ℓ(ξ,η), ξ ≠ η,

K_q(ξ,ξ) = 0.

Конвенція степеня:

q⁰ = 1 для всіх q ∈ [0,1].

Для k ≥ 1:

0^k = 0.

Оператор:

(T_q f)(ξ) = ∫ K_q(ξ,η)f(η)dμ_b(η).

Нормувальна константа:

c_q = (b−1)/(b−q).

Ієрархічні власні значення:

λ_j(q) = −(1−q)q^(j−1) / [b^(j−1)(b−q)], j ≥ 1.

Кратності:

m_j = (b−1)b^(j−1).

Ортогональний розклад:

H = W₀ ⊕ W₁ ⊕ W₂ ⊕ …,

де:

dim W₀ = 1,

dim W_j = (b−1)b^(j−1).

На цих підпросторах:

T_q|W₀ = c_q I,

T_q|W_j = λ_j(q)I.

Ця спільна ортогональна декомпозиція є основою всіх наступних результатів.

# 3. Скінченновимірна циліндрична апроксимація

## 3.1. Простір H_n

Нехай H_n — простір функцій, сталих на кожному циліндрі довжини n.

Тоді:

dim H_n = bⁿ.

Маємо вкладення:

H₀ ⊂ H₁ ⊂ H₂ ⊂ …,

а об'єднання цих просторів щільне в H:

closure(∪ₙ H_n) = H.

Позначимо через P_n ортогональну проєкцію H → H_n.

Тоді:

P_n → I сильно.

Скінченна апроксимація визначається:

T_q^(n) = P_n T_q P_n|H_n.

Для порівняння операторів на всьому H використовуємо нульове продовження:

T̃_q^(n) = P_n T_q P_n.

## 3.2. Ортонормована циліндрична база

Для кожної адреси σ ∈ B_bⁿ визначимо:

e_σ = b^(n/2) · 1_[σ],

де [σ] — циліндр адрес, що починаються з σ.

Оскільки:

μ_b([σ]) = b^−n,

то:

||e_σ||² = bⁿ · b^−n = 1.

Для різних σ, τ циліндри не перетинаються, отже:

⟨e_σ,e_τ⟩ = 0.

Таким чином, {e_σ : σ ∈ B_bⁿ} є ортонормованою базою H_n.

## 3.3. Виведення матричних елементів

Матричні елементи:

M_n(σ,τ) = ⟨T_q e_τ,e_σ⟩.

### Випадок A: σ ≠ τ

Нехай:

ℓ(σ,τ) = k < n.

Для всіх ξ ∈ [σ] і η ∈ [τ]:

ℓ(ξ,η) = k.

Отже, ядро на [σ] × [τ] стало:

K_q(ξ,η) = q^k.

Тоді:

M_n(σ,τ)
= bⁿ ∫_[σ] ∫_[τ] q^k dμ_b(η)dμ_b(ξ)

= bⁿ · b^−n · b^−n · q^k.

Отже:

**M_n(σ,τ) = b^−n q^ℓ(σ,τ), σ ≠ τ.**

### Випадок B: σ = τ

Тут ξ та η належать одному циліндру довжини n.

Тому:

ℓ(ξ,η) = n + L,

де L — довжина спільного префікса двох незалежних хвостів після рівня n.

За рівномірної міри:

P(L = k) = (b−1)/b^(k+1).

Тому:

E[q^L]
= Σₖ₌₀∞ (b−1)q^k/b^(k+1)
= c_q.

Отже:

E[q^(n+L)] = qⁿc_q.

Підстановка в матричний елемент дає:

**M_n(σ,σ) = b^−n qⁿc_q.**

Таким чином, точна матриця має вигляд:

M_n(σ,τ) =

- b^−n q^ℓ(σ,τ), якщо σ ≠ τ;
- b^−n qⁿc_q, якщо σ = τ.

Важливо: ненульова діагональ матриці не суперечить умові K_q(ξ,ξ)=0. Діагональний матричний елемент є інтегралом на всьому добутку [σ] × [σ], а не значенням ядра в одній точці.

**Результат:** T-013 підтверджено незалежним виведенням із нормованої циліндричної бази.

# 4. Точний спектр скінченної матриці

Оскільки:

H_n = W₀ ⊕ W₁ ⊕ … ⊕ W_n,

а T_q діє скалярно на кожному W_j, скінченна апроксимація має точний спектр:

Spec(T_q^(n)) = {c_q, λ₁(q), …, λ_n(q).

Кратності:

- c_q — 1;
- λ_j(q) — (b−1)b^(j−1), j = 1,…,n.

Сума кратностей:

1 + Σⱼ₌₁ⁿ (b−1)b^(j−1) = bⁿ.

Отже, спектр повністю заповнює розмірність H_n.

Це не наближений спектр і не чисельна оцінка. Він випливає з того, що H_n є точною сумою перших n+1 ієрархічних підпросторів.

## 4.1. Перевірка сліду через спектр

За визначенням:

Tr(T_q^(n)) = c_q + Σⱼ₌₁ⁿ m_j λ_j(q).

Підставляємо:

Tr(T_q^(n))
= c_q − (b−1)(1−q)/(b−q) · Σⱼ₌₁ⁿ q^(j−1).

Для q ≠ 1:

Σⱼ₌₁ⁿ q^(j−1) = (1−qⁿ)/(1−q).

Тому:

Tr(T_q^(n))
= c_q − c_q(1−qⁿ).

Отже:

**Tr(T_q^(n)) = qⁿc_q.**

Для q = 1 результат безпосередньо дорівнює 1.

## 4.2. Перевірка сліду через діагональ

Кожен із bⁿ діагональних елементів дорівнює:

b^−n qⁿc_q.

Тому:

Tr(T_q^(n))
= bⁿ · b^−n qⁿc_q.

Отже:

**Tr(T_q^(n)) = qⁿc_q.**

Два незалежні виведення збігаються:

- через власні значення;
- через діагональні елементи матриці.

Це закриває аналітичну перевірку T-015.

# 5. Точна похибка в операторній нормі

Розглянемо нульове продовження:

T̃_q^(n) = P_nT_qP_n.

На W₀,…,W_n воно збігається з T_q.

На ортогональному доповненні:

H_n⊥ = W_(n+1) ⊕ W_(n+2) ⊕ …,

скінченний оператор дорівнює нулю.

Отже:

T_q − T̃_q^(n)

має власні значення λ_j(q) для j > n.

Тому:

||T_q − T̃_q^(n)||
= sup_{j>n}|λ_j(q)|.

Оскільки для 0 ≤ q < 1:

|λ_(j+1)(q)| = q/b · |λ_j(q)|,

послідовність модулів власних значень спадна.

Отже:

||T_q − T̃_q^(n)|| = |λ_(n+1)(q)|.

Після підстановки:

**||T_q − T̃_q^(n)|| = (1−q)qⁿ / [bⁿ(b−q)].**

Це точна похибка скінченної апроксимації.

Не просто:

||T_q − T̃_q^(n)|| → 0,

а конкретна формула швидкості збіжності.

Для кожного фіксованого 0 ≤ q < 1:

limₙ→∞ ||T_q − T̃_q^(n)|| = 0.

Для q = 1:

T₁ = P_const.

Оскільки сталі функції належать кожному H_n:

P_nT₁P_n = T₁.

Тому:

**||T₁ − T̃₁^(n)|| = 0.**

Граничний оператор відтворюється скінченною апроксимацією точно на кожному рівні.

---

# 6. Нова точна формула: похибка у слідовій нормі

W25 встановлює:

||T_q||₁ = 2c_q, 0 ≤ q < 1.

Однак точну слідову похибку скінченної апроксимації необхідно виписати окремо.

Оскільки різниця:

T_q − T̃_q^(n)

має власні значення λ_j(q) для всіх j > n, її слідова норма дорівнює:

||T_q − T̃_q^(n)||₁
= Σⱼ₌ₙ₊₁∞ m_j |λ_j(q)|.

Підставляємо:

m_j |λ_j(q)|
= (b−1)(1−q)q^(j−1)/(b−q).

Отже:

||T_q − T̃_q^(n)||₁
= (b−1)(1−q)/(b−q)
  · Σⱼ₌ₙ₊₁∞ q^(j−1).

Для 0 ≤ q < 1:

Σⱼ₌ₙ₊₁∞ q^(j−1) = qⁿ/(1−q).

Тому:

**||T_q − T̃_q^(n)||₁ = c_q qⁿ.**

Це точна формула слідової похибки.

Таким чином, маємо дві незалежні оцінки апроксимації:

### Операторна норма

||T_q − T̃_q^(n)||
= (1−q)qⁿ/[bⁿ(b−q)].

### Слідова норма

||T_q − T̃_q^(n)||₁
= c_q qⁿ.

Обидві прямують до нуля при фіксованому q < 1.

Для q = 0 і n ≥ 1 обидві похибки дорівнюють нулю.

Для q = 1:

T̃₁^(n) = T₁,

тому обидві похибки також дорівнюють нулю.

**Новий результат W33.3-A:** скінченні апроксимації T_q збігаються до T_q не лише в операторній нормі, а й у слідовій нормі для кожного q ∈ [0,1].

# 7. Слід скінченної апроксимації та слід нескінченного оператора

Для 0 ≤ q < 1:

Tr(T_q) = 0.

Водночас:

Tr(T̃_q^(n)) = qⁿc_q.

Отже:

limₙ→∞ Tr(T̃_q^(n)) = 0 = Tr(T_q).

Це узгоджується зі збіжністю у слідовій нормі.

Для q = 1:

T₁ = P_const,

Tr(T₁) = 1,

і:

Tr(T̃₁^(n)) = 1.

Тому:

limₙ→∞ Tr(T̃₁^(n)) = Tr(T₁) = 1.

Необхідно зберігати три різні поняття:

1. слід нескінченного оператора;
2. слід скінченної матриці;
3. слід різниці між оператором та його апроксимацією.

Для 0 ≤ q < 1:

Tr(T_q) = 0,

Tr(T̃_q^(n)) = qⁿc_q,

Tr(T_q − T̃_q^(n)) = −qⁿc_q.

Це не суперечність, а точний наслідок спектральної декомпозиції.

# 8. Endpoint audit: q = 0

За конвенцією:

q⁰ = 1.

При q = 0:

c₀ = (b−1)/b.

Власні значення:

λ₁(0) = −1/b,

λ_j(0) = 0, j ≥ 2.

Отже:

T₀ має ранг b.

Ненульові власні значення:

- (b−1)/b — кратність 1;
- −1/b — кратність b−1.

Нуль має нескінченну кратність.

## 8.1. Скінченна матриця при q = 0

Для n ≥ 1:

M_n(σ,τ) =

- b^−n, якщо перші символи σ та τ різні;
- 0, якщо перші символи збігаються.

У цьому режимі матриця залежить лише від першого символу адреси.

Її ненульовий спектр:

(b−1)/b, кратність 1;

−1/b, кратність b−1.

Усі інші власні значення нульові.

Тому для кожного n ≥ 1:

T̃₀^(n) = T₀.

Отже:

||T₀ − T̃₀^(n)|| = 0,

||T₀ − T̃₀^(n)||₁ = 0.

Важливо не поширювати це твердження на n = 0 без окремого розгляду: H₀ містить лише сталі функції і не відтворює весь ранг T₀.

**Висновок:** q = 0 є скінченновимірним спектральним режимом, точно представленим уже на першому рівні.

# 9. Endpoint audit: q = 1

Для q = 1:

K₁(ξ,η) = 1, ξ ≠ η,

K₁(ξ,ξ) = 0.

Діагональ має нульову міру щодо μ_b × μ_b.

Тому як інтегральний оператор:

T₁f = ∫ f dμ_b.

Отже:

T₁ = P_const.

Спектр:

Spec(T₁) = {1,0}.

Нуль має нескінченну кратність.

Норми:

||T₁|| = 1,

||T₁||₁ = 1,

Tr(T₁) = 1.

Для кожного n ≥ 0:

P_nT₁P_n = T₁.

Тому скінченна апроксимація точно відтворює граничний оператор.

Цей результат відокремлює q = 1 від усіх q < 1: при q = 1 оператор має ранг 1, тоді як при 0 < q < 1 він має нескінченний ранг.

---

# 10. Граничний перехід q → 1⁻

Розглянемо сімейство T_q при q < 1.

На сталому підпросторі:

c_q = (b−1)/(b−q).

При q → 1⁻:

c_q → 1.

На ієрархічних підпросторах:

λ_j(q) → 0.

Отже, спектрально:

T_q → P_const.

Але необхідно розрізняти операторну та слідову норми.

## 10.1. Точна операторна відстань

На W₀:

|c_q − 1|
= (1−q)/(b−q).

На W_j:

|λ_j(q)|
= (1−q)q^(j−1)/[b^(j−1)(b−q)].

Найбільше значення серед j ≥ 1 досягається при j = 1:

|λ₁(q)| = (1−q)/(b−q).

Тому:

**||T_q − P_const|| = (1−q)/(b−q).**

Отже:

lim_{q→1⁻} ||T_q − P_const|| = 0.

Збіжність в операторній нормі є точною і має лінійну швидкість за параметром 1−q.

## 10.2. Точна слідова відстань

Оскільки оператори мають спільну ортогональну декомпозицію:

T_q − P_const

діє:

- на W₀ зі значенням c_q − 1;
- на W_j зі значеннями λ_j(q).

Тому:

||T_q − P_const||₁
= |c_q−1| + Σⱼ₌₁∞m_j|λ_j(q)|.

Маємо:

1−c_q = (1−q)/(b−q).

А сума модулів негативних власних значень:

Σⱼ₌₁∞m_j|λ_j(q)| = c_q.

Отже:

||T_q − P_const||₁
= 1−c_q+c_q.

Тому:

**||T_q − P_const||₁ = 1, для кожного 0 ≤ q < 1.**

Це точна рівність, а не лише відсутність збіжності.

Таким чином:

lim_{q→1⁻} ||T_q − P_const|| = 0,

але:

lim_{q→1⁻} ||T_q − P_const||₁ = 1.

**Новий результат W33.3-B:** сімейство T_q неперервне в операторній нормі при q = 1, але не є неперервним у слідовій нормі.

## 10.3. Чому це не суперечить W25

W25 встановлює:

lim_{q→1⁻} ||T_q||₁ = 2,

тоді як:

||T₁||₁ = 1.

W33.3 уточнює сильніше твердження:

||T_q − T₁||₁ = 1.

Це узгоджується з нерівністю оберненої трикутної нерівності:

| ||T_q||₁ − ||T₁||₁ |
≤ ||T_q−T₁||₁.

Ліва частина прямує до 1, а права частина тотожно дорівнює 1.

Отже, гранична поведінка повністю узгоджена.

# 11. Центрована апроксимація

Визначимо:

L_q = T_q − c_qI.

Тут необхідно розрізняти два способи скінченного продовження.

## 11.1. Нульове продовження

L_q^(n) = P_nT_qP_n − c_qP_n.

На H_n воно збігається з L_q.

На H_n⊥:

L_q^(n) = 0,

тоді як:

L_q = T_q − c_qI.

На рівнях j > n його власні значення прямують до −c_q.

Тому нульове продовження загалом не збігається до L_q в операторній нормі.

Насправді:

||L_q − L_q^(n)|| = c_q,

для 0 ≤ q < 1.

## 11.2. Узгоджене продовження

Визначимо:

L̃_q^(n) = P_nT_qP_n − c_qI.

Тоді:

L_q − L̃_q^(n)
= T_q − P_nT_qP_n.

Отже:

**||L_q − L̃_q^(n)|| = |λ_(n+1)(q)|.**

Таким чином, узгоджене продовження збігається в операторній нормі.

Це підтверджує T-018 та уточнює практичне правило реалізації:

**скінченне центроване ядро потрібно продовжувати на весь H через −c_qI, а не через −c_qP_n, якщо метою є операторно-нормова збіжність.**

# 12. Регресійний протокол для W20

W33.3 визначає обов'язкові перевірки для майбутньої повної регресії.

Для кожного b ≥ 2, n ≥ 1 та q ∈ [0,1] необхідно перевіряти:

### R-01. Розмірність

dim H_n = bⁿ.

### R-02. Ортонормованість

⟨e_σ,e_τ⟩ = δ_(σ,τ).

### R-03. Симетричність

M_n = M_nᵀ.

### R-04. Діагональні елементи

M_n(σ,σ) = b^−n qⁿc_q.

### R-05. Позадіагональні елементи

M_n(σ,τ) = b^−n q^ℓ(σ,τ).

### R-06. Рядкові суми

Σ_τ M_n(σ,τ) = c_q.

### R-07. Слід

Tr(M_n) = qⁿc_q.

### R-08. Спектр

Spec(M_n) = {c_q, λ₁,…,λ_n} з правильними кратностями.

### R-09. Операторна похибка

||T_q − T̃_q^(n)|| = |λ_(n+1)(q)|.

### R-10. Слідова похибка

||T_q − T̃_q^(n)||₁ = c_qqⁿ.

### R-11. Endpoint q = 0

Для n ≥ 1:

T̃₀^(n) = T₀.

### R-12. Endpoint q = 1

Для кожного n ≥ 0:

T̃₁^(n) = T₁.

### R-13. Гранична операторна відстань

||T_q−T₁|| = (1−q)/(b−q).

### R-14. Гранична слідова відстань

||T_q−T₁||₁ = 1, q < 1.

### R-15. Центроване продовження

||L_q−L̃_q^(n)|| = |λ_(n+1)(q)|.

Усі перевірки мають бути виконані з окремим обліком:

- аналітичної рівності;
- чисельної похибки;
- програмної реалізації;
- формальної верифікації.
