## 1.1. Позначення статусів

- **PROVED** — аналітичне доведення сформульоване та перевірене.

- **NOT FORMALIZED** — немає машинно-перевіреного формального доведення.

# 2. Канонічні типи та метрики

До реєстру теорем вводяться такі типи.

## 2.1. Алфавіт і простір адрес

Нехай:

A = {00, 01, 10, 11}

B_b = {1, 2, …, b}, де b ≥ 2.

Pos_b = B_b^{<ω}

Σ_b = B_b^N

Для основної тернарної моделі SUBIT-WARP:

b = 3.

Pos_b — множина скінченних адрес, Σ_b — простір нескінченних адрес.

## 2.2. Розрізнення типів дерев

Необхідно зберігати три різні конструкції:

**FullTree_A**

Повні нескінченні дерева, у яких кожна внутрішня вершина має рівно b дочірніх вершин.

**PartialTree_A**

Часткові дерева, у яких вершина може бути відсутньою, листком або внутрішньою вершиною.

**FiniteTree_A**

Скінченні дерева з окремо визначеною структурою дочірніх вершин.

Ці типи не можна ототожнювати.

Особливо важливо: твердження, доведене для повних нескінченних дерев, не переноситься автоматично на часткові дерева.

## 2.3. Канонічні метрики

Для усунення конфлікту позначень W24 закріплює:

- d_F — метрика на просторі дерев;
- d_Σ — ультраметрика на просторі адрес;
- d_T — шляхова метрика скінченного дерева;
- d_H — метрика Гаусдорфа на непорожніх компактних підмножинах.

Для адрес ξ, η ∈ Σ_b:

d_Σ(ξ,η) = 2^−ℓ(ξ,η),

де ℓ(ξ,η) — довжина їхнього найдовшого спільного префікса.

Для скінченних дерев:

d_T(ξ,η) = h(ξ) + h(η) − 2ℓ(ξ,η).

Для порожньої множини використовується окрема домовленість:

d₀(∅,A) = 2.

Це спеціальне розширення, а не стандартна метрика Гаусдорфа.

# 3. Канонічний реєстр теорем

## T-001. Компактність простору повних дерев

**Твердження.** Простір FullTree_A з природною метрикою d_F є компактним.

**Припущення:**
- алфавіт A скінченний;
- множина адрес Pos_b зліченна;
- простір дерев реалізується як замкнена підмножина добутку скінченних дискретних просторів;
- умови повноти дерева задаються замкненими локальними обмеженнями.

**Залежності:** W0, W24.16.

**Статус:** PROVED.

**Перевірка:** аналітичне доведення через компактність зліченного добутку компактних просторів.

**Машинна формалізація:** NOT FORMALIZED.

---

## T-002. Компактність класу нерозтягувальних відображень

**Твердження.** Клас

ℛ₀ = {ρ : Tree∞ → Tree∞ : Lip(ρ) ≤ 1}

є компактним у топології рівномірної збіжності.

**Припущення:**
- Tree∞ компактний;
- відображення неперервні;
- цільовий простір компактний;
- використовується рівномірна метрика на просторі відображень.

**Залежності:** T-001.

**Статус:** PROVED.

**Примітка.** Результат спирається на компактність області та рівностепеневу неперервність класу нерозтягувальних відображень.

---

## T-003. Контрактність оператора grafting

Нехай:

ρ_a(f) = Node(f, Leaf(a), Leaf(a)).

**Твердження:**

d_F(ρ_a(f), ρ_a(g)) = 1/2 · d_F(f,g).

Отже:

Lip(ρ_a) = 1/2.

**Припущення:**
- використовується канонічна метрика d_F;
- grafting додає однакову структуру до обох дерев;
- відмінність між f та g переноситься на один рівень глибше.

**Залежності:** T-001, W2.

**Статус:** PROVED.

### Наслідок T-003A. Теорема Банаха

Якщо Tree∞ є повним метричним простором, то ρ_a має єдину нерухому точку.

**Статус:** PROVED.

Нерухома точка відповідає нескінченному продовженню через гілку, визначену конструкцією grafting.

## T-004. Компактність простору адрес

**Твердження.**

Σ_b = B_b^N

є компактним метричним простором з ультраметрикою:

d_Σ(ξ,η) = 2^−ℓ(ξ,η).

**Припущення:**
- B_b скінченний;
- використовується топологія добутку;
- метрика визначена через найдовший спільний префікс.

**Залежності:** W3, W24.16.

**Статус:** PROVED.

---

## T-005. Хаусдорфова розмірність повної межі

**Твердження.**

Для повного рівномірного b-арного простору адрес:

dim_H(Σ_b,d_v) = ln(b)/α_v,

де:

d_v(ξ,η) = exp(−α_vℓ(ξ,η)).

**Припущення:**
- b ≥ 2;
- α_v > 0;
- використовується повний простір нескінченних адрес;
- міра є рівномірною бернуллівською добутковою мірою;
- міра циліндра довжини n дорівнює b^−n.

**Доведення, верхня оцінка.**

Простір Σ_b покривається b^n циліндрами довжини n.

Діаметр кожного циліндра:

diam(C_n) = exp(−α_v n).

Для s > ln(b)/α_v:

b^n · exp(−sα_v n) → 0.

Звідси:

dim_H(Σ_b) ≤ ln(b)/α_v.

**Доведення, нижня оцінка.**

Для рівномірної міри μ:

μ(C_n) = b^−n.

Оскільки:

b^−n = exp(−n ln b),

то для s = ln(b)/α_v:

μ(C_n) = diam(C_n)^s.

Стандартна оцінка міри на циліндрах дає нижню оцінку хаусдорфової розмірності.

Отже:

dim_H(Σ_b) = ln(b)/α_v.

**Залежності:** T-004, W3–W4.

**Статус:** PROVED.

**Редакційна вимога:** у фінальній v0.4 потрібно повністю виписати перехід від оцінки на циліндрах до оцінки для довільних достатньо малих куль або множин. Саме цей перехід має бути частиною канонічного доведення, а не прихованим посиланням на інтуїцію.

## T-006. Непорожність межі для Tω⁺

Визначимо:

Tω⁺ = {f ∈ Tω : ∂f ≠ ∅}.

**Твердження.** Для кожного f ∈ Tω⁺ межа ∂f є непорожньою компактною підмножиною Σ_b.

**Припущення:**
- дерево має скінченне розгалуження;
- кожна наявна внутрішня вершина має хоча б одну нескінченну гілку;
- межа складається лише з нескінченних адрес, усі скінченні префікси яких є внутрішніми вершинами.

**Залежності:** W5, W23, W24.16.

**Статус:** PROVED для визначеного класу Tω⁺.

**Критичне застереження.** Не слід використовувати Tω без додаткової умови непорожності межі: кореневий листок задовольняє умову про всі внутрішні вершини вакуумно, але має порожню межу.

---

## T-007. Ліпшицевість відображення межі

**Твердження.**

Для f,g ∈ Tω⁺:

d_H(∂f,∂g) ≤ 2d_F(f,g).

**Припущення:**
- дерева належать до Tω⁺;
- гілки мають скінченне розгалуження;
- кожна внутрішня вершина має нескінченне продовження принаймні через одну дочірню гілку;
- d_F і d_H використовують узгоджені домовленості щодо глибини.

**Основна ідея доведення.**

Нехай перша відмінність між f і g виникає на глибині r.

Для кожної нескінченної гілки одного дерева:

1. спільний префікс зберігається до першої відмінності;
2. умова Tω гарантує нескінченне продовження через доступну дочірню гілку іншого дерева;
3. відстань між відповідними гілками обмежується подвоєним масштабом першої відмінності.

Тому:

d_H(∂f,∂g) ≤ 2d_F(f,g).

**Залежності:** T-006, W27.1.

**Статус:** PROVED — аналітичне доведення закрито у W27.1.

**Формалізація:** NOT FORMALIZED.

# 4. Ієрархічні ядра та оператори

## T-008. Бoundedness спадного ядра

Нехай:

K_q(ξ,η) = q^ℓ(ξ,η),

де 0 < q < 1.

На діагоналі використовується:

K_q(ξ,ξ) = 1.

Оператор:

(T_q f)(ξ) = ∫ K_q(ξ,η)f(η)dμ_b(η).

**Твердження.** T_q є обмеженим самоспряженим компактним оператором на L²(Σ_b,μ_b).

**Припущення:**
- рівномірна бернуллівська міра;
- 0 < q < 1;
- ядро симетричне;
- ядро обмежене та квадратично інтегровне.

**Залежності:** W6, W23.

**Статус:** PROVED.

**Примітка.** Компактність випливає з властивості Гільберта—Шмідта.

---

## T-009. Ієрархічний спектр T_q

Визначимо:

c_q = (b−1)/(b−q).

Для j ≥ 1:

λ_j = −(1−q)q^(j−1) / [b^(j−1)(b−q)].

Кратність:

m_j = (b−1)b^(j−1).

**Твердження.**

Спектр оператора:

Spec(T_q) = {c_q} ∪ {λ_j : j ≥ 1} ∪ {0}.

Для 0 < q < 1:
- c_q — власне значення на просторі сталих функцій;
- λ_j — власні значення на ієрархічних деталізаціях;
- 0 є граничною точкою спектра, але не власним значенням.

**Припущення:**
- рівномірна міра;
- повний b-арний простір адрес;
- ортогональний розклад L² на сталу складову та ієрархічні простори;
- ядро залежить лише від довжини спільного префікса.

**Залежності:** T-004, T-008, W23.11.

**Статус:** PROVED аналітично.

**Важливо.** Спектральне доведення має містити побудову ортогональних просторів W_j та перевірку дії T_q на кожному з них. Сам перелік власних значень не є достатнім доказом.

---

## T-010. Спектр центрованого оператора

Визначимо:

L_q = T_q − c_q I.

**Твердження.**

- на сталих функціях L_q = 0;
- на W_j власне значення дорівнює τ_j = λ_j − c_q;
- L_q ≤ 0;
- ker(L_q) = W₀;
- essential spectrum(L_q) = {−c_q}.

**Залежності:** T-009.

**Статус:** PROVED.

**Застереження.** T_q не є додатно напіввизначеним оператором. Не можна переносити на нього властивості додатних ядер лише через симетричність ядра.

---

## T-011. Операторні норми та слід

Для 0 ≤ q < 1:

||T_q|| = c_q,

||T_q||²_HS = (b−1)/(b−q²),

||T_q||₁ = 2(b−1)/(b−q),

Tr(T_q) = 0.

Тут ||·||₁ — слідова норма.

**Припущення:**
- спектральний розклад T-009;
- абсолютна збіжність ряду власних значень для слідової норми;
- для q=0 використовується окреме граничне тлумачення степенів.

**Залежності:** T-009.

**Статус:** PROVED аналітично.

### Граничний випадок q = 1

За домовленістю:

T₁ = P_const,

де P_const — ортогональна проєкція на простір сталих функцій.

Тоді:

||T₁|| = 1,

||T₁||₁ = 1,

Tr(T₁) = 1.

Формули для q < 1 не можна механічно переносити на q=1.

### Граничний випадок q = 0

Для q=0:

c₀ = (b−1)/b,

λ₁ = −1/b,

λ_j = 0 для j ≥ 2.

Нуль стає власним значенням нескінченної кратності.

### Конвенція степеня

Для всіх q ∈ [0,1] явно встановлюється:

q⁰ := 1.

Для k ≥ 1:

0^k = 0.

Це усуває неоднозначність 0⁰ у формулах для ядра та скінченних матриць.

# 5. Зростаюче ядро

## T-012. Критерій обмеженості зростаючого ядра

Нехай:

K_+(ξ,η) = exp(α_wℓ(ξ,η)).

Для b ≥ 2:

**Твердження 1.**

Оператор є обмеженим тоді й лише тоді, коли:

α_w < ln(b).

**Твердження 2.**

Оператор є Гільберта—Шмідта тоді й лише тоді, коли:

α_w < (ln b)/2.

**Припущення:**
- рівномірна бернуллівська міра;
- діагональне значення визначене окремо;
- використовується відповідна інтегральна операторна конструкція.

**Залежності:** W6, W23.10.

**Статус:** PROVED аналітично.

**Критична відмінність:** умови обмеженості та Гільберта—Шмідта не є еквівалентними. Друга є суворішою.

# 6. Скінченновимірні апроксимації

Нехай P_n — ортогональна проєкція на простір функцій, сталих на циліндрах довжини n.

Визначимо:

T_q^(n) = P_n T_q P_n | H_n.

## T-013. Матриця скінченного оператора

Для адрес i,j довжини n:

- якщо i ≠ j:

M_n(i,j) = b^−n q^ℓ(i,j);

- якщо i = j:

M_n(i,i) = b^−n q^n c_q.

**Припущення:**
- рівномірна міра;
- ортонормована циліндрична база;
- домовленість q⁰=1.

**Залежності:** T-009, W23.14.

**Статус:** PROVED.

## T-014. Сума рядка

Для кожного рядка:

Σ_j M_n(i,j) = c_q.

**Залежності:** T-013.

**Статус:** PROVED.

## T-015. Слід скінченної апроксимації

Tr(T_q^(n)) = q^n c_q.

**Залежності:** T-013.

**Статус:** PROVED.

**Важливо:** це слід скінченновимірної апроксимації. Він не дорівнює сліду нескінченного оператора T_q.

## T-016. Скінченний спектр

Спектр T_q^(n):

Spec(T_q^(n)) = {c_q, λ₁, …, λ_n},

з урахуванням відповідних кратностей.

**Залежності:** T-009, T-013.

**Статус:** PROVED.

## T-017. Норма похибки апроксимації

Для 0 < q < 1:

||T_q − P_nT_qP_n|| = |λ_(n+1)|

= (1−q)q^n / [b^n(b−q)].

**Залежності:** T-009, T-016.

**Статус:** PROVED.

## T-018. Центрована апроксимація

Розрізняються два продовження скінченних операторів.

**Варіант A:**

P_nT_qP_n − c_qP_n.

Він сильно збігається до L_q, але не зобов'язаний збігатися в операторній нормі.

**Варіант B:**

P_nT_qP_n − c_qI.

Він збігається до L_q в операторній нормі.

**Залежності:** T-017.

**Статус:** PROVED.

# 7. Параметрична неперервність

## T-019. Ліпшицевість сімейства T_q

**Твердження.**

Для b ≥ 2 та q,r ∈ [0,1]:

||T_q − T_r|| ≤ |q−r|.

**Припущення:**
- оператори T_q мають спільний ортогональний ієрархічний розклад;
- спектральні формули коректні на всьому відрізку [0,1] з окремим тлумаченням кінців;
- використовується операторна норма.

**Доведення.**

Оскільки всі T_q діагоналізуються в одній і тій самій ортогональній декомпозиції, то:

||T_q−T_r|| = sup_k |μ_k(q)−μ_k(r)|.

Для сталого власного значення:

c_q = (b−1)/(b−q),

і:

|c'_q| = (b−1)/(b−q)² ≤ 1.

Для ієрархічних власних значень:

g_n(q) = (1−q)q^n/[b^n(b−q)].

Оцінка похідної дає:

|g'_n(q)| ≤ 1.

Застосування теореми Лагранжа:

|μ_k(q)−μ_k(r)| ≤ |q−r|.

Після взяття супремуму:

||T_q−T_r|| ≤ |q−r|.

**Залежності:** T-009, W27.2.

**Статус:** PROVED аналітично.

**Критична залежність:** доведення не є незалежним від спектральної теореми. Спільна ієрархічна декомпозиція — необхідна частина аргументу.

# 8. Структурна реконструкція

## T-020. Неупорядкована реконструкція скінченного дерева

Нехай для скінченного кореневого дерева задано:

F(T) = (L,h,a),

де:
- L — множина листків;
- h — глибина кожного листка;
- a — матриця глибин найменших спільних предків для кожної пари листків.

**Твердження.** Ці дані визначають скінченне кореневе дерево з точністю до кореневого ізоморфізму, який не враховує порядок дочірніх гілок.

**Припущення:**
- дерево скінченне;
- корінь визначений;
- враховуються unary-вузли;
- збережені всі глибини листків та попарні глибини LCA.

**Залежності:** W27.3, W29-04.

**Статус:** PROVED у межах неупорядкованої реконструкції.

## T-021. Упорядкована реконструкція SUBIT-дерева

Для відновлення порядку гілок необхідно додати адреси листків:

p : L → B_b^{<ω}.

Тоді:

F_ordered(T) = (L,h,a,p).

**Твердження.** За умови, що адреси листків є коректними та сумісними з деревом, множина адрес і їхніх префіксів визначає упорядковану структуру дерева.

**Залежності:** T-020, W29-04.

**Статус:** PROVED за умовою коректності адрес.

**Обмеження.** Неупорядкований fingerprint не можна подавати як повний інваріант упорядкованого тернарного дерева SUBIT-WARP.

# 10. Виявлені залежності, які потребують редакційного контролю

## W30-01. Спектральна декомпозиція

**Проблема:** формули спектра не повинні з'являтися раніше за визначення ієрархічних просторів W_j.

**Виправлення:** канонічний порядок:

1. побудова L²;
2. визначення H_n;
3. побудова W_j;
4. доведення ортогональності;
5. доведення повноти розкладу;
6. дія T_q на W_j;
7. спектральні формули.

**Статус:** REQUIRED FOR CANONICAL EDITION.

## W30-02. Параметрична ліпшицевість

**Проблема:** T-019 використовує спільний спектральний базис.

**Виправлення:** явно включити цей факт до припущень і доведення.

**Статус:** RESOLVED IN W27.2; DEPENDENCY EXPLICIT.

## W30-03. Межа часткового дерева

**Проблема:** Tω не гарантує непорожності межі.

**Виправлення:** для теорем про d_H використовувати виключно Tω⁺.

**Статус:** RESOLVED.

## W30-04. Упорядкована структура

**Проблема:** неупорядкований fingerprint не відновлює позиції дочірніх гілок 1, 2, 3.

**Виправлення:** розділити T-020 і T-021.

**Статус:** RESOLVED.

## W30-05. Граничні значення q

**Проблема:** формули для 0 < q < 1 не можна механічно застосовувати до q=0 або q=1.

**Виправлення:** окремо визначити три режими:

- q=0;
- 0<q<1;
- q=1.

**Статус:** RESOLVED.

## W30-06. Конвенція 0⁰

**Проблема:** неоднозначність степеневої функції в ядрах та скінченних матрицях.

**Виправлення:**

q⁰ := 1 для всіх q ∈ [0,1].

**Статус:** RESOLVED.

## W30-07. Слід скінченного оператора

**Проблема:** Tr(T_q^(n)) не можна ототожнювати з Tr(T_q).

**Виправлення:** усі формули повинні вказувати, до якого оператора належить слід.

**Статус:** RESOLVED.

## W30-08. Доведення хаусдорфової розмірності

**Проблема:** недостатньо навести формулу ln(b)/α_v без повного обґрунтування нижньої оцінки.

**Виправлення:** включити циліндричну оцінку міри та її перенесення на довільні малі множини.

**Статус:** PROVED ANALYTICALLY; PRESENTATION STRENGTHENING REQUIRED.

## W30-09. Lean-формалізація

**Проблема:** аналітичні доведення не є Lean-доведеннями.

**Виправлення:** створити окрему формальну карту залежностей і визначити машинно-перевірювану підмножину.

**Статус:** NOT FORMALIZED.

## W30-10. Регресійна перевірка

**Проблема:** специфікація W28 не є доказом виконання тестів.

**Виправлення:** зберігати окремі статуси SPECIFIED та EXECUTED.

**Статус:** W25 NUMERICALLY VERIFIED; W20 FULL SUITE NOT EXECUTED.
