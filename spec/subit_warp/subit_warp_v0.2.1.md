# Анотація

SUBIT-WARP досліджує геометричні, топологічні та спектральні властивості ієрархічних структур, заданих у просторі нескінченних дерев SUBIT-∞.

Мета модуля — побудувати математично узгоджену систему, яка пов'язує:

1. скінченні адреси та позиції дерева;
2. нескінченні гілки й межовий простір;
3. класи причинних операторів;
4. геометрію межі;
5. міру та розмірність;
6. взаємодії між межовими точками;
7. ієрархічні лапласіани та їхній спектр.

SUBIT-WARP не вводить нову онтологію замість SUBIT-∞. Він використовує структуру Tree∞ як математичний субстрат для дослідження того, як локальні правила породжують глобальні межові структури.

Основна архітектурна ідея:

**локальна структура → ієрархічна динаміка → нескінченна межа → геометрія → взаємодія → спектр.**

Важливо розрізняти три незалежні параметри:

* αᵥ — параметр геометрії межового простору;
* α𝑤 — параметр загасання взаємодій;
* αₛ = ln 2 — параметр, узгоджений із базовою метрикою SUBIT-∞.

Їх ототожнення допускається лише як окрема модельна умова.

# 2. W0 — Ontological Substrate

## 2.1. Простір позицій

Визначимо простір скінченних адрес:

**Pos := B* = {1,2,3}*.**

Адреса σ ∈ Pos задає шлях від кореня дерева.

Для σ ∈ Pos і i ∈ B:

σi

позначає адресу, отриману додаванням символу i.

Довжина адреси:

**|σ| ∈ N₀.**

Корінь дерева має адресу ε.

## 2.2. Структура дерева

Визначимо простір дерев Tree∞ коіндуктивно.

Елемент f ∈ Tree∞ має одну з форм:

1. leaf(a);
2. node(f₁,f₂,f₃).

Отже:

**Tree∞ ≅ A + Tree∞³.**

Це коіндуктивна структура: дерево може мати скінченну або нескінченну глибину.

Важливо: Tree∞ не ототожнюється з Pos або Σ.

Це три різні типи об'єктів:

* Pos — скінченні адреси;
* Tree∞ — дерева;
* Σ — нескінченні гілки.

## 2.3. Функція міток

Для f ∈ Tree∞ визначимо часткову функцію:

**label_f : Pos ⇀ {node} ∪ {leaf(a) : a ∈ A}.**

Адреса σ належить області визначення тоді й лише тоді, коли відповідна вершина існує в дереві.

Якщо вершина σ має тип node, її діти:

σ1, σ2, σ3.

Якщо вершина має тип leaf(a), її нащадки відсутні.

## 2.4. Множина внутрішніх вершин

Визначимо:

**Occ(f) := {σ ∈ Pos : label_f(σ) = node}.**

Occ(f) — множина адрес внутрішніх вершин дерева.

Для листків окремо:

**Leaves(f) := {σ ∈ Pos : label_f(σ) = leaf(a) для деякого a ∈ A}.**

## 2.5. Простір нескінченних гілок

Визначимо:

**Σ := B^N = {1,2,3}^N.**

Елемент ξ ∈ Σ є нескінченною послідовністю:

ξ = (ξ₁, ξ₂, ξ₃, ...).

Початковий відрізок довжини n:

ξ|n = ξ₁ξ₂...ξₙ.

Нескінченна гілка ξ проходить через дерево f, якщо:

**∀n ∈ N₀: ξ|n ∈ Occ(f) ∪ {ε}.**

Точніше, для n ≥ 1 кожна адреса ξ|n має бути внутрішньою вершиною.

Визначимо межу дерева:

**∂f := {ξ ∈ Σ : ∀n ≥ 1, ξ|n ∈ Occ(f)}.**

Отже, ∂f — множина всіх нескінченних гілок дерева.

Для скінченного дерева:

∂f = ∅.

Для нескінченного дерева межа може бути порожньою, одноелементною або нескінченною.

## 2.6. Принцип типізації

Усі оператори SUBIT-WARP мають явно визначені області та кодомени.

Зокрема:

* ∂ : Tree∞ → P(Σ);
* ∂ : Tω → K(Σ), якщо f належить спеціальному підпростору Tω;
* dᵥ : Σ × Σ → R;
* K : Σ × Σ ⇀ R.

Заборонено використовувати dᵥ для скінченних адрес без окремого означення метрики на Pos.

# 3. W1 — Causal Filtration

## 3.1. Простір операторів

Нехай:

**ℛ₀ := {ρ : Tree∞ → Tree∞ : ρ є 1-Lipschitz}.**

Метрика на просторі операторів:

**dℛ(ρ,σ) := sup{dₛ(ρ(f),σ(f)) : f ∈ Tree∞}.**

Компактність ℛ₀ успадковується від відповідного результату базової специфікації за умови компактності Tree∞ та прийнятої метрики.

## 3.2. Класи причинності

Для m ∈ N₀ визначимо:

**ℛ⁽ᵐ⁾ := {ρ ∈ ℛ₀ : ∀f,g ∈ Tree∞, dₛ(ρ(f),ρ(g)) ≤ 2⁻ᵐ dₛ(f,g)}.**

Це клас операторів із коефіцієнтом Ліпшиця не більшим за 2⁻ᵐ.

Інтерпретація:

* ℛ⁽⁰⁾ — неекспансивні оператори;
* ℛ⁽¹⁾ — оператори з коефіцієнтом не більше 1/2;
* ℛ⁽²⁾ — оператори з коефіцієнтом не більше 1/4;
* ℛ⁽ᵐ⁾ — дедалі сильніше згладжування відмінностей вхідних станів.

Індекс m тут є рівнем причинної фільтрації, а не глибиною дерева.

## 3.3. Теорема W1.1 — Монотонність фільтрації

**ℛ⁽ᵐ⁺¹⁾ ⊆ ℛ⁽ᵐ⁾.**

Доведення.

Нехай ρ ∈ ℛ⁽ᵐ⁺¹⁾.

Тоді:

dₛ(ρ(f),ρ(g)) ≤ 2⁻⁽ᵐ⁺¹⁾dₛ(f,g).

Оскільки:

2⁻⁽ᵐ⁺¹⁾ ≤ 2⁻ᵐ,

отримуємо:

dₛ(ρ(f),ρ(g)) ≤ 2⁻ᵐdₛ(f,g).

Отже, ρ ∈ ℛ⁽ᵐ⁾. ∎

**Статус:** DP-f.

## 3.4. Теорема W1.2 — Композиція

Для всіх m,k ∈ N₀:

**ℛ⁽ᵐ⁾ ∘ ℛ⁽ᵏ⁾ ⊆ ℛ⁽ᵐ⁺ᵏ⁾.**

Доведення.

Нехай:

ρ ∈ ℛ⁽ᵐ⁾,

σ ∈ ℛ⁽ᵏ⁾.

Тоді:

dₛ(ρ(σ(f)),ρ(σ(g)))
≤ 2⁻ᵐ dₛ(σ(f),σ(g))
≤ 2⁻ᵐ 2⁻ᵏ dₛ(f,g).

Отже:

dₛ((ρ∘σ)(f),(ρ∘σ)(g))
≤ 2⁻⁽ᵐ⁺ᵏ⁾dₛ(f,g).

Тому:

ρ∘σ ∈ ℛ⁽ᵐ⁺ᵏ⁾. ∎

**Статус:** DP-f.

## 3.5. Теорема W1.3 — Перетин фільтрації

**⋂ₘ≥₀ ℛ⁽ᵐ⁾ = {κ_c : c ∈ Tree∞}.**

Тут:

κ_c(f) := c

— стала функція.

Доведення.

Нехай:

ρ ∈ ⋂ₘ≥₀ ℛ⁽ᵐ⁾.

Для будь-яких f,g:

dₛ(ρ(f),ρ(g)) ≤ 2⁻ᵐdₛ(f,g)

для кожного m.

Оскільки діаметр Tree∞ скінченний, при m → ∞ права частина прямує до нуля.

Отже:

dₛ(ρ(f),ρ(g)) = 0.

Тому:

ρ(f) = ρ(g).

Отже, ρ є сталою функцією.

Навпаки, кожна стала функція має коефіцієнт Ліпшиця 0 і належить кожному ℛ⁽ᵐ⁾. ∎

**Статус:** DP-f.

## 3.6. Теорема W1.4 — Компактність класів ℛ⁽ᵐ⁾

Якщо ℛ₀ компактний у метриці dℛ, то кожен ℛ⁽ᵐ⁾ є компактним.

Доведення.

Нехай ρₙ ∈ ℛ⁽ᵐ⁾ і:

dℛ(ρₙ,ρ) → 0.

Для будь-яких f,g:

dₛ(ρₙ(f),ρₙ(g)) ≤ 2⁻ᵐdₛ(f,g).

Збіжність у dℛ забезпечує поточкову збіжність:

ρₙ(f) → ρ(f).

За неперервністю метрики:

dₛ(ρ(f),ρ(g)) ≤ 2⁻ᵐdₛ(f,g).

Отже:

ρ ∈ ℛ⁽ᵐ⁾.

Тому ℛ⁽ᵐ⁾ замкнений у компактному ℛ₀, а отже компактний. ∎

**Статус:** DP-f за компактності ℛ₀.

## 3.7. Експоненційне загасання

Для α𝑤 > 0 визначимо:

**Ω𝑤(m) := e⁻ᵅʷᵐ.**

Це моноїдний гомоморфізм:

Ω𝑤(m+k) = Ω𝑤(m)Ω𝑤(k).

Важливо:

Ω𝑤 не зобов'язаний дорівнювати 2⁻ᵐ.

Рівність:

e⁻ᵅʷᵐ = 2⁻ᵐ

виконується лише за умови:

**α𝑤 = ln 2.**

У загальному випадку α𝑤 є незалежним параметром моделі взаємодії.

# 4. W2 — Grafting Dynamics

## 4.1. Оператор grafting

Для a ∈ A визначимо:

**ρₐ(f) := node(f, leaf(a), leaf(a)).**

Оператор додає новий корінь, зберігаючи f у першій гілці.

Цей оператор має фіксовану точку pₐ:

**pₐ = node(pₐ, leaf(a), leaf(a)).**

Ітерації:

ρₐ⁰(f) = f,

ρₐ¹(f) = ρₐ(f),

ρₐᵐ⁺¹(f) = ρₐ(ρₐᵐ(f)).

## 4.2. Теорема W2.1 — Контрактивність

Для базової метрики SUBIT-∞:

**dₛ(ρₐ(f),ρₐ(g)) = 1/2 · dₛ(f,g).**

За відповідної конвенції індексації глибини.

Для m ітерацій:

**dₛ(ρₐᵐ(f),ρₐᵐ(g)) = 2⁻ᵐdₛ(f,g).**

Отже:

ρₐᵐ ∈ ℛ⁽ᵐ⁾.

**Статус:** DP-f за точного узгодження конвенції dₛ із базовим означенням grafting.

## 4.3. Теорема W2.2 — Збіжність до фіксованої точки

Для будь-якого f ∈ Tree∞:

**dₛ(ρₐᵐ(f),pₐ) = 2⁻ᵐdₛ(f,pₐ).**

Тому:

**limₘ→∞ ρₐᵐ(f) = pₐ.**

Доведення.

Оскільки pₐ є фіксованою точкою:

ρₐ(pₐ) = pₐ.

Застосовуємо контрактну властивість m разів:

dₛ(ρₐᵐ(f),ρₐᵐ(pₐ))
= 2⁻ᵐdₛ(f,pₐ).

Але:

ρₐᵐ(pₐ) = pₐ.

Отже отримуємо потрібну рівність. ∎

**Статус:** DP-f.

## 4.4. Твердження W2.3 — Топологічна ентропія

Якщо ρₐ є строгим стиском на компактному метричному просторі Tree∞, тоді:

**h_top(ρₐ) = 0.**

Це не означає, що всі оператори SUBIT-WARP мають нульову ентропію.

Це твердження стосується саме контрактної динаміки ρₐ.

Необхідно також розрізняти:

1. динаміку на Tree∞;
2. динаміку на розширеному просторі Tree∞ × R;
3. метаеволюцію правил.

Результат базової специфікації для g∞ = π_R не можна автоматично переносити на довільну метаеволюцію.

**Статус:** CONDITIONAL.

# 5. W3 — Boundary Geometry

## 5.1. Спільний префікс

Для ξ,η ∈ Σ визначимо:

**ℓ(ξ,η) := sup{n ∈ N₀ : ξ|n = η|n}.**

Якщо ξ = η:

ℓ(ξ,η) = ∞.

Якщо перші символи різняться:

ℓ(ξ,η) = 0.

## 5.2. Межова метрика

Для αᵥ > 0 визначимо:

**dᵥ(ξ,η) := e⁻ᵅᵛˡ⁽ξ,η⁾.**

Для ξ = η покладаємо:

dᵥ(ξ,ξ) = 0.

Ця функція є ультраметрикою на Σ.

Виконується:

dᵥ(ξ,ζ) ≤ max(dᵥ(ξ,η),dᵥ(η,ζ)).

## 5.3. Теорема W3.1 — Компактність межового простору

**(Σ,dᵥ) є компактним ультраметричним простором.**

Доведення.

Σ = {1,2,3}^N є добутком скінченних дискретних компактних просторів.

За теоремою Тихонова Σ компактний у добутковій топології.

Метрика dᵥ індукує саме цю топологію, оскільки дві послідовності близькі тоді й лише тоді, коли мають довгий спільний початковий префікс.

Отже, (Σ,dᵥ) компактний. ∎

**Статус:** DP-f.

## 5.4. Теорема W3.2 — Еквівалентність геометричних параметрів

Нехай αᵥ > 0 і β > 0.

Тоді метрики:

dᵥ(ξ,η) = e⁻ᵅᵛˡ⁽ξ,η⁾

та

dᵥ,β(ξ,η) = e⁻ᵝˡ⁽ξ,η⁾

індукують однакову топологію.

Доведення.

Обидві метрики задають однакову систему циліндричних околів:

C(σ) := {ξ ∈ Σ : ξ||σ| = σ}.

Зміна додатного параметра змінює числові значення відстаней, але не систему відкритих множин. ∎

**Статус:** DP-f.

## 5.5. Три незалежні масштаби

У SUBIT-WARP використовуються:

**αᵥ — візуальна геометрія межі.**

**α𝑤 — загасання взаємодій.**

**αₛ = ln 2 — базова геометрія SUBIT-∞.**

Умова:

αᵥ = α𝑤 = αₛ

не є загальним законом.

Це спеціальний режим узгодження трьох масштабів.

# 6. W4 — Hausdorff Dimension

## 6.1. Канонічна міра

Нехай μ — добуткова ймовірнісна міра на Σ, для якої:

μ(ξ₁=i₁,...,ξₙ=iₙ) = 3⁻ⁿ.

Тобто кожен символ має ймовірність 1/3.

Для циліндра C(σ), де |σ|=n:

**μ(C(σ)) = 3⁻ⁿ.**

## 6.2. Теорема W4.1 — Розмірність межі

Для метрики dᵥ:

**dim_H(Σ,dᵥ) = ln 3 / αᵥ.**

Доведення.

Кожен циліндр глибини n має діаметр:

diam(C(σ)) = e⁻ᵅᵛⁿ.

Кількість циліндрів глибини n:

3ⁿ.

Отже, для s > 0 сума s-степенів діаметрів покриття дорівнює:

3ⁿ · e⁻ˢᵅᵛⁿ.

Це:

exp(n(ln 3 − sαᵥ)).

Якщо:

s > ln 3 / αᵥ,

ця величина прямує до нуля.

Тому:

dim_H(Σ) ≤ ln 3 / αᵥ.

Для нижньої оцінки використовуємо μ.

Для циліндра глибини n:

μ(C(σ)) = 3⁻ⁿ.

При цьому:

3⁻ⁿ = (e⁻ᵅᵛⁿ)ˢ

за:

s = ln 3 / αᵥ.

Оскільки ультраметричні кулі збігаються з циліндричними множинами з точністю до конвенції радіуса, міра μ задовольняє умову масового розподілу.

Отже:

dim_H(Σ) ≥ ln 3 / αᵥ.

Об'єднуючи оцінки:

**dim_H(Σ) = ln 3 / αᵥ.** ∎

**Статус:** DP-f.

## 6.3. Наслідки

Якщо:

αᵥ = ln 2,

тоді:

dim_H(Σ) = ln 3 / ln 2.

Це не ціле число.

Якщо:

αᵥ = ln 3,

тоді:

dim_H(Σ) = 1.

Розмірність залежить від вибраної метрики, а не лише від абстрактної топології Σ.

# 7. W5 — Boundary Operator

## 7.1. Простір компактних підмножин

Позначимо:

K(Σ) — множину непорожніх компактних підмножин Σ.

Оскільки Σ компактний, кожна замкнена підмножина Σ є компактною.

Для непорожніх A,B ∈ K(Σ) визначимо метрику Гаусдорфа:

**d_H(A,B) := max{supₐ∈A infᵦ∈B dᵥ(a,b), supᵦ∈B infₐ∈A dᵥ(a,b)}.**

Для роботи з порожньою межею введемо розширений простір:

**K₀(Σ) := K(Σ) ∪ {∅}.**

Для K₀(Σ) використовуємо окрему топологію:

* K(Σ) має стандартну топологію Гаусдорфа;
* ∅ є ізольованою точкою.

Це усуває неоднозначність щодо відстані між порожньою та непорожньою множинами.

## 7.2. Оператор межі

Визначимо:

**∂ : Tree∞ → K₀(Σ).**

∂f є множиною всіх нескінченних гілок f.

## 7.3. Теорема W5.1 — Розривність глобального оператора межі

Оператор:

∂ : Tree∞ → K₀(Σ)

не є неперервним на всьому Tree∞.

Доведення.

Розглянемо:

f₀ = leaf(a).

Тоді:

∂f₀ = ∅.

Визначимо:

fₙ := ρₐⁿ(f₀).

За теоремою W2.2:

fₙ → pₐ.

Оскільки кожне fₙ має скінченну глибину:

∂fₙ = ∅.

Водночас:

pₐ = node(pₐ,leaf(a),leaf(a)).

Його єдина нескінченна гілка:

ξ = 111...

Тому:

∂pₐ = {111...}.

Отже:

∂fₙ = ∅

для всіх n, але:

∂pₐ ≠ ∅.

Оскільки ∅ ізольована в K₀(Σ), послідовність ∂fₙ не збігається до ∂pₐ.

Тому ∂ не є неперервним у pₐ. ∎

**Статус:** DP-f.

## 7.4. Підпростір нескінченної продовжуваності

Визначимо:

**Tω := {f ∈ Tree∞ : кожна внутрішня вершина має хоча б одну нескінченну гілку нижче себе}.**

Тобто:

∀σ ∈ Occ(f), існує ξ ∈ ∂f, для якої σ є префіксом ξ.

Ця умова сильніша за просту нескінченність дерева.

Вона виключає внутрішні частини, які не належать жодній нескінченній гілці.

## 7.5. Теорема W5.2 — Непорожність межі

Для кожного f ∈ Tω:

**∂f ≠ ∅.**

Доведення.

За означенням Tω кожна внутрішня вершина має нескінченне продовження.

Якщо дерево має корінь node, він сам має нескінченне продовження.

Отже існує ξ ∈ Σ, усі скінченні префікси якого належать Occ(f).

Тому ξ ∈ ∂f. ∎

## 7.6. Теорема W5.3 — Замкненість Tω

**Tω є замкненим підпростором Tree∞.**

Доведення.

Нехай fₙ ∈ Tω і fₙ → f.

Розглянемо довільну внутрішню вершину σ ∈ Occ(f).

За збіжністю дерев існує N, після якого σ залишається внутрішньою вершиною всіх fₙ.

Оскільки fₙ ∈ Tω, для кожного такого n існує нескінченна гілка ξₙ, що проходить через σ.

Простір Σ компактний.

Тому з послідовності ξₙ можна вибрати збіжну підпослідовність:

ξₙₖ → ξ.

Оскільки збіжність у Σ означає стабілізацію кожного скінченного префікса, а дерева fₙₖ збігаються до f, кожен префікс ξ належить f.

Отже ξ ∈ ∂f.

Таким чином, σ має нескінченне продовження.

Оскільки σ було довільним:

f ∈ Tω.

Отже Tω замкнений. ∎

**Статус:** DP-f за стандартної компактної ультраметричної структури Tree∞.

## 7.7. Теорема W5.4 — Ліпшицевість оператора межі

Обмеження:

**∂|Tω : Tω → K(Σ)**

є неперервним.

За конвенції метрики SUBIT-∞:

**d_H(∂f,∂g) ≤ 2dₛ(f,g).**

Доведення.

Нехай:

dₛ(f,g) = 2⁻ⁿ.

Тоді дерева збігаються на відповідних скінченних рівнях, окрім можливої різниці на межі глибини n.

Візьмемо ξ ∈ ∂f.

Оскільки f ∈ Tω, кожна відповідна внутрішня вершина має нескінченне продовження.

За збігом f і g до рівня n можна побудувати ξ' ∈ ∂g з тим самим префіксом до глибини n−1.

Отже:

dᵥ(ξ,ξ') ≤ e⁻ᵅᵛ⁽ⁿ⁻¹⁾.

За αᵥ = ln 2:

dᵥ(ξ,ξ') ≤ 2·2⁻ⁿ.

Тобто:

dᵥ(ξ,ξ') ≤ 2dₛ(f,g).

Аналогічно для кожного елемента ∂g.

Отже:

d_H(∂f,∂g) ≤ 2dₛ(f,g). ∎

**Статус:** CONDITIONAL — точна константа залежить від конвенції індексації кореня та діаметра циліндра в базовій метриці.

## 7.8. Принцип W5

Оператор межі має дві різні властивості:

* на всьому Tree∞ він розривний;
* на Tω він неперервний.

Це не суперечність.

Обмеження області визначення змінює топологічну поведінку оператора.

# 8. W6 — Interaction Kernels

## 8.1. Загальні умови

Ядра взаємодії визначаються на парах межових точок:

**K : Σ × Σ → R**

або на частковій області:

**K : {(ξ,η) ∈ Σ² : ξ ≠ η} → R.**

Для кожного ядра мають бути визначені:

1. область визначення;
2. симетрія;
3. поведінка на діагоналі;
4. обмеженість або умови інтегровності;
5. параметри нормалізації.

Метрика dᵥ визначена на Σ, а не на Pos.

Тому K не можна застосовувати до скінченних адрес без окремого означення.

## 8.2. Ядро спільного предка

Визначимо:

**Kₐₙ𝒸(ξ,η) := e⁻ᵅʷˡ⁽ξ,η⁾.**

Для ξ = η покладаємо:

Kₐₙ𝒸(ξ,ξ) := 0.

Це ядро описує загасання взаємодії залежно від глибини спільного префікса.

Якщо ξ і η мають короткий спільний префікс, значення ядра велике.

Якщо їхній спільний префікс довгий, значення мале.

## 8.3. Властивості Kₐₙ𝒸

Для ξ ≠ η:

0 < Kₐₙ𝒸(ξ,η) ≤ 1.

Ядро симетричне:

Kₐₙ𝒸(ξ,η) = Kₐₙ𝒸(η,ξ).

Оскільки при ξ → η довжина спільного префікса прямує до нескінченності:

Kₐₙ𝒸(ξ,η) → 0.

Отже, означення на діагоналі забезпечує неперервність.

**Статус:** DP-f.

## 8.4. Волтеррівське ядро

Визначимо на позадіагональній області:

**Kᵥₗ(ξ,η) := e⁺ᵅʷˡ⁽ξ,η⁾, ξ ≠ η.**

Це ядро зростає зі збільшенням довжини спільного префікса.

При ξ → η:

Kᵥₗ(ξ,η) → ∞.

Тому ядро має сингулярність на діагоналі.

Його не можна вважати обмеженим або неперервним ядром на всьому Σ².

## 8.5. Умови інтегровності Kᵥₗ

Нехай μ — канонічна міра з розділу W4.

Для фіксованого ξ множина точок η, що мають із ξ спільний префікс довжини рівно k, має міру:

**2·3⁻ᵏ⁻¹.**

Тому:

∫Σ Kᵥₗ(ξ,η)dμ(η)

=

Σₖ≥₀ 2·3⁻ᵏ⁻¹eᵅʷᵏ.

Цей геометричний ряд збігається тоді й лише тоді, коли:

**α𝑤 < ln 3.**

У цьому випадку:

**∫Σ Kᵥₗ(ξ,η)dμ(η) = 2/(3−eᵅʷ).**

Отже, для α𝑤 < ln 3 ядро інтегровне за μ, незважаючи на сингулярність на діагоналі.

Для α𝑤 ≥ ln 3 інтеграл розбігається.

## 8.6. Регуляризоване ядро

Для скінченного рівня N визначимо:

**Kᵥₗ⁽ᴺ⁾(ξ,η) := eᵅʷᵐⁱⁿ⁽ˡ⁽ξ,η⁾,ᴺ⁾.**

Це обмежене ядро.

Для всіх ξ,η:

Kᵥₗ⁽ᴺ⁾(ξ,η) ≤ eᵅʷᴺ.

При N → ∞:

Kᵥₗ⁽ᴺ⁾(ξ,η) → Kᵥₗ(ξ,η)

для ξ ≠ η.

Регуляризація дозволяє будувати скінченні наближення без необмеженої сингулярності.

## 8.7. Різниця моделей взаємодії

Kₐₙ𝒸 та Kᵥₗ не є двома нормалізаціями одного й того самого ядра.

Вони описують протилежні режими:

* Kₐₙ𝒸 — загасання взаємодії для близьких межових гілок;
* Kᵥₗ — посилення взаємодії для гілок із довгим спільним префіксом.

Їх не можна ототожнювати без окремого модельного обґрунтування.

## 8.8. Відкриті питання W6

1. Чи є Kₐₙ𝒸 додатно визначеним ядром у сенсі теорії відтворювальних ядерних просторів?
2. За яких параметрів Kᵥₗ задає компактний інтегральний оператор?
3. Які функціональні простори є природними для сингулярного ядра?
4. Чи існує природна регуляризація, сумісна з категоріальною структурою SUBIT-∞?

Ці питання не вважаються розв'язаними у v0.2.

# 9. W7 — Hierarchical Laplacian

## 9.1. Канонічна міра та гільбертів простір

Використаємо канонічну міру μ на Σ.

Визначимо:

**H := L²(Σ, μ).**

Скалярний добуток:

⟨f,g⟩ := ∫Σ f(ξ)g(ξ)dμ(ξ).

Розглянемо ядро:

**Kₐₙ𝒸(ξ,η) = e⁻ᵅʷˡ⁽ξ,η⁾**, якщо ξ ≠ η,

і нуль на діагоналі.

Позначимо:

q := e⁻ᵅʷ.

Тоді:

Kₐₙ𝒸(ξ,η) = qˡ⁽ξ,η⁾.

## 9.2. Інтегральний оператор

Визначимо:

**(T_q f)(ξ) := ∫Σ Kₐₙ𝒸(ξ,η)f(η)dμ(η).**

Оскільки 0 < q < 1, ядро обмежене:

|Kₐₙ𝒸(ξ,η)| ≤ 1.

Тому T_q є обмеженим оператором на L²(Σ,μ).

Ядро симетричне:

Kₐₙ𝒸(ξ,η) = Kₐₙ𝒸(η,ξ).

Отже, T_q є самоспряженим оператором.

Оскільки ядро обмежене на просторі скінченної міри, воно належить L²(Σ², μ×μ).

Тому T_q є оператором Гільберта—Шмідта, а отже компактним.

## 9.3. Стала функція суміжності

Визначимо:

c_q := ∫Σ Kₐₙ𝒸(ξ,η)dμ(η).

За симетрією дерева це значення не залежить від ξ.

Для кожного k:

μ{η : ℓ(ξ,η)=k} = 2·3⁻ᵏ⁻¹.

Тому:

c_q = Σₖ≥₀ 2·3⁻ᵏ⁻¹qᵏ.

Отже:

**c_q = 2/(3−q).**

## 9.4. Ієрархічний лапласіан

Визначимо:

**(L_q f)(ξ) := ∫Σ Kₐₙ𝒸(ξ,η)(f(η)−f(ξ))dμ(η).**

Еквівалентно:

**L_q = T_q − c_q I.**

Оскільки T_q самоспряжений:

L_q також самоспряжений.

## 9.5. Теорема W7.1 — Невід'ємність −L_q

Для кожного f ∈ L²(Σ,μ):

**⟨f,−L_q f⟩ ≥ 0.**

Доведення.

Маємо:

⟨f,−L_q f⟩

=

1/2 ∫Σ∫Σ Kₐₙ𝒸(ξ,η)(f(ξ)−f(η))² dμ(ξ)dμ(η).

Оскільки:

Kₐₙ𝒸(ξ,η) ≥ 0,

а квадрат невід'ємний, весь інтеграл невід'ємний.

Отже:

⟨f,−L_q f⟩ ≥ 0. ∎

**Статус:** DP-f.

## 9.6. Циліндричні підпростори

Для n ≥ 0 визначимо:

Hₙ := {f ∈ L²(Σ,μ) : f залежить лише від перших n символів ξ}.

Тобто f стала на кожному циліндрі глибини n.

Виконується:

H₀ ⊂ H₁ ⊂ H₂ ⊂ ...

Об'єднання цих просторів щільне в L²(Σ,μ).

## 9.7. Ієрархічні хвильові підпростори

Визначимо:

**Wⱼ := Hⱼ ⊖ Hⱼ₋₁.**

Елементи Wⱼ:

* сталі на кожному циліндрі глибини j;
* мають нульове середнє на відповідному батьківському циліндрі глибини j−1.

Розмірність:

**dim(Wⱼ) = 2·3ʲ⁻¹.**

Маємо ортогональний розклад:

L²(Σ,μ) = H₀ ⊕ ⨁ⱼ≥₁ Wⱼ.

## 9.8. Теорема W7.2 — Спектральна дія T_q

Для кожного j ≥ 1 простір Wⱼ є власним підпростором T_q.

Власне значення:

**τⱼ(q) = Σₖ≥ⱼ 2qᵏ/3ᵏ⁺¹ − qʲ⁻¹/3ʲ − c_q.**

Після спрощення:

**τⱼ(q) = −[Σₖ₌₀ʲ⁻¹ 2qᵏ/3ᵏ⁺¹ + qʲ⁻¹/3ʲ].**

Доведення.

Нехай f ∈ Wⱼ.

Розглянемо точку ξ, що належить певному циліндру глибини j.

Функція f стала на кожному дочірньому циліндрі глибини j.

Для η, що має з ξ спільний префікс довжини k ≥ j, значення f(η)=f(ξ).

Сумарний внесок таких точок:

Σₖ≥ⱼ 2qᵏ/3ᵏ⁺¹ · f(ξ).

Для точок η, які належать двом іншим дочірнім циліндрам того самого батьківського циліндра, ядро має значення qʲ⁻¹.

Оскільки сума трьох дочірніх значень функції дорівнює нулю, сума значень у двох інших дочірніх циліндрах дорівнює −f(ξ).

Їхній внесок:

−qʲ⁻¹/3ʲ · f(ξ).

Отже:

T_q f = τ̃ⱼ(q)f,

де:

τ̃ⱼ(q) = Σₖ≥ⱼ 2qᵏ/3ᵏ⁺¹ − qʲ⁻¹/3ʲ.

Для лапласіана віднімаємо c_q I:

L_q f = (τ̃ⱼ(q)−c_q)f.

Отримуємо:

τⱼ(q) = −[Σₖ₌₀ʲ⁻¹ 2qᵏ/3ᵏ⁺¹ + qʲ⁻¹/3ʲ].

Отже Wⱼ є власним підпростором L_q із зазначеним власним значенням. ∎

**Статус:** DP-f.

## 9.9. Спектр лапласіана

На сталих функціях:

**L_q 1 = 0.**

На Wⱼ:

**L_q f = τⱼ(q)f.**

Отже спектральна структура складається з:

* нульового власного значення;
* послідовності від'ємних власних значень τⱼ(q);
* кратності 2·3ʲ⁻¹ для кожного рівня j.

Оскільки:

τⱼ(q) → −c_q

при j → ∞,

точка −c_q є граничною точкою спектра.

Тому:

**Spec(L_q) = {0} ∪ {τⱼ(q) : j ≥ 1} ∪ {−c_q}.**

За q ∈ (0,1) граничне значення −c_q не є ізольованим власним значенням цього ієрархічного розкладу.

## 9.10. Теорема W7.3 — Скінченні наближення

Нехай L_q⁽ⁿ⁾ — оператор на просторі функцій, сталих на циліндрах глибини n, із нормованими вагами:

**wₙ(ξ,η) := 3⁻ⁿqˡ⁽ξ,η⁾.**

Тоді відповідні скінченні оператори є симетричними лапласіанами.

Для кожного фіксованого рівня j ≤ n їхні власні значення збігаються до τⱼ(q) при n → ∞.

Це забезпечує узгоджений перехід:

**скінченна ієрархія → нескінченний гільбертів простір.**

Важливо: цей результат стосується саме нормованого сімейства L_q⁽ⁿ⁾. Ненормовані матриці не мають автоматично скінченного спектрального граничного переходу.

# 14. Відомі обмеження

## 14.1. Межа та топологія

Розривність ∂ на всьому Tree∞ залежить від способу включення порожньої множини в простір значень.

У v0.2 це явно визначено через K₀(Σ), де ∅ ізольована.

Інші топології можуть давати іншу поведінку.

## 14.2. Розмірність

Формула:

dim_H(Σ) = ln 3 / αᵥ

стосується повного трійкового простору Σ.

Вона не є автоматично формулою розмірності межі довільного дерева ∂f.

Для конкретного f розмірність може бути меншою.

## 14.3. Ядра

Kₐₙ𝒸 і Kᵥₗ описують різні режими взаємодії.

Позитивна визначеність Kₐₙ𝒸 не постулюється.

Сингулярність Kᵥₗ вимагає окремого функціонально-аналітичного дослідження.

## 14.4. Спектральна теорія

Результати W7 стосуються Kₐₙ𝒸.

Вони не переносяться автоматично на Kᵥₗ.

## 14.5. Фізична інтерпретація

SUBIT-WARP є математичною моделлю ієрархічних структур.

Він не є фізичною теорією простору, часу, гравітації або квантових взаємодій.

Будь-яке фізичне застосування потребує окремих емпіричних припущень, операціоналізації та перевірки.

# 16. Підсумкова теза

SUBIT-WARP описує перехід від локальної структури до глобальної межі, а від межі — до геометрії, взаємодії та спектральної організації.

Його фундаментальна конструкція:

**Tree∞ → ℛ → Σ → K(Σ) → L²(Σ,μ) → Spec(L).**

У цьому ланцюгу кожен перехід має власні математичні умови.

Не кожне нескінченне дерево має непорожню межу.

Не кожен оператор межі є неперервним.

Не кожне ядро є обмеженим.

Не кожен скінченний спектр має коректну нескінченну границю.

Тому центральний принцип SUBIT-WARP залишається тим самим:

**DO NOT COLLAPSE — CONTEXTUALIZE.**

Локальна структура не зводиться до її межі; межа не зводиться до геометрії; геометрія не зводиться до спектра.

Вони пов'язані, але зберігають власні типи, параметри, інваріанти та умови коректності.

**Кінець специфікації SUBIT-WARP v0.2.**
