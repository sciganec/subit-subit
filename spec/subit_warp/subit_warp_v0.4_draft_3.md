# SUBIT-WARP v0.4

## W14 — Coupled Geometry–Interaction Operators

**Статус:** DRAFT · MATHEMATICALLY DERIVED · NOT FORMALLY VERIFIED
**Залежності:** W0–W13
**Мета:** дослідити суму, композицію та комутатор геометричного й інтеракційного операторів; визначити, чи містить їхня спільна спектральна структура додаткову інформацію про систему.

---

# W14.0. Постановка задачі

У W7 визначено оператор взаємодії:

`T𝑤 = T_q𝑤`

де:

`q𝑤 = exp(−α𝑤)`.

У W13 визначено геометричний оператор:

`Tᵥ = T_qᵥ`

де:

`qᵥ = exp(−sαᵥ)`.

Обидва оператори діють на одному просторі:

`H = L²(Σ_b, μ_b)`

де:

* `Σ_b = {1,...,b}^ℕ`;
* `b ≥ 2`;
* `μ_b` — рівномірна бернуллівська міра;
* `0 < q𝑤,qᵥ < 1`.

Їхні ядра:

`K𝑤(ξ,η) = q𝑤^ℓ(ξ,η)`

`Kᵥ(ξ,η) = qᵥ^ℓ(ξ,η)`.

Питання W14:

1. Чи комутують `T𝑤` і `Tᵥ`?
2. Який спектр їхньої суми?
3. Який спектр їхньої композиції?
4. Чи створює спільний оператор нову спектральну інформацію?
5. За яких умов можна відновити обидва параметри з комбінованого спектра?

# W14.1. Спільна ієрархічна декомпозиція

Нехай:

`H₀ ⊂ H₁ ⊂ H₂ ⊂ ...`

— послідовність підпросторів функцій, сталих на циліндрах відповідного рівня.

Визначимо:

`W₀ = H₀`

`Wⱼ = Hⱼ ⊖ Hⱼ₋₁`, `j ≥ 1`.

Тоді:

`H = ⊕ⱼ₌₀∞ Wⱼ`.

Розмірності:

`dim(W₀) = 1`

`dim(Wⱼ) = (b−1)b^(j−1)`.

Для кожного `q ∈ (0,1)` оператор `T_q` діє скалярно на кожному підпросторі:

`T_q|W₀ = c_q I`

`T_q|Wⱼ = λⱼ(q) I`.

Тут:

`c_q = (b−1)/(b−q)`

`λⱼ(q) = −(1−q)q^(j−1)/[b^(j−1)(b−q)]`.

Це означає, що всі оператори сімейства `{T_q : 0 < q < 1}` мають спільну систему власних підпросторів.

Власні функції можуть бути різними всередині кожного підпростору, але самі підпростори не залежать від `q`.

# W14.2. Теорема комутативності

### Теорема W14-T01 — Commutativity

Для будь-яких:

`q₁,q₂ ∈ (0,1)`

оператори:

`T_q₁` і `T_q₂`

комутують:

`T_q₁T_q₂ = T_q₂T_q₁`.

Отже:

`[T_q₁,T_q₂] = 0`.

Зокрема:

`[T𝑤,Tᵥ] = 0`.

**Доведення.**

На `W₀`:

`T_q₁T_q₂ = c_q₁c_q₂ I`.

Тому порядок композиції не має значення.

На кожному `Wⱼ`, `j ≥ 1`:

`T_q₁T_q₂ = λⱼ(q₁)λⱼ(q₂)I`.

Знову порядок композиції не має значення.

Оскільки:

`H = ⊕ⱼ₌₀∞ Wⱼ`,

оператори збігаються на щільній прямій сумі підпросторів, а отже, збігаються на всьому `H`.

Теорему доведено.

### Наслідок W14-C01

У межах однорідної b-арної моделі геометрія та взаємодія не породжують некомутативної операторної структури.

Це означає:

`[T𝑤,Tᵥ] = 0`

незалежно від значень `α𝑤`, `αᵥ` та `s`, якщо параметри належать допустимій області.

# W14.3. Сума операторів

Визначимо комбінований оператор:

`TΣ = T𝑤 + γTᵥ`

де:

`γ ≥ 0`

— коефіцієнт відносної ваги геометричного внеску.

На сталому підпросторі:

`TΣ|W₀ = (c_q𝑤 + γc_qᵥ)I`.

На ієрархічному підпросторі:

`TΣ|Wⱼ = [λⱼ(q𝑤) + γλⱼ(qᵥ)]I`.

Отже, власні значення:

`Λ₀ = c_q𝑤 + γc_qᵥ`

`Λⱼ = λⱼ(q𝑤) + γλⱼ(qᵥ)`.

Кратності залишаються незмінними:

`mⱼ = (b−1)b^(j−1)`.

### Теорема W14-T02 — Spectrum of the Coupled Sum

Оператор:

`TΣ = T_q₁ + γT_q₂`

є компактним, самоспряженим і слідовим.

Його спектр:

`Spec(TΣ) = {0} ∪ {Λ₀} ∪ {Λⱼ : j ≥ 1}`,

де:

`Λ₀ = c_q₁ + γc_q₂`

`Λⱼ = λⱼ(q₁) + γλⱼ(q₂)`.

Нуль є точкою накопичення.

**Доведення.**

Кожен із операторів `T_q₁` і `T_q₂` є компактним, самоспряженим та слідовим.

Сума двох компактних операторів компактна.

Сума двох самоспряжених операторів самоспряжена.

Сума двох операторів класу слідових операторів також належить класу слідових операторів.

Спільна ієрархічна декомпозиція дає наведені власні значення.

Теорему доведено.

### Зауваження

Для `γ ≥ 0` і `0 < q₁,q₂ < 1`:

`Λⱼ < 0`, `j ≥ 1`.

Однак комбінований оператор не обов'язково є додатно визначеним. Насправді його ієрархічні власні значення від'ємні.

---

# W14.4. Композиція операторів

Визначимо:

`TΠ = T𝑤Tᵥ`.

Оскільки оператори комутують, порядок композиції не має значення.

На `W₀`:

`TΠ|W₀ = c_q𝑤c_qᵥ I`.

На `Wⱼ`:

`TΠ|Wⱼ = λⱼ(q𝑤)λⱼ(qᵥ)I`.

Отже:

`Π₀ = c_q𝑤c_qᵥ`

`Πⱼ = λⱼ(q𝑤)λⱼ(qᵥ)`.

Оскільки обидва ієрархічні власні значення від'ємні:

`Πⱼ > 0`.

Таким чином, на відміну від окремих операторів, композиція є додатно визначеною.

### Теорема W14-T03 — Positivity of the Coupled Product

Для будь-яких `q₁,q₂ ∈ (0,1)`:

`T_q₁T_q₂ ≥ 0`.

**Доведення.**

Для довільного:

`f = f₀ + Σⱼ₌₁∞ fⱼ`

маємо:

`⟨f,T_q₁T_q₂f⟩`

`= c_q₁c_q₂‖f₀‖²`

`+ Σⱼ₌₁∞ λⱼ(q₁)λⱼ(q₂)‖fⱼ‖²`.

Усі коефіцієнти невід'ємні:

`c_q₁c_q₂ > 0`

`λⱼ(q₁)λⱼ(q₂) > 0`.

Отже:

`⟨f,T_q₁T_q₂f⟩ ≥ 0`.

Теорему доведено.

### Наслідок W14-C02

Композиція геометричного та інтеракційного операторів має невід'ємний спектр.

Це не означає, що кожен із вихідних операторів додатно визначений.

Потрібно розрізняти:

`T𝑤 ≱ 0`

`Tᵥ ≱ 0`

але:

`T𝑤Tᵥ ≥ 0`.

# W14.5. Явна формула композиційного спектра

Введемо:

`r₁ = q₁/b`

`r₂ = q₂/b`

`A₁ = (1−q₁)/(b−q₁)`

`A₂ = (1−q₂)/(b−q₂)`.

Тоді:

`λⱼ(q₁) = −A₁r₁^(j−1)`

`λⱼ(q₂) = −A₂r₂^(j−1)`.

Отже:

`Πⱼ = A₁A₂(r₁r₂)^(j−1)`.

Тобто:

`Πⱼ = [(1−q₁)(1−q₂)/((b−q₁)(b−q₂))] · (q₁q₂/b²)^(j−1)`.

Відношення сусідніх композиційних власних значень:

`Πⱼ₊₁/Πⱼ = q₁q₂/b²`.

Це означає, що композиційний спектр визначає добуток параметрів:

`q₁q₂`.

Але сам по собі не розділяє їх.

### Наслідок W14-C03

Окремі оператори містять інформацію про окремі параметри.

Їхня композиція зберігає лише добуткову комбінацію на рівні ієрархічних спектральних відношень.

Тому композицію не можна використовувати як єдине джерело відновлення обох параметрів.

# W14.6. Центровані оператори

У W7 визначено:

`L_q = T_q − c_q I`.

Це центрований оператор, для якого:

`L_q|W₀ = 0`

`L_q|Wⱼ = τⱼ(q)I`

де:

`τⱼ(q) = λⱼ(q) − c_q`.

Оскільки всі `L_q` мають ту саму систему власних підпросторів:

`[L_q₁,L_q₂] = 0`.

Визначимо:

`LΣ = L_q₁ + γL_q₂`.

Тоді:

`LΣ|W₀ = 0`

`LΣ|Wⱼ = [τⱼ(q₁)+γτⱼ(q₂)]I`.

При цьому:

`τⱼ(q) → −c_q`.

Отже:

`τⱼ(q₁)+γτⱼ(q₂) → −(c_q₁+γc_q₂)`.

Тому:

`Spec_ess(LΣ) = {−(c_q₁+γc_q₂)}`.

Це відрізняється від спектра компактного оператора `TΣ`, для якого нуль є точкою накопичення.

# W14.7. Чи створює комбінація нову інформацію?

Це центральне питання розділу.

Встановлено:

1. Сума операторів дає суму власних значень.
2. Композиція операторів дає добуток власних значень.
3. Комутатор дорівнює нулю.
4. Усі оператори зберігають ту саму ієрархічну декомпозицію.

Отже, у поточній моделі комбінування не створює нової системи власних підпросторів.

Проте сума може зберігати більше параметричної інформації, ніж композиція.

Розглянемо:

`Λⱼ = λⱼ(q₁)+γλⱼ(q₂)`.

Використовуючи:

`λⱼ(q) = −A(q)r(q)^(j−1)`,

де:

`A(q) = (1−q)/(b−q)`

`r(q) = q/b`,

отримуємо:

`−Λⱼ = A(q₁)r₁^(j−1) + γA(q₂)r₂^(j−1)`.

Це сума двох геометричних послідовностей.

Якщо:

* `γ` відомий;
* `q₁ ≠ q₂`;
* обидві компоненти спектрально роздільні;
* доступно достатньо точних послідовних власних значень,

то задача відновлення може бути зведена до задачі відновлення двох експоненційних компонент.

Однак це не автоматична гарантія ідентифікованості: потрібно враховувати перестановку компонентів, можливу близькість `q₁` та `q₂`, шум і виродження при `q₁=q₂`.

---

# W14.8. Теорема виродження двох параметрів

### Теорема W14-T04 — Degenerate Coupling

Якщо:

`q₁ = q₂ = q`,

то:

`TΣ = (1+γ)T_q`.

У цьому випадку комбінований оператор не містить окремої інформації про геометричний та інтеракційний параметри.

**Доведення.**

За умови `q₁=q₂`:

`TΣ = T_q + γT_q = (1+γ)T_q`.

Отже, спектр масштабується одним коефіцієнтом.

Теорему доведено.

### Наслідок W14-C04

Якщо геометричний та інтеракційний параметри дають однакове значення `q`, їх неможливо розділити лише за спектром суми.

Це ще один випадок параметричної неідентифікованості.

# W14.9. Розширення: некомутативне збурення

У поточній моделі:

`[T𝑤,Tᵥ] = 0`.

Щоб отримати нетривіальну некомутативну структуру, потрібно змінити хоча б одну з умов:

* рівномірність міри;
* однорідність дерева;
* радіальну залежність ядра лише від довжини спільного префікса;
* спільність ієрархічної фільтрації.

Можливий напрямок — ввести оператор:

`U : H → H`

який змінює або перемішує ієрархічні підпростори.

Тоді:

`Tᵥ' = U*TᵥU`

і дослідити:

`[T𝑤,Tᵥ']`.

Однак сам факт, що `U` є унітарним, ще не гарантує ненульового комутатора. Якщо `U` зберігає кожен `Wⱼ`, комутативність може зберегтися.

Необхідна умова для нетривіальної взаємодії — змішування підпросторів, на яких оператори мають різні спектральні значення.

### Дослідницька гіпотеза W14-H01

Для належно вибраного обмеженого оператора `U`, який змішує різні ієрархічні рівні:

`[T𝑤,U*TᵥU] ≠ 0`

у загальному випадку.

Це гіпотеза про розширену модель, а не доведений результат поточної специфікації.

# W14.10. Обчислювальна програма

Новий модуль:

`subit-warp-coupled`

### CPL-01 — Commutator Test

Обчислити:

`C = T_q₁T_q₂ − T_q₂T_q₁`.

Перевірити:

`‖C‖ ≈ 0`.

### CPL-02 — Sum Spectrum

Побудувати:

`TΣ = T_q₁ + γT_q₂`.

Порівняти чисельний спектр із:

`Λ₀ = c_q₁+γc_q₂`

`Λⱼ = λⱼ(q₁)+γλⱼ(q₂)`.

### CPL-03 — Product Spectrum

Перевірити:

`Π₀ = c_q₁c_q₂`

`Πⱼ = λⱼ(q₁)λⱼ(q₂)`.

### CPL-04 — Positivity Test

Для композиції перевірити:

`min Spec(T_q₁T_q₂) ≥ 0`

у скінченновимірних апроксимаціях.

### CPL-05 — Parameter Recovery

Відновити `q₁,q₂` із комбінованої суми за допомогою методу двох експоненційних компонент.

Порівняти відновлені параметри з початковими.

### CPL-06 — Degeneracy Test

Перевірити випадки:

* `q₁=q₂`;
* `q₁≈q₂`;
* `q₁≠q₂`;
* `γ=0`;
* `γ>0`.

### CPL-07 — Noncommutative Extension

Побудувати оператор `U`, що змішує ієрархічні рівні, та дослідити:

`[T_q₁,U*T_q₂U]`.

# W14.13. Висновок

У межах однорідної b-арної моделі геометричний та інтеракційний оператори мають спільну ієрархічну структуру.

Звідси випливає:

`[T𝑤,Tᵥ] = 0`.

Їхня сума зберігає від'ємний характер ієрархічних власних значень.

Їхня композиція є додатно визначеною.

Композиція кодує добуток параметрів, тоді як сума містить суму двох геометричних спектральних послідовностей.

Отже, W14 встановлює межу поточної архітектури:

**ОДНОРІДНА ІЄРАРХІЯ → СПІЛЬНА СПЕКТРАЛЬНА БАЗА → КОМУТАТИВНІСТЬ.**

Для переходу до некомутативної геометрії необхідно вийти за межі однорідної радіальної моделі.

`DO NOT COLLAPSE — CONTEXTUALIZE.`
