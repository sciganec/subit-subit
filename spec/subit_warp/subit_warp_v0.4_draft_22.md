# 4. Обов'язкові математичні інтеграції

Це центральний розділ W32.

## 4.1. C-11 — Zero-power convention

Для спадного ядра:

K_q(ξ,η) = q^ℓ(ξ,η)

необхідно явно визначити:

q⁰ = 1 для всіх q ∈ [0,1].

Зокрема:

0⁰ = 1

у контексті цього визначення ядра.

Це спеціальна математична конвенція для нульового показника, а не твердження про загальну арифметику степенів у довільному контексті.

Діагональ:

K_q(ξ,ξ) = 1.

**Рішення:** обов'язково внести до канонічного документа та майбутнього Lean-визначення.

## 4.2. C-12 — Ordered / Unordered Reconstruction

Необхідно розділити два типи структурної реконструкції.

**Unordered fingerprint:**

F(T) = (L,h,a).

Він визначає структуру дерева з точністю до відповідного класу ізоморфізму, що не зберігає порядок дочірніх гілок.

**Ordered fingerprint:**

F_ordered(T) = (L,h,a,p).

Тут p зберігає адресну інформацію.

Звідси випливають дві різні теореми:

- unordered reconstruction theorem;
- ordered reconstruction theorem.

Не можна стверджувати, що неупорядкований fingerprint відновлює адресну структуру.

Окремо повинні розглядатися:

- unary-вузли;
- дерево з одним коренем;
- відсутність дочірніх вершин;
- перестановки дочірніх гілок.

**Рішення:** два окремі твердження в канонічному документі та два окремі Lean-завдання.

## 4.3. C-13 — Trace Separation

Необхідно чітко розрізняти:

Скінченний слід:

Tr(T_q⁽ⁿ⁾).

Нескінченновимірний слід:

Tr(T_q).

Вони не є взаємозамінними.

Для скінченної апроксимації:

Tr(T_q⁽ⁿ⁾) = qⁿc_q.

Це не означає, що нескінченний оператор має той самий слід.

Для компактного оператора необхідно окремо встановити trace-class властивість, перш ніж використовувати слід у відповідному сенсі.

**Рішення:** заборонити перенесення формули скінченного сліду на нескінченний оператор без окремого доказу.

## 4.4. C-14 — Endpoint Separation

Необхідно розділити три режими.

| Режим | Математичний контекст |
|---|---|
| q = 0 | Окремий граничний оператор |
| 0 < q < 1 | Основний спектральний режим |
| q = 1 | Проєкційний граничний оператор |

Для q = 1:

T₁ = P_const.

Це не просто підстановка q = 1 у всі формули, виведені за припущенням 0 < q < 1.

Для q = 0:

необхідно окремо довести твердження про кратність нульового власного значення.

**Рішення:** окремі леми для обох кінцевих режимів.

## 4.5. C-15 — Kernel Threshold Separation

Для зростаючого ядра необхідно розділяти:

- умови існування інтегрального оператора;
- умови обмеженості;
- умови належності до класу Гільберта—Шмідта;
- умови компактності;
- умови trace-class.

Ці властивості не є еквівалентними.

Зокрема, критерій Гільберта—Шмідта не повинен автоматично використовуватися як критерій trace-class.

**Рішення:** кожен поріг має бути пов'язаний із власною теоремою та власними припущеннями.

# 5. Інтеграція результатів W25

W25 є важливим, але його статус необхідно визначати точно.

Він містить аналітичні результати та чисельні перевірки скінченних апроксимацій.

84 перевірені конфігурації не означають повного виконання W20.

## 5.1. Операторна збіжність

Необхідно зберегти розрізнення:

T_q → T₁ в операторній нормі.

Це не означає збіжності в trace norm.

## 5.2. Слідова збіжність

За результатами W25:

lim ‖T_q‖₁ = 2,

тоді як:

‖P_const‖₁ = 1.

Отже:

операторна збіжність ≠ слідова збіжність.

Цей результат повинен залишатися окремим твердженням.

Його аналітичний доказ необхідно зберігати окремо від чисельної перевірки.

# 6. Інтеграція W27 — Proof Closure

W27 повинен бути включений до доказового шару майбутнього канону.

Принципова вимога:

Не дублювати теореми з різними формулюваннями в декількох розділах.

Для кожної теореми необхідно мати:

- одне канонічне формулювання;
- один набір припущень;
- один доказовий ланцюг;
- посилання на залежності;
- окремий статус формальної перевірки.

Якщо доказ використовує додаткову умову, ця умова повинна бути присутня у формулюванні теореми.

Особливо це стосується:

- повної межі Tω⁺;
- boundary map;
- Lipschitz-оцінки;
- параметричної неперервності;
- спектральної декомпозиції.
