# SUBIT-WARP v0.4

## W13 — Metric Reconstruction and Geometry-Coupled Operators

**Статус:** DRAFT · MATHEMATICALLY DERIVED · NOT FORMALLY VERIFIED
**Залежності:** W0–W12
**Мета:** побудувати спектральний оператор, безпосередньо залежний від граничної метрики, та визначити умови відновлення геометричного параметра αᵥ.

---

# W13.0. Постановка задачі

У W12 встановлено:

`dᵥ(ξ,η) = exp(−αᵥℓ(ξ,η))`

`q = exp(−α𝑤)`.

Спектр оператора

`T_q f(ξ) = ∫Σ q^ℓ(ξ,η)f(η)dμ(η)`

не визначає `αᵥ`, оскільки `αᵥ` не входить до його визначення.

Для розв'язання цієї проблеми необхідно побудувати оператор, ядро якого залежить безпосередньо від `dᵥ`.

Основна ідея:

`Kᵥ,s(ξ,η) = dᵥ(ξ,η)^s`

де `s > 0` — незалежний параметр ядра.

Оскільки:

`dᵥ(ξ,η)^s = exp(−sαᵥℓ(ξ,η))`,

вводимо:

`qᵥ = exp(−sαᵥ)`.

Тоді:

`Kᵥ,s(ξ,η) = qᵥ^ℓ(ξ,η)`.

Таким чином, геометричний оператор має ту саму ієрархічну спектральну структуру, що й W7, але його спектральний параметр тепер визначається геометрією.

---

# W13.1. Визначення геометричного оператора

Нехай:

`Σ_b = {1,...,b}^ℕ`, `b ≥ 2`.

Міра:

`μ_b = (1/b,b/b,...,1/b)^ℕ`

тобто рівномірна бернуллівська міра з імовірністю `1/b` для кожного символу.

Гранична метрика:

`dᵥ(ξ,η) = exp(−αᵥℓ(ξ,η))`

для `ξ ≠ η`, а:

`dᵥ(ξ,ξ) = 0`.

Визначимо:

`Tᵥ,s : L²(Σ_b,μ_b) → L²(Σ_b,μ_b)`

`(Tᵥ,s f)(ξ) = ∫Σ_b dᵥ(ξ,η)^s f(η)dμ_b(η)`.

Еквівалентно:

`(Tᵥ,s f)(ξ) = ∫Σ_b exp(−sαᵥℓ(ξ,η))f(η)dμ_b(η)`.

Позначимо:

`qᵥ = exp(−sαᵥ)`.

Тоді:

`Tᵥ,s = T_(qᵥ)`.

Це не новий тип спектральної структури, а геометрично параметризований представник уже дослідженого сімейства операторів.

**Умова W13-A01:**

`αᵥ > 0`, `s > 0`, `b ≥ 2`.

Звідси:

`0 < qᵥ < 1`.

# W13.2. Теорема спектральної залежності від метрики

### Теорема W13-T01 — Metric-Coupled Spectrum

Для рівномірної b-арної межі та оператора `Tᵥ,s`:

Власне значення сталого підпростору:

`λ₀ᵥ = (b−1)/(b−qᵥ)`.

Ієрархічні власні значення:

`λⱼᵥ = −(1−qᵥ)qᵥ^(j−1) / [b^(j−1)(b−qᵥ)]`.

Кратності:

`mⱼ = (b−1)b^(j−1)`.

Спектр:

`Spec(Tᵥ,s) = {0} ∪ {λ₀ᵥ} ∪ {λⱼᵥ : j ≥ 1}`.

Точка `0` є точкою накопичення спектра.

Оскільки:

`qᵥ = exp(−sαᵥ)`,

усі ненульові власні значення залежать від `αᵥ`.

**Доведення.**

Ядро оператора:

`Kᵥ,s(ξ,η) = exp(−sαᵥℓ(ξ,η))`.

Воно збігається з ядром W7 за підстановки:

`q = exp(−sαᵥ)`.

Тому спектральні формули b-арної моделі з W12-T02 застосовуються без змін.

Теорему доведено.

# W13.3. Теорема відновлення геометричного параметра

### Теорема W13-T02 — Metric Parameter Recovery

Нехай:

* арність `b` відома;
* степінь ядра `s` відомий;
* міра `μ_b` є рівномірною;
* доступні два послідовні ненульові ієрархічні власні значення.

Тоді:

`qᵥ = b·λⱼ₊₁ᵥ/λⱼᵥ`.

Звідси:

`αᵥ = −ln(qᵥ)/s`.

Отже:

`αᵥ = −(1/s)ln(b·λⱼ₊₁ᵥ/λⱼᵥ)`.

**Доведення.**

З W12-T02:

`λⱼ₊₁ᵥ/λⱼᵥ = qᵥ/b`.

Тому:

`qᵥ = b·λⱼ₊₁ᵥ/λⱼᵥ`.

За визначенням:

`qᵥ = exp(−sαᵥ)`.

Беремо натуральний логарифм:

`ln(qᵥ) = −sαᵥ`.

Отже:

`αᵥ = −ln(qᵥ)/s`.

Теорему доведено.

### Наслідок W13-C01 — Hausdorff Dimension Recovery

Розмірність Гаусдорфа:

`Dᵥ = ln(b)/αᵥ`.

Підставляючи формулу відновлення:

`Dᵥ = s ln(b) / [−ln(qᵥ)]`.

Або безпосередньо через спектральні дані:

`Dᵥ = s ln(b) / [−ln(b·λⱼ₊₁ᵥ/λⱼᵥ)]`.

Таким чином, у межах заданої рівномірної b-арної моделі геометрична розмірність може бути відновлена зі спектра геометрично зв'язаного оператора.

Важливо: це відновлення одного геометричного параметра та розмірності в заданому сімействі метрик, а не реконструкція довільної метрики.

# W13.4. Проблема невідомого степеня s

Попередня теорема передбачає, що `s` відомий.

Якщо `s` невідомий, спектр визначає лише добуток:

`θ = sαᵥ`.

Оскільки:

`qᵥ = exp(−sαᵥ) = exp(−θ)`,

спектральні дані не дозволяють розділити `s` та `αᵥ`.

### Теорема W13-T03 — Exponent-Scale Non-identifiability

Якщо `s` та `αᵥ` є одночасно невідомими, оператор `Tᵥ,s` визначає лише їхній добуток:

`θ = sαᵥ`.

Для будь-якого `c > 0` пара параметрів:

`(s,αᵥ)`

і пара:

`(cs,αᵥ/c)`

задають однакове ядро та однаковий оператор.

**Доведення.**

Маємо:

`(cs)(αᵥ/c) = sαᵥ`.

Отже:

`exp(−cs·αᵥ/c·ℓ) = exp(−sαᵥℓ)`.

Ядра збігаються, тому збігаються оператори та їхні спектри.

Теорему доведено.

### Наслідок W13-C02

Для відновлення `αᵥ` необхідно мати хоча б одне незалежне джерело інформації про `s`.

Можливі варіанти:

1. Фіксація `s` у специфікації.
2. Незалежне калібрування `s`.
3. Використання кількох операторів із відомими степенями.
4. Зовнішнє метричне вимірювання.

Саме введення геометричного ядра не усуває автоматично всі проблеми ідентифікованості.

# W13.5. Геометричний спектральний профіль

Визначимо профіль:

`Gᵥ,s = (λ₀ᵥ, λ₁ᵥ, λ₂ᵥ, ..., m₁, m₂, ...)`.

Для нього справджуються:

### 1. Спектральне відношення

`Rᵥ = λⱼ₊₁ᵥ/λⱼᵥ = qᵥ/b`.

### 2. Геометричний параметр

`αᵥ = −ln(bRᵥ)/s`.

### 3. Розмірність межі

`Dᵥ = s ln(b)/[−ln(bRᵥ)]`.

### 4. Норма оператора

`‖Tᵥ,s‖ = (b−1)/(b−qᵥ)`.

### 5. Слідова норма

`‖Tᵥ,s‖₁ = 2(b−1)/(b−qᵥ)`.

### 6. Норма Гільберта—Шмідта

`‖Tᵥ,s‖²_HS = (b−1)/(b−qᵥ²)`.

### 7. Слід

`Tr(Tᵥ,s) = 0`.

### 8. Гранична поведінка

При:

`αᵥ → 0⁺`

маємо:

`qᵥ → 1⁻`.

При:

`αᵥ → ∞`

маємо:

`qᵥ → 0⁺`.

Ці граничні режими потрібно розглядати окремо від основної області `αᵥ > 0`.

# W13.6. Відмінність між параметричною та повною геометричною реконструкцією

W13 дозволяє відновити `αᵥ` за таких припущень:

* відома арність;
* відома міра;
* відомий степінь ядра;
* структура дерева належить до заданого однорідного сімейства.

Однак це не означає, що можна відновити довільний метричний простір за спектром одного оператора.

Необхідно розрізняти:

**Metric parameter recovery**

Відновлення параметра `αᵥ` у відомій моделі.

**Metric dimension recovery**

Відновлення `Dᵥ` за відомих `b` та `s`.

**Metric reconstruction**

Відновлення самої метрики як функції двох точок.

**Topological reconstruction**

Відновлення топологічної структури межі.

Перші два результати встановлені в межах цієї моделі.

Останні два не випливають із наведених формул.

# W13.7. Незалежність геометрії та взаємодії

Зберігаємо два оператори:

`T𝑤 = T_q`, де `q = exp(−α𝑤)`,

`Tᵥ,s = T_(qᵥ)`, де `qᵥ = exp(−sαᵥ)`.

Їхні спектральні параметри:

`q = exp(−α𝑤)`

`qᵥ = exp(−sαᵥ)`.

Це дозволяє досліджувати співвідношення між взаємодією та геометрією без ототожнення їхніх параметрів.

Визначимо:

`R_cross = qᵥ/q`.

Тоді:

`R_cross = exp(α𝑤 − sαᵥ)`.

Це допоміжний безрозмірний параметр порівняння двох масштабів.

Він не є універсальним фізичним законом і не повинен отримувати таку інтерпретацію без окремої моделі.

**Архітектурне правило W13-R01:**

`GEOMETRY ≠ INTERACTION`.

`Tᵥ,s ≠ T𝑤` загалом.

Збіг операторів можливий лише за умови:

`sαᵥ = α𝑤`.

Це умова параметричного збігу, а не твердження про тотожність геометрії та взаємодії.

# W13.8. Обчислювальна програма

Новий модуль:

`subit-warp-geometry`

## GEO-01 — Metric Spectrum

Вхід:

* `b`;
* `αᵥ`;
* `s`;
* максимальний рівень `n`.

Вихід:

* `qᵥ`;
* `λ₀ᵥ`;
* `λ₁ᵥ,...,λₙᵥ`;
* кратності.

## GEO-02 — Metric Recovery

Вхід:

* `b`;
* `s`;
* послідовність власних значень.

Вихід:

* `q̂ᵥ`;
* `α̂ᵥ`;
* `D̂ᵥ`;
* залишки відновлення.

## GEO-03 — Scale Ambiguity

Побудувати дві пари:

`(s,αᵥ)`

`(cs,αᵥ/c)`.

Перевірити збіг операторів.

## GEO-04 — Geometry/Interaction Separation

Побудувати `T𝑤` та `Tᵥ,s` з незалежними параметрами.

Перевірити:

* збіг спектрів при `α𝑤=sαᵥ`;
* відмінність спектрів при `α𝑤≠sαᵥ`.

## GEO-05 — Dimension Recovery

Порівняти:

`Dᵥ = ln(b)/αᵥ`

із:

`D̂ᵥ = s ln(b)/[−ln(q̂ᵥ)]`.

## GEO-06 — Noise Sensitivity

Дослідити похибку відновлення `αᵥ` при збуренні малих власних значень.

Окремо перевірити стабільність оцінювання за різних рівнів `j`.

# W13.11. Висновок

W12 встановив, що спектр оператора взаємодії не визначає геометричний масштаб межі.

W13 показує, що геометричний параметр можна зробити спектрально ідентифікованим, якщо безпосередньо включити метрику до ядра оператора.

Основна формула:

`αᵥ = −ln(b·λⱼ₊₁ᵥ/λⱼᵥ)/s`.

Однак відновлення можливе лише за незалежно заданого `s`.

Отже:

`SPECTRAL DATA + KNOWN KERNEL SCALE → METRIC PARAMETER`.

Але:

`SPECTRAL DATA ALONE ↛ ARBITRARY METRIC`.

Це принципова межа реконструкції.

W13 розширює SUBIT-WARP від спектрального аналізу взаємодії до спектрального аналізу геометрії, не ототожнюючи ці два рівні.
