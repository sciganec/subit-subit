# 3. BLOCKER-01 — канонічна міра μ

Це найважливіше уточнення для W6–W8.

У попередніх формулах використовується:

μ(Cσ) = 3⁻ⁿ.

Це означає, що μ має бути рівномірною добутковою мірою на просторі:

Σ = {1,2,3}ᴺ.

Тобто:

**μ = (⅓,⅓,⅓)ᴺ.**

Якщо ця умова не зафіксована в W0–W4, усі наступні інтегральні та спектральні формули мають приховане припущення.

### Чому це критично?

Формула:

P(ℓ(ξ,η)=k) = 2/3ᵏ⁺¹

використовується для отримання:

c_q = 2/(3 − q).

Якщо замінити рівномірну міру на нерівномірну:

p = (p₁,p₂,p₃),

де p₁+p₂+p₃=1,

то ймовірність точного спільного префікса довжини k буде:

P(ℓ=k) = (1 − s₂)s₂ᵏ,

де:

s₂ = p₁²+p₂²+p₃².

Тоді інтегральна константа стане:

**c_q(p) = (1 − s₂)/(1 − qs₂).**

Для рівномірної міри:

s₂ = 1/3,

і ми повертаємося до:

c_q = 2/(3 − q).

Отже, спектральні формули W7 залежать не лише від трійкового дерева, а й від конкретної міри.

### Рішення

У специфікації необхідно додати:

**Canonical Measure Axiom**

μ = (⅓,⅓,⅓)ᴺ.

Для кожного σ ∈ Bⁿ:

μ(Cσ)=3⁻ⁿ.

Усі результати W6–W8 мають посилатися на цю умову.

Це не просто технічна деталь. Це частина математичної структури SUBIT-WARP.

# 4. BLOCKER-02 — Boundary Operator і параметр αᵥ

Попередня версія W5 використовувала твердження:

Lip(∂) ≤ 2

для αᵥ = ln 2.

Це твердження не можна автоматично переносити на всі αᵥ > 0.

Маємо:

dᵥ = d_Sᵞ,

де:

γ = αᵥ/ln 2.

Якщо для базової метрики доведено:

d_H,S(∂f,∂g) ≤ 2d_S(f,g),

то для нової метрики:

d_H,ᵥ(∂f,∂g)
≤ [2d_S(f,g)]ᵞ.

Отже:

**d_H,ᵥ(∂f,∂g) ≤ 2ᵞd_S(f,g)ᵞ.**

Це дає три режими.

| αᵥ            |         γ | Регулярність              |
| ------------- | --------: | ------------------------- |
| αᵥ > ln 2     |     γ > 1 | Lipschitz із константою 2 |
| αᵥ = ln 2     |     γ = 1 | Lipschitz із константою 2 |
| 0 < αᵥ < ln 2 | 0 < γ < 1 | Hölder із показником γ    |

Для αᵥ > ln 2 наведена оцінка також дає Lipschitz-константу 2, оскільки діаметр простору не перевищує 1.

Для αᵥ < ln 2 загальна Lipschitz-оцінка з базовою метрикою не випливає, але зберігається Hölder-оцінка.

### Архітектурне рішення

W5 необхідно розділити на два результати:

* **W5-A:** Lipschitz continuity при αᵥ ≥ ln 2;
* **W5-B:** Hölder continuity при 0 < αᵥ < ln 2.

Це важливе уточнення: геометричний параметр впливає не тільки на розмірність межі, але й на регулярність оператора межі.

# 5. BLOCKER-03 — обернене ядро K_Vl

У W6 та W9 розглядається:

K_Vl(ξ,η) = exp(α𝑤ℓ(ξ,η)).

У попередній редакції було доведено умову інтегровності:

α𝑤 < ln 3.

Це правильно, але для операторної теорії недостатньо просто назвати ядро інтегровним.

Потрібно визначити, в якому класі операторів воно працює.

## 5.1. Умова L¹-інтегровності

Маємо:

∫Σ K_Vl(ξ,η)dμ(η)
= 2/(3 − eᵅʷ).

Ця величина скінченна тоді й лише тоді, коли:

**α𝑤 < ln 3.**

## 5.2. Умова Гільберта — Шмідта

Для квадратичної інтегровності необхідно:

∫Σ×Σ |K_Vl|² d(μ×μ) < ∞.

Аналогічний геометричний ряд тепер має знаменник e²ᵅʷ/3.

Тому:

**α𝑤 < (ln 3)/2.**

Це суворіша умова.

## 5.3. Обмеженість оператора на L²

Оскільки ядро симетричне й невід'ємне, за умови обмеженості його інтегралів за рядками та стовпцями можна застосувати критерій Шура.

Отже, за:

α𝑤 < ln 3

інтегральний оператор, визначений цим ядром, є обмеженим на L².

Але він не обов'язково є оператором Гільберта — Шмідта.

### Підсумкова таблиця

| Властивість K_Vl                  | Умова          |
| --------------------------------- | -------------- |
| L¹-інтегровність за кожним рядком | α𝑤 < ln 3     |
| Обмеженість оператора на L²       | α𝑤 < ln 3     |
| Гільберт — Шмідт                  | α𝑤 < (ln 3)/2 |
| Формула інтеграла                 | 2/(3 − eᵅʷ)    |

**Рекомендація:** W6 повинен окремо визначити операторний статус K_Vl. Не можна переносити результати спектрального аналізу спадного ядра K_q на обернене ядро без нового доведення.

# 6. Новий результат: T_q є оператором слідового класу

Це додатковий результат, який варто включити до W7.

Раніше було доведено, що T_q є оператором Гільберта — Шмідта.

Але спектральні формули дають сильніше твердження.

Маємо:

λ₀ = c_q,

λⱼ = −(1 − q)qʲ⁻¹/[3ʲ⁻¹(3 − q)],

mⱼ = 2·3ʲ⁻¹.

Розглянемо суму модулів власних значень з урахуванням кратності:

Σⱼ₌₀∞ mⱼ|λⱼ|.

Для несталих рівнів:

Σⱼ₌₁∞ 2·3ʲ⁻¹ · (1 − q)qʲ⁻¹/[3ʲ⁻¹(3 − q)]

= 2(1 − q)/(3 − q) · Σⱼ₌₀∞qʲ

= 2/(3 − q).

Але:

c_q = 2/(3 − q).

Тому:

Σⱼ₌₀∞ mⱼ|λⱼ| = 2c_q.

Отже:

**T_q належить до слідового класу S₁.**

Тобто він не просто компактний і не просто Гільберт — Шмідта.

Він є trace-class оператором.

### 6.1. Точна норма сліду

Оскільки оператор самоспряжений:

‖T_q‖₁ = Σⱼ mⱼ|λⱼ|.

Отже:

**‖T_q‖₁ = 4/(3 − q).**

### 6.2. Слід оператора

Слід:

Tr(T_q) = c_q + Σⱼ₌₁∞mⱼλⱼ.

Оскільки сума від'ємних власних значень із кратностями дорівнює −c_q:

**Tr(T_q) = 0.**

Це узгоджується з тим, що ядро дорівнює нулю на діагоналі.

### 6.3. Норма Гільберта — Шмідта

Також:

‖T_q‖²_HS = ∫Σ×Σ |K_q|² d(μ×μ).

Тому:

**‖T_q‖²_HS = 2/(3 − q²).**

Це дає ще один незалежний інваріант для чисельних тестів W10.

### 6.4. Essential spectrum нормалізованого оператора

Оскільки:

L_q = T_q − c_qI,

а T_q компактний, за теоремою Вейля:

**Spec_ess(L_q) = {−c_q}.**

Отже, точка −c_q має точніший статус, ніж просто гранична точка спектра: вона є єдиною точкою істотного спектра.

Вона не є власним значенням L_q.

Це варто прямо зазначити у W7.

# W11. GLOBAL CONSISTENCY AND THEOREM DEPENDENCY REGISTRY

**Status:** INTEGRATION SPECIFICATION · MATHEMATICAL REFINEMENT REQUIRED BEFORE STABLE RELEASE.

## W11.1. Purpose

W11 establishes global consistency across W0–W10.

Its purpose is to ensure that:

1. All modules use compatible definitions.
2. All theorems declare their dependencies.
3. All implicit assumptions become explicit.
4. Numerical and formal verification statuses remain distinct.
5. No theorem is used outside its established domain.

W11 does not introduce a new independent mathematical structure.

It coordinates the existing architecture.

## W11.2. Canonical measure

Let:

Σ = {1,2,3}ᴺ.

The canonical measure is the uniform Bernoulli product measure:

μ = (⅓,⅓,⅓)ᴺ.

For every finite address σ of length n:

μ(Cσ) = 3⁻ⁿ.

All integral, kernel, and spectral results in W6–W8 refer to this measure unless explicitly stated otherwise.

The spectral formulas derived under μ must not be transferred to arbitrary probability measures without a separate proof.

## W11.3. Metric conventions

Define:

ℓ(ξ,η) = length of the longest common prefix,

with:

ℓ(ξ,ξ) = ∞.

For 0 < q < 1:
