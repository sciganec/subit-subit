# 1. W0 — структурна основа

## W24.16.1. Типізація дерева

У первинному v0.3 задано:

- алфавіт значень: `A = {00, 01, 10, 11}`;
- алфавіт адрес: `B = {1, 2, 3}`;
- множина адрес: `Pos = B^{<ω}`;
- множина міток: `Λ = {None, node} ∪ {leaf(a) : a ∈ A}`.

Дерево — функція:

`f : Pos → Λ`

з умовами T1–T4.

Ключові умови:

`f(ε) ≠ None`

`f(σ)=node ⇒ f(σ·i)≠None`

`f(σ)=leaf(a) ⇒ f(σ·i)=None`

`f(σ)=None ⇒ f(σ·τ)=None`

### Знахідка W24.16-01 — PASS WITH CONDITIONS

Первинна модель не є моделлю довільного часткового трійкового дерева.

Умова T2 вимагає, щоб кожен внутрішній вузол мав рівно три наявні дочірні позиції. Умова T3 забороняє нащадків листка, а T4 поширює відсутність на всі наступні позиції.

Тому первинна модель описує **повні за розгалуженням дерева**, в яких:

- внутрішній вузол має три дочірні піддерева;
- листок завершує відповідну гілку;
- нескінченна гілка може не мати листка;
- відсутні позиції не можуть виникати безпосередньо під внутрішнім вузлом.

Це узгоджується з коалгебраїчним означенням:

`F_tree(X) = A ⊔ X³`

`Tree∞ ≅ A ⊔ Tree∞³`

Тут важливо не ототожнювати `Tree∞` із простором усіх можливих часткових дерев.

### Що зробив W23

W23 розділив:

`FullTree_A ≅ Leaf(A) ⊔ Node(FullTree_A^b)`

і

`PartialTree_A ≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A)^b`.

Це правильне концептуальне розширення, але воно не є просто переписуванням первинного v0.3. W23 вводить додатковий тип дерев.

**Необхідна поправка до W23:** чітко вказати, що `PartialTree` — нове розширення моделі, а не прихований зміст початкового `Tree∞`.

`Tree∞ ≅ A ⊔ Tree∞³`

`out : Tree∞ → A ⊔ Tree∞³`.

Твердження W0.1: `Tree∞` є фінальною коалгеброю для `F_tree`.

## W24.16.3. Межа дерева

Первинне означення:

`∂f = {ξ ∈ Σ : ∀n≥0, f(ξ|n)=node}`.

Це означає, що кожен скінченний префікс нескінченної адреси має відповідати внутрішньому вузлу.

### Знахідка W24.16-03 — PASS

Означення коректне для первинного `Tree∞`.

Воно правильно розрізняє:

- скінченні листки;
- нескінченні гілки;
- повну межу `Σ`;
- порожню межу `∅`.

Важлива деталь: умова включає `n=0`, отже перевіряється і корінь.

Якщо корінь є листком, то:

`∂f = ∅`.

Це правильна поведінка.

### Що потрібно уточнити

W23 правильно формалізує межу через внутрішні вузли на всіх префіксах. Однак необхідно зберегти первинне розрізнення між деревом і його межею.

Межа — множина нескінченних адрес, а не множина всіх листків дерева.

**Рішення:** зберегти означення W23, але додати явне посилання на T1–T4 як первинну семантику дерева.

# 2. W1 — причинна фільтрація та метрика дерев

Це один із найважливіших результатів аудиту.

У W24 було заявлено, що метрика на просторі дерев потребує первинного означення. Але в оригінальному v0.3 таке означення вже присутнє.

## W24.16.4. Метрика на деревах

Первинне означення:

`r_addr(f,g) = min{|σ| : f(σ) ≠ g(σ)}`

Якщо `f=g`:

`r_addr(f,f)=∞`.

Метрика:

`d_S(f,g)=2^{-r_addr(f,g)}`.

### Знахідка W24.16-04 — PASS

Це коректна ультраметрика на `Tree∞`.

Якщо два дерева різні, існує перша адреса, на якій їхні мітки відрізняються.

Тому:

- невід’ємність виконується;
- `d_S(f,g)=0` тоді й лише тоді, коли `f=g`;
- симетричність очевидна;
- ультраметрична нерівність випливає з властивості першої відмінної позиції.

Отже, твердження W24 про відсутність первинної метрики на просторі дерев є **помилковим**.

### Знахідка W24.16-05 — CORRECT

У v0.3 існує метрика дерев `d_S`, але її назва збігається з позначенням, яке W23 використовує для метрики адрес.

Це не математична суперечність, але це **термінологічний конфлікт, який потрібно усунути**.

Рекомендована канонічна схема:

| Об’єкт | Позначення |
|---|---|
| Нескінченні адреси | `d_Σ` |
| Дерева як функції на `Pos` | `d_F` |
| Листки скінченного дерева | `d_T` |
| Граничні множини | `d_H` |

Тоді:

`d_F(f,g)=2^{-r_addr(f,g)}`

`d_Σ(ξ,η)=2^{-ℓ(ξ,η)}`

Це дозволить не змішувати метрику на деревах із метрикою на нескінченних адресах.

У v0.3 стверджується, що `Tree∞` є компактним, повним і обмеженим.

Це твердження можна обґрунтувати незалежно від посилання на базову систему.

`Tree∞` компактний.

Звідси також випливає повнота метричного простору.

### Знахідка W24.16-06 — PASS

Математичне твердження v0.3 коректне.

Однак твердження про наявність відповідного Lean-звіту не можна вважати підтвердженим без самого артефакту.

## W24.16.6. Компактність простору операторів ℛ₀

Первинний текст визначає:

`ℛ₀ = {ρ : Tree∞ → Tree∞ : Lip(ρ)≤1}`

та

`d_ℛ(ρ,σ)=sup_f d_F(ρ(f),σ(f))`.

Твердження W1.1: простір `ℛ₀` компактний.

### Знахідка W24.16-07 — PASS WITH CONDITIONS

Тут можна застосувати теорему Арцела—Асколі.

Маємо:

1. компактну область визначення `Tree∞`;
2. компактний цільовий простір `Tree∞`;
3. рівномірно еквінеперервну сім’ю 1-Lipschitz-відображень;
4. замкненість умови `Lip(ρ)≤1` щодо рівномірної збіжності.

Отже, `ℛ₀` компактний у метриці рівномірної збіжності.

Це математично коректно.

**Уточнення:** якщо твердження позначається `BASE-INHERITED`, це не повинно створювати враження, що сам текст v0.3 містить повний формальний доказ або що наявність Lean-артефакту вже перевірена.

## W24.16.7. Фільтрація стискання

Первинне означення:

`ℛ^(m) = {ρ∈ℛ₀ : Lip(ρ)≤2^{-m}}`.

Теорема:

`ℛ^(m) ∘ ℛ^(k) ⊆ ℛ^(m+k)`.

### Знахідка W24.16-08 — PASS

Доведення коректне:

`d_F(ρ(σ(f)),ρ(σ(g)))`

`≤ 2^{-m}d_F(σ(f),σ(g))`

`≤ 2^{-(m+k)}d_F(f,g)`.

Звідси:

`Lip(ρ∘σ)≤2^{-(m+k)}`.

Теорема W1.3 також правильна:

`⋂_{m≥0}ℛ^(m)=Const(Tree∞)`.

Тут немає виявленої математичної помилки.

# 3. W2 — grafting та нерухома точка

## W24.16.8. Точне масштабування

Первинне означення:

`ρₐ(f)=node(f,leaf(a),leaf(a))`.

Для різних `f,g`:

`r_addr(ρₐ(f),ρₐ(g))=r_addr(f,g)+1`.

Звідси:

`d_F(ρₐ(f),ρₐ(g))=½d_F(f,g)`.

### Знахідка W24.16-09 — PASS

Формула правильна.

Додавання нового кореня зміщує всі адреси початкового дерева на один рівень. Відповідно, перша відмінність також зміщується на один рівень.

Тому:

`Lip(ρₐ)=½`.

## W24.16.9. Теорема Банаха

У v0.3 застосування теореми Банаха обґрунтовується повнотою `Tree∞`.

### Знахідка W24.16-10 — PASS

Оскільки:

- `Tree∞` непорожній;
- `Tree∞` повний;
- `ρₐ:Tree∞→Tree∞`;
- `Lip(ρₐ)=½<1`;

існує єдина нерухома точка `pₐ`.

Оцінка:

`d_F(ρₐⁿ(f),pₐ)≤2^{-n}d_F(f,pₐ)`

також коректна.

Результат W2 можна залишити без зміни суті.

З рівності:

`pₐ=node(pₐ,leaf(a),leaf(a))`

випливає, що єдина нескінченна гілка проходить через першу дочірню позицію на кожному рівні.

Тому:

`∂pₐ={1111…}`.

### Знахідка W24.16-11 — PASS

Результат коректний.

Він також правильно демонструє розривність оператора межі на всьому просторі дерев.

Цей приклад потрібно зберегти як нормативний контрприклад до глобальної неперервності.

# 4. W3–W4 — геометрія межі та розмірність

## W24.16.11. Ультраметрика межі

Первинне означення:

`d_v(ξ,η)=exp(−α_vℓ(ξ,η))`

для `ξ≠η`, де `α_v>0`.

### Знахідка W24.16-12 — PASS

Ультраметрична нерівність випливає з:

`ℓ(ξ,ζ)≥min(ℓ(ξ,η),ℓ(η,ζ))`.

Отже:

`d_v(ξ,ζ)≤max(d_v(ξ,η),d_v(η,ζ))`.

Усі метричні властивості виконуються.

Топологічна інваріантність щодо додатного параметра також правильна: усі метрики цього сімейства породжують одну й ту саму топологію.

## W24.16.12. Компактність повного простору адрес

`Σ={1,2,3}^ℕ`.

Оскільки це зліченний добуток скінченних компактних просторів, `Σ` компактний.

### Знахідка W24.16-13 — PASS

Твердження правильне.

Однак W24 має одну редакційну неточність: у цьому контексті не потрібно називати метрику адрес `d_S`, якщо ця назва вже використовується для метрики дерев у первинному v0.3.

## W24.16.13. Hausdorff dimension

Первинна теорема:

`dim_H(Σ,d_v)=ln3/α_v`.

### Знахідка W24.16-14 — PASS WITH CONDITIONS

Результат правильний для повного однорідного трійкового простору.

Кількість циліндрів рівня `n` дорівнює `3ⁿ`, а діаметр кожного:

`diam(C(σ))=exp(−α_v n)`.

Критичний показник визначається умовою:

`3ⁿ exp(−α_v s n)≈1`.

Тому:

`s=ln3/α_v`.

**Уточнення до доказу:** нижня оцінка в v0.3 подана занадто стисло. Формулювання про «кулю радіуса порядку» потрібно замінити точною оцінкою міри циліндричних куль або аргументом масового розподілу з явно зазначеними константами.

Це не спростовує теорему, але первинний доказ варто посилити.

# 5. W5 — оператор межі

Саме тут виявлено головну математичну проблему первинного тексту.

## W24.16.14. Простір компактних множин

У v0.3:

`K(Σ)={K⊆Σ : K непорожня і компактна}`

`K₀(Σ)=K(Σ)∪{∅}`

і:

`d₀(∅,A)=2`

для кожної непорожньої компактної множини `A`.

Оскільки:

`diam(Σ)≤1`,

додавання ізольованої точки з відстанню 2 утворює метричний простір.

### Знахідка W24.16-15 — PASS

Твердження про метричність і компактність `K₀(Σ)` правильне.

Важливо зберегти застереження W23: це спеціальна метрика на розширенні простору компактів, а не стандартна Hausdorff-метрика, застосована до порожньої множини без додаткових домовленостей.

## W24.16.15. Замкненість Tω

Первинне означення:

`Tω={f∈Tree∞ : кожен внутрішній вузол має хоча б одну нескінченну гілку нижче себе}`.

Доказ замкненості використовує лему Кеніга.

### Знахідка W24.16-16 — PASS WITH CONDITIONS

Аргумент загалом правильний.

Якщо `f_n→f`, то мітки на кожній скінченній множині адрес стабілізуються. Для кожного внутрішнього вузла граничного дерева можна побудувати префіксне дерево можливих продовжень довільної глибини.

Оскільки розгалуження скінченне, лема Кеніга дає нескінченну гілку.

Отже, властивість зберігається в границі.

Проте саме означення Tω має дефект.

### Знахідка W24.16-17 — CORRECT

Умова «кожен внутрішній вузол має хоча б одну нескінченну гілку» виконується вакуумно для дерева, яке взагалі не має внутрішніх вузлів.

Зокрема, для дерева:

`f=leaf(a)`

маємо:

`f∈Tω`

але:

`∂f=∅`.

Отже, первинне означення Tω **не гарантує непорожності межі**.

Це критично, оскільки теорема W5.4 використовує Hausdorff-метрику `d_H` на просторі непорожніх компактних множин `K(Σ)`.

Для `f=leaf(a)` вираз:

`d_H(∂f,∂g)`

не визначений у первинній системі, якщо `∂g` непорожня.

### Необхідне виправлення

Запровадити:

`Tω⁺={f∈Tree∞ : ∂f≠∅ і кожен внутрішній вузол має хоча б одну нескінченну гілку нижче себе}`.

Тоді:

`Tω⁺={f∈Tω : ∂f≠∅}`.

Це усуває вакуумний випадок кореня-листка.

Важливо: `Tω⁺` також є замкненим, оскільки:

1. `Tω` замкнений;
2. множина дерев із непорожньою межею замкнена в метриці першої відмінності.

Останній пункт можна довести через лему Кеніга та стабілізацію скінченних префіксів.

## W24.16.16. Lipschitz-теорема W5.4

Первинне твердження:

`d_H(∂f,∂g)≤2d_F(f,g)`

для `f,g∈Tω`, за умови `α_v=ln2`.

### Знахідка W24.16-18 — PASS AFTER DOMAIN CORRECTION

Сам доказ оцінки правильний за умови, що обидві межі непорожні.

Нехай:

`m=r_addr(f,g)`.

Якщо `ξ∈∂f`, але `ξ∉∂g`, то перша відмінність виникає на рівні не раніше `m`.

У відповідному попередньому вузлі дерева `g` існує інша нескінченна гілка. Вона збігається з `ξ` щонайменше до рівня `m−1`.

Звідси:

`dist(ξ,∂g)≤2^{-(m-1)}`

і тому:

`dist(ξ,∂g)≤2·2^{-m}`.

Оскільки:

`d_F(f,g)=2^{-m}`,

одержуємо потрібну оцінку.

Симетричний аргумент завершує доведення.

### Канонічне виправлене формулювання

> **Теорема W5.4′.** Для всіх `f,g∈Tω⁺`, за умови `α_v=ln2`, виконується:
>
> `d_H(∂f,∂g)≤2d_F(f,g)`.
>
> Отже, відображення межі `∂:Tω⁺→K(Σ)` є 2-Lipschitz.

Це виправлення не змінює суті результату, але робить його коректним за областю визначення.

# 6. W6 — ядра взаємодії

## W24.16.17. Спадне ядро

Первинне означення:

`K_anc(ξ,η)=q^{ℓ(ξ,η)}` для `ξ≠η`

`K_anc(ξ,ξ)=0`

де:

`q=exp(−α_w)`, `0<q<1`.

### Знахідка W24.16-19 — PASS

Ядро обмежене:

`0≤K_anc≤1`.

Воно симетричне та належить `L²(Σ×Σ)`.

Тому інтегральний оператор на `L²(Σ,μ)` є Hilbert–Schmidt, отже компактним і обмеженим.

Симетричність дійснозначного ядра забезпечує самоспряженість оператора.

Важливо: позитивна визначеність ядра не випливає автоматично з цих властивостей. Первинне v0.3 правильно не заявляє її.

## W24.16.18. Зростаюче ядро

Первинне означення:

`K_Vl(ξ,η)=exp(α_wℓ(ξ,η))`

для `ξ≠η`.

Імовірність спільного префікса довжини рівно `k`:

`P(ℓ(ξ,η)=k)=2/3^{k+1}`.

Тому:

`∫K_Vl(ξ,η)dμ(η)`

`=2/3 · Σₖ₌₀∞ (exp(α_w)/3)^k`.

Звідси:

`α_w<ln3`.

### Знахідка W24.16-20 — PASS

Формула інтегровності правильна.

За цієї умови:

`∫K_Vl(ξ,η)dμ(η)=2/(3−exp(α_w))`.

W23 правильно узагальнює результат на довільне `b`:

`α_w<ln b`.

Для Hilbert–Schmidt-властивості потрібна сильніша умова:

`α_w<(ln b)/2`.

### Знахідка W24.16-21 — CORRECT

У v0.3 діагональ зростаючого ядра описана як така, що не має скінченного значення.

Це недостатньо точне означення для подальшої операторної роботи.

Оскільки діагональ має нульову міру щодо добуткової міри `μ×μ`, її значення не змінює відповідний інтегральний оператор як елемент класу ядер, що збігаються майже всюди.

Проте канонічна специфікація має вибрати одну домовленість:

- `K_Vl(ξ,ξ)=0`; або
- `K_Vl(ξ,ξ)=+∞` як розширене значення з окремим зазначенням, що діагональ має нульову міру.

W23 обирає перший варіант. Це зручніше для обчислювальної реалізації та не змінює інтегральних властивостей оператора.
