# 0. СТАТУС І ПРИЗНАЧЕННЯ

## 0.1. Мета

SUBIT-WARP досліджує взаємозв'язок між п'ятьма математичними рівнями:

1. структурою скінченних та нескінченних дерев;
2. простором причинних перетворень;
3. геометрією нескінченних граничних гілок;
4. операторами взаємодії на просторі меж;
5. спектральними властивостями ієрархічних операторів.

Основна дослідницька гіпотеза:

**Структурна ієрархія дерева індукує геометрію його межі, а геометрія межі дозволяє побудувати оператори, спектр яких відображає ієрархічну організацію початкової структури.**

Це математична дослідницька програма, а не твердження про вже встановлений фізичний механізм.

# 1. W0 — STRUCTURAL SUBSTRATE

## 1.1. Алфавіти

Використовуються два різні алфавіти.

Алфавіт значень:

`A = {00, 01, 10, 11}`.

Алфавіт адрес:

`B = {1, 2, 3}`.

Вони мають різні функції:

* A визначає значення листків;
* B визначає позиції у дереві.

Простір адрес:

`Pos = B^{<ω}`.

Порожня адреса:

`ε ∈ Pos`.

Конкатенація адрес:

`σ·i`, де `σ ∈ Pos`, `i ∈ B`.

## 1.2. Алфавіт міток

`Λ = {None, node} ∪ {leaf(a) : a ∈ A}`.

Кількість міток:

`|Λ| = 6`.

Інтерпретація:

| Мітка   | Значення              |
| ------- | --------------------- |
| None    | Відсутня позиція      |
| node    | Внутрішній вузол      |
| leaf(a) | Листок зі значенням a |

## 1.3. Простір дерев

`Tree∞` — множина функцій:

`f : Pos → Λ`

які задовольняють умови:

**T1. Непорожній корінь**

`f(ε) ≠ None`.

**T2. Повнота розгалуження**

`f(σ)=node ⇒ f(σ·i)≠None`, для кожного `i∈B`.

**T3. Відсутність нащадків листка**

`f(σ)=leaf(a) ⇒ f(σ·i)=None`.

**T4. Наслідування відсутності**

`f(σ)=None ⇒ f(σ·τ)=None` для будь-якого `τ∈Pos`.

## 1.4. Коалгебраїчна структура

Визначимо:

`F_tree(X) = A ⊔ X³`.

Тоді:

`Tree∞ ≅ A ⊔ Tree∞³`.

Оператор розгортання:

`out : Tree∞ → A ⊔ Tree∞³`

задається:

* якщо корінь — `leaf(a)`, результат `inl(a)`;
* якщо корінь — `node`, результат `inr(f₁,f₂,f₃)`.

Тут `f₁,f₂,f₃` — піддерева.

**Твердження W0.1.**

`Tree∞` є фінальною коалгеброю для `F_tree`.

**Статус:** BASE-INHERITED / DP-s у базовій специфікації.

WARP не приписує цьому твердженню новий незалежний доказ.

## 1.5. Простір нескінченних адрес

Визначимо:

`Σ = B^ℕ`.

Елемент:

`ξ = (ξ₁, ξ₂, ξ₃, …)`

є нескінченною послідовністю адресних символів.

Для `ξ ∈ Σ` позначимо:

`ξ|n = (ξ₁,…,ξₙ)`.

Це префікс довжини n.

## 1.6. Оператор граничної структури

Для дерева `f` визначимо:

`∂f = {ξ ∈ Σ : ∀n≥0, f(ξ|n)=node}`.

Тобто нескінченна гілка належить межі тоді й лише тоді, коли всі її скінченні префікси проходять через внутрішні вузли дерева.

Зокрема:

* скінченне дерево має порожню межу;
* дерево з нескінченними гілками має непорожню межу;
* повне нескінченне дерево має `∂f=Σ`.

**Важливо:** `∂f` — підмножина Σ, а не саме дерево.

# 2. W1 — CAUSAL FILTRATION

## 2.1. Базова метрика дерева

Для `f,g ∈ Tree∞`:

`r_addr(f,g) = min{|σ| : f(σ)≠g(σ)}`.

Якщо `f=g`, покладаємо:

`r_addr(f,g)=∞`.

Метрика:

`d_S(f,g)=2^{-r_addr(f,g)}`.

Для однакових дерев:

`d_S(f,f)=0`.

Це ультраметрика.

## 2.2. Простір причинних операторів

Визначимо:

`ℛ₀ = {ρ : Tree∞ → Tree∞ : Lip(ρ)≤1}`.

Метрика:

`d_ℛ(ρ,σ)=sup_{f∈Tree∞} d_S(ρ(f),σ(f))`.

Оскільки `Tree∞` компактний, повний і обмежений, а сімейство 1-Lipschitz-відображень рівномірно еквінеперервне, простір `ℛ₀` компактний у метриці рівномірної збіжності.

**Твердження W1.1.**

`(ℛ₀,d_ℛ)` — компактний метричний простір.

**Статус:** BASE-INHERITED. Компактність `ℛ₀` також зазначена в базовому Lean-звіті.

## 2.3. Фільтрація стискання

Для `m∈ℕ₀`:

`ℛ^(m) = {ρ∈ℛ₀ : Lip(ρ)≤2^{-m}}`.

Тоді:

`ℛ^(0) ⊇ ℛ^(1) ⊇ ℛ^(2) ⊇ …`.

## 2.4. Композиційна властивість

**Теорема W1.2.**

`ℛ^(m) ∘ ℛ^(k) ⊆ ℛ^(m+k)`.

Доведення:

Нехай `ρ∈ℛ^(m)`, `σ∈ℛ^(k)`.

Тоді:

`d_S(ρ(σ(f)),ρ(σ(g)))`

`≤ 2^{-m}d_S(σ(f),σ(g))`

`≤ 2^{-m}2^{-k}d_S(f,g)`.

Отже:

`Lip(ρ∘σ)≤2^{-(m+k)}`.

Тому:

`ρ∘σ∈ℛ^(m+k)`.

**Статус:** PROVED.

## 2.5. Перетин фільтрації

**Теорема W1.3.**

`⋂_{m≥0}ℛ^(m) = Const(Tree∞)`.

Доведення:

Якщо `ρ` належить кожному `ℛ^(m)`, то:

`d_S(ρ(f),ρ(g))≤2^{-m}d_S(f,g)`.

При `m→∞` права частина прямує до нуля.

Тому:

`d_S(ρ(f),ρ(g))=0`.

Отже:

`ρ(f)=ρ(g)` для всіх `f,g`.

Тобто ρ — стала функція.

Навпаки, кожне стале відображення має коефіцієнт Ліпшиця 0 і належить усім рівням фільтрації.

**Статус:** PROVED.

## 2.6. Інтерпретація

Фільтрація описує послідовне зменшення чутливості оператора до початкових відмінностей.

Вона не є часовою динамікою сама по собі.

Індекс m — рівень метричного стискання, а не фізичний час.

# 3. W2 — GRAFTING DYNAMICS

## 3.1. Оператор прищеплення

Для `a∈A` визначимо:

`ρₐ(f)=node(f,leaf(a),leaf(a))`.

Цей оператор створює новий корінь, а початкове дерево розміщує у першій гілці.

## 3.2. Точне масштабування

Якщо `f≠g`, то:

`r_addr(ρₐ(f),ρₐ(g))=r_addr(f,g)+1`.

Отже:

`d_S(ρₐ(f),ρₐ(g))`

`=2^{-(r_addr(f,g)+1)}`

`=½d_S(f,g)`.

**Теорема W2.1.**

`Lip(ρₐ)=½`.

**Статус:** PROVED за базовим означенням метрики.

## 3.3. Нерухома точка

Оскільки `Tree∞` повний, за теоремою Банаха існує єдина точка `pₐ`, для якої:

`ρₐ(pₐ)=pₐ`.

Для будь-якого `f∈Tree∞`:

`ρₐⁿ(f)→pₐ`.

Оцінка збіжності:

`d_S(ρₐⁿ(f),pₐ)≤2^{-n}d_S(f,pₐ)`.

**Теорема W2.2.**

Оператор прищеплення має єдину нерухому точку та є глобальним стисканням.

**Статус:** PROVED через теорему Банаха.

## 3.4. Межа нерухомої точки

Оскільки:

`pₐ=node(pₐ,leaf(a),leaf(a))`,

нескінченна гілка може залишатися на першій гілці необмежено довго.

Тому:

`∂pₐ={1111…}`.

За прийнятої адресної нумерації.

Це важливий приклад:

`limₙ ρₐⁿ(f)=pₐ`

але:

`∂(ρₐⁿ(f))=∅` для скінченного початкового дерева та кожного скінченного n.

Він буде використаний для демонстрації розривності оператора межі.

# 4. W3 — BOUNDARY GEOMETRY

## 4.1. Спільний префікс

Для різних `ξ,η∈Σ` визначимо:

`ℓ(ξ,η)=max{n : ξ|n=η|n}`.

Для `ξ=η` покладаємо:

`ℓ(ξ,ξ)=∞`.

## 4.2. Ультраметрика межі

Для параметра `αᵥ>0`:

`dᵥ(ξ,η)=exp(−αᵥℓ(ξ,η))`, якщо `ξ≠η`.

`dᵥ(ξ,ξ)=0`.

**Теорема W3.1.**

`dᵥ` є ультраметрикою на Σ.

Доведення:

Для будь-яких `ξ,η,ζ`:

`ℓ(ξ,ζ)≥min(ℓ(ξ,η),ℓ(η,ζ))`.

Тому:

`dᵥ(ξ,ζ)≤max(dᵥ(ξ,η),dᵥ(η,ζ))`.

**Статус:** PROVED.

## 4.3. Топологічна інваріантність параметра

Для будь-яких `αᵥ,βᵥ>0` метрики:

`dᵥ,α(ξ,η)=exp(−αᵥℓ(ξ,η))`

та

`dᵥ,β(ξ,η)=exp(−βᵥℓ(ξ,η))`

породжують ту саму топологію.

Отже, параметр αᵥ змінює метричний масштаб, але не топологічний тип простору.

**Статус:** PROVED.

## 4.4. Компактність

Оскільки:

`Σ={1,2,3}^ℕ`

є зліченним добутком скінченних дискретних компактних просторів, за теоремою Тихонова Σ компактний.

Ультраметрика dᵥ метризує добуткову топологію.

Тому:

**Теорема W3.2.**

`(Σ,dᵥ)` — компактний ультраметричний простір.

**Статус:** PROVED.

# 5. W4 — HAUSDORFF DIMENSION

## 5.1. Циліндричні множини

Для скінченного слова `σ∈Bⁿ`:

`C(σ)={ξ∈Σ : ξ|n=σ}`.

Множина всіх циліндрів рівня n:

`C_n={C(σ):σ∈Bⁿ}`.

Кількість:

`|C_n|=3ⁿ`.

Діаметр:

`diam(C(σ))=exp(−αᵥn)`.

## 5.2. Рівномірна міра

Нехай μ — добуткова ймовірнісна міра на Σ з однаковою вагою кожного символу.

Тоді:

`μ(C(σ))=3^{-n}`.

## 5.3. Верхня оцінка розмірності

Використаємо покриття простору всіма циліндрами рівня n.

Для `s>0`:

`Σ_{C∈C_n} diam(C)^s`

`=3ⁿexp(−αᵥsn)`.

Якщо:

`3exp(−αᵥs)<1`,

то сума прямує до нуля.

Отже:

`dim_H(Σ)≤ln3/αᵥ`.

## 5.4. Нижня оцінка

Для кулі радіуса порядку `exp(−αᵥn)` її міра має порядок `3^{-n}`.

Позначимо:

`s₀=ln3/αᵥ`.

Тоді:

`3^{-n}=exp(−αᵥs₀n)`.

Отже існує стала C>0 така, що для достатньо малих r:

`μ(B(x,r))≤Cr^{s₀}`.

За принципом масового розподілу:

`dim_H(Σ)≥s₀`.

## 5.5. Результат

**Теорема W4.1.**

`dim_H(Σ,dᵥ)=ln3/αᵥ`.

**Статус:** PROVED.

**Обмеження:** це розмірність повного простору Σ. Розмірність конкретної межі ∂f може бути іншою.

# 6. W5 — BOUNDARY OPERATOR

## 6.1. Простір компактних множин

Нехай:

`K(Σ)={K⊆Σ : K непорожня і компактна}`.

На K(Σ) визначається метрика Гаусдорфа:

`d_H(A,B)=max{sup_{a∈A}inf_{b∈B}dᵥ(a,b),`

`             sup_{b∈B}inf_{a∈A}dᵥ(a,b)}`.

## 6.2. Розширення порожньою множиною

Оператор межі може повертати порожню множину.

Тому визначимо:

`K₀(Σ)=K(Σ)∪{∅}`.

Для `A,B∈K(Σ)` використовуємо d_H.

Для непорожнього A:

`d₀(∅,A)=d₀(A,∅)=2`.

`d₀(∅,∅)=0`.

Оскільки діаметр Σ не перевищує 1, це задає метричне розширення з ізольованою точкою ∅.

**Твердження W5.1.**

`(K₀(Σ),d₀)` — компактний метричний простір.

Доведення випливає з компактності простору непорожніх компактних підмножин компактного метричного простору та додавання ізольованої точки.

**Статус:** PROVED.

## 6.3. Оператор межі

`∂ : Tree∞ → K₀(Σ)`.

Для кожного дерева f:

`∂f={ξ∈Σ : ∀n, f(ξ|n)=node}`.

Межа дерева компактна, оскільки визначається перетином замкнених циліндричних умов.

## 6.4. Глобальна розривність

**Теорема W5.2.**

Оператор:

`∂ : Tree∞ → K₀(Σ)`

не є неперервним.

Доведення:

Візьмемо:

`fₙ=ρₐⁿ(leaf(a))`.

За теоремою W2.2:

`fₙ→pₐ`.

Для кожного скінченного n:

`∂fₙ=∅`.

Але:

`∂pₐ={111…}`.

Тому:

`d₀(∂fₙ,∂pₐ)=2`

для всіх n.

Отже:

`∂fₙ` не прямує до `∂pₐ`.

**Статус:** PROVED.

## 6.5. Підпростір нескінченно підтриманих дерев

Визначимо:

`Tω={f∈Tree∞ : кожен внутрішній вузол має хоча б одну нескінченну гілку нижче себе}`.

Формально:

Для кожної адреси σ, якщо `f(σ)=node`, то існує нескінченна адреса ξ, яка продовжує σ і проходить лише через вузли f.

## 6.6. Замкненість Tω

**Теорема W5.3.**

`Tω` є замкненою підмножиною `Tree∞`.

Доведення:

Нехай:

`fₙ∈Tω`, `fₙ→f`.

Візьмемо довільний вузол σ дерева f.

Оскільки збіжність відбувається в ультраметриці d_S, для кожної фіксованої скінченної множини адрес мітки стабілізуються.

Зокрема, для достатньо великих n:

`fₙ(σ)=node`.

Оскільки `fₙ∈Tω`, існує нескінченна гілка, що проходить через σ.

Розглянемо дерево префіксів таких гілок. Воно має скінченне розгалуження і довільно велику глибину.

За лемою Кеніга існує нескінченна гілка, що проходить через σ.

У кожному її фіксованому префіксі мітки стабілізуються до відповідних міток f.

Отже, нескінченна гілка існує і в f.

Оскільки σ було довільним вузлом:

`f∈Tω`.

**Статус:** PROVED за лемою Кеніга.

## 6.7. Ліпшицевість оператора межі на Tω

Для узгодженості параметрів покладемо:

`αᵥ=ln2`.

Тоді:

`dᵥ(ξ,η)=2^{-ℓ(ξ,η)}`.

**Теорема W5.4.**

Для всіх `f,g∈Tω`:

`d_H(∂f,∂g)≤2d_S(f,g)`.

Доведення:

Нехай `f≠g` і:

`m=r_addr(f,g)`.

Тоді дерева збігаються на всіх адресах довжини меншої за m.

Візьмемо:

`ξ∈∂f`.

Якщо ξ також належить ∂g, відстань до ∂g дорівнює нулю.

Інакше перша адреса, на якій ξ перестає проходити через вузли g, має довжину не меншу за m.

У цьому місці гілка дерева g може завершитися листком, тоді як f продовжує гілку.

Оскільки `g∈Tω`, у відповідному попередньому вузлі g існує інша нескінченна гілка.

Вона збігається з ξ щонайменше до попереднього рівня.

Тому існує:

`η∈∂g`

таке, що:

`dᵥ(ξ,η)≤2^{-(m-1)}`.

Отже:

`inf_{η∈∂g}dᵥ(ξ,η)≤2·2^{-m}`.

Оскільки:

`d_S(f,g)=2^{-m}`,

маємо:

`dist(ξ,∂g)≤2d_S(f,g)`.

Симетричний аргумент дає зворотну оцінку.

Тому:

`d_H(∂f,∂g)≤2d_S(f,g)`.

**Статус:** PROVED за визначенням Tω та метрик.

## 6.8. Висновок W5

Оператор межі:

* визначений на всьому Tree∞;
* глобально розривний;
* неперервний на Tω;
* 2-Lipschitz на Tω за αᵥ=ln2.

Це розрізнення є фундаментальним для WARP.

# 7. W6 — INTERACTION KERNELS

## 7.1. Параметри

Вводимо незалежний параметр:

`α𝑤>0`.

Позначимо:

`q=exp(−α𝑤)`.

Тоді:

`0<q<1`.

α𝑤 визначає масштаб взаємодії, а не геометрію простору меж.

## 7.2. Ядро спільного предка

Визначимо:

`K_anc(ξ,η)=q^{ℓ(ξ,η)}`, якщо `ξ≠η`.

На діагоналі:

`K_anc(ξ,ξ)=0`.

Ядро обмежене:

`0≤K_anc≤1`.

Оскільки:

`q^n→0` при `n→∞`,

ядро неперервне і на діагоналі.

**Важливе застереження:** це означення не дає автоматичної позитивної визначеності ядра. Позитивна визначеність не заявляється.

## 7.3. Ядро зростаючої близькості

Для `ξ≠η`:

`K_Vl(ξ,η)=exp(α𝑤ℓ(ξ,η))`.

На діагоналі ядро не визначається як скінченна функція.

Воно є сингулярним.

## 7.4. Інтегровність K_Vl

Зафіксуємо ξ.

Імовірність того, що випадкова η має рівно k спільних початкових символів із ξ:

`P(ℓ(ξ,η)=k)=2/3^{k+1}`.

Тому:

`∫K_Vl(ξ,η)dμ(η)`

`=Σₖ₌₀∞ (2/3^{k+1})exp(α𝑤k)`.

Це геометричний ряд:

`=2/3 · Σₖ₌₀∞ (exp(α𝑤)/3)^k`.

Він збігається тоді й лише тоді, коли:

`exp(α𝑤)<3`.

Отже:

**Теорема W6.1.**

`K_Vl(ξ,·)∈L¹(Σ,μ)` тоді й лише тоді, коли:

`α𝑤<ln3`.

У цьому випадку:

`∫K_Vl(ξ,η)dμ(η)=2/(3−exp(α𝑤))`.

## 7.5. Регуляризація

Для N∈ℕ:

`K_Vl^(N)(ξ,η)=exp(α𝑤 min(ℓ(ξ,η),N))`.

Це обмежене ядро.

Для кожного N:

`K_Vl^(N)≤exp(α𝑤N)`.

Якщо `α𝑤<ln3`, то за теоремою монотонної збіжності:

`K_Vl^(N)→K_Vl`

в L¹ у відповідних інтегральних перерізах.

## 7.6. Розрізнення моделей

| Характеристика | K_anc              | K_Vl                 |
| -------------- | ------------------ | -------------------- |
| Залежність     | q^ℓ                | exp(α𝑤ℓ)            |
| Поведінка      | Спадає             | Зростає              |
| Діагональ      | 0                  | Сингулярна           |
| Обмеженість    | Так                | Ні                   |
| Інтегровність  | Так                | За α𝑤<ln3           |
| Призначення    | Згасання взаємодії | Посилення близькості |

Ці ядра не є взаємозамінними.

# 8. W7 — HIERARCHICAL SPECTRAL OPERATOR

## 8.1. Простір функцій

Визначимо:

`H=L²(Σ,μ)`.

Внутрішній добуток:

`⟨f,g⟩=∫f(ξ)g(ξ)dμ(ξ)`.

Розглядаємо дійснозначний простір функцій.

## 8.2. Інтегральний оператор

Для `q∈(0,1)`:

`(T_qf)(ξ)=∫q^{ℓ(ξ,η)}f(η)dμ(η)`.

Значення ядра на діагоналі можна визначити довільно, оскільки діагональ має міру нуль у добутковій мірі μ×μ.

Ядро обмежене:

`0≤q^ℓ≤1`.

Тому:

`K_q∈L²(Σ×Σ)`.

Отже `T_q` — оператор Гільберта—Шмідта.

Звідси:

**Теорема W7.1.**

`T_q` компактний і самоспряжений.

## 8.3. Константа нормування

Інтеграл ядра не залежить від ξ:

`c_q=∫q^{ℓ(ξ,η)}dμ(η)`.

За розподілом спільного префікса:

`c_q=Σₖ₌₀∞ 2qᵏ/3^{k+1}`.

Тому:

`c_q=2/(3−q)`.

## 8.4. Нормований оператор

Визначимо:

`L_q=T_q−c_qI`.

Тоді:

`L_q1=0`.

Тобто сталі функції належать ядру L_q.

Оскільки `T_q` компактний, а `I` некомпактний на нескінченновимірному H:

**L_q загалом не є компактним.**

Це обов'язкове обмеження специфікації.

## 8.5. Циліндричні підпростори

Для n≥0 нехай `H_n` — простір функцій, сталих на кожному циліндрі рівня n.

Тоді:

`H₀⊂H₁⊂H₂⊂…`.

`dim(H_n)=3ⁿ`.

Визначимо:

`W₀=H₀`.

Для j≥1:

`W_j=H_j⊖H_{j−1}`.

Тоді:

`dim(W_j)=3ʲ−3^{j−1}`.

Отже:

`dim(W_j)=2·3^{j−1}`.

## 8.6. Повнота розкладу

Циліндричні функції щільні в `L²(Σ,μ)`.

Тому:

`H=⊕_{j=0}∞W_j`.

Це ортогональний гільбертів розклад.

**Твердження W7.2.**

Кожен елемент H має унікальний ортогональний розклад за ієрархічними рівнями W_j.

**Статус:** PROVED через щільність простих функцій на породженій циліндричною алгеброю σ-алгебрі.

## 8.7. Власне значення на W₀

Для сталої функції:

`T_q1=c_q1`.

Отже:

`L_q1=0`.

Тому:

`τ₀=0`.

## 8.8. Власні значення на W_j

Для j≥1:

`T_q|W_j=λ_j(q)I`.

Власне значення T_q:

`λ_j(q)=Σₖ₌ⱼ∞ 2qᵏ/3^{k+1}−q^{j−1}/3ʲ`.

Пояснення:

1. для рівнів k≥j функція з W_j має нульове середнє на відповідних циліндрах;
2. інтегральний внесок від глибших спільних префіксів утворює геометричний ряд;
3. віднімання внеску рівня j−1 дає другий член.

Геометрична сума:

`Σₖ₌ⱼ∞ 2qᵏ/3^{k+1}`

`=2qʲ/[3ʲ(3−q)]`.

Отже:

`λ_j(q)=2qʲ/[3ʲ(3−q)]−q^{j−1}/3ʲ`.

Для L_q:

`τ_j(q)=λ_j(q)−c_q`.

Після спрощення:

`τ_j(q)=−[Σₖ₌₀^{j−1}2qᵏ/3^{k+1}+q^{j−1}/3ʲ]`.

**Твердження W7.3.**

Для кожного j≥1 простір W_j є власним підпростором L_q з власним значенням τ_j(q) та кратністю `2·3^{j−1}`.

**Статус:** PROOF-REFINED. Формула отримана з ієрархічного розкладу; перед статусом STABLE потрібна незалежна перевірка повного обчислення дії оператора на W_j.

## 8.9. Граничне спектральне значення

Оскільки:

`Σₖ₌₀∞2qᵏ/3^{k+1}=c_q`,

маємо:

`lim_{j→∞}τ_j(q)=−c_q`.

Отже:

`−c_q`

є граничною точкою послідовності власних значень.

Це узгоджується з некомпактністю L_q.

## 8.10. Спектральна множина

За повнотою ортогонального розкладу:

`H=W₀⊕W₁⊕W₂⊕…`.

Тому спектр оператора:

`Spec(L_q)={0}∪{τ_j(q):j≥1}∪{−c_q}`.

Тут:

* 0 — власне значення на сталих функціях;
* τ_j — ієрархічні власні значення;
* −c_q — точка накопичення спектра.

**Статус:** CONDITIONAL до завершення незалежного аудиту W7.3 та перевірки спектрального висновку.

## 8.11. Знак оператора

Оскільки ядро q^ℓ має невід'ємні ієрархічні коефіцієнти в цій моделі, очікується:

`λ_j(q)≤c_q`.

Тому:

`τ_j(q)≤0`.

Але твердження про від'ємну напіввизначеність L_q має бути зафіксоване лише після повного доведення для всіх компонентів розкладу.

У цій редакції воно не використовується як незалежна аксіома.

# 9. W8 — FINITE-LEVEL APPROXIMATION

## 9.1. Проєкції

Нехай:

`P_n:H→H_n`

— ортогональна проєкція.

Оскільки циліндричні функції щільні:

`P_n f→f` для кожного `f∈H`.

## 9.2. Скінченні оператори

Визначимо:

`T_q^(n)=P_nT_qP_n`.

Це скінченновимірний оператор на H_n.

Нормований варіант:

`L_q^(n)=T_q^(n)−c_qI_{H_n}`.

## 9.3. Матричне подання

Позначимо циліндри рівня n:

`C_σ`, де `σ∈Bⁿ`.

Для функції, що має на циліндрі C_τ значення x_τ:

`(T_q^(n)x)_σ`

`=Σ_{τ∈Bⁿ}M_στ^(n)x_τ`.

Елемент матриці:

`M_στ^(n)=3^{-n}·Avg_{C_σ×C_τ}(q^ℓ)`.

Тут `Avg` — середнє значення ядра на відповідному добутку циліндрів.

Це визначення усуває неоднозначність щодо діагональних елементів і нормування матриці.

## 9.4. Збіжність

Оскільки T_q компактний і P_n→I сильно, маємо:

`||T_q−P_nT_qP_n||→0`.

Отже:

`T_q^(n)→T_q`

у операторній нормі після природного розгляду скінченновимірних операторів як операторів на H з нульовим продовженням.

Для нормованих операторів необхідно використовувати узгоджене продовження:

`L̃_q^(n)=P_nT_qP_n−c_qI_H`.

Тоді:

`||L̃_q^(n)−L_q||→0`.

**Теорема W8.1.**

Скінченні оператори `P_nT_qP_n` збігаються до T_q в операторній нормі.

**Статус:** PROVED за компактністю T_q та сильною збіжністю P_n.

## 9.5. Спектральні наслідки

Операторна збіжність самоспряжених операторів забезпечує збіжність спектральних даних у відповідному сенсі.

Однак скінченна матриця не може буквально відтворити всю структуру нескінченновимірного спектра.

Зокрема, вона не має нескінченної послідовності кратностей `2·3^{j−1}`.

Тому:

* скінченні власні значення апроксимують відповідні рівні;
* гранична спектральна точка потребує окремого аналізу;
* кратності на рівнях n мають бути обмежені розмірністю H_n.

**Статус:** CONDITIONAL для конкретних оцінок швидкості збіжності.

# 10. W9 — PARAMETER SEPARATION

## 10.1. Незалежні параметри

WARP використовує три різні параметри:

`αᵥ` — геометрія межі;

`α𝑤` — масштаб ядра взаємодії;

`αₛ=ln2` — масштаб базової метрики дерева, якщо він використовується в оцінках межі.

Не можна автоматично ототожнювати:

`αᵥ=α𝑤=αₛ`.

## 10.2. Геометрична сумісність

Для доведення W5.4 використовується:

`αᵥ=ln2`.

Для розмірності W4.1 допускається будь-яке:

`αᵥ>0`.

Для інтегровності K_Vl:

`α𝑤<ln3`.

Ці умови належать різним теоремам.

## 10.3. Дослідницький режим

Окремо можна розглядати спеціальний режим:

`αᵥ=α𝑤=ln2`.

Це зручний вибір параметрів, але не математична необхідність усієї системи.

# 16. ЗАКЛЮЧНИЙ ПРИНЦИП

SUBIT-WARP не ототожнює структуру з її межею, межу з геометрією, геометрію з взаємодією, а взаємодію зі спектром.

Він досліджує послідовність математичних переходів:

`Tree∞ → Σ → K(Σ) → L²(Σ,μ) → Spec(L_q)`.

Кожен перехід має власні означення, власну математичну структуру та окремі умови коректності.

Головна теза WARP:

**Нескінченна структура може бути досліджена через геометрію її межі, а ієрархія цієї межі може проявлятися у спектрі операторів взаємодії.**

Це не означає, що всі властивості початкового дерева зберігаються у спектрі. Спектр є окремим математичним представленням, яке потребує власного аналізу.
