# SUBIT-WARP v0.4

## W15 — Non-Homogeneous Trees and Broken Hierarchical Symmetry

**Статус:** DRAFT · FINITE MODEL PROVED · GENERAL THEORY OPEN
**Залежності:** W0–W14
**Мета:** дослідити спектральні властивості неоднорідних дерев, порушення спільної ієрархічної декомпозиції та виникнення некомутативності між геометричними й інтеракційними операторами.

# W15.0. Мотивація

У W14 було встановлено:

`[T_q₁,T_q₂] = 0`.

Цей результат справедливий для однорідної b-арної моделі, у якій:

* кожна вершина має однакову кількість дочірніх вершин;
* усі гілки мають однакову структурну організацію;
* міра є рівномірною;
* ядро залежить лише від довжини спільного початкового префікса.

За цих умов усі оператори сімейства `T_q` мають спільну систему власних підпросторів.

Але природні ієрархічні структури не завжди однорідні.

Можливі:

* різна кількість дочірніх вершин;
* нерівномірна глибина гілок;
* локальні структурні дефекти;
* неоднорідний розподіл міри;
* різні параметри взаємодії на різних ділянках;
* асиметричні правила переходу між рівнями.

Тому W15 досліджує питання:

**Чи породжує порушення однорідності нову операторну структуру, зокрема некомутативність?**

# W15.1. Загальна модель неоднорідного дерева

Нехай:

`𝒯 = (V,E)`

— скінченне або нескінченне кореневе дерево.

Позначимо:

* `V` — множина вершин;
* `E` — множина ребер;
* `∂𝒯` — множина нескінченних шляхів від кореня;
* `ℓ(x,y)` — довжина спільної частини шляхів x та y.

Для скінченної моделі замість нескінченних шляхів використовуємо множину листків:

`X = {x₁,...,xₙ}`.

Визначимо структурну функцію:

`h : X × X → ℕ₀`

де `h(x,y)` — глибина найглибшого спільного предка різних листків.

Для нескінченної межі:

`h(x,y) = ℓ(x,y)`.

У скінченній моделі діагональ обробляється окремо.

Визначимо ядро:

`K_q(x,y) = q^{h(x,y)}`, якщо `x ≠ y`;

`K_q(x,x) = 0`.

Це скінченне off-diagonal представлення ієрархічної взаємодії.

**Важливе застереження:** нуль на діагоналі є спеціальною конвенцією скінченної атомарної моделі. Він не є буквальним перенесенням нескінченного ядра на атомарний простір, де діагональ має додатну міру.

Нехай `μ` — ймовірнісна міра на X:

`μ(xᵢ) = pᵢ > 0`

`Σᵢ pᵢ = 1`.

Тоді оператор:

`(T_q f)(x) = Σᵧ∈X K_q(x,y)f(y)μ(y)`.

У координатах:

`T_q = K_q D_μ`

де:

`D_μ = diag(p₁,...,pₙ)`.

У просторі `L²(X,μ)` цей оператор самоспряжений, оскільки ядро симетричне.

# W15.2. Мінімальний контрприклад: дерево з трьома листками

Розглянемо дерево:

* корінь має два дочірні напрями;
* перший напрям веде до внутрішньої вершини з листками `a` та `b`;
* другий напрям веде безпосередньо до листка `c`.

Схематично:

```text
             root
            /    \
           u      c
          / \
         a   b
```

Спільна глибина:

`h(a,b) = 1`

`h(a,c) = 0`

`h(b,c) = 0`.

Використаємо рівномірну міру:

`μ(a) = μ(b) = μ(c) = 1/3`.

Матриця ядра:

`K_q =`

```text
[ 0   q   1 ]
[ q   0   1 ]
[ 1   1   0 ]
```

Оператор:

`T_q = (1/3)K_q`.

Введемо дві матриці:

```text
       [ 0  0  1 ]
A  =   [ 0  0  1 ]
       [ 1  1  0 ]
```

```text
       [ 0  1  0 ]
B  =   [ 1  0  0 ]
       [ 0  0  0 ]
```

Тоді:

`K_q = A + qB`.

Для двох параметрів:

`T_q₁ = (A+q₁B)/3`

`T_q₂ = (A+q₂B)/3`.

Обчислимо комутатор:

`[T_q₁,T_q₂] = T_q₁T_q₂ − T_q₂T_q₁`.

Після розкриття:

`[T_q₁,T_q₂] = (q₁−q₂)(BA−AB)/9`.

При цьому:

```text
BA − AB =

[  0   0   1 ]
[  0   0   1 ]
[ -1  -1   0 ]
```

Отже:

`[T_q₁,T_q₂] =`

```text
(q₁−q₂)/9 ·

[  0   0   1 ]
[  0   0   1 ]
[ -1  -1   0 ]
```

### Теорема W15-T01 — Finite Noncommutativity

Для наведеного неоднорідного дерева:

`[T_q₁,T_q₂] ≠ 0`

тоді й лише тоді, коли:

`q₁ ≠ q₂`.

**Доведення.**

Матриця `BA−AB` ненульова.

Тому комутатор дорівнює нулю тоді й лише тоді, коли множник `q₁−q₂` дорівнює нулю.

Теорему доведено.

### Інтерпретація

Цей результат демонструє, що спільна ієрархічна структура W14 не є універсальною властивістю всіх дерев.

Порушення однорідності може зруйнувати комутативність навіть за рівномірної міри.

# W15.3. Норма комутатора

Для матриці:

`C₀ = BA−AB`

маємо:

`C₀ᵀ = −C₀`.

Отже, комутатор є кососиметричною матрицею.

Його спектр:

`Spec(C₀) = {0, i√2, −i√2}`.

Тому операторна норма:

`‖C₀‖ = √2`.

Звідси:

### Наслідок W15-C01

`‖[T_q₁,T_q₂]‖ = √2·|q₁−q₂|/9`.

Це дає точну кількісну оцінку порушення комутативності для мінімальної моделі.

Комутатор:

* дорівнює нулю при `q₁=q₂`;
* лінійно зростає за модулем різниці параметрів;
* обмежений зверху величиною `√2/9`, оскільки `q₁,q₂ ∈ (0,1)`.

Таким чином, у цій моделі некомутативність має чітку параметричну залежність.

# W15.4. Спектр окремого оператора

Для трьохлисткового дерева:

`T_q = (1/3)`

```text
[ 0   q   1 ]
[ q   0   1 ]
[ 1   1   0 ]
```

Вектор:

`v₋ = (1,−1,0)`

є власним вектором із власним значенням:

`λ₋ = −q/3`.

Інші два власні значення отримуємо на підпросторі векторів вигляду:

`(x,x,y)`.

Відповідна матриця дії:

```text
(1/3) ·

[ q   1 ]
[ 2   0 ]
```

Характеристичне рівняння:

`λ² − (q/3)λ − 2/9 = 0`.

Отже:

`λ± = [q ± √(q²+8)]/6`.

Повний спектр:

`Spec(T_q) = {−q/3, [q+√(q²+8)]/6, [q−√(q²+8)]/6}`.

Це скінченний спектр із трьох власних значень.

На відміну від однорідної нескінченної моделі, тут немає нескінченної послідовності рівнів і точки накопичення нуль.

Цей приклад не можна безпосередньо ототожнювати зі спектром W7: він є окремою скінченною моделлю.

# W15.5. Порушення спільної спектральної бази

У W14 комутативність випливала зі спільної ортогональної декомпозиції:

`H = ⊕ⱼ Wⱼ`.

Для неоднорідного дерева загалом не існує такої універсальної декомпозиції, на якій усі оператори `T_q` діяли б скалярно.

У трьохлистковому прикладі:

* `T_q₁` і `T_q₂` симетричні;
* кожен окремо має ортогональну систему власних векторів;
* але при `q₁ ≠ q₂` вони не комутують.

Для скінченновимірних самоспряжених операторів спільна ортонормована база власних векторів існує тоді й лише тоді, коли оператори комутують.

Тому:

`[T_q₁,T_q₂] ≠ 0`

означає відсутність спільної ортонормованої бази власних векторів.

Це і є математичний зміст порушення спільної спектральної симетрії.

# W15.6. Дефект однорідності

Введемо поняття структурного дефекту.

Нехай `𝒯₀` — однорідне дерево, а `𝒯` — його неоднорідна модифікація.

Позначимо відповідні оператори:

`T_q⁽⁰⁾`

`T_q`.

Визначимо:

`ΔT_q = T_q − T_q⁽⁰⁾`.

Це операторний дефект.

Для двох параметрів:

`C(q₁,q₂) = [T_q₁,T_q₂]`.

Назвемо його **комутативним дефектом**.

У однорідній моделі:

`C(q₁,q₂) = 0`.

У неоднорідній моделі:

`C(q₁,q₂)` може бути ненульовим.

Введемо нормований показник:

`κ(q₁,q₂) = ‖[T_q₁,T_q₂]‖ / (‖T_q₁‖‖T_q₂‖)`.

Для ненульових операторів:

`0 ≤ κ ≤ 2`.

Інтерпретація:

* `κ = 0` — комутативна пара;
* `κ > 0` — порушення комутативності;
* більше `κ` означає сильніше операторне розходження від комутативного режиму.

Важливо: `κ` не є універсальною мірою неоднорідності дерева. Різні дерева можуть мати однаковий показник, а деякі неоднорідні дерева можуть породжувати комутативні оператори.

# W15.7. Типологія порушень симетрії

Визначимо п'ять класів структурних порушень.

### NHT-01 — Variable Branching

Кількість дочірніх вершин залежить від батьківської вершини.

`deg⁺(v) ≠ const`.

### NHT-02 — Variable Depth

Листки мають різну глибину.

`depth(x) ≠ const`.

### NHT-03 — Nonuniform Measure

Міра залежить від локального шляху:

`μ(C_v) ≠ b^(−|v|)`.

### NHT-04 — Local Interaction

Параметр взаємодії залежить від ділянки дерева:

`q = q(v)`.

### NHT-05 — Asymmetric Geometry

Геометричне ядро не залежить лише від довжини спільного префікса:

`K(ξ,η) ≠ F(ℓ(ξ,η))`.

Ці класи можуть комбінуватися.

Необхідно досліджувати кожен окремо, перш ніж вводити їх у спільну модель.

# W15.8. Загальна операторна модель

Для неоднорідного дерева визначимо:

`K𝑤(x,y) = exp(−α𝑤 h(x,y))`

`Kᵥ(x,y) = exp(−sαᵥ h(x,y))`

для `x ≠ y`.

Оператори:

`T𝑤 = K𝑤D_μ`

`Tᵥ = KᵥD_μ`.

У загальному випадку:

`[T𝑤,Tᵥ] ≠ 0`.

Однак ця нерівність не є автоматичною для кожного неоднорідного дерева.

Вона залежить від:

* топології дерева;
* розподілу міри;
* геометричного ядра;
* інтеракційного ядра.

### Теорема W15-T02 — Finite Symmetric Operator Criterion

Нехай X — скінченна множина, `μ(x)>0`, а `K₁`, `K₂` — симетричні ядра.

Тоді оператори:

`T₁ = K₁D_μ`

`T₂ = K₂D_μ`

є самоспряженими в `L²(X,μ)`.

Вони комутують тоді й лише тоді, коли:

`K₁D_μK₂ = K₂D_μK₁`.

**Доведення.**

Самоспряженість випливає з симетричності ядер:

`⟨f,T₁g⟩_μ = ⟨T₁f,g⟩_μ`.

Комутативність:

`T₁T₂ = T₂T₁`

еквівалентна:

`K₁D_μK₂D_μ = K₂D_μK₁D_μ`.

Оскільки `D_μ` оборотна:

`K₁D_μK₂ = K₂D_μK₁`.

Теорему доведено.

Це точний критерій для скінченних моделей.

# W15.13. Висновок

W15 розширює SUBIT-WARP за межі однорідної ієрархії.

Мінімальна модель із трьома листками демонструє:

`[T_q₁,T_q₂] ≠ 0`, якщо `q₁ ≠ q₂`.

Отже, некомутативність може виникати вже на мінімальному скінченному структурному прикладі.

Це означає, що спільна спектральна база W14 є властивістю спеціальної симетричної архітектури, а не універсальним законом усіх ієрархічних просторів.

W15 відкриває дослідження локальних структурних дефектів, порушення симетрії та операторної взаємодії в неоднорідних системах.
