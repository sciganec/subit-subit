# SUBIT-WARP v0.4

## W18 — Structural Fingerprints, Hierarchical Invariants and Reconstruction Framework

**Статус:** DRAFT · MATHEMATICALLY DERIVED
**Залежності:** W0–W17
**Призначення:** формалізація структурних сигнатур скінченних дерев та умов їх реконструкції.

---

# 1. Мотивація

W17 встановив, що спектральна інформація не визначає довільну деревну структуру однозначно.

Навіть якщо два дерева породжують однаковий оператор, це не гарантує їхньої структурної тотожності.

Тому SUBIT-WARP потребує додаткового рівня опису — Structural Fingerprint.

Його призначення:

1. зберігати ієрархічну структуру;
2. відображати локальну арність вузлів;
3. фіксувати глибину листків;
4. зберігати відношення спільного предка;
5. враховувати міру;
6. забезпечувати реконструкцію в межах чітко визначеного класу дерев;
7. відокремлювати повні структурні інваріанти від часткових дескрипторів.

Основна відмінність W18 від W17:

* W17 досліджує, що можна дізнатися зі спектра.
* W18 визначає, які дані необхідно зберегти для структурної реконструкції.

# 2. W18.1 — Формальна модель скінченного дерева

Нехай X — скінченне кореневе дерево.

Позначимо:

* V(X) — множина всіх вузлів;
* E(X) — множина ребер;
* r — корінь;
* L(X) — множина листків;
* I(X)=V(X)\L(X) — множина внутрішніх вузлів.

Розглядаємо дерева, в яких кожен вузол лежить на шляху від кореня до принаймні одного листка.

Це виключає вузли без нащадків-листків.

Кожне ребро має одиничну довжину, якщо не зазначено інше.

Для вузла v визначимо:

h(v)=відстань від кореня до v.

Для листка ξ:

h(ξ)=глибина листка.

Для двох листків ξ,η визначимо:

ℓ(ξ,η)=глибина їхнього найглибшого спільного предка.

Позначимо його:

LCA(ξ,η).

Тоді:

ℓ(ξ,ξ)=h(ξ).

Для ξ≠η:

0≤ℓ(ξ,η)<min(h(ξ),h(η)).

Ці домовленості є канонічними для W18.

---

# 3. W18.2 — Структурний профіль дерева

Визначимо перший рівень Structural Fingerprint.

## 3.1. Профіль глибин листків

Для кожного k≥0:

P_depth(k)=|{ξ∈L(X):h(ξ)=k}|.

Тоді:

P_depth=(P_depth(0),P_depth(1),...).

Оскільки дерево скінченне, послідовність має скінченну підтримку.

Для зваженого випадку:

P_depth^μ(k)=Σ_{ξ:h(ξ)=k}μ(ξ).

Важливо розділяти кількість листків та їхню сумарну міру.

## 3.2. Профіль арності

Для внутрішнього вузла v визначимо:

deg⁺(v)=кількість його дочірніх вузлів.

Тоді:

P_arity(k)=|{v∈I(X):deg⁺(v)=k}|.

Повний профіль:

P_arity=(P_arity(1),P_arity(2),...).

Вузли арності 1 зберігаються. Вони не вилучаються автоматично, оскільки можуть кодувати глибину або часову послідовність структурних переходів.

## 3.3. Профіль кількості вузлів за рівнями

Визначимо:

N_k=|{v∈V(X):h(v)=k}|.

Тоді:

P_level=(N₀,N₁,N₂,...).

Цей профіль відображає розподіл вузлів за глибиною.

## 3.4. Статус інваріантів

P_depth, P_arity та P_level є структурними інваріантами відносно ізоморфізму кореневих дерев.

Однак окремо жоден із них не гарантує повної реконструкції.

**Статус:** PROVED.

---

# 4. W18.3 — Матриця спільного предка

Нехай множина листків:

L(X)={ξ₁,...,ξₙ}.

Визначимо матрицю:

A_LCA(X)=[ℓ(ξᵢ,ξⱼ)].

Вона має такі властивості:

1. Симетричність:

   ℓ(ξᵢ,ξⱼ)=ℓ(ξⱼ,ξᵢ).

2. Діагональ:

   ℓ(ξᵢ,ξᵢ)=h(ξᵢ).

3. Невід'ємність:

   ℓ(ξᵢ,ξⱼ)≥0.

4. Обмеження:

   ℓ(ξᵢ,ξⱼ)≤min(h(ξᵢ),h(ξⱼ)).

Матриця спільного предка зберігає більше інформації, ніж спектр оператора, оскільки безпосередньо кодує ієрархічні відношення між листками.

## 4.1. Відстань між листками

Визначимо:

d_T(ξᵢ,ξⱼ)
=h(ξᵢ)+h(ξⱼ)−2ℓ(ξᵢ,ξⱼ).

Це звичайна деревна відстань між листками.

Отже:

A_LCA + P_depth

визначають матрицю попарних деревних відстаней.

Але сама матриця відстаней не завжди достатня для відновлення всіх деталей кореневої структури, якщо не збережено умови моделі.

W18 тому використовує безпосередньо матрицю LCA разом із вектором глибин.

---

# 5. W18.4 — Structural Fingerprint

Визначимо основний структурний дескриптор:

SF(X)=
(L(X), P_depth, A_LCA, P_arity).

Для зваженого дерева:

SF_μ(X)=
(L(X), P_depth, A_LCA, P_arity, μ).

Тут:

* L(X) — множина листків;
* P_depth — глибини листків;
* A_LCA — матриця спільного предка;
* P_arity — профіль арності;
* μ — міра на листках.

Профіль арності є надлишковим щодо повної LCA-інформації за умов теореми реконструкції нижче. Проте його збереження корисне для незалежної перевірки узгодженості.

## 5.1. Мічений та немічений варіанти

Для міченого дерева порядок листків фіксований.

Тоді матриця A_LCA має конкретне координатне представлення.

Для неміченого дерева допускаються одночасні перестановки рядків і стовпців:

A'_LCA=P A_LCA Pᵀ,

де P — матриця перестановки.

Два структурні fingerprints вважаються еквівалентними, якщо їхні компоненти збігаються після допустимої одночасної перестановки листків.

Позначення:

SF(X)≅SF(Y).

# 6. W18.5 — Теорема повної реконструкції

Це центральний результат W18.

## Теорема 1. Реконструкція скінченного кореневого дерева за LCA-матрицею та глибинами листків

Нехай X і Y — скінченні кореневі дерева з одиничними довжинами ребер, у яких кожен вузол лежить на шляху від кореня до принаймні одного листка.

Нехай існує бієкція:

φ:L(X)→L(Y),

така, що для всіх листків ξ,η:

h_X(ξ)=h_Y(φ(ξ))

і

ℓ_X(ξ,η)=ℓ_Y(φ(ξ),φ(η)).

Тоді X та Y ізоморфні як кореневі дерева зі збереженням глибин вузлів.

### Доведення

Позначимо:

L=L(X).

Для кожного рівня k≥0 визначимо множину активних листків:

L_k={ξ∈L:h(ξ)≥k}.

На L_k введемо відношення:

ξ~ₖη ⇔ ℓ(ξ,η)≥k.

Це відношення еквівалентності.

Рефлексивність:

ℓ(ξ,ξ)=h(ξ)≥k.

Симетричність випливає із симетричності LCA.

Транзитивність випливає з того, що якщо два листки мають спільний префікс довжини k, а другий і третій також мають спільний префікс довжини k, то всі три мають однаковий префікс довжини k.

Класи еквівалентності відповідають вузлам дерева на рівні k.

Кожен вузол рівня k має хоча б один листок-нащадок, тому кожен вузол представлений певним класом еквівалентності.

Для кожного k отримуємо множину вузлів рівня k.

Зв'язок між рівнями визначається включенням класів:

клас рівня k+1 міститься в єдиному класі рівня k.

Отже, матриця LCA та глибини листків визначають:

* усі вузли;
* рівні вузлів;
* відношення батьківства;
* кореневу структуру.

Для дерева Y виконується така сама конструкція.

Оскільки φ зберігає глибини та значення LCA, вона породжує бієкцію між класами еквівалентності кожного рівня.

Ця бієкція зберігає включення класів, а отже, відношення батьківства.

Тому вона визначає ізоморфізм кореневих дерев.

Теорему доведено.

**Статус:** PROVED у зазначеному класі скінченних кореневих дерев.

## 6.1. Межі теореми

Теорема не стверджує реконструкцію довільних графів.

Вона не поширюється автоматично на:

* дерева з додатковими вузлами, що не лежать на жодному шляху до листка;
* графи з циклами;
* дерева з невідомою структурою ребер та довільними вагами;
* нескінченні дерева без додаткових умов.

Для зважених дерев необхідна окрема постановка з позитивними довжинами ребер та накопиченими відстанями від кореня.

# 7. W18.6 — Канонічна реконструкція

Теорема 1 дає конструктивний алгоритм.

Вхідні дані:

* множина листків L;
* глибини h(ξ);
* матриця ℓ(ξ,η).

Алгоритм:

### Крок 1. Рівні

Для кожного k від 0 до:

H_max=maxξ h(ξ)

побудувати:

L_k={ξ:h(ξ)≥k}.

### Крок 2. Еквівалентність

Для ξ,η∈L_k:

ξ~ₖη ⇔ ℓ(ξ,η)≥k.

### Крок 3. Вузли

Кожен клас еквівалентності на рівні k утворює один вузол.

### Крок 4. Батьківство

Клас рівня k+1 має батьком той єдиний клас рівня k, який його містить.

### Крок 5. Листки

Листок ξ додається до вузла, що відповідає його префіксу довжини h(ξ).

### Крок 6. Перевірка

Перевірити:

* існування єдиного кореня;
* зв'язність;
* відсутність циклів;
* єдиність батька кожного некореневого вузла;
* узгодженість глибин;
* відповідність відновленої LCA-матриці вхідній.

Результат:

X_reconstructed.

## Складність

Нехай n — кількість листків, H — максимальна глибина.

Без спеціалізованих структур даних побудова всіх відношень еквівалентності може вимагати:

O(Hn²)

операцій.

Це верхня оцінка для прямої реалізації.

Оптимізація через групування листків за LCA-значеннями та побудову префіксних класів може зменшити практичну складність.

# 8. W18.7 — Перевірка структурної узгодженості

Не кожна довільна симетрична матриця є допустимою LCA-матрицею.

Тому введемо критерії валідності.

Нехай задано:

* множину L;
* функцію h:L→ℕ;
* симетричну функцію ℓ:L×L→ℕ.

Необхідні умови:

### SF-C1 — Діагональна узгодженість

ℓ(ξ,ξ)=h(ξ).

### SF-C2 — Межі

0≤ℓ(ξ,η)≤min(h(ξ),h(η)).

### SF-C3 — Симетричність

ℓ(ξ,η)=ℓ(η,ξ).

### SF-C4 — Ієрархічна транзитивність

Для кожного k множина:

L_k={ξ:h(ξ)≥k}

з відношенням:

ξ~ₖη ⇔ ℓ(ξ,η)≥k

має утворювати відношення еквівалентності.

Це означає, що для кожного k воно повинно бути рефлексивним, симетричним і транзитивним.

### SF-C5 — Узгодженість рівнів

Кожен клас рівня k+1 повинен міститися рівно в одному класі рівня k.

### SF-C6 — Листкова повнота

Кожен клас на максимальному рівні повинен відповідати хоча б одному листку, що завершується на цьому рівні.

### SF-C7 — Корінь

На рівні 0 повинен існувати рівно один клас.

Для непорожнього дерева це відповідає єдиному кореню.

## Теорема 2. Достатність критеріїв

Якщо скінченні дані (L,h,ℓ) задовольняють SF-C1–SF-C7, то наведений алгоритм реконструює єдине кореневе дерево з точністю до ізоморфізму, що зберігає листки, глибини та LCA-відношення.

**Статус:** PROVED конструктивно.

# 9. W18.8 — Роль міри

Нехай:

μ:L(X)→(0,1],

Σξ μ(ξ)=1.

Зважений fingerprint:

SF_μ(X)=(SF(X),μ).

Якщо листки мічені, міра зберігається як функція на листках.

Якщо листки немічені, одночасна перестановка листків повинна переносити разом:

* глибини;
* LCA-матрицю;
* ваги міри.

## 9.1. Чому міра важлива

Одна й та сама топологічна структура може мати різні розподіли міри.

Це змінює оператор:

T_K=K D_μ.

Отже, спектр може змінюватися навіть за незмінного дерева.

## 9.2. Структура та міра — різні об'єкти

Позначимо:

X_struct=(V,E,r),

X_measured=(X_struct,μ).

Рівність структур не означає рівності вимірюваних дерев.

І навпаки, однаковий спектр операторів не гарантує однакової структури чи міри.

**Статус:** PROVED.

---

# 10. W18.9 — Інтегрований Structural Fingerprint

Визначимо повний fingerprint для скінченного зваженого дерева:

SF_full(X,μ)=
(L,h,A_LCA,μ).

Похідні компоненти:

* P_depth;
* P_level;
* P_arity;
* матриця деревних відстаней;
* загальна кількість вузлів;
* максимальна глибина.

Ці компоненти можна обчислити зі структурного fingerprint.

## 10.1. Розширена сигнатура

Для інтеграції зі спектральною теорією визначимо:

SF_ext(X,μ,K)=
(SF_full,Σ_spec).

Тут:

Σ_spec={Spec(T_q):q∈Q}.

Це не мінімальний набір для структурної реконструкції. Це розширений дослідницький об'єкт, який поєднує:

* структурну інформацію;
* міру;
* операторну інформацію;
* спектральну поведінку.

## 10.2. Принцип незмішування

SF_full і Σ_spec не повинні зливатися в один нерозрізнений дескриптор.

Структурна частина відповідає на питання:

«Яке дерево?»

Спектральна частина відповідає на питання:

«Як це дерево проявляється через заданий оператор?»

---

# 11. W18.10 — Відстань між Structural Fingerprints

Для двох дерев з однаковою кількістю мічених листків визначимо структурну відстань.

Нехай:

X=(L,h_X,A_X),

Y=(L,h_Y,A_Y).

Визначимо:

D_depth(X,Y)=maxξ|h_X(ξ)−h_Y(ξ)|.

D_LCA(X,Y)=maxξ,η|A_X(ξ,η)−A_Y(ξ,η)|.

Тоді:

D_SF(X,Y)=
w_h D_depth+w_L D_LCA,

де:

w_h,w_L≥0,

w_h+w_L=1.

Це метрика на множині мічених структурних fingerprints, якщо обидві ваги строго додатні.

### Доведення

Невід'ємність і симетричність очевидні.

Якщо D_SF=0, тоді:

h_X=h_Y,

A_X=A_Y.

За теоремою 1 дерева ізоморфні зі збереженням міток.

Нерівність трикутника виконується, оскільки максимум абсолютних різниць є метрикою, а невід'ємна зважена сума метрик також є метрикою за додатних ваг.

Отже, D_SF є метрикою на просторі допустимих мічених fingerprints.

**Статус:** PROVED.

## 11.1. Немічений випадок

Для немічених дерев визначимо:

D_SF^unlab(X,Y)=
min_P D_SF(X,P·Y),

де P пробігає всі допустимі перестановки листків.

Це відстань між класами fingerprints за перестановками.

Для коректного фактор-простору вона є метрикою на класах еквівалентності.

---

# 12. W18.11 — Структурна та спектральна відстані

Для порівняння двох дерев визначимо окремо:

D_struct(X,Y)=D_SF(X,Y),

D_spec(X,Y)=d_H(Spec(T_X),Spec(T_Y)).

Ці відстані вимірюють різні властивості.

Можливі випадки:

### Випадок A

D_struct=0,

D_spec=0.

Структури еквівалентні, оператори ізоспектральні.

### Випадок B

D_struct>0,

D_spec=0.

Структури різні, але оператори ізоспектральні.

### Випадок C

D_struct=0,

D_spec>0.

Структура однакова, але міра або ядро різні.

### Випадок D

D_struct>0,

D_spec>0.

Відрізняються і структура, і спектральна поведінка.

Ця класифікація забороняє інтерпретувати спектральну відстань як універсальну структурну відстань.

# 13. W18.12 — Контрольний приклад

Розглянемо два дерева W17:

Дерево A:

* корінь має дві гілки;
* перша містить чотири листки;
* друга містить два листки;
* перша гілка має збалансовану внутрішню структуру.

Дерево B:

* корінь має дві гілки;
* перша містить ті самі чотири листки;
* друга містить ті самі два листки;
* перша гілка має незбалансовану внутрішню структуру.

При q=0:

K₀(A)=K₀(B).

Тому:

T₀(A)=T₀(B).

І:

Spec(T₀(A))=Spec(T₀(B)).

Однак:

A_LCA(A)≠A_LCA(B)

за відповідного фіксованого маркування листків.

Отже:

D_SF(A,B)>0.

Це контрольний приклад, у якому спектральна відстань дорівнює нулю, але структурна відстань додатна.

Він демонструє незалежність структурної та спектральної інформації.

Подати матрицю, що порушує транзитивність відношення ~ₖ.

Очікуваний результат:

`INVALID_STRUCTURAL_FINGERPRINT`.

**SF-TEST-06 — Measure Preservation**

Перевірити, що перестановка листків одночасно переносить координати міри.

**SF-TEST-07 — q=0 Spectral Blindness**

T₀(A)=T₀(B),

D_SF(A,B)>0.

**SF-TEST-08 — Reconstruction Roundtrip**

Виконати:

SF(Tree)=SF(Tree').

**SF-TEST-09 — Label Permutation**

Переставити назви листків.

Перевірити незмінність неміченого fingerprint.

**SF-TEST-10 — Structural Distance**

Перевірити невід'ємність, симетричність та нерівність трикутника.

# 17. Висновок W18

W18 встановлює структурну основу реконструкції скінченних кореневих дерев.

Центральний результат:

**Для заданого класу скінченних кореневих дерев структура однозначно визначається множиною листків, їхніми глибинами та матрицею спільного предка.**

Це сильніше за спектральну реконструкцію, оскільки LCA-матриця зберігає безпосередню інформацію про ієрархію.

Водночас цей результат не слід поширювати на довільні нескінченні або зважені дерева без окремих доведень.

Архітектура SUBIT-WARP тепер має два незалежні рівні:

**Structural Layer**

Tree → SF → Reconstruction.

**Spectral Layer**

Tree → Measure → Kernel → Operator → Spectrum.

Їхнє поєднання:

**Structural Fingerprint + Spectral Signature → Extended Model Description.**

Проте структурний fingerprint залишається первинним джерелом інформації про дерево.

Це математично реалізує принцип:

**DO NOT COLLAPSE — CONTEXTUALIZE.**
