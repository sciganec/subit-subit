# 1. Базовий простір

Нехай:

`b≥2`.

`B_b={1,…,b}`.

`Σ_b=B_b^ℕ`.

На `Σ_b` визначено рівномірну ймовірнісну міру `μ_b`, для якої:

`μ_b([u])=b^(−|u|)`.

Тут `[u]` — циліндр усіх нескінченних адрес, що починаються з `u`.

Розглядаємо гільбертів простір:

`H=L²(Σ_b,μ_b)`.

Скалярний добуток:

`⟨f,g⟩=∫ f(ξ) overline(g(ξ)) dμ_b(ξ)`.

Для адрес `ξ,η` визначимо довжину спільного префікса:

`ℓ(ξ,η)=sup{n∈ℕ₀ : ξ|n=η|n}`.

Якщо `ξ=η`, то `ℓ(ξ,η)=∞`.

# 4. Власне значення на сталому підпросторі

Оскільки ядро залежить лише від довжини спільного префікса, оператор зберігає сталий підпростір.

Для сталої функції `1`:

`T_q1(ξ)=∫Σ_b q^{ℓ(ξ,η)}dμ_b(η)`.

Імовірність того, що дві незалежні адреси мають спільний префікс довжини рівно `k`, дорівнює:

`P(ℓ=k)=(b−1)b^(−k−1)`.

Тому:

`T_q1=(b−1)/b Σ_{k=0}∞(q/b)^k`.

Для `0≤q≤1`:

`T_q1=(b−1)/(b−q)`.

Отже, власне значення сталого підпростору:

`λ₀(q)=(b−1)/(b−q)`.

Це значення додатне на всьому відрізку `0≤q≤1`.

# 5. Спектр ієрархічних мод

Розглянемо функцію `f∈W_j`.

Нехай `ξ` належить дочірньому циліндру глибини `j`, який має батьківський циліндр глибини `j−1`.

На дочірніх циліндрах усередині цього батьківського циліндра функція `f` має значення з нульовою сумою.

Розділимо інтеграл на:

1. той самий дочірній циліндр;
2. інші дочірні циліндри того самого батьківського циліндра;
3. решту простору.

Для третьої частини внесок дорівнює нулю через нульове середнє функції на батьківських циліндрах.

Внесок того самого дочірнього циліндра:

`b^(−j)q^j λ₀(q)f(ξ)`.

Сумарний внесок інших дочірніх циліндрів:

`−b^(−j)q^(j−1)f(ξ)`.

Отже:

`T_qf = b^(−j)[q^jλ₀(q)−q^(j−1)]f`.

Підставляємо:

`λ₀(q)=(b−1)/(b−q)`.

Отримуємо:

`λ_j(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)]`.

Таким чином, спектр:

**Стала мода**

`λ₀(q)=(b−1)/(b−q)`.

**Моди глибини j≥1**

`λ_j(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)]`.

**Кратність**

`m_j=(b−1)b^(j−1)`.

Формули W39 для спадного ядра підтверджуються незалежним виведенням.

# 9. Поріг обмеженості

Інтеграл ядра за другим аргументом:

`∫K_t(ξ,η)dμ_b(η)`

дорівнює:

`(b−1)/b Σ_{k=0}∞(t/b)^k`.

Цей ряд збігається тоді й лише тоді, коли:

`t<b`.

За критерієм Шура, симетричне невід'ємне ядро з рівномірно обмеженими інтегралами рядків задає обмежений оператор на `L²`.

Отже, для:

`1<t<b`

оператор `T_t` є обмеженим.

Оскільки:

`K_t(ξ,η)≥0`,

його інтегральна форма є невід'ємною на невід'ємних функціях.

Для повної позитивної визначеності використовується ієрархічний спектральний розклад, наведений нижче.

# 10. Поріг Hilbert–Schmidt

Оператор із ядром `K_t` є Hilbert–Schmidt тоді й лише тоді, коли:

`∫∫|K_t(ξ,η)|²dμ_b(ξ)dμ_b(η)<∞`.

За симетрією:

`∫∫t^(2ℓ(ξ,η))dμ_b(ξ)dμ_b(η)`

дорівнює:

`(b−1)/b Σ_{k=0}∞(t²/b)^k`.

Отже, ряд збігається тоді й лише тоді, коли:

`t²<b`.

Тобто:

**Hilbert–Schmidt threshold**

`t<√b`.

Це строгіша умова, ніж обмеженість:

`√b<b`.

Тому існує область:

`√b≤t<b`,

у якій оператор обмежений, але не є Hilbert–Schmidt.

Це принципове розрізнення.

# 11. Компактність зростаючого оператора

Для:

`1<t<b`

визначимо усічене ядро:

`K_t^(N)(ξ,η)=t^{min(ℓ(ξ,η),N)}`.

Це ядро залежить лише від перших `N` координат адрес.

Тому відповідний оператор `T_t^(N)` має скінченний ранг і є компактним.

Різниця ядер:

`K_t−K_t^(N)`.

За критерієм Шура норма відповідної різниці операторів обмежена максимальною інтегральною нормою залишку.

Для фіксованої адреси:

`∫(K_t−K_t^(N))dμ_b`

дорівнює:

`(b−1)/b Σ_{k=N}∞(t/b)^k − (t/b)^N` з відповідним урахуванням маси циліндра рівня N.

Еквівалентно, оскільки для `ℓ≥N` усічене ядро дорівнює `t^N`, залишок інтеграла має вигляд:

`(t/b)^N · (t−1)/(b−t)`.

Для `1<t<b` ця величина прямує до нуля.

Отже:

`‖T_t−T_t^(N)‖→0`.

Оскільки `T_t^(N)` компактний, а границя компактних операторів у операторній нормі компактна:

**Твердження:** `T_t` компактний для `1<t<b`.

# 13. Trace-class threshold

Для зростаючого ядра:

`Σ_{j≥1}m_jλ_j(t)`

дорівнює:

`(b−1)(t−1)/(b−t) Σ_{j≥1}t^(j−1)`.

Для будь-якого `t>1` цей ряд розбігається.

Отже, навіть у діапазоні:

`1<t<b`

оператор не є trace-class.

Таким чином, маємо:

- bounded: `1<t<b`;
- compact: `1<t<b`;
- Hilbert–Schmidt: `1<t<√b`;
- trace-class: жодного `t>1`.

Важливо: trace-class властивість тут не можна виводити з компактності або Hilbert–Schmidt властивості.

# 14. Необмеженість при t≥b

Однієї розбіжності інтеграла рядка недостатньо для формального висновку про необмеженість.

Потрібно показати, що норми відповідних скінченних апроксимацій необмежено зростають.

Визначимо:

`K_t^(N)(ξ,η)=t^{min(ℓ(ξ,η),N)}`.

Нехай `1` — нормована стала функція в `L²(Σ_b,μ_b)`.

Тоді:

`⟨1,T_t^(N)1⟩`

дорівнює:

`(b−1)/b Σ_{k=0}^{N−1}(t/b)^k + (t/b)^N`.

Для `t=b`:

`⟨1,T_b^(N)1⟩=(b−1)N/b+1`.

Це прямує до нескінченності.

Для `t>b` останній доданок зростає експоненційно.

Отже:

`‖T_t^(N)‖ ≥ ⟨1,T_t^(N)1⟩ →∞`.

Таким чином, усічені позитивні оператори не мають рівномірної межі в операторній нормі.

Це виключає існування обмеженого позитивного оператора, який реалізує граничну інтегральну форму ядра `K_t`.

**Висновок:** для `t≥b` оператор не має обмеженого extension на всьому `L²(Σ_b,μ_b)` із цією інтегральною формою.

# 16. Скінченновимірні апроксимації

Для кожного `n≥0`:

`H_n=P_nH`.

Розглянемо:

`T_q^(n)=P_nT_qP_n|_{H_n}`.

Виберемо ортонормований базис:

`e_u=b^(n/2)1_[u]`, де `|u|=n`.

Тоді матричні елементи:

`A_n(u,v)=⟨e_u,T_qe_v⟩`.

## 16.1. Різні циліндри

Якщо `u≠v`, довжина спільного префікса `ℓ(u,v)` стала на `[u]×[v]`.

Тому:

`A_n(u,v)=b^(−n)q^{ℓ(u,v)}`.

## 16.2. Той самий циліндр

Якщо `u=v`, умовний спектральний інтеграл усередині циліндра дає:

`A_n(u,u)=b^(−n)q^nλ₀(q)`.

Отже:

`A_n(u,u)=b^(−n)q^n(b−1)/(b−q)`.

## 16.3. Повна матриця

Таким чином:

`A_n(u,v)=`

- `b^(−n)q^{ℓ(u,v)}`, якщо `u≠v`;
- `b^(−n)q^n(b−1)/(b−q)`, якщо `u=v`.

Це матричне представлення оператора `P_nT_qP_n` в ортонормованому циліндричному базисі.

Її ранг не перевищує `b`.

Це відповідає скінченному рангу нескінченного оператора `T₀`.

# 18. Trace-norm convergence

Для `0≤q<1` оператор `T_q` є trace-class.

Оскільки:

`H_n=H₀⊕W₁⊕…⊕W_n`,

проєкція `P_n` зберігає перші `n` ієрархічних рівнів.

Тому:

`T_q−P_nT_qP_n`

складається лише з рівнів `j>n`.

Trace norm різниці:

`‖T_q−P_nT_qP_n‖₁`

дорівнює:

`Σ_{j=n+1}∞m_j|λ_j(q)|`.

Підставляємо формули:

`=(b−1)(1−q)/(b−q) Σ_{j=n+1}∞q^(j−1)`.

Отже:

`‖T_q−P_nT_qP_n‖₁=(b−1)/(b−q)q^n`.

Для `0≤q<1`:

`‖T_q−T_q^(n)‖₁→0`.

Для `q=1` оператор має ранг 1 і міститься в кожному `H_n`, тому:

`P_nT₁P_n=T₁`.

Таким чином, trace-norm convergence підтверджується для всього відрізка `0≤q≤1`.

# 19. Важливе розмежування матриць та операторів

Матриця `A_n` — це не повний нескінченний оператор.

Вона є його ортогональною компресією:

`P_nT_qP_n|_{H_n}`.

Тому:

1. спектр `A_n` містить лише перші `n` ієрархічних рівнів;
2. відсутні в матриці вищі рівні не є нульовими власними значеннями повного оператора;
3. вони вилучені з апроксимації;
4. для trace-class оператора похибка контрольована trace norm;
5. для оператора, який не є trace-class, такий висновок автоматично не переноситься.

Це має бути прямо зазначено в реалізації SUBIT-WARP.

# 21. Питання, які залишаються відкритими

## Q1. Відповідність W30

Потрібно звірити, чи використовує W30:

- ту саму нормалізацію `μ_b`;
- ту саму конвенцію `ℓ(ξ,η)`;
- ту саму діагональну конвенцію;
- той самий оператор `T_q`;
- той самий циліндричний базис.

Без цього спектральні формули математично узгоджені з моделлю W42, але ще не можуть бути оголошені підтвердженням усіх формул W30.

## Q2. Оператор для t≥b

Для `t≥b` можна досліджувати щільно визначені необмежені оператори та замикання квадратичних форм.

Але це інша математична конструкція, ніж обмежений оператор на всьому `L²`.

Її не слід додавати до базової архітектури без окремої специфікації області визначення.

## Q3. Зв'язок із геометричними параметрами WARP

Спектральний параметр `q` або `t` не можна автоматично ототожнювати з геометричним параметром `α`.

Потрібно довести конкретне відображення параметрів та перевірити його сумісність із метрикою:

`d_α(ξ,η)=exp(−αℓ(ξ,η))`.

## Q4. Спектральна геометрія та фізична інтерпретація

Спектральні пороги є математичними властивостями ієрархічного інтегрального оператора.

Самі по собі вони не доводять фізичної інтерпретації гравітації, геометрії простору-часу чи Randall–Sundrum відповідності.

# 22. Підсумок

W42 підтверджує, що спектральна архітектура ієрархічного ядра має внутрішньо узгоджену математичну структуру.

Для спадного ядра:

`K_q=q^ℓ`, `0≤q≤1`:

- оператор обмежений;
- компактний;
- Hilbert–Schmidt;
- trace-class;
- спектр має одну додатну сталу моду та від'ємні ієрархічні моди.

Для зростаючого ядра:

`K_t=t^ℓ`, `t>1`:

- обмеженість: `t<b`;
- компактність: `t<b`;
- Hilbert–Schmidt: `t<√b`;
- trace-class: відсутня для всіх `t>1`;
- при `t≥b` обмежений оператор із заданою інтегральною формою не існує.

Скінченновимірні матриці є коректними ортогональними компресіями нескінченного оператора. Для спадного ядра доведено збіжність у trace norm.
