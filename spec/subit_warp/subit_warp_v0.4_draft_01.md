# SUBIT-WARP v0.4

## W12 — Spectral Geometry and Inverse Problems

**Статус:** DRAFT · MATHEMATICALLY DERIVED · NOT FORMALLY VERIFIED
**Залежності:** W0–W11
**Мета:** встановити, яку структурну та параметричну інформацію можна відновити зі спектра ієрархічного оператора SUBIT-WARP.

---

## W12.0. Постановка задачі

У попередніх розділах визначено оператор

`T_q f(ξ) = ∫Σ q^{ℓ(ξ,η)} f(η) dμ(η)`

де:

* `Σ = {1,2,3}^ℕ` — межа трійкового дерева;
* `μ` — рівномірна бернуллівська міра;
* `ℓ(ξ,η)` — довжина спільного початкового префікса;
* `q = exp(−α𝑤)`, `0 < q < 1`.

Спектральна задача має вигляд:

`T_q f = λf`.

Обернена задача ставить інше питання:

**Яку інформацію про початкову геометрію та параметри системи можна відновити, знаючи спектр T_q?**

Необхідно розрізняти три рівні:

1. Параметрична ідентифікація — відновлення `q`.
2. Структурна ідентифікація — відновлення арності дерева.
3. Геометрична ідентифікація — відновлення метрики та її масштабних параметрів.

Ці задачі не є еквівалентними.

---

## W12.1. Спектральна структура

Для `0 < q < 1` оператор `T_q` має:

* одне власне значення на просторі сталих функцій;
* нескінченну послідовність від’ємних власних значень на ієрархічних хвильових підпросторах;
* нуль як точку накопичення спектра.

Позначимо:

`c_q = 2/(3−q)`

`λ₀(q) = c_q`

а для `j ≥ 1`:

`λⱼ(q) = −(1−q)q^(j−1) / [3^(j−1)(3−q)]`

Кратності:

`m₀ = 1`

`mⱼ = 2·3^(j−1)`.

Отже:

`Spec(T_q) = {0} ∪ {c_q} ∪ {λⱼ(q) : j ≥ 1}`.

Тут `0` є точкою накопичення, але не власним значенням для `0 < q < 1`.

Важливо: `T_q` є компактним, самоспряженим і слідовим оператором. Його слід дорівнює нулю:

`Tr(T_q) = 0`.

Норма слідового класу:

`‖T_q‖₁ = 4/(3−q)`.

## W12.2. Теорема відновлення параметра q

### Теорема W12-T01 — Ratio Recovery

Для кожного `j ≥ 1`:

`λⱼ₊₁(q)/λⱼ(q) = q/3`.

Тому:

`q = 3·λⱼ₊₁/λⱼ`.

**Доведення.**

Із формули власних значень:

`λⱼ(q) = −(1−q)q^(j−1)/[3^(j−1)(3−q)]`

`λⱼ₊₁(q) = −(1−q)q^j/[3^j(3−q)]`.

Ділення дає:

`λⱼ₊₁/λⱼ = q/3`.

Отже:

`q = 3λⱼ₊₁/λⱼ`.

Теорему доведено.

### Наслідок W12-C01

Параметр взаємодії відновлюється:

`α𝑤 = −ln(q)`.

Таким чином, за наявності двох послідовних ненульових ієрархічних власних значень можна відновити `α𝑤`.

### Практичне обмеження

У чисельному експерименті відновлення `q` залежатиме від точності оцінювання малих власних значень.

Оскільки:

`|λⱼ| → 0` при `j → ∞`,

високорівневі власні значення можуть бути чутливими до похибок округлення, шуму та неповноти даних.

Для практичної ідентифікації доцільно використовувати кілька послідовних пар власних значень і оцінювати:

`q̂ = median(3λⱼ₊₁/λⱼ)`.

Це чисельна процедура, а не окрема математична теорема про статистичну оптимальність оцінки.

## W12.3. Відновлення арності дерева

У поточній моделі використовується трійковий алфавіт:

`B = {1,2,3}`.

Однак спектральну конструкцію можна узагальнити на `b`-арне дерево:

`B_b = {1,...,b}`, `b ≥ 2`.

Нехай:

`Σ_b = B_b^ℕ`

і `μ_b` — рівномірна бернуллівська міра.

Для ядра:

`K_q(ξ,η) = q^ℓ(ξ,η)`

отримуємо загальні формули.

### Теорема W12-T02 — b-ary Spectrum

Для `0 < q < 1`:

**Власне значення сталого підпростору:**

`c_q^(b) = (b−1)/(b−q)`.

**Ієрархічні власні значення:**

`λⱼ^(b)(q) = −(1−q)q^(j−1) / [b^(j−1)(b−q)]`.

**Кратності:**

`mⱼ^(b) = (b−1)b^(j−1)`.

**Відношення сусідніх власних значень:**

`λⱼ₊₁^(b)/λⱼ^(b) = q/b`.

**Доведення.**

Імовірність того, що два незалежні випадкові промені мають спільний префікс довжини рівно `k`, дорівнює:

`P(ℓ = k) = (b−1)/b^(k+1)`.

Тому:

`∫Σ_b q^ℓ dμ_b = Σₖ₌₀∞ (b−1)q^k/b^(k+1)`

`= (b−1)/(b−q)`.

Для хвильового підпростору рівня `j` значення функції на `b` дочірніх циліндрах мають суму нуль.

Внесок дочірнього циліндра, який містить точку `ξ`, становить:

`b^(−j)q^j c_q^(b)`.

Сумарний внесок інших дочірніх циліндрів:

`−b^(−j)q^(j−1)`.

Отже:

`λⱼ^(b) = b^(−j)(q^j c_q^(b) − q^(j−1))`

`= −(1−q)q^(j−1)/[b^(j−1)(b−q)]`.

Розмірність хвильового підпростору:

`b^j − b^(j−1) = (b−1)b^(j−1)`.

Теорему доведено.

## W12.4. Теорема структурної ідентифікації

### Теорема W12-T03 — Branching Recovery

Якщо спектр оператора заданий разом із кратностями його власних значень, то для цієї рівномірної b-арної моделі арність дерева визначається співвідношенням:

`b = mⱼ₊₁/mⱼ`.

Після цього:

`q = b·λⱼ₊₁/λⱼ`.

**Інтерпретація.**

Спектральна структура містить два різні типи інформації:

* відношення власних значень визначає `q/b`;
* відношення кратностей визначає `b`.

Разом вони дозволяють відновити `b` і `q`.

Для SUBIT-WARP:

`b = 3`

`mⱼ₊₁/mⱼ = 3`

`q = 3λⱼ₊₁/λⱼ`.

### Межа теореми

Цей результат стосується саме сімейства рівномірних b-арних моделей із заданим типом ядра.

Він не доводить, що довільне дерево можна однозначно відновити за спектром довільного оператора на його межі.

Також необхідно зберігати кратності. Якщо доступний лише набір різних власних значень без спектральних кратностей, наведений спосіб відновлення арності безпосередньо не застосовується.

## W12.5. Геометрична неідентифікованість αᵥ

Це один із найважливіших результатів W12.

У W3 визначено граничну метрику:

`dᵥ(ξ,η) = exp(−αᵥℓ(ξ,η))`.

Її параметр `αᵥ` визначає масштаб геометрії межі.

Для трійкового дерева:

`dim_H(Σ,dᵥ) = ln(3)/αᵥ`.

Однак спектральні формули W7 залежать від:

`q = exp(−α𝑤)`

і рівномірної міри `μ`.

Параметр `αᵥ` у формулах спектра `T_q` безпосередньо не присутній.

### Теорема W12-T04 — Metric Non-identifiability

Нехай два набори параметрів мають однакове значення `q`, але різні значення `αᵥ`:

`αᵥ¹ ≠ αᵥ²`.

Тоді відповідні оператори `T_q` на тому самому вимірному просторі `(Σ,μ)` мають однаковий спектр, хоча граничні метрики:

`dᵥ¹(ξ,η) = exp(−αᵥ¹ℓ(ξ,η))`

і

`dᵥ²(ξ,η) = exp(−αᵥ²ℓ(ξ,η))`

різні.

Отже, спектр `T_q` сам по собі не визначає `αᵥ`.

**Доведення.**

Формула оператора:

`T_q f(ξ) = ∫Σ q^ℓ(ξ,η)f(η)dμ(η)`

не містить `αᵥ`.

Тому за незмінних `q`, `Σ` і `μ` оператор залишається тим самим незалежно від вибору `αᵥ`.

Водночас зміна `αᵥ` змінює метрику та її розмірність Гаусдорфа.

Отже, однаковий спектр сумісний із різними значеннями `αᵥ`.

Теорему доведено.

### Наслідок W12-C02

Ізольований спектральний аналіз `T_q` дозволяє відновити параметр взаємодії `α𝑤`, але не параметр геометричного масштабу `αᵥ`.

Для відновлення `αᵥ` потрібна додаткова геометрична інформація.

Наприклад:

* безпосередні вимірювання відстаней;
* оцінка розмірності межі;
* метрично залежний оператор;
* спектральні дані іншого оператора, що явно залежить від `dᵥ`.

## W12.6. Принцип збереження параметричної незалежності

У SUBIT-WARP не можна ототожнювати:

`αᵥ` — параметр граничної геометрії;

`α𝑤` — параметр взаємодії;

`q = exp(−α𝑤)` — параметр спектрального ядра.

Навіть якщо ввести:

`β = α𝑤/αᵥ`,

то:

`dᵥ(ξ,η)^β = exp(−αᵥβℓ) = exp(−α𝑤ℓ) = q^ℓ`.

Це означає, що ядро можна записати через метрику:

`K(ξ,η) = dᵥ(ξ,η)^β`.

Але така перепараметризація не забезпечує відновлення `αᵥ`.

Якщо відомий лише `β` і спектр ядра, що визначає `α𝑤`, то:

`αᵥ = α𝑤/β`.

Однак якщо `β` не виміряний незалежно, геометричний масштаб залишається неідентифікованим.

**Архітектурне правило W12-R01:**

`DO NOT COLLAPSE αᵥ AND α𝑤`.

Параметри геометрії та взаємодії повинні залишатися незалежними до появи окремої теореми або емпіричного обґрунтування їхнього зв'язку.

## W12.7. Узагальнені спектральні інваріанти

Для b-арної моделі можна визначити такі інваріанти.

### 1. Спектральне відношення

`Rλ = λⱼ₊₁/λⱼ = q/b`.

### 2. Відношення кратностей

`Rm = mⱼ₊₁/mⱼ = b`.

### 3. Параметр взаємодії

`q = Rλ·Rm`.

### 4. Параметр взаємодії в експоненціальній формі

`α𝑤 = −ln(Rλ·Rm)`.

### 5. Норма оператора

Оскільки найбільше за модулем власне значення — `c_q^(b)`:

`‖T_q‖ = (b−1)/(b−q)`.

### 6. Слідова норма

`‖T_q‖₁ = 2(b−1)/(b−q)`.

### 7. Норма Гільберта—Шмідта

`‖T_q‖²_HS = (b−1)/(b−q²)`.

### 8. Слід

`Tr(T_q) = 0`.

Ці величини утворюють спектральний профіль моделі.

Для `b=3` вони переходять у результати W7.

## W12.8. Необхідні застереження щодо оберненої задачі

Отримані теореми не дають підстав стверджувати, що спектр повністю визначає геометрію межі.

Необхідно розділяти такі твердження:

| Задача                                         | Статус                                             |
| ---------------------------------------------- | -------------------------------------------------- |
| Відновлення q за сусідніми власними значеннями | Доведено для заданої моделі                        |
| Відновлення α𝑤                                | Доведено за умови відомого спектрального сімейства |
| Відновлення b за кратностями                   | Доведено для рівномірної b-арної моделі            |
| Відновлення αᵥ зі спектра T_q                  | Неможливе без додаткових даних                     |
| Відновлення довільної топології межі           | Не доведено                                        |
| Відновлення довільної метрики межі             | Не доведено                                        |
| Відновлення нерівномірної міри                 | Потребує окремої теорії                            |

Особливо важливо: однаковий спектр не обов'язково означає ізометричність просторів. Спектральна еквівалентність є слабшою за метричну еквівалентність.

## W12.9. Обчислювальна програма

Для перевірки W12 необхідно реалізувати окремий модуль `subit-warp-inverse`.

### INV-01 — Parameter Recovery

Вхідні дані:

* спектральні власні значення;
* кратності;
* допустима похибка.

Вихідні дані:

* оцінка `q`;
* оцінка `α𝑤`;
* залишки відновлення.

### INV-02 — Branching Recovery

Вхідні дані:

* послідовність кратностей `mⱼ`.

Вихідні дані:

* оцінка `b`;
* перевірка геометричної послідовності кратностей.

### INV-03 — Spectral Consistency

Перевірити:

`λⱼ₊₁/λⱼ ≈ q/b`

`mⱼ₊₁/mⱼ ≈ b`.

### INV-04 — Metric Non-identifiability Test

Побудувати дві моделі:

* однакові `b`, `q`, `μ`;
* різні `αᵥ`.

Перевірити:

* спектри `T_q` збігаються;
* метрики відрізняються;
* розмірності Гаусдорфа відрізняються.

Цей тест є чисельною ілюстрацією теореми W12-T04, а не її доказом.

### INV-05 — Noise Sensitivity

Дослідити вплив похибок на оцінку:

`q̂ⱼ = b·λ̂ⱼ₊₁/λ̂ⱼ`.

Особливу увагу приділити великим `j`, де абсолютні значення власних чисел малі.

## W12.12. Висновок

Спектральна структура SUBIT-WARP несе інформацію про ієрархічну організацію простору.

У межах рівномірної b-арної моделі:

* геометрія розгалуження кодується спектральними кратностями;
* параметр взаємодії кодується відношеннями сусідніх власних значень;
* геометричний масштаб межі не визначається спектром оператора взаємодії.

Це встановлює принципову межу оберненої задачі.

Спектр не є повним описом простору. Він є проєкцією певних структурних властивостей на операторний рівень.

**SUBIT-WARP W12 формулює це як окремий принцип:**

`SPECTRAL EQUIVALENCE ≠ METRIC EQUIVALENCE`.

Відновлення структури потребує збереження контексту, в якому ця структура визначена.
