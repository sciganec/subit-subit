1. інтегрувати всі підтверджені математичні виправлення;
2. усунути суперечності між попередніми редакціями;

W33 не оголошує математичну систему формально верифікованою і не присвоює статус STABLE.

## W33.2. Канонічні простори

Для b ≥ 2:

B_b = {1, 2, …, b}

Pos_b = B_b^{<ω}

Σ_b = B_b^ℕ

Простір нескінченних адрес Σ_b не ототожнюється з множиною скінченних адрес Pos_b.

Повне дерево:

FullTree_A^(b) ≅ A ⊔ (FullTree_A^(b))^b

Часткове дерево визначається окремим типом:

PartialTree_A^(b) ≅ None ⊔ A ⊔ (PartialTree_A^(b))^b

Скінченне кореневе дерево FiniteTree визначається окремо.

Відсутня позиція None не є листком і не інтерпретується автоматично як нескінченна гілка.

## W33.3. Канонічні метрики

Адресна ультраметрика:

d_Σ(ξ,η) = 2^−ℓ(ξ,η)

Метрика дерев:

d_F(f,g) = 2^−r_addr(f,g)

Метрика скінченних листків:

d_T(ξ,η) = h(ξ) + h(η) − 2ℓ(ξ,η)

Метрика Гаусдорфа:

d_H(K,L) = max{supₓ∈K infᵧ∈L d(x,y), supᵧ∈L infₓ∈K d(x,y)}

Її стандартна область визначення — непорожні компактні множини.

Жодні дві з чотирьох метрик не ототожнюються лише через подібність їхніх формул.

---

## W33.4. Grafting і геометрія межі

Для трійкового дерева:

ρ_a(f) = Node(f, Leaf(a), Leaf(a))

Контрактивність:

d_F(ρ_a(f),ρ_a(g)) = ½d_F(f,g)

Для граничного відображення область визначення обмежується:

Tω⁺ = {f ∈ Tω : ∂f ≠ ∅}

Основна оцінка:

d_H(∂f,∂g) ≤ 2d_F(f,g)

Усі твердження про межу повинні явно вказувати область визначення та умови непорожності.

## W33.5. Hausdorff dimension

Для метрики:

d_v(ξ,η) = exp(−α_vℓ(ξ,η))

канонічна формула:

dim_H(Σ_b,d_v) = ln(b)/α_v

Доведення має містити:

1. оцінку діаметрів циліндрів;
2. верхню оцінку Hausdorff dimension;
3. міру циліндрів;
4. оцінку для довільних достатньо малих множин;
5. нижню оцінку за принципом розподілу маси.

Оцінка лише на циліндричних множинах не вважається завершеним доведенням нижньої межі.

## W33.6. Спадне ядро

Для q ∈ [0,1]:

K_q(ξ,η) = q^ℓ(ξ,η)

Діагональна домовленість:

q^∞ = 1.

Окрема домовленість:

q⁰ = 1 для всіх q ∈ [0,1].

Це визначення є частиною специфікації ядра, а не загальною зміною арифметики.

Основні режими:

- q = 0;
- 0 < q < 1;
- q = 1.

Для q = 1:

T₁ = P_const.

Формули, що містять знаменник b − q, застосовуються лише за умов, за яких знаменник ненульовий.

## W33.7. Спектральна модель

Для основного режиму 0 < q < 1:

c_q = (b−1)/(b−q)

λ_j = −(1−q)q^(j−1)/[b^(j−1)(b−q)]

m_j = (b−1)b^(j−1)

Канонічний спектральний опис має включати:

- сталий підпростір;
- ієрархічні підпростори;
- відповідні власні значення;
- кратності;
- повноту ортогонального розкладу;
- граничну точку спектра.

Для q = 0 та q = 1 потрібні окремі твердження.

## W33.8. Скінченні апроксимації

Нехай P_n — ортогональна проєкція на циліндричний підпростір H_n.

T_q^(n) = P_nT_qP_n|H_n

Для i ≠ j:

M_n(i,j) = b^−n q^ℓ(i,j)

Для i = j:

M_n(i,i) = b^−n q^n c_q

Скінченний слід:

Tr(T_q^(n)) = q^n c_q

Ця формула не є автоматичним твердженням про слід нескінченновимірного T_q.

## W33.9. Операторна та слідова збіжність

Необхідно окремо розглядати:

- збіжність у операторній нормі;
- збіжність у нормі Гільберта—Шмідта;

Жодна з цих форм збіжності не підміняє іншу без окремої теореми.

Зокрема, границя q → 1⁻ потребує окремого аналізу слідової норми.
