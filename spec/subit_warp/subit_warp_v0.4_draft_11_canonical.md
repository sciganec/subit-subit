# W23.1. Канонічні множини та типи

## W23.1.1. Алфавіт листків

Нехай:

A = {00, 01, 10, 11}.

Елементи A є мітками листків.

## W23.1.2. Алфавіт розгалуження

Для базової трійкової моделі:

B = {1, 2, 3}.

Для узагальненої b-арної моделі:

B_b = {1, 2, …, b}, де b ≥ 2.

## W23.1.3. Простір адрес

Pos_b = B_b^{<ω}.

Pos_b містить усі скінченні слова над алфавітом B_b, включно з порожнім словом ε.

ε позначає корінь.

Для адрес u, v:

* u ⪯ v означає, що u є префіксом v;
* |u| означає довжину адреси;
* u·i означає приєднання символу i до адреси u.

## W23.1.4. Повні нескінченні дерева

Визначимо коіндуктивний тип:

FullTree_A ≅ Leaf(A) ⊔ Node(FullTree_A^3).

Тут:

* Leaf(a) — листок із міткою a ∈ A;
* Node(f₁,f₂,f₃) — внутрішній вузол із трьома дочірніми піддеревами.

Ця конструкція задає повне трійкове розгалуження кожного внутрішнього вузла.

Для загального b:

FullTree_A^(b) ≅ Leaf(A) ⊔ Node(FullTree_A^b).

Це основний тип дерева для однорідної b-арної моделі.

## W23.1.5. Часткові дерева

Часткове дерево визначається окремо:

PartialTree_A^(b)
≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A^(b))^b.

Інтерпретація:

* None — відсутня позиція;
* Leaf(a) — наявний листок;
* Node(...) — внутрішній вузол.

None не є листком і не має автоматично інтерпретуватися як порожній нескінченний простір.

Повні та часткові дерева не ототожнюються:

FullTree_A^(b) ≠ PartialTree_A^(b).

## W23.1.6. Скінченні кореневі дерева

Окремо визначимо FiniteTree:

* скінченне зв'язне ациклічне дерево;
* має виділений корінь;
* кожна вершина досяжна з кореня;
* кожна вершина лежить на деякому шляху від кореня до листка;
* ребра мають додатну довжину.

Для структурної реконструкції W18–W23 основна модель використовує одиничні довжини ребер.

Скінченні дерева не є підтипом нескінченних дерев без додаткової конструкції вкладення.

# W23.2. Простір межі

Для повної b-арної моделі:

Σ_b = B_b^ℕ.

Елемент ξ ∈ Σ_b є нескінченною адресою:

ξ = (ξ₁, ξ₂, ξ₃, …).

Для n ≥ 0 позначимо:

ξ|n = (ξ₁, …, ξₙ).

За n = 0:

ξ|0 = ε.

Межа повного дерева f:

∂f = {ξ ∈ Σ_b : для кожного n ≥ 0 вузол f(ξ|n) є внутрішнім}.

Для повного нескінченного дерева кожна нескінченна адреса визначає граничну гілку.

Для часткових дерев межа визначається окремо, оскільки відсутня позиція може обірвати адресу.

Необхідно розрізняти:

* Σ_b — повний простір можливих адрес;
* ∂f — множина нескінченних гілок конкретного дерева;
* Leaves(f) — множина листків конкретного дерева.

# W23.3. Адресна метрика

Для двох різних адрес ξ, η ∈ Σ_b визначимо:

ℓ(ξ,η) = max{n ≥ 0 : ξ|n = η|n}.

Для ξ = η покладемо:

ℓ(ξ,ξ) = ∞.

Адресна ультраметрика:

d_S(ξ,η) = 2^(−ℓ(ξ,η)).

Зокрема:

d_S(ξ,ξ) = 0.

Для двох різних послідовностей:

0 < d_S(ξ,η) ≤ 1.

Виконується ультраметрична нерівність:

d_S(ξ,ζ) ≤ max(d_S(ξ,η), d_S(η,ζ)).

Це канонічна метрика повного простору адрес.

## W23.3.1. Метрика на скінченних деревах

Для скінченних дерев із однаково визначеною множиною листків використовуємо глибини та LCA-структуру.

Для листків ξ, η:

d_T(ξ,η) = h(ξ) + h(η) − 2ℓ(ξ,η).

Це звичайна відстань уздовж дерева.

Не слід ототожнювати d_T з адресною ультраметрикою d_S.

Перша є деревною метрикою на листках скінченного дерева, друга — ультраметрикою на нескінченних адресах.

# W23.4. Контрактивне вкладення та grafting

Для трійкового дерева визначимо:

ρ_a(f) = Node(f, Leaf(a), Leaf(a)).

Тут a ∈ A.

За адресною метрикою на деревному просторі, у якому перша дочірня гілка відповідає першому символу адреси, маємо:

d_S(ρ_a(f), ρ_a(g)) = 1/2 · d_S(f,g).

Отже:

Lip(ρ_a) = 1/2.

За теоремою Банаха кожне ρ_a має єдину нерухому точку p_a.

Вона задовольняє:

p_a = Node(p_a, Leaf(a), Leaf(a)).

Цей результат справедливий за умови, що простір дерев із метрикою d_S є повним.

**Статус:** PROVED за умови повноти визначеного простору дерев.

Для загального b-арного grafting потрібне окреме визначення позиції вкладення. Не можна автоматично переносити коефіцієнт 1/2 на довільне b-арне відображення.

# W23.5. Геометрія межі

Визначимо параметричну метрику:

d_v(ξ,η) = exp(−α_v ℓ(ξ,η)),

де α_v > 0.

Оскільки:

d_S(ξ,η) = 2^(−ℓ(ξ,η)),

то:

d_v(ξ,η) = d_S(ξ,η)^γ,

де:

γ = α_v / ln 2.

## W23.5.1. Hausdorff dimension

Для повного однорідного b-арного простору:

dim_H(Σ_b,d_v) = ln b / α_v.

Ця формула не переноситься автоматично на неоднорідні дерева.

## W23.5.2. Регулярність граничного відображення

Нехай задано відображення:

∂ : F → K(Σ_b),

де F — визначений простір дерев, а K(Σ_b) — простір непорожніх компактних підмножин межі.

Якщо буде доведено базову оцінку:

d_H,S(∂f,∂g) ≤ C₀ d_F(f,g),

то для метрики d_v маємо:

d_H,v(∂f,∂g) ≤ C₀^γ d_F(f,g)^γ.

Для попередньої оцінки C₀ = 2:

d_H,v(∂f,∂g) ≤ 2^γ d_F(f,g)^γ.

Якщо γ ≥ 1 і d_F ≤ 1:

d_H,v(∂f,∂g) ≤ 2^γ d_F(f,g).

Тому гарантована Lipschitz-константа:

L ≤ 2^γ.

Вона дорівнює 2 лише за γ = 1 у межах цієї оцінки.

**Критичне уточнення:** сама базова оцінка для граничного відображення не вважається доведеною без окремого доказу. W23 фіксує її як умову для подальшої теореми регулярності.

Статус базової оцінки: PROOF REQUIRED.

# W23.6. Простір компактних підмножин межі

Нехай K(Σ_b) — множина всіх непорожніх компактних підмножин Σ_b.

Для C,D ∈ K(Σ_b) визначимо метрику Гаусдорфа:

# d_H(C,D)

max {
sup_{x∈C} inf_{y∈D} d_v(x,y),
sup_{y∈D} inf_{x∈C} d_v(x,y)
}.

Для розширення простору введемо:

K₀(Σ_b) = K(Σ_b) ∪ {∅}.

Визначимо відстань до порожньої множини:

d_H(∅,C) = d_H(C,∅) = 2,

для кожного непорожнього C.

Також:

d_H(∅,∅) = 0.

Оскільки діаметр Σ_b не перевищує 1, вибір відстані 2 відокремлює ∅ від усіх непорожніх компактів.

Це є окремою метричною конструкцією, а не стандартною формулою Hausdorff distance для порожніх множин.

**Статус:** DEFINED.

# W23.7. Простір дерев із нескінченними гілками

f ∈ T_ω ⇔ для кожного внутрішнього вузла u існує ξ ∈ Σ_b така, що:

Для часткових дерев вона є нетривіальною.

Не слід ототожнювати T_ω з простором усіх часткових дерев.

(b−1)/b^(k+1).

exp(2α_w) < b.

Отже:

Таким чином:

* bounded operator за оцінкою Шура: α_w < ln b;

## W23.14.2. Точність апроксимації

Оскільки T_q компактний:

‖T_q − P_nT_qP_n‖ → 0.

У цій моделі точна похибка:

# ‖T_q − P_nT_qP_n‖

|λₙ₊₁(q)|.

Отже:

# ‖T_q − P_nT_qP_n‖

(1−q)qⁿ / [bⁿ(b−q)].

## W23.14.3. Центровані апроксимації

На H_n:

L_q⁽ⁿ⁾ = T_q⁽ⁿ⁾ − c_q I_Hn.

Спектр:

# Spec(L_q⁽ⁿ⁾)

{0}
∪
{τ_j(q):1 ≤ j ≤ n}.

Нульове продовження на H:

L̃_q⁽ⁿ⁾ = P_nT_qP_n − c_qP_n.

Воно збігається з L_q сильно, але не в операторній нормі.

Інший оператор:

P_nT_qP_n − c_qI_H

збігається з L_q в операторній нормі.

Ці два продовження не можна ототожнювати.

# W23.15. Геометрично зчеплений оператор

Метрика межі:

d_v(ξ,η) = exp(−α_vℓ(ξ,η)).

Визначимо:

K_v,s(ξ,η) = d_v(ξ,η)^s,

для ξ ≠ η, а на діагоналі покладемо нуль.

Тоді:

# K_v,s(ξ,η)

exp(−sα_vℓ(ξ,η)).

Позначимо:

q_v = exp(−sα_v).

Отже:

T_v,s = T_(q_v).

Спектр визначається формулами W23.10.

Якщо s відомий:

α_v = −ln(q_v)/s.

Якщо s невідомий, оператор ідентифікує лише добуток:

sα_v.

Це параметрична неідентифікованість, а не недолік спектрального методу.

# W23.16. Кілька операторів

У межах однорідної b-арної моделі всі оператори T_q мають спільний ієрархічний розклад.

Тому:

[T_q₁,T_q₂] = 0.

## W23.16.1. Сума

Нехай:

T_Σ = T_q₁ + γT_q₂.

Тоді на константах:

Λ₀ = c_q₁ + γc_q₂.

На рівні W_j:

Λ_j = λ_j(q₁) + γλ_j(q₂).

Кратність:

m_j = (b−1)b^(j−1).

## W23.16.2. Добуток

Оскільки оператори мають спільні власні підпростори:

T_q₁T_q₂ = T_q₂T_q₁.

Власні значення добутку:

Π₀ = c_q₁c_q₂.

Для j ≥ 1:

Π_j = λ_j(q₁)λ_j(q₂).

Отже:

# Π_j

[(1−q₁)(1−q₂)/((b−q₁)(b−q₂))]
·
(q₁q₂/b²)^(j−1).

Всі ці власні значення невід'ємні.

Тому добуток T_q₁T_q₂ є додатно напіввизначеним.

## W23.16.3. Межі твердження

Комутативність є наслідком спільної ієрархічної діагоналізації.

Вона не є універсальною властивістю довільних дерев.

Для неоднорідних моделей необхідно перевіряти комутатор окремо.

# W23.17. Неоднорідні дерева

Розглянемо скінченну модель із листками a,b,c:

ℓ(a,b)=1,

ℓ(a,c)=ℓ(b,c)=0.

Матриця:

K_q =
[ [0, q, 1],
[q, 0, 1],
[1, 1, 0] ].

За рівномірної міри:

T_q = K_q/3.

Власні значення:

λ₁ = −q/3,

λ₊ = (q + √(q²+8))/6,

λ₋ = (q − √(q²+8))/6.

Для двох параметрів:

# ‖[T_q₁,T_q₂]‖

√2 |q₁−q₂|/9.

Отже, оператори не комутують, якщо q₁ ≠ q₂.

Цей приклад доводить, що спільна спектральна діагоналізація може руйнуватися в неоднорідній ієрархії.

Він не доводить, що кожна неоднорідність спричиняє некомутативність.

## W23.17.1. Нерівномірна міра

Для скінченної множини X:

T = KD_μ,

де K — симетрична матриця ядра, D_μ — додатна діагональна матриця ваг.

Оператор є самоспряженим у L²(X,μ).

Симетричне евклідове представлення:

T̃ = D_μ^(1/2) K D_μ^(1/2).

Операторні норми мають бути визначені в одному й тому самому скалярному добутку.

Для двох операторів із різними мірами без спільного простору порівняння комутатор не визначений автоматично.

# W23.18. Теорія збурень

Для скінченних самоспряжених операторів:

A = A₀ + E.

Оцінка Вейля:

|λ_k(A) − λ_k(A₀)| ≤ ‖E‖.

Для збурення двох операторів:

# [A+E,B+F] − [A,B]

[E,B] + [A,F] + [E,F].

Звідси:

‖[A+E,B+F] − [A,B]‖
≤
2‖E‖‖B‖
+
2‖A‖‖F‖
+
2‖E‖‖F‖.

Для ізольованих спектральних підпросторів за наявності спектрального проміжку можна застосовувати оцінки типу Davis–Kahan.

Порівнювати слід спектральні проєкції, а не довільно обрані власні вектори.

Для однорідної b-арної моделі:

# ‖T_q − T_r‖

supⱼ≥0 |λ_j(q) − λ_j(r)|.

Потрібна оцінка:

‖T_q − T_r‖ ≤ |q−r|.

Це твердження має супроводжуватися повним доказом через контроль похідних усіх спектральних гілок.

Для W15:

‖T_q − T_r‖ = |q−r|/3.

Це точна формула для скінченної моделі W15.

# W23.19. Спектральні інваріанти

M_k = Tr(T^k).

M₂ = Σᵢ,ⱼ μᵢμⱼKᵢⱼ².

M₃ =
Σᵢ,ⱼ,ₖ
μᵢμⱼμₖ

# W23.20. Structural Fingerprint

Нехай X — скінченне кореневе дерево з одиничними ребрами.

Для кожного листка ξ визначимо:

h(ξ) = глибина листка.

Для двох листків:

ℓ(ξ,η) = глибина найнижчого спільного предка.

Матриця:

A_LCA = [ℓ(ξᵢ,ξⱼ)].

Діагональ:

A_LCA(i,i) = h(ξᵢ).

Відстань між листками:

# d_T(ξᵢ,ξⱼ)

h(ξᵢ)+h(ξⱼ)−2A_LCA(i,j).

## W23.20.1. Структурні профілі

Профіль глибин:

P_depth(k) = кількість листків глибини k.

Профіль розгалуження:

P_arity(k) = кількість внутрішніх вузлів із k дочірніми вузлами.

Профіль рівнів:

P_level(k) = кількість вузлів на рівні k.

Структурний відбиток:

SF(X) = (L, P_depth, A_LCA, P_arity).

Деякі компоненти можуть бути надлишковими за наявності повної LCA-матриці, але корисні для незалежної перевірки.

## W23.20.2. Теорема реконструкції

Для скінченних кореневих дерев із одиничними довжинами ребер повні дані:

* глибини всіх листків;
* попарні глибини LCA;

визначають дерево з точністю до коренезберігаючого ізоморфізму.

Доведення базується на відношеннях еквівалентності на активних листках кожного рівня.

Для рівня k:

L_k = {ξ : h(ξ) ≥ k}.

Відношення:

ξ ~ₖ η ⇔ ℓ(ξ,η) ≥ k.

Класи еквівалентності відповідають вузлам рівня k.

Вкладення класів між сусідніми рівнями відновлює батьківсько-дочірні відношення.

Листки приєднуються на рівнях, заданих їхніми глибинами.

Кореневий листок і дерева з одним листком обробляються як окремий граничний випадок.

Unary-вузли зберігаються через продовження відповідного класу на наступному рівні.

## W23.20.3. Структурна метрика

Для однаково позначених множин листків:

D_depth = maxᵢ |h_X(ξᵢ) − h_Y(ξᵢ)|.

D_LCA = maxᵢ,ⱼ |A_X(i,j) − A_Y(i,j)|.

D_SF = w_h D_depth + w_LCA D_LCA.

Умови:

w_h > 0,

w_LCA > 0,

w_h + w_LCA = 1.

Це метрика на просторі відповідних позначених структурних відбитків.

Для непозначених дерев відстань визначається мінімізацією за бієкціями листків, якщо кількість листків однакова.

Для дерев із різною кількістю листків потрібна окрема розширена метрика.

## W23.20.4. Зважений відбиток

Визначимо:

SF_μ(X) = (SF(X), μ).

Міра μ задовольняє:

μ(ξ) > 0,

Σ_ξ μ(ξ) = 1.

Структура дерева та міра на його листках є різними компонентами моделі.

# W23.21. Відновлення параметрів

Для однорідної b-арної моделі:

# λ_j(q)

−(1−q)q^(j−1)/[b^(j−1)(b−q)].

Тому:

λ_(j+1)/λ_j = q/b.

Звідси:

q = b λ_(j+1)/λ_j.

Якщо q > 0:

α_w = −ln q.

Кратності:

m_j = (b−1)b^(j−1).

Тому:

m_(j+1)/m_j = b.

Ці формули відновлюють параметри в межах відомої однорідної моделі.

Вони не є алгоритмом відновлення довільного неоднорідного дерева.
