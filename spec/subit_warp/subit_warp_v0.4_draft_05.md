# SUBIT-WARP v0.4

## W16 — Structural Defects, Perturbation Theory and Spectral Stability

**Статус:** DRAFT · MATHEMATICALLY DERIVED
**Залежність:** W7–W15
**Призначення:** формалізація спектральних наслідків відхилення неоднорідної деревної структури від однорідної базової моделі.

---

# 1. Мотивація та межі W16

W12–W14 встановили спектральну структуру операторів взаємодії для однорідного b-арного дерева з рівномірною мірою. W15 показав, що на неоднорідному дереві оператори з різними параметрами взаємодії можуть не комутувати.

Однак некомутативність сама по собі ще не характеризує спектральну нестабільність. Так само спектральна зміна не обов'язково означає зміну геометрії дерева.

Тому W16 вводить три незалежні типи збурень:

1. **Параметричне збурення:** зміна параметра взаємодії q.
2. **Метрично-структурне збурення:** зміна ядра або ваг взаємодії на фіксованому просторі.
3. **Топологічне збурення:** зміна самої деревної структури, множини листків або відношень спільного предка.

Ці типи збурень мають різні математичні умови порівняння. Їх не можна об'єднувати в одну універсальну величину без додаткової структури.

Основний принцип W16:

**Спектральна стійкість визначається нормою операторного збурення, але операторне збурення має бути визначене на спільному просторі.**

---

# 2. Базова операторна постановка

Нехай H — скінченновимірний або сепарабельний гільбертів простір.

Розглянемо самоспряжений оператор A₀ та його збурення:

A = A₀ + E,

де:

* A₀ — базовий оператор;
* E — самоспряжений оператор збурення;
* A — збурений оператор.

Позначимо:

δ_A = ‖E‖.

У скінченновимірному випадку власні значення впорядковуємо за спаданням:

λ₁(A) ≥ λ₂(A) ≥ ... ≥ λₙ(A).

Для компактних самоспряжених операторів на нескінченновимірному просторі потрібно окремо розглядати додатну та від'ємну частини спектра. Нуль може бути точкою накопичення, тому механічне перенесення скінченновимірної нумерації на весь спектр некоректне.

---

# 3. W16.1 — Теорема про спектральну стійкість

## Теорема 1. Скінченновимірна спектральна оцінка

Нехай A₀ і E — самоспряжені оператори на скінченновимірному гільбертовому просторі, а A=A₀+E.

Тоді для кожного k:

|λₖ(A) − λₖ(A₀)| ≤ ‖E‖.

Отже:

|λₖ(A) − λₖ(A₀)| ≤ δ_A.

### Доведення

За мінімаксним принципом:

λₖ(A) =
min_{dim S=n−k+1}
max_{x∈S, ‖x‖=1}
⟨Ax,x⟩.

Оскільки A=A₀+E, для кожного одиничного x:

|⟨Ex,x⟩| ≤ ‖E‖.

Звідси:

⟨A₀x,x⟩ − ‖E‖
≤ ⟨Ax,x⟩
≤ ⟨A₀x,x⟩ + ‖E‖.

Застосовуючи мінімаксну характеристику до обох нерівностей, отримуємо:

λₖ(A₀) − ‖E‖
≤ λₖ(A)
≤ λₖ(A₀) + ‖E‖.

Теорему доведено.

**Статус:** PROVED.

## Наслідок 1

Якщо:

‖A−A₀‖ → 0,

то кожне впорядковане власне значення скінченновимірної сім'ї операторів змінюється неперервно.

Це не означає, що власні вектори також змінюються неперервно без додаткових умов.

---

# 4. W16.2 — Спектральна стійкість компактних операторів

Нехай A₀ та A=A₀+E — компактні самоспряжені оператори на нескінченновимірному гільбертовому просторі.

Для додатних власних значень використовуємо спадну послідовність:

λ₁⁺(A) ≥ λ₂⁺(A) ≥ ... ≥ 0.

Для від'ємних власних значень окремо впорядковуємо модулі:

|λ₁⁻(A)| ≥ |λ₂⁻(A)| ≥ ... ≥ 0.

Якщо відповідна послідовність існує, маємо:

|λₖ⁺(A) − λₖ⁺(A₀)| ≤ ‖E‖,

а аналогічно для від'ємної частини після впорядкування її модулів.

Це дозволяє контролювати спектральні гілки компактного оператора, не змішуючи їх із нульовою точкою накопичення.

### Важливе обмеження

Нормова близькість операторів контролює спектральні значення, але не гарантує однакової кількості ненульових власних значень.

Малі збурення можуть змінювати поведінку спектра поблизу нуля. Тому нульова частина спектра потребує окремого аналізу.

**Статус:** PROVED за стандартними мінімаксними оцінками для компактних самоспряжених операторів.

---

# 5. W16.3 — Параметричне збурення однорідного оператора

Розглянемо однорідний b-арний оператор:

T_q : H → H.

Його спектральні компоненти:

c_q = (b−1)/(b−q),

λ₀(q) = c_q,

λⱼ(q) = −(1−q)q^(j−1)/[b^(j−1)(b−q)], j≥1.

Вейвлетні простори Wⱼ не залежать від q.

Нехай q,r ∈ [0,1).

Оскільки оператори T_q і T_r діагоналізуються на спільному ортогональному розкладі:

H = ⊕ⱼ≥0 Wⱼ,

то:

‖T_q−T_r‖
= supⱼ≥0 |λⱼ(q)−λⱼ(r)|,

де для j=0 використовуємо λ₀=c.

Це точна формула для операторної норми різниці в однорідній моделі.

## Теорема 2. Параметрична неперервність

Для кожного q,r∈[0,1):

‖T_q−T_r‖ ≤ |q−r|.

### Доведення

Позначимо:

aⱼ(q) = −(1−q)q^(j−1)/[b^(j−1)(b−q)].

Для j≥1:

aⱼ(q) = λⱼ(q).

Для q∈[0,1) маємо:

|aⱼ'(q)| ≤ 1.

Це випливає з диференціювання функції та оцінок 0≤q<1, b≥2.

Для константної компоненти:

c_q' = (b−1)/(b−q)² ≤ 1,

оскільки b≥2.

Отже, за теоремою Лагранжа:

|λⱼ(q)−λⱼ(r)| ≤ |q−r|

для кожного j≥0.

Беручи супремум:

‖T_q−T_r‖ ≤ |q−r|.

**Статус:** PROVED.

Примітка: оцінка є універсальною, але не обов'язково оптимальною для конкретних b,q,r.

# 6. W16.4 — Структурне збурення на фіксованому просторі

Нехай X — скінченна множина листків дерева, а μ — фіксована ймовірнісна міра.

Позначимо:

D_μ = diag(μ₁,...,μₙ).

Для симетричного ядра K визначимо оператор:

T_K = K D_μ.

У просторі L²(X,μ) цей оператор самоспряжений, хоча його матриця K D_μ не обов'язково симетрична в стандартному евклідовому скалярному добутку.

Еквівалентна симетрична матриця:

S_K = D_μ^(1/2) K D_μ^(1/2).

Вона має ті самі власні значення, що й T_K, якщо всі μᵢ>0.

Нехай:

K = K₀ + ΔK.

Тоді:

T_K − T_K₀ = ΔK D_μ.

У стандартній евклідовій нормі:

‖T_K−T_K₀‖₂
≤ ‖ΔK‖₂ ‖D_μ‖₂.

Для ймовірнісної міри:

‖D_μ‖₂ = maxᵢ μᵢ ≤ 1.

Тому:

‖T_K−T_K₀‖₂ ≤ ‖ΔK‖₂.

Для симетризованої форми:

‖S_K−S_K₀‖₂
≤ ‖D_μ^(1/2)‖₂² ‖ΔK‖₂
= (maxᵢ μᵢ) ‖ΔK‖₂.

Звідси випливає спектральна оцінка:

|λₖ(T_K)−λₖ(T_K₀)|
≤ (maxᵢ μᵢ) ‖ΔK‖₂.

Ця оцінка застосовна за умови, що простір X і міра μ залишаються незмінними.

---

# 7. W16.5 — Зміна міри

Зміна міри — окремий тип збурення.

Нехай:

μ = (μ₁,...,μₙ),

ν = (ν₁,...,νₙ),

де всі координати додатні та сума кожного вектора дорівнює 1.

Для фіксованого симетричного ядра K:

T_(K,μ) = K D_μ,

T_(K,ν) = K D_ν.

Тоді:

T_(K,μ) − T_(K,ν)
= K(D_μ−D_ν).

Отже:

‖T_(K,μ)−T_(K,ν)‖₂
≤ ‖K‖₂ · maxᵢ|μᵢ−νᵢ|.

Це оцінка матриць у стандартному координатному представленні.

Однак оператори T_(K,μ) та T_(K,ν) природно діють у різних гільбертових просторах:

L²(X,μ) та L²(X,ν).

Тому для прямого спектрального порівняння потрібно використовувати спільне представлення.

Якщо всі μᵢ,νᵢ>0, можна застосувати симетризовані матриці:

S_(K,μ)=D_μ^(1/2) K D_μ^(1/2),

S_(K,ν)=D_ν^(1/2) K D_ν^(1/2).

Тоді:

|λₖ(S_(K,μ))−λₖ(S_(K,ν))|
≤ ‖S_(K,μ)−S_(K,ν)‖₂.

Ця формула є коректною основою для аналізу чутливості спектра до зміни міри.

**Важливо:** якщо деякі координати міри прямують до нуля, відповідне симетризоване представлення може змінювати ранг. Таку границю необхідно аналізувати окремо.

# 8. W16.6 — Топологічні збурення

Топологічне збурення змінює структуру дерева:

* кількість листків;
* глибину окремих гілок;
* відношення спільного предка;
* локальну арність;
* множину допустимих адрес.

У такому випадку оператори можуть діяти на різних просторах:

H₀=L²(X₀,μ₀),

H₁=L²(X₁,μ₁).

Без додаткової структури вираз:

‖T₁−T₀‖

не має визначеного змісту.

## Необхідна умова порівняння

Потрібно задати один із способів перенесення:

1. Спільне вкладення обох просторів у більший гільбертів простір.
2. Відображення між множинами листків із контрольованою похибкою.
3. Спільний простір адрес із відповідними мірами.
4. Явну матрицю відповідності між станами двох дерев.

Лише після такого ототожнення можна визначати операторне збурення:

E = T₁−T₀.

### Наслідок

Зміна топології не є автоматично малим операторним збуренням.

Навіть одна локальна зміна структури може мати значний спектральний ефект, якщо вона змінює великі частини ядра взаємодії.

**Статус:** загальна схема формалізована; універсальна теорема для довільних пар дерев не встановлена.

# 9. W16.7 — Стійкість власних підпросторів

Спектральна стійкість власних значень не гарантує стійкості власних векторів.

Нехай A₀ — самоспряжений оператор, а λ — ізольоване власне значення або ізольований спектральний кластер.

Позначимо:

P₀ — ортогональний спектральний проєктор на відповідний власний підпростір.

Для збуреного оператора:

A=A₀+E

позначимо відповідний спектральний проєктор P.

Якщо спектральний кластер відділений від решти спектра зазором δ>0 і збурення достатньо мале відносно цього зазору, можна застосувати теорему Девіса—Кахана.

У стандартній формі оцінка має вигляд:

‖P−P₀‖ ≤ C · ‖E‖/δ,

де C залежить від конкретної форми оцінки та умов відокремлення спектральних кластерів.

Для одновимірного власного підпростору це означає контроль кута між власними напрямами.

### Важливий випадок кратних власних значень

Якщо власне значення має кратність більшу за 1, окремі власні вектори всередині відповідного підпростору не є однозначними.

Тому в SUBIT-WARP потрібно порівнювати не конкретні власні вектори, а спектральні проєктори або цілі власні підпростори.

**Статус:** застосування стандартної теорії збурень; конкретні константи мають визначатися для кожної постановки.

# 10. W16.8 — Збурення комутативності

Нехай A,B — оператори, а E,F — їхні збурення.

Визначимо:

A' = A+E,

B' = B+F.

Комутатор:

[A,B]=AB−BA.

Тоді:

[A',B']−[A,B]
= [E,B]+[A,F]+[E,F].

Використовуючи нерівність:

‖[X,Y]‖ ≤ 2‖X‖‖Y‖,

отримуємо:

‖[A',B']−[A,B]‖
≤ 2‖E‖‖B‖

* 2‖A‖‖F‖
* 2‖E‖‖F‖.

## Теорема 3. Контроль дефекту комутативності

Якщо базові оператори комутують:

[A,B]=0,

то:

‖[A',B']‖
≤ 2‖E‖‖B‖

* 2‖A‖‖F‖
* 2‖E‖‖F‖.

Отже, малі операторні збурення породжують контрольований дефект комутативності.

**Статус:** PROVED.

Це дає загальну оцінку для переходу від однорідної моделі W14 до її збурених реалізацій.

# 11. W16.9 — Точна перевірка на дереві W15

Розглянемо дерево з трьома листками:

X={a,b,c}.

Його матриця взаємодії:

K_q =
[[0,q,1],
[q,0,1],
[1,1,0]].

За рівномірної міри:

μ=(1/3,1/3,1/3).

Оператор:

T_q = (1/3)K_q.

Розкладемо:

T_q = (A+qB)/3,

де:

A =
[[0,0,1],
[0,0,1],
[1,1,0]],

B =
[[0,1,0],
[1,0,0],
[0,0,0]].

Матриця B має власні значення:

{−1,0,1}.

Тому:

‖B‖₂=1.

Для двох параметрів q,r:

T_q−T_r = (q−r)B/3.

Звідси отримуємо точну рівність:

**‖T_q−T_r‖₂ = |q−r|/3.**

За теоремою 1:

|λₖ(T_q)−λₖ(T_r)| ≤ |q−r|/3.

## Точні власні значення

λ₁(q)=−q/3,

λ₊(q)=[q+√(q²+8)]/6,

λ₋(q)=[q−√(q²+8)]/6.

Похідні:

λ₁'(q)=−1/3,

λ₊'(q)=[1+q/√(q²+8)]/6,

λ₋'(q)=[1−q/√(q²+8)]/6.

Для q∈[0,1):

|λₖ'(q)| ≤ 1/3.

Таким чином, усі три власні значення є 1/3-Lipschitz за параметром q.

Це узгоджується з точною операторною оцінкою.

**Статус:** PROVED аналітично.

# 12. W16.10 — Точний дефект комутативності для W15

Для операторів:

T_q=(A+qB)/3,

T_r=(A+rB)/3

маємо:

[T_q,T_r]
= (q−r)(BA−AB)/9.

Матриця:

BA−AB =
[[0,0,1],
[0,0,1],
[−1,−1,0]].

Її власні значення:

{0,i√2,−i√2}.

Оскільки вона нормальна:

‖BA−AB‖₂=√2.

Отже:

**‖[T_q,T_r]‖₂ = √2|q−r|/9.**

Це точна формула, а не верхня оцінка.

Вона демонструє:

* q=r ⇒ оператори комутують;
* q≠r ⇒ оператори не комутують;
* величина некомутативності лінійно залежить від |q−r|.

Цей результат належить конкретній трьохлистковій моделі W15. Його не можна без доведення переносити на довільні неоднорідні дерева.

# 13. W16.11 — Три незалежні індекси дефекту

Для подальшого розвитку SUBIT-WARP доцільно розділити три типи дефекту.

## 13.1. Операторний дефект

δ_op = ‖T−T₀‖.

Вимірює відхилення оператора від базової моделі.

## 13.2. Комутативний дефект

δ_com = ‖[T₁,T₂]‖.

Вимірює некомутативність пари операторів.

## 13.3. Спектральний дефект

Для скінченновимірних самоспряжених операторів:

δ_spec =
maxₖ |λₖ(T)−λₖ(T₀)|.

За теоремою 1:

δ_spec ≤ δ_op.

Це три різні характеристики.

Вони не є взаємозамінними:

* малий операторний дефект гарантує малу зміну власних значень;
* малий комутативний дефект не гарантує близькості до конкретної однорідної моделі;
* мала спектральна відстань не гарантує близькості власних підпросторів без спектрального зазору.

## 13.4. Нормалізований комутативний індекс

Якщо ‖T₁‖‖T₂‖>0, можна визначити:

κ(T₁,T₂)=
‖[T₁,T₂]‖/[‖T₁‖‖T₂‖].

Тоді:

0≤κ≤2.

Якщо один із операторів нульовий, цей індекс не визначений; у такому разі слід використовувати ненормований δ_com.

κ є індексом некомутативності конкретної пари операторів, а не універсальною мірою неоднорідності дерева.

# 14. W16.12 — Протокол порівняння моделей

Кожне порівняння двох моделей SUBIT-WARP має пройти такі етапи.

### Етап A. Простір

Встановити, чи діють оператори на одному гільбертовому просторі.

Якщо ні — задати явне вкладення, відображення або спільне представлення.

### Етап B. Міра

Зафіксувати міру або явно включити її зміну до збурення.

### Етап C. Ядро

Визначити:

ΔK=K−K₀.

### Етап D. Оператор

Побудувати:

E=T−T₀.

### Етап E. Норма

Обчислити або оцінити:

‖E‖.

### Етап F. Спектр

Порівняти впорядковані власні значення або відповідні спектральні гілки.

### Етап G. Підпростори

За наявності спектрального зазору порівняти спектральні проєктори.

### Етап H. Комутативність

Для пар операторів обчислити:

‖[T₁,T₂]‖.

### Етап I. Інтерпретація

Окремо сформулювати:

* що змінилося в геометрії;
* що змінилося в ядрі;
* що змінилося в спектрі;
* що змінилося в комутативності.

Заборонено робити висновок про топологічну еквівалентність лише на підставі спектральної близькості.

# 15. W16.13 — Вимоги до обчислювальної перевірки

Запропонований модуль:

`subit-warp-perturbation`

Статус: NOT IMPLEMENTED.

## Набір тестів

**PT-01 — Parameter Lipschitz**

Перевірити:

‖T_q−T_r‖ ≤ |q−r|.

**PT-02 — Exact W15 parameter norm**

Перевірити:

‖T_q−T_r‖ = |q−r|/3.

**PT-03 — Weyl bound**

Для випадкових скінченних симетричних матриць A₀,E перевірити:

maxₖ|λₖ(A₀+E)−λₖ(A₀)| ≤ ‖E‖₂.

**PT-04 — Commutator perturbation**

Перевірити:

‖[A+E,B+F]−[A,B]‖
≤ 2‖E‖‖B‖+2‖A‖‖F‖+2‖E‖‖F‖.

**PT-05 — Measure perturbation**

Для фіксованого симетричного K перевірити:

‖K D_μ−K D_ν‖₂
≤ ‖K‖₂ maxᵢ|μᵢ−νᵢ|.

**PT-06 — Symmetrized representation**

Перевірити збіг спектрів:

K D_μ

та

D_μ^(1/2) K D_μ^(1/2)

за строго додатної міри.

**PT-07 — Spectral projection stability**

Для ізольованих спектральних кластерів порівнювати проєктори, а не окремі власні вектори.

**PT-08 — Topology mismatch guard**

Спроба порівняти оператори на різних просторах без заданого відображення повинна повертати помилку типу:

`UNDEFINED_COMMON_OPERATOR_SPACE`.

# 17. Висновок W16

W16 встановлює математичний міст між однорідною спектральною теорією SUBIT-WARP та неоднорідними деревними структурами.

Його головний результат полягає не в тому, що всі неоднорідні дерева мають подібні спектри, а в тому, що спектральне порівняння стає строгим після визначення спільного простору, міри та операторної норми збурення.

Отримуємо принципову послідовність:

**Структура → Міра → Ядро → Оператор → Спектр → Спектральні підпростори → Комутативність.**

Кожен перехід має власні математичні умови.

Це відповідає загальному принципу SUBIT:

**DO NOT COLLAPSE — CONTEXTUALIZE.**

Спектр не замінює геометрію.
Комутативність не замінює структуру.
Операторна близькість не означає топологічної тотожності.

W16 створює основу для наступного етапу — **W17: Spectral Invariants, Isospectrality and Limits of Reconstruction**, де центральним питанням стане не лише те, наскільки два дерева спектрально близькі, а й те, яку інформацію про структуру дерева взагалі можна відновити зі спектра.
