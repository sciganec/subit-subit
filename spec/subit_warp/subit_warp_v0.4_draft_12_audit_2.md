W24 перевіряє математичні основи SUBIT-WARP до побудови спектральної теорії.

Аудит має встановити:

1. чи правильно визначено простір дерев;
2. чи є адресна метрика справжньою метрикою на заданому просторі;

W24 розділяє три типи аудиту:

* **Definition Audit** — коректність визначень;
* **Theorem Audit** — коректність тверджень та доказів;

# W24.3. Аудит W1 — рекурсивна структура дерев

## W24.3.1. Повне дерево

Для однорідної b-арної моделі:

FullTree_A^(b) ≅ Leaf(A) ⊔ Node(FullTree_A^(b))^b.

Це коректна коіндуктивна схема повного дерева.

Однак для математичної повноти необхідно вказати:

1. чи йдеться про коіндуктивний тип;
2. чи розглядаються дерева з нескінченними гілками;
3. чи дозволені нескінченні шляхи без листків;
4. чи дозволені вузли з одним або кількома відсутніми нащадками;
5. чи існують обмеження на мітки листків.

Для повного дерева з фіксованою кількістю дочірніх позицій кожен внутрішній вузол має рівно b позицій.

Це не тотожне твердженню, що кожна з цих позицій обов'язково містить листок.

## W24.3.2. Часткове дерево

Часткова модель:

PartialTree_A^(b)
≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A^(b))^b.

Тут необхідно визначити семантику None.

Рекомендована інтерпретація:

None означає, що відповідна позиція не належить дереву.

Воно не є:

* листком;
* нескінченною гілкою;
* порожньою множиною межі без додаткової інтерпретації.

## W24.3.3. Потенційна проблема коіндуктивної рівності

Запис рекурсивного типу сам по собі не визначає, які саме спостережувані властивості дерев зберігаються при переході до граничного об'єкта.

Якщо W1 використовує коіндуктивні визначення, потрібно визначити:

* спостережувану еквівалентність дерев;
* критерій рівності;
* принцип коіндукції;
* правила рекурсивного розгортання.

**Рішення W24:** не використовувати рекурсивну рівність як заміну повному визначенню типу.

Статус: **DEFINITION AUDIT REQUIRED**.

# W24.4. Аудит W2 — адресний простір та метрика

## W24.4.1. Простір адрес

Pos_b = B_b^{<ω}.

Σ_b = B_b^ℕ.

Для ξ, η ∈ Σ_b:

ℓ(ξ,η) = довжина найдовшого спільного префікса.

Якщо ξ = η:

ℓ(ξ,ξ) = ∞.

Метрика:

d_S(ξ,η) = 2^(−ℓ(ξ,η)),

із домовленістю:

2^(−∞) = 0.

## W24.4.2. Перевірка метричних аксіом

Для d_S необхідно перевірити:

**M1 — Невід'ємність**

d_S(ξ,η) ≥ 0.

**M2 — Розділення точок**

d_S(ξ,η) = 0 ⇔ ξ = η.

**M3 — Симетричність**

d_S(ξ,η) = d_S(η,ξ).

**M4 — Ультраметрична нерівність**

d_S(ξ,ζ)
≤ max(d_S(ξ,η), d_S(η,ζ)).

Це коректна ультраметрика на Σ_b.

## W24.4.3. Компактність

За скінченного алфавіту B_b простір Σ_b із цією топологією компактний.

Крім того, він повний.

Це можна встановити через стандартний аргумент діагонального вибору для послідовностей нескінченних слів.

Для будь-якої послідовності адрес можна вибрати підпослідовність, у якій перший символ стабілізується; потім підпослідовність, у якій стабілізується другий символ, і так далі.

Діагональна підпослідовність збігається в d_S.

## W24.4.4. Важливе розмежування

Метрика d_S на межі не є автоматично метрикою на просторі дерев.

Для визначення метрики між деревами потрібна окрема конструкція.

Можливі варіанти:

* адресна метрика на кодованих деревах;
* метрика Гаусдорфа на множинах гілок;
* метрика редагування структури;
* метрика на функціях, що задають вузли.

Ці метрики мають різні властивості.

**Рішення W24:** у каноні зберігати окремо:

d_S — метрика на адресах;

d_T — деревна метрика на листках скінченного дерева;

d_F — метрика на просторі дерев, якщо її буде визначено.

Статус: **METRIC CORE VERIFIED; TREE-SPACE METRIC REQUIRES PRIMARY DEFINITION**.

# W24.5. Аудит W3 — нескінченні гілки та межа

## W24.5.1. Межа дерева

Для дерева f:

∂f = {ξ ∈ Σ_b : усі префікси ξ відповідають внутрішнім вузлам f}.

Це коректна схема визначення межі, якщо функція f та значення f(u) формально визначені для кожної адреси u.

Необхідно уточнити:

* чи визначена f на всіх адресах;
* як кодуються відсутні позиції;
* що відбувається після листка;
* чи може нескінченна адреса продовжуватися після None;
* чи включається корінь до перевірки внутрішніх вузлів.

## W24.5.2. Замкненість межі

Для повного дерева умова належності нескінченної адреси до межі визначається локальними умовами на її скінченні префікси.

Якщо множина порушення умови на кожному рівні є відкритою циліндричною множиною, тоді її доповнення є замкненим.

Отже, ∂f є замкненою підмножиною компактного Σ_b.

Тому:

∂f ∈ K₀(Σ_b).

Цей висновок потребує, щоб межа була визначена саме як множина нескінченних адрес, усі префікси яких залишаються всередині дерева.

Для повного дерева межа непорожня.

Для часткового дерева межа може бути порожньою.

## W24.5.3. Проблема скінченних листків

Скінченний листок не є нескінченною адресою.

Тому не можна включати його до ∂f без окремого кодування.

Якщо модель потребує одночасного представлення листків і нескінченних гілок, слід використовувати розширений простір:

Boundary⁺(f) = InfiniteBranches(f) ⊔ FiniteLeaves(f).

Це диз'юнктне об'єднання різних типів граничних об'єктів.

Статус: **BOUNDARY DEFINITION REQUIRES PRIMARY SOURCE CHECK**.

# W24.6. Аудит W4 — гранична геометрія

## W24.6.1. Метрика

d_v(ξ,η) = exp(−α_vℓ(ξ,η)).

Еквівалентно:

d_v = d_S^γ,

де:

γ = α_v/ln 2.

Це метрика, оскільки додатний степінь метрики зберігає метричні аксіоми.

Для ультраметрики зберігається й ультраметрична нерівність.

## W24.6.2. Hausdorff dimension

Для повної однорідної b-арної межі:

dim_H(Σ_b,d_v) = ln b/α_v.

Перевірка через циліндри:

* кількість циліндрів рівня n: bⁿ;
* діаметр кожного циліндра: exp(−α_v n).

Критичний показник s визначається умовою:

bⁿ exp(−α_v n s) ≈ 1.

Звідси:

ln b − α_v s = 0.

Тому:

s = ln b/α_v.

## W24.6.3. Регулярність відображення межі

Якщо базова оцінка:

d_H,S(∂f,∂g) ≤ C₀d_F(f,g)

є правильною, тоді:

d_H,v(∂f,∂g)
≤ C₀^γ d_F(f,g)^γ.

Але ця оцінка не є самодостатнім доказом регулярності.

Потрібно довести базову оцінку для конкретної метрики d_F на деревах.

**Рішення:** не вважати граничне відображення Lipschitz або Hölder без вказаного джерела базової оцінки.

Статус: **CONDITIONAL RESULT**.

# W24.7. Аудит W5 — grafting та динаміка

Для трійкової моделі:

ρ_a(f) = Node(f,Leaf(a),Leaf(a)).

Якщо метрика дерев побудована за першою відмінною адресою, то при додаванні одного рівня адреси відстань масштабується в 1/2.

Тому:

d_F(ρ_a(f),ρ_a(g)) = 1/2 · d_F(f,g).

Звідси:

Lip(ρ_a)=1/2.

Якщо простір F повний, теорема Банаха дає єдину нерухому точку.

## W24.7.1. Перевірка прихованих умов

Для застосування теореми Банаха потрібні:

1. непорожність F;
2. повнота F;
3. відображення ρ_a:F→F;
4. існування коефіцієнта стиску c<1.

Наявність формули Lip(ρ_a)=1/2 не замінює перевірки повноти F.

## W24.7.2. Унікальність нерухомої точки

Якщо всі умови виконані:

ρ_a(p_a)=p_a.

Якщо p і q — дві нерухомі точки:

# d_F(p,q)

d_F(ρ_a(p),ρ_a(q))
≤
1/2 d_F(p,q).

Звідси:

d_F(p,q)=0.

Отже:

p=q.

**Статус:** PROVED за умови повноти простору дерев.

# W24.8. Аудит W6 — простір взаємодій

W6 є критично важливим, оскільки саме тут геометрична структура переходить в операторну.

Потрібно чітко визначити:

* простір станів;
* міру;
* ядро;
* область визначення оператора;
* цільовий простір;
* умови інтегровності;
* самоспряженість;
* компактність;
* операторну норму.

## W24.8.1. Канонічний оператор

Для рівномірної міри μ_b:

H = L²(Σ_b,μ_b).

Для симетричного ядра K:

# (T_Kf)(ξ)

∫ K(ξ,η)f(η)dμ_b(η).

Достатньою умовою для Hilbert–Schmidt-оператора є:

∫∫ |K(ξ,η)|² dμ_b(ξ)dμ_b(η) < ∞.

У цьому випадку:

‖T_K‖ ≤ ‖T_K‖_HS.

Якщо K симетричне та дійснозначне, T_K є самоспряженим.

## W24.8.2. Спадне ядро

K_anc(ξ,η)=q^ℓ(ξ,η), ξ≠η.

K_anc(ξ,ξ)=0.

За 0<q<1 ядро обмежене:

0 ≤ K_anc ≤ 1.

Тому воно належить L²(Σ_b×Σ_b).

Отже, T_q є Hilbert–Schmidt та компактним.

## W24.8.3. Зростаюче ядро

K_Vl(ξ,η)=exp(α_wℓ(ξ,η)), ξ≠η.

K_Vl(ξ,ξ)=0.

Для цього ядра обмеженість не випливає автоматично.

Потрібно використовувати інтегровність за мірою.

Рядкова L¹-оцінка:

# ∫ |K_Vl(ξ,η)|dμ_b(η)

(b−1)/b
Σₖ₌₀^∞ [exp(α_w)/b]^k.

Тому оператор обмежений за оцінкою Шура, якщо:

α_w < ln b.

Hilbert–Schmidt-умова:

α_w < (ln b)/2.

## W24.8.4. Відмінність двох режимів

| Властивість                      | K_anc     | K_Vl             |
| -------------------------------- | --------- | ---------------- |
| Поведінка                        | Спадна    | Зростаюча        |
| Параметр                         | q ∈ (0,1) | α_w > 0          |
| Обмеженість ядра                 | Так       | Не завжди        |
| Hilbert–Schmidt                  | Так       | За α_w < ln(b)/2 |
| Обмеженість оператора            | Так       | За α_w < ln b    |
| Канонічна спектральна формула W7 | Так       | Не встановлена   |

Не можна переносити спектральні формули T_q на T_Vl без окремого доказу.

# W24.9. Перевірка переходу W6 → W7

Перехід до спектральної теорії допустимий за таких умов:

1. H є гільбертовим простором;
2. T_q визначений на всьому H;
3. T_q обмежений;
4. T_q самоспряжений;
5. T_q компактний;
6. ієрархічні підпростори W_j утворюють повний ортогональний розклад H.

Тоді можна застосовувати спектральну теорему для компактних самоспряжених операторів.

Це обґрунтовує метод W7.

Однак спектральні формули потребують додаткового прямого обчислення дії T_q на кожному W_j.

Сам факт компактності не визначає власних значень.

# W24.12. Мінімальні вимоги до первинних текстів

Для завершення повного аудиту необхідно отримати оригінальні тексти W0–W6.

Кожен текст повинен містити:

1. визначення всіх математичних об'єктів;
2. типи просторів;
3. область визначення кожного відображення;
4. цільовий простір;
5. метрики та норми;
6. умови застосування теорем;
7. повні докази;
8. контрприклади або обмеження;
9. залежності від попередніх розділів.

Особливо важливо перевірити, чи не використовують W3–W6 результати, які були сформульовані лише пізніше.

Це дозволить виявити можливі ретроспективні припущення — коли пізніша властивість фактично вбудована в раннє визначення без окремого доказу.

# W24.13. Вимоги до аудиторського звіту

Для кожного твердження первинного тексту має бути сформовано запис:

**Claim ID:** унікальний ідентифікатор.

**Original statement:** точне первинне формулювання.

**Mathematical objects:** усі використані об'єкти.

**Assumptions:** повний перелік припущень.

**Proof:** перевірка кожного логічного переходу.

**Counterexample check:** пошук граничних випадків.

**Dependencies:** посилання на попередні твердження.

**Verdict:** один зі статусів:

* PASS;
* PASS WITH CONDITIONS;
* CORRECT;
* REJECT;
* NOT AUDITABLE.

**Required correction:** точна заміна або додатковий доказ.

Жодне твердження не може отримати PASS лише через те, що воно використовується в пізнішій частині специфікації.

# W24.14. Остаточний висновок

На підставі доступного математичного матеріалу можна підтвердити внутрішню узгодженість значної частини основної моделі:

* адресної ультраметрики;
* повного b-арного граничного простору;
* Hausdorff dimension;
* спектрального оператора;
* ієрархічних власних значень;
* скінченних апроксимацій;
* операторних норм;
* структурної реконструкції.

Однак повний аудит W0–W6 не завершений.

Ключові первинні питання:

1. Чи визначено простір дерев до введення метрики?
2. Чи є метрика на деревах повною?
3. Чи правильно визначено нескінченну межу?
4. Чи доведено регулярність граничного відображення?
5. Чи має grafting повну область визначення?
6. Чи обґрунтовано перехід від ядра до компактного оператора?

До отримання первинних текстів остаточний статус:

**W24 — PARTIALLY VERIFIED · PRIMARY SOURCE AUDIT INCOMPLETE.**
