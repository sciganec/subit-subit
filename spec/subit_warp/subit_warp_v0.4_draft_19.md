# W29.2. Аудит W27.1 — Boundary Lipschitz

### Твердження

Для:

`f,g∈Tω⁺`

маємо:

`d_H(∂f,∂g)≤2d_F(f,g)`.

### Перевірка

Нехай:

`m=r(f,g)`.

Дерева збігаються на всіх адресах глибини меншої за m.

Якщо:

`ξ∈∂f`,

але:

`ξ∉∂g`,

то існує перша адреса σ уздовж ξ, на якій g має листок.

Оскільки f і g збігаються до глибини m−1:

`|σ|≥m`.

За умовою Tω батьківський вузол σ⁻ має нескінченну гілку в g.

Оскільки σ у g є листком, така гілка проходить через іншу дочірню адресу.

Тому існує:

`η∈∂g`

із:

`ℓ(ξ,η)≥m−1`.

Звідси:

`d_Σ(ξ,η)≤2^{-(m-1)}`.

Але:

`d_F(f,g)=2^{-m}`.

Отже:

`dist(ξ,∂g)≤2d_F(f,g)`.

Симетричне міркування завершує доказ.

### Перевірка граничних випадків

- `f=g`: ліва і права частини дорівнюють нулю.
- Розбіжність на корені: неможлива для двох елементів Tω⁺, оскільки корінь обох має бути Node.
- Розбіжність на глибині 1: оцінка залишається коректною.
- Розбіжність на довільній глибині m: коефіцієнт 2 зберігається.
- Порожня межа: виключена умовою Tω⁺.

### Вердикт

**PASS — PROVED ANALYTICALLY.**

Домен Tω⁺ є необхідною частиною формулювання. Заміна його на Tω без зміни метрики Гаусдорфа некоректна.

# W29.3. Аудит W27.2 — Параметрична ліпшицевість

### Твердження

Для b≥2 та q,r∈[0,1]:

`||T_q−T_r||≤|q−r|`.

### Перевірка

Оскільки всі оператори мають спільний ортогональний ієрархічний розклад:

`||T_q−T_r||=sup_j |λ_j(q)−λ_j(r)|`.

Для сталого підпростору:

`c_q=(b−1)/(b−q)`.

Похідна:

`c'_q=(b−1)/(b−q)²`.

На [0,1]:

`|c'_q|≤1`.

Для j≥1:

`g_n(q)=(1−q)q^n/[b^n(b−q)]`, `n=j−1`.

Тоді:

`λ_j(q)=−g_n(q)`.

Для n=0:

`|g'_0(q)|=(b−1)/(b−q)²≤1`.

Для n≥1:

`g'_n(q)=A_n(q)−B_n(q)`,

де:

`A_n(q)=nq^{n−1}(1−q)/[b^n(b−q)]`,

`B_n(q)=q^n(b−1)/[b^n(b−q)²]`.

Використовуючи:

`(1−q)/(b−q)≤1/(b−1)`

та:

`(b−1)/(b−q)²≤1/(b−1)`,

отримуємо:

`A_n(q)≤n/[b^n(b−1)]`,

`B_n(q)≤1/[b^n(b−1)]`.

Оскільки:

`n≤b^n`,

то:

`|g'_n(q)|≤1`.

За теоремою Лагранжа:

`|λ_j(q)−λ_j(r)|≤|q−r|`.

Отже, загальна операторна оцінка доведена.

### Вердикт

**PASS — PROVED ANALYTICALLY.**

Область застосування: однорідне сімейство T_q зі спільними підпросторами W_j.

Не поширювати автоматично на неоднорідні ядра.

# W29.4. Аудит W27.3 — Structural Fingerprint

### Початкове твердження

Fingerprint:

`F(T)=(L,h,a)`

визначає скінченне кореневе дерево з точністю до ізоморфізму.

### Перевірка

Для листків x,y:

`a(x,y)=depth(LCA(x,y))`.

На рівні k:

`x~_k y ⇔ a(x,y)≥k`.

Ці класи визначають множини листків, що проходять через один вузол глибини k.

Відношення включення класів на сусідніх рівнях відновлює батьківські зв'язки.

Глибини листків відновлюють кінці гілок.

Unary-вузли зберігаються, оскільки однаковий клас може повторюватися на послідовних рівнях.

### Виявлене обмеження

Первинна модель SUBIT-WARP має адреси:

`B={1,2,3}`.

Отже, діти вузла є впорядкованими та мають адресні ідентифікатори.

Fingerprint `(L,h,a)` відновлює лише неупорядковану структуру.

Він не визначає, чи конкретна гілка є:
- першою;
- другою;
- третьою.

Два різні впорядковані тернарні дерева можуть мати однаковий fingerprint, якщо їхні дочірні гілки переставити місцями, не змінюючи глибини листків та глибини LCA.

### Канонічна корекція

Розділити два результати.

**Теорема A — Unordered Structural Reconstruction**

`F(T)=(L,h,a)`

визначає скінченне кореневе дерево з точністю до ізоморфізму, що не зберігає порядок дітей.

**Теорема B — Ordered SUBIT Reconstruction**

Для відновлення впорядкованого тернарного дерева fingerprint має містити додаткову інформацію про адреси листків:

`F_ordered(T)=(L,h,a,p)`,

де:

`p:L→B^{<ω}`

відображає кожен листок у його повну адресу.

Тоді множина адрес листків визначає скінченне префіксно замкнене дерево шляхів.

Вузли — усі префікси адрес листків.

Ребра:

`σ→σi`

існують тоді й лише тоді, коли `σi` є префіксом адреси хоча б одного листка.

Unary-вузли автоматично зберігаються.

Порядок дітей визначається символами `1,2,3`.

### Вердикт

- Неупорядкована реконструкція: **PASS**.
- Повна реконструкція впорядкованого SUBIT-дерева за `(L,h,a)`: **NOT VALID**.
- Розширена реконструкція за `(L,h,a,p)`: **PASS WITH CONDITIONS**.

Це не помилка теореми W27.3, а обмеження її області застосування, яке раніше не було достатньо виразно відокремлене від канонічної тернарної моделі.

# W29.5. Аудит W28 — q=0 та неоднозначність 0⁰

### Проблема

W28.8 задає:

`(T_q^(n))_{ij}=b^{-n}q^{ℓ(i,j)}`.

Для різних циліндрів першого рівня:

`ℓ(i,j)=0`.

При:

`q=0`

виникає:

`0⁰`.

Без окремої конвенції запис неоднозначний.

### Корекція

Для параметричної родини q∈[0,1] визначити:

`q⁰:=1`

для всіх q, включно з q=0.

Для k≥1:

`0^k=0`.

Це узгоджується з інтерпретацією ядра:

`K_q(ξ,η)=q^{ℓ(ξ,η)}`

для ξ≠η.

Якщо адреси не мають спільного початкового символу, то:

`ℓ(ξ,η)=0`.

Отже:

`K_0(ξ,η)=1`.

Якщо вони мають хоча б один спільний символ:

`K_0(ξ,η)=0`.

### Вердикт

**CORRECTED — CONVENTION REQUIRED.**

Це обов'язкова зміна W28 та всіх пов'язаних реалізацій.

# W29.6. Аудит спектральних норм

Для `0≤q<1`:

`c_q=(b−1)/(b−q)`.

Власні значення:

`λ_j=−(1−q)q^{j−1}/[b^{j−1}(b−q)]`.

Кратності:

`m_j=(b−1)b^{j−1}`.

### Норма оператора

Найбільше абсолютне власне значення:

`||T_q||=c_q`.

PASS.

### Норма Гільберта—Шмідта

`||T_q||²_HS=c_q²+Σ_{j≥1}m_jλ_j²`.

Після підстановки:

`||T_q||²_HS=(b−1)/(b−q²)`.

PASS.

### Слідова норма

`||T_q||₁=c_q+Σ_{j≥1}m_j|λ_j|`.

Оскільки:

`m_j|λ_j|=(b−1)(1−q)q^{j−1}/(b−q)`,

то:

`Σ_{j≥1}m_j|λ_j|=(b−1)/(b−q)=c_q`.

Отже:

`||T_q||₁=2c_q`.

PASS.

### Слід

За абсолютної збіжності спектрального ряду:

`Tr(T_q)=c_q+Σ_{j≥1}m_jλ_j=0`.

PASS.

### Критична межа

Для q=1:

`T₁=P_const`.

Тому:

`Tr(T₁)=1`,  
`||T₁||₁=1`.

Формули для q<1 не можна механічно переносити на q=1.

PASS WITH ENDPOINT SEPARATION.

# W29.7. Аудит скінченних матриць

Для рівня n:

`H_n=span{1_[σ]:|σ|=n}`.

Нормований базис:

`e_σ=b^{n/2}1_[σ]`.

Для різних циліндрів:

`(T_q^(n))_{σ,τ}=b^{-n}q^{ℓ(σ,τ)}`.

Для однакових циліндрів:

`(T_q^(n))_{σ,σ}=b^{-n}q^n c_q`.

### Перевірка діагонального елемента

Усередині одного циліндра довжини n дві незалежні адреси мають спільний префікс довжини:

`n+L`,

де L має геометричний розподіл:

`P(L=k)=(b−1)b^{-(k+1)}`.

Тому:

`E[q^L]=(b−1)/(b−q)=c_q`.

Отже:

`(T_q^(n))_{σ,σ}=b^{-n}q^n c_q`.

PASS.

### Перевірка скінченного сліду

Кількість діагональних елементів:

`b^n`.

Тому:

`Tr(T_q^(n))=b^n·b^{-n}q^n c_q=q^n c_q`.

PASS.

Важливо:

`Tr(T_q^(n))≠Tr(T_q)`.

Перший вираз — слід скінченної проєкції, другий — слід нескінченновимірного оператора.

# W29.8. Аудит зростаючого ядра

Ядро:

`K_+(ξ,η)=exp(α_wℓ(ξ,η))`.

Ймовірність того, що дві незалежні адреси мають спільний префікс довжини рівно k:

`P(ℓ=k)=(b−1)b^{-(k+1)}`.

Тому інтеграл ядра за фіксованою адресою пропорційний ряду:

`Σ_{k≥0} exp(α_w k)(b−1)b^{-(k+1)}`.

Цей ряд збігається тоді й лише тоді, коли:

`exp(α_w)<b`.

Отже:

`α_w<ln b`.

Для квадрата ядра аналогічна умова:

`exp(2α_w)<b`.

Тобто:

`α_w<(ln b)/2`.

### Вердикт

**PASS — ANALYTICALLY VERIFIED.**

Перше обмеження відповідає обмеженості оператора за оцінкою Шура; друге — умові Гільберта—Шмідта.

# W29.10. Канонічні виправлення

Обов'язково внести до v0.4:

**C-11. Zero-power convention**

`q⁰=1` для q∈[0,1].

**C-12. Ordered fingerprint separation**

Неупорядкована структурна реконструкція та реконструкція впорядкованого тернарного дерева є різними теоремами.

Умови обмеженості та Гільберта—Шмідта для зростаючого ядра не об'єднуються.
