# W27.1. Boundary operator: коректна область і ліпшицева оцінка

## W27.1.1. Вихідні визначення

Нехай `Tree∞` — простір повних тернарних дерев із мітками листків.

Для двох дерев:

`d_F(f,g)=2^{-r(f,g)}`,

де `r(f,g)` — найменша глибина адреси, на якій їхні мітки відрізняються.

Простір адрес:

`Σ={1,2,3}^N`.

За `α_v=ln2`:

`d_Σ(ξ,η)=2^{-ℓ(ξ,η)}`,

де `ℓ(ξ,η)` — довжина спільного початкового префікса.

Межа дерева:

`∂f={ξ∈Σ : ∀n≥0, f(ξ|n)=Node}`.

Вихідний клас:

`Tω={f∈Tree∞ : кожен внутрішній вузол має принаймні одну нескінченну гілку нижче себе}`.

## W27.1.2. Корекція домену

У первинному означенні `Tω` дерево, корінь якого є листком, задовольняє умову вакуумно.

Однак:

`∂f=∅`.

Тому оператор межі не може бути відображенням у `K(Σ)` — просторі непорожніх компактних множин — на всьому `Tω`.

Вводимо:

`Tω⁺={f∈Tω : ∂f≠∅}`.

Для повних дерев із властивістю Tω це еквівалентно умові:

`f(ε)=Node`,

де ε — порожня адреса кореня.

Отже:

`Tω⁺=Tω∩{f : f(ε)=Node}`.

Оскільки умова на кореневу мітку задає відкриту й замкнену множину в топології дискретних міток, а `Tω` замкнений, маємо:

`Tω⁺` — замкнений підпростір `Tree∞`.

Це виправляє проблему порожньої межі без зміни первинної структури дерев.

## W27.1.3. Теорема про ліпшицевість

**Теорема W27.1.**

Для всіх `f,g∈Tω⁺`:

`d_H(∂f,∂g)≤2d_F(f,g)`.

**Доведення.**

Якщо `f=g`, твердження очевидне.

Нехай `f≠g` і:

`m=r(f,g)`.

Тоді дерева збігаються на всіх адресах глибини меншої за m.

Візьмемо довільну адресу:

`ξ∈∂f`.

Якщо `ξ∈∂g`, то:

`dist(ξ,∂g)=0`.

Інакше існує перша адреса вздовж ξ, на якій дерево g має листок замість внутрішнього вузла.

Позначимо її σ.

Оскільки ξ проходить через вузли f, а f і g збігаються до глибини m−1, маємо:

`|σ|≥m`.

Попередня адреса:

`σ⁻`

є внутрішнім вузлом g.

За означенням `Tω` існує нескінченна гілка η дерева g, що проходить через `σ⁻`.

Тому:

`ℓ(ξ,η)≥m−1`.

Звідси:

`d_Σ(ξ,η)≤2^{-(m-1)}=2·2^{-m}`.

Оскільки:

`d_F(f,g)=2^{-m}`,

отримуємо:

`dist(ξ,∂g)≤2d_F(f,g)`.

Беручи супремум за ξ∈∂f:

`sup_{ξ∈∂f}dist(ξ,∂g)≤2d_F(f,g)`.

Симетричне міркування дає:

`sup_{η∈∂g}dist(η,∂f)≤2d_F(f,g)`.

Отже:

`d_H(∂f,∂g)≤2d_F(f,g)`.

Доведено.

**Висновок:** W5.4 можна зберегти після виправлення домену.

**Статус:** PROVED ANALYTICALLY, DOMAIN CORRECTED.

# W27.2. Параметрична ліпшицевість спектрального оператора

## W27.2.1. Постановка

Нехай b≥2, а:

`H=L²(Σ_b,μ_b)`.

Для `0≤q<1` визначено оператор:

`(T_qf)(ξ)=∫q^{ℓ(ξ,η)}f(η)dμ_b(η)`.

Його ієрархічні власні значення:

`λ₀(q)=c_q=(b−1)/(b−q)`,

`λ_j(q)=−(1−q)q^{j−1}/[b^{j−1}(b−q)]`, j≥1.

Усі оператори мають спільні ортогональні власні підпростори `W_j`.

Тому:

`||T_q−T_r||=sup_{j≥0}|λ_j(q)−λ_j(r)|`.

## W27.2.2. Лема для сталого підпростору

Для:

`c_q=(b−1)/(b−q)`

маємо:

`c'_q=(b−1)/(b−q)²`.

Оскільки:

`b−q≥b−1`,

то:

`0<c'_q≤1/(b−1)≤1`.

За теоремою Лагранжа:

`|c_q−c_r|≤|q−r|`.

## W27.2.3. Лема для ієрархічних власних значень

Для j≥1 покладемо n=j−1:

`g_n(q)=(1−q)q^n/[b^n(b−q)]`.

Тоді:

`λ_j(q)=−g_n(q)`.

Для n=0:

`g₀(q)=(1−q)/(b−q)`,

і:

`|g₀'(q)|=(b−1)/(b−q)²≤1`.

Для n≥1:

`g_n'(q)=A_n(q)−B_n(q)`,

де:

`A_n(q)=nq^{n−1}(1−q)/[b^n(b−q)]`,

`B_n(q)=q^n(b−1)/[b^n(b−q)²]`.

Обидві функції невід'ємні.

Оскільки:

`(1−q)/(b−q)≤1/(b−1)`,

отримуємо:

`A_n(q)≤n/[b^n(b−1)]`.

Також:

`(b−1)/(b−q)²≤1/(b−1)`,

тому:

`B_n(q)≤1/[b^n(b−1)]`.

Для невід'ємних A і B:

`|A−B|≤max(A,B)`.

Отже:

`|g_n'(q)|≤max(n,1)/[b^n(b−1)]`.

Для b≥2 і n≥1:

`n≤b^n`.

Тому:

`|g_n'(q)|≤1/(b−1)≤1`.

Таким чином:

`|λ'_j(q)|≤1`.

За теоремою Лагранжа:

`|λ_j(q)−λ_j(r)|≤|q−r|`.

## W27.2.4. Основна теорема

**Теорема W27.2.**

Для всіх b≥2 і q,r∈[0,1]:

`||T_q−T_r||≤|q−r|`.

**Доведення.**

Спільний ієрархічний розклад операторів дає:

`||T_q−T_r||=sup_{j≥0}|λ_j(q)−λ_j(r)|`.

Для j=0 нерівність доведено в W27.2.2.

Для всіх j≥1 її доведено в W27.2.3.

Отже:

`||T_q−T_r||≤|q−r|`.

Доведено.

**Статус:** PROVED ANALYTICALLY.

**Зауваження:** твердження стосується саме сімейства однорідних операторів зі спільним ієрархічним розкладом. Воно не поширюється автоматично на неоднорідні ядра.

# W27.3. Структурна реконструкція скінченних дерев

## W27.3.1. Обмеження початкового формулювання

Твердження про реконструкцію дерева за глибинами листків і попарними глибинами найглибших спільних предків потребує фіксації класу дерев.

Зокрема, ці дані самі по собі не визначають:
- порядок дочірніх ребер;
- мітки ребер;
- зовнішні ідентифікатори внутрішніх вузлів;
- структуру, що не лежить на жодному шляху від кореня до листка.

Тому реконструкцію слід формулювати з точністю до певного типу ізоморфізму.

## W27.3.2. Клас дерев

Нехай T — скінченне кореневе дерево з такими властивостями:

1. кожен вузол належить шляху від кореня до деякого листка;
2. усі ребра мають одиничну довжину;
3. множина листків L є скінченною;
4. листки мають сталі ідентифікатори;
5. внутрішні вузли можуть мати будь-яку скінченну кількість дітей, включно з одним.

Не враховуються порядок дітей і мітки ребер.

Для x∈L позначимо:

`h(x)=depth(x)`.

Для x,y∈L:

`a(x,y)=depth(LCA(x,y))`.

Для x=y:

`a(x,x)=h(x)`.

Дані:

`F(T)=(L,h,a)`

назвемо структурним fingerprint.

## W27.3.3. Еквівалентності на листках

Для кожного цілого k≥0 визначимо відношення:

`x~_k y ⇔ a(x,y)≥k`,

за умови, що:

`h(x)≥k` і `h(y)≥k`.

Інтуїція: два листки еквівалентні на рівні k тоді й лише тоді, коли вони проходять через той самий вузол глибини k.

Це відношення є еквівалентністю на множині листків, що існують на рівні k.

Кожен клас еквівалентності відповідає множині листків, що лежать під певним вузлом глибини k.

## W27.3.4. Реконструкція вузлів

Для кожного k визначимо вузли реконструйованого дерева як класи:

`[x]_k` за відношенням `~_k`.

Множина вузлів на рівні k:

`V_k=L_k/~_k`,

де:

`L_k={x∈L:h(x)≥k}`.

Для класу `[x]_k` його батьківський вузол на рівні k−1 визначається як клас:

`[x]_{k−1}`.

Оскільки:

`a(x,y)≥k ⇒ a(x,y)≥k−1`,

відображення батьків коректне.

Листок x розміщується на глибині h(x).

Ця конструкція зберігає unary-вузли: якщо на двох послідовних рівнях існує той самий клас листків, то це означає, що між ними немає розгалуження, але є окремий вузол.

У такий спосіб відновлюються навіть ланцюги з одним нащадком.

## W27.3.5. Теорема реконструкції

**Теорема W27.3.**

Для скінченних кореневих дерев, що задовольняють умови W27.3.2, структурний fingerprint:

`F(T)=(L,h,a)`

визначає дерево з точністю до ізоморфізму, який:
- зберігає корінь;
- зберігає ідентифікатори листків;
- зберігає глибини;
- не зобов'язаний зберігати порядок дітей або мітки ребер.

**Доведення.**

Кожен вузол v дерева T відповідає непорожній множині листків під ним:

`D(v)={x∈L : v лежить на шляху від кореня до x}`.

Якщо depth(v)=k, то:

`D(v)=[x]_k`

для будь-якого листка x під v.

Отже, класи еквівалентності `~_k` однозначно визначають усі вузли глибини k.

Відношення включення класів на сусідніх рівнях визначає батьківські зв'язки.

Глибини листків визначають момент завершення кожної гілки.

Тому fingerprint відновлює всі вузли, усі рівні, усі батьківські зв'язки та листки.

Отримане дерево ізоморфне T у зазначеному сенсі.

Доведено.

## W27.3.6. Особливі випадки

**Одновузлове дерево.**

Якщо корінь є єдиним листком:

`L={x}`, `h(x)=0`.

Fingerprint однозначно задає дерево з одним вузлом.

**Дерево з одним листком і unary-ланцюгом.**

Якщо:

`L={x}`, `h(x)=n`,

реконструюється ланцюг із n ребер та n+1 вузлів.

**Дерево з кількома листками.**

Попарні значення a(x,y) визначають рівні, на яких листки належать одному піддереву. Це відновлює всі розгалуження.

## W27.3.7. Межі теореми

Fingerprint не відновлює:
- порядок дітей;
- мітки ребер;
- зовнішні імена внутрішніх вузлів;
- додаткові дані, не закодовані у структурі кореневого дерева.

Якщо порядок ребер важливий для SUBIT-WARP, він має бути окремою частиною fingerprint.
