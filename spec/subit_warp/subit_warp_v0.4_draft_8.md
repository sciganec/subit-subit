# 4. W19.3 — Канонічна однорідна модель

Для основної спектральної теорії фіксуємо:

B={1,...,b}, b≥2.

Граничний простір:

Σ_b=B^ℕ.

μ_b=(1/b,...,1/b)^ℕ.

Метрика:

dᵥ(ξ,η)=exp(−αᵥℓ(ξ,η)).

Параметр взаємодії:

Отже:

K_q(ξ,η)=

H=L²(Σ_b,μ_b).

Це канонічна постановка для W7–W14.

# 5. W19.4 — Перевірка спектральної системи

Для b-арної однорідної моделі:

c_q=(b−1)/(b−q).

Ієрархічний розклад:

H=⊕ⱼ≥0 Wⱼ.

Для j≥1:

Власні значення T_q:

λ₀(q)=c_q,

L_q=T_q−c_qI.

Для q∈(0,1):

* τⱼ<0;
* τⱼ→−c_q;

# 6. W19.5 — Перевірка операторних норм та слідів

Для канонічного T_q встановлюємо:

‖T_q‖=c_q.

Оскільки:

c_q=(b−1)/(b−q).

Слід:

Tr(T_q)=0.

Норма Гільберта—Шмідта:

‖T_q‖²_HS=(b−1)/(b−q²).

Слідова норма:

‖T_q‖₁=2(b−1)/(b−q).

Звідси:

T_q∈S₁(H)⊂S₂(H)⊂K(H).

Тобто оператор є:

* слідовим;
* Гільберта—Шмідта;
* компактним.

Для центрованого оператора:

L_q=T_q−c_qI.

Оскільки компактний оператор є нульовим з точністю до компактного збурення:

Spec_ess(L_q)={−c_q}.

Це узгоджується зі спектральною формулою W7.

### Контрольний пункт

Слідова норма T_q не повинна плутатися з операторною нормою.

Так само:

Tr(T_q)=0

не означає:

T_q=0.

# 7. W19.6 — Перевірка скінченних апроксимацій

Позначимо:

Hₙ — простір функцій, сталих на циліндрах довжини n.

Pₙ — ортогональна проєкція на Hₙ.

Тоді:

Pₙ→I сильно.

Оскільки T_q компактний:

‖T_q−PₙT_qPₙ‖→0.

Для канонічної моделі точна похибка:

‖T_q−PₙT_qPₙ‖
=|λₙ₊₁(q)|.

Тобто:

‖T_q−PₙT_qPₙ‖
=(1−q)qⁿ/[bⁿ(b−q)].

Це узгоджується з геометричним спаданням спектральних рівнів.

## Важливе розмежування

Скінченновимірний оператор на Hₙ:

T_q⁽ⁿ⁾=PₙT_qPₙ|Hₙ.

Його спектр:

Spec(T_q⁽ⁿ⁾)
={c_q}∪{λⱼ(q):1≤j≤n}.

Центрований оператор на Hₙ:

L_q⁽ⁿ⁾=T_q⁽ⁿ⁾−c_qI_Hₙ.

Його спектр:

Spec(L_q⁽ⁿ⁾)
={0}∪{τⱼ(q):1≤j≤n}.

Він не містить окремого власного значення −c_q.

Це значення належить спектру нескінченновимірного L_q як точка накопичення.

### Два способи продовження на H

Нульове продовження:

PₙT_qPₙ−c_qPₙ.

Воно збігається сильно з L_q, але не в операторній нормі.

Зміщене продовження:

PₙT_qPₙ−c_qI_H.

Воно збігається з L_q в операторній нормі.

Ці два оператори не можна ототожнювати.

sαᵥ.

Це не помилка моделі, а межа ідентифікованості.

# 11. W19.10 — Перевірка теорії збурень

Для скінченновимірних самоспряжених операторів:

|λₖ(A+E)−λₖ(A)|≤‖E‖.

Це основна оцінка Вейля.

Для компактних самоспряжених операторів потрібно окремо розглядати додатні та від'ємні спектральні гілки.

Для операторів:

A'=A+E,

B'=B+F,

маємо:

[A',B']−[A,B]
=[E,B]+[A,F]+[E,F].

Отже:

‖[A',B']−[A,B]‖
≤2‖E‖‖B‖
+2‖A‖‖F‖
+2‖E‖‖F‖.

Це узгоджується з W16.

## Важливе уточнення

Нормова близькість операторів гарантує контроль спектральних значень, але не гарантує близькість власних підпросторів без спектрального зазору.

Для підпросторів застосовується теорія спектральних проєкторів, зокрема оцінки Девіса—Кахана.

# 13. W19.12 — Перевірка Structural Fingerprint

Для скінченного кореневого дерева з одиничними ребрами:

SF(X)=(L,h,A_LCA,P_arity).

Центральна теорема W18:

Множина листків + їхні глибини + матриця LCA визначають дерево з точністю до ізоморфізму, що зберігає відповідні дані.

Профіль арності є похідним контрольним інваріантом.

## Перевірка узгодженості

Для кожного рівня k:

ξ~ₖη ⇔ ℓ(ξ,η)≥k.

Це має бути відношення еквівалентності на множині листків, глибина яких не менша за k.

Класи еквівалентності відповідають вузлам рівня k.

Вкладення класів між рівнями визначає батьківство.

Це забезпечує конструктивну реконструкцію.

### Обмеження

Результат стосується скінченних кореневих дерев з одиничними ребрами та без вузлів, що не лежать на жодному шляху до листка.

Не слід поширювати його на довільні нескінченні дерева без окремого доведення.

# 15. W19.14 — Канонічна політика доказовості

Усі твердження SUBIT-WARP повинні належати до однієї з шести категорій.

| Код                      | Значення                                        |
| ------------------------ | ----------------------------------------------- |
| PROVED                   | Є повне математичне доведення                   |
| DERIVED                  | Формула виведена з раніше доведених результатів |
| COMPUTATIONALLY VERIFIED | Перевірено виконанням відтворюваних тестів      |
| CONJECTURE               | Є аргументи, але немає доведення                |
| OPEN                     | Задача сформульована, результат не встановлений |
| NOT IMPLEMENTED          | Програмна реалізація відсутня                   |

Категорії не є взаємозамінними.

Наприклад:

PROVED ≠ COMPUTATIONALLY VERIFIED.

NOT IMPLEMENTED ≠ OPEN.

OPEN ≠ FALSE.

Кожна теорема повинна мати:

1. унікальний ідентифікатор;
2. точні припущення;
3. формулювання;
4. доведення;
5. залежності;
6. статус;
7. відомі обмеження.

# 18. W19.17 — Критерії завершення інтеграційного аудиту

W19 вважається завершеним, коли:

1. усі означення мають єдині канонічні формулювання;
2. усі символи мають однозначні значення;
3. усі теореми мають явні припущення;
4. спектральні формули узгоджені;
5. граничні випадки q=0 та q→1⁻ описані;
6. геометричний та інтеракційний параметри розділені;
7. скінченні та нескінченні моделі не змішуються;
8. структурна і спектральна реконструкції розділені;
9. усі відкриті задачі зареєстровані;
10. жодна реалізація або формальна верифікація не заявлена без артефактів.

# 19. Підсумок W19

W19 формує канонічну основу для заключної редакції SUBIT-WARP v0.4.

Найважливіші результати інтеграційного аудиту:

* спектральна теорія має чітку область застосування;
* операторні апроксимації узгоджені з ієрархічним розкладом;
* неоднорідні дерева потребують окремого операторного представлення;
* теорія збурень застосовується лише після визначення спільного простору;
* спектральна реконструкція не замінює структурної;
* скінченний Structural Fingerprint має конструктивну теорему реконструкції.

Основний архітектурний результат:

**SUBIT-WARP складається з двох незалежних, але сумісних систем опису: Structural Layer та Spectral Layer.**

Вони повинні зберігати власні типи, припущення та критерії доказовості.
