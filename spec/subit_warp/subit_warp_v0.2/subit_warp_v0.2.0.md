# Анотація

SUBIT-WARP — математичний дослідницький модуль над SUBIT-∞, призначений для формалізації рекурсивної геометрії деревних конфігурацій, масштабної фільтрації відображень, ультраметричної геометрії простору нескінченних адрес, граничних операторів та ієрархічних спектральних конструкцій.

Специфікація розглядає п'ять взаємопов'язаних, але математично відмінних рівнів:

1. **Рекурсивна структура:** конфігурації дерев, адреси та нескінченні граничні промені.
2. **Масштабна структура:** фільтрація відображень за коефіцієнтом стискання.
3. **Ультраметрична геометрія:** метрики, циліндричні множини та розмірність межі.
4. **Гранична структура:** відображення деревних конфігурацій у простори компактних підмножин.
5. **Операторна структура:** ієрархічні ядра, скінченні лапласіани та граничні самоспряжені оператори.

Основна мета — встановити строгі математичні зв'язки між рекурсивною структурою, глибиною, масштабом, відстанню та взаємодією, не ототожнюючи їх без окремих доведень.

SUBIT-WARP не є фізичною теорією гравітації, космологічною моделлю або доведенням голографічного принципу. Будь-яке застосування до фізичних систем потребує окремої фізичної моделі, операційного визначення величин та емпіричної перевірки.

# 1. Рекурсивна структура

## 1.1. Алфавіт

Нехай:

A = {1, 2, 3}.

Це алфавіт трирозгалуженої рекурсивної структури.

## 1.2. Простір скінченних адрес

Визначимо:

Pos = A⁼⁼ = ⋃ₙ₌₀∞ Aⁿ.

Порожня адреса ε є коренем.

Для σ ∈ Pos та a ∈ A конкатенація позначається σa.

Глибина адреси:

|σ| = n, якщо σ ∈ Aⁿ.

Для адрес σ, τ ∈ Pos визначимо:

σ ∧ τ = найдовший спільний префікс σ та τ.

Pos є комбінаторною структурою кореневого трирозгалуженого дерева.

Pos не є простором конфігурацій.

## 1.3. Простір нескінченних адрес

Визначимо:

Σ = Aᴺ.

Елемент ξ ∈ Σ має вигляд:

ξ = (ξ₁, ξ₂, ξ₃, …), де ξᵢ ∈ A.

Для ξ, η ∈ Σ визначимо довжину спільного початку:

ℓ(ξ,η) = sup{n ∈ ℕ₀ : ξᵢ = ηᵢ для всіх i ≤ n}.

Якщо ξ = η, то:

ℓ(ξ,ξ) = ∞.

Якщо ξ ≠ η, то ℓ(ξ,η) є скінченним невід'ємним цілим числом.

## 1.4. Простір деревних конфігурацій Tree∞

Нехай алфавіт міток:

Λ = {None, Node} ∪ {Leaf(a) : a ∈ A}.

Множина Λ містить шість елементів.

Tree∞ — множина функцій:

f : Pos → Λ,

які задовольняють умови T1–T4.

**T1 — непорожній корінь**

f(ε) ≠ None.

**T2 — повнота дочірніх позицій вузла**

Якщо:

f(σ) = Node,

то:

f(σ·i) ≠ None

для i = 1, 2, 3.

**T3 — листок не має нащадків**

Якщо:

f(σ) = Leaf(a),

то:

f(σ·i) = None

для i = 1, 2, 3.

**T4 — поширення порожнечі**

Якщо:

f(σ) = None,

то:

f(σ·τ) = None

для будь-якого τ ∈ Pos.

Отже, допустима конфігурація має або листок, або вузол із трьома непорожніми дочірніми позиціями.

Корінь може бути листком або вузлом.

## 1.5. Коалгебраїчне подання

Визначимо функтор:

F_tree(X) = A ⊔ X³.

Для f ∈ Tree∞:

* якщо f(ε) = Leaf(a), то out(f) = inl(a);
* якщо f(ε) = Node, то out(f) = inr(f₁,f₂,f₃).

Піддерева визначені лише тоді, коли корінь є вузлом:

fᵢ(σ) = f(i·σ).

Якщо корінь є листком, піддерева не визначаються.

Tree∞ розглядається як простір допустимих конфігурацій фінальної коалгебри F_tree.

Статус повної фінальності: DP-s, якщо повний аргумент фінальності не перенесений із базової специфікації до формального доказового артефакту WARP.

## 1.6. Розмежування просторів

Встановлюємо три незалежні типи:

* Pos — скінченні адреси;
* Σ — нескінченні промені;
* Tree∞ — деревні конфігурації.

Заборонено використовувати елемент одного простору як елемент іншого без явного відображення.

# 2. Базова ультраметрична геометрія SUBIT-∞

## 2.1. Адресна відстань

Для f,g ∈ Tree∞ визначимо:

r_addr(f,g) = min{|σ| : f(σ) ≠ g(σ)}.

Якщо f = g:

r_addr(f,g) = ∞.

Базова метрика:

dₛ(f,g) = 2⁻ʳᵃᵈᵈʳ⁽ᶠ,ᵍ⁾.

За домовленістю:

2⁻∞ = 0.

Це метрика базової системи SUBIT-∞.

## 2.2. Ультраметричність

**Твердження W2.1.** dₛ є ультраметрикою на Tree∞.

Тобто:

dₛ(f,h) ≤ max{dₛ(f,g), dₛ(g,h)}.

**Доказ.**

На всіх адресах глибини, меншої за:

min{r_addr(f,g), r_addr(g,h)},

маємо:

f = g = h.

Тому:

r_addr(f,h) ≥ min{r_addr(f,g),r_addr(g,h)}.

Після застосування спадної функції 2⁻ⁿ одержуємо ультраметричну нерівність. ∎

Статус: DP-f.

## 2.3. Компактність

**Твердження W2.2.** (Tree∞,dₛ) є компактним, повним і цілком обмеженим простором.

**Доказова основа.**

Λ є скінченною дискретною множиною. Простір Λ^Pos компактний у топології добутку.

Кожна з умов T1–T4 визначається скінченним набором координат, тому задає замкнену множину.

Tree∞ є замкненою підмножиною компактного простору Λ^Pos.

Метрика dₛ метризує відповідну топологію добутку.

Отже, Tree∞ компактний. Компактний метричний простір повний і цілком обмежений. ∎

Статус: DP-f.

## 2.4. Зсув глибини піддерева

Якщо f(ε)=g(ε)=Node, то:

dₛ(fᵢ,gᵢ) ≤ 2dₛ(f,g).

Це випливає з того, що розбіжність на глибині r у піддереві відповідає розбіжності на глибині r+1 у вихідному дереві.

Статус: DP-f.

# 3. Неможливість глобального рекурсивного закону глибини

## 3.1. Постановка

Розглянемо функцію:

h : Tree∞ → ℤ.

Спробуємо вимагати, щоб для кожного дерева з коренем Node виконувалося:

h(fᵢ) = h(f)+1

для кожного дочірнього піддерева i = 1,2,3.

Це формалізує глобальний закон, за яким перехід до будь-якого дочірнього піддерева збільшує глибину на одиницю.

## 3.2. Графтинг-відображення

Для a ∈ A визначимо:

ρₐ(f) = Node(f,Leaf(a),Leaf(a)).

У координатному записі:

ρₐ(f)(ε) = Node;

ρₐ(f)(1σ) = f(σ);

ρₐ(f)(2) = Leaf(a);

ρₐ(f)(3) = Leaf(a).

Для інших адрес значення визначаються умовами T1–T4.

Побудова коректна, оскільки зберігає всі умови допустимості дерева.

## 3.3. Нерухома точка

Оскільки ρₐ стискає відстань із коефіцієнтом 1/2, за теоремою Банаха існує єдина нерухома точка pₐ:

ρₐ(pₐ)=pₐ.

Водночас:

(pₐ)₁ = pₐ.

Тобто перше дочірнє піддерево нерухомої конфігурації збігається з усією конфігурацією.

## 3.4. Теорема про неможливість

**Твердження W0.1.** Не існує функції h : Tree∞ → ℤ, яка задовольняє глобальний закон:

h(fᵢ)=h(f)+1

для кожного дерева f з коренем Node та кожного його дочірнього піддерева.

**Доказ.**

Візьмемо нерухому точку pₐ.

Оскільки:

(pₐ)₁ = pₐ,

з рекурсивного закону випливало б:

h(pₐ)=h(pₐ)+1.

Це суперечність. ∎

Статус: DP-f.

## 3.5. Межі твердження

Теорема не стверджує, що довільні функції глибини на Tree∞ не існують.

Вона виключає лише глобальну функцію, яка одночасно задовольняє наведений закон приросту для всіх допустимих дерев і всіх дочірніх переходів.

Локальні, часткові, контекстуальні або залежні від конфігурації функції глибини не виключаються.

# 4. Масштабна фільтрація відображень

## 4.1. Базовий простір правил

Визначимо:

ℛ₀ = {F : Tree∞ → Tree∞ : dₛ(F(f),F(g)) ≤ dₛ(f,g)}.

Елементи ℛ₀ називаються нерозтягувальними відображеннями.

Метрика на просторі правил:

dℛ(F,G) = sup{dₛ(F(f),G(f)) : f ∈ Tree∞}.

Оскільки Tree∞ компактний, а значення dₛ обмежені одиницею, supremum існує.

## 4.2. Фільтровані класи

Для m ∈ ℕ₀ визначимо:

ℛ⁽ᵐ⁾ = {F : Tree∞ → Tree∞ :

dₛ(F(f),F(g)) ≤ 2⁻ᵐdₛ(f,g)}.

Тоді:

ℛ⁽⁰⁾ = ℛ₀.

Фільтрація вкладена:

ℛ⁽ᵐ⁺¹⁾ ⊆ ℛ⁽ᵐ⁾.

## 4.3. Композиційна властивість

**Твердження W1.1.**

Якщо:

F ∈ ℛ⁽ᵐ⁾, G ∈ ℛ⁽ᵏ⁾,

то:

F∘G ∈ ℛ⁽ᵐ⁺ᵏ⁾.

**Доказ.**

dₛ(F(G(f)),F(G(g)))

≤ 2⁻ᵐdₛ(G(f),G(g))

≤ 2⁻ᵐ2⁻ᵏdₛ(f,g)

= 2⁻⁽ᵐ⁺ᵏ⁾dₛ(f,g).

Отже, F∘G ∈ ℛ⁽ᵐ⁺ᵏ⁾. ∎

Статус: DP-f.

## 4.4. Перетин фільтрації

**Твердження W1.2.**

⋂ₘ₌₀∞ ℛ⁽ᵐ⁾ = {κ꜀ : c ∈ Tree∞},

де κ꜀(f)=c.

**Доказ.**

Нехай F належить усім ℛ⁽ᵐ⁾.

Для будь-яких f,g:

dₛ(F(f),F(g)) ≤ 2⁻ᵐdₛ(f,g)

для кожного m.

При m → ∞ права частина прямує до нуля.

Тому:

dₛ(F(f),F(g))=0.

Отже F(f)=F(g), і F є сталим відображенням.

Зворотне включення очевидне. ∎

Статус: DP-f.

## 4.5. Замкненість

Нехай C(Tree∞,Tree∞) — простір неперервних відображень із рівномірною метрикою:

dᵤ(F,G)=supₓdₛ(F(x),G(x)).

**Твердження W1.3.** Кожен клас ℛ⁽ᵐ⁾ замкнений у C(Tree∞,Tree∞).

**Доказ.**

Нехай Fₙ ∈ ℛ⁽ᵐ⁾ і Fₙ → F рівномірно.

Для всіх x,y:

dₛ(Fₙ(x),Fₙ(y)) ≤ 2⁻ᵐdₛ(x,y).

Переходимо до границі за n:

dₛ(F(x),F(y)) ≤ 2⁻ᵐdₛ(x,y).

Отже F ∈ ℛ⁽ᵐ⁾. ∎

Статус: DP-f.

Компактність класів ℛ⁽ᵐ⁾ може бути доведена через рівномірну обмеженість, рівностепеневу неперервність і компактність Tree∞ за теоремою Арцела—Асколі.

## 4.6. Параметр масштабного загасання

Введемо незалежний параметр:

α𝑤 > 0.

Визначимо:

Ω𝑤(m)=exp(−α𝑤m).

Тоді:

Ω𝑤(m+k)=Ω𝑤(m)Ω𝑤(k).

Це гомоморфізм адитивного моноїда ℕ₀ у мультиплікативний моноїд додатних дійсних чисел.

Умова:

α𝑤 = ln 2

дає:

Ω𝑤(m)=2⁻ᵐ.

Без цієї умови Ω𝑤 є окремою параметризацією масштабу загасання, а не коефіцієнтом фільтрації ℛ⁽ᵐ⁾.

# 5. Рекурсивна локалізація

## 5.1. Графтинг як стискальне відображення

Для a ∈ A:

ρₐ(f)=Node(f,Leaf(a),Leaf(a)).

Для f,g ∈ Tree∞:

r_addr(ρₐ(f),ρₐ(g))=r_addr(f,g)+1.

Отже:

dₛ(ρₐ(f),ρₐ(g))=½dₛ(f,g).

Тому:

ρₐ ∈ ℛ⁽¹⁾.

## 5.2. Ітерації

Для m ∈ ℕ₀:

dₛ(ρₐᵐ(f),ρₐᵐ(g))=2⁻ᵐdₛ(f,g).

Це випливає індукцією за m.

## 5.3. Нерухома точка

За теоремою Банаха існує єдина pₐ ∈ Tree∞:

ρₐ(pₐ)=pₐ.

Для довільного f:

dₛ(ρₐᵐ(f),pₐ)=2⁻ᵐdₛ(f,pₐ).

Отже, кожна конфігурація під ітераціями ρₐ експоненційно наближається до pₐ.

## 5.4. Ентропійне застереження

Для стискального відображення ρₐ на компактному метричному просторі:

h_top(ρₐ)=0.

Це твердження стосується саме графтинг-динаміки ρₐ.

Воно не поширюється автоматично на всі можливі динаміки на Tree∞ або на добуткових просторах SUBIT.

Зокрема, нульова ентропія проєкційної метаеволюції g∞=π_R не означає, що кожна інша метаеволюція має додатну ентропію.

Статус: DP-f за стандартною теоремою про ентропію стискального відображення.

# 6. Ультраметрична геометрія нескінченної межі

## 6.1. Візуальний параметр

Нехай:

αᵥ > 0.

Визначимо для ξ,η ∈ Σ:

dᵥ(ξ,η)=exp(−αᵥℓ(ξ,η)), якщо ξ ≠ η;

dᵥ(ξ,ξ)=0.

Параметр αᵥ визначає швидкість спадання відстані зі збільшенням спільного префікса.

## 6.2. Ультраметрична нерівність

**Твердження W3.1.** dᵥ є ультраметрикою на Σ.

**Доказ.**

Для будь-яких ξ,η,ζ:

ℓ(ξ,ζ) ≥ min{ℓ(ξ,η),ℓ(η,ζ)}.

Оскільки exp(−αᵥt) є спадною функцією:

dᵥ(ξ,ζ) ≤ max{dᵥ(ξ,η),dᵥ(η,ζ)}.

Симетрія, невід'ємність і умова тотожності нерозрізнюваних точок випливають із означення. ∎

Статус: DP-f.

## 6.3. Циліндричні множини

Для σ ∈ Pos визначимо:

[σ]={ξ ∈ Σ : σ є префіксом ξ}.

Якщо |σ|=n, то:

diam([σ])=exp(−αᵥn).

Множини [σ] є відкритими й замкненими та утворюють базу топології Σ.

## 6.4. Канторова структура

Σ є компактним простором, гомеоморфним стандартному канторовому простору.

Він:

* метризовний;
* цілком незв'язний;
* без ізольованих точок;
* компактний.

Ці властивості не залежать від вибору αᵥ>0, оскільки всі додатні значення αᵥ задають ту саму топологію.

## 6.5. Рівномірна міра

Визначимо добуткову міру μ так, щоб кожен символ мав імовірність 1/3.

Для циліндра глибини n:

μ([σ])=3⁻ⁿ.

Це ймовірнісна міра на Σ.

## 6.6. Розмірність Хаусдорфа

**Твердження W3.2.**

dimᴴ(Σ,dᵥ)=ln3/αᵥ.

**Доказ.**

Позначимо:

s=ln3/αᵥ.

Для циліндра [σ] глибини n:

μ([σ])=3⁻ⁿ=exp(−αᵥsn)=diam([σ])ˢ.

Для верхньої оцінки покриваємо Σ усіма 3ⁿ циліндрами глибини n. Сума s-степенів їхніх діаметрів:

3ⁿexp(−αᵥsn)=1.

Для t>s відповідна сума прямує до нуля при n→∞. Отже:

dimᴴ(Σ,dᵥ)≤s.

Для нижньої оцінки використовуємо масову оцінку. Куля радіуса r, де exp(−αᵥ(n+1)) ≤ r < exp(−αᵥn), є циліндром глибини n або збігається з таким циліндром залежно від відкритої/замкненої конвенції.

Її міра не перевищує:

3⁻ⁿ ≤ 3rˢ.

Отже існує стала C=3 така, що:

μ(B(x,r))≤Crˢ.

За принципом розподілу мас:

dimᴴ(Σ,dᵥ)≥s.

Разом:

dimᴴ(Σ,dᵥ)=ln3/αᵥ. ∎

Статус: DP-f.

## 6.7. Незалежність візуального параметра

αᵥ є параметром геометричної метрики.

Він не визначає автоматично α𝑤 — параметр загасання взаємодії.

Зв'язок між ними може бути введений як додаткова гіпотеза, але не є наслідком самої ультраметричної конструкції.

# 7. Граничний оператор деревної конфігурації

## 7.1. Нескінченні гілки

Для f ∈ Tree∞ визначимо:

∂f={ξ ∈ Σ : для кожного n≥0 активний префікс ξ|ₙ належить f}.

Тут ξ|ₙ — префікс ξ довжини n.

Активною вважається позиція з міткою Node або Leaf.

Нескінченний промінь не може проходити через Leaf, тому для ξ ∈ ∂f кожна позиція ξ|ₙ має бути Node.

## 7.2. Клас Tω

Визначимо Tω ⊆ Tree∞ умовами:

1. f(ε)=Node;
2. кожен активний вузол має хоча б одне нескінченне продовження.

Еквівалентна умова:

для кожної позиції σ, де f(σ)=Node, і кожного N>|σ| існує активна позиція τ, що продовжує σ і має глибину N.

За умовою T2 це означає, що активне дерево не має вузлів, від яких усі шляхи завершуються на скінченній глибині.

## 7.3. Непорожність і компактність межі

**Твердження W5.1.** Для кожного f ∈ Tω множина ∂f є непорожньою компактною підмножиною Σ.

**Доказ.**

Непорожність випливає з умови нескінченного продовження та леми Кеніга для скінченно розгалуженого дерева.

Замкненість: якщо ξ не належить ∂f, то існує скінченний префікс ξ|ₙ, який не є активним вузлом. Усі промені з тим самим префіксом також не належать ∂f. Отже доповнення ∂f відкрите.

Оскільки Σ компактний, замкнена підмножина ∂f компактна. ∎

Статус: DP-f.

## 7.4. Простір компактних підмножин

Позначимо K(Σ) простір усіх непорожніх компактних підмножин Σ.

Для P,Q ∈ K(Σ) визначимо метрику Гаусдорфа:

dᴴ(P,Q)=max{

supₚ∈P infᵩ∈Q dᵥ(p,q),

supᵩ∈Q infₚ∈P dᵥ(p,q)

}.

Це метрика на K(Σ).

## 7.5. Оператор межі

Визначимо:

∂ : Tω → K(Σ),

f ↦ ∂f.

Це типізований граничний оператор.

Він не визначається як відображення Tree∞ → K(Σ) для всіх дерев, оскільки скінченні дерева мають порожню межу.

## 7.6. Оцінка неперервності

Нехай f,g ∈ Tω і:

r=r_addr(f,g).

Якщо r=∞, то f=g і dᴴ(∂f,∂g)=0.

Якщо r<∞, то всі адреси глибини меншої за r збігаються. Тому кожен промінь із ∂f має спільний префікс довжини принаймні r−1 з деяким променем із ∂g, і навпаки.

Отже:

dᴴ(∂f,∂g) ≤ exp(−αᵥ(r−1)).

Оскільки:

dₛ(f,g)=2⁻ʳ,

отримуємо:

dᴴ(∂f,∂g) ≤ exp(αᵥ) · dₛ(f,g)^(αᵥ/ln2).

**Наслідок.** Оператор межі є глобально гельдеровим на Tω з показником:

θ=αᵥ/ln2,

якщо праву частину використовувати з відповідною сталою.

За αᵥ=ln2:

dᴴ(∂f,∂g)≤2dₛ(f,g).

За αᵥ≥ln2 оператор також є ліпшицевим із наведеною грубою сталою 2.

За 0<αᵥ<ln2 ця оцінка гарантує гельдеровість, але не дає ліпшицевості.

Статус: DP-f за наведених означень Tω та метрик.

## 7.7. Розрив на всьому Tree∞

Для всього Tree∞ межа може бути порожньою.

Розглянемо:

fₙ=ρₐⁿ(Leaf(a)).

Тоді:

fₙ → pₐ,

де pₐ — нерухома точка ρₐ.

Для кожного скінченного n:

∂fₙ=∅.

Водночас pₐ є нескінченним самоподібним деревом і має непорожню межу.

Тому оператор межі з кодоменом K(Σ) не може бути неперервним на всьому Tree∞: на скінченних деревах він взагалі не має значення в K(Σ).

Можливі дві моделі:

* обмежити область на Tω;
* перейти до розширеного простору компактних підмножин K₀(Σ), що містить ∅, і окремо визначити метрику або топологію для порожньої множини.

У v0.2 використовується перший варіант.

# 8. Ієрархічні ядра взаємодії

## 8.1. Параметри

Нехай:

K₀>0, α𝑤>0, β>0.

α𝑤 є параметром загасання взаємодії.

β є показником сингулярності граничного ядра.

Вони не ототожнюються з αᵥ без окремої гіпотези.

## 8.2. Радіальний потенціал

Для скінченної адреси σ:

Kᵣ(σ)=K₀exp(−α𝑤|σ|).

Це однопозиційний радіальний потенціал.

Він залежить від глибини однієї адреси.

Він не є парним ядром.

## 8.3. Ядро спільного предка

Для σ,τ ∈ Pos:

Kₐ(σ,τ)=K₀exp(−α𝑤|σ∧τ|).

Властивості:

* симетричність;
* невід'ємність;
* залежність від глибини спільного предка.

Kₐ не є автоматично додатно визначеним ядром. Додатна визначеність має перевірятися окремо для кожної обраної моделі та області визначення.

## 8.4. Граничне ядро

Для ξ,η ∈ Σ, ξ≠η:

Kᵦ(ξ,η)=K₀dᵥ(ξ,η)⁻ᵝ.

Еквівалентно:

Kᵦ(ξ,η)=K₀exp(αᵥβℓ(ξ,η)).

Область визначення:

Dom(Kᵦ)={(ξ,η): ξ≠η}.

На діагоналі ядро сингулярне.

## 8.5. Інтегровність граничного ядра

Для фіксованого ξ визначимо:

I(ξ)=∫ΣKᵦ(ξ,η)dμ(η).

Міра множини променів, що мають із ξ спільний префікс рівно довжини n:

μ{η:ℓ(ξ,η)=n}=2·3⁻ⁿ⁻¹.

Тому:

I(ξ)=K₀Σₙ₌₀∞2·3⁻ⁿ⁻¹exp(αᵥβn).

Це геометричний ряд:

I(ξ)=(2K₀/3)Σₙ₌₀∞(exp(αᵥβ)/3)ⁿ.

Він збігається тоді й лише тоді, коли:

exp(αᵥβ)<3.

Отже:

αᵥβ<ln3.

Оскільки:

dimᴴ(Σ,dᵥ)=ln3/αᵥ,

умова набуває вигляду:

β<dimᴴ(Σ,dᵥ).

**Твердження W6.1.** Граничне ядро Kᵦ є інтегровним за μ у кожній точці ξ тоді й лише тоді, коли β<dimᴴ(Σ,dᵥ).

Статус: DP-f.

## 8.6. Інтегральний оператор

За умови інтегровності можна формально визначити:

(Tᵦf)(ξ)=∫ΣKᵦ(ξ,η)f(η)dμ(η).

Однак існування обмеженого оператора на L²(Σ,μ) потребує окремих оцінок типу Шура або інших умов інтегровності ядра.

Умова β<dimᴴ є необхідною та достатньою для скінченності наведеного точкового інтеграла, але сама по собі не є повним доказом усіх операторних властивостей Tᵦ.

## 8.7. Відмінність трьох моделей

| Ядро | Аргументи | Залежність                        |
| ---- | --------- | --------------------------------- |
| Kᵣ   | σ         | Глибина адреси                    |
| Kₐ   | σ,τ       | Спільний предок                   |
| Kᵦ   | ξ,η       | Відстань між граничними променями |

Їх не можна використовувати як взаємозамінні математичні об'єкти.

# 9. Скінченні ієрархічні оператори

## 9.1. Скінченні рівні

Для n≥1 визначимо:

Σₙ=Aⁿ.

Тоді:

|Σₙ|=3ⁿ.

На Σₙ розглядаємо рівномірну міру:

μₙ({x})=3⁻ⁿ.

## 9.2. Вага взаємодії

Нехай задано послідовність:

w₀,w₁,w₂,…

де:

wⱼ>0.

Для x≠y ∈ Σₙ визначимо:

w(x,y)=w(|x∧y|).

## 9.3. Ієрархічний лапласіан

На функціях f:Σₙ→ℂ визначимо:

Δₙf(x)=Σᵧ≠ₓw(|x∧y|)(f(y)−f(x)).

Оператор має такі властивості:

1. Лінійність.
2. Симетричність.
3. Нульові суми рядків.
4. Від'ємна напіввизначеність.

## 9.4. Від'ємна напіввизначеність

Для скалярного добутку, узгодженого з μₙ:

⟨f,Δₙf⟩ = −½Σₓ,ᵧ w(|x∧y|)|f(x)−f(y)|².

Отже:

⟨f,Δₙf⟩≤0.

Нульовий простір складається зі сталих функцій, оскільки всі попарні ваги додатні.

Статус: DP-f.

## 9.5. Ієрархічний хвильовий розклад

Нехай Vₖ — простір функцій, сталих на циліндрах довжини k.

Тоді:

V₀⊂V₁⊂…⊂Vₙ.

Для k=0,…,n−1 визначимо:

Wₖ=Vₖ₊₁⊖Vₖ.

Розмірність:

dim(Wₖ)=2·3ᵏ.

Маємо ортогональний розклад:

L²(Σₙ,μₙ)=V₀⊕W₀⊕…⊕Wₙ₋₁.

## 9.6. Спектр скінченного лапласіана

**Твердження W7.1.**

Для кожного k=0,…,n−1 власне значення Δₙ на Wₖ дорівнює:

λₙ,ₖ=−(Σⱼ₌₀ᵏ⁻¹2·3ⁿ⁻ʲ⁻¹wⱼ+3ⁿ⁻ᵏwₖ).

Кратність:

mₖ=2·3ᵏ.

Нульове власне значення на V₀ має кратність 1.

**Доказова ідея.**

Для функції з Wₖ сума значень на кожному циліндрі рівня k дорівнює нулю, а функція є сталою на циліндрах рівня k+1.

Розбиваємо суму Δₙ на:

* адреси з першим розходженням на рівнях j<k;
* адреси з першим розходженням на рівні k.

Внесок кожного рівня є сталим кратним f(x), а сума коефіцієнтів дає наведене λₙ,ₖ.

Статус: DP-f після явного виписування підрахунку для кожного рівня; до перенесення цього підрахунку в доказовий артефакт статус реалізації залишається не підтвердженим.

## 9.7. Перевірка кратностей

1+Σₖ₌₀ⁿ⁻¹2·3ᵏ=3ⁿ.

Отже спектральні підпростори охоплюють весь скінченний простір.

## 9.8. Нормалізація

Визначимо:

Δ̃ₙ=3⁻ⁿΔₙ.

Тоді:

λ̃ₙ,ₖ=−(Σⱼ₌₀ᵏ⁻¹2·3⁻ʲ⁻¹wⱼ+3⁻ᵏwₖ).

Для фіксованого k це значення не залежить від n, якщо n>k.

Ця властивість дозволяє побудувати сумісну нескінченну модель.

# 10. Граничний спектральний оператор

## 10.1. Нескінченний простір

Розглянемо L²(Σ,μ), де μ — рівномірна добуткова міра.

Для кожного n визначимо Vₙ як простір функцій, сталих на циліндрах довжини n.

Маємо:

V₀⊂V₁⊂V₂⊂…

Об'єднання:

V_fin=⋃ₙVₙ

є щільним у L²(Σ,μ).

## 10.2. Вкладення скінченних просторів

Функція f:Σₙ→ℂ ототожнюється з функцією на Σ, яка має однакове значення на всьому циліндрі відповідного префікса.

Це ізометричне вкладення:

L²(Σₙ,μₙ) → L²(Σ,μ).

Для n<m вкладення узгоджені.

## 10.3. Сумісність нормалізованих операторів

Нехай f ∈ Vₘ і n>m.

Розглянемо f як функцію на Σₙ.

Кожна точка на рівні m має 3ⁿ⁻ᵐ нащадків на рівні n.

Взаємодії всередині одного циліндра рівня m не дають внеску, оскільки f там стала.

Для інших циліндрів кожна взаємодія повторюється 3ⁿ⁻ᵐ разів.

Отже:

Δₙf=3ⁿ⁻ᵐΔₘf.

Після нормалізації:

3⁻ⁿΔₙf=3⁻ᵐΔₘf.

Тому оператори Δ̃ₙ сумісні на вкладених скінченновимірних просторах.

## 10.4. Граничний оператор на V_fin

Визначимо:

Δ_fin f=Δ̃ₙf,

якщо f∈Vₙ.

Сумісність із §10.3 гарантує, що це визначення не залежить від вибору достатньо великого n.

Оператор Δ_fin є щільно визначеним і симетричним на V_fin.

Він є від'ємно напіввизначеним.

## 10.5. Граничні хвильові підпростори

У L²(Σ,μ) визначимо:

Wₖ=Vₖ₊₁⊖Vₖ.

Тоді:

L²(Σ,μ)=V₀⊕⨁ₖ₌₀∞Wₖ.

Кожен Wₖ має розмірність:

dim(Wₖ)=2·3ᵏ.

Це повний ортогональний ієрархічний розклад.

## 10.6. Граничні власні значення

Для k≥0:

λₖ=−(Σⱼ₌₀ᵏ⁻¹2·3⁻ʲ⁻¹wⱼ+3⁻ᵏwₖ).

На Wₖ оператор діє множенням на λₖ.

На сталих функціях V₀ оператор дорівнює нулю.

Отже, спектральна модель має вигляд:

Δ∞|V₀=0;

Δ∞|Wₖ=λₖI.

## 10.7. Самоспряжене замикання

Визначимо:

aₖ=−λₖ≥0.

Для f∈L²(Σ,μ) розкладемо:

f=f₀+Σₖfₖ,

де f₀∈V₀ і fₖ∈Wₖ.

Визначимо область:

Dom(Δ∞)={f : Σₖaₖ²||fₖ||²<∞}.

На цій області:

Δ∞f=−Σₖaₖfₖ.

Оскільки оператор діагональний у повному ортогональному розкладі з дійсними власними значеннями, він є самоспряженим.

Він є від'ємно напіввизначеним.

Ця конструкція визначає самоспряжене замикання Δ_fin.

**Твердження W7.2.** Для послідовності додатних ваг wⱼ граничний оператор Δ∞ існує як самоспряжений від'ємно напіввизначений оператор із зазначеною областю визначення.

Статус: DP-f за побудованою ортогональною діагоналізацією.

## 10.8. Спеціальна параметризація ваг

Нехай:

wⱼ=3ʲexp(α𝑤βj).

Позначимо:

q=exp(α𝑤β).

Тоді:

aₖ=(2/3)Σⱼ₌₀ᵏ⁻¹qʲ+qᵏ.

Якщо q≠1:

aₖ=(2/3)(qᵏ−1)/(q−1)+qᵏ.

Якщо q=1:

aₖ=1+(2/3)k.

Отже:

λₖ=−aₖ.

За α𝑤β>0 маємо q>1, тому |λₖ| зростає експоненційно з k.

## 10.9. Кратності нескінченного спектра

Власне значення λₖ має кратність:

mₖ=2·3ᵏ,

якщо відповідні λₖ є попарно різними.

Для спеціальної моделі q≥1:

aₖ₊₁−aₖ=(5/3)qᵏ+(2/3)qᵏ⁺¹−qᵏ?

Уточнена різниця за загальною формулою:

aₖ₊₁−aₖ=3⁻ᵏ⁻¹(3wₖ₊₁−wₖ).

Для wₖ=3ᵏqᵏ:

aₖ₊₁−aₖ=3⁻ᵏ⁻¹(3·3ᵏ⁺¹qᵏ⁺¹−3ᵏqᵏ)

=3qᵏ⁺¹−(1/3)qᵏ.

Це додатне для q>1/9, зокрема для всіх q≥1.

Отже для параметрів α𝑤β≥0 спектральні рівні є строго різними.

## 10.10. Спектральна збіжність

Скінченні нормалізовані оператори Δ̃ₙ збігаються з Δ_fin на V_fin після вкладення у L²(Σ,μ).

Самоспряжений Δ∞ є замиканням цього сумісного оператора.

Для повної теореми про збіжність резольвент або напівгруп необхідно явно зафіксувати вибрану топологію операторної збіжності та відповідні області визначення.

У v0.2 заявляється сумісність на щільному ядрі та самоспряжене замикання, але не заявляється окрема теорема про збіжність у будь-якому сильнішому сенсі без додаткового доказу.

Це є математичним інтерфейсом, а не доказом фізичної відповідності.

## 11.3. Статус відповідності

WARP–CH–CORRESPONDENCE = STRUCTURAL / NOT PROVEN.

Для переходу до математичної відповідності необхідно надати конкретні відображення та довести їхні властивості.
