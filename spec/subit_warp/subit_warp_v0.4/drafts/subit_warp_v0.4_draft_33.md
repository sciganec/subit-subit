## 2. Підтверджені математичні блоки

### 2.1. Тотальне кодування та компактність

За скінченного алфавіту A простір станів
`S_A={ABSENT, INTERNAL}∪{LEAF(a):a∈A}`
є скінченним дискретним компактним простором. `Pos_b=B_b^{<ω}` зліченний, тому `S_A^{Pos_b}` компактний за теоремою Тихонова.

TC-01–TC-05 задаються умовами на скінченних наборах координат. Кожне порушення має скінченний свідок, отже `C_Full` і `C_Partial` замкнені. Відповідно, обидва класи компактні.

### 2.2. Замкненість Tω

Для фіксованого u множина пар (t,ξ), у яких t(u)=INTERNAL, ξ продовжує u та всі наступні префікси ξ є INTERNAL, замкнена в компактному просторі `C_Partial×[u]`. Її проєкція на `C_Partial` компактна, отже замкнена. Об'єднання з clopen-множиною кодів, де t(u)≠INTERNAL, дає замкнену умову для кожного u. Перетин за всіма u залишається замкненим.

Аргумент коректний за скінченного b та заданої добуткової топології.

### 2.3. Замкнені кулі та Hausdorff dimension

Для
`exp(−α_v n)≤r<exp(−α_v(n−1))`
маємо саме
`B̄_v(ξ,r)=[ξ|n]`.
Гранична точка r=exp(−α_v n) включена правильно. Звідси
`μ_b(B̄_v(ξ,r))=b^(−n)`
та
`r^s/b<μ_b(B̄_v(ξ,r))≤r^s`,
де `s=ln(b)/α_v`.

Верхня оцінка Hausdorff dimension через циліндричні покриття та нижня оцінка через mass distribution principle узгоджуються. Для нижньої оцінки достатньо застосувати оцінку замкнених куль до відкритих куль через включення `B(ξ,r)⊆B̄(ξ,r)`.

### 2.4. Boundary metric conversion

Для `d_v=d_Σ^γ`, γ>0, індукована Hausdorff-метрика задовольняє
`d_H,v(C,D)=d_H,Σ(C,D)^γ`.
Це випливає з монотонності x↦x^γ та сумісності цієї функції з inf/sup на компактних множинах. Перехід від Hölder-оцінки до Lipschitz-оцінки при γ≥1 та d_F≤1 коректний.

### 2.5. Зростаюче ядро

Для t>1 рівень спільного префікса k має міру (b−1)b^(−k−1). Тому рядок ядра має суму
`Σ_{k≥0}(b−1)b^(−k−1)t^k=(b−1)/(b−t)`
саме за t<b. Для t≥b застосування оператора до сталої функції дає нескінченний інтеграл, отже обмеженого оператора на L² не існує.

У bounded regime власні значення
`λ_j(t)=((t−1)/(b−t))(t/b)^(j−1)`
з кратністю `(b−1)b^(j−1)` прямують до нуля. Тому оператор компактний. HS-поріг t²<b випливає з інтеграла |K|². Рівневі внески в trace norm не прямують до нуля для t>1, отже оператор не є trace-class.

### 2.6. Скінченні апроксимації

Формула для n=0 узгоджується з одновимірним H₀ та домовленістю q⁰=1. Endpoint q=1 задає проєкцію на сталі функції, яка точно зберігається кожним P_n. Trace-norm збіжність при n→∞ для фіксованого q<1 не змішується з границею q→1−.

### 2.7. Fingerprint

FP-01–FP-06 забезпечують еквівалентності на кожному рівні k. Умови сумісності класів за рівнями задають єдиного батька; singleton-класи з h(x)>k зберігають unary-вузли, а singleton з h(x)=k є листком. T-021′ коректно відновлює лише зайнятий trie та не робить висновку про семантику відсутніх слотів.

## 3. Обов'язкові уточнення перед канонічною інтеграцією

### BLOCKER A — явне вкладення PartialTree у тотальні коди

W23′.1.5 задає рекурсивний тип:

`PartialTree_A^(b) ≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A^(b))^b`.

W34.1.3 вводить тотальний код `t:Pos_b→S_A`, але не визначає явну функцію кодування між цими двома поданнями.

Потрібно додати:
1. `Enc:PartialTree_A^(b)→C_Partial`;
2. рекурсивні правила: None ↦ ABSENT; Leaf(a) ↦ LEAF(a); Node(children) ↦ INTERNAL у корені з рекурсивним кодуванням дітей;
3. канонічне продовження ABSENT під None та LEAF;
4. зворотне декодування з `C_Partial`;
5. доказ взаємної оберненості Enc/Dec;
6. доказ, що `d_F` на кодах збігається з метрикою першої відмінності W23′.

Для `FullTree_A^(b)` аналогічно зафіксувати обмеження Enc на `C_Full`.

Це має бути не лише пояснювальна аналогія, а конкретний ізоморфізм типів або явно визначена вкладена репрезентація. Без цього таблиця інтеграції не повинна говорити про заміну канонічного типу.

### BLOCKER B — не перейменовувати Tω без фіксації області

Означення W23′ Tω та означення `C_ω` у W34.1.3 змістовно узгоджуються після Enc, але формальна відповідність наразі не записана.

До завершення BLOCKER A використовувати позначення `Tω_code:=C_ω` або `Tω^{(code)}`. Після доведення Enc/Dec можна встановити рівність/ізоморфізм із W23′ Tω. Це усуває ризик прихованого перевизначення вже наявного канонічного символу.

### BLOCKER C — уточнити статус Tω⁺ як множини кодів

У W23′ Tω⁺ визначено через непорожню межу. W34.1.3 доводить рівність Tω⁺ = Tω∩{root INTERNAL} для свого тотального кодування. Після BLOCKER A потрібно явно перенести цю рівність через Enc/Dec, а не використовувати її як безумовну тотожність двох різних подань.

## 7. Додатковий blocker: індуктивність чи коіндуктивність PartialTree

Під час повторного зіставлення W23′.1.5 виявлено ще одну передумову, яку слід закрити до Enc/Dec.

W23′.1.4 прямо називає `FullTree_A` коіндуктивним типом. W23′.1.5 записує рівняння для `PartialTree_A^(b)`, але не вказує, чи це least fixed point (індуктивний тип), чи greatest fixed point (коіндуктивний тип).

Ця відмінність істотна:
- індуктивне тлумачення зазвичай описує лише скінченні дерева;
- коіндуктивне тлумачення допускає нескінченні гілки;
- W23′.7 та нове означення `C_ω` потребують класу, в якому нескінченні гілки справді є елементами типу.

Тому BLOCKER A слід розширити двома кроками:

1. Явно зафіксувати семантику `PartialTree_A^(b)` у W23′: inductive чи coinductive.
2. Якщо задумана модель включає нескінченні часткові дерева, визначити coinductive/greatest-fixed-point версію та будувати Enc/Dec саме для неї. Якщо ж наявний тип індуктивний, не оголошувати `C_Partial` його ізоморфною репрезентацією; запровадити окремий тип `PartialTree∞_A^(b)` або `PartialTree^{co}_A^(b)`.

Це не спростовує компактність `C_Partial`; воно уточнює, з яким саме вихідним типом її можна ототожнити.

**Оновлений інтеграційний статус:** BLOCKER A = OPEN (тип fixed-point не визначений); BLOCKER B/C залишаються відкритими до доведення Enc/Dec та перенесення Tω/Tω⁺.
