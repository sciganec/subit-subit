# 2. Strengthened Tree Domain

## 2.1. Проблема початкового означення

Початкове означення:

`Contω(t,u) ⇔ ∀k ≥ 0, ∃v ∈ B_b^k : t(u·v)=INTERNAL`

визначає нескінченне продовження від вузла u.

Початковий клас:

`Tω = {t ∈ C_Partial : Contω(t, ε)}`

гарантує нескінченне INTERNAL-продовження від кореня.

Але він не гарантує, що кожен INTERNAL-вузол має нескінченне продовження.

Це розрізнення критичне для T-007.

Тому історичне означення Tω зберігається, але для теорем, які потребують локального продовження з кожного внутрішнього вузла, вводиться сильніший клас.

## 2.2. Нове означення Tω^pr

Нехай:

- `B_b = {1, …, b}` — скінченний алфавіт дочірніх позицій;
- `B_b*` — множина скінченних адрес;
- `ε` — коренева адреса;
- `t : B_b* → C` — часткова конфігурація дерева;
- `INTERNAL` — стан внутрішнього вузла;
- `LEAF` — стан термінального вузла.

Визначимо:

`Tω^pr = {t ∈ C_Partial : ∀u ∈ B_b*, t(u)=INTERNAL ⇒ Contω(t,u)}`

Тобто кожен INTERNAL-вузол має нескінченне INTERNAL-продовження.

Для коренево орієнтованого класу:

`Tω^pr,+ = {t ∈ Tω^pr : t(ε)=INTERNAL}`

Цей клас є сильнішим за початковий root-continuation клас.

Зокрема:

`Tω^pr,+ ⊆ Tω⁺`

за умови, що `Tω⁺` визначено як початковий клас із нескінченним продовженням від кореня.

## 2.3. Важливе розрізнення

Необхідно зберегти три різні поняття:

**Root continuation**

`Contω(t, ε)`

Гарантує нескінченне продовження від кореня.

**Local continuation**

`Contω(t, u)`

Гарантує нескінченне продовження від конкретного вузла u.

**Persistent continuation**

`∀u, t(u)=INTERNAL ⇒ Contω(t,u)`

Гарантує нескінченне продовження з кожного внутрішнього вузла.

Ці поняття не є взаємозамінними.

# 3. Compactness of Tω^pr

## 3.1. Передумови

Нехай простір конфігурацій `C_Partial` наділений добутковою топологією.

Припускаємо:

1. Алфавіт станів скінченний.
2. Множина адрес `B_b*` зліченна.
3. Простір `C_Partial` компактний.
4. Для кожної адреси u координатне відображення `t ↦ t(u)` неперервне.

Мета — довести, що `Tω^pr` є замкненим підпростором `C_Partial`.

## 3.2. Локальна умова

Для кожного вузла u визначимо:

`U(u,k) = {t : ∃v ∈ B_b^k, t(u·v)=INTERNAL}`

Оскільки `B_b^k` скінченна, множина `U(u,k)` є скінченним об'єднанням циліндричних множин.

Циліндричні множини в добутковій топології є clopen.

Отже:

`U(u,k)` є clopen.

Визначимо:

`Cω(u) = ⋂_{k≥0} U(u,k)`

За означенням:

`t ∈ Cω(u) ⇔ Contω(t,u)`

Оскільки перетин замкнених множин є замкненим:

`Cω(u)` є closed.

## 3.3. Умова persistent continuation

Для кожної адреси u:

`P(u) = {t : t(u) ≠ INTERNAL} ∪ Cω(u)`

Перша множина є clopen, друга — closed.

Тому їх об'єднання є closed.

Тепер:

`Tω^pr = ⋂_{u∈B_b*} P(u)`

Оскільки множина адрес зліченна, це зліченний перетин замкнених множин.

Отже:

`Tω^pr` є closed у `C_Partial`.

## 3.4. Компактність кореневого підкласу

Множина:

`R = {t : t(ε)=INTERNAL}`

є clopen.

Тому:

`Tω^pr,+ = Tω^pr ∩ R`

є замкненою в компактному просторі `C_Partial`.

Звідси:

**Theorem W48.1-C1 — Compactness of Persistent-Continuation Trees**

Якщо `C_Partial` компактний, то:

`Tω^pr` і `Tω^pr,+` є компактними.

**Proof status:** PROVED, за наведених топологічних передумов.

# 4. T-007 — Corrected Boundary Stability Theorem

## 4.1. Виправлення домену

Початкове твердження:

`d_H,Σ(∂f,∂g) ≤ 2 d_F(f,g)`

не є коректним на всьому початковому класі `Tω⁺`.

Контрприклад W48 залишається чинним.

Тому T-007 отримує новий домен:

`f,g ∈ Tω^pr,+`

Це не косметична зміна. Вона є необхідною умовою коректності теореми.

## 4.2. Метрики

Нехай:

`r_F(f,g) = min{|u| : f(u) ≠ g(u)}`

для `f ≠ g`.

Визначимо:

`d_F(f,g) = 2^(-r_F(f,g))`

та:

`d_F(f,f)=0`.

Для граничних послідовностей `ξ,η ∈ Σ_b` нехай:

`ℓ(ξ,η) = common-prefix-length(ξ,η)`

Тоді:

`d_Σ(ξ,η) = 2^(-ℓ(ξ,η))`

з конвенцією:

`d_Σ(ξ,ξ)=0`.

Для непорожніх компактних множин межі:

`d_H,Σ(A,B) = max{sup_{ξ∈A} inf_{η∈B} d_Σ(ξ,η), sup_{η∈B} inf_{ξ∈A} d_Σ(ξ,η)}`

## 4.3. Теорема

**T-007′ — Persistent-Continuation Boundary Stability**

Для будь-яких:

`f,g ∈ Tω^pr,+`

виконується:

`d_H,Σ(∂f,∂g) ≤ 2 d_F(f,g)`.

## 4.4. Доведення

Якщо `f=g`, твердження очевидне.

Нехай `f≠g` і:

`m = r_F(f,g)`.

За означенням:

`f(u)=g(u)` для всіх `|u|<m`.

Оскільки обидва дерева належать `Tω^pr,+`, їхні корені є INTERNAL.

Тому `m≥1`.

Візьмемо довільний:

`ξ ∈ ∂f`.

Якщо:

`ξ ∈ ∂g`,

то:

`inf_{η∈∂g} d_Σ(ξ,η)=0`.

Розглянемо інший випадок:

`ξ ∉ ∂g`.

Оскільки `g ∈ Tω^pr,+`, а ξ не є його граничною послідовністю, шлях ξ у g мусить завершитися на деякому LEAF.

Нехай цей LEAF розташований на глибині ℓ.

Оскільки f і g збігаються на всіх вузлах глибини меншої за m, маємо:

`ℓ ≥ m`.

Розглянемо спільний префікс:

`u = ξ|_(m−1)`.

Тобто u — вузол на глибині m−1 уздовж ξ.

Оскільки ξ належить ∂f, вузол u є INTERNAL у f.

Через збіг f і g на глибинах, менших за m, вузол u є INTERNAL і в g.

Тепер використаємо умову:

`g ∈ Tω^pr,+`.

З неї випливає:

`Contω(g,u)`.

Отже, з вузла u існує нескінченне INTERNAL-продовження.

Але продовження, яке проходило б через дочірній вузол на шляху ξ, не могло б бути нескінченним: цей шлях у g завершується LEAF на глибині ℓ.

Тому існує інше нескінченне INTERNAL-продовження з u.

Нехай його гранична послідовність — η.

Тоді:

`η ∈ ∂g`

і η має спільний префікс із ξ довжини принаймні m−1.

Отже:

`d_Σ(ξ,η) ≤ 2^(-(m−1))`

тобто:

`d_Σ(ξ,η) ≤ 2 · 2^(-m)`.

Оскільки:

`d_F(f,g)=2^(-m)`,

маємо:

`inf_{η∈∂g} d_Σ(ξ,η) ≤ 2 d_F(f,g)`.

Оскільки ξ було довільним:

`sup_{ξ∈∂f} inf_{η∈∂g} d_Σ(ξ,η) ≤ 2 d_F(f,g)`.

Повністю симетричний аргумент із перестановкою f та g дає:

`sup_{η∈∂g} inf_{ξ∈∂f} d_Σ(ξ,η) ≤ 2 d_F(f,g)`.

Отже:

`d_H,Σ(∂f,∂g) ≤ 2 d_F(f,g)`.

Теорему доведено.

**Proof status:** PROVED ON Tω^pr,+.

## 4.5. Наслідок

Відображення межі:

`∂ : Tω^pr,+ → K(Σ_b)`

є Lipschitz неперервним із константою 2.

Тут `K(Σ_b)` — простір непорожніх компактних підмножин `Σ_b`, наділений метрикою Гаусдорфа.

Не слід переносити цей висновок на весь `Tω⁺` без додаткових умов.

# 5. T-014 — Corrected Matrix Row Sum

## 5.1. Проблема нормування

У WARP v0.4 для матриці `T_q^(n)` у нормованому циліндричному базисі було заявлено:

`Σ_v (T_q^(n))_(u,v) = b^(-n)c_q`

Це твердження несумісне з нормуванням базису.

Нехай:

`e_u = b^(n/2) 1_[u]`

де `[u]` — циліндричний простір, а міра є рівномірною Bernoulli-мірою.

Тоді:

`‖e_u‖₂=1`.

Константна функція має представлення:

`1 = b^(-n/2) Σ_u e_u`.

Якщо:

`T_q 1 = c_q 1`,

то константний вектор координат є власним вектором матриці `T_q^(n)` із власним значенням `c_q`.

Звідси:

`Σ_v (T_q^(n))_(u,v) = c_q`

за симетричного матричного представлення.

## 5.2. Виправлене твердження

**T-014 — Row Sum of the Normalized Cylinder Matrix**

Для нормованого циліндричного базису:

`Σ_v (T_q^(n))_(u,v) = c_q`

де:

`c_q = (b−1)/(b−q)`.

Множник `b^(-n)` у правій частині вилучається.

## 5.3. Контрольний приклад

Нехай:

`b=2, n=1, q=1/2`.

Тоді:

`c_q = (2−1)/(2−1/2)=2/3`.

Для відповідної матриці:

- діагональний елемент дорівнює 1/6;
- позадіагональний елемент дорівнює 1/2.

Сума рядка:

`1/6 + 1/2 = 2/3`.

Отже:

`Σ_v (T_q^(1))_(u,v)=c_q`.

Вона не дорівнює 1/3.

## 5.4. Нормативне уточнення

Якщо в іншій частині специфікації потрібне ненормоване представлення, воно має бути визначене окремо із зазначенням:

- конкретного базису;
- норми базисних векторів;
- правила переходу між базисами;
- відповідного нормування матриці.

Не можна змішувати ці дві конвенції в межах одного твердження.

**Proof status:** PROVED.

# 6. T-019 — Global Lipschitz Continuity of T_q

## 6.1. Формулювання

Розглянемо сімейство операторів `T_q`, параметризоване:

`q ∈ [0,1]`.

Їхні спектральні значення:

`c_q = (b−1)/(b−q)`

та:

`λ_j(q) = −(1−q)q^(j−1) / [b^(j−1)(b−q)]`

для `j≥1`.

Оператори діагоналізуються в одному й тому самому ортогональному розкладі.

Тому:

`‖T_q−T_r‖ = max(|c_q−c_r|, sup_(j≥1)|λ_j(q)−λ_j(r)|)`.

Мета — довести існування глобальної константи L.

## 6.2. Частина I: константний спектральний компонент

Маємо:

`c_q = (b−1)/(b−q)`.

Похідна:

`c'_q = (b−1)/(b−q)^2`.

Оскільки:

`b−q ≥ b−1`,

то:

`|c'_q| ≤ 1/(b−1)`.

За `b≥2`:

`|c'_q| ≤ 1`.

За теоремою Лагранжа:

`|c_q−c_r| ≤ |q−r|`.

## 6.3. Частина II: λ₁

Для `j=1`:

`λ₁(q)=−(1−q)/(b−q)`.

Похідна:

`λ₁'(q)=(b−1)/(b−q)^2`.

Тому:

`|λ₁'(q)| ≤ 1/(b−1) ≤ 1`.

Звідси:

`|λ₁(q)−λ₁(r)| ≤ |q−r|`.

## 6.4. Частина III: λ_j для j≥2

Для `j≥2` визначимо:

`N_j(q)=(1−q)q^(j−1)`.

Тоді:

`λ_j(q)=−b^(-(j−1)) N_j(q)/(b−q)`.

Похідна:

`N'_j(q)=q^(j−2)[(j−1)−jq]`.

Потрібно встановити рівномірну оцінку:

`|N'_j(q)| ≤ 1`

для всіх `j≥2` і `q∈[0,1]`.

Розглянемо два випадки.

### Випадок A

Якщо:

`0≤q≤(j−1)/j`,

то:

`N'_j(q)≥0`.

Функція:

`q^(j−2)[(j−1)−jq]`

досягає максимуму на відрізку в точці:

`q=(j−2)/j`

для `j>2`.

У цій точці:

`N'_j(q)=((j−2)/j)^(j−2) ≤ 1`.

Для j=2 маємо:

`N'_2(q)=1−2q`

і відповідна оцінка також виконується.

### Випадок B

Якщо:

`(j−1)/j≤q≤1`,

то:

`N'_j(q)≤0`.

Модуль:

`|N'_j(q)|=q^(j−2)[jq−(j−1)]`.

Ця функція зростає на відповідному відрізку та досягає максимуму при q=1:

`|N'_j(1)|=1`.

Отже, для всіх `j≥2`:

`|N'_j(q)|≤1`.

Також:

`0≤N_j(q)≤1`.

Тепер диференціюємо:

`d/dq [N_j(q)/(b−q)] = N'_j(q)/(b−q) + N_j(q)/(b−q)^2`.

Отже:

`|λ'_j(q)| ≤ b^(-(j−1)) [1/(b−q) + 1/(b−q)^2]`.

Оскільки:

`b^(-(j−1))≤1`

та:

`b−q≥b−1≥1`,

отримуємо:

`|λ'_j(q)| ≤ 1/(b−1)+1/(b−1)^2 ≤ 2`.

За теоремою Лагранжа:

`|λ_j(q)−λ_j(r)| ≤ 2|q−r|`

для всіх `j≥2`.

## 6.5. Глобальний висновок

Об'єднавши оцінки для:

- `c_q`;
- `λ₁(q)`;
- `λ_j(q)`, `j≥2`,

отримуємо:

`‖T_q−T_r‖ ≤ 2|q−r|`.

**T-019 — Global Operator-Norm Lipschitz Continuity**

Для всіх:

`q,r ∈ [0,1]`

виконується:

`‖T_q−T_r‖ ≤ 2|q−r|`.

Отже, сімейство операторів T_q є глобально Lipschitz неперервним у операторній нормі.

**Lipschitz constant:** `L=2`.

Ця константа є доведеною верхньою межею. Її оптимальність не заявляється.

## 6.6. Крайові значення

При q=0:

`c_0=(b−1)/b`.

Для j=1:

`λ₁(0)=−1/b`.

Для j≥2:

`λ_j(0)=0`.

При q=1:

`c_1=1`

та:

`λ_j(1)=0`.

Усі наведені спектральні компоненти неперервно продовжуються на замкнений інтервал `[0,1]`.

Тому глобальна оцінка включає обидва крайові значення.

**Proof status:** PROVED.

# 7. T-020′ — Strengthened Unordered Fingerprint

## 7.1. Проблема

Початковий fingerprint:

`F(T)=(L,h,a)`

містить:

- L — множину вузлів;
- h — функцію глибини;
- a — функцію спільної глибини.

Однак лише цих даних недостатньо без додаткових структурних умов для однозначної реконструкції rooted tree.

Зокрема, необхідно закрити:

- існування кореня;
- унікальність батьківського вузла;
- зв'язність;
- відсутність циклів;
- узгодженість рівнів;
- семантику unary nodes;
- відсутність непідтриманих вузлів.

## 7.2. Посилений fingerprint

Визначимо:

`F(T)=(L,h,a,p)`

де:

- L — множина вузлів;
- h — функція глибини;
- a — функція спільної глибини;
- p — батьківське відношення.

У неупорядкованому випадку p не містить інформації про порядок дочірніх позицій.

## 7.3. Умови реконструкції

**FP-01 — Nonempty vertex set**

`L ≠ ∅`.

**FP-02 — Nonnegative depth**

`h : L → ℕ₀`.

**FP-03 — Unique root**

Існує єдиний вузол r:

`h(r)=0`.

**FP-04 — Unique parent**

Для кожного `x∈L`, де `h(x)>0`, існує рівно один `p(x)∈L` такий, що:

`h(p(x))=h(x)−1`.

**FP-05 — Parent chain**

Повторне застосування p до будь-якого вузла завершується коренем r за скінченну кількість кроків.

**FP-06 — Symmetry of common-depth function**

`a(x,y)=a(y,x)`.

**FP-07 — Self-depth**

`a(x,x)=h(x)`.

**FP-08 — Parent uniqueness consistency**

Для різних вузлів x та y:

якщо один є батьком іншого, то:

`a(x,y)=min(h(x),h(y))`.

Зворотне твердження має також виконуватися для вузлів різної глибини.

**FP-09 — Level coverage**

Якщо існує вузол глибини n, то для кожного:

`0≤k≤n`

існує вузол глибини k на його батьківському шляху.

Ця умова виключає пропущені рівні.

**FP-10 — No unsupported vertices**

Кожен вузол, окрім кореня, повинен бути пов'язаний із коренем через скінченний ланцюг батьківських відношень.

Не допускаються ізольовані компоненти.

**FP-11 — Unary-node convention**

Вузол з одним дочірнім вузлом залишається окремим вузлом дерева.

Його не можна автоматично стискати або видаляти.

Це необхідно для збереження глибинної метрики.

## 7.4. Умова узгодженості a

Для функції спільної глибини додатково вимагається:

`0≤a(x,y)≤min(h(x),h(y))`

та ультраметрична нерівність у формі similarity:

`a(x,z)≥min(a(x,y),a(y,z))`.

Це забезпечує узгодженість спільних предків.

## 7.5. Статус T-020′

T-020′ може стверджувати реконструкцію rooted tree лише за умови виконання FP-01…FP-11 та відповідності функції a батьківській структурі.

Саме по собі існування трійки `(L,h,a)` не є достатнім.

**Proof status:** CONDITIONAL.

Перехід до PROVED потребує окремого формального доказу:

1. існування реконструйованого дерева;
2. єдиності реконструкції з точністю до ізоморфізму;
3. збереження глибинної структури;
4. збереження unary nodes;
5. відповідності реконструйованої функції спільної глибини початковій a.

# 8. T-021′ — Ordered Fingerprint and Occupancy Semantics

## 8.1. Початкове означення

Упорядкований fingerprint:

`F_ord(T)=(L,h,a,p)`

де:

`p : L → B_b*`

призначає кожному вузлу адресу в упорядкованому дереві.

Ін'єктивність p забезпечує, що різні вузли не мають однакової адреси.

Prefix closure:

якщо адреса u належить образу p, то всі її скінченні префікси також мають належати образу p.

Це визначає occupied ordered trie.

Однак цього недостатньо для повного опису часткової структури.

## 8.2. Проблема відсутніх дочірніх позицій

Якщо дочірня позиція не присутня в `L`, це може означати щонайменше два різні стани:

- позиція структурно відсутня;
- стан позиції невідомий або ще не встановлений.

Ці стани не можна ототожнювати.

Тому для реконструкції часткових дерев вводиться додаткова функція статусу позиції.

## 8.3. Розширений ordered fingerprint

Визначимо:

`F_ord⁺(T)=(L,h,a,p,σ)`

де:

`σ : L × B_b → {PRESENT, ABSENT, UNKNOWN}`.

Семантика:

**PRESENT**

Дочірня позиція існує і має відповідний вузол.

**ABSENT**

Дочірня позиція структурно відсутня.

**UNKNOWN**

Наявність дочірньої позиції не встановлена.

## 8.4. Structural constraints

Для кожного вузла u та дочірньої позиції i:

Якщо:

`σ(u,i)=PRESENT`,

то існує рівно один вузол v з адресою:

`p(v)=p(u)·i`.

Якщо:

`σ(u,i)=ABSENT`,

то вузла з адресою `p(u)·i` не існує.

Якщо:

`σ(u,i)=UNKNOWN`,

то fingerprint не дозволяє робити висновок про існування або відсутність відповідного дочірнього вузла.

Отже, UNKNOWN не є синонімом ABSENT.

## 8.5. Визначення terminal та internal

Для повністю визначеної структури:

- LEAF — усі дочірні позиції ABSENT;
- INTERNAL — принаймні одна дочірня позиція PRESENT.

Якщо є хоча б одна UNKNOWN-позиція, структура не повинна автоматично класифікуватися як повністю визначений LEAF.

Це дозволяє зберегти різницю між структурною термінальністю та епістемічною невизначеністю.

## 8.6. Unary convention

Якщо існує рівно одна дочірня позиція PRESENT, вузол є unary INTERNAL.

Unary-вузол не можна автоматично зливати з його єдиним дочірнім вузлом.

Інакше змінюються:

- глибина;
- common-prefix structure;
- глибинна метрика;
- потенційні спектральні характеристики.

## 8.7. Статус T-021′

Fingerprint:

`F_ord=(L,h,a,p)`

є достатнім для реконструкції occupied ordered trie за відповідних умов.

Але він не є достатнім для відновлення семантики ABSENT/UNKNOWN у часткових структурах.

Для такої реконструкції необхідний розширений:

`F_ord⁺=(L,h,a,p,σ)`.

**Proof status:** CONDITIONAL.

Реконструкція occupied trie та реконструкція часткового дерева з тризначною семантикою мають бути двома окремими твердженнями.

# 9. Spectral Results — Domain Conditions

Усі спектральні твердження T_q та T_+ мають супроводжуватися явним переліком передумов.

Обов'язкові умови:

1. Простір межі — повний `Σ_b`.
2. Міра — рівномірна Bernoulli-міра.
3. Використовується визначений ієрархічний ортогональний розклад.
4. Ядро має зафіксовану діагональну конвенцію.
5. Для операторного визначення явно вказано область застосування.
6. Формальні інтегральні вирази не оголошуються bounded operators без відповідної оцінки.

Окремо необхідно розрізняти:

`Tr(T_q)=0`

та:

`Tr(T_q^(n))=q^n c_q`.

Це різні твердження, які стосуються різних операторних об'єктів.

Так само:

`T_q → P_const`

в операторній нормі не означає:

`‖T_q−P_const‖₁ → 0`.

Для відповідного сімейства при `q<1` trace-norm відстань може залишатися сталою:

`‖T_q−P_const‖₁=1`.

Тому операторна, trace-norm та інші форми збіжності повинні реєструватися окремо.
