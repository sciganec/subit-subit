# PART I. CANONICAL TREE CLASSES

## 1. Адресний простір

Нехай:

`B_b={1,…,b}`, де `b∈ℕ`, `b≥2`.

Множина скінченних адрес:

`Pos_b=B_b^{<ω}`.

Корінь:

`ε∈Pos_b`.

Множина нескінченних адрес:

`Σ_b=B_b^ℕ`.

Для `u,v∈Pos_b` префіксне відношення:

`u≼v ⇔ ∃w∈Pos_b : v=u·w`.

Для нескінченної адреси `ξ∈Σ_b` її префікс довжини `k` позначається:

`ξ|k`.

Кожне дерево кодується тотальною функцією:

`t:Pos_b→S_A`,

де:

`S_A={ABSENT,INTERNAL} ⊔ {LEAF(a):a∈A}`.

## 2. Умови допустимості

Зберігаються канонічні умови:

**TC-01 — Root admissibility**

`t(ε)≠ABSENT`.

**TC-02 — Absent closure**

`t(u)=ABSENT ⇒ ∀i∈B_b, t(u·i)=ABSENT`.

**TC-03 — Leaf closure**

`t(u)=LEAF(a) ⇒ ∀i∈B_b, t(u·i)=ABSENT`.

**TC-04 — Full branching**

Для повних дерев:

`t(u)=INTERNAL ⇒ ∀i∈B_b, t(u·i)≠ABSENT`.

**TC-05 — Partial branching**

Для часткових дерев дочірні позиції внутрішнього вузла можуть бути INTERNAL, LEAF або ABSENT.

З цих умов випливає важлива властивість:

Якщо `t(u)=INTERNAL`, то всі префікси адреси `u` також мають стан INTERNAL, за умови, що `u≠ε`.

Отже, множина INTERNAL-адрес кожного допустимого дерева є prefix-closed.

## 3. Чотири класи, які необхідно розмежувати

### 3.1. FullTree

`FullTree_A^(b)=νX. Leaf(A) ⊔ Node(X^b)`.

Кожен внутрішній вузол має рівно `b` наявних дочірніх піддерев.

Повнота branching не означає, що дерево обов'язково має нескінченну гілку.

Наприклад, корінь може бути INTERNAL, а всі його діти — LEAF.

Таке дерево є повним, але має скінченну глибину.

### 3.2. PartialTree∞

`PartialTree∞_A^(b)=νX. None ⊔ Leaf(A) ⊔ Node(X^b)`.

Часткове дерево допускає відсутні дочірні позиції.

Цей клас містить як дерева з нескінченними гілками, так і дерева без них.

### 3.3. FiniteTree

Скінченне кореневе дерево:

`FiniteTree=(V,E,r)`, де `|V|<∞`.

Це окремий комбінаторний тип.

Його не можна автоматично ототожнювати з `PartialTree∞` без явного embedding або coding map.

Для скінченного дерева нескінченна межа зазвичай порожня.

### 3.4. C_Partial

`C_Partial` — простір тотальних кодів часткових дерев із допустимим коренем.

Це ambient-простір, у якому можна визначати підпростори нескінченного продовження.

**Результат:** C_Partial, FullTree, PartialTree∞ та FiniteTree — різні математичні об'єкти.

# PART II. INFINITE CONTINUATION

## 4. Предикат Contω

Для `t∈C_Partial` та `u∈Pos_b` визначимо:

`Contω(t,u) ⇔ ∀k≥0, ∃v∈B_b^k : t(u·v)=INTERNAL`.

Інтерпретація:

Для кожної скінченної глибини від `u` існує хоча б один внутрішній нащадок на цій глибині.

За TC-02 і TC-03 усі префікси внутрішнього нащадка також внутрішні.

Тому множина внутрішніх нащадків `u` утворює скінченно-гіллясте дерево необмеженої висоти.

За лемою Кеніга з цього випливає існування нескінченної гілки INTERNAL-вузлів, що починається в `u`.

### Лема 4.1 — Infinite continuation implies internal root

`Contω(t,u) ⇒ t(u)=INTERNAL`.

**Доведення.**

Візьмемо `k=0`.

Маємо єдине слово довжини 0 — `ε`.

Отже:

`t(u·ε)=t(u)=INTERNAL`.

Доведено.

---

## 5. Підпростір Tω

Визначимо:

`Tω={t∈C_Partial : Contω(t,ε)}`.

Це клас дерев, у яких від кореня існують внутрішні шляхи довільної скінченної довжини.

За лемою 4.1:

`t(ε)=INTERNAL`.

Однак Tω не вимагає, щоб кожен внутрішній вузол мав нескінченне продовження.

Це принципове обмеження.

В одному дереві може існувати:

- один нескінченний шлях;
- декілька нескінченних шляхів;
- нескінченна кількість нескінченних шляхів;
- внутрішні вузли, які закінчуються скінченними внутрішніми піддеревами.

Останній випадок дозволений у Tω.

---

## 6. Підпростір Tω⁺

Визначимо межу:

`∂t={ξ∈Σ_b : ∀k≥0, t(ξ|k)=INTERNAL}`.

Тоді:

`Tω⁺={t∈Tω : ∂t≠∅}`.

### Теорема 6.1 — Boundary existence

Для скінченного `b`:

`Tω=Tω⁺`.

**Доведення.**

Нехай `t∈Tω`.

Тоді внутрішні вузли від кореня мають необмежену глибину.

Оскільки branching factor `b` скінченний, кожен вузол має скінченну кількість дітей.

За лемою Кеніга існує нескінченна послідовність внутрішніх вузлів:

`ε ≺ u₁ ≺ u₂ ≺ …`

яка визначає нескінченну адресу:

`ξ∈Σ_b`.

Для кожного `k`:

`t(ξ|k)=INTERNAL`.

Отже:

`ξ∈∂t`.

Тому:

`∂t≠∅`.

Отже:

`Tω⊆Tω⁺`.

Зворотне включення випливає безпосередньо з визначення Tω⁺.

Доведено.

### Важливе застереження

Рівність:

`Tω=Tω⁺`

залежить від скінченності branching factor.

Для нескінченного branching вона не є загальним фактом.

У канонічній SUBIT-WARP моделі `b=3`, тому умова скінченного branching виконується.

# PART III. THE PRUNED SUBSPACE

## 7. Чому Tω⁺ недостатньо для T-007

Теорема T-007 стосується не лише існування межі, а й стабільності межі при зміні дерева.

Нехай:

`f,g∈Tω⁺`.

Нехай їхні коди вперше відрізняються на глибині `r`.

Тоді:

`d_F(f,g)=2^(-r)`.

Для доведення оцінки Гаусдорфа потрібно показати:

Для кожної гілки `ξ∈∂f` існує гілка `η∈∂g`, яка збігається з `ξ` щонайменше до глибини `r−1`.

Але Tω⁺ гарантує лише одну нескінченну гілку від кореня.

Воно не гарантує нескінченного продовження кожного внутрішнього вузла.

Отже, внутрішній префікс гілки `ξ` може бути внутрішнім у `g`, але не мати жодного нескінченного продовження.

Тоді найближча гілка `g` може відходити від `ξ` значно раніше за глибину `r−1`.

Це руйнує універсальну оцінку `2d_F`.

---

## 8. Контрприклад до T-007 на Tω⁺

Нехай `b≥2`, а `r≥2`.

Виберемо дві адреси глибини `r−1`:

`p=1^(r−1)`,

`q=2^(r−1)`.

Вони мають різні перші символи.

Побудуємо дерева `f` і `g` так, щоб:

1. усі їхні стани на глибинах менших за `r` збігалися;
2. обидві адреси `p` та `q` були INTERNAL;
3. у дереві `f` існувала нескінченна гілка через `p`;
4. у дереві `g` вузол `p` не мав INTERNAL-нащадків на глибині `r`;
5. у дереві `g` існувала нескінченна гілка через `q`;
6. усі інші гілки завершувалися скінченно.

Тоді:

`f,g∈Tω=Tω⁺`.

Перша відмінність кодів виникає на глибині `r`:

`r_F(f,g)=r`.

Отже:

`d_F(f,g)=2^(−r)`.

Межа `f` містить нескінченну гілку через `p`.

Межа `g` містить нескінченну гілку через `q`, але не через `p`.

Оскільки `p` та `q` відрізняються першим символом, для будь-якої гілки `ξ` через `p` та будь-якої гілки `η` через `q`:

`ℓ(ξ,η)=0`.

Тому:

`d_Σ(ξ,η)=1`.

Отже:

`d_H,Σ(∂f,∂g)=1`.

Але:

`2d_F(f,g)=2^(1−r)`.

Для `r≥2`:

`2^(1−r)<1`.

Таким чином:

`d_H,Σ(∂f,∂g)>2d_F(f,g)`.

**Висновок:** T-007 не є коректною на всьому домені Tω⁺.

Це не проблема константи 2. Контрприклад показує, що відношення між двома метриками може бути необмеженим на цьому домені.

---

## 9. Визначення Tω^pr

Для усунення проблеми введемо підпростір дерев, у яких кожен внутрішній вузол має нескінченне продовження.

### Definition 9.1 — Pruned infinite-continuation space

`Tω^pr={t∈C_Partial : ∀u∈Pos_b, t(u)=INTERNAL ⇒ Contω(t,u)}`.

Інтерпретація:

Кожен внутрішній вузол належить хоча б одній нескінченній гілці, яка починається з цього вузла.

Це умова відсутності скінченно завершених внутрішніх піддерев.

Вона не забороняє:

- листки;
- відсутні позиції;
- різну кількість нескінченних продовжень;
- нерівномірне розгалуження;
- дерева з однією нескінченною гілкою.

### Definition 9.2 — Rooted pruned space

`Tω^pr,+={t∈Tω^pr : t(ε)=INTERNAL}`.

Оскільки корінь внутрішній і кожен внутрішній вузол має нескінченне продовження:

`Tω^pr,+⊆Tω⁺`.

Це канонічний домен для T-007.

# PART IV. COMPACTNESS OF THE PRUNED DOMAIN

## 10. Топологія кодів

Нехай:

`S_A` — скінченний дискретний простір станів.

Розглянемо:

`X=S_A^Pos_b`

із топологією добутку.

Оскільки `Pos_b` є зліченною множиною, а `S_A` — скінченним компактним простором, за теоремою Тихонова:

`X` компактний.

Простір `C_Partial` є замкненим підпростором `X`, оскільки умови TC-01–TC-03 визначаються локальними обмеженнями на скінченні множини координат.

Отже:

`C_Partial` компактний.

## 11. Замкненість Tω^pr

Для фіксованої адреси `u` визначимо:

`Q_u={t : t(u)≠INTERNAL або Contω(t,u)}`.

Маємо:

`Contω(t,u) ⇔ ∀k≥0, ∃v∈B_b^k : t(u·v)=INTERNAL`.

Для кожного фіксованого `k` множина:

`O_(u,k)={t : ∃v∈B_b^k, t(u·v)=INTERNAL}`

є скінченним об'єднанням циліндричних множин.

Оскільки `B_b^k` скінченна, кожна така множина є відкритою та замкненою.

Тому:

`Contω(·,u)=⋂_(k≥0) O_(u,k)`

є замкненою.

Множина:

`{t:t(u)≠INTERNAL}`

також є clopen.

Отже:

`Q_u={t:t(u)≠INTERNAL}∪{t:Contω(t,u)}`

є замкненою.

Тепер:

`Tω^pr=⋂_(u∈Pos_b) Q_u`.

Перетин замкнених множин замкнений.

Тому:

`Tω^pr` є замкненим у `C_Partial`.

Умова:

`t(ε)=INTERNAL`

є clopen.

Отже:

`Tω^pr,+`

також замкнений у `C_Partial`.

### Теорема 11.1 — Compactness of pruned domain

`Tω^pr,+` є компактним метричним простором із метрикою `d_F`.

**Доведення.**

`C_Partial` компактний.

`Tω^pr,+` є його замкненою підмножиною.

Отже, `Tω^pr,+` компактний.

Топологія, індукована `d_F`, збігається з топологією добутку на кодованих деревах.

Доведено.

# PART V. BOUNDARY MAP

## 12. Межа конкретного дерева

Для `t∈Tω⁺`:

`∂t={ξ∈Σ_b : ∀k≥0, t(ξ|k)=INTERNAL}`.

Для кожного `k` визначимо:

`U_k(t)=⋃{[u] : u∈B_b^k, t(u)=INTERNAL}`,

де `[u]` — циліндр нескінченних адрес, що починаються з `u`.

Тоді:

`∂t=⋂_(k≥0) U_k(t)`.

Оскільки `B_b^k` скінченна, `U_k(t)` є скінченним об'єднанням clopen-циліндрів.

Отже, `U_k(t)` є замкненою множиною.

Тому `∂t` замкнена в `Σ_b`.

Простір `Σ_b` компактний.

Отже:

`∂t` компактна.

Для `t∈Tω⁺` вона також непорожня.

### Теорема 12.1 — Boundary compactness

Для кожного `t∈Tω⁺`:

`∂t∈K(Σ_b)`.

**Статус:** PROVED.

---

## 13. Межове відображення

Визначимо:

`∂ : Tω⁺ → K(Σ_b)`,

`t↦∂t`.

Це відображення коректно визначене на Tω⁺, оскільки межа кожного такого дерева є непорожньою компактною множиною.

Але для стабільності цього відображення потрібен сильніший домен.

Надалі:

`∂_pr : Tω^pr,+ → K(Σ_b)`.

Саме це відображення використовується у виправленій T-007.

# PART VI. T-007 — INDEPENDENT PROOF ON THE PRUNED DOMAIN

## 14. Теорема T-007^pr

Нехай:

`f,g∈Tω^pr,+`.

Тоді:

`d_H,Σ(∂f,∂g)≤2d_F(f,g)`.

### Доведення

Якщо `f=g`, то:

`∂f=∂g`

і відстань Гаусдорфа дорівнює нулю.

Нехай:

`f≠g`.

Позначимо:

`r=r_F(f,g)`.

Оскільки обидва дерева мають внутрішній корінь:

`f(ε)=g(ε)=INTERNAL`.

Тому:

`r≥1`.

За визначенням `r_F`, коди збігаються на всіх адресах глибини меншої за `r`.

Отже, для кожної адреси `u` з:

`|u|=r−1`

маємо:

`f(u)=g(u)`.

Візьмемо довільну адресу:

`ξ∈∂f`.

Нехай:

`u=ξ|(r−1)`.

За визначенням межі:

`f(u)=INTERNAL`.

Оскільки дерева збігаються на глибині `r−1`:

`g(u)=INTERNAL`.

Оскільки `g∈Tω^pr,+`, кожен його внутрішній вузол має нескінченне продовження.

Тому:

`Contω(g,u)`.

За лемою Кеніга існує:

`η∈∂g`

така, що `η` продовжує адресу `u`.

Отже:

`ℓ(ξ,η)≥r−1`.

За означенням ультраметрики:

`d_Σ(ξ,η)≤2^(−(r−1))`.

Тобто:

`d_Σ(ξ,η)≤2·2^(−r)`.

Оскільки:

`d_F(f,g)=2^(−r)`,

маємо:

`d_Σ(ξ,η)≤2d_F(f,g)`.

Оскільки `ξ` була довільною:

`sup_(ξ∈∂f) inf_(η∈∂g) d_Σ(ξ,η)≤2d_F(f,g)`.

Аналогічне доведення зі зміною ролей `f` та `g` дає:

`sup_(η∈∂g) inf_(ξ∈∂f) d_Σ(ξ,η)≤2d_F(f,g)`.

За означенням метрики Гаусдорфа:

`d_H,Σ(∂f,∂g)≤2d_F(f,g)`.

Доведено.

### Статус

**PROVED — за умови домену `Tω^pr,+`.**

Константа 2 є достатньою верхньою межею. Її оптимальність цим доведенням не встановлюється.

# PART VII. FOUR DIFFERENT GEOMETRIC OBJECTS

## 15. Простір адрес Σ_b

`Σ_b=B_b^ℕ`

є повним ambient-простором усіх нескінченних адрес.

Він не залежить від конкретного дерева.

Для канонічної моделі:

`b=3`.

Отже:

`Σ_3={1,2,3}^ℕ`.

Це повний трійковий простір адрес.

## 16. Межа конкретного дерева ∂t

`∂t⊆Σ_b`.

Це множина нескінченних адрес, які реально проходять через внутрішні вузли конкретного дерева.

Вона залежить від `t`.

Різні дерева можуть мати:

- однакові межі;
- різні межі;
- межі з різною потужністю;
- межі з різною хаусдорфовою розмірністю.

## 17. Простір компактних меж K(Σ_b)

`K(Σ_b)`

є простором непорожніх компактних підмножин ambient-простору.

Boundary map має вигляд:

`∂:Tω⁺→K(Σ_b)`.

Метрика між двома межами — це:

`d_H,Σ`.

Це не метрика між деревами.

## 18. Простір дерев C_Partial

`C_Partial` — простір кодів дерев.

Він має власну метрику:

`d_F(f,g)=2^(−r_F(f,g))`.

Вона вимірює глибину першої структурної відмінності.

Отже:

- `d_F` порівнює дерева;
- `d_Σ` порівнює нескінченні адреси;
- `d_H` порівнює множини нескінченних адрес;
- `∂` переводить дерево у його boundary.

Ці чотири рівні мають залишатися окремими.

# PART VIII. HAUSDORFF DIMENSION — AMBIENT SPACE VS INDIVIDUAL BOUNDARY

## 19. T-005 і повний простір Σ_b

У SUBIT-WARP задано:

`d_v(ξ,η)=exp(−α_v ℓ(ξ,η))`.

Для повного простору:

`Σ_b=B_b^ℕ`

за рівномірної міри Бернуллі:

`μ_b([u])=b^(−|u|)`.

Теорема T-005 встановлює:

`dim_H(Σ_b,d_v)=ln(b)/α_v`.

Це коректна формула для ambient Cantor space.

## 20. Чому формула не переноситься автоматично на ∂t

Для конкретного дерева:

`∂t⊆Σ_b`.

Але довільна компактна підмножина `Σ_b` не має тієї самої хаусдорфової розмірності, що й увесь простір.

### Приклад 20.1 — Одноелементна межа

Для нерухомої точки grafting-оператора:

`∂p_a={(1,1,1,…)}`.

Тому:

`dim_H(∂p_a,d_v)=0`.

### Приклад 20.2 — Повна межа

Якщо всі адреси є нескінченними шляхами внутрішніх вузлів:

`∂t=Σ_b`.

Тоді:

`dim_H(∂t,d_v)=ln(b)/α_v`.

### Приклад 20.3 — Проміжна межа

Якщо дерево допускає нескінченні шляхи лише через частину дочірніх позицій, boundary може бути власною фрактальною підмножиною `Σ_b`.

Її розмірність залежить від структури дозволених нескінченних шляхів.

Отже, загалом:

`0≤dim_H(∂t,d_v)≤ln(b)/α_v`.

Рівність із верхньою межею не є автоматичною.

### Рішення

T-005 повинна залишатися теоремою про ambient space `Σ_b`.

Для окремих дерев потрібна окрема теорія:

`T-005(t): dim_H(∂t,d_v)`.

Вона має враховувати конкретну структуру гілок.

# PART IX. SPECTRAL COMPATIBILITY

## 21. Ambient spectral operator

У SUBIT-WARP оператор визначено як:

`T_q:L²(Σ_b,μ_b)→L²(Σ_b,μ_b)`,

де:

`K_q(ξ,η)=q^(ℓ(ξ,η))`

для різних адрес, із окремою діагональною конвенцією.

Це оператор на повному просторі адрес.

Його спектральна теорія спирається на:

- ambient Cantor space;
- міру Бернуллі `μ_b`;
- ієрархічний ортогональний розклад;
- циліндричні підпростори.

## 22. Чому T_q не є автоматично оператором на ∂t

Для конкретної межі:

`∂t⊆Σ_b`

потрібно окремо визначити міру:

`μ_t`

на `∂t`.

Після цього можна розглядати:

`H_t=L²(∂t,μ_t)`.

Але:

`μ_t` не визначається лише фактом `∂t⊆Σ_b`.

Необхідно вказати:

- чи є міра обмеженням `μ_b`;
- чи є вона нормованою;
- чи має вона повний носій на `∂t`;
- чи задовольняє вона потрібні регулярнісні умови;
- чи зберігається ієрархічний ортогональний розклад.

Навіть якщо міра існує, спектр відповідного оператора не обов'язково збігається зі спектром ambient-оператора.

### Рішення

Не використовувати позначення `T_q|∂t` без визначення міри, простору функцій та оператора.

Ambient spectral system і tree-specific spectral system повинні залишатися різними модулями.

# PART X. COMPLETION SEMANTICS AND TREE BOUNDARY

## 23. Completion space

За W51:

`Comp(P,A;𝒯_allowed)`

є множиною всіх допустимих повних дерев, сумісних із позитивними та негативними обмеженнями.

Для універсального класу:

`𝒯_all`

існування completion еквівалентне:

`P*∩A*=∅`.

Однак це ще не визначає boundary конкретного дерева.

## 24. Boundary of a completion

Для кожного:

`T∈Comp(P,A;𝒯_allowed)`

визначається окрема множина:

`∂T`.

Отже, partial fingerprint породжує не одну boundary, а сімейство:

`B(P,A)={∂T:T∈Comp(P,A;𝒯_allowed)}`.

Це новий об'єкт.

Його не можна ототожнювати з:

`∂(P*)`

або з boundary одного довільно обраного completion.

### Наслідок

Якщо `Comp` містить декілька дерев із різними межами, частковий fingerprint визначає множину можливих boundary objects.

Для такого випадку потрібне окреме означення:

- можливих граничних адрес;
- необхідних граничних адрес;
- невизначених граничних адрес.

Це не тотожне трьом статусам PRESENT / ABSENT / UNKNOWN на рівні вузлів.

## 25. Рекомендоване розширення

Ввести:

`BoundaryComp(F)={∂T:T∈Comp(F)}`.

Далі розглядати:

`BoundaryPossible(F)=⋃ BoundaryComp(F)`,

`BoundaryCertain(F)=⋂ BoundaryComp(F)`.

Ці множини мають різну семантику:

- `BoundaryPossible` — адреси, що належать межі хоча б одного completion;
- `BoundaryCertain` — адреси, що належать межі кожного completion.

Якщо множина completions непорожня, то:

`BoundaryCertain(F)⊆BoundaryPossible(F)`.

Адреси в різниці:

`BoundaryPossible(F)\BoundaryCertain(F)`

є епістемічно невизначеними щодо належності до boundary.

Але ця конструкція потребує окремого аналізу компактності та замкненості.

Не можна без доведення стверджувати, що `BoundaryPossible(F)` або `BoundaryCertain(F)` завжди є непорожніми компактними множинами.

# PART XIII. ACCEPTANCE CRITERIA

## 35. Structural acceptance

1. `C_Partial` визначений як ambient coding space.
2. `Tω` визначений через `Contω` від кореня.
3. `Tω⁺` визначений через непорожність boundary.
4. Рівність `Tω=Tω⁺` обмежена скінченним branching.
5. `Tω^pr` визначений через продовження кожного внутрішнього вузла.
6. `Tω^pr,+` вимагає внутрішнього кореня.
7. Доведена замкненість `Tω^pr,+`.
8. Доведена його компактність.

## 36. Boundary acceptance

1. `∂t` визначена лише для допустимих кодів.
2. Доведено замкненість `∂t`.
3. Доведена компактність `∂t`.
4. Доведена непорожність на Tω⁺.
5. T-007 обмежена доменом Tω^pr,+.
6. Доведення використовує continuation кожного внутрішнього вузла.
7. Не заявляється оптимальність константи 2.

## 37. Geometric and spectral acceptance

1. T-005 залишається теоремою про `Σ_b`.
2. Розмірність окремих `∂t` не ототожнюється з ambient dimension.
3. `T_q` залишається оператором на `L²(Σ_b,μ_b)`.
4. Tree-specific operators вимагають окремої міри.
5. Boundary completion family не ототожнюється з однією межею.
6. Completion semantics не переноситься на boundary без окремого доведення.
