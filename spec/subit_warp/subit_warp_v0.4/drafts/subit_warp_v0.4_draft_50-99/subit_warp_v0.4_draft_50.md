# 3. Критична проблема: означення Tω та теорема T-007

Це найважливіше математичне зауваження W48.

## 3.1. Поточне означення

У WARP v0.4 визначено:

Contω(t,u) ⇔ ∀k≥0, ∃v∈B_b^k : t(u·v)=INTERNAL.

Далі:

Tω = {t∈C_Partial : Contω(t,ε)}.

За скінченного розгалуження лема Кеніга дає існування принаймні однієї нескінченної INTERNAL-гілки.

Отже:

Tω=Tω⁺.

Ця частина є коректною.

Але з неї не випливає, що кожний INTERNAL-вузол дерева має нескінченне продовження.

Поточне означення вимагає нескінченного продовження лише від кореня.

Воно дозволяє наявність інших INTERNAL-вузлів, піддерева яких є скінченними.

## 3.2. Чому це важливо для T-007

Теорема T-007 стверджує:

d_H,Σ(∂f,∂g)≤2d_F(f,g).

У доказі використовується аргумент:

- f та g збігаються до глибини m−1;
- уздовж гілки ξ∈∂f знаходиться INTERNAL-вузол у g;
- із цього вузла можна знайти нескінченне продовження в g;
- отже, існує близька адреса η∈∂g.

Проблема: третій крок не випливає з поточного означення Tω.

Воно гарантує нескінченне продовження кореня, але не довільного INTERNAL-вузла.

## 3.3. Контрприклад для поточного домену

Розглянемо двійкову модель b=2.

Побудуємо дерева f та g, які:

- мають INTERNAL у корені;
- мають однакові стани всіх вузлів глибин 0, 1 та 2;
- належать Tω;
- мають різні нескінченні гілки.

Нехай обидва дерева мають INTERNAL-вузли на рівнях 0, 1 та 2.

У f нескінченне продовження зберігається через гілку:

111111…

У g нескінченне продовження зберігається через гілку:

222222…

На глибині 3 дерева вперше відрізняються.

Тому:

r_F(f,g)=3,

d_F(f,g)=2⁻³=1/8.

Однак їхні межі мають різні перші символи.

Отже:

d_H,Σ(∂f,∂g)=1/2.

Твердження T-007 вимагало б:

1/2≤2·1/8=1/4,

що є хибним.

Таким чином, за поточного домену Tω теорема T-007 не доведена і загалом є хибною.

## 3.4. Рекомендоване виправлення

Не змінювати історичне означення Tω.

Замість цього ввести окремий сильніший клас.

Визначимо:

Tω^pr = {

t∈C_Partial :

∀u∈Pos_b,

t(u)=INTERNAL ⇒ Contω(t,u)

}.

Це клас дерев, у яких кожен INTERNAL-вузол має нескінченне INTERNAL-продовження.

Визначимо:

Tω^pr,+ = {

t∈Tω^pr :

t(ε)=INTERNAL

}.

Тоді:

Tω^pr,+ ⊆ Tω⁺.

Для цього нового домену аргумент W41 можна застосовувати.

### Нормативна заміна домену T-007

∂ : (Tω^pr,+,d_F) → (K(Σ_b),d_H,Σ).

Твердження:

d_H,Σ(∂f,∂g)≤2d_F(f,g).

Тепер у доказі дозволено використовувати нескінченне продовження довільного INTERNAL-вузла.

### Висновок A-002

**REJECT CURRENT DOMAIN FOR T-007.**

Рекомендований статус після виправлення:

- Tω — root-continuation class;
- Tω⁺ — class with nonempty boundary;
- Tω^pr — every-internal-node continuation class;
- Tω^pr,+ — canonical domain of T-007.

Це зберігає попередню історію означень та не руйнує сумісність із W23′.

# 4. T-001: компактність класу Tω

Поточне означення Tω:

Tω={t∈C_Partial : Contω(t,ε)}.

Де:

Contω(t,ε) ⇔ ∀k≥0, ∃v∈B_b^k : t(v)=INTERNAL.

Для кожного фіксованого k визначимо:

U_k={t∈C_Partial : ∃v∈B_b^k, t(v)=INTERNAL}.

Оскільки B_b^k скінченна множина, U_k є скінченним об'єднанням циліндричних множин:

U_k=⋃_{v∈B_b^k}{t:t(v)=INTERNAL}.

Кожна така множина є відкритою і замкненою.

Тому U_k є замкненою.

Отже:

Tω=⋂_{k≥0}U_k

є замкненою множиною.

Оскільки C_Partial компактний:

Tω компактний.

### Висновок A-003

**ACCEPT.**

Однак компактність Tω не означає автоматично компактність будь-якого підкласу, визначеного додатковими неформалізованими властивостями.

Для Tω^pr необхідно явно довести замкненість через відповідні умови Contω(t,u).

# 5. T-014: помилка у формулі суми рядків

У §10.2 WARP v0.4 наведено:

Σ_v (T_q^(n))_(u,v)=b⁻ⁿc_q.

Це неправильно для матриці в ортонормованому базисі:

e_u=b^(n/2)1_[u].

## 5.1. Перевірка через власний вектор

Константна функція:

1=b^(−n/2)Σ_{v∈B_b^n}e_v.

Оскільки:

T_q1=c_q1,

а P_n зберігає константи:

T_q^(n)1=c_q1.

Отже, в координатах ортонормованого базису вектор із рівними координатами є власним вектором матриці з власним значенням c_q.

Тому сума кожного рядка матриці дорівнює c_q.

Правильна формула:

**Σ_v (T_q^(n))_(u,v)=c_q.**

## 5.2. Перевірка на прикладі

Нехай:

b=2, n=1, q=1/2.

Тоді:

c_q=(2−1)/(2−1/2)=2/3.

Матричні елементи:

діагональ = 1/6;

позадіагональний елемент = 1/2.

Сума рядка:

1/6+1/2=2/3=c_q.

Натомість b⁻ⁿc_q=1/3.

Отже, поточна формула T-014 суперечить власному значенню константної функції.

### Висновок A-004

**REJECT CURRENT FORMULA.**

Виправити T-014:

Σ_v (T_q^(n))_(u,v)=c_q.

Примітку про ненормоване представлення вилучити або визначити окремо з точним описом базису.

# 6. T-018 та скінченна апроксимація

У специфікації:

‖T_q−P_nT_qP_n‖₁=(b−1)q^n/(b−q).

Це правильна формула для 0≤q<1.

Однак у різних частинах документа змішуються:

- trace-norm convergence;
- operator-norm convergence;
- finite trace;
- infinite trace.

Необхідно зберегти розрізнення:

Tr(T_q)=0,

Tr(T_q^(n))=q^nc_q.

При q<1:

Tr(T_q^(n))→0.

Але рівність слідів для кожного скінченного n не виконується.

Так само:

‖T_q−P_const‖→0

при q→1⁻, але:

‖T_q−P_const‖₁=1.

Це дві різні топології збіжності.

### Висновок A-005

**ACCEPT.**

Рекомендовано додати окремий regression test для обох норм збіжності.

# 7. T-019: параметрична Lipschitz continuity

У реєстрі теорем заявлено T-019:

Parameter Lipschitz Continuity in q.

Проте в поточному тексті відсутнє повне окреме формулювання з доказом та чітким доменом.

Наявність теореми в реєстрі не замінює її доказу.

Для операторної сім'ї:

T_q|W₀=c_qI,

T_q|W_j=λ_j(q)I

необхідно довести:

‖T_q−T_r‖≤C|q−r|

для всіх q,r у заявленому діапазоні.

Рекомендований підхід:

1. окремо оцінити |c_q−c_r|;
2. оцінити супремум |λ_j(q)−λ_j(r)|;
3. отримати найкращу допустиму глобальну константу;
4. перевірити крайові випадки q=0 та q=1;
5. не поширювати результат на зростаюче ядро без окремого доказу.

# 9. T-020′: неупорядкована реконструкція

У поточній редакції fingerprint:

F(T)=(L,h,a).

Використовуються:

x~_k y ⇔ a(x,y)≥k.

Умови FP-01–FP-07 потребують додаткової перевірки на:

1. існування кореня;
2. єдиність батьківської вершини;
3. зв'язність реконструйованого графа;
4. відсутність циклів;
5. коректність unary vertices;
6. узгодженість класів на суміжних рівнях.

Особливо важливо узгодити:

- T-020′ заявляє реконструкцію без unary contractions;
- FP-07 вимагає, щоб внутрішні вершини лежали на шляхах від кореня до листків;
- але FP-01–FP-07 не містять явної умови, яка гарантує потрібну структуру всіх проміжних рівнів.

Рекомендовано додати умови:

**FP-08 — Parent uniqueness.**

Кожна вершина ненульової глибини має рівно одного батька.

**FP-09 — Level coverage.**

Кожний клас на рівні k+1 має рівно один відповідний клас на рівні k.

**FP-10 — No unsupported vertices.**

Кожна реконструйована вершина лежить на шляху від кореня до принаймні одного листка.

**FP-11 — Unary convention.**

Явно встановити, чи unary vertices зберігаються як окремі вершини або факторизуються.

# 10. T-021′: упорядкована реконструкція

Упорядкований fingerprint:

F_ord(T)=(L,h,a,p).

Де p є prefix-free адресним відображенням.

Основна ідея коректна: prefix closure множини адрес листків відновлює occupied ordered trie.

Однак occupied trie не є автоматично повною структурою дочірніх позицій.

Потрібно розрізняти:

- відсутню дочірню позицію;
- наявну позицію;
- листок;
- внутрішній вузол;
- невідомий стан.

Також необхідно визначити, чи зберігаються unary vertices.

**CONDITIONAL ACCEPTANCE.**

T-021′ потребує окремої теореми про унікальність реконструкції та явної семантики ABSENT.

# 11. Спектральна система

Спектральні формули T_q та T_+ у C2 структурно узгоджені з ієрархічним розкладом:

H=W₀⊕⨁W_j.

Спадне ядро:

c_q=(b−1)/(b−q),

λ_j(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)].

Зростаюче ядро:

λ₀(t)=(b−1)/(b−t),

λ_j(t)=(t−1)t^(j−1)/[b^(j−1)(b−t)].

Критерії:

- boundedness: t<b;
- compactness: t<b;
- Hilbert–Schmidt: t²<b;
- trace-class: ні для якого t>1.

Ці формули узгоджені з ієрархічною структурою.

Однак необхідно зберегти обмеження:

1. міра — рівномірна Bernoulli;
2. простір — повний Σ_b;
3. оператор — інтегральний оператор саме з указаним ядром;
4. діагональна конвенція — K(ξ,ξ)=0;
5. для t≥b не можна трактувати формальний інтеграл як обмежений оператор на всьому L².
