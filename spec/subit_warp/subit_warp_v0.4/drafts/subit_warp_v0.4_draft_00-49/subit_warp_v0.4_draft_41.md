## 0. Резюме

W39 запропонував узгоджену архітектуру для кодування скінченних і нескінченних дерев, їхніх меж та спектральних операторів. Проте в документі залишилася одна суттєва метрична неоднозначність: використано позначення `d_P`, для якого не було надано незалежного формального означення.

Це створює проблему не лише нотації. Теорема про неперервність граничного відображення залежить від конкретної метрики на просторі дерев. Тому не можна вважати доведення завершеним, доки не встановлено, яка саме метрика стоїть у її передумові.

W39.1 запроваджує такі корекції:

1. Єдина базова метрика простору кодів — `d_code`.
2. На підпросторах використовується її обмеження, а не нова незалежна метрика.
3. Історичну метрику `d_F` не ототожнюємо з `d_code` без перевірки первинного означення.
4. Домен граничного відображення фіксується як `Tω_P⁺`.
5. Випадок першої відмінності на глибині 0 виключається для цього домену.
6. Оцінка для граничних множин формулюється без невизначеного `d_P`.
7. Компактність `Tω_P` отримує окремий доказовий каркас.
8. Реконструкція дерева та структурне кодування відокремлюються від тверджень про епістемічну невизначеність.

Цей документ виправляє архітектуру W39, але сам по собі не закриває всі завдання W34.

# 1. Базові множини та типи

Нехай:

- `b ≥ 2` — скінченний коефіцієнт розгалуження;
- `B_b = {1,…,b}`;
- `A` — скінченний алфавіт;
- `Pos_b = B_b^{<ω}` — множина скінченних адрес;
- `Σ_b = B_b^ℕ` — простір нескінченних адрес.

Порожня адреса позначається `ε`.

Множина станів вузла:

`S_A = {ABSENT, INTERNAL} ∪ {LEAF(a) : a ∈ A}`.

Повний простір кодів:

`Code_b(A) = S_A^{Pos_b}`.

Код дерева — функція:

`t : Pos_b → S_A`.

Кожна адреса отримує рівно один стан. Це тотальне кодування, а не часткова функція.

## 1.1. Локальні умови допустимості

Для адреси `u` та її дитини `ui` вводимо такі умови.

**C1 — ABSENT closure**

Якщо `t(u)=ABSENT`, то для кожного `i∈B_b`:

`t(ui)=ABSENT`.

**C2 — LEAF closure**

Якщо `t(u)=LEAF(a)`, то для кожного `i∈B_b`:

`t(ui)=ABSENT`.

**C3 — INTERNAL expansion**

Якщо `t(u)=INTERNAL`, кожна дитина має один зі станів:

`ABSENT`, `INTERNAL`, `LEAF(a)`.

Ця умова вже випливає з тотальності кодування, але її варто залишити в переліку локальних інваріантів як явну перевірку.

# 2. Розділення просторів дерев

## 2.1. Усі локально допустимі коди

`C_Partial^all ⊆ Code_b(A)`

— множина кодів, що задовольняють C1–C3.

У цьому просторі корінь може бути `ABSENT`.

## 2.2. Коренево-часткові дерева

`C_Partial = {t ∈ C_Partial^all : t(ε) ≠ ABSENT}`.

Корінь тут або `INTERNAL`, або `LEAF(a)`.

## 2.3. Повні дерева

`C_Full ⊆ C_Partial`

визначається додатковою умовою:

`∀u, t(u)=INTERNAL ⇒ ∀i∈B_b, t(ui)≠ABSENT`.

Отже, кожен внутрішній вузол має рівно `b` зайнятих дочірніх позицій.

Це означення не слід змішувати з умовою нескінченного продовження: повне дерево може мати скінченну глибину.

## 2.4. Нескінченне продовження

Позначимо:

`IB(u,t)`

твердження, що:

1. `t(u)=INTERNAL`;
2. існує нескінченна адреса `ξ∈Σ_b`, яка продовжує `u`;
3. кожен вузол уздовж цього продовження має стан `INTERNAL`.

Формально:

`IB(u,t) ⇔ t(u)=INTERNAL ∧ ∃ξ∈Σ_b, (u ⊑ ξ ∧ ∀k≥|u|, t(ξ|k)=INTERNAL)`.

Тут `u ⊑ ξ` означає, що `u` є префіксом `ξ`.

Важливо: `IB(u,t)` не означає, що всі діти `u` мають нескінченне продовження. Достатньо існування хоча б однієї нескінченної гілки.

## 2.5. Простір нескінченно продовжуваних дерев

`Tω_P = {t ∈ C_Partial : ∀u, t(u)=INTERNAL ⇒ IB(u,t)}`.

Ця умова виключає внутрішні вузли, які не мають жодної нескінченної гілки.

Визначимо:

`Tω_P⁺ = {t ∈ Tω_P : ∂t ≠ ∅}`.

За наведеними означеннями:

`Tω_P⁺ = {t ∈ Tω_P : t(ε)=INTERNAL}`.

Причина: якщо корінь є `LEAF(a)`, нескінченної гілки від кореня немає. Якщо корінь є `INTERNAL`, умова `IB(ε,t)` гарантує принаймні одну нескінченну гілку.

# 3. Канонічна метрика кодування

## 3.1. Відстань між кодами

Для `t,s ∈ Code_b(A)` визначимо:

`r_code(t,s) = min{|u| : t(u) ≠ s(u)}`.

Якщо `t=s`, покладаємо:

`r_code(t,s)=∞`.

Тоді:

`d_code(t,s) = 2^(−r_code(t,s))`,

де `2^(−∞)=0`.

Це ультраметрика на `Code_b(A)`.

Вона вимірює глибину першої координатної відмінності двох кодів.

## 3.2. Властивості

Для всіх `t,s,q ∈ Code_b(A)`:

1. `d_code(t,s) ≥ 0`;
2. `d_code(t,s)=0 ⇔ t=s`;
3. `d_code(t,s)=d_code(s,t)`;
4. `d_code(t,q) ≤ max(d_code(t,s),d_code(s,q))`.

Отже, `d_code` є ультраметрикою.

## 3.3. Метрики на підпросторах

На кожному підпросторі використовуємо обмеження цієї самої метрики:

`d_code|_C_Partial`

`d_code|_C_Full`

`d_code|_Tω_P`

`d_code|_Tω_P⁺`.

Ці позначення означають restriction метрики, а не введення нових незалежних метрик.

**Корекція W39:** позначення `d_P` вилучається з архітектури, якщо для нього не буде окремо доведено конкретне означення та його зв'язок із `d_code`.

# 4. Компактність простору кодів

Оскільки `S_A` скінченна, а `Pos_b` зліченна, простір:

`Code_b(A)=S_A^{Pos_b}`

компактний у топології добутку.

Метрика `d_code` породжує саме цю топологію.

Локальні умови C1 і C2 є замкненими: їх порушення можна виявити на скінченній кількості координат.

Отже:

`C_Partial^all`

є замкненою підмножиною компактного простору `Code_b(A)` і тому компактним.

Умова `t(ε)≠ABSENT` також є замкненою, оскільки координата кореня належить скінченній дискретній множині.

Тому:

`C_Partial`

компактний.

Аналогічно, умова повноти `C_Full` є перетином замкнених локальних умов. Отже, `C_Full` також компактний.

---

# 5. Замкненість умови нескінченного продовження

Цей пункт є важливим для компактності `Tω_P`.

Для фіксованого вузла `u` визначимо:

`B_u = {t ∈ C_Partial : IB(u,t)}`.

Розглянемо відношення:

`R_u = {(t,ξ) ∈ C_Partial × [u] : ∀k≥|u|, t(ξ|k)=INTERNAL}`,

де `[u]` — циліндр адрес, що продовжують `u`.

Простір `C_Partial × [u]` компактний.

Умова

`∀k≥|u|, t(ξ|k)=INTERNAL`

є перетином замкнених координатних умов. Отже, `R_u` замкнене і компактне.

Проєкція компактної множини на перший множник компактна:

`π₁(R_u)=B_u`.

Оскільки `C_Partial` є метричним простором, компактна підмножина в ньому замкнена.

Тому `B_u` замкнена.

Тепер позначимо:

`N_u = {t ∈ C_Partial : t(u) ≠ INTERNAL}`.

Це також замкнена множина.

Умова для вузла `u`:

`t(u) ≠ INTERNAL ∨ IB(u,t)`

еквівалентна належності:

`t ∈ N_u ∪ B_u`.

Отже:

`Tω_P = ⋂_{u∈Pos_b}(N_u ∪ B_u)`.

Це перетин замкнених множин, тому `Tω_P` замкнений у `C_Partial`.

Оскільки `C_Partial` компактний:

**Твердження:** `Tω_P` компактний.

Додатково:

`Tω_P⁺ = {t∈Tω_P : t(ε)=INTERNAL}`.

Це замкнений підпростір `Tω_P`, тому:

**Твердження:** `Tω_P⁺` компактний.

Цей доказовий каркас має бути перенесений до формального математичного шару та перевірений у Lean окремо. Тут наведено математичну аргументацію, а не результат kernel verification.

# 6. Граничне відображення

## 6.1. Означення межі

Для `t∈Tω_P⁺` визначимо:

`∂t = {ξ∈Σ_b : ∀k≥0, t(ξ|k)=INTERNAL}`.

Тобто межа складається з нескінченних адрес, уздовж яких усі вузли залишаються внутрішніми.

## 6.2. Замкненість межі

Для кожного `k≥0` умова:

`t(ξ|k)=INTERNAL`

визначає замкнену і відкриту підмножину `Σ_b`, оскільки вона залежить від скінченного префікса.

Тому:

`∂t = ⋂_{k≥0}{ξ∈Σ_b : t(ξ|k)=INTERNAL}`

є замкненою підмножиною `Σ_b`.

Оскільки `Σ_b` компактний, `∂t` компактний.

Оскільки `t∈Tω_P⁺`, маємо `IB(ε,t)`, а отже `∂t≠∅`.

Таким чином:

`∂ : Tω_P⁺ → K(Σ_b)`,

де `K(Σ_b)` — простір непорожніх компактних підмножин `Σ_b`.

# 7. Корекція оцінки граничного відображення

## 7.1. Метрика на просторі адрес

Для `ξ,η∈Σ_b` нехай:

`ℓ(ξ,η)=max{n : ξ|n=η|n}`.

Якщо `ξ=η`, то `ℓ(ξ,η)=∞`.

Визначимо:

`d_Σ(ξ,η)=2^(−ℓ(ξ,η))`.

Це стандартна ультраметрика на просторі нескінченних адрес.

На `K(Σ_b)` використовуємо відповідну метрику Гаусдорфа:

`d_H,Σ`.

## 7.2. Основна оцінка

**Теорема W39.1-B1.**

Для всіх `f,g∈Tω_P⁺`:

`d_H,Σ(∂f,∂g) ≤ 2 d_code(f,g)`.

### Доведення

Якщо `f=g`, твердження очевидне.

Нехай `f≠g`, а перша координатна відмінність виникає на глибині:

`m = r_code(f,g)`.

Оскільки обидва дерева належать `Tω_P⁺`, маємо:

`f(ε)=g(ε)=INTERNAL`.

Тому:

`m≥1`.

Візьмемо довільний елемент:

`ξ∈∂f`.

Позначимо:

`u=ξ|m−1`.

За означенням межі:

`f(u)=INTERNAL`.

Оскільки `f` і `g` збігаються на всіх координатах глибини меншої за `m`, маємо:

`g(u)=INTERNAL`.

З умови `g∈Tω_P` випливає:

`IB(u,g)`.

Отже, існує нескінченне продовження `η∈∂g`, яке починається з `u`.

Таким чином:

`ξ|m−1 = η|m−1`.

Звідси:

`d_Σ(ξ,η) ≤ 2^(−(m−1))`.

Але:

`d_code(f,g)=2^(−m)`.

Отже:

`d_Σ(ξ,η) ≤ 2 d_code(f,g)`.

Оскільки `ξ` було довільним елементом `∂f`, маємо:

`sup_{ξ∈∂f} inf_{η∈∂g} d_Σ(ξ,η) ≤ 2d_code(f,g)`.

Симетричний аргумент дає:

`sup_{η∈∂g} inf_{ξ∈∂f} d_Σ(ξ,η) ≤ 2d_code(f,g)`.

За означенням метрики Гаусдорфа:

`d_H,Σ(∂f,∂g) ≤ 2d_code(f,g)`.

Теорему доведено.

### Важливе уточнення

Випадок `m=0` тут неможливий, бо корені обох дерев мають стан `INTERNAL`.

Цей випадок можливий у загальному просторі кодів, але не належить до домену `Tω_P⁺`.

# 8. Візуальна метрика

Нехай:

`d_v(ξ,η)=d_Σ(ξ,η)^γ`, де `γ>0`.

Оскільки функція `x↦x^γ` монотонна та неперервна на невід'ємній півосі, відповідна метрика Гаусдорфа задовольняє:

`d_H,v(K,L)=d_H,Σ(K,L)^γ`.

Тому з W39.1-B1 отримуємо:

`d_H,v(∂f,∂g) ≤ 2^γ d_code(f,g)^γ`.

Це є наслідком основної оцінки, а не незалежною теоремою.

Для `0<γ≤1` функція `d_Σ^γ` також є метрикою. Для `γ>1` її метричність загалом не гарантується; у такому випадку її слід трактувати як перетворену функцію відстані, а не автоматично як метрику.

# 9. Історична метрика d_F

W39.1 не ототожнює:

`d_F`

та

`d_code`.

Позначення `d_F` зберігається для історичної метрики, означення якої має бути звірене з первинними документами W23′, W30 та W34.

До завершення цього аудиту не можна стверджувати:

`d_F = d_code`.

## 9.1. Умовний міст між метриками

Нехай `D` — історичний простір дерев, а:

`ι : D → Tω_P⁺`

— структурне вкладення.

Якщо буде доведено, що:

`d_F(x,y)=d_code(ι(x),ι(y))`,

то з W39.1-B1 випливатиме:

`d_H,Σ(∂ι(x),∂ι(y)) ≤ 2d_F(x,y)`.

Якщо замість рівності буде доведена лише оцінка:

`d_code(ι(x),ι(y)) ≤ C d_F(x,y)`,

то:

`d_H,Σ(∂ι(x),∂ι(y)) ≤ 2C d_F(x,y)`.

Для візуальної метрики відповідно:

`d_H,v(∂ι(x),∂ι(y)) ≤ (2C)^γ d_F(x,y)^γ`.

Ці висновки є умовними до встановлення конкретного вкладення та метричного співвідношення.

# 10. Структурне кодування та декодування

Визначимо структурні операції:

`Enc_sub : PartialTree∞_A^(b) → C_Partial`

`Dec_sub : C_Partial → PartialTree∞_A^(b)`.

Їх не слід оголошувати взаємно оберненими лише на підставі інтуїтивної відповідності між деревом і його координатним кодом.

Необхідно довести:

**ENC-01 — Reconstruction**

`Dec_sub(Enc_sub(T)) ≅ T`.

**ENC-02 — Code identity**

`Enc_sub(Dec_sub(t)) = t`.

**ENC-03 — Constructor preservation**

- `None` відповідає `ABSENT`;
- `Leaf(a)` відповідає `LEAF(a)`;
- `Node(T₁,…,T_b)` відповідає `INTERNAL` із відповідними дочірніми кодами.

**ENC-04 — Infinite-depth preservation**

Нескінченні гілки в коіндуктивному дереві мають відповідати нескінченним INTERNAL-шляхам у коді.

**ENC-05 — Bisimulation**

Якщо тип `PartialTree∞` визначений коіндуктивно, доведення структурної еквівалентності має спиратися на коіндукцію або бісимуляцію, а не на скінченну індукцію, яка не охоплює нескінченні структури.

До виконання цих зобов'язань `Enc_sub` і `Dec_sub` залишаються запропонованими структурними відображеннями.

# 11. Реконструкція дерева: T-020′

Для unordered reconstruction розглядається fingerprint:

`F=(L,h,a)`,

де:

- `L` — множина листків;
- `h` — функція висот або рівнів;
- `a` — функція спільного предка або глибини спільного префікса.

Пропонована еквівалентність:

`x ~_k y ⇔ a(x,y)≥k`.

Однак цього запису недостатньо для завершення реконструкції.

Потрібно довести:

1. Рефлексивність, симетричність і транзитивність `~_k`.
2. Вкладеність класів еквівалентності між рівнями.
3. Існування єдиного батьківського класу для кожного некореневого класу.
4. Зв'язність реконструйованої структури.
5. Відсутність циклів.
6. Збереження unary chains.
7. Узгодженість реконструкції з вихідним fingerprint.

Особливу увагу слід приділити випадкам, коли різні вузли мають однакові висоти або коли відомості про спільного предка неповні.

**Статус:** CONDITIONALLY ACCEPTED; proof obligations remain open.

# 12. Реконструкція дерева: T-021′

Для ordered reconstruction пропонується відображення адрес:

`p : L → B_b^{<ω}`.

Якщо множина адрес листків є prefix-free, вона визначає зайнятий ordered trie.

Однак необхідно розрізняти три поняття:

1. **Occupied position** — позиція, що належить структурі дерева.
2. **Absent position** — позиція, явно позначена як відсутня.
3. **Unknown position** — позиція, щодо якої інформація відсутня або не визначена.

`ABSENT` не можна автоматично ототожнювати з `UNKNOWN`.

Перший стан є структурним значенням коду. Другий — епістемічним статусом інформації.

Якщо SUBIT-WARP має підтримувати обидва рівні, це повинно бути реалізовано окремим шаром метаданих або окремим розширеним алфавітом станів.

**Статус:** ACCEPTED FOR OCCUPIED ORDERED TRIES; epistemic extension remains separate.

# 13. Виправлена метрична архітектура W39

Після W39.1 метричний шар має виглядати так:

**Кодовий простір**

`Code_b(A), d_code`

**Часткові дерева**

`C_Partial ⊆ Code_b(A)`

з метрикою `d_code|_C_Partial`.

**Повні дерева**

`C_Full ⊆ C_Partial`

з метрикою `d_code|_C_Full`.

**Нескінченно продовжувані дерева**

`Tω_P ⊆ C_Partial`

з метрикою `d_code|_Tω_P`.

**Дерева з непорожньою межею**

`Tω_P⁺ ⊆ Tω_P`

з метрикою `d_code|_Tω_P⁺`.

**Простір меж**

`K(Σ_b), d_H,Σ`.

**Візуальна функція відстані**

`d_v=d_Σ^γ`, з окремою перевіркою метричних властивостей для обраного γ.

**Історична метрика**

`d_F` залишається незалежним об'єктом до завершення звірення W23′/W30.

# 16. Висновок

W39.1 усуває головну типову неоднозначність W39: граничне відображення тепер пов'язане з конкретною, явно означеною метрикою на просторі кодів.

Отримано чітке твердження:

`d_H,Σ(∂f,∂g) ≤ 2d_code(f,g)`

для `f,g∈Tω_P⁺`.

Ця оцінка спирається на дві принципові властивості:

1. дерева збігаються на всіх координатах до глибини першої відмінності;
2. кожен INTERNAL-вузол має хоча б одну нескінченну INTERNAL-гілку.

Водночас W39.1 не розв'язує автоматично питання історичної метрики `d_F`, реконструкції дерева та спектральної теорії. Ці питання залишаються окремими завданнями.
