# 3. Головні результати інтеграції

## 3.1. Метрика дерев d_F

### Поточний стан

W23′.3.2 визначає:

`d_F(f,g)=2^(−r_addr(f,g))`

де:

`r_addr(f,g)=min{|u|:f(u)≠g(u)}`.

Водночас у визначенні не повністю формалізовано, що саме означає `f(u)` для адрес, які лежать нижче листка або поза наявною частиною дерева.

Це не просто редакційна проблема. Від області визначення функції залежить коректність порівняння дерев на всьому `Pos_b`.

### Канонічна корекція

Ввести тотальне кодування дерева:

`S_A={ABSENT, INTERNAL}∪{LEAF(a):a∈A}`.

Для кожного дерева:

`t_f:Pos_b→S_A`.

Локальні умови допустимості:

**F-01. Root**

Корінь не може мати стан ABSENT.

**F-02. Absent closure**

Якщо `t_f(u)=ABSENT`, то для кожного i:

`t_f(ui)=ABSENT`.

**F-03. Leaf closure**

Якщо `t_f(u)=LEAF(a)`, то для кожного i:

`t_f(ui)=ABSENT`.

**F-04. Full branching**

Якщо `t_f(u)=INTERNAL`, то в FullTree усі b дочірніх позицій є наявними.

**F-05. Partial branching**

У PartialTree дочірні позиції INTERNAL можуть бути як наявними, так і ABSENT.

Після цього:

`r_F(f,g)=min{|u|:t_f(u)≠t_g(u)}`.

`d_F(f,g)=2^(−r_F(f,g))`.

Для однакових дерев:

`r_F(f,f)=∞`, `d_F(f,f)=0`.

### Висновок

Це уточнення має бути інтегроване в W23′.3.2 та W30.2. Воно не змінює принцип першої відмінності, але робить область визначення метрики однозначною.

Статус: **CANONICAL DEFINITION FIX REQUIRED**.

## 3.2. Компактність простору дерев

За скінченного алфавіту станів `S_A` простір усіх тотальних кодувань:

`S_A^{Pos_b}`

є компактним у топології добутку.

Множина допустимих дерев визначається локальними умовами F-01–F-05.

Оскільки порушення кожної такої умови виявляється на скінченній кількості координат, множина допустимих кодувань є замкненою.

Отже:

`Tree_A^(b) ⊆ S_A^{Pos_b}`

є компактною.

Метрика `d_F` породжує відповідну топологію першої відмінності.

Таким чином, компактність простору дерев може бути обґрунтована через компактність добутку та замкненість множини допустимих кодувань.

**Уточнення:** цей аргумент потрібно застосовувати до конкретно визначеного типу дерев. Не можна без окремої перевірки ототожнювати компактність FullTree, PartialTree і класу Tω⁺.

## 3.3. Адресна геометрія та Hausdorff dimension

W23′.5 визначає:

`d_v(ξ,η)=exp(−α_vℓ(ξ,η))`.

Для повного однорідного b-арного простору:

`Σ_b=B_b^N`.

Рівномірна міра:

`μ_b([σ])=b^(−n)`

для циліндра довжини n.

Параметр розмірності:

`s=ln(b)/α_v`.

### Точна оцінка куль

Якщо:

`exp(−α_v(n+1)) < r ≤ exp(−α_v n)`,

то замкнена куля радіуса r збігається з циліндром довжини n:

`B̄_v(ξ,r)=[ξ|n]`.

Тому:

`μ_b(B̄_v(ξ,r))=b^(−n)`.

Оскільки:

`r^s≤b^(−n)<b·r^s`,

отримуємо:

`r^s≤μ_b(B̄_v(ξ,r))<b·r^s`.

Отже, простір є Ahlfors s-регулярним із константами 1 та b.

Звідси:

`dim_H(Σ_b,d_v)=ln(b)/α_v`.

### Канонічна редакційна дія

W23′.5.1 необхідно доповнити наведеною оцінкою куль. Це закриває прогалину між оцінкою на циліндрах і оцінкою Hausdorff dimension.

**Статус:** ANALYTICAL PROOF CLOSED UNDER UNIFORM BERNOULLI MEASURE.

Цей результат не переноситься автоматично на неоднорідні дерева чи нерівномірні міри.

## 3.4. Boundary map

W23′.5.2 визначає:

`∂:Tω⁺→K(Σ_b)`.

Для:

`Tω⁺={f∈Tω:∂f≠∅}`

маємо:

`d_H,Σ(∂f,∂g)≤2d_F(f,g)`.

Для параметричної метрики:

`d_v=d_Σ^γ`,

де:

`γ=α_v/ln2`,

отримуємо:

`d_H,v(∂f,∂g)≤2^γ d_F(f,g)^γ`.

Відповідно:

- `0<γ<1` — гарантована оцінка Гельдера;
- `γ=1` — оцінка Ліпшиця з константою 2;
- `γ>1` — також оцінка Ліпшиця з константою не більшою за `2^γ`, оскільки `d_F≤1`.

### Канонічне уточнення

У W23′ потрібно явно вказати, що оцінка застосовується до дерев, для яких:

1. межа є непорожньою;
2. межа є компактною;
3. метрика дерев використовує ту саму домовленість щодо глибини, що й доказ.

Не слід розширювати теорему на порожні межі без окремого доведення в `K₀(Σ_b)`.

**Статус:** ANALYTICAL PROOF CLOSED UNDER Tω⁺.

# 4. Інтеграція спектрального блоку

## 4.1. T-009 — спадне ядро

W30.3 та W23.11 мають містити узгоджену канонічну версію спектрального результату.

Для:

`K_q(ξ,η)=q^ℓ(ξ,η)`, ξ≠η,

із діагоналлю:

`K_q(ξ,ξ)=0`

та рівномірною мірою μ_b:

`c_q=(b−1)/(b−q)`.

Для j≥1:

`λ_j(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)]`.

Кратність:

`m_j=(b−1)b^(j−1)`.

Спектральна декомпозиція:

`L²(Σ_b,μ_b)=W₀⊕W₁⊕W₂⊕…`.

Де:

`dim(W₀)=1`

та:

`dim(W_j)=(b−1)b^(j−1)`.

Для `0≤q<1`:

`||T_q||=c_q`.

`||T_q||²_HS=(b−1)/(b−q²)`.

`||T_q||₁=2c_q`.

`Tr(T_q)=0`.

### Endpoint q=0

`c₀=(b−1)/b`.

`λ₁(0)=−1/b`.

`λ_j(0)=0`, j≥2.

### Endpoint q=1

За визначеною конвенцією:

`T₁=P_const`.

`Spec(T₁)={0,1}`.

`Tr(T₁)=1`.

`||T₁||₁=1`.

### Важливе розрізнення

Для q→1−:

`T_q→P_const`

в операторній нормі.

Однак:

`lim(q→1−)||T_q||₁=2`,

тоді як:

`||P_const||₁=1`.

Більше того:

`||T_q−P_const||₁=1`

для q<1.

Отже, збіжність у слідовій нормі до P_const відсутня.

Це потрібно зберегти як окрему властивість, а не трактувати як суперечність операторній збіжності.

**Статус:** ANALYTICAL PROOF CLOSED; ENDPOINTS EXPLICIT.

`K_+(ξ,η)=exp(α_wℓ(ξ,η))`

покладемо:

`t=exp(α_w)`.

`t<b`.

# 5. Скінченні апроксимації

Нехай:

`H_n` — простір функцій, сталих на циліндрах довжини n.

`P_n` — ортогональна проєкція на H_n.

`T_q^(n)=P_nT_qP_n|H_n`.

Для ортонормованого базису:

`e_σ=b^(n/2)1_[σ]`.

Матриця:

Для σ≠τ:

`(T_q^(n))_(σ,τ)=b^(−n)q^ℓ(σ,τ)`.

Для σ=τ:

`(T_q^(n))_(σ,σ)=b^(−n)q^n c_q`.

Спектр:

- c_q на W₀;
- λ_j(q) на W_j, j=1,…,n;
- відповідні кратності `(b−1)b^(j−1)`.

Слід:

`Tr(T_q^(n))=q^n c_q`.

Для фіксованого q<1:

`P_nT_qP_n→T_q`

в операторній нормі.

Оскільки T_q є trace-class:

`||P_nT_qP_n−T_q||₁→0`.

Однак це твердження стосується збіжності за n для фіксованого q<1.

Його не можна плутати з відсутністю trace-norm збіжності при q→1−.

**Статус:** ANALYTICAL PROOF CLOSED.

# 6. Structural Fingerprint: уточнення T-020 і T-021

## 6.1. T-020 — неупорядкована реконструкція

W30 визначає:

`F(T)=(L,h,a)`.

Ці дані визначають скінченне кореневе дерево з точністю до кореневого ізоморфізму, який не зберігає порядок дітей.

Для однозначної реконструкції необхідні умови допустимості.

**F-01.** `h(x)∈N₀`.

**F-02.** `a(x,y)=a(y,x)`.

**F-03.** Для x≠y:

`0≤a(x,y)<min(h(x),h(y))`.

**F-04.** Для x=y:

`a(x,x)=h(x)`.

**F-05.** Ієрархічна умова:

`a(x,z)≥min(a(x,y),a(y,z))`.

**F-06.** Множина L скінченна та непорожня.

**F-07.** Кожен внутрішній вузол належить шляху до листка.

На кожному рівні k визначимо:

`L_k={x∈L:h(x)≥k}`.

`x~_k y ⇔ a(x,y)≥k`.

Класи еквівалентності задають вузли рівня k.

Включення класів на сусідніх рівнях задає батьківські відношення.

Повторення класу на послідовних рівнях зберігає unary-вузли.

**T-020′.** За умов F-01–F-07 fingerprint `(L,h,a)` визначає скінченне кореневе дерево з точністю до неупорядкованого кореневого ізоморфізму.

Статус: ANALYTICAL RESULT; ADMISSIBILITY CONDITIONS REQUIRED.

## 6.2. T-021 — упорядкована реконструкція

Для впорядкованої SUBIT-структури необхідно додати:

`p:L→B_b^{<ω}`.

Fingerprint:

`F_ordered(T)=(L,h,a,p)`.

Умови:

1. p є ін'єктивним;
2. адреси листків є префіксно вільними;
3. `|p(x)|=h(x)`;

# 10. Розмежування математичної та програмної стабільності

Необхідно ввести два незалежні поняття.

## 10.1. Mathematical Core Stable

Може бути присвоєно, коли:

1. усі математичні визначення канонічно інтегровані;
2. теореми мають точні області застосування;
3. граничні випадки перевірені;
4. залежності теорем узгоджені;
5. відкриті математичні твердження або доведені, або явно винесені за межі ядра;
6. W20 математичні regression cases виконані в частині, що стосується аналітичного ядра.

Lean не є обов'язковим для цього статусу, якщо межа формалізації чітко задекларована.

## 10.2. Software Release Stable

Додатково вимагає:

1. реалізацію відповідно до канонічних типів;
2. проходження W20 у повному обсязі;
3. відтворювані чисельні результати;
4. аудит Rust або іншого обчислювального шару;
5. документовані версії залежностей та середовища;
6. перевірку граничних випадків;
7. відсутність невирішених критичних дефектів.

Отже:

`MATHEMATICAL CORE STABLE ≠ SOFTWARE RELEASE STABLE`.

І навпаки, працездатність програмного коду не доводить математичної коректності моделі.
