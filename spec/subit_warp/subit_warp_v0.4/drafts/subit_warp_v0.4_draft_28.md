# 2. Метрична структура простору дерев

## 2.1. Поточне визначення

У W23′ задано:

Pos_b = B_b^{<ω},

де B_b = {1,2,…,b}.

Для двох дерев f,g:

r_addr(f,g) = min{|u| : f(u) ≠ g(u)}.

Тоді:

d_F(f,g) = 2^(−r_addr(f,g)),

а для f=g:

d_F(f,f)=0.

Це визначення задумане як метрика першої структурної відмінності.

## 2.2. Виявлена проблема типізації

У W23′ дерева задаються рекурсивними типами:

FullTree_A^(b) ≅ Leaf(A) ⊔ Node(FullTree_A^(b))^b,

PartialTree_A^(b) ≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A^(b))^b.

Водночас d_F визначається через порівняння f(u) та g(u) на Pos_b.

Однак у рекурсивному визначенні не встановлено повністю, яке значення має f(u), якщо адреса u лежить нижче листка або відсутньої позиції.

Це не обов'язково робить метрику неправильною, але залишає неформалізованим її домен.

**Корекція W33.4-01: ввести канонічне тотальне кодування дерева.**

## 2.3. Тотальне кодування

Визначимо скінченний алфавіт станів:

S_A = {ABSENT, INTERNAL} ∪ {LEAF(a) : a ∈ A}.

Кожне дерево f представляється функцією:

t_f : Pos_b → S_A.

Інтерпретація:

- ABSENT — позиція відсутня;
- INTERNAL — позиція є внутрішнім вузлом;
- LEAF(a) — позиція є листком із міткою a.

Встановлюються локальні умови узгодженості.

### C-01. Корінь

t_f(ε) ≠ ABSENT.

### C-02. Відсутність

Якщо:

t_f(u) = ABSENT,

то:

t_f(ui) = ABSENT

для кожного i ∈ B_b.

### C-03. Листок

Якщо:

t_f(u) = LEAF(a),

то:

t_f(ui) = ABSENT

для кожного i ∈ B_b.

### C-04. Внутрішній вузол

Якщо:

t_f(u) = INTERNAL,

то:

- у FullTree всі b дочірніх позицій присутні;
- у PartialTree кожна дочірня позиція може бути присутньою або ABSENT.

Це розрізнення зберігає різницю між FullTree та PartialTree.

## 2.4. Канонічна метрика

Для різних дерев:

r_F(f,g) = min{|u| : t_f(u) ≠ t_g(u)}.

Тоді:

d_F(f,g) = 2^(−r_F(f,g)).

Для однакових дерев:

d_F(f,f)=0.

Тепер визначення є однозначним для всіх адрес, включно з позиціями нижче листків і відсутніх вузлів.

## 2.5. Доведення метричних властивостей

### Невід'ємність

Безпосередньо:

d_F(f,g) ≥ 0.

### Симетричність

Оскільки:

t_f(u) ≠ t_g(u)

еквівалентно:

t_g(u) ≠ t_f(u),

то:

d_F(f,g)=d_F(g,f).

### Тотожність нерозрізнених

Якщо:

d_F(f,g)=0,

то дерева не мають першої відмінності.

Отже:

t_f(u)=t_g(u)

для всіх u.

Тому:

f=g.

Обернене твердження очевидне.

### Ультраметрична нерівність

Нехай:

r_F(f,g)=m,

r_F(g,h)=n.

Тоді f і h збігаються на всіх адресах глибини меншої за min(m,n).

Отже:

r_F(f,h) ≥ min(m,n).

Тому:

d_F(f,h)
≤ 2^(−min(m,n))
= max(2^(−m),2^(−n)).

Отримуємо:

**d_F(f,h) ≤ max(d_F(f,g),d_F(g,h)).**

Отже, d_F є ультраметрикою.

**Вердикт:** метрична конструкція коректна після явного тотального кодування.

# 4. Простір нескінченних адрес

Нехай:

Σ_b = B_b^ℕ.

Для ξ,η ∈ Σ_b визначимо:

ℓ(ξ,η) = довжина найбільшого спільного префікса.

Адресна метрика:

d_Σ(ξ,η)=2^(−ℓ(ξ,η)),

для ξ ≠ η.

Для ξ=η:

d_Σ(ξ,ξ)=0.

## 4.1. Ультраметрична нерівність

Нехай ξ,η,ζ — три адреси.

Якщо ξ і η збігаються на перших m символах, а η і ζ — на перших n символах, то ξ і ζ збігаються щонайменше на перших min(m,n) символах.

Отже:

ℓ(ξ,ζ) ≥ min(ℓ(ξ,η),ℓ(η,ζ)).

Після застосування 2^(−·):

**d_Σ(ξ,ζ) ≤ max(d_Σ(ξ,η),d_Σ(η,ζ)).**

Тому d_Σ — ультраметрика.

## 4.2. Компактність Σ_b

Простір Σ_b є зліченним добутком скінченних компактних дискретних просторів B_b.

За теоремою Тихонова він компактний.

Метрика d_Σ задає добуткову топологію.

Отже:

**(Σ_b,d_Σ) — компактний ультраметричний простір.**

d_v(ξ,η)=exp(−α_vℓ(ξ,η)),

# 6. Циліндрична геометрія та Hausdorff dimension

## 6.1. Циліндри

Для σ ∈ B_b^n визначимо:

[σ] = {ξ ∈ Σ_b : ξ|n=σ}.

Маємо:

μ_b([σ])=b^(−n).

Діаметр циліндра:

diam([σ])=exp(−α_v n).

Це точна рівність для b≥2.

## 6.2. Верхня оцінка розмірності

На рівні n простір Σ_b покривається b^n циліндрами.

Для s>0:

Σ diam([σ])^s
= b^n exp(−α_v s n).

Перепишемо:

= exp(n(ln b−α_v s)).

Якщо:

s>ln b/α_v,

то сума прямує до нуля.

Отже:

dim_H(Σ_b,d_v) ≤ ln b/α_v.

## 6.3. Точна оцінка міри куль

Позначимо:

s = ln b/α_v.

Нехай:

exp(−α_v(n+1)) < r ≤ exp(−α_v n).

Для замкненої кулі:

B̄_v(ξ,r)={η:d_v(ξ,η)≤r}

маємо точну рівність:

**B̄_v(ξ,r)=[ξ|n].**

Тому:

μ_b(B̄_v(ξ,r))=b^(−n).

Оскільки:

r^s ∈ (b^(−n−1),b^(−n)],

отримуємо:

**r^s ≤ μ_b(B̄_v(ξ,r)) < b r^s.**

Це точна двостороння оцінка з явними константами.

## 6.4. Ahlfors-регулярність

Отже, існують сталі C₁,C₂>0 такі, що:

C₁r^s ≤ μ_b(B̄_v(ξ,r)) ≤ C₂r^s.

Можна взяти:

C₁=1,

C₂=b.

Тому:

**(Σ_b,d_v,μ_b) є s-Ahlfors-регулярним простором, де s=ln b/α_v.**

За принципом масового розподілу:

dim_H(Σ_b,d_v) ≥ s.

Разом із верхньою оцінкою:

**dim_H(Σ_b,d_v)=ln b/α_v.**

Це закриває геометричне доведення T-005.

Важливе обмеження: результат стосується повного однорідного b-арного простору з рівномірною мірою. Він не переноситься автоматично на довільні часткові або неоднорідні дерева.

# 7. Простір компактних граничних множин

Нехай:

K(Σ_b)

— множина непорожніх компактних підмножин Σ_b.

Оскільки Σ_b компактний метричний простір, простір K(Σ_b) також компактний за метрикою Гаусдорфа.

Для C,D∈K(Σ_b):

d_H(C,D)=

max {
sup_{x∈C} inf_{y∈D} d_v(x,y),
sup_{y∈D} inf_{x∈C} d_v(x,y)
}.

Це стандартна метрика Гаусдорфа на непорожніх компактних підмножинах.

## 7.1. Розширення порожньою множиною

W23′ вводить:

K₀(Σ_b)=K(Σ_b)∪{∅},

з умовою:

d_H(∅,C)=2

для C≠∅.

Оскільки:

diam(Σ_b)≤1,

ця конструкція задовольняє трикутну нерівність.

Відстань 2 відокремлює порожню множину від усіх непорожніх компактів.

Тому K₀(Σ_b) є метричним простором.

Однак необхідно зберегти редакційне уточнення:

**це спеціально визначене розширення метрики Гаусдорфа, а не стандартне означення Hausdorff distance для порожніх множин.**

## 7.2. Компактність K₀

**K₀(Σ_b) також компактний.**

# 8. Простір Tω⁺ та межа дерева

Нехай Tω — клас часткових дерев, для яких кожен наявний внутрішній вузол має хоча б одну нескінченну гілку.

Визначимо:

Tω⁺={f∈Tω:∂f≠∅}.

## 8.1. Непорожність межі

Для кожного f∈Tω⁺ за визначенням:

∂f≠∅.

Твердження про непорожність не можна поширювати на весь Tω.

Зокрема, кореневий листок Leaf(a) належить Tω за вакуумним виконанням умови про внутрішні вузли, але:

∂Leaf(a)=∅.

## 8.2. Компактність межі

Для кожного n визначимо:

C_n(f)=
∪{[u]: |u|=n, u є внутрішнім вузлом f}.

Кожен C_n(f) є скінченним об'єднанням циліндрів, отже компактним і замкненим.

Множини вкладені:

C_(n+1)(f)⊆C_n(f).

Межа:

∂f=∩ₙ C_n(f).

Тому ∂f замкнена в компактному Σ_b.

Отже:

**∂f є компактною підмножиною Σ_b.**

Для f∈Tω⁺ вона непорожня.

## 8.3. Замкненість Tω⁺

Нехай:

f_n∈Tω⁺,

і:

f_n→f

у d_F.

Для кожного n існує адреса ξ_n∈∂f_n.

Оскільки Σ_b компактний, існує підпослідовність:

ξ_(n_k)→ξ.

Для кожного фіксованого рівня m адреси ξ_(n_k) з достатньо великим k збігаються з ξ на перших m символах.

Збіжність f_(n_k)→f означає стабілізацію станів на кожній скінченній множині адрес.

Тому кожен скінченний префікс ξ відповідає внутрішньому вузлу f.

Отже:

ξ∈∂f.

Тому:

∂f≠∅.

Аналогічний аргумент для кожного внутрішнього вузла забезпечує збереження умови Tω.

Отже:

**Tω⁺ є замкненою підмножиною простору дерев за умови канонічного кодування та скінченного розгалуження.**

Оскільки простір дерев компактний:

**Tω⁺ також компактний.**

# 9. Регулярність граничного відображення

Розглянемо:

∂:Tω⁺→K(Σ_b).

За W29.2:

d_H,Σ(∂f,∂g)≤2d_F(f,g).

Тут d_H,Σ використовує адресну метрику d_Σ.

## 9.1. Перехід до параметричної метрики

Оскільки:

d_v=d_Σ^γ,

то для Hausdorff-метрик:

**d_H,v(C,D)=d_H,Σ(C,D)^γ.**

Це точна рівність, оскільки функція x↦x^γ зростає та неперервна.

Отже:

d_H,v(∂f,∂g)
≤(2d_F(f,g))^γ.

Тому:

**d_H,v(∂f,∂g)≤2^γd_F(f,g)^γ.**

## 9.2. Класи регулярності

### 0<γ<1

Гарантована γ-Hölder неперервність:

d_H,v≤2^γd_F^γ.

Це не доводить Lipschitz-неперервності.

### γ=1

Маємо:

d_H,v≤2d_F.

Отже, відображення є 2-Lipschitz.

### γ>1

Оскільки:

0≤d_F≤1,

то:

d_F^γ≤d_F.

Отже:

d_H,v≤2^γd_F.

Таким чином, отримуємо Lipschitz-оцінку з константою 2^γ.

## 9.3. Обмеження

Наведені оцінки є гарантованими верхніми межами.

Вони не доводять оптимальність константи 2^γ.

Для твердження про найкращу Lipschitz-константу потрібен окремий аналіз граничних пар дерев.

**Вердикт:** T-007 підтверджено; область Tω⁺ та залежність від α_v мають залишатися частиною формулювання.

# 10. Structural Fingerprint: неупорядкована реконструкція

h(x)=depth(x).

Для x,y∈L, x≠y:

a(x,y)=depth(LCA(x,y)).

## 10.1. Fingerprint

Визначимо:

F(T)=(L,h,a).

Мета — відновити дерево з точністю до кореневого ізоморфізму без збереження порядку дітей.

## 10.2. Необхідні умови допустимості

Не кожна довільна трійка (L,h,a) відповідає дереву.

Для коректної реконструкції потрібні умови.

### F-01. Глибини

Для кожного x∈L:

h(x)∈ℕ₀.

### F-02. Симетричність

Для x≠y:

a(x,y)=a(y,x).

### F-03. Межі LCA

Для x≠y:

0≤a(x,y)<min(h(x),h(y)).

### F-04. Самозначення

Визначимо:

a(x,x)=h(x).

### F-05. Ієрархічна нерівність

Для всіх x,y,z∈L:

a(x,z)≥min(a(x,y),a(y,z)).

Ця умова виражає вкладену структуру спільних префіксів.

### F-06. Скінченність

L — скінченна множина.

### F-07. Повнота дерева

Кожен внутрішній вузол належить хоча б одному шляху до листка.

Це виключає зайві внутрішні компоненти, не представлені fingerprint.

## 10.3. Реконструкція через еквівалентності

Для кожного k≥0 визначимо:

L_k={x∈L:h(x)≥k}.

На L_k:

x~_k y ⇔ a(x,y)≥k.

За умов F-01–F-05 це відношення еквівалентності.

Його класи відповідають вузлам глибини k.

Для кожного класу C на рівні k+1 існує єдиний клас на рівні k, який містить C.

Він є батьківським вузлом.

Ребра відновлюються через включення класів.

Unary-вузли зберігаються: якщо один і той самий набір листків утворює клас на послідовних рівнях, між цими рівнями існує unary-ребро.

Листок x розміщується на глибині h(x).

Таким чином, fingerprint відновлює всі вузли та ребра дерева.

## 10.4. Теорема

**T-020′ — Admissible Unordered Structural Reconstruction**

Для кожного допустимого fingerprint F=(L,h,a), який задовольняє F-01–F-07, існує скінченне кореневе дерево T, таке що:

F(T)=F.

Таке дерево єдине з точністю до кореневого ізоморфізму, який не зберігає порядок дочірніх гілок.

**Статус:** ANALYTICALLY PROVED UNDER ADMISSIBILITY CONDITIONS.

# 11. Ordered SUBIT Reconstruction

Неупорядкований fingerprint не визначає адрес дочірніх гілок.

У SUBIT-WARP адреси мають значення:

B={1,2,3}.

Тому для впорядкованої реконструкції необхідна додаткова інформація.

## 11.1. Розширений fingerprint

Визначимо:

F_ordered(T)=(L,h,a,p),

де:

p:L→B^{<ω}

призначає кожному листку його повну адресу.

## 11.2. Умови допустимості адрес

### O-01. Ін'єктивність

Для різних листків:

x≠y ⇒ p(x)≠p(y).

### O-02. Prefix-free

Жодна адреса листка не є власним префіксом адреси іншого листка.

### O-03. Узгодженість глибин

Для кожного x:

h(x)=|p(x)|.

### O-04. Узгодженість LCA

Для x≠y:

a(x,y)=ℓ(p(x),p(y)).

### O-05. Коректний алфавіт

Кожен символ адреси належить B.

## 11.3. Реконструкція

Нехай:

P={p(x):x∈L}.

Визначимо множину всіх префіксів:

V={σ: σ є префіксом деякого p(x)}.

Тоді:

- ε є коренем;
- кожна σ∈V є вузлом;
- ребро σ→σi існує тоді й лише тоді, коли σi∈V;
- порядок дітей задається символами 1,2,3;
- листки відповідають максимальним адресам P.

Unary-вузли автоматично зберігаються, оскільки всі проміжні префікси включені до V.

Отже, впорядковане дерево відновлюється однозначно.

## 11.4. Теорема

**T-021′ — Ordered SUBIT Structural Reconstruction**

Для кожного допустимого F_ordered=(L,h,a,p) існує єдине впорядковане кореневе дерево, адреси листків якого задаються p.

Єдиність розуміється з точністю до ізоморфізму, що зберігає адреси вузлів.

**Статус:** ANALYTICALLY PROVED UNDER ADDRESS CONSISTENCY.

## 11.5. Редакційне уточнення

Упорядкована реконструкція за F_ordered має сильнішу інформаційну основу, ніж F.

Дані h та a стають перевірками узгодженості адрес p, а не незалежно необхідними для побудови префіксного дерева.

Їх збереження корисне для аудиту та provenance.

# 12. Межі застосування

W33.4 встановлює такі розмежування.

## 12.1. Повне та часткове дерево

Теореми про компактність простору кодувань застосовуються до обох типів за відповідних локальних обмежень.

Проте межа часткового дерева не повинна ототожнюватися з повним простором адрес.

## 12.2. Однорідна та неоднорідна геометрія

Формула:

dim_H(Σ_b,d_v)=ln b/α_v

стосується повного однорідного b-арного простору.

Для неоднорідних розгалужень потрібна окрема геометрична модель.

## 12.3. Порядок гілок

Fingerprint (L,h,a) не відновлює адресні позиції дітей.

Для впорядкованого SUBIT-дерева потрібен p.

## 12.4. Скінченні та нескінченні дерева

Теореми T-020′ та T-021′ стосуються скінченних кореневих дерев.

Вони не є автоматичними теоремами реконструкції нескінченних дерев.

## 12.5. Метрична та топологічна збіжність

Компактність простору дерев за d_F не означає, що довільні структурні операції є неперервними.

Кожна операція повинна мати окремий аналіз неперервності або контрактності.
