# PART I. GENERAL ARCHITECTURE

## 1. Призначення

SUBIT-WARP — математична архітектура для дослідження взаємозв'язку між:

1. структурою скінченних та нескінченних дерев;
2. простором структурних перетворень;
3. геометрією нескінченних граничних адрес;
4. мірами на просторах меж;
5. ієрархічними операторами взаємодії;
6. спектральними властивостями цих операторів;
7. реконструкцією деревних структур.

Центральна дослідницька гіпотеза:

**Структурна ієрархія Tree∞ індукує геометрію граничного простору, а геометрія межі дозволяє побудувати оператори, спектр яких відображає ієрархічну організацію початкової структури.**

Це математична гіпотеза про зв'язок між структурою, геометрією та спектром. Вона не є твердженням про фізичну природу гравітації.

SUBIT-WARP не змінює означень базової системи SUBIT-∞ і не входить до її стабільного ядра.

# PART II. STRUCTURAL FOUNDATION

## 2. Алфавіти та простори адрес

Нехай алфавіт листків:

A = {00, 01, 10, 11}.

Для основної моделі SUBIT-WARP використовується трійковий алфавіт розгалуження:

B₃ = {1, 2, 3}.

Узагальнена модель:

B_b = {1, 2, …, b}, де b ≥ 2.

Множина скінченних адрес:

Pos_b = B_b^{<ω}.

Простір нескінченних адрес:

Σ_b = B_b^ℕ.

Порожня адреса ε є адресою кореня.

Для u,v ∈ Pos_b:

- |u| — довжина адреси;
- u ⪯ v — u є префіксом v;
- u·i — адреса, отримана додаванням символу i;
- ξ|n — префікс нескінченної адреси ξ довжини n.

За домовленістю:

ξ|0 = ε.

## 2.1. Розділення трьох класів дерев

SUBIT-WARP використовує три різні структурні конструкції.

### FullTree

Повне нескінченне дерево:

FullTree_A^(b) ≅ Leaf(A) ⊔ Node(FullTree_A^(b))^b.

Кожна внутрішня вершина має рівно b дочірніх піддерев.

### PartialTree

Часткове дерево:

PartialTree_A^(b) ≅ None ⊔ Leaf(A) ⊔ Node(PartialTree_A^(b))^b.

Тут:

- None — відсутня позиція;
- Leaf(a) — листок із міткою a;
- Node — внутрішній вузол.

None не є листком і не означає автоматично порожній нескінченний простір.

### FiniteTree

Скінченне кореневе дерево — окрема комбінаторна конструкція.

Воно має:

- скінченну множину вершин;
- виділений корінь;
- зв'язність;
- відсутність циклів;
- скінченні шляхи від кореня до листків.

Скінченне дерево не вважається підтипом нескінченного дерева без окремо визначеного вкладення.

**Критичне правило:** FullTree, PartialTree та FiniteTree не ототожнюються.

## 2.2. Повне адресне кодування

Для однозначного порівняння дерев вводимо скінченний алфавіт станів:

S_A = {ABSENT, INTERNAL} ∪ {LEAF(a) : a ∈ A}.

Код дерева:

t : Pos_b → S_A.

Це тотальна функція, навіть якщо дерево має скінченну або часткову структуру.

Вона дозволяє однозначно визначати стан будь-якої адреси.

### Умови допустимості

**TC-01 — Root**

t(ε) ≠ ABSENT.

**TC-02 — Absent closure**

Якщо t(u)=ABSENT, тоді:

t(u·i)=ABSENT

для кожного i∈B_b.

**TC-03 — Leaf closure**

Якщо t(u)=LEAF(a), тоді:

t(u·i)=ABSENT

для кожного i∈B_b.

**TC-04 — Full branching**

Для FullTree, якщо t(u)=INTERNAL, кожна дочірня позиція u·i повинна бути присутньою:

t(u·i) ≠ ABSENT.

**TC-05 — Partial branching**

Для PartialTree внутрішній вузол може мати відсутні дочірні позиції.

Усі наявні дочірні позиції повинні задовольняти умови допустимості.

TC-01–TC-05 визначають локальні структурні класи.

Вони самі по собі не визначають умову існування нескінченного продовження.

## 2.3. ABSENT та UNKNOWN

ABSENT — структурна відсутність позиції.

UNKNOWN — невизначеність знання про позицію.

Це різні семантичні стани.

UNKNOWN не входить до базового структурного алфавіту S_A.

Якщо епістемічний шар вводить UNKNOWN, він повинен бути окремим типом або окремим контекстом над структурним кодом.

# PART III. INFINITE CONTINUATION

## 3. Нескінченне продовження

Для адреси u та дерева t визначимо властивість нескінченного INTERNAL-продовження:

IB(u,t).

Вона виконується тоді й лише тоді, коли:

1. t(u)=INTERNAL;
2. існує нескінченна адреса ξ∈Σ_b, яка продовжує u;
3. усі вузли на цій нескінченній гілці після u є INTERNAL.

Формально:

IB(u,t) ⇔

t(u)=INTERNAL ∧

∃ξ∈Σ_b,

u ⪯ ξ ∧

∀k≥|u|, t(ξ|k)=INTERNAL.

Тут ξ|k позначає префікс повної адреси ξ довжини k.

## 3.1. Клас Tω

Визначимо:

Tω = {t ∈ C_Partial :

∀u∈Pos_b,

t(u)=INTERNAL ⇒ IB(u,t)}.

Отже, кожен наявний INTERNAL-вузол повинен мати хоча б одне нескінченне INTERNAL-продовження.

Це глобальна умова, а не локальна умова допустимості TC-05.

## 3.2. Клас Tω⁺

Визначимо:

Tω⁺ = {t∈Tω : t(ε)=INTERNAL}.

Еквівалентно, за умовою rootedness:

Tω⁺ = {t∈Tω : ∂t≠∅}.

Rooted LEAF tree належить Tω, оскільки умова для INTERNAL-вузлів виконується вакуумно.

Однак:

Rooted LEAF tree ∉ Tω⁺.

Скінченне rooted tree з хоча б одним INTERNAL-вузлом без нескінченного INTERNAL-продовження не належить Tω.

## 3.3. Компактність кодованих класів

Повний кодовий простір:

S_A^{Pos_b}

є компактним добутком скінченних дискретних просторів.

Класи, визначені TC-01–TC-05, є замкненими, оскільки кожне порушення локальних умов виявляється на скінченній кількості координат.

Умова IB також задає замкнену властивість у відповідному просторі кодів.

Для фіксованого u існування нескінченного INTERNAL-продовження можна подати через нескінченну систему умов скінченної глибини.

Тому:

- Tω є замкненим підпростором кодового компактного простору;
- Tω⁺ є замкненим підпростором Tω;
- обидва класи компактні в індукованій топології.

**Обмеження:** цей результат стосується саме визначених кодованих класів. Він не ототожнює автоматично історичний Tree∞ із будь-яким новим PartialTree-кодуванням.

# PART IV. METRIC STRUCTURE

## 4. Метрика нескінченних адрес

Для ξ,η∈Σ_b, ξ≠η, визначимо:

ℓ(ξ,η) = довжина найдовшого спільного префікса.

Для ξ=η:

ℓ(ξ,ξ)=∞.

Адресна ультраметрика:

d_Σ(ξ,η)=2^(−ℓ(ξ,η)).

За домовленістю:

2^(−∞)=0.

Виконується:

d_Σ(ξ,ζ) ≤ max(d_Σ(ξ,η),d_Σ(η,ζ)).

Простір (Σ_b,d_Σ) є компактним.

## 4.1. Метрика дерев d_F

Для кодованих дерев f,g визначимо:

r_F(f,g)=min{|u| : t_f(u)≠t_g(u)}.

Якщо f=g:

r_F(f,f)=∞.

Тоді:

d_F(f,g)=2^(−r_F(f,g)).

Значення коду під листком або відсутньою позицією однозначно визначається тотальним кодуванням.

Це усуває неоднозначність попереднього функціонального запису f(u).

Для кожного фіксованого допустимого класу кодів d_F є ультраметрикою.

Доказ ґрунтується на першій адресі розходження.

Якщо f і g збігаються на всіх адресах глибини меншої за m, а g і h — на всіх адресах глибини меншої за n, то f і h збігаються на всіх адресах глибини меншої за min(m,n).

Отже:

d_F(f,h)≤max(d_F(f,g),d_F(g,h)).

**Канонічне правило:** d_F — метрика дерев; d_Σ — метрика нескінченних адрес. Їх не ототожнювати.

## 4.2. Метрика скінченних дерев

Для листків ξ,η скінченного дерева:

d_T(ξ,η)=h(ξ)+h(η)−2ℓ(ξ,η).

Це звичайна деревна відстань уздовж ребер.

Вона не є ультраметрикою d_Σ.

## 4.3. Метрика Гаусдорфа

Нехай K(Σ_b) — простір непорожніх компактних підмножин Σ_b.

Для C,D∈K(Σ_b):

d_H(C,D)=

max {

sup_{x∈C} inf_{y∈D} d_Σ(x,y),

sup_{y∈D} inf_{x∈C} d_Σ(x,y)

}.

Це метрика Гаусдорфа на непорожніх компактних множинах.

Розширення на порожню множину визначається окремо:

K₀(Σ_b)=K(Σ_b)∪{∅}.

За прийнятою конвенцією:

d_H(∅,C)=d_H(C,∅)=2,

d_H(∅,∅)=0.

Це спеціальне метричне розширення, а не автоматично стандартна метрика Гаусдорфа.

# PART V. GRAFTING AND FIXED POINTS

## 5. Канонічне grafting

Для базового трійкового дерева визначимо:

ρ_a(f)=Node(f,Leaf(a),Leaf(a)),

де a∈A.

За метрикою d_F:

d_F(ρ_a(f),ρ_a(g))=½d_F(f,g).

Отже:

Lip(ρ_a)=½.

Простір повних дерев із метрикою d_F є повним.

За теоремою Банаха існує єдина нерухома точка p_a:

p_a=ρ_a(p_a).

Тобто:

p_a=Node(p_a,Leaf(a),Leaf(a)).

**Статус:** аналітично доведено за умов повноти простору та коректності grafting.

Для загального b-арного випадку коефіцієнт контрактності не переноситься автоматично. Потрібне окреме означення grafting та його метричний доказ.

# PART VI. BOUNDARY GEOMETRY

## 6. Межа дерева

Для t∈Tω⁺:

∂t={ξ∈Σ_b :

∀k≥0, t(ξ|k)=INTERNAL}.

Межа складається з усіх нескінченних INTERNAL-гілок.

За визначенням Tω⁺:

∂t≠∅.

Оскільки умови належності визначаються замкненими циліндричними обмеженнями, ∂t є замкненою підмножиною компактного Σ_b.

Отже:

∂t∈K(Σ_b).

## 6.1. Параметрична геометрія

Для α_v>0 визначимо:

d_v(ξ,η)=exp(−α_vℓ(ξ,η)).

Оскільки:

d_Σ(ξ,η)=2^(−ℓ(ξ,η)),

маємо:

d_v=d_Σ^γ,

де:

γ=α_v/ln2.

Це метрика для γ>0, оскільки степінь додатної ультраметрики зберігає ультраметричну нерівність.

## 6.2. Hausdorff dimension

Для повного однорідного b-арного простору з рівномірною мірою:

μ_b([u])=b^(−|u|)

маємо:

dim_H(Σ_b,d_v)=ln(b)/α_v.

Позначимо:

s=ln(b)/α_v.

Для n≥1 та радіусів

exp(−α_v n)≤r<exp(−α_v(n−1))

замкнена куля має вигляд:

B̄_v(ξ,r)=[ξ|n].

Тому:

μ_b(B̄_v(ξ,r))=b^(−n).

Оскільки:

r^s≥b^(−n)

та

r^s<b·b^(−n),

отримуємо:

r^s/b<μ_b(B̄_v(ξ,r))≤r^s.

Для r≥1 куля збігається з усім Σ_b.

Отже, міра є Ahlfors s-regular з константами 1/b та 1 за цієї конвенції замкнених куль.

За принципом масового розподілу:

dim_H(Σ_b,d_v)≥s.

Покриття b^n циліндрами рівня n дає:

dim_H(Σ_b,d_v)≤s.

Таким чином:

**dim_H(Σ_b,d_v)=ln(b)/α_v.**

**Обмеження:** це твердження стосується повного однорідного b-арного простору з рівномірною Bernoulli-мірою. Воно не переноситься автоматично на довільні часткові або неоднорідні дерева.

## 6.3. Boundary map

Визначимо:

∂:Tω⁺→K(Σ_b).

Для f,g∈Tω⁺:

d_H,Σ(∂f,∂g)≤2d_F(f,g).

### Доведення

Нехай:

m=r_F(f,g).

Якщо f=g, твердження очевидне.

Якщо f≠g, корені обох дерев є INTERNAL, тому m≥1.

Нехай ξ∈∂f.

Якщо ξ∈∂g, відстань до ∂g дорівнює нулю.

Якщо ξ∉∂g, існує перша адреса вздовж ξ, на якій g має LEAF.

Оскільки f і g збігаються на всіх адресах глибини меншої за m, ця адреса має глибину не менш як m.

Її батьківський вузол є INTERNAL в обох деревах.

Оскільки g∈Tω⁺, цей вузол має нескінченне INTERNAL-продовження.

Таке продовження не може проходити через дочірню позицію, яка є LEAF у g. Отже, існує інша нескінченна гілка η∈∂g, що збігається з ξ щонайменше до глибини m−1.

Тому:

d_Σ(ξ,η)≤2^(−(m−1)).

Але:

d_F(f,g)=2^(−m).

Отже:

dist(ξ,∂g)≤2d_F(f,g).

Симетричний аргумент дає:

d_H,Σ(∂f,∂g)≤2d_F(f,g).

**Статус:** ANALYTICALLY PROVED на Tω⁺.

## 6.4. Параметрична регулярність

Оскільки:

d_v=d_Σ^γ,

індуковані метрики Гаусдорфа задовольняють:

d_H,v(C,D)=d_H,Σ(C,D)^γ.

Отже:

d_H,v(∂f,∂g)≤2^γd_F(f,g)^γ.

Таким чином:

- для 0<γ<1 boundary map є Hölder із показником γ;
- для γ=1 boundary map є 2-Lipschitz;
- для γ>1 маємо Lipschitz-оцінку з константою 2^γ, оскільки d_F≤1.

Ця параметрична оцінка є короларієм базового T-007.

Теорема не поширюється автоматично на порожні межі через спеціальне розширення K₀.

# PART VII. MEASURE AND SPECTRAL SPACE

## 7. Канонічна міра

На:

Σ_b=B_b^ℕ

визначимо рівномірну Bernoulli-міру:

μ_b=(1/b,…,1/b)^ℕ.

Для кожного циліндра [u]:

μ_b([u])=b^(−|u|).

Міра є ймовірнісною та безатомною.

Усі канонічні спектральні результати цієї специфікації стосуються саме μ_b.

Заміна міри на нерівномірну потребує нового спектрального аналізу.

## 7.1. Гільбертів простір

H=L²(Σ_b,μ_b).

Нехай H_n — простір функцій, сталих на циліндрах довжини n.

Тоді:

dim H_n=b^n.

Маємо вкладення:

H₀⊂H₁⊂H₂⊂…

і:

H=closure(∪ₙH_n).

Визначимо:

W₀=H₀,

W_j=H_j⊖H_{j−1}, j≥1.

Тоді:

H=W₀⊕⨁_{j≥1}W_j.

Розмірності:

dim W₀=1,

dim W_j=(b−1)b^(j−1).

Це канонічна ієрархічна декомпозиція.

# PART VIII. DECREASING KERNEL

## 8. Спадне ядро

Для 0≤q≤1 визначимо:

K_q(ξ,η)=q^ℓ(ξ,η), ξ≠η.

Діагональна конвенція:

K_q(ξ,ξ)=0.

Для всіх q∈[0,1]:

q⁰:=1.

Для k≥1:

0^k=0.

**Примітка щодо джерельної сумісності:** у W30 зустрічається діагональне значення 1. Оскільки діагональ має нульову μ_b×μ_b-міру, обидва представники ядра задають той самий інтегральний оператор на L². Канонічна точкова конвенція цієї редакції — K_q(ξ,ξ)=0.

Інтегральний оператор:

(T_qf)(ξ)=∫Σ_b K_q(ξ,η)f(η)dμ_b(η).

## 8.1. Спектральний розклад

Для константного підпростору:

λ₀(q)=c_q=(b−1)/(b−q).

Для j≥1:

λ_j(q)=−(1−q)q^(j−1)/[b^(j−1)(b−q)].

Кратність:

m_j=(b−1)b^(j−1).

Дія оператора:

T_q|W₀=c_qI,

T_q|W_j=λ_j(q)I.

Отже:

Spec(T_q)={c_q}∪{λ_j(q):j≥1}∪{0}.

Для 0<q<1 нуль є точкою накопичення власних значень.

Оператор T_q є самоспряженим, компактним та trace-class.

## 8.2. Операторні норми

Для 0≤q<1:

‖T_q‖=c_q.

‖T_q‖²_HS=(b−1)/(b−q²).

‖T_q‖₁=2c_q.

Tr(T_q)=0.

Тут ‖·‖₁ — слідова норма.

Оператор T_q не є додатно напіввизначеним, оскільки всі λ_j(q) при 0≤q<1 є непозитивними, а λ₁(q)<0.

## 8.3. Центрований оператор

Визначимо:

L_q=T_q−c_qI.

Тоді:

L_q|W₀=0,

L_q|W_j=(λ_j(q)−c_q)I.

Виконується:

L_q≤0.

Ker(L_q)=W₀.

Оскільки T_q компактний:

Spec_ess(L_q)={−c_q}.

Точка −c_q є точкою істотного спектра, але не власним значенням.

## 8.4. Крайові значення

### q=0

c₀=(b−1)/b.

λ₁(0)=−1/b.

λ_j(0)=0 для j≥2.

Оператор має скінченний ранг не більше b.

### q=1

Оператор визначається окремо:

T₁=P_const.

Тобто ортогональна проєкція на простір сталих функцій.

‖T₁‖=1.

‖T₁‖₁=1.

Tr(T₁)=1.

Формули для q<1 не можна механічно переносити на q=1.

## 8.5. Гранична поведінка q→1⁻

Для q<1:

‖T_q−P_const‖₁=1.

Тому:

lim(q→1⁻)‖T_q−P_const‖₁=1.

Отже, збіжність до T₁ не відбувається у trace norm.

Водночас операторна збіжність:

T_q→P_const

відбувається в операторній нормі.

Також:

lim(q→1⁻)‖T_q‖₁=2,

тоді як:

‖T₁‖₁=1.

Ці результати необхідно розглядати як різні режими збіжності.

# PART IX. INCREASING KERNEL

## 9. Зростаюче ядро

Нехай:

t=exp(α_w)>1.

Для ξ≠η:

K_+(ξ,η)=t^ℓ(ξ,η).

Діагональ визначається окремо:

K_+(ξ,ξ)=0.

Відповідний інтегральний оператор позначимо T_+.

Він є окремою конструкцією, не тотожною T_q.

## 9.1. Спектр у bounded regime

Для:

1<t<b

власне значення константного підпростору:

λ₀(t)=(b−1)/(b−t).

Для j≥1:

λ_j(t)=(t−1)t^(j−1)/[b^(j−1)(b−t)].

Кратність:

m_j=(b−1)b^(j−1).

Усі власні значення додатні.

## 9.2. Критерії операторних класів

Оператор T_+:

- обмежений тоді й лише тоді, коли t<b;
- компактний тоді й лише тоді, коли t<b;
- Hilbert–Schmidt тоді й лише тоді, коли t²<b;
- не належить до trace-class для жодного t>1 у bounded regime.

Еквівалентно:

Boundedness:

α_w<ln b.

Hilbert–Schmidt:

α_w<(ln b)/2.

Для t<b:

‖T_+‖=(b−1)/(b−t).

Для t²<b:

‖T_+‖²_HS=(b−1)/(b−t²).

Необмеженість при t≥b випливає з розбіжності інтеграла ядра на константній функції.

## 9.3. Відмінність від спадного ядра

Не можна переносити на T_+ властивості T_q лише через схожість ієрархічних формул.

Необхідно окремо перевіряти:

- boundedness;
- compactness;
- Hilbert–Schmidt membership;
- trace-class membership.

# PART X. FINITE APPROXIMATION

## 10. Скінченновимірні підпростори

Нехай P_n — ортогональна проєкція на H_n.

Визначимо:

T_q^(n)=P_nT_qP_n|H_n.

Використаємо ортонормований циліндричний базис:

e_u=b^(n/2)1_[u],

де u∈B_b^n.

## 10.1. Матричні елементи

Для u≠v:

(T_q^(n))_(u,v)=b^(−n)q^ℓ(u,v).

Для u=v:

(T_q^(n))_(u,u)=b^(−n)q^n c_q.

Ці формули використовують конвенцію q⁰=1.

## 10.2. Випадок n=0

Простір H₀ є одновимірним.

Матриця:

T_q^(0)=[c_q].

Це окремий коректний крайовий випадок.

## 10.3. Скінченний спектр

Для кожного n:

Spec(T_q^(n)) складається з:

- c_q на W₀;
- λ_j(q) на W_j для 1≤j≤n.

Кратність кожного λ_j:

m_j=(b−1)b^(j−1).

## 10.4. Слід скінченної апроксимації

Tr(T_q^(n))=q^n c_q.

Цей слід не є слідом нескінченного оператора T_q.

Для q<1:

Tr(T_q)=0.

Отже, два значення не можна ототожнювати.

## 10.5. Операторна похибка

Для 0<q<1:

‖T_q−P_nT_qP_n‖=|λ_(n+1)(q)|.

Тобто:

‖T_q−P_nT_qP_n‖=

(1−q)q^n/[b^n(b−q)].

## 10.6. Trace-norm convergence

Для 0≤q<1:

‖T_q−P_nT_qP_n‖₁=

(b−1)q^n/(b−q).

Тому за фіксованого q<1:

P_nT_qP_n→T_q

у trace norm.

Для q=1:

T₁=P_const.

Оскільки константи належать H_n для кожного n≥0, компресія є точною:

P_nT₁P_n=T₁.

**Критичне розрізнення:** trace-norm convergence скінченних апроксимацій за фіксованого q<1 не означає trace-norm convergence сімейства T_q до P_const при q→1⁻.

Первинні параметри:

Похідні параметри:

# PART XII. STRUCTURAL RECONSTRUCTION

## 12. Неупорядкована реконструкція

Для скінченного кореневого дерева визначимо fingerprint:

F(T)=(L,h,a),

де:

- L — скінченна непорожня множина листків;
- h(x) — глибина листка x;
- a(x,y) — глибина найменшого спільного предка листків x,y.

Для коректної реконструкції необхідні умови:

**FP-01:** h(x)∈ℕ₀.

**FP-02:** a(x,y)=a(y,x).

**FP-03:** для x≠y:

0≤a(x,y)<min(h(x),h(y)).

**FP-04:** a(x,x)=h(x).

**FP-05:** для всіх x,y,z:

a(x,z)≥min(a(x,y),a(y,z)).

**FP-06:** L скінченна та непорожня.

**FP-07:** усі внутрішні вершини лежать на шляхах від кореня до листків; unary vertices зберігаються.

Для кожного k визначимо:

L_k={x∈L:h(x)≥k}.

Відношення:

x~_k y ⇔ a(x,y)≥k.

За наведених умов класи еквівалентності визначають вершини відповідного рівня.

Вкладення класів на суміжних рівнях визначає батьківські відношення.

**T-020′:** fingerprint (L,h,a) визначає скінченне кореневе дерево з точністю до root-preserving unordered isomorphism за заявлених умов та конвенції одиничних ребер.

## 12.1. Упорядкована реконструкція

Для відновлення порядку дочірніх гілок необхідно додати:

p:L→B_b^{<ω}.

Вимоги:

1. p ін'єктивне;
2. множина адрес листків prefix-free;
3. |p(x)|=h(x);
4. a(x,y)=ℓ(p(x),p(y)) для x≠y;
5. усі символи адрес належать B_b;
6. адреси сумісні з обраною моделлю розгалуження.

Префіксне замикання адрес листків відновлює occupied ordered trie.

**T-021′:** за умов коректності адрес fingerprint (L,h,a,p) визначає впорядковане скінченне дерево.

Prefix closure саме по собі не відновлює семантику незайнятих дочірніх позицій. Якщо модель допускає відсутні позиції, їх потрібно явно кодувати.
