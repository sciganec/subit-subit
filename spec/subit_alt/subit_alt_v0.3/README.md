# SUBIT-ALT

Альтернативні теоретичні надбудови над `subit_spec_v0.1.md` (SUBIT = WHO × WHERE × WHEN, 6 бітів, 64 стани). Не залежать від SUBIT-∞ (v6.13.x).

**Основний документ: `subit_alt_spec.md` (SUBIT-ALT v0.3)** — об'єднує ALT1 (алгебра і динаміка на ℤ₄³) та ALT2 (логіка контекстів «хто–де–коли») і додає розділи 11–16 з новими результатами на стику двох частин.

Спільна відправна точка: коди v0.1 для кожної осі (10 → 11 → 01 → 00) утворюють цикл Грея, тож SUBIT — це тор ℤ₄³ з метрикою Лі, яка збігається з метрикою Геммінга на 6 бітах.

## Ключові результати

**Частина A (динаміка на 64 станах).**
- 3×3 матриці над ℤ₄: 262144 відображення, 86016 оборотних; 17 циклових типів, найбільший порядок 14, найбільший передперіод 6.
- Ядерна гексаграма N: N²(w,e,n) = (e,e,e); атрактори — дві нерухомі точки і 2-цикл; басейни залежать лише від WHERE; N є 𝔽₂-лінійним відображенням рангу 4.

**Частина B (логіка).**
- Три осі дають добуток S5-логік (аксіоми перевірено вичерпно на площині 4×4); розмір шкали «4» виразний модально.
- Двовимірна семантика: контингентне апріорне, жорсткі індексикали, оператори-«монстри», що не комутують з «Actually».

**Частина C (нове).**
- Групи: автоморфізми рамки S₄ ≀ S₃ (82944), ізометрії Лі = Aut(Q₆) (46080); їх перетин — рівно мономіальна група порядку 3072, також рівна множині ℤ₄-афінних автоморфізмів рамки.
- Морфізми рамки серед лінійних відображень: 1000 матриць (стовпці з ≤ 1 ненульовою клітинкою); бієктивних 48.
- Теорема колапсу: ◇ ≡ ◇⁺ ≡ ↺ ⇔ відображення бієктивне; ◇⁺ ≡ ↺ ⇔ образ лежить у періодичних точках. Підтверджено на всіх 262144 матрицях і 1500 випадкових функціях.
- Код Грея: лінійне над ℤ₄ відображення 𝔽₂-афінне ⇔ у кожному рядку M mod 2 не більше однієї непарної клітинки (32768 матриць); N 𝔽₂-лінійне, але не ℤ₄-афінне.
- Централізатор N у геометричних групах — чотирьохелементна група {id, антипод, реверс, їх композиція}; усього автоморфізмів динаміки N: 2⁴²·3¹⁶ ≈ 1,9·10²⁰.
- Жодне лінійне відображення не розрізняє всі 64 контексти: максимум 36 класів бісимуляції (орбіти x ↦ −x).

## Як відтворити

Потрібен Python 3.

```text
python3 verify_alt1.py
python3 verify_alt2.py
python3 verify_alt2b.py
python3 verify_alt_u.py            # або окремі секції: python3 verify_alt_u.py U3
python3 audit_numbers.py           # звірка чисел специфікації з verification_logs/
```

## Чого тут немає

- Немає Lean- чи Rust-перевірки, немає незалежної рецензії. Текст і скрипти створив той самий автор-асистент; скрипти перевіряють відповідність власним означенням, а не «правильність» задуму.
- Немає тверджень про фізику, спостерігача чи природу реальності. Логіка формалізує лише те, що істинність речень можна зробити відносною до **заданого** контексту; модель не показує, що спостереження породжує складність.
- Моделі навмисно скінченні й іграшкові (4 особи, 4 напрями, 4 пори року).

## Відкриті напрямки

Орбітні профілі всіх 16 777 216 афінних відображень; структура групи H = {M : M mod 2 ∈ S₃} (порядок 3072, індекс 28 у GL₃(ℤ₄)); чому S5 + N має рівно 36 класів; гібридна логіка з номіналами; епістемічна версія з ME/WE/YOU/THEY як агентами; повна аксіоматизація рамки з X і N. Повний список — розділ 18 специфікації.
