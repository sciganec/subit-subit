# SUBIT-ALT

Альтернативні теоретичні надбудови над `subit_spec_v0.1.md` (SUBIT = WHO × WHERE × WHEN, 6 бітів, 64 стани). Вони розвивають інші напрями, ніж SUBIT-∞ (v6.13.x), і не залежать від нього.

Спільна відправна точка: коди v0.1 для кожної осі (10 → 11 → 01 → 00) утворюють цикл Грея, тож SUBIT можна читати як тор ℤ₄³ з метрикою Лі, яка збігається з метрикою Геммінга на 6 бітах.

## Як відтворити

Потрібен Python 3.

```bash
python subit_alt1_v0.1/verify_alt1.py      # потрібен numpy; кілька десятків секунд-хвилин
python subit_alt2_v0.1/verify_alt2.py      # хвилина або менше
python subit_alt2_v0.1/verify_alt2b.py     # секунди
```

Кожен скрипт друкує числа, що наведені в відповідній специфікації. У кожній специфікації є додаток «Відтворення» з підсумком очікуваного виводу.

## Статуси тверджень

У специфікаціях вживаються такі позначки:

| Позначка | Значення |
| :-- | :-- |
| **COMPUTED (вичерпно)** | перебрано всі випадки скінченної множини |
| **COMPUTED (вибірка)** | випадкова або часткова перевірка: свідчення, а не доказ |
| **Ручне доведення** | доказ виписано в тексті |
| **СТАНДАРТНИЙ ФАКТ** | відомий результат із літератури, тут не перевірявся |
| **ВІДКРИТО** | не досліджено |

## Чого тут немає

- Немає Lean- чи Rust-перевірки, немає незалежної рецензії. Текст і скрипти створив той самий автор-асистент; скрипти перевіряють відповідність власним означенням, а не «правильність» задуму.
- Немає тверджень про фізику, спостерігача чи природу реальності. ALT2 формалізує лише те, що істинність речень можна зробити відносною до заданого контексту; контексти там задані, а не породжені спостереженням.
- Моделі навмисно скінченні й іграшкові (4 особи, 4 напрями, 4 пори року).

## Відкриті напрямки

Афінна динаміка над ℤ₄ (5,5 млн відображень) і структурна класифікація циклових типів у GL₃(ℤ₄) (ALT1); гібридна логіка з номіналами, епістемічна версія з ME/WE/YOU/THEY як агентами, повна аксіоматизація рамки, динамічна семантика зміни контексту (ALT2). Повні списки є в розділах «Відкриті питання» специфікацій.
