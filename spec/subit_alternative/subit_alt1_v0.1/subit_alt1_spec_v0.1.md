Альтернативна надбудова над `subit_spec_v0.1.md`. Вона не замінює SUBIT-∞ (v6.13.x), а розвиває інший напрям: використовує ті властивості кодування v0.1, які в SUBIT-∞ лишилися невикористаними (цикл Грея, блочна структура 2+2+2, тотожність 6-бітного коду з гексаграмою).

## 1. Основа: SUBIT як ℤ₄³

**Означення 1.1 (γ).** ℤ₄ = {0, 1, 2, 3}. Відображення γ : ℤ₄ → {0,1}²:

```text
γ(0) = 10,  γ(1) = 11,  γ(2) = 01,  γ(3) = 00
```

Це точно кодування v0.1 для кожної з трьох осей:

| a ∈ ℤ₄ | γ(a) | WHO | WHERE | WHEN |
| :-- | :-- | :-- | :-- | :-- |
| 0 | 10 | ME | EAST | SPRING |
| 1 | 11 | WE | SOUTH | SUMMER |
| 2 | 01 | YOU | WEST | AUTUMN |
| 3 | 00 | THEY | NORTH | WINTER |

**Означення 1.2 (SUBIT-ALT1).** 𝕊 := ℤ₄³ ∋ (w, e, n) (WHO, WHERE, WHEN). Бітове слово: bits(w,e,n) := γ(w)γ(e)γ(n) ∈ {0,1}⁶. Код: code6 як у v0.1 (b₁ — старший біт).

**Твердження 1.3 (bits — бієкція).** bits : 𝕊 → {0,1}⁶ бієктивне; code6∘bits : 𝕊 → {0,…,63} бієкція. COMPUTED; очевидно з бієктивності γ.

**Твердження 1.4 (цикл Грея).** γ(a) і γ(a+1 mod 4) відрізняються рівно в одному біті для кожного a (включно з переходом 3 → 0: 00 → 10). COMPUTED. *Зміст:* порядок осей у v0.1 (ME → WE → YOU → THEY, EAST → SOUTH → WEST → NORTH, SPRING → SUMMER → AUTUMN → WINTER) — це обхід чотирикутного циклу C₄ = Q₂ по сусідніх вершинах.

**Означення 1.5 (метрика Лі).** d_L(a, b) := min((a−b) mod 4, (b−a) mod 4) на ℤ₄; на 𝕊 — сума по трьох координатах.

**Твердження 1.6 (Лі = Геммінг).** d_L(x, y) = d_H(bits x, bits y) для всіх x, y ∈ 𝕊. COMPUTED (4096 пар). *Доведення (ручне).* Метрики адитивні по координатах, тож досить ℤ₄: сусідні елементи дають слова, що різняться в одному біті; елементи 0, 2 (10 і 01) і 1, 3 (11 і 00) різняться в двох. ∎

**Твердження 1.7 (додавання 2 — це XOR).** Додавання 2 до i-ї координати дорівнює побітовому XOR з 11 у i-му блоці. COMPUTED. Наслідок: комплементація всіх 6 бітів (гексаграма «cuo») є зсувом на (2, 2, 2).

**Зауваження 1.8.** Додавання 1 не є XOR-зсувом: для зсуву третьої координати на 1 маємо 2 різні XOR-патерни (COMPUTED). Отже ℤ₄-структура і XOR-структура на 64 станах — різні; їх зв'язує лише відображення Грея (відома тема для ℤ₄-лінійних кодів; СТАНДАРТНИЙ ФАКТ, тут не розвивається).

**Зіставлення з гексаграмами.** Код слова збігається з кодами Додатка А v0.1. Чотири особливі стани:

| Координати | Біти | № | Роль нижче |
| :-- | :-- | :-- | :-- |
| (0,0,0) = ME/EAST/SPRING | 101010 | 63 | елемент 2-циклу ядра |
| (1,1,1) = WE/SOUTH/SUMMER | 111111 | 1 | нерухома точка ядра |
| (2,2,2) = YOU/WEST/AUTUMN | 010101 | 64 | елемент 2-циклу ядра |
| (3,3,3) = THEY/NORTH/WINTER | 000000 | 2 | нерухома точка ядра |

## 2. Зсуви

𝕊 — абелева група порядку 64. Зсув T_t(x) := x + t.

**Твердження 2.1.** Серед 64 векторів t порядок 1 має 1, порядок 2 — 7, порядок 4 — 56. Відображення T_t має 64/ord(t) циклів довжини ord(t). COMPUTED (порядки); друга частина — елементарна властивість зсуву групи.

**Приклад (годинник).** Зсув на (0,0,1): 16 циклів довжини 4, у кожному WHO, WHERE фіксовані, WHEN обходить пори року.

Динаміка зсувів тривіальна (періодична з періодом, що ділить 4), тому змістовніші класи — наступні розділи.

## 3. Симетрії

**Означення 3.1 (мономіальна група).** Μ := усі відображення

```text
x ↦ y,   y_i = ε_i · x_{π(i)} + c_i  (mod 4),   ε_i ∈ {1, 3},  π ∈ S₃,  c ∈ ℤ₄³
```

**Твердження 3.2.** (а) |Μ| = 3072 = 8³·6 (всі відображення попарно різні); (б) кожен елемент Μ зберігає d_L; (в) Μ збігається з множиною ізометрій куба Q₆, що зберігають розбиття бітів {b₁b₂ | b₃b₄ | b₅b₆} на три пари (перестановка бітів + XOR-зсув). Усе COMPUTED вичерпно. *Інтерпретація:* Μ ≅ D₄ ≀ S₃, де D₄ — діедральна група порядку 8, симетрії самого циклу C₄.

**Зауваження 3.3 (СТАНДАРТНИЙ ФАКТ, не обчислювався).** Повна група ізометрій метричного простору (𝕊, d_L) збігається з групою ізометрій Q₆, тобто з гіпероктаедральною групою порядку 2⁶·6! = 46080. Індекс Μ у ній дорівнює 15 — числу способів розбити 6 координат на 3 пари (COMPUTED: 46080/3072 = 15). Тому поділ WHO/WHERE/WHEN — один з 15 рівноправних метрично, а Μ — підгрупа, що його зберігає.

**Твердження 3.4 (COMPUTED).** Елементи Μ мають 14 різних циклових типів; найбільший порядок елемента — 12.

## 4. Лінійна динаміка над ℤ₄

Розглядаємо відображення x ↦ Mx, M ∈ M₃(ℤ₄), x ∈ 𝕊 як вектор-стовпець. Усього 4⁹ = 262144 відображень. Кожне — автономна скінченна система на 64 станах, тож для кожного означені цикловий тип, передперіод і розмір образу.

**Результати (COMPUTED, вичерпно по всіх 262144 матрицях):**

| Величина | Значення |
| :-- | :-- |
| Оборотні (бієктивні) матриці | 86016 = \|GL₃(ℤ₄)\| = 168·2⁹ (збігається з очікуваним) |
| Різних циклових типів серед оборотних | 17 |
| Найбільший порядок оборотної матриці (НСК довжин циклів) | 14 |
| Нільпотентні (усі точки йдуть в 0, єдиний цикл — нерухома 0) | 32768 = 2¹⁵ |
| Найбільший передперіод по всіх матрицях | 6 (приклад: [[0,0,1],[0,1,1],[2,1,1]]) |
| Максимальний НСК циклів по всіх матрицях | 14 |

Розподіл передперіоду (кількість матриць): 0 → 86016; 1 → 43905; 2 → 68383; 3 → 18144; 4 → 29568; 5 → 5376; 6 → 10752.

Найчастіші циклові типи серед оборотних (запис «довжина: кількість циклів», сума довжин = 64):

| Цикли | Кількість матриць |
| :-- | :-- |
| 14: 4, 7: 1, 1: 1 | 21504 |
| 6: 8, 3: 4, 1: 4 | 10752 |
| 8: 6, 4: 3, 2: 1, 1: 2 | 10752 |
| 6: 9, 3: 2, 2: 1, 1: 2 | 10752 |
| 8: 4, 4: 4, 2: 6, 1: 4 | 5376 |
| 4: 14, 2: 2, 1: 4 | 5376 |

**Приклад 4.1 (порядок 3).** M = [[1,1],[1,2]] над ℤ₄ (діє на двох осях). *Доведення, що M³ = I.* det M = 2 − 1 = 1, оборотна; M² = [[2,3],[3,5]] ≡ [[2,3],[3,1]]; M³ = M²·M = [[5,8],[4,5]] ≡ [[1,0],[0,1]]. Дія на ℤ₄²: 5 циклів довжини 3 і 1 нерухома точка (COMPUTED). ∎

**Зауваження 4.2.** Класифікація циклових типів тут емпірична (перебір). Структурна теорія (опис через спряженість у GL₃(ℤ₄) і розклад на ℤ₂-шари) ВІДКРИТО.

## 5. Ядерна гексаграма як динаміка на 𝕊

**Означення 5.1.** N : {0,1}⁶ → {0,1}⁶, N(b₁…b₆) := (b₂, b₃, b₄, b₃, b₄, b₅). Нижня ядерна триграма — лінії 2–4, верхня — лінії 3–5; це традиційна «ядерна» (hu) гексаграма. Через bits перенесено на 𝕊.

**Твердження 5.2 (структура N).** (а) N²(b) = (b₃, b₄, b₃, b₄, b₃, b₄); (б) образ N² складається з 4 слів (p,q,p,q,p,q), тобто з 000000, 010101, 101010, 111111; (в) N діє на цих чотирьох як обмін p ↔ q. *Доведення.* (а) для c = N(b) маємо c = (b₂,b₃,b₄,b₃,b₄,b₅), N(c) = (c₂,c₃,c₄,c₃,c₄,c₅) = (b₃,b₄,b₃,b₄,b₃,b₄). (б), (в): N(p,q,p,q,p,q) = (q,p,q,p,q,p). ∎

**Наслідок / COMPUTED.** Атрактори: дві нерухомі точки 000000 (№2) і 111111 (№1) та 2-цикл 101010 ↔ 010101 (№63 ↔ №64). Розмір образу N — 16. Глибина: 4 вершини глибини 0 (самі атрактори), 12 — глибини 1, 48 — глибини 2; максимальний передперіод 2. Басейни: 16 для 000000, 16 для 111111, 32 для 2-циклу.

**У координатах 𝕊.** Усі чотири атрактори лежать на діагоналі {(a,a,a)}: нерухомі (3,3,3) і (1,1,1), 2-цикл (0,0,0) ↔ (2,2,2). На діагоналі N діє як a ↦ 2 − a (фіксує 1 і 3, міняє 0 ↔ 2). Це узгоджується з 5.2(в).

**Твердження 5.3 (симетрії N, COMPUTED).**
- Комплементація b ↦ 1−b комутує з N; у координатах вона дорівнює зсуву на (2,2,2) (див. 1.7).
- Реверс ліній b ↦ (b₆,…,b₁) комутує з N; у координатах він дорівнює (w, e, n) ↦ (2−n, 2−e, 2−w).
- Група ⟨комплемент, реверс⟩ порядку 4 має на 64 станах 20 орбіт: 12 розміру 4 і 8 розміру 2. Реверс-інваріантних гексаграм 8, комплемент-реверс-інваріантних 8.

**Твердження 5.4 (N поза афінним класом, COMPUTED).** (а) Найбільший коефіцієнт розтягу N у метриці Геммінга = 2, тож N не нерозтягувальне; (б) N не адитивне на ℤ₄³: рівність N(x+y) = N(x)+N(y) виконується для 0 з 4096 пар. Зокрема N(0,0,0) = (2,2,2) ≠ 0 (бо N(101010) = 010101), тож N не гомоморфізм груп і не лінійне. Чи є N афінним відображенням x ↦ Mx + t, окремо не перевірялося (ВІДКРИТО).

## 6. Загальна рамка: профіль орбіт

**Означення 6.1.** Для f : 𝕊 → 𝕊 профіль OP(f) := (мультимножина довжин циклів, максимальний передперіод, \|f(𝕊)\|).

Приклади: OP(зсув на 1 по WHEN) = (шістнадцять циклів довжини 4, 0, 64); OP(N) = ({1, 1, 2}, 2, 16).

Профіль — єдиний інваріант, який тут використовується. Він не залежить від жодних семантичних назв (ME, EAST, …).

## 7. Зв'язок з v0.1 і SUBIT-∞

**Що ALT1 використовує з v0.1:** код Грея на кожній осі (1.4), блочне розбиття 2+2+2 (3.3), збіг 6-бітного слова з гексаграмою (розділ 5).

**Чого ALT1 не використовує:** назви (ME, EAST, SPRING), білаттис Белнапа, триграми як кольори чи сторони світу.

**Зв'язок з SUBIT-∞.** За твердженням 8.6 (K5) SUBIT-∞ кожна автономна система (S, f) вкладається в SUBIT як (S, {f}, g_f). Тому кожне f : 𝕊 → 𝕊 з цього тексту є об'єктом SUBIT; зворотного не стверджується. Тверджень SUBIT-∞ ALT1 не потребує і не змінює.

## 8. Відкриті питання

1. Повний перебір афінних відображень x ↦ Mx + t (5505024 штук) і порівняння профілів з лінійними.
2. Скільки різних профілів OP має множина всіх 262144 лінійних відображень (скрипт рахує лише циклові типи оборотних і розподіл передперіоду).
3. Структурна класифікація циклових типів у GL₃(ℤ₄) (замість перебору).
4. Спряженість відображень на 𝕊 до XOR-лінійних відображень на {0,1}⁶ через γ і опис ℤ₄-лінійних, але не ℤ₂-лінійних відображень (відома тема ℤ₄-лінійних кодів; тут не досліджувалась).
5. Чи є природна ℤ₄-афінна функція, що має атрактори ядра (двох нерухомих точок і 2-цикл)? Не досліджувалось. Єдине, що відомо: N — не гомоморфізм (5.4).
6. Зв'язок із «індексикальною» логікою (Варіант 2): контекст (w,e,n) як точка 𝕊 і модальні оператори зсувів. Не розвивається тут.
